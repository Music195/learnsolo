Number of Divisors

Counting divisors from the prime factorisation

Every divisor of $N$ is built from the same primes as $N$, each used at most as many times as in $N$.

For $12 = 2^2 \times 3$: a divisor uses $2^0$, $2^1$ or $2^2$ (3 choices) and $3^0$ or $3^1$ (2 choices), so there are $3 \times 2 = 6$ divisors:

$3^0$$3^1$
$2^0$$1$$3$
$2^1$$2$$6$
$2^2$$4$$12$

Number of positive divisors

$$N = p^a\, q^b\, r^c \cdots \;\Longrightarrow\; (a + 1)(b + 1)(c + 1)\cdots$$

$p, q, r, \dots$ are different primes; add 1 to each exponent and multiply.

Sum of positive divisors

$$(1 + p + \dots + p^a)(1 + q + \dots + q^b)\cdots$$

Expanding the brackets produces every divisor exactly once. For $12$: $(1 + 2 + 4)(1 + 3) = 7 \times 4 = 28$.

Factorise into primes first. Writing $72 = 8 \times 9$ and using exponents $1, 1$ gives $4$, which is wrong: $72 = 2^3 \times 3^2$ has $(3 + 1)(2 + 1) = 12$ divisors.

Example 1

How many positive divisors does $72$ have, and what is their sum?

Show solution
  1. $72 = 2^3 \times 3^2$
  2. Number: $(3 + 1)(2 + 1) = 12$
  3. Sum: $(1 + 2 + 4 + 8)(1 + 3 + 9) = 15 \times 13 = 195$

12 divisors, sum 195

Example 2

How many positive divisors does $210$ have?

Show solution
  1. $210 = 2 \times 3 \times 5 \times 7$ (every exponent is 1)
  2. $(1 + 1)^4 = 16$

16

Example 3

Find the smallest natural number with exactly 12 positive divisors.

Show solution
  1. Write 12 as a product of (exponent + 1) values: $12$, $\;6 \times 2$, $\;4 \times 3$, $\;3 \times 2 \times 2$
  2. So $N = p^{11}$, $\;p^5 q$, $\;p^3 q^2$ or $\;p^2 q r$
  3. Put the biggest exponents on the smallest primes: $2^{11} = 2048$, $\;2^5 \times 3 = 96$, $\;2^3 \times 3^2 = 72$, $\;2^2 \times 3 \times 5 = 60$

$60$

A number has an odd number of divisors exactly when it is a perfect square: divisors come in pairs $d \times \frac{N}{d}$, except $\sqrt{N}$, which pairs with itself.
  • Factorise into primes: $N = p^a q^b \cdots$
  • Number of divisors: $(a + 1)(b + 1)\cdots$
  • Sum of divisors: $(1 + p + \dots + p^a)(1 + q + \dots + q^b)\cdots$
  • Odd number of divisors ⇔ perfect square.
