Counting Circular Permutations

Rotations look the same

At a round table only the order around the circle matters, not which chair is "first". Turning everyone one seat to the left gives the same seating.

Each circular seating appears $n$ times among the $n!$ row arrangements (once for each rotation), so there are $\dfrac{n!}{n} = (n-1)!$ circular arrangements.

Round table ($n$ different people)

$$(n - 1)!$$

Fix one person's seat, then arrange the other $n - 1$ in a row.

Necklace / bracelet (can be flipped over)

$$\frac{(n - 1)!}{2}$$

Flipping turns a clockwise order into the anticlockwise one, so each necklace was counted twice. (Needs $n \ge 3$.)

Round table explorer

Example 1

In how many ways can 6 people sit at a round table?

Show solution
  1. Fix one person; arrange the other 5: $(6 - 1)! = 5!$

$120$

Example 2

How many different necklaces can be made from 6 different beads?

Show solution
  1. As a round table: $(6 - 1)! = 120$
  2. A necklace can be turned over, so divide by 2

$60$

Example 3

3 parents and 3 children sit at a round table so that parents and children alternate. How many ways?

Show solution
  1. Seat the parents around the table first: $(3 - 1)! = 2$
  2. That leaves 3 gaps between the parents, now in fixed positions. The children fill them in a row: $3! = 6$

$2 \times 6 = 12$

Only use $(n - 1)!$ when the seats are all alike. If one seat is special (a chairperson's seat, a door, numbered chairs), rotations are no longer the same, so count as a row: $n!$.
  • Round table: $(n - 1)!$ (fix one person, arrange the rest).
  • Necklace that can be flipped: $(n - 1)!/2$.
  • Seat one group first; the second group then fills fixed gaps, like a row.
