Basic Properties of Probability

Events are sets

An event is a set of outcomes, so the set rules from counting carry over to probability: "$A$ or $B$" is $A \cup B$, "$A$ and $B$" is $A \cap B$, "not $A$" is $\overline{A}$.

Two events are mutually exclusive when they can't happen together: $A \cap B = \varnothing$. For one die, "roll a 2" and "roll an odd number" are mutually exclusive.

Range

$$0 \le P(A) \le 1, \qquad P(\varnothing) = 0, \qquad P(U) = 1$$

Addition rule

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

If $A$ and $B$ are mutually exclusive, $P(A \cap B) = 0$, so $P(A \cup B) = P(A) + P(B)$.

Complement

$$P(\overline{A}) = 1 - P(A)$$

Two dice: $P(A \cup B)$

Example 1

One card is drawn from 52. Find the probability that it is a heart or a picture card (J, Q, K).

Show solution
  1. $P(\text{heart}) = \dfrac{13}{52}$, $\;P(\text{picture}) = \dfrac{12}{52}$
  2. Both (heart J, Q, K): $\dfrac{3}{52}$
  3. $\dfrac{13 + 12 - 3}{52} = \dfrac{22}{52}$

$\dfrac{11}{26}$

Example 2

A bag has 4 red, 3 white and 2 blue balls. Two are taken out together. Find the probability that both are the same colour.

Show solution
  1. All ways: ${}_9\mathrm{C}_2 = 36$
  2. "Both red", "both white" and "both blue" are mutually exclusive, so add: ${}_4\mathrm{C}_2 + {}_3\mathrm{C}_2 + {}_2\mathrm{C}_2 = 6 + 3 + 1 = 10$

$\dfrac{10}{36} = \dfrac{5}{18}$

Example 3

$P(A) = 0.5$, $P(B) = 0.4$ and $P(A \cup B) = 0.7$. Find $P(A \cap B)$. Are $A$ and $B$ mutually exclusive?

Show solution
  1. $0.7 = 0.5 + 0.4 - P(A \cap B)$
  2. $P(A \cap B) = 0.2 \neq 0$

$P(A \cap B) = 0.2$; not mutually exclusive.

Only add probabilities directly when the events can't happen together. Otherwise you count the overlap twice and can even get an answer bigger than 1.
  • $0 \le P(A) \le 1$; $\;P(\varnothing) = 0$; $\;P(U) = 1$.
  • $P(A \cup B) = P(A) + P(B) - P(A \cap B)$; mutually exclusive → just add.
  • $P(\overline{A}) = 1 - P(A)$.
