Addition Rule for Counting

"Either this case or that case"

Split the problem into cases that can't happen at the same time. Count each case, then add.

Example: rolling two dice, how many ways give a sum of 5 or 6? A roll can't have sum 5 and sum 6, so count each and add: $4 + 5 = 9$.

Addition rule

$$\text{case } A \text{ in } m \text{ ways},\;\; \text{case } B \text{ in } n \text{ ways},\;\; \text{never both} \;\Longrightarrow\; m + n \text{ ways}$$

In set language: if $A \cap B = \varnothing$, then $n(A \cup B) = n(A) + n(B)$.

Only add when the cases can't overlap. "Sum is even or a double" overlaps (e.g. $(2, 2)$ is both), so plain adding counts it twice. Use $n(A \cup B) = n(A) + n(B) - n(A \cap B)$ from the previous note instead.

Two dice: count the sums

Example 1

Two dice are rolled. In how many ways is the sum a multiple of 5?

Show solution
  1. Possible sums are 2 to 12, so a multiple of 5 means sum $5$ or sum $10$. These cases can't happen together.
  2. Sum 5: $(1,4), (2,3), (3,2), (4,1)$, so 4 ways
  3. Sum 10: $(4,6), (5,5), (6,4)$, so 3 ways

$4 + 3 = 7$ ways

Example 2

A café has 3 sandwiches and 4 salads. You choose one item. How many choices are there?

Show solution
  1. The item is either a sandwich or a salad, never both.

$3 + 4 = 7$ choices

Example 3

How many 2-digit numbers have digits that add up to 4 or 5?

Show solution
  1. Digit sum 4 (first digit not 0): $13, 22, 31, 40$, so 4 numbers
  2. Digit sum 5: $14, 23, 32, 41, 50$, so 5 numbers

$4 + 5 = 9$

"or" (one case or another) → add.   "and then" (one step followed by another) → multiply (next note).
  • Split into cases that can't happen together, count each, then add.
  • If the cases can overlap, subtract the overlap.
  • "Or" → add; "and then" → multiply.
