Condition for a Quadrilateral to be Cyclic

Check the angles to know the circle exists

Note 12 says: on a circle → opposite angles add to $180°$. The converse is also true. If a (convex) quadrilateral has one pair of opposite angles adding to $180°$, a circle passes through all four corners.

$ABCD$ is cyclic if any one of these holds

$$\angle A + \angle C = 180° \quad\text{or}\quad \angle DCE = \angle A \quad\text{or}\quad \angle ADB = \angle ACB$$

2nd: exterior angle at $C$ ($BC$ extended to $E$) equals the opposite interior angle. 3rd: two corners on the same side of $AB$ see it at equal angles (note 11).

  1. Suppose $\angle A + \angle C = 180°$. Draw the circle through $A$, $B$, $D$, and pick any point $C'$ on its arc on the other side of $BD$ from $A$.
  2. $ABC'D$ is cyclic, so $\angle BC'D = 180° - \angle A = \angle BCD$.
  3. $C$ and $C'$ are on the same side of $BD$ and see it at the same angle, so by the converse of the inscribed angle theorem, $C$ is on the circle too.

Drag any corner

The circle goes through $A$, $B$, $D$. When $\angle A + \angle C = 180°$, $C$ lands on it.

Example 1

Quadrilateral $ABCD$ has $\angle A = 70°$, $\angle B = 80°$, $\angle C = 110°$, $\angle D = 100°$. Is it cyclic? What about $70°, 80°, 90°, 120°$?

Show solution
  1. First: $\angle A + \angle C = 70° + 110° = 180°$ → cyclic.
  2. Second: $70° + 90° = 160° \neq 180°$ → not cyclic.

The first is cyclic; the second is not.

Example 2

Show that an isosceles trapezoid ($AD \parallel BC$, $AB = DC$) is always cyclic.

Show solution
  1. An isosceles trapezoid has equal base angles: $\angle B = \angle C$.
  2. $AD \parallel BC$, so $\angle A + \angle B = 180°$ (co-interior angles).
  3. Replace $\angle B$ with $\angle C$: $\angle A + \angle C = 180°$.

Opposite angles add to $180°$, so it is cyclic.

Example 3

In $\triangle ABC$, the altitudes $AD$ and $BE$ meet at $H$. Show that $C$, $D$, $H$, $E$ are on one circle.

Show solution
  1. In quadrilateral $CDHE$: $\angle HDC = 90°$ and $\angle HEC = 90°$.
  2. These are opposite angles and add to $180°$.

$CDHE$ is cyclic (the circle has diameter $CH$).

Two right angles at opposite corners are the most common way this appears in problems (altitudes, perpendiculars).
  • One pair of opposite angles adding to $180°$ → cyclic.
  • Exterior angle = opposite interior angle → cyclic.
  • Equal angles on the same side of a side → cyclic (note 11).
