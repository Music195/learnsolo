Triangle Angle-Side Relationship

Bigger angle, longer side opposite

Open an angle wider and the side across from it gets longer. In any triangle, the largest angle faces the longest side and the smallest angle faces the shortest side. It works in both directions.

Write $a = BC$, $b = CA$, $c = AB$: side $a$ is opposite $\angle A$, and so on.

Angle–side relationship

$$b > c \iff \angle B > \angle C$$

And equal sides $\iff$ equal angles (isosceles triangle).

  1. Suppose $AC > AB$. Mark $D$ on $AC$ with $AD = AB$. Then $\triangle ABD$ is isosceles: $\angle ABD = \angle ADB$.
  2. $\angle ADB$ is an exterior angle of $\triangle BCD$, so $\angle ADB > \angle ACB$.
  3. $\angle ABC > \angle ABD = \angle ADB > \angle ACB$, so $\angle B > \angle C$.
  4. Converse: if $\angle B > \angle C$, then $b = c$ would give $\angle B = \angle C$ and $b < c$ would give $\angle B < \angle C$. Both are impossible, so $b > c$.

Example 1

In $\triangle ABC$, $\angle A = 40°$, $\angle B = 60°$, $\angle C = 80°$. Order the sides from shortest to longest.

Show solution
  1. $\angle A < \angle B < \angle C$, so the opposite sides are in the same order.

$a < b < c$, i.e. $BC < CA < AB$

Example 2

In $\triangle XYZ$, $XY = 5$, $YZ = 7$, $ZX = 8$. Which angle is largest, and which is smallest?

Show solution
  1. Longest side $ZX = 8$ is opposite $\angle Y$.
  2. Shortest side $XY = 5$ is opposite $\angle Z$.

Largest $\angle Y$, smallest $\angle Z$ (order $\angle Y > \angle X > \angle Z$)

Example 3

An isosceles triangle has base angles of $50°$. Is the base longer or shorter than the equal sides?

Show solution
  1. The top angle is $180° - 2 \times 50° = 80°$.
  2. The base faces the $80°$ angle; each equal side faces a $50°$ angle.

The base is longer.

Use the side opposite the angle, not a side touching it. $\angle A$ goes with $BC$, the only side that doesn't touch $A$.
  • Largest angle ↔ longest side; smallest angle ↔ shortest side.
  • Works both ways; equal angles ↔ equal sides.
  • Used to prove the triangle inequality (note 08).
