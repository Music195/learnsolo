Complement of a Set

Everything that is not in $A$

First fix the universal set $U$, the set of everything being considered. The complement of $A$ is everything in $U$ that is not in $A$.

The complement depends on $U$: if $A = \{2, 4\}$, its complement in $U = \{1, 2, 3, 4\}$ is $\{1, 3\}$, but in $U = \{1, 2, 3, 4, 5\}$ it is $\{1, 3, 5\}$.

Complement

$$\overline{A} = \{\,x \mid x \in U \text{ and } x \notin A\,\}$$

Read "$A$ bar". Other books write $A'$ or $A^c$; they mean the same thing.

RuleFormulaIn words

Double complement$\overline{\overline{A}} = A$"not not in $A$" means "in $A$"

Counting$n(\overline{A}) = n(U) - n(A)$useful for "at least one" problems
Complements of $A \cup B$ and $A \cap B$ follow De Morgan's laws: $\overline{A \cup B} = \overline{A} \cap \overline{B}$ and $\overline{A \cap B} = \overline{A} \cup \overline{B}$. See the next note.

Example 1

$U = \{1, 2, \dots, 10\}$ and $A = \{2, 4, 6, 8, 10\}$. Find $\overline{A}$.

Show solution
  1. Take every element of $U$ and remove the ones in $A$.

$\overline{A} = \{1, 3, 5, 7, 9\}$

Example 2

$U = \{a, b, c, d, e, f\}$ and $B = \{a, c, e\}$. Find $\overline{B}$ and $\overline{\overline{B}}$.

Show solution
  1. $\overline{B} = \{b, d, f\}$
  2. The complement of $\{b, d, f\}$ in $U$ is $\{a, c, e\}$

$\overline{B} = \{b, d, f\}$, $\;\overline{\overline{B}} = \{a, c, e\} = B$

Example 3

If $A \cap B = \varnothing$, what is $\overline{A} \cup \overline{B}$?

Show solution
  1. By De Morgan's law, $\overline{A} \cup \overline{B} = \overline{A \cap B}$
  2. $A \cap B = \varnothing$, so this is $\overline{\varnothing}$

$\overline{A} \cup \overline{B} = U$

Always take the complement inside the given $U$. If the problem says $U = \{1, \dots, 10\}$, $\overline{A}$ can never contain $0$ or $11$.
  • $\overline{A}$ = elements of $U$ not in $A$; it depends on $U$.
  • $A \cap \overline{A} = \varnothing$, $\;A \cup \overline{A} = U$, $\;\overline{\overline{A}} = A$.
  • $n(\overline{A}) = n(U) - n(A)$.
