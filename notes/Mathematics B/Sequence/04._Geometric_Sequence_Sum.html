Sum of Geometric Sequence

What are we adding up?

A geometric sequence multiplies by the same number $r$ (the common ratio) to get each new term:

$$a,\; ar,\; ar^2,\; ar^3,\; \dots,\; ar^{n-1}$$

$S_n$ is the sum of the first $n$ of these terms. Which formula you use depends on whether $r = 1$.

When $r \neq 1$

$$S_n = \frac{a(1 - r^n)}{1 - r} = \frac{a(r^n - 1)}{r - 1}$$

$S_n$ = sum of the first $n$ terms
$a$ = first term
$r$ = common ratio
$n$ = number of terms

When $r = 1$

$$S_n = na$$

Every term equals $a$ ($a, a, a, \dots$), so the sum is just $n$ copies of $a$.

Both versions of the formula give the same answer. Use $\dfrac{a(1-r^n)}{1-r}$ when $r < 1$ and $\dfrac{a(r^n-1)}{r-1}$ when $r > 1$, so you work with positive numbers.

Why the formula works: multiply and subtract

  1. Write the sum: $\;S = a + ar + ar^2 + \dots + ar^{n-1}$
  2. Multiply both sides by $r$: $\;rS = ar + ar^2 + \dots + ar^{n-1} + ar^n$
  3. Subtract the second line from the first. Every middle term cancels: $\;S - rS = a - ar^n$
  4. Factor both sides: $\;S(1 - r) = a(1 - r^n)$
  5. Divide by $1 - r$ (allowed because $r \neq 1$): $\;S_n = \dfrac{a(1 - r^n)}{1 - r}$

Adding infinitely many terms

$|r| < 1$: converges

$r^n \to 0$, so the sum settles on a finite value:

$$S_\infty = \frac{a}{1 - r}$$

$|r| \geq 1$: diverges

The terms do not shrink to $0$, so the sum never settles. There is no finite total.

(Except the trivial case $a = 0$.)

Check $|r| < 1$ before using $S_\infty = \dfrac{a}{1-r}$. For example, with $a = 1$, $r = 2$ the formula gives $-1$, but $1 + 2 + 4 + \dots$ obviously does not add up to $-1$.

Example 1

Find the sum of the first 6 terms of $3, 6, 12, 24, \dots$

Show solution
  1. $a = 3$, $\;r = 6 \div 3 = 2$, $\;n = 6$
  2. $r > 1$, so use $S_n = \dfrac{a(r^n - 1)}{r - 1}$
  3. $S_6 = \dfrac{3(2^6 - 1)}{2 - 1} = \dfrac{3 \times 63}{1}$

$S_6 = 189$

Example 2

The sum of the first 5 terms of a geometric sequence is $62$ and the common ratio is $2$. Find the first term.

Show solution
  1. $S_5 = 62$, $\;r = 2$, $\;n = 5$
  2. $S_5 = \dfrac{a(2^5 - 1)}{2 - 1} = 31a$
  3. $31a = 62$

$a = 2$

Example 3

Find the sum of the infinite series $8 + 4 + 2 + 1 + \dots$

Show solution
  1. $a = 8$, $\;r = 4 \div 8 = \tfrac{1}{2}$
  2. $|r| = \tfrac{1}{2} < 1$, so the series converges
  3. $S_\infty = \dfrac{8}{1 - \tfrac{1}{2}} = \dfrac{8}{\tfrac{1}{2}}$

$S_\infty = 16$

Where you meet geometric sums

  • Compound interest: money grows by the same percentage each period.
  • Population growth: a population multiplies by a constant factor.
  • Radioactive decay: a fixed fraction remains after each half-life.
  • Bouncing ball: each bounce reaches a fixed fraction of the previous height.
  • Loan repayments: the value of each payment is discounted by the same rate.
  • $S_n = \dfrac{a(1 - r^n)}{1 - r}$ for $r \neq 1$, and $S_n = na$ for $r = 1$.
  • The formula comes from multiplying by $r$ and subtracting.
  • An infinite geometric series converges only when $|r| < 1$, to $\dfrac{a}{1-r}$.
  • Geometric sums model repeated growth or decay by the same factor.
