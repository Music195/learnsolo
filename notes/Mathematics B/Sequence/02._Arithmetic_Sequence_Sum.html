Sum of Arithmetic Sequence

Adding up an arithmetic sequence

$S_n$ is the total of the first $n$ terms of an arithmetic sequence. There are two versions of the formula; pick the one that matches what you already know.

When you know the first and last terms

$$S_n = \frac{n}{2}(a + l)$$

$n$ = number of terms
$a$ = first term
$l$ = last term

When you know the first term and common difference

$$S_n = \frac{n}{2}\bigl[2a + (n - 1)d\bigr]$$

$n$ = number of terms
$a$ = first term
$d$ = common difference

Read $\dfrac{n}{2}(a + l)$ as number of terms × average of the first and last term. In an arithmetic sequence the average of all the terms equals the average of the first and last.

Why it works: write the sum forwards and backwards

  1. Forwards: $\;S_n = a + (a + d) + (a + 2d) + \dots + (l - d) + l$
  2. Backwards: $\;S_n = l + (l - d) + (l - 2d) + \dots + (a + d) + a$
  3. Add the two lines column by column. Every column adds to $a + l$, and there are $n$ columns: $\;2S_n = n(a + l)$
  4. Divide by 2: $\;S_n = \dfrac{n}{2}(a + l)$
  5. For the second formula, substitute the last term $l = a + (n - 1)d$: $\;S_n = \dfrac{n}{2}\bigl[2a + (n - 1)d\bigr]$

Example 1

Find the sum of the first 20 terms of $3, 7, 11, 15, \dots$

Show solution
  1. $a = 3$, $\;d = 7 - 3 = 4$, $\;n = 20$
  2. $S_{20} = \dfrac{20}{2}\bigl[2 \times 3 + 19 \times 4\bigr] = 10\,[6 + 76] = 10 \times 82$

$S_{20} = 820$

Example 2

The sum of the first 15 terms of an arithmetic sequence is $225$ and the first term is $5$. Find the common difference.

Show solution
  1. $S_{15} = 225$, $\;a = 5$, $\;n = 15$
  2. $225 = \dfrac{15}{2}\bigl[2 \times 5 + 14d\bigr]$
  3. Multiply both sides by $\dfrac{2}{15}$: $\;30 = 10 + 14d$
  4. $14d = 20$

$d = \dfrac{10}{7}$

Example 3

Find the sum of all odd numbers from $1$ to $99$.

Show solution
  1. $a = 1$, $\;l = 99$, $\;d = 2$
  2. Number of terms: $\;99 = 1 + (n - 1) \times 2$, so $n = 50$
  3. $S_{50} = \dfrac{50}{2}(1 + 99) = 25 \times 100$

$S_{50} = 2500$

Count the terms carefully. From $1$ to $99$ in steps of $2$ there are $50$ terms, not $49$ and not $99$. Use $l = a + (n - 1)d$ to find $n$ instead of guessing.
  • $S_n = \dfrac{n}{2}(a + l)$ when you know the first and last terms.
  • $S_n = \dfrac{n}{2}\bigl[2a + (n - 1)d\bigr]$ when you know $a$ and $d$.
  • Both come from adding the sum to itself written backwards.
  • Sum = number of terms × average of first and last term.
