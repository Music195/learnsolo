Square Inequalities

Squaring keeps the order, if both sides are $\ge 0$

Inequalities with $\sqrt{\phantom{a}}$ or $|\;|$ are awkward to compare directly. If both sides are not negative, compare their squares instead: the larger square belongs to the larger number.

For $a \ge 0$, $b \ge 0$

$$a > b \iff a^2 > b^2, \qquad a \ge b \iff a^2 \ge b^2$$

For any real $a, b$: $a^2 \ge b^2 \iff |a| \ge |b|$, since $|a|^2 = a^2$.

Triangle inequality

$$|a| + |b| \ge |a + b| \qquad (= \text{ when } ab \ge 0)$$
  1. Both sides are $\ge 0$, so compare squares.
  2. $(|a| + |b|)^2 - |a + b|^2 = (a^2 + 2|a||b| + b^2) - (a^2 + 2ab + b^2) = 2(|ab| - ab)$.
  3. $|ab| \ge ab$ always, so the difference is $\ge 0$; it is $0$ when $|ab| = ab$, i.e. $ab \ge 0$.

$\sqrt{a} + \sqrt{b} > \sqrt{a + b}$: two legs beat the hypotenuse

Example 1

Which is larger, $\sqrt{3} + \sqrt{5}$ or $\sqrt{2} + \sqrt{6}$?

Show solution
  1. Both positive. Squares: $8 + 2\sqrt{15}$ and $8 + 2\sqrt{12}$.
  2. $\sqrt{15} > \sqrt{12}$.

$\sqrt{3} + \sqrt{5}$ is larger.

Example 2

$a > 0$, $b > 0$. Prove $\sqrt{a} + \sqrt{b} > \sqrt{a + b}$.

Show solution
  1. Both sides positive. $(\sqrt{a} + \sqrt{b})^2 - (\sqrt{a + b})^2 = a + 2\sqrt{ab} + b - (a + b) = 2\sqrt{ab} > 0$.

Proved.

Example 3

Prove $\sqrt{2(a^2 + b^2)} \ge a + b$ for all real $a, b$. When is it an equality?

Show solution
  1. If $a + b < 0$, the left side ($\ge 0$) is bigger. Done.
  2. If $a + b \ge 0$, both sides are $\ge 0$: $2(a^2 + b^2) - (a + b)^2 = (a - b)^2 \ge 0$.
  3. Equality needs $a = b$ and $a + b \ge 0$.

Proved; equality when $a = b \ge 0$.

Squaring can reverse an inequality when a side is negative: $-3 < 2$ but $(-3)^2 > 2^2$. Check both sides are $\ge 0$ before squaring.
When the squares share a part (the $8$ in Example 1), compare only the parts that differ.
  • $a, b \ge 0$: $a > b \iff a^2 > b^2$.
  • Show both sides are $\ge 0$ before squaring.
  • $|a| + |b| \ge |a + b|$, equality when $ab \ge 0$.
