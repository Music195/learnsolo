Properties of Real Number Squares

A square is never negative

For a real number $a$, $a^2 \ge 0$. To prove $A \ge B$, work out $A - B$ and rewrite it as a sum of squares (often by completing the square). A sum of squares is $\ge 0$, so $A \ge B$.

Always state when equality holds: exactly when every square is $0$.

For real numbers $a, b$

$$a^2 \ge 0 \;(= \text{ only when } a = 0), \qquad a^2 + b^2 \ge 0 \;(= \text{ only when } a = b = 0)$$
  1. Prove $a^2 + b^2 \ge ab$.
  2. $a^2 - ab + b^2 = \left(a - \dfrac{b}{2}\right)^2 + \dfrac{3}{4}b^2$ (completing the square in $a$).
  3. Both parts are $\ge 0$, so $a^2 + b^2 - ab \ge 0$.
  4. Equality: $a - \dfrac{b}{2} = 0$ and $b = 0$, i.e. $a = b = 0$.

$y = a^2 - ab + b^2$ as a function of $a$ (choose $b$)

Example 1

Prove $2(a^2 + b^2) \ge (a + b)^2$. When does equality hold?

Show solution
  1. $2(a^2 + b^2) - (a + b)^2 = a^2 - 2ab + b^2 = (a - b)^2 \ge 0$.

Proved; equality when $a = b$.

Example 2

Prove $x^2 + y^2 \ge 2(x + y) - 2$. When does equality hold?

Show solution
  1. Difference: $x^2 - 2x + 1 + y^2 - 2y + 1 = (x - 1)^2 + (y - 1)^2 \ge 0$.

Proved; equality when $x = y = 1$.

Example 3

Prove $a^2 + b^2 + c^2 \ge ab + bc + ca$.

Show solution
  1. Twice the difference: $2a^2 + 2b^2 + 2c^2 - 2ab - 2bc - 2ca = (a - b)^2 + (b - c)^2 + (c - a)^2 \ge 0$.

Proved; equality when $a = b = c$.

Example 4

Real numbers $x, y$ satisfy $x^2 + y^2 - 4x + 6y + 13 = 0$. Find $x$ and $y$.

Show solution
  1. $(x - 2)^2 + (y + 3)^2 = 0$.
  2. A sum of two squares is $0$ only if each is $0$.

$x = 2,\; y = -3$

$a^2 \ge 0$ holds only for real $a$. For the imaginary unit, $i^2 = -1 < 0$.
When cross terms like $ab + bc + ca$ appear, doubling the difference often lets it split into squares, as in Example 3.
  • To prove $A \ge B$: show $A - B$ is a sum of squares.
  • Equality: when every square is $0$.
  • $a^2 + b^2 = 0$ (real) $\Rightarrow a = b = 0$.
