Circle and Line: Discriminant Method

Common points = common solutions

The points where a line meets a circle satisfy both equations. Substitute the line into the circle to get a quadratic in $x$: each real solution gives one common point. So the discriminant $D$ tells you how many there are.

Note 13 does the same job with distances.

After substituting: $px^2 + qx + s = 0$, $D = q^2 - 4ps$

$$D > 0: \text{ 2 points (crosses)}, \qquad D = 0: \text{ 1 point (tangent)}, \qquad D < 0: \text{ none}$$
  1. If $D > 0$, the two solutions $x_1, x_2$ are the $x$-coordinates of the two common points.
  2. By the relation between roots and coefficients, $x_1 + x_2 = -\dfrac{q}{p}$, so the midpoint of the chord has $x = -\dfrac{q}{2p}$, found without solving.

Circle $x^2 + y^2 = 5$ and line $y = 2x + k$

Example 1

Find the common points of $x^2 + y^2 = 25$ and $x + y = 7$.

Show solution
  1. $y = 7 - x$: $x^2 + (7 - x)^2 = 25 \Rightarrow 2x^2 - 14x + 24 = 0 \Rightarrow (x - 3)(x - 4) = 0$.

$(3, 4)$ and $(4, 3)$

Example 2

Find $k$ so that $x + y = k$ touches $x^2 + y^2 = 16$.

Show solution
  1. $x^2 + (k - x)^2 = 16 \Rightarrow 2x^2 - 2kx + k^2 - 16 = 0$.
  2. $\dfrac{D}{4} = k^2 - 2(k^2 - 16) = 32 - k^2 = 0$.

$k = \pm 4\sqrt{2}$

Example 3

The line $y = x + 1$ cuts $x^2 + y^2 = 4$. Find the midpoint and the length of the chord.

Show solution
  1. $x^2 + (x + 1)^2 = 4 \Rightarrow 2x^2 + 2x - 3 = 0$, so $x_1 + x_2 = -1$, $x_1x_2 = -\dfrac{3}{2}$.
  2. Midpoint: $x = -\dfrac{1}{2}$, $y = \dfrac{1}{2}$.
  3. $(x_1 - x_2)^2 = (x_1 + x_2)^2 - 4x_1x_2 = 7$. The line has slope $1$, so the chord is $\sqrt{2} \cdot \sqrt{7}$.

Midpoint $\left(-\dfrac{1}{2}, \dfrac{1}{2}\right)$, length $\sqrt{14}$

Remove one variable completely before using $D$. If the line is vertical ($x = c$), substitute $x$ and get a quadratic in $y$ instead.
Need the actual common points or the chord midpoint? Use substitution (this note). Only need to know how many points? The distance method (note 13) is quicker.
  • Substitute the line into the circle → quadratic.
  • $D > 0$ two points, $D = 0$ tangent, $D < 0$ none.
  • Chord midpoint from $x_1 + x_2 = -\dfrac{q}{p}$.
