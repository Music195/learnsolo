Parallel and Perpendicular Lines

Compare the slopes

Parallel lines have the same steepness, so the same slope. Perpendicular lines have slopes that multiply to $-1$: turning a line through $90°$ changes slope $m$ into $-\dfrac{1}{m}$.

$y = m_1x + n_1$ and $y = m_2x + n_2$

$$\text{parallel} \iff m_1 = m_2, \qquad \text{perpendicular} \iff m_1 m_2 = -1$$

($m_1 = m_2$ and $n_1 = n_2$ means the same line; here it counts as parallel.)

$a_1x + b_1y + c_1 = 0$ and $a_2x + b_2y + c_2 = 0$

$$\text{parallel} \iff a_1b_2 - a_2b_1 = 0, \qquad \text{perpendicular} \iff a_1a_2 + b_1b_2 = 0$$
  1. Move both lines to pass through $O$: $y = m_1x$ and $y = m_2x$. Take $P(1, m_1)$ and $Q(1, m_2)$.
  2. $\angle POQ = 90° \iff OP^2 + OQ^2 = PQ^2$ (Pythagoras and its converse).
  3. $(1 + m_1^2) + (1 + m_2^2) = (m_1 - m_2)^2 \iff 2 = -2m_1m_2 \iff m_1m_2 = -1$.

Line $y = mx + n$; drag $P$

Example 1

Find the lines through $(1, 2)$ parallel and perpendicular to $3x + 4y - 1 = 0$.

Show solution
  1. Parallel: same $3x + 4y$, so $3x + 4y + c = 0$ with $3 + 8 + c = 0$.
  2. Perpendicular: swap the coefficients and change one sign: $4x - 3y + c = 0$ with $4 - 6 + c = 0$.

$3x + 4y - 11 = 0$; $\;4x - 3y + 2 = 0$

Example 2

$ax + 2y - 1 = 0$ and $x + (a - 1)y + 3 = 0$. Find $a$ so that they are (i) perpendicular, (ii) parallel.

Show solution
  1. (i) $a \cdot 1 + 2(a - 1) = 0 \Rightarrow a = \dfrac{2}{3}$.
  2. (ii) $a(a - 1) - 2 \cdot 1 = 0 \Rightarrow (a - 2)(a + 1) = 0$. Both give two different lines (check the constants).

(i) $a = \dfrac{2}{3}$; (ii) $a = 2$ or $a = -1$

Example 3

Find the mirror image $B$ of $A(3, 4)$ in the line $\ell: x + y - 1 = 0$.

Show solution
  1. Let $B(p, q)$. $AB \perp \ell$: $\ell$ has slope $-1$, so $\dfrac{q - 4}{p - 3} = 1$, i.e. $q = p + 1$.
  2. The midpoint $\left(\dfrac{p + 3}{2}, \dfrac{q + 4}{2}\right)$ is on $\ell$: $p + q + 7 - 2 = 0$, i.e. $p + q = -5$.
  3. $2p + 1 = -5$, so $p = -3$, $q = -2$.

$B(-3, -2)$

Perpendicular slope is the negative reciprocal: for $m = -2$ it is $\dfrac{1}{2}$, not $2$ and not $-\dfrac{1}{2}$.
Through $(x_1, y_1)$: parallel to $ax + by + c = 0$ is $a(x - x_1) + b(y - y_1) = 0$; perpendicular is $b(x - x_1) - a(y - y_1) = 0$.
  • Parallel: $m_1 = m_2$ ($a_1b_2 - a_2b_1 = 0$).
  • Perpendicular: $m_1m_2 = -1$ ($a_1a_2 + b_1b_2 = 0$).
  • Mirror image: perpendicular + midpoint on the line.
