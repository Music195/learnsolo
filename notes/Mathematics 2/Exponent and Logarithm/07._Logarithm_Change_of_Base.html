Logarithm Change of Base

Any log can be written with any base

The rules in note 06 need a common base. The change-of-base formula converts $\log_a b$ to any base $c$ you like. Base 10 (the common logarithm, 常用対数) is especially useful for counting digits of huge numbers.

Change of base ($a, c > 0$; $a, c \ne 1$; $b > 0$)

$$\log_a b = \frac{\log_c b}{\log_c a}$$

Consequences: $\log_a b = \dfrac{1}{\log_b a}$ and $\log_a b \cdot \log_b c = \log_a c$.

Number of digits

$$N \text{ has } k \text{ digits} \iff 10^{k-1} \le N < 10^k \iff k - 1 \le \log_{10} N < k$$

Values to know: $\log_{10} 2 \approx 0.3010$, $\;\log_{10} 3 \approx 0.4771$.

  1. Let $p = \log_a b$, so $a^p = b$.
  2. Take $\log_c$ of both sides: $p\log_c a = \log_c b$.
  3. $a \ne 1$, so $\log_c a \ne 0$; divide: $p = \dfrac{\log_c b}{\log_c a}$.

How many digits does $a^n$ have?

Example 1

Calculate $\log_4 8$ and $\log_2 3 \cdot \log_3 8$.

Show solution
  1. $\log_4 8 = \dfrac{\log_2 8}{\log_2 4} = \dfrac{3}{2}$.
  2. $\log_2 3 \cdot \dfrac{\log_2 8}{\log_2 3} = \log_2 8$.

$\dfrac{3}{2}$, $\;3$

Example 2

Calculate $(\log_2 9 + \log_4 3)(\log_3 4 + \log_9 2)$.

Show solution
  1. In base 2 and 3: $\log_2 9 = 2\log_2 3$, $\log_4 3 = \dfrac{1}{2}\log_2 3$, so the first bracket is $\dfrac{5}{2}\log_2 3$.
  2. $\log_3 4 = 2\log_3 2$, $\log_9 2 = \dfrac{1}{2}\log_3 2$, so the second is $\dfrac{5}{2}\log_3 2$.
  3. $\log_2 3 \cdot \log_3 2 = 1$.

$\dfrac{25}{4}$

Example 3

How many digits does $2^{50}$ have? ($\log_{10} 2 = 0.3010$)

Show solution
  1. $\log_{10} 2^{50} = 50 \times 0.3010 = 15.05$.
  2. $15 \le 15.05 < 16$, so $10^{15} \le 2^{50} < 10^{16}$.

16 digits

Example 4

Find $\log_{10} 12$ and $\log_{10} 5$ using $\log_{10} 2 = 0.3010$, $\log_{10} 3 = 0.4771$.

Show solution
  1. $\log_{10} 12 = 2\log_{10} 2 + \log_{10} 3 = 0.6020 + 0.4771$.
  2. $\log_{10} 5 = 1 - \log_{10} 2$.

$1.0791$; $\;0.6990$

$\log_{10} N = 15.05$ means 16 digits, not 15. The number of digits is (whole-number part) + 1.
With mixed bases, change everything to the smallest base that appears (usually 2 or 3), then use the rules from note 06.
  • $\log_a b = \dfrac{\log_c b}{\log_c a}$.
  • $\log_a b \cdot \log_b a = 1$.
  • Digits of $N$: $\lfloor \log_{10} N \rfloor + 1$.
