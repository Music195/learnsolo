Product To Sum Formulas

Add or subtract two addition formulas

Adding $\sin(\alpha + \beta)$ and $\sin(\alpha - \beta)$ makes the $\cos\alpha\sin\beta$ terms cancel, leaving a product. Read one way, a product becomes a sum; read the other way, a sum becomes a product.

These are an advanced topic (発展) in Math 2; you can always derive them from note 07 instead of memorising.

Product → sum

$$\sin\alpha\cos\beta = \frac{1}{2}\{\sin(\alpha + \beta) + \sin(\alpha - \beta)\}, \qquad \cos\alpha\cos\beta = \frac{1}{2}\{\cos(\alpha + \beta) + \cos(\alpha - \beta)\}$$
$$\sin\alpha\sin\beta = -\frac{1}{2}\{\cos(\alpha + \beta) - \cos(\alpha - \beta)\}$$

Sum → product

$$\sin A + \sin B = 2\sin\frac{A + B}{2}\cos\frac{A - B}{2}, \qquad \sin A - \sin B = 2\cos\frac{A + B}{2}\sin\frac{A - B}{2}$$
$$\cos A + \cos B = 2\cos\frac{A + B}{2}\cos\frac{A - B}{2}, \qquad \cos A - \cos B = -2\sin\frac{A + B}{2}\sin\frac{A - B}{2}$$
  1. $\sin(\alpha + \beta) + \sin(\alpha - \beta) = 2\sin\alpha\cos\beta$ (the $\cos\alpha\sin\beta$ terms cancel). Divide by $2$.
  2. For sum → product, put $A = \alpha + \beta$, $B = \alpha - \beta$, so $\alpha = \dfrac{A + B}{2}$, $\beta = \dfrac{A - B}{2}$.
  3. The other formulas come the same way from $\cos(\alpha \pm \beta)$.

$\sin m\theta \cos n\theta = \dfrac{1}{2}\{\sin(m + n)\theta + \sin(m - n)\theta\}$

Example 1

Find $\sin 75° \cos 15°$.

Show solution
  1. $\dfrac{1}{2}(\sin 90° + \sin 60°) = \dfrac{1}{2}\left(1 + \dfrac{\sqrt{3}}{2}\right)$.

$\dfrac{2 + \sqrt{3}}{4}$

Example 2

Find $\sin 75° + \sin 15°$.

Show solution
  1. $2\sin 45° \cos 30° = 2 \cdot \dfrac{\sqrt{2}}{2} \cdot \dfrac{\sqrt{3}}{2}$.

$\dfrac{\sqrt{6}}{2}$

Example 3

Solve $\sin 4x - \sin 2x = 0$ for $0 \le x < \pi$.

Show solution
  1. $2\cos 3x \sin x = 0$, so $\cos 3x = 0$ or $\sin x = 0$.
  2. $0 \le 3x < 3\pi$: $3x = \dfrac{\pi}{2}, \dfrac{3}{2}\pi, \dfrac{5}{2}\pi$, so $x = \dfrac{\pi}{6}, \dfrac{\pi}{2}, \dfrac{5}{6}\pi$. And $\sin x = 0$: $x = 0$.

$x = 0, \dfrac{\pi}{6}, \dfrac{\pi}{2}, \dfrac{5}{6}\pi$

The two families in Example 3, $x = n\pi$ and $x = \dfrac{\pi}{6} + \dfrac{n\pi}{3}$, do not combine into $x = \dfrac{n\pi}{3}$: $x = \dfrac{\pi}{3}$ gives $\sin\dfrac{4\pi}{3} - \sin\dfrac{2\pi}{3} = -\sqrt{3} \ne 0$. List the answers in the given range instead.
If you forget a formula, write $\sin(\alpha + \beta)$ and $\sin(\alpha - \beta)$ (or the $\cos$ pair) and add or subtract them.
  • Product → sum: add/subtract two addition formulas.
  • Sum → product: $A = \alpha + \beta$, $B = \alpha - \beta$.
  • Useful for $\sin A \pm \sin B = 0$ type equations.
