Position Vector of Division Points

A weighted average of the two ends

Fix an origin O. The position vector (位置ベクトル) of a point P is $\vec{p} = \overrightarrow{OP}$, and we write P$(\vec{p})$.

The point dividing AB internally in $m : n$ is $\dfrac{n\vec{a} + m\vec{b}}{m + n}$: the ratio numbers cross over, because the point is closer to the end with the smaller share. For external division, replace $n$ by $-n$.

A$(\vec{a})$, B$(\vec{b})$, $m, n > 0$

$$\text{internal } m : n: \;\frac{n\vec{a} + m\vec{b}}{m + n}, \qquad \text{external } m : n: \;\frac{-n\vec{a} + m\vec{b}}{m - n} \;\; (m \ne n)$$

Midpoint: $\dfrac{\vec{a} + \vec{b}}{2}$. In coordinates, apply the same formula to $x$ and to $y$.

  1. P divides AB internally in $m : n$, so $\overrightarrow{AP} = \dfrac{m}{m + n}\overrightarrow{AB}$.
  2. $\vec{p} - \vec{a} = \dfrac{m}{m + n}(\vec{b} - \vec{a})$, so $\vec{p} = \dfrac{(m + n)\vec{a} - m\vec{a} + m\vec{b}}{m + n} = \dfrac{n\vec{a} + m\vec{b}}{m + n}$.
  3. External: $\overrightarrow{AP} = \dfrac{m}{m - n}\overrightarrow{AB}$ gives $\dfrac{-n\vec{a} + m\vec{b}}{m - n}$ the same way.

Example 1

A$(2, 4)$, B$(8, 6)$. Find the point dividing AB internally in $2 : 3$.

Show solution
  1. $\dfrac{3(2, 4) + 2(8, 6)}{5} = \dfrac{(22, 24)}{5}$

$\left(\dfrac{22}{5}, \dfrac{24}{5}\right)$

Example 2

A$(1, 3)$, B$(5, 7)$. Find the points dividing AB externally in $3 : 2$ and in $2 : 3$.

Show solution
  1. $3 : 2$: $\dfrac{-2(1, 3) + 3(5, 7)}{1} = (13, 15)$.
  2. $2 : 3$: $\dfrac{-3(1, 3) + 2(5, 7)}{-1} = -(7, 5)$.

$(13, 15)$ (beyond B) and $(-7, -5)$ (beyond A)

Example 3

In triangle OAB with $\overrightarrow{OA} = \vec{a}$, $\overrightarrow{OB} = \vec{b}$, M is the midpoint of OA and N divides AB in $1 : 2$. Write $\overrightarrow{MN}$.

Show solution
  1. $\overrightarrow{OM} = \dfrac{1}{2}\vec{a}$, $\;\overrightarrow{ON} = \dfrac{2\vec{a} + \vec{b}}{3}$.
  2. $\overrightarrow{MN} = \dfrac{2\vec{a} + \vec{b}}{3} - \dfrac{\vec{a}}{2}$.

$\overrightarrow{MN} = \dfrac{1}{6}\vec{a} + \dfrac{1}{3}\vec{b}$

Example 4

Triangle ABC; P satisfies $3\overrightarrow{PA} + 2\overrightarrow{PB} + \overrightarrow{PC} = \vec{0}$. Where is P?

Show solution
  1. Use A as the origin: $\overrightarrow{AB} = \vec{b}$, $\overrightarrow{AC} = \vec{c}$, $\overrightarrow{AP} = \vec{p}$. Then $-3\vec{p} + 2(\vec{b} - \vec{p}) + (\vec{c} - \vec{p}) = \vec{0}$, so $\vec{p} = \dfrac{2\vec{b} + \vec{c}}{6}$.
  2. Write it as $\vec{p} = \dfrac{1}{2} \cdot \dfrac{2\vec{b} + \vec{c}}{3}$. Here $\dfrac{2\vec{b} + \vec{c}}{3}$ is the point D dividing BC in $1 : 2$.

D divides BC in $1 : 2$, and P is the midpoint of AD

The weights cross: for $m : n$, $\vec{a}$ gets $n$ and $\vec{b}$ gets $m$. Writing $\dfrac{m\vec{a} + n\vec{b}}{m + n}$ gives the point dividing in $n : m$ instead.
In conditions like Example 4, choose one vertex as the origin: its position vector is $\vec{0}$ and the algebra gets shorter.
  • Internal $m : n$: $\dfrac{n\vec{a} + m\vec{b}}{m + n}$; external: $\dfrac{-n\vec{a} + m\vec{b}}{m - n}$.
  • External with $m > n$ is beyond B; with $m < n$, beyond A.
  • Midpoint: $\dfrac{\vec{a} + \vec{b}}{2}$.
