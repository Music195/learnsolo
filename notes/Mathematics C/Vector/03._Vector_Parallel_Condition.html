Vector Parallel Condition

Parallel means "a real multiple"

Two nonzero vectors are parallel (平行, $\vec{a} \parallel \vec{b}$) when they point the same way or exactly opposite ways. That happens exactly when one is a real multiple of the other: $\vec{b} = k\vec{a}$.

In components, $(b_1, b_2) = k(a_1, a_2)$ means the components are in the same ratio. Cross-multiplying removes $k$ and gives the handy test $a_1b_2 - a_2b_1 = 0$.

$\vec{a} = (a_1, a_2) \ne \vec{0}$, $\vec{b} = (b_1, b_2) \ne \vec{0}$

$$\vec{a} \parallel \vec{b} \iff \vec{b} = k\vec{a} \text{ for some real } k \iff a_1b_2 - a_2b_1 = 0$$

$k > 0$: same direction. $k < 0$: opposite direction.

  1. If $\vec{b} = k\vec{a}$, then $a_1b_2 - a_2b_1 = a_1(ka_2) - a_2(ka_1) = 0$.
  2. Conversely, let $a_1b_2 = a_2b_1$ with $a_1 \ne 0$. Put $k = \dfrac{b_1}{a_1}$; then $b_1 = ka_1$ and $b_2 = \dfrac{a_2b_1}{a_1} = ka_2$.
  3. (If $a_1 = 0$, then $a_2 \ne 0$; use $k = \dfrac{b_2}{a_2}$ the same way.)

Example 1

Which are parallel? (i) $(2, 3)$ and $(4, 6)$ (ii) $(1, -2)$ and $(-3, 6)$ (iii) $(1, 2)$ and $(2, 3)$

Show solution
  1. (i) $2 \cdot 6 - 3 \cdot 4 = 0$: parallel, $(4, 6) = 2(2, 3)$.
  2. (ii) $1 \cdot 6 - (-2)(-3) = 0$: parallel, $(-3, 6) = -3(1, -2)$.
  3. (iii) $1 \cdot 3 - 2 \cdot 2 = -1 \ne 0$: not parallel.

Example 2

$\vec{a} = (x, 3)$ and $\vec{b} = (2, -1)$ are parallel. Find $x$.

Show solution
  1. $x \cdot (-1) - 3 \cdot 2 = 0$.

$x = -6$

Example 3

Find the unit vectors parallel to $\vec{a} = (3, -4)$.

Show solution
  1. $|\vec{a}| = 5$; parallel unit vectors are $\pm\dfrac{\vec{a}}{5}$.

$\left(\dfrac{3}{5}, -\dfrac{4}{5}\right)$ and $\left(-\dfrac{3}{5}, \dfrac{4}{5}\right)$

Example 4

$\vec{a} = (1, 2)$, $\vec{b} = (1, -1)$, $\vec{c} = (3, 1)$. Find $t$ so that $\vec{a} + t\vec{b}$ is parallel to $\vec{c}$.

Show solution
  1. $\vec{a} + t\vec{b} = (1 + t, 2 - t)$.
  2. $(1 + t) \cdot 1 - (2 - t) \cdot 3 = 0$, so $4t - 5 = 0$.

$t = \dfrac{5}{4}$

The ratio test $\dfrac{b_1}{a_1} = \dfrac{b_2}{a_2}$ breaks when a component is $0$. Use $a_1b_2 - a_2b_1 = 0$ or $\vec{b} = k\vec{a}$ instead; neither divides. Also remember the opposite direction: "parallel unit vectors" means two answers, $\pm$.
$a_1b_2 - a_2b_1$ is "cross-multiply and subtract", the same as checking two fractions are equal. It will come back for triangle areas (note 11).
  • $\vec{a} \parallel \vec{b} \iff \vec{b} = k\vec{a}$ (nonzero vectors).
  • Component test: $a_1b_2 - a_2b_1 = 0$.
  • Parallel unit vectors: $\pm\dfrac{\vec{a}}{|\vec{a}|}$.
