Vector Scalar Multiplication Properties

Stretch, shrink or flip

For a real number $k$, the real multiple (実数倍) $k\vec{a}$ is $\vec{a}$ stretched by $|k|$. If $k > 0$ it points the same way as $\vec{a}$; if $k < 0$ it points the opposite way; if $k = 0$ it is $\vec{0}$.

Real multiples follow the same algebra rules as ordinary numbers, so expressions like $2(\vec{a} + 3\vec{b}) - 3(\vec{a} - \vec{b})$ simplify just like $2(x + 3y) - 3(x - y)$.

$k$, $l$ real

$$k(l\vec{a}) = (kl)\vec{a}, \qquad (k + l)\vec{a} = k\vec{a} + l\vec{a}, \qquad k(\vec{a} + \vec{b}) = k\vec{a} + k\vec{b}$$
$$|k\vec{a}| = |k|\,|\vec{a}|, \qquad \text{unit vector along } \vec{a}: \;\frac{\vec{a}}{|\vec{a}|} \;\; (\vec{a} \ne \vec{0})$$
  1. $\dfrac{1}{|\vec{a}|} > 0$, so $\dfrac{\vec{a}}{|\vec{a}|}$ points the same way as $\vec{a}$.
  2. Its length is $\dfrac{1}{|\vec{a}|} \cdot |\vec{a}| = 1$.

Example 2

Solve $3\vec{x} - \vec{a} = \vec{x} + 5\vec{b}$ for $\vec{x}$.

Show solution
  1. $2\vec{x} = \vec{a} + 5\vec{b}$.

$\vec{x} = \dfrac{1}{2}\vec{a} + \dfrac{5}{2}\vec{b}$

Example 3

Solve the pair $\vec{x} + \vec{y} = \vec{a}$, $\vec{x} - 2\vec{y} = \vec{b}$.

Show solution
  1. Subtract: $3\vec{y} = \vec{a} - \vec{b}$.
  2. Then $\vec{x} = \vec{a} - \vec{y} = \dfrac{2\vec{a} + \vec{b}}{3}$.

$\vec{x} = \dfrac{2\vec{a} + \vec{b}}{3}$, $\;\vec{y} = \dfrac{\vec{a} - \vec{b}}{3}$

Example 4

$|\vec{a}| = 4$. Find the unit vector along $\vec{a}$, and the vector of length $6$ pointing opposite to $\vec{a}$.

Show solution
  1. Unit vector: $\dfrac{\vec{a}}{4}$.
  2. Opposite, length $6$: $-6 \cdot \dfrac{\vec{a}}{4}$.

$\dfrac{1}{4}\vec{a}$ and $-\dfrac{3}{2}\vec{a}$

$|k\vec{a}| = |k||\vec{a}|$, with $|k|$: $|-3\vec{a}| = 3|\vec{a}|$, not $-3|\vec{a}|$. A length is never negative.
Treat $\vec{a}$ and $\vec{b}$ like the letters $x$ and $y$ in algebra: expand, collect, and solve vector equations the same way.
  • $k > 0$: same direction; $k < 0$: opposite; length $\times |k|$.
  • Usual algebra rules hold for $k\vec{a}$.
  • Unit vector: $\dfrac{\vec{a}}{|\vec{a}|}$.
