Hyperbola: Basic Properties

A constant difference of two distances

Fix two foci F and F′. The points P where $|PF - PF'|$ equals a fixed constant form a hyperbola (双曲線). It has two separate branches, one curving round each focus.

Far from the centre, each branch gets closer and closer to a pair of straight lines, the asymptotes (漸近線).

$a > 0$, $b > 0$: foci on the $x$-axis

$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1, \qquad \text{foci } (\pm\sqrt{a^2 + b^2},\, 0)$$
$$|PF - PF'| = 2a, \qquad \text{asymptotes } y = \pm\frac{b}{a}x$$

Vertices $(\pm a, 0)$. $\;\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = -1$ opens up and down, with foci $(0, \pm\sqrt{a^2 + b^2})$ and $|PF - PF'| = 2b$.

  1. The equation itself comes from $|PF - PF'| = 2a$ by squaring twice, as for the ellipse. This time $c^2 - a^2 = b^2$.
  2. Solve for $y$: $y = \pm\dfrac{b}{a}x\sqrt{1 - \dfrac{a^2}{x^2}}$.
  3. As $|x| \to \infty$, $\dfrac{a^2}{x^2} \to 0$, so the curve approaches $y = \pm\dfrac{b}{a}x$. To sketch them, draw the box $|x| \le a$, $|y| \le b$; the asymptotes are its diagonals.

Drag $P$: the difference $|PF - PF'|$ never changes

Example 1

For $\dfrac{x^2}{9} - \dfrac{y^2}{16} = 1$, find the foci, vertices and asymptotes.

Show solution
  1. $a = 3$, $b = 4$, $\sqrt{9 + 16} = 5$.

Foci $(\pm 5, 0)$; vertices $(\pm 3, 0)$; asymptotes $y = \pm\dfrac{4}{3}x$

Example 2

Find the hyperbola with foci $(0, \pm 5)$ and vertices $(0, \pm 3)$.

Show solution
  1. Opens up and down: $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = -1$ with $b = 3$.
  2. $a^2 + b^2 = 25$, so $a^2 = 16$.

$\dfrac{x^2}{16} - \dfrac{y^2}{9} = -1$

Example 3

Find the hyperbola with foci $(\pm 4, 0)$ for which $|PF - PF'| = 4$.

Show solution
  1. $2a = 4$, so $a = 2$; $b^2 = 4^2 - 2^2 = 12$.

$\dfrac{x^2}{4} - \dfrac{y^2}{12} = 1$

Example 4

A hyperbola has asymptotes $y = \pm 2x$ and passes through $(1, 0)$. Find it.

Show solution
  1. $(1, 0)$ is a vertex on the $x$-axis, so $a = 1$; $\dfrac{b}{a} = 2$ gives $b = 2$.

$x^2 - \dfrac{y^2}{4} = 1$

For a hyperbola the focus distance is $\sqrt{a^2 + b^2}$ (plus). Here $a$ is not necessarily bigger than $b$. The sign of the right-hand side ($+1$ or $-1$) tells you whether the curve opens left–right or up–down.
To get the asymptotes, replace the $1$ on the right with $0$: $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 0$ factorises into $\dfrac{x}{a} = \pm\dfrac{y}{b}$.
  • Hyperbola: $|PF - PF'| = $ constant.
  • $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$: foci $(\pm\sqrt{a^2 + b^2}, 0)$, asymptotes $y = \pm\dfrac{b}{a}x$.
  • $= -1$: the same asymptotes, opening up and down.
