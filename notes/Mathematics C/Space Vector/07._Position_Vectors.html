Position Vectors

Every point is an arrow from O

Fix the origin O. Each point P then has a position vector (位置ベクトル) $\vec{p} = \overrightarrow{OP}$, and we write P$(\vec{p})$. Points become vectors, so geometry becomes vector algebra.

The key fact: P lies on the plane ABC exactly when $\vec{p} = s\vec{a} + t\vec{b} + u\vec{c}$ with $s + t + u = 1$. Same idea as "P on line AB ⇔ coefficients add to 1" in the plane.

A$(\vec{a})$, B$(\vec{b})$, C$(\vec{c})$

$$\overrightarrow{AB} = \vec{b} - \vec{a}, \qquad \text{midpoint of AB: } \frac{\vec{a} + \vec{b}}{2}$$
$$\text{centroid of triangle ABC: } \frac{\vec{a} + \vec{b} + \vec{c}}{3}$$
$$\text{P on plane ABC} \iff \vec{p} = s\vec{a} + t\vec{b} + u\vec{c}, \;\; s + t + u = 1$$

Equivalently $\overrightarrow{AP} = t\overrightarrow{AB} + u\overrightarrow{AC}$. (O, A, B, C not all on one plane.)

  1. P is on plane ABC $\iff$ $\overrightarrow{AP} = t\overrightarrow{AB} + u\overrightarrow{AC}$ for some real $t$, $u$.
  2. In position vectors: $\vec{p} - \vec{a} = t(\vec{b} - \vec{a}) + u(\vec{c} - \vec{a})$.
  3. So $\vec{p} = (1 - t - u)\vec{a} + t\vec{b} + u\vec{c}$. Writing $s = 1 - t - u$ gives $s + t + u = 1$.

Tetrahedron OABC and $\vec{p} = s\vec{a} + t\vec{b} + u\vec{c}$

Example 1

A$(1, 2, 3)$, B$(4, 5, -1)$. Find the midpoint M of AB, and the centroid G of triangle ABC where C$(1, -1, 4)$.

Show solution
  1. M $= \dfrac{1}{2}(5, 7, 2)$.
  2. G $= \dfrac{1}{3}(6, 6, 6)$.

M$\left(\dfrac{5}{2}, \dfrac{7}{2}, 1\right)$, G$(2, 2, 2)$

Example 2

Tetrahedron OABC with $\overrightarrow{OA} = \vec{a}$, $\overrightarrow{OB} = \vec{b}$, $\overrightarrow{OC} = \vec{c}$. G is the centroid of triangle ABC. Write $\overrightarrow{OG}$, and the vector to the midpoint M of OG.

Show solution
  1. $\overrightarrow{OG} = \dfrac{\vec{a} + \vec{b} + \vec{c}}{3}$.
  2. $\overrightarrow{OM} = \dfrac{1}{2}\overrightarrow{OG}$.

$\overrightarrow{OG} = \dfrac{1}{3}(\vec{a} + \vec{b} + \vec{c})$, $\;\overrightarrow{OM} = \dfrac{1}{6}(\vec{a} + \vec{b} + \vec{c})$

Example 3

In tetrahedron OABC, the point P with $\overrightarrow{OP} = k(\vec{a} + 2\vec{b} + 3\vec{c})$ lies on plane ABC. Find $k$.

Show solution
  1. Coefficients $k$, $2k$, $3k$ must add to $1$: $6k = 1$.

$k = \dfrac{1}{6}$

Example 4

Do A$(1, 0, 0)$, B$(0, 1, 0)$, C$(0, 0, 1)$ and D$(2, -1, 0)$ lie on one plane?

Show solution
  1. Try $\overrightarrow{AD} = t\overrightarrow{AB} + u\overrightarrow{AC}$: $(1, -1, 0) = t(-1, 1, 0) + u(-1, 0, 1)$.
  2. $z$: $u = 0$; then $x$: $-t = 1$, $t = -1$, and $y$: $t = -1$ ✓.

Yes: $\overrightarrow{AD} = -\overrightarrow{AB}$, so D is on plane ABC

The "$s + t + u = 1$" test only works when $\vec{p}$, $\vec{a}$, $\vec{b}$, $\vec{c}$ are all written from the same origin O, and O itself is not on the plane ABC.
Because $\vec{a}$, $\vec{b}$, $\vec{c}$ (of a tetrahedron) don't lie in one plane, the coefficients in $s\vec{a} + t\vec{b} + u\vec{c}$ are unique. If two expressions for the same point come out, you may compare coefficients.
  • $\overrightarrow{AB} = \vec{b} - \vec{a}$; midpoint $\dfrac{\vec{a} + \vec{b}}{2}$; centroid $\dfrac{\vec{a} + \vec{b} + \vec{c}}{3}$.
  • P on plane ABC $\iff$ $\vec{p} = s\vec{a} + t\vec{b} + u\vec{c}$, $s + t + u = 1$.
  • Coefficients along three non-coplanar vectors are unique.
