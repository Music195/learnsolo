Component Representation of Vector Operations

End minus start

The vector $\overrightarrow{AB}$ says how to walk from A to B: so far along $x$, so far along $y$, so far along $z$. Each step is (B's coordinate) − (A's coordinate).

Its length is the distance AB. So the distance formula in space is just $|\overrightarrow{AB}|$ written out.

A$(a_1, a_2, a_3)$, B$(b_1, b_2, b_3)$

$$\overrightarrow{AB} = (b_1 - a_1,\; b_2 - a_2,\; b_3 - a_3)$$
$$\text{AB} = |\overrightarrow{AB}| = \sqrt{(b_1 - a_1)^2 + (b_2 - a_2)^2 + (b_3 - a_3)^2}$$
  1. $\overrightarrow{OA} = (a_1, a_2, a_3)$ and $\overrightarrow{OB} = (b_1, b_2, b_3)$.
  2. Going O → A → B is the same as O → B: $\overrightarrow{OA} + \overrightarrow{AB} = \overrightarrow{OB}$.
  3. So $\overrightarrow{AB} = \overrightarrow{OB} - \overrightarrow{OA}$, computed component by component.

From A$(1, -1, 0)$ to B: one step along each axis

Example 1

A$(1, 2, 3)$, B$(4, -1, 2)$. Find $\overrightarrow{AB}$ and AB.

Show solution
  1. $\overrightarrow{AB} = (3, -3, -1)$.
  2. $\sqrt{9 + 9 + 1}$

$(3, -3, -1)$, AB $= \sqrt{19}$

Example 2

A$(1, 0, 2)$, B$(3, 1, 0)$, C$(2, 4, 1)$. Find D so that ABCD is a parallelogram.

Show solution
  1. $\overrightarrow{AD} = \overrightarrow{BC} = (-1, 3, 1)$.
  2. D $=$ A $+ (-1, 3, 1)$.

D$(0, 3, 3)$

Example 3

Find the point P on the $x$-axis that is equally far from A$(1, 2, 3)$ and B$(3, 0, -1)$.

Show solution
  1. P$(x, 0, 0)$: $(x - 1)^2 + 4 + 9 = (x - 3)^2 + 0 + 1$.
  2. $-2x + 14 = -6x + 10$, so $4x = -4$.

P$(-1, 0, 0)$

Example 4

Show that A$(1, 1, 0)$, B$(0, 1, 1)$, C$(1, 0, 1)$ form an equilateral triangle.

Show solution
  1. $\overrightarrow{AB} = (-1, 0, 1)$, $\overrightarrow{BC} = (1, -1, 0)$, $\overrightarrow{CA} = (0, 1, -1)$.
  2. Each has length $\sqrt{2}$.

AB = BC = CA $= \sqrt{2}$

$\overrightarrow{AB}$ is B − A, not A − B. The wrong order gives $\overrightarrow{BA} = -\overrightarrow{AB}$, the same length but the opposite direction.
"ABCD is a parallelogram" is the same as $\overrightarrow{AD} = \overrightarrow{BC}$ (or $\overrightarrow{AB} = \overrightarrow{DC}$). Keep the letters in cyclic order and the condition writes itself.
  • $\overrightarrow{AB} = \overrightarrow{OB} - \overrightarrow{OA}$: end minus start.
  • AB $= |\overrightarrow{AB}|$.
  • Parallelogram ABCD: $\overrightarrow{AD} = \overrightarrow{BC}$.
