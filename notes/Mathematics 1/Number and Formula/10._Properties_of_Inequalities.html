Properties of Inequalities

Like equations, except for negative multipliers

You can add, subtract, multiply and divide both sides of an inequality just as with an equation. The one difference: multiplying or dividing by a negative number flips the sign, because it reflects the number line ($2 < 5$ but $-2 > -5$).

Properties (for $a < b$)

$$a + c < b + c, \qquad a - c < b - c$$
$$c > 0:\; ac < bc,\; \frac{a}{c} < \frac{b}{c} \qquad\quad c < 0:\; ac > bc,\; \frac{a}{c} > \frac{b}{c}$$

Apply the same operation to both sides of $a < b$

Example 1

Solve $3 - 2x > 7$.

Show solution
  1. Subtract 3: $-2x > 4$.
  2. Divide by $-2$ and flip: $x < -2$.

$x < -2$

Example 2

Solve $\dfrac{x - 1}{2} \le \dfrac{2x + 1}{3}$.

Show solution
  1. Multiply by 6 (positive, no flip): $3(x - 1) \le 2(2x + 1)$.
  2. $3x - 3 \le 4x + 2 \Rightarrow -x \le 5 \Rightarrow x \ge -5$.

$x \ge -5$

Example 3

Solve the system $\begin{cases} 2x + 1 > x - 3 \\ 3x - 2 \le x + 6 \end{cases}$.

Show solution
  1. First: $x > -4$. Second: $2x \le 8 \Rightarrow x \le 4$.
  2. Both must hold: take the overlap on the number line.

$-4 < x \le 4$

Example 4

If $-1 < x < 3$, find the range of $2 - 3x$.

Show solution
  1. Multiply by $-3$ and flip: $3 > -3x > -9$, i.e. $-9 < -3x < 3$.
  2. Add 2: $-7 < 2 - 3x < 5$.

$-7 < 2 - 3x < 5$

Never multiply both sides by an expression whose sign you don't know (like $x$): you can't tell whether to flip.
For systems, draw both answers on one number line. Use a filled dot for $\le, \ge$ and an open dot for $<, >$, then read off the overlap.
  • Adding/subtracting never changes the sign.
  • × or ÷ by a positive keeps it; by a negative flips it.
  • Systems: solve each, then take the overlap.
