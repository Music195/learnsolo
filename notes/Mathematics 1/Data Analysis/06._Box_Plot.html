Box Plot

Five numbers in one picture

A box plot (box-and-whisker plot) draws the five-number summary: minimum, $Q_1$, median, $Q_3$, maximum.

The box runs from $Q_1$ to $Q_3$ with a line at the median, so it holds the middle half of the data. The whiskers reach out to the minimum and maximum. Each of the four parts contains about a quarter of the data.

Outliers (外れ値)

$$x < Q_1 - 1.5 \times \text{IQR} \quad\text{or}\quad x > Q_3 + 1.5 \times \text{IQR}$$

Such values are drawn as separate dots, and the whiskers stop at the most extreme values that are not outliers.

Find the five-number summary of 3, 7, 8, 12, 15, 18, 22.

  1. Median 12. Lower half 3, 7, 8 → $Q_1 = 7$. Upper half 15, 18, 22 → $Q_3 = 18$.

min 3, $Q_1 = 7$, median 12, $Q_3 = 18$, max 22

Example 2

Is 50 an outlier in 1, 3, 5, 7, 9, 11, 13, 50?

Show solution
  1. $Q_1 = \dfrac{3 + 5}{2} = 4$, $Q_3 = \dfrac{11 + 13}{2} = 12$, IQR $= 8$.
  2. Upper limit: $12 + 1.5 \times 8 = 24$, and $50 > 24$.

Yes. The right whisker stops at 13 and 50 is drawn as a dot.

Example 3

A = 2, 4, 6, 8, 10 and B = 1, 3, 7, 9, 15. Which has the larger IQR?

Show solution
  1. A: lower half 2, 4 → $Q_1 = 3$; upper half 8, 10 → $Q_3 = 9$. IQR $= 6$.
  2. B: lower half 1, 3 → $Q_1 = 2$; upper half 9, 15 → $Q_3 = 12$. IQR $= 10$.

B (10 against 6)

A box plot hides individual values but shows shape: a long right whisker or a median near $Q_1$ means the data is stretched towards large values. Several box plots side by side make groups easy to compare.
A longer part does not contain more data. Each of the four parts holds about a quarter of the values; a long part just means those values are spread out.
  • Box plot = min, $Q_1$, median, $Q_3$, max.
  • Box length = IQR; each part ≈ a quarter of the data.
  • Outliers: beyond $1.5 \times$ IQR from the box.
