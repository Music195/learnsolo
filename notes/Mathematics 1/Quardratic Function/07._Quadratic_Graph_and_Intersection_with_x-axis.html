Quadratic Graph and Intersection with x-axis

Where the graph meets $y = 0$

The $x$-axis is the line $y = 0$. So the $x$-coordinates of the points where $y = ax^2 + bx + c$ meets the $x$-axis are exactly the real solutions of $ax^2 + bx + c = 0$.

The discriminant tells you how many such points there are, before you solve anything.

Common points with the $x$-axis

$$D > 0: \text{ 2 points (crosses)}, \qquad D = 0: \text{ 1 point (touches, 接する)}, \qquad D < 0: \text{ none}$$

When it touches, the touching point is the vertex.

Drag the vertex $V$ of $y = a(x - p)^2 + q$

Example 1

Find where $y = x^2 - x - 6$ meets the $x$-axis.

Show solution
  1. $x^2 - x - 6 = 0 \Rightarrow (x + 2)(x - 3) = 0$.

$(-2, 0)$ and $(3, 0)$

Example 2

Find the length of the segment that the $x$-axis cuts from $y = x^2 - 2x - 2$.

Show solution
  1. $x^2 - 2x - 2 = 0 \Rightarrow x = 1 \pm \sqrt{3}$.
  2. Length $= (1 + \sqrt{3}) - (1 - \sqrt{3})$.

$2\sqrt{3}$

Example 3

Find $m$ so that $y = x^2 + mx + 2m - 3$ touches the $x$-axis, and find the touching point.

Show solution
  1. $D = m^2 - 4(2m - 3) = m^2 - 8m + 12 = (m - 2)(m - 6) = 0$.
  2. Touching point $x = -\dfrac{m}{2}$.

$m = 2$: $(-1, 0)$; $\;m = 6$: $(-3, 0)$

Example 4

Find the common points of $y = x^2 - 3x + 1$ and the line $y = x - 2$.

Show solution
  1. Set equal: $x^2 - 3x + 1 = x - 2 \Rightarrow x^2 - 4x + 3 = 0 \Rightarrow x = 1, 3$.
  2. $y = x - 2$ gives $y = -1, 1$.

$(1, -1)$ and $(3, 1)$

Shortcut without $D$: for $a > 0$, the graph meets the $x$-axis twice exactly when the vertex is below it ($q < 0$). Try it in the demo.
