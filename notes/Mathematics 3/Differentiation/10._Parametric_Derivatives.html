Parametric Derivatives

Slope = vertical speed ÷ horizontal speed

A curve given by $x = f(t)$, $y = g(t)$ is traced by a point moving with time $t$. At each moment it moves $\dfrac{dx}{dt}$ sideways and $\dfrac{dy}{dt}$ up per unit time. The direction it moves in is the tangent, so the slope is the ratio of the two speeds.

First derivative

$$\frac{dy}{dx} = \frac{\;\dfrac{dy}{dt}\;}{\dfrac{dx}{dt}} = \frac{g'(t)}{f'(t)} \qquad (f'(t) \ne 0)$$

$\dfrac{dx}{dt} = 0$ and $\dfrac{dy}{dt} \ne 0$: vertical tangent. $\;\dfrac{dy}{dt} = 0$ and $\dfrac{dx}{dt} \ne 0$: horizontal tangent.

Second derivative

$$\frac{d^2y}{dx^2} = \frac{d}{dt}\left(\frac{dy}{dx}\right) \Big/ \frac{dx}{dt}$$

Differentiate $\dfrac{dy}{dx}$ (a function of $t$) with respect to $t$, then divide by $\dfrac{dx}{dt}$ again.

  1. Where $f'(t) \ne 0$, $t$ can be seen as a function of $x$, and $\dfrac{dt}{dx} = 1 \Big/ \dfrac{dx}{dt}$ (inverse function rule).
  2. Chain rule: $\dfrac{dy}{dx} = \dfrac{dy}{dt} \cdot \dfrac{dt}{dx} = \dfrac{dy}{dt} \Big/ \dfrac{dx}{dt}$.
  3. Apply the same step to $\dfrac{dy}{dx}$ in place of $y$ to get $\dfrac{d^2y}{dx^2}$.

The velocity arrow points along the tangent

Example 1

$x = t^2$, $y = t^3$. Find $\dfrac{dy}{dx}$ and $\dfrac{d^2y}{dx^2}$ ($t \ne 0$).

Show solution
  1. $\dfrac{dx}{dt} = 2t$, $\dfrac{dy}{dt} = 3t^2$, so $\dfrac{dy}{dx} = \dfrac{3t^2}{2t} = \dfrac{3}{2}t$.
  2. $\dfrac{d}{dt}\left(\dfrac{3}{2}t\right) = \dfrac{3}{2}$; divide by $\dfrac{dx}{dt} = 2t$.

$\dfrac{dy}{dx} = \dfrac{3}{2}t$, $\;\dfrac{d^2y}{dx^2} = \dfrac{3}{4t}$

Example 2

Ellipse $x = 3\cos t$, $y = 2\sin t$. Find $\dfrac{dy}{dx}$ and the tangent at $t = \dfrac{\pi}{4}$.

Show solution
  1. $\dfrac{dy}{dx} = \dfrac{2\cos t}{-3\sin t}$ ($\sin t \ne 0$). At $t = \dfrac{\pi}{4}$ the slope is $-\dfrac{2}{3}$.
  2. Point: $\left(\dfrac{3}{\sqrt{2}}, \sqrt{2}\right)$. Tangent: $y - \sqrt{2} = -\dfrac{2}{3}\left(x - \dfrac{3}{\sqrt{2}}\right)$.

$\dfrac{dy}{dx} = -\dfrac{2\cos t}{3\sin t}$; tangent $y = -\dfrac{2}{3}x + 2\sqrt{2}$

Example 3

Cycloid $x = t - \sin t$, $y = 1 - \cos t$. Find $\dfrac{dy}{dx}$ and the slope at $t = \dfrac{\pi}{2}$.

Show solution
  1. $\dfrac{dx}{dt} = 1 - \cos t$, $\dfrac{dy}{dt} = \sin t$, so $\dfrac{dy}{dx} = \dfrac{\sin t}{1 - \cos t}$ ($\cos t \ne 1$).
  2. At $t = \dfrac{\pi}{2}$: $\dfrac{1}{1 - 0}$.

$\dfrac{dy}{dx} = \dfrac{\sin t}{1 - \cos t}$; slope $1$

Example 4

$x = t^2 + 1$, $y = t^3 - t$. Find the tangent at $t = 1$.

Show solution
  1. Point: $(2, 0)$. $\dfrac{dx}{dt} = 2t = 2$, $\dfrac{dy}{dt} = 3t^2 - 1 = 2$, so the slope is $1$.

$y = x - 2$

$\dfrac{d^2y}{dx^2}$ is not $\dfrac{d^2y}{dt^2} \Big/ \dfrac{d^2x}{dt^2}$. Differentiate $\dfrac{dy}{dx}$ with respect to $t$, then divide by $\dfrac{dx}{dt}$.
For a tangent at a given $t$: find the point $(x(t), y(t))$, find the slope from the formula, then use $y - y_1 = m(x - x_1)$. No need to eliminate $t$.
  • $\dfrac{dy}{dx} = \dfrac{dy/dt}{dx/dt}$.
  • $\dfrac{dx}{dt} = 0$: vertical tangent; $\dfrac{dy}{dt} = 0$: horizontal tangent.
  • $\dfrac{d^2y}{dx^2} = \dfrac{d}{dt}\left(\dfrac{dy}{dx}\right) \Big/ \dfrac{dx}{dt}$.
