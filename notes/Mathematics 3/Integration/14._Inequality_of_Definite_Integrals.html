Inequality of Definite Integrals

A higher curve has more area

If $f(x) \ge g(x)$ on $[a, b]$, the area under $f$ is at least the area under $g$. If the curves are continuous and differ somewhere, the inequality is strict.

This is how you compare a sum with an integral. Rectangles of height $\dfrac{1}{k}$ stand above the curve $y = \dfrac{1}{x}$ or below it. So $1 + \dfrac{1}{2} + \cdots + \dfrac{1}{n}$ can be squeezed between two logarithms.

$a < b$, $f$ and $g$ continuous

$$f(x) \ge g(x) \text{ on } [a, b] \;\Longrightarrow\; \int_a^b f(x)\,dx \ge \int_a^b g(x)\,dx$$

Equality holds only if $f(x) = g(x)$ for every $x$ in $[a, b]$. Special case: $\left|\displaystyle\int_a^b f(x)\,dx\right| \le \displaystyle\int_a^b |f(x)|\,dx$.

  1. On $k \le x \le k + 1$: $\dfrac{1}{x} \le \dfrac{1}{k}$, with equality only at $x = k$. So $\displaystyle\int_k^{k+1} \frac{dx}{x} < \frac{1}{k}$.
  2. Add for $k = 1, \ldots, n$: $\log(n + 1) = \displaystyle\int_1^{n+1} \frac{dx}{x} < 1 + \frac{1}{2} + \cdots + \frac{1}{n}$.
  3. In the same way, $\dfrac{1}{k} < \displaystyle\int_{k-1}^{k} \frac{dx}{x}$ for $k \ge 2$, so $1 + \dfrac{1}{2} + \cdots + \dfrac{1}{n} < 1 + \log n$.

Rectangles of height $\frac{1}{k}$ versus the area under $y = \frac{1}{x}$

Example 1

Show that $\dfrac{1}{2} < \displaystyle\int_0^1 \frac{dx}{1 + x^2} < 1$ without integrating.

Show solution
  1. On $0 \le x \le 1$: $1 \le 1 + x^2 \le 2$, so $\dfrac{1}{2} \le \dfrac{1}{1 + x^2} \le 1$. Equality holds only at the ends.
  2. Integrate over an interval of length $1$.

Shown (the true value is $\dfrac{\pi}{4} \approx 0.785$)

Example 2

Show that $\displaystyle\int_0^1 e^{x^2}\,dx > \frac{4}{3}$.

Show solution
  1. $e^t \ge 1 + t$ for all $t$, with equality only at $t = 0$. Put $t = x^2$: $e^{x^2} \ge 1 + x^2$.
  2. $\displaystyle\int_0^1 (1 + x^2)\,dx = \frac{4}{3}$, and the curves differ for $x \ne 0$.

Shown ($e^{x^2}$ has no elementary antiderivative, so an inequality is the way to go)

Example 3

Show that $1 + \dfrac{1}{2} + \cdots + \dfrac{1}{n} > \log(n + 1)$, and deduce that $\displaystyle\sum_{k=1}^\infty \frac{1}{k}$ diverges.

Show solution
  1. See the proof block: each $\dfrac{1}{k}$ is more than $\displaystyle\int_k^{k+1} \frac{dx}{x}$.
  2. $\log(n + 1) \to \infty$, and the sum is bigger.

The harmonic series diverges

Example 4

Show that $\displaystyle\int_0^{\frac{\pi}{2}} \sin^2 x\,dx > \int_0^{\frac{\pi}{2}} \sin^3 x\,dx$.

Show solution
  1. On $\left[0, \dfrac{\pi}{2}\right]$, $0 \le \sin x \le 1$, so $\sin^3 x \le \sin^2 x$. Equality holds only where $\sin x$ is $0$ or $1$.

Shown (values $\dfrac{\pi}{4} > \dfrac{2}{3}$)

There is no rule like $\displaystyle\int fg = f(a)\int g + \ldots$. Only compare whole integrands point by point. Also, the interval must run forwards ($a < b$); if $a > b$ the inequality flips.
For a sum against an integral, sketch the rectangles on the graph. The picture tells you which way the inequality goes and which interval to use, $[k, k + 1]$ or $[k - 1, k]$.
  • $f \ge g$ on $[a, b]$ $\Rightarrow$ $\int_a^b f \ge \int_a^b g$ (strict unless $f = g$ everywhere).
  • Bound the integrand first, then integrate the bounds.
  • $\log(n + 1) < \displaystyle\sum_{k=1}^n \frac{1}{k} < 1 + \log n$.
