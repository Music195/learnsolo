Integration by Substitution

The chain rule run backwards

If the integrand has the shape (function of $g(x)$) × $g'(x)$, rename the inside $u = g(x)$. Then $g'(x)\,dx$ becomes $du$, and the integral turns into a simpler one in $u$.

A common special case is a fraction whose top is the derivative of its bottom. Its integral is $\log|\text{bottom}|$.

Put $u = g(x)$, so $du = g'(x)\,dx$

$$\int f(g(x))\,g'(x)\,dx = \int f(u)\,du, \qquad \int \frac{g'(x)}{g(x)}\,dx = \log|g(x)| + C$$

The other direction also works: put $x = h(t)$, so $dx = h'(t)\,dt$, and $\displaystyle\int f(x)\,dx = \int f(h(t))\,h'(t)\,dt$.

  1. Let $F' = f$. By the chain rule, $\{F(g(x))\}' = f(g(x))\,g'(x)$.
  2. So $\displaystyle\int f(g(x))g'(x)\,dx = F(g(x)) + C = F(u) + C = \int f(u)\,du$.
  3. With $f(u) = \dfrac{1}{u}$: $\displaystyle\int \frac{g'(x)}{g(x)}\,dx = \log|u| + C = \log|g(x)| + C$.

$\dfrac{g'(x)}{g(x)}$ (blue) is the slope of $\log g(x)$ (orange)

Example 1

Find $\displaystyle\int (2x + 1)^4\,dx$.

Show solution
  1. $u = 2x + 1$, $du = 2\,dx$, so $dx = \dfrac{du}{2}$.
  2. $\displaystyle\int u^4 \cdot \frac{du}{2} = \frac{u^5}{10} + C$

$\dfrac{(2x + 1)^5}{10} + C$

Example 2

Find $\displaystyle\int x\sqrt{x^2 + 3}\,dx$.

Show solution
  1. $u = x^2 + 3$, $du = 2x\,dx$, so $x\,dx = \dfrac{du}{2}$.
  2. $\displaystyle\int \sqrt{u}\,\frac{du}{2} = \frac{1}{2} \cdot \frac{2}{3}u^{\frac{3}{2}} + C$

$\dfrac{1}{3}(x^2 + 3)\sqrt{x^2 + 3} + C$

Example 3

Find $\displaystyle\int \tan x\,dx$.

Show solution
  1. $\tan x = \dfrac{\sin x}{\cos x} = -\dfrac{(\cos x)'}{\cos x}$.
  2. Top is (minus) the derivative of the bottom.

$-\log|\cos x| + C$

Example 4

Find $\displaystyle\int \sin^3 x\cos x\,dx$ and $\displaystyle\int x e^{x^2}\,dx$.

Show solution
  1. $u = \sin x$, $du = \cos x\,dx$: $\displaystyle\int u^3\,du = \frac{u^4}{4} + C$.
  2. $u = x^2$, $du = 2x\,dx$: $\displaystyle\int e^u\,\frac{du}{2} = \frac{e^u}{2} + C$.

$\dfrac{\sin^4 x}{4} + C$ and $\dfrac{e^{x^2}}{2} + C$

Example 5

Find $\displaystyle\int x\sqrt{x - 1}\,dx$.

Show solution
  1. Put $t = \sqrt{x - 1}$: $x = t^2 + 1$, $dx = 2t\,dt$.
  2. $\displaystyle\int (t^2 + 1)\,t \cdot 2t\,dt = \int (2t^4 + 2t^2)\,dt = \frac{2}{5}t^5 + \frac{2}{3}t^3 + C$

$\dfrac{2}{5}(x - 1)^2\sqrt{x - 1} + \dfrac{2}{3}(x - 1)\sqrt{x - 1} + C$

Replace $dx$ as well, using $du = g'(x)\,dx$. And write the final answer in terms of $x$, not $u$.
Choose $u$ to be the "inside" whose derivative (up to a constant) also appears as a factor. Examples: $u = x^2 + 3$ next to $x$, or $u = \sin x$ next to $\cos x$.
