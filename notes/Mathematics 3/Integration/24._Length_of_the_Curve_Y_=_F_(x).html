Length of the Curve y = f(x)

A small step along the curve is a tiny hypotenuse

Treat $y = f(x)$ as a parametric curve with $x = t$, $y = f(t)$. Then $\dfrac{dx}{dt} = 1$, and the parametric formula (note 23) becomes simpler.

Picture: moving $dx$ to the right raises the curve by about $f'(x)\,dx$. So the step along the curve is $\sqrt{1 + f'(x)^2}\,dx$. A steep curve has more length per unit of $x$.

$a \le x \le b$

$$L = \int_a^b \sqrt{1 + \{f'(x)\}^2}\,dx = \int_a^b \sqrt{1 + \left(\frac{dy}{dx}\right)^2}\,dx$$
  1. Parametrise by $x = t$, $y = f(t)$, $a \le t \le b$.
  2. $\left(\dfrac{dx}{dt}\right)^2 + \left(\dfrac{dy}{dt}\right)^2 = 1 + f'(t)^2$.
  3. So $L = \displaystyle\int_a^b \sqrt{1 + f'(t)^2}\,dt$; rename $t$ as $x$.

Step $dx$ (grey), rise $f'(x)\,dx$ (orange), step along the curve (teal)

Example 1

Find the length of $y = \dfrac{2}{3}x\sqrt{x}$ for $0 \le x \le 3$.

Show solution
  1. $y' = \sqrt{x}$, so $\sqrt{1 + y'^2} = \sqrt{1 + x}$.
  2. $\displaystyle\int_0^3 \sqrt{1 + x}\,dx = \Big[\frac{2}{3}(1 + x)^{\frac{3}{2}}\Big]_0^3 = \frac{2}{3}(8 - 1)$

$\dfrac{14}{3}$

Example 2

Find the length of $y = \dfrac{e^x + e^{-x}}{2}$ (a catenary) for $0 \le x \le 1$.

Show solution
  1. $y' = \dfrac{e^x - e^{-x}}{2}$, and $1 + y'^2 = \dfrac{e^{2x} + 2 + e^{-2x}}{4} = \left(\dfrac{e^x + e^{-x}}{2}\right)^2$.
  2. $\displaystyle\int_0^1 \frac{e^x + e^{-x}}{2}\,dx = \Big[\frac{e^x - e^{-x}}{2}\Big]_0^1$

$\dfrac{1}{2}\left(e - \dfrac{1}{e}\right)$

Example 3

Find the length of $y = \dfrac{x^2}{4} - \dfrac{1}{2}\log x$ for $1 \le x \le 2$.

Show solution
  1. $y' = \dfrac{x}{2} - \dfrac{1}{2x}$, so $1 + y'^2 = \dfrac{x^2}{4} + \dfrac{1}{2} + \dfrac{1}{4x^2} = \left(\dfrac{x}{2} + \dfrac{1}{2x}\right)^2$.
  2. $\displaystyle\int_1^2 \left(\frac{x}{2} + \frac{1}{2x}\right)dx = \Big[\frac{x^2}{4} + \frac{\log x}{2}\Big]_1^2 = \frac{3}{4} + \frac{\log 2}{2}$

$\dfrac{3}{4} + \dfrac{1}{2}\log 2$

Example 4

Find the length of the straight line $y = 2x + 1$ for $0 \le x \le 3$, and check it with Pythagoras.

Show solution
  1. $\displaystyle\int_0^3 \sqrt{1 + 4}\,dx = 3\sqrt{5}$
  2. From $(0, 1)$ to $(3, 7)$: $\sqrt{3^2 + 6^2} = \sqrt{45} = 3\sqrt{5}$. They agree.

$3\sqrt{5}$

The formula uses the derivative: $\sqrt{1 + f'(x)^2}$, not $\sqrt{1 + f(x)^2}$. And don't simplify $\sqrt{1 + f'^2}$ to $1 + f'$; that is wrong.
Exam curves are built so that $1 + f'^2$ is a perfect square. If $f' = \dfrac{1}{2}\left(u - \dfrac{1}{u}\right)$, then $1 + f'^2 = \dfrac{1}{4}\left(u + \dfrac{1}{u}\right)^2$. The minus becomes a plus.

  • It is the parametric formula with $x = t$.
  • Look for $1 + f'^2$ as a perfect square.
