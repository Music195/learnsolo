Convergence and Divergence of Geometric Series

Adding infinitely many terms

An infinite series $a + ar + ar^2 + \cdots$ has a sum only if its partial sums $S_n$ (the first $n$ terms added up) converge. The sum is then $\displaystyle\lim_{n \to \infty} S_n$.

For a geometric series this depends on $r^n$, the topic of the previous note. It settles exactly when $|r| < 1$.

$\displaystyle\sum_{n=1}^{\infty} ar^{n-1} = a + ar + ar^2 + \cdots$

$$a \ne 0,\; |r| < 1: \;\text{ converges to } \frac{a}{1 - r} \qquad\qquad a \ne 0,\; |r| \ge 1: \;\text{ diverges}$$

$a$: first term, $r$: common ratio. If $a = 0$ every term is $0$ and the sum is $0$.

  1. For $r \ne 1$: $S_n = a + ar + \cdots + ar^{n-1} = \dfrac{a(1 - r^n)}{1 - r}$.
  2. If $|r| < 1$ then $r^n \to 0$, so $S_n \to \dfrac{a}{1 - r}$.
  3. If $|r| > 1$ or $r = -1$, then $r^n$ has no limit, so neither does $S_n$. If $r = 1$, $S_n = na$, which goes to $\pm\infty$.

Partial sums $S_1, S_2, \dots, S_{20}$

Example 1

Find $\displaystyle 4 + \frac{8}{3} + \frac{16}{9} + \cdots$.

Show solution
  1. $a = 4$, $r = \dfrac{2}{3}$, and $|r| < 1$, so it converges.
  2. $\dfrac{4}{1 - \frac{2}{3}} = \dfrac{4}{\frac{1}{3}}$

$12$

Example 2

Write the recurring decimal $0.\dot{1}\dot{2} = 0.121212\ldots$ as a fraction.

Show solution
  1. $0.12 + 0.0012 + 0.000012 + \cdots$: $a = 0.12$, $r = 0.01$.
  2. $\dfrac{0.12}{1 - 0.01} = \dfrac{12}{99}$

$\dfrac{4}{33}$

Example 3

For which $x$ does $1 + (x - 1) + (x - 1)^2 + \cdots$ converge? Find the sum.

Show solution
  1. $a = 1 \ne 0$, $r = x - 1$. It converges when $|x - 1| < 1$, i.e. $0 < x < 2$.
  2. Sum $= \dfrac{1}{1 - (x - 1)}$.

$0 < x < 2$, sum $\dfrac{1}{2 - x}$

Example 4

For which $x$ does $x + x(1 - x) + x(1 - x)^2 + \cdots$ converge? Find the sum.

Show solution
  1. If $x = 0$ every term is $0$: converges, sum $0$.
  2. If $x \ne 0$: $a = x$, $r = 1 - x$. Need $|1 - x| < 1$, i.e. $0 < x < 2$. The sum is $\dfrac{x}{1 - (1 - x)} = 1$.

$0 \le x < 2$; sum $0$ when $x = 0$, sum $1$ when $0 < x < 2$

When the first term contains the variable (as in Example 4), check $a = 0$ separately. Then the series converges whatever $r$ is.
Any recurring decimal is a geometric series. The repeating block is $a$, and $r = 10^{-k}$ where $k$ is the length of the block.
  • A series converges when its partial sums $S_n$ converge.
  • Geometric: converges $\iff a = 0$ or $|r| < 1$; the sum is $\dfrac{a}{1 - r}$.
  • Find $a$ and $r$ first, then check $|r| < 1$ before using the formula.
