Inverse Function Properties

Doing one function after another

The composite function $(g \circ f)(x) = g(f(x))$ means: apply $f$ first, then $g$. Order matters: $g \circ f$ and $f \circ g$ are usually different.

A function followed by its inverse brings every input back: $f^{-1}(f(x)) = x$.

Composite and inverse

$$(g \circ f)(x) = g(f(x))$$
$$f^{-1}(f(x)) = x, \qquad f(f^{-1}(x)) = x, \qquad (f^{-1})^{-1} = f$$

$b = f(a) \iff a = f^{-1}(b)$. Generally $g \circ f \ne f \circ g$.

  1. Let $b = f(a)$. By definition of the inverse, $f^{-1}(b) = a$.
  2. So $f^{-1}(f(a)) = f^{-1}(b) = a$ for every $a$ in the domain of $f$. The other order is the same argument starting from $b$.

$f(x) = 2x + 1$ and a choice of $g$: compare $g \circ f$ with $f \circ g$

Example 1

$f(x) = 2x + 1$, $g(x) = x^2$. Find $(g \circ f)(x)$ and $(f \circ g)(x)$.

Show solution
  1. $g(f(x)) = (2x + 1)^2$; $\;f(g(x)) = 2x^2 + 1$.

$4x^2 + 4x + 1$ and $2x^2 + 1$ (different)

Example 2

$f(x) = \dfrac{ax + 1}{x + 2}$ satisfies $f^{-1}(3) = 1$. Find $a$.

Show solution
  1. $f^{-1}(3) = 1 \iff f(1) = 3$: $\dfrac{a + 1}{3} = 3$.

$a = 8$

Example 3

Find the common points of $y = \sqrt{x - 1}$ and its inverse $y = x^2 + 1$ ($x \ge 0$).

Show solution
  1. An increasing function meets its inverse only on $y = x$. Solve $x^2 + 1 = x$: $D = 1 - 4 < 0$.

No common points

$f^{-1}(x)$ is the inverse function, not $\dfrac{1}{f(x)}$. And $g \circ f$ means "$f$ first": read it right to left.
To find a value like $f^{-1}(3)$, you rarely need the formula for $f^{-1}$: just solve $f(x) = 3$.
  • $(g \circ f)(x) = g(f(x))$; order matters.
  • $f^{-1}(f(x)) = x$, $\;f(f^{-1}(x)) = x$.
  • $f^{-1}(b) = a \iff f(a) = b$.
