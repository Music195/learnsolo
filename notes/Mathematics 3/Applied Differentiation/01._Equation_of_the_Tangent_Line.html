Equation of the Tangent Line

A point and a slope

A line is fixed by one point and its slope. For the tangent to $y = f(x)$ at $x = a$, the point is $(a, f(a))$ and the slope is $f'(a)$.

If the question gives a point that is not on the curve, the touching point is unknown. Call it $(t, f(t))$ and make the tangent pass through the given point.

Tangent at $(a, f(a))$

$$y - f(a) = f'(a)(x - a)$$

For a curve given by an equation in $x$ and $y$ (e.g. a circle), find the slope by differentiating both sides (Differentiation note 06).

  1. Let the touching point be $(t, f(t))$. The tangent there is $y - f(t) = f'(t)(x - t)$.
  2. It must pass through the given point $(p, q)$: substitute $x = p$, $y = q$ to get an equation in $t$.
  3. Solve for $t$, then put each $t$ back into the tangent equation. Each solution $t$ gives one tangent.

Example 1

Find the tangent to $y = e^x$ at $x = 1$.

Show solution
  1. Point $(1, e)$, slope $y' = e^x = e$.
  2. $y - e = e(x - 1)$

$y = ex$

Example 2

Find the tangent to $y = \log x$ that passes through the origin.

Show solution
  1. Touching point $(t, \log t)$, slope $\dfrac{1}{t}$: $y - \log t = \dfrac{1}{t}(x - t)$.
  2. Through $(0, 0)$: $-\log t = -1$, so $t = e$.
  3. $y - 1 = \dfrac{1}{e}(x - e)$

$y = \dfrac{1}{e}x$, touching at $(e, 1)$

Example 3

Find the tangent to the circle $x^2 + y^2 = 25$ at $(3, 4)$.

Show solution
  1. Differentiate: $2x + 2yy' = 0$, so $y' = -\dfrac{x}{y} = -\dfrac{3}{4}$ at $(3, 4)$.
  2. $y - 4 = -\dfrac{3}{4}(x - 3)$, i.e. $3x + 4y = 25$.

$3x + 4y = 25$

Example 4

Find the tangent to $y = x^3 - 3x$ that is parallel to $y = 9x$.

Show solution
  1. $y' = 3x^2 - 3 = 9$, so $x = \pm 2$.
  2. $x = 2$: point $(2, 2)$, $y = 9x - 16$. $\;x = -2$: point $(-2, -2)$, $y = 9x + 16$.

$y = 9x - 16$ and $y = 9x + 16$

"Tangent at a point" and "tangent through a point" are different questions. If the point isn't on the curve, using $f'$ there gives a wrong line. Use the unknown touching point $t$.
Always the same three steps: find the point, find the slope with $f'$, write $y - y_1 = m(x - x_1)$.
  • Tangent at $x = a$: $y - f(a) = f'(a)(x - a)$.
  • Through an outside point: let the touching point be $(t, f(t))$ and solve for $t$.
  • Parallel to a line with slope $m$: solve $f'(x) = m$.
