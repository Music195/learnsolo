Mathematical Induction — Summation Formulas

Six practice problems on applying and evaluating classic summation formulas proved by mathematical induction: sums of integers, squares, cubes, odd numbers, and telescoping series. Try each one first. Open the hint if you are stuck, then compare with the full step-by-step solution.

Problem 1

Using the formula $1 + 2 + 3 + \dots + n = \dfrac{n(n + 1)}{2}$, evaluate the sum of the first $20$ positive integers.

Uses: Principle of Mathematical Induction, Proofs of Summation Formulas

Show hint

Substitute $n = 20$ into the triangular number formula $\dfrac{n(n + 1)}{2}$.

Show solution
  1. Set $n = 20$: $$S_{20} = \frac{20(20 + 1)}{2} = \frac{20 \times 21}{2} = 10 \times 21 = 210$$

$210$

Problem 2

The sum of squares of the first $n$ positive integers is given by $1^2 + 2^2 + \dots + n^2 = \dfrac{n(n + 1)(2n + 1)}{6}$. Calculate the sum of the first $10$ squares.

Uses: Proofs of Summation Formulas

Show hint

Substitute $n = 10$: evaluate $n(n + 1)(2n + 1) = 10 \times 11 \times 21$, then divide by $6$.

Show solution
  1. Substitute $n = 10$: $$S_{10} = \frac{10(10 + 1)(2(10) + 1)}{6} = \frac{10 \times 11 \times 21}{6}$$
  2. Simplify: $\dfrac{210 \times 11}{6} = 35 \times 11 = 385$.

$385$

Problem 3

For all $n \ge 1$, $\dfrac{1}{1 \cdot 2} + \dfrac{1}{2 \cdot 3} + \dfrac{1}{3 \cdot 4} + \dots + \dfrac{1}{n(n + 1)} = \dfrac{n}{n + 1}$. Find the exact sum when $n = 9$.

Uses: Proofs of Summation Formulas

Show hint

Substitute $n = 9$ directly into $\dfrac{n}{n + 1}$.

Show solution
  1. Substitute $n = 9$: $$S_9 = \frac{9}{9 + 1} = \frac{9}{10}$$
  2. (Notice the telescoping cancellation: $(1 - 1/2) + (1/2 - 1/3) + \dots + (1/9 - 1/10) = 1 - 1/10 = 9/10$.)

$\dfrac{9}{10}$

Problem 4

The sum of the first $n$ positive odd integers satisfies $1 + 3 + 5 + \dots + (2n - 1) = n^2$. Find the sum of the first $25$ positive odd integers.

Uses: Principle of Mathematical Induction

Show hint

Here $n = 25$. Evaluate $n^2$.

Show solution
  1. Substitute $n = 25$: $$S_{25} = 25^2 = 625$$

$625$

Problem 5

The formula $1 \cdot 2 + 2 \cdot 3 + 3 \cdot 4 + \dots + n(n + 1) = \dfrac{n(n + 1)(n + 2)}{3}$ holds for all $n \in \mathbb{N}$. Calculate the sum of the first $5$ terms.

Uses: Proofs of Summation Formulas

Show hint

Substitute $n = 5$ into $\dfrac{n(n + 1)(n + 2)}{3}$.

Show solution
  1. Substitute $n = 5$: $$S_5 = \frac{5(5 + 1)(5 + 2)}{3} = \frac{5 \times 6 \times 7}{3} = 5 \times 2 \times 7 = 70$$
  2. (Check: $2 + 6 + 12 + 20 + 30 = 70$ ✓.)

$70$

Problem 6

The sum of cubes of the first $n$ positive integers satisfies $1^3 + 2^3 + \dots + n^3 = \left[\dfrac{n(n + 1)}{2}\right]^2$. Evaluate the sum of the first $6$ cubes.

Uses: Proofs of Summation Formulas

Show hint

Compute the sum of the first $6$ integers $\dfrac{6 \times 7}{2} = 21$, then square the result.

Show solution
  1. First compute $\dfrac{n(n + 1)}{2}$ for $n = 6$: $\dfrac{6 \times 7}{2} = 21$.
  2. Square the result: $21^2 = 441$.
  3. (Check: $1 + 8 + 27 + 64 + 125 + 216 = 441$ ✓.)

$441$
