Permutations and Combinations

A comprehensive review of Permutations and Combinations, covering counting rules, factorials, arrangements of distinct and repeated objects, circular permutations, and selections.

Evaluate the value of the expression $\frac{0! + 1!}{2}$.

Uses: Counting Principles and Factorial Notation

Hint

By mathematical convention and definition, $0! = 1$ and $1! = 1$.

Solution

Recall the definition $0! = 1$:

\[ \frac{0! + 1!}{2} = \frac{1 + 1}{2} = \frac{2}{2} = 1. \]

If ${}^{10}C_r = {}^{10}C_3$ with $r \neq 3$, find the value of $r$.

Uses: Combinations and Selections

Hint

Use the symmetry identity of combinations: ${}^nC_r = {}^nC_{n-r}$.

Solution

By combination symmetry:

\[ {}^{10}C_r = {}^{10}C_{10-r}. \]

Since ${}^{10}C_r = {}^{10}C_3$ and $r \ne 3$, we have:

\[ r = 10 - 3 = 7. \]

How many $5$-letter permutations can be formed from the letters of the word $\text{SMART}$ such that the letter $\text{S}$ is always in the first position?

Uses: Permutations of Distinct Objects

Hint

Fix $\text{S}$ in position 1. Then arrange the remaining $4$ letters ($\text{M, A, R, T}$) in the remaining $4$ positions ($4!$ choices).

Solution

The letters are $\text{S, M, A, R, T}$ ($5$ distinct letters).

Fixing $\text{S}$ in the first position leaves $4$ positions to fill with the $4$ distinct letters $\text{M, A, R, T}$:

\[ N = 1 \times 4! = 1 \times 24 = 24. \]

In how many ways can $3$ couples (husband and wife pairs) be seated around a circular dining table such that each couple sits together side by side?

Uses: Advanced Counting Techniques and Repetitions

Hint

Treat each of the $3$ couples as $1$ unit. Arrange $3$ units circularly in $(3-1)! = 2!$ ways. Each couple can swap seats internally in $2$ ways: $2! \times 2^3$.

Solution

Treat each couple as a single block. The $3$ blocks can be arranged around the circular table in:

\[ (3 - 1)! = 2! = 2 \text{ ways}. \]

Each of the $3$ couples can be seated in $2$ different internal orders ($2! = 2$). With $3$ couples, this gives $2^3 = 8$ internal arrangements:

\[ \text{Total ways} = 2! \times 2^3 = 2 \times 8 = 16. \]

A student must choose at least one course from $4$ available elective subjects. How many different non-empty selections can the student make?

Uses: Combinations and Selections

Hint

For each of the $4$ subjects there are $2$ options (take or not take). Subtract the empty selection: $2^n - 1$.

Solution

The total number of subsets of a set of $4$ items is $2^4 = 16$.

Excluding the empty set (choosing zero courses):

\[ 2^4 - 1 = 16 - 1 = 15. \]

Find the total number of distinct arrangements of the $6$ letters in $\text{PEPPER}$ that start with the letter $\text{P}$.

Uses: Advanced Counting Techniques and Repetitions

Hint

Fix one $\text{P}$ in the first position. The remaining $5$ letters to arrange are $\text{E, P, P, E, R}$ ($2$ P's, $2$ E's, $1$ R). Calculate $\frac{5!}{2!\,2!\,1!}$.

Solution

The letters of $\text{PEPPER}$ are $3$ P's, $2$ E's, and $1$ R (total $6$).

When the first letter is fixed to be $\text{P}$, the remaining $5$ slots are filled with the remaining letters: $2$ P's, $2$ E's, and $1$ R.

The number of distinct arrangements is:

\[ N = \frac{5!}{2!\,2!\,1!} = \frac{120}{2 \times 2} = \frac{120}{4} = 30. \]
