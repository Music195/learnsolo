Trigonometric Functions

A comprehensive review of Trigonometric Functions, covering graph properties (amplitude, period, asymptotes), inverse trigonometric functions, and derivatives.

Find the amplitude of the curve $y = 4\cos\left(3x + \frac{\pi}{4}\right) - 2$.

Uses: Graphs of Sine and Cosine Functions

Hint

The amplitude of $y = A\cos(Bx + C) + D$ is $|A|$.

Solution

The vertical stretch coefficient is $A = 4$, so:

\[ \text{Amplitude} = |4| = 4. \]

Find the principal value of $\arctan(1)$ in degrees.

Uses: Inverse Trigonometric Functions

Hint

The principal range of $\arctan x$ is $(-90^\circ, 90^\circ)$. Which angle in this interval satisfies $\tan\theta = 1$?

Solution

In the interval $(-90^\circ, 90^\circ)$, $\tan(45^\circ) = 1$.

Therefore:

\[ \arctan(1) = 45^\circ. \]

Let $f(x) = \cos x$. Find the value of the derivative $f'\left(\frac{\pi}{2}\right)$.

Uses: Differentiation of Trigonometric Functions

Hint

Recall that $\frac{d}{dx}(\cos x) = -\sin x$.

Solution

Differentiating $f(x)$:

\[ f'(x) = -\sin x. \]

Evaluating at $x = \frac{\pi}{2}$:

\[ f'\left(\frac{\pi}{2}\right) = -\sin\left(\frac{\pi}{2}\right) = -1. \]

Evaluate $\cos\left(\arcsin\left(\frac{3}{5}\right)\right)$ as a decimal.

Uses: Inverse Trigonometric Functions

Hint

Let $\theta = \arcsin(3/5)$. Use the Pythagorean identity $\cos\theta = \sqrt{1 - \sin^2\theta}$.

Solution

Since $\theta = \arcsin\left(\frac{3}{5}\right)$ lies in the first quadrant:

\[ \cos\theta = \sqrt{1 - \sin^2\theta} = \sqrt{1 - \left(\frac{3}{5}\right)^2} = \sqrt{1 - \frac{9}{25}} = \sqrt{\frac{16}{25}} = \frac{4}{5} = 0.8. \]

Find the slope of the tangent line to the curve $y = 2\sin x$ at the origin $(0, 0)$.

Uses: Differentiation of Trigonometric Functions

Hint

The slope of the tangent line is given by $\frac{dy}{dx}$ evaluated at $x = 0$.

Solution

Differentiating $y = 2\sin x$:

\[ \frac{dy}{dx} = 2\cos x. \]

At $x = 0$:

\[ m = 2\cos(0) = 2(1) = 2. \]

Let $f(x) = \tan x + \sin x$. Evaluate the derivative $f'(0)$ at $x = 0$.

Uses: Differentiation of Trigonometric Functions

Hint

Differentiate term-by-term: $\frac{d}{dx}(\tan x) = \sec^2 x$ and $\frac{d}{dx}(\sin x) = \cos x$.

Solution

Differentiating $f(x)$:

\[ f'(x) = \sec^2 x + \cos x. \]

Evaluating at $x = 0$:

\[ f'(0) = \sec^2(0) + \cos(0) = 1 + 1 = 2. \]
