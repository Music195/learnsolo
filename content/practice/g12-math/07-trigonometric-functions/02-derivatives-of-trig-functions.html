Trigonometric Functions — Derivatives

Practise differentiation formulas for sine, cosine, tangent, secant, cosecant, and cotangent, combined with product, quotient, and chain rules.

Let $f(x) = 3\sin x + 4\cos x$. Evaluate the derivative $f'(0)$ at $x = 0$.

Uses: Differentiation of Trigonometric Functions

Hint

Use the basic differentiation rules: $\frac{d}{dx}(\sin x) = \cos x$ and $\frac{d}{dx}(\cos x) = -\sin x$.

Solution

Differentiating term-by-term:

\[ f'(x) = 3\cos x - 4\sin x. \]

Evaluating at $x = 0$:

\[ f'(0) = 3\cos(0) - 4\sin(0) = 3(1) - 4(0) = 3. \]

Evaluate the derivative of $f(x) = \tan x$ at $x = 0$.

Uses: Differentiation of Trigonometric Functions

Hint

The derivative of tangent is $\frac{d}{dx}(\tan x) = \sec^2 x = \frac{1}{\cos^2 x}$.

Solution

Applying the standard derivative rule:

\[ f'(x) = \sec^2 x = \frac{1}{\cos^2 x}. \]

At $x = 0$:

\[ f'(0) = \frac{1}{\cos^2(0)} = \frac{1}{1^2} = 1. \]

If $f(x) = \sin(2x)$, find the exact value of $f'\left(\frac{\pi}{6}\right)$.

Uses: Differentiation of Trigonometric Functions

Hint

Use the chain rule: $\frac{d}{dx}(\sin(2x)) = 2\cos(2x)$.

Solution

By the chain rule:

\[ f'(x) = 2\cos(2x). \]

At $x = \frac{\pi}{6}$:

\[ f'\left(\frac{\pi}{6}\right) = 2\cos\left(2 \cdot \frac{\pi}{6}\right) = 2\cos\left(\frac{\pi}{3}\right) = 2\left(\frac{1}{2}\right) = 1. \]

Let $f(x) = x\sin x$. Evaluate the derivative $f'\left(\frac{\pi}{2}\right)$.

Uses: Differentiation of Trigonometric Functions

Hint

Use the product rule: $(uv)' = u'v + uv'$. Note that $\cos(\pi/2) = 0$ and $\sin(\pi/2) = 1$.

Solution

Apply the product rule:

\[ f'(x) = (1)\sin x + x\cos x = \sin x + x\cos x. \]

Substitute $x = \frac{\pi}{2}$:

\[ f'\left(\frac{\pi}{2}\right) = \sin\left(\frac{\pi}{2}\right) + \frac{\pi}{2}\cos\left(\frac{\pi}{2}\right) = 1 + \frac{\pi}{2}(0) = 1. \]

If $f(x) = \sin^2 x$, find the value of $f'\left(\frac{\pi}{4}\right)$.

Uses: Differentiation of Trigonometric Functions

Hint

By the chain rule, $\frac{d}{dx}(\sin^2 x) = 2\sin x\cos x = \sin(2x)$.

Solution

Differentiating using the chain rule:

\[ f'(x) = 2\sin x\cos x = \sin(2x). \]

At $x = \frac{\pi}{4}$:

\[ f'\left(\frac{\pi}{4}\right) = \sin\left(2 \cdot \frac{\pi}{4}\right) = \sin\left(\frac{\pi}{2}\right) = 1. \]

Find the second derivative $y''(0)$ at $x = 0$ for the function $y = \cos(3x)$.

Uses: Differentiation of Trigonometric Functions

Hint

Compute the first derivative $y' = -3\sin(3x)$ and differentiate again to obtain $y''$.

Solution

First derivative:

\[ y' = -3\sin(3x). \]

Second derivative:

\[ y'' = -3(3)\cos(3x) = -9\cos(3x). \]

Evaluating at $x = 0$:

\[ y''(0) = -9\cos(0) = -9(1) = -9. \]
