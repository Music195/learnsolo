Application of Differentiation

A comprehensive review of Application of Differentiation, covering slopes of tangents and normals, critical points, local extrema, concavity, optimization, and linear approximations.

Find the $x$-coordinate of the stationary point of $f(x) = x^2 - 6x + 8$.

Uses: Increasing, Decreasing Functions and Extrema

Hint

A stationary point is where the first derivative equals zero: $f'(x) = 0$.

Solution

Differentiating $f(x)$:

\[ f'(x) = 2x - 6 = 0 \implies x = 3. \]

The tangent line to a curve at point $P$ has slope $m = 2$. What is the slope of the normal line to the curve at the same point?

Uses: Tangent Line and Normal Line

Hint

The normal line is perpendicular to the tangent line: $m_{\text{norm}} = -\frac{1}{m_{\text{tan}}}$.

Solution

Using the perpendicular slope relation:

\[ m_{\text{norm}} = -\frac{1}{2} = -0.5. \]

Find the $x$-coordinate of the local maximum of the function $f(x) = 2x^3 + 3x^2 - 12x + 5$.

Uses: Increasing, Decreasing Functions and Extrema

Hint

Find the roots of $f'(x) = 6x^2 + 6x - 12 = 0$. Test with the second derivative: $f''(x) < 0$ at a local maximum.

Solution

Differentiating:

\[ f'(x) = 6x^2 + 6x - 12 = 6(x^2 + x - 2) = 6(x + 2)(x - 1) = 0. \]

The critical points are $x = -2$ and $x = 1$.

Checking the second derivative $f''(x) = 12x + 6$:

\[ f''(-2) = 12(-2) + 6 = -18 < 0 \implies \text{local maximum at } x = -2. \]

An open-top rectangular box is made by cutting equal squares of side $x$ from the corners of a $12 \times 12\text{ cm}$ square sheet of metal and folding up the sides. Find the value of $x$ (in cm) that maximizes the volume of the box.

Uses: Concavity, Inflection Points and Optimization

Hint

The base is $(12 - 2x) \times (12 - 2x)$ and height is $x$. Maximize $V(x) = x(12 - 2x)^2 = 4x(6 - x)^2$.

Solution

The volume function for $0 < x < 6$ is:

\[ V(x) = x(12 - 2x)^2 = x(144 - 48x + 4x^2) = 4x^3 - 48x^2 + 144x. \]

Differentiating:

\[ V'(x) = 12x^2 - 96x + 144 = 12(x^2 - 8x + 12) = 12(x - 2)(x - 6) = 0. \]

Inside the domain $0 < x < 6$, the critical point is $x = 2\text{ cm}$.

Find the $x$-coordinate of the inflection point of the cubic curve $y = x^3 - 3x$.

Uses: Concavity, Inflection Points and Optimization

Hint

Compute $y'' = 6x$ and set equal to $0$.

Solution

Differentiating twice:

\[ y' = 3x^2 - 3, \quad y'' = 6x. \]

Setting $y'' = 0$ gives $x = 0$.

Use the linear approximation for $f(x) = (1 + x)^3$ around $x = 0$ to estimate $(1.02)^3$.

Uses: Linearization and Linear Approximation

Hint

The linearization of $(1 + x)^3$ at $a = 0$ is $L(x) = 1 + 3x$. Substitute $x = 0.02$.

Solution

The tangent line approximation at $a = 0$ is:

\[ L(x) = f(0) + f'(0)x = 1 + 3x. \]

With $x = 0.02$:

\[ (1.02)^3 \approx L(0.02) = 1 + 3(0.02) = 1 + 0.06 = 1.06. \]
