Method of Integration

A comprehensive review of Method of Integration, covering fundamental antiderivatives, substitution techniques, integration by parts, partial fractions, and differential equations.

Evaluate the definite integral $\int_1^3 (2x + 1)\,dx$.

Uses: Antiderivatives and Basic Integration Rules

Hint

The antiderivative is $x^2 + x$. Evaluate at $3$ and subtract the value at $1$.

Solution

Finding the antiderivative:

\[ \int (2x + 1)\,dx = x^2 + x. \]

Evaluating between limits $1$ and $3$:

\[ [x^2 + x]_1^3 = (3^2 + 3) - (1^2 + 1) = (9 + 3) - (1 + 1) = 12 - 2 = 10. \]

Evaluate $\int_0^{\pi} \sin x\,dx$.

Uses: Antiderivatives and Basic Integration Rules

Hint

The antiderivative of $\sin x$ is $-\cos x$. Remember $\cos\pi = -1$ and $\cos 0 = 1$.

Solution

Using the antiderivative $-\cos x$:

\[ \int_0^{\pi} \sin x\,dx = [-\cos x]_0^{\pi} = (-\cos\pi) - (-\cos 0) = -(-1) - (-1) = 1 + 1 = 2. \]

Evaluate the definite integral $\int_0^{\pi/2} \sin x\cos x\,dx$ as a decimal.

Uses: Integration by Substitution

Hint

Let $u = \sin x$, so $du = \cos x\,dx$. The limits become $u = 0$ to $u = 1$.

Solution

Substitute $u = \sin x \implies du = \cos x\,dx$:

\[ \int_0^{\pi/2} \sin x\cos x\,dx = \int_0^1 u\,du = \left[\frac{u^2}{2}\right]_0^1 = \frac{1^2}{2} - 0 = 0.5. \]

Evaluate the definite integral $\int_0^1 6x(1 - x)\,dx$.

Uses: Antiderivatives and Basic Integration Rules

Hint

Expand the integrand: $6x - 6x^2$. Find the antiderivative and evaluate from $0$ to $1$.

Solution

Expand the integrand:

\[ \int_0^1 (6x - 6x^2)\,dx = \left[3x^2 - 2x^3\right]_0^1 = (3(1)^2 - 2(1)^3) - 0 = 3 - 2 = 1. \]

If $\frac{x + 7}{(x - 2)(x + 1)} = \frac{A}{x - 2} + \frac{B}{x + 1}$, find the value of $A$.

Uses: Partial Fractions and Initial Value Problems

Hint

Multiply both sides by $(x - 2)(x + 1)$ and substitute $x = 2$.

Solution

Multiplying by the common denominator:

\[ x + 7 = A(x + 1) + B(x - 2). \]

Set $x = 2$ to eliminate $B$:

\[ 2 + 7 = A(2 + 1) + B(0) \implies 9 = 3A \implies A = 3. \]

An object moves along a straight line with acceleration $a(t) = 6t$. At time $t = 0$, its velocity is $v(0) = 4$ and position is $s(0) = 0$. Find the position $s(2)$ at time $t = 2$.

Uses: Partial Fractions and Initial Value Problems

Hint

Integrate $a(t)$ to find $v(t) = 3t^2 + 4$, then integrate $v(t)$ to find $s(t) = t^3 + 4t$.

Solution

Find the velocity function:

\[ v(t) = \int 6t\,dt = 3t^2 + C_1. \]

Since $v(0) = 4$, $C_1 = 4$, so $v(t) = 3t^2 + 4$.

Find the position function:

\[ s(t) = \int (3t^2 + 4)\,dt = t^3 + 4t + C_2. \]

Since $s(0) = 0$, $C_2 = 0$, so $s(t) = t^3 + 4t$.

At $t = 2$:

\[ s(2) = 2^3 + 4(2) = 8 + 8 = 16. \]
