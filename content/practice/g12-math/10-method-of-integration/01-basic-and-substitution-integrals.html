Method of Integration — Basic Rules and Substitution

Practise antiderivatives, power rule, exponential and trigonometric integration, the method of substitution ($u$-substitution), and determining constants of integration.

Evaluate the definite integral $\int_0^2 (3x^2 + 2x)\,dx$.

Uses: Antiderivatives and Basic Integration Rules

Hint

Use the power rule $\int x^n\,dx = \frac{x^{n+1}}{n+1}$ term-by-term, then evaluate between limits $0$ and $2$.

Solution

Find the antiderivative:

\[ \int (3x^2 + 2x)\,dx = x^3 + x^2. \]

Evaluate from $0$ to $2$:

\[ [x^3 + x^2]_0^2 = (2^3 + 2^2) - (0^3 + 0^2) = (8 + 4) - 0 = 12. \]

Evaluate the integral $\int_0^1 2x(x^2 + 1)^3\,dx$ as a decimal.

Uses: Integration by Substitution

Hint

Substitute $u = x^2 + 1$, so $du = 2x\,dx$. The limits transform from $x=0 \to u=1$ and $x=1 \to u=2$.

Solution

Let $u = x^2 + 1 \implies du = 2x\,dx$.

When $x = 0$, $u = 1$; when $x = 1$, $u = 2$.

\[ \int_0^1 2x(x^2 + 1)^3\,dx = \int_1^2 u^3\,du = \left[\frac{u^4}{4}\right]_1^2 = \frac{2^4 - 1^4}{4} = \frac{16 - 1}{4} = \frac{15}{4} = 3.75. \]

Find the positive constant $k$ such that $\int_0^k 2x\,dx = 9$.

Uses: Antiderivatives and Basic Integration Rules

Hint

The antiderivative of $2x$ is $x^2$. Evaluate $[x^2]_0^k$ and set it equal to $9$.

Solution

Evaluate the integral:

\[ \int_0^k 2x\,dx = [x^2]_0^k = k^2 - 0 = k^2. \]

Given that the integral equals $9$:

\[ k^2 = 9 \implies k = 3 \quad (\text{since } k > 0). \]

Evaluate the definite integral $\int_0^{\pi/2} 6\sin x\cos^2 x\,dx$.

Uses: Integration by Substitution

Hint

Let $u = \cos x$, so $du = -\sin x\,dx$. Change limits: $x=0 \to u=1$, and $x=\pi/2 \to u=0$.

Solution

Let $u = \cos x$, then $du = -\sin x\,dx$.

When $x = 0$, $u = 1$; when $x = \pi/2$, $u = 0$.

\[ \int_0^{\pi/2} 6\sin x\cos^2 x\,dx = \int_1^0 -6u^2\,du = \int_0^1 6u^2\,du = [2u^3]_0^1 = 2(1) - 0 = 2. \]

A function satisfies $f'(x) = 4x + 3$ and passes through the point $(1, 10)$. Find the value of $f(0)$.

Uses: Antiderivatives and Basic Integration Rules

Hint

Integrate $f'(x)$ to find $f(x) = 2x^2 + 3x + C$. Use $f(1) = 10$ to solve for $C$, then $f(0) = C$.

Solution

Integrate the derivative:

\[ f(x) = \int (4x + 3)\,dx = 2x^2 + 3x + C. \]

Substitute $f(1) = 10$:

\[ 2(1)^2 + 3(1) + C = 10 \implies 5 + C = 10 \implies C = 5. \]

Thus $f(0) = 2(0)^2 + 3(0) + 5 = 5$.

Evaluate the definite integral $\int_0^4 \frac{1}{\sqrt{2x + 1}}\,dx$.

Uses: Integration by Substitution

Hint

Recall that $\frac{d}{dx}(\sqrt{2x + 1}) = \frac{1}{\sqrt{2x + 1}}$. Alternatively, let $u = 2x + 1$.

Solution

Let $u = 2x + 1 \implies du = 2\,dx \implies dx = \frac{du}{2}$.

When $x = 0$, $u = 1$; when $x = 4$, $u = 9$.

\[ \int_0^4 \frac{1}{\sqrt{2x + 1}}\,dx = \int_1^9 \frac{1}{\sqrt{u}} \cdot \frac{du}{2} = \frac{1}{2} [2\sqrt{u}]_1^9 = [\sqrt{u}]_1^9 = \sqrt{9} - \sqrt{1} = 3 - 1 = 2. \]
