Method of Integration — Parts and Partial Fractions

Practise integration by parts ($\int u\,dv = uv - \int v\,du$), algebraic partial fraction decomposition, and solving first-order initial value problems.

Evaluate the definite integral $\int_0^1 x e^x\,dx$.

Uses: Integration by Parts

Hint

Use integration by parts: let $u = x$ and $dv = e^x\,dx$. Then $du = dx$ and $v = e^x$.

Solution

Apply integration by parts:

\[ \int x e^x\,dx = x e^x - \int e^x\,dx = x e^x - e^x. \]

Evaluate between limits $0$ and $1$:

\[ [x e^x - e^x]_0^1 = (1\cdot e^1 - e^1) - (0\cdot e^0 - e^0) = (e - e) - (0 - 1) = 0 - (-1) = 1. \]

In the partial fraction decomposition $\frac{3x + 1}{(x - 1)(x + 1)} = \frac{A}{x - 1} + \frac{B}{x + 1}$, find the value of $A$.

Uses: Partial Fractions and Initial Value Problems

Hint

Multiply through by the common denominator: $3x + 1 = A(x + 1) + B(x - 1)$. Then substitute $x = 1$ to eliminate $B$.

Solution

Clearing denominators:

\[ 3x + 1 = A(x + 1) + B(x - 1). \]

Substitute $x = 1$:

\[ 3(1) + 1 = A(1 + 1) + B(0) \implies 4 = 2A \implies A = 2. \]

Evaluate the definite integral $\int_1^e \ln x\,dx$.

Uses: Integration by Parts

Hint

Set $u = \ln x$ and $dv = dx$. Then $du = \frac{1}{x}\,dx$ and $v = x$, yielding $\int \ln x\,dx = x\ln x - x$.

Solution

Apply integration by parts:

\[ \int \ln x\,dx = x\ln x - \int x \cdot \frac{1}{x}\,dx = x\ln x - x. \]

Evaluate from $1$ to $e$:

\[ [x\ln x - x]_1^e = (e\ln e - e) - (1\ln 1 - 1) = (e(1) - e) - (0 - 1) = 0 - (-1) = 1. \]

A curve satisfies the differential equation $\frac{dy}{dx} = \frac{1}{x + 1}$ for $x > -1$. If $y(0) = 3$, find the value of $y(e - 1)$.

Uses: Partial Fractions and Initial Value Problems

Hint

Integrate to find $y(x) = \ln(x + 1) + C$. Use $y(0) = 3$ to determine $C$, then substitute $x = e - 1$.

Solution

Integrate both sides:

\[ y(x) = \int \frac{1}{x + 1}\,dx = \ln(x + 1) + C. \]

Using the initial condition $y(0) = 3$:

\[ \ln(0 + 1) + C = 3 \implies \ln(1) + C = 3 \implies C = 3. \]

Now evaluate at $x = e - 1$:

\[ y(e - 1) = \ln((e - 1) + 1) + 3 = \ln(e) + 3 = 1 + 3 = 4. \]

Evaluate the definite integral $\int_0^1 \frac{4}{(x + 1)^2}\,dx$.

Uses: Partial Fractions and Initial Value Problems

Hint

The antiderivative of $(x + 1)^{-2}$ is $-(x + 1)^{-1} = -\frac{1}{x + 1}$.

Solution

Integrate using the power rule for $(x + 1)^{-2}$:

\[ \int_0^1 \frac{4}{(x + 1)^2}\,dx = \left[-\frac{4}{x + 1}\right]_0^1 = \left(-\frac{4}{1 + 1}\right) - \left(-\frac{4}{0 + 1}\right) = -2 - (-4) = 2. \]

Find the positive constant $k$ such that $\int_0^k x e^{x^2}\,dx = \frac{e^4 - 1}{2}$.

Uses: Integration by Parts

Hint

Notice that $\frac{d}{dx}(e^{x^2}) = 2x e^{x^2}$. Integrate and compare the upper limit with $e^4$.

Solution

Use substitution with $u = x^2, du = 2x\,dx$:

\[ \int_0^k x e^{x^2}\,dx = \left[\frac{1}{2} e^{x^2}\right]_0^k = \frac{e^{k^2} - e^0}{2} = \frac{e^{k^2} - 1}{2}. \]

Equating to the given value:

\[ \frac{e^{k^2} - 1}{2} = \frac{e^4 - 1}{2} \implies k^2 = 4 \implies k = 2 \quad (\text{since } k > 0). \]
