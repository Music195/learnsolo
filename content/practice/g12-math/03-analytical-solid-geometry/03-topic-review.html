Analytical Solid Geometry

A comprehensive review of Analytical Solid Geometry, covering 3D coordinates, distance, lines in space, parallelism, orthogonality, planes, and spheres.

Find the distance from the point $P(2, 3, 6)$ to the origin $O(0, 0, 0)$ in three-dimensional space.

Uses: Coordinates of a Point in Space

Hint

The distance to the origin is given by $OP = \sqrt{x^2 + y^2 + z^2}$.

Solution

Using the coordinates $(2, 3, 6)$:

\[ OP = \sqrt{2^2 + 3^2 + 6^2} = \sqrt{4 + 9 + 36} = \sqrt{49} = 7. \]

If $l, m, n$ are the direction cosines of any straight line in space, evaluate the sum $l^2 + m^2 + n^2$.

Uses: Coordinates of a Point in Space

Hint

The direction cosines represent the components of a unit vector along the line: $\mathbf{u} = \langle l, m, n \rangle$ where $\|\mathbf{u}\| = 1$.

Solution

For any direction vector with angles $\alpha, \beta, \gamma$ to the positive coordinate axes:

\[ l = \cos\alpha, \quad m = \cos\beta, \quad n = \cos\gamma. \]

Since $\langle l, m, n \rangle$ is a unit vector pointing along the line:

\[ l^2 + m^2 + n^2 = \cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1. \]

The line $\frac{x-1}{2} = \frac{y-2}{3} = \frac{z-3}{4}$ is perpendicular to the plane $4x + 6y + kz = 15$. Find the value of $k$.

Uses: Parallel, Skew, and Perpendicular Lines, Planes in Space

Hint

A line is perpendicular to a plane if its direction vector $\mathbf{d}$ is parallel (proportional) to the normal vector $\mathbf{n}$ of the plane.

Solution

The direction vector of the line is $\mathbf{d} = \langle 2, 3, 4 \rangle$, and the normal vector to the plane is $\mathbf{n} = \langle 4, 6, k \rangle$.

Since the line is perpendicular to the plane, $\mathbf{d}$ and $\mathbf{n}$ must be proportional:

\[ \frac{4}{2} = \frac{6}{3} = \frac{k}{4} = 2 \] \[ \frac{k}{4} = 2 \implies k = 8. \]

Find the diameter of the sphere whose equation is $(x - 1)^2 + (y - 2)^2 + (z - 2)^2 = 9$.

Uses: Equations of Spheres

Hint

Compare with $(x-h)^2 + (y-k)^2 + (z-l)^2 = R^2$. The diameter is $2R$.

Solution

The standard sphere equation indicates $R^2 = 9$, which gives radius $R = 3$.

The diameter is therefore:

\[ D = 2R = 2(3) = 6. \]

Find the perpendicular distance between the two parallel planes $2x - y + 2z + 4 = 0$ and $2x - y + 2z - 5 = 0$.

Uses: Planes in Space

Hint

The distance between parallel planes $Ax + By + Cz + D_1 = 0$ and $Ax + By + Cz + D_2 = 0$ is $d = \frac{|D_1 - D_2|}{\sqrt{A^2 + B^2 + C^2}}$.

Solution

Here $A = 2$, $B = -1$, $C = 2$, $D_1 = 4$, and $D_2 = -5$:

\[ d = \frac{|4 - (-5)|}{\sqrt{2^2 + (-1)^2 + 2^2}} = \frac{|9|}{\sqrt{4 + 1 + 4}} = \frac{9}{\sqrt{9}} = \frac{9}{3} = 3. \]

A sphere has its center at $(2, 3, 6)$ and passes through the origin $O(0, 0, 0)$. Find the radius of this sphere.

Uses: Equations of Spheres

Hint

The radius of the sphere is the Euclidean distance from the center $(2, 3, 6)$ to the given boundary point $(0, 0, 0)$.

Solution

The radius is the distance from the center $C(2, 3, 6)$ to $O(0, 0, 0)$:

\[ R = \sqrt{(2 - 0)^2 + (3 - 0)^2 + (6 - 0)^2} = \sqrt{4 + 9 + 36} = \sqrt{49} = 7. \]
