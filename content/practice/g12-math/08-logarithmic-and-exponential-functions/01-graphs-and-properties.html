Logarithmic and Exponential Functions — Graphs and Properties

Practise graphs of logarithmic and exponential functions, domain and range, vertical and horizontal asymptotes, intercepts, and inverse relationships.

Find the vertical asymptote $x = k$ of the logarithmic function $f(x) = \ln(x - 4)$. What is the value of $k$?

Uses: Graphs of Logarithmic Functions

Hint

The natural logarithm $\ln u$ is defined only when $u > 0$. The vertical asymptote occurs where the argument equals zero: $x - 4 = 0$.

Solution

Set the argument of the logarithm to zero:

\[ x - 4 = 0 \implies x = 4. \]

Thus the vertical asymptote is $x = 4$, so $k = 4$.

Find the horizontal asymptote $y = k$ of the exponential function $f(x) = e^x - 3$ as $x \to -\infty$. What is $k$?

Uses: Graphs of Exponential Functions

Hint

Recall that $\lim_{x \to -\infty} e^x = 0$. Evaluate the limit of $f(x)$ as $x \to -\infty$.

Solution

Taking the limit as $x \to -\infty$:

\[ \lim_{x \to -\infty} (e^x - 3) = 0 - 3 = -3. \]

The horizontal asymptote is $y = -3$, so $k = -3$.

Find the $x$-intercept of the function $f(x) = \log_2(x - 3)$.

Uses: Graphs of Logarithmic Functions

Hint

Set $f(x) = 0$. Recall that $\log_b(u) = 0$ when $u = 1$.

Solution

Set $f(x) = 0$:

\[ \log_2(x - 3) = 0 \implies x - 3 = 2^0 = 1 \implies x = 4. \]

Find the $y$-intercept of the exponential function $f(x) = 3 \cdot 2^{x+1} - 1$.

Uses: Graphs of Exponential Functions

Hint

The $y$-intercept is found by evaluating $f(0)$.

Solution

Substitute $x = 0$ into the function:

\[ f(0) = 3 \cdot 2^{0+1} - 1 = 3 \cdot 2 - 1 = 6 - 1 = 5. \]

If $f(x) = e^{x-2} + 5$, evaluate $f^{-1}(6)$.

Uses: Graphs of Exponential Functions

Hint

Finding $f^{-1}(6)$ is equivalent to solving the equation $f(x) = 6$ for $x$.

Solution

Set $f(x) = 6$:

\[ e^{x-2} + 5 = 6 \implies e^{x-2} = 1. \]

Take the natural logarithm of both sides:

\[ x - 2 = \ln(1) = 0 \implies x = 2. \]

Therefore, $f^{-1}(6) = 2$.

The natural domain of the function $f(x) = \ln(9 - x^2)$ is the open interval $(-a, a)$. Find the value of $a$.

Uses: Graphs of Logarithmic Functions

Hint

The argument of the natural logarithm must be strictly positive: $9 - x^2 > 0$.

Solution

Solve the inequality for the domain:

\[ 9 - x^2 > 0 \implies x^2 < 9 \implies -3 < x < 3. \]

Comparing with $(-a, a)$, we have $a = 3$.
