Logarithmic and Exponential Functions

A comprehensive review of Logarithmic and Exponential Functions, covering graph properties, asymptotes, inverses, and differentiation rules.

Evaluate the exact numerical value of $\ln(e)$.

Uses: Graphs of Logarithmic Functions

Hint

The natural logarithm has base $e$. By definition, $\log_b(b) = 1$.

Solution

Since $\ln x \equiv \log_e x$:

\[ \ln(e) = \log_e(e) = 1. \]

Let $f(x) = e^{3x}$. Find the value of the derivative $f'(0)$.

Uses: Differentiation of Exponential Functions

Hint

By the chain rule, $\frac{d}{dx}(e^{kx}) = k\,e^{kx}$.

Solution

Differentiating $f(x)$:

\[ f'(x) = 3e^{3x}. \]

At $x = 0$:

\[ f'(0) = 3e^0 = 3(1) = 3. \]

Let $f(x) = x\ln x$. Evaluate the derivative $f'(1)$.

Uses: Differentiation of Logarithmic Functions

Hint

Apply the product rule: $\frac{d}{dx}(x\ln x) = (1)\ln x + x(1/x) = \ln x + 1$.

Solution

Applying the product rule:

\[ f'(x) = (1)\ln x + x\left(\frac{1}{x}\right) = \ln x + 1. \]

Substitute $x = 1$ (noting $\ln 1 = 0$):

\[ f'(1) = \ln(1) + 1 = 0 + 1 = 1. \]

Find the minimum value of the function $f(x) = x - \ln x$ for $x > 0$.

Uses: Differentiation of Logarithmic Functions

Hint

Set $f'(x) = 1 - \frac{1}{x} = 0$ to find the critical point, then evaluate $f(x)$ at that point.

Solution

Find the critical point:

\[ f'(x) = 1 - \frac{1}{x} = 0 \implies x = 1. \]

Since $f''(x) = \frac{1}{x^2} > 0$, this is a local and global minimum.

Evaluate $f(1)$:

\[ f(1) = 1 - \ln(1) = 1 - 0 = 1. \]

Find the slope of the normal line to the curve $y = e^x$ at the point $(0, 1)$.

Uses: Differentiation of Exponential Functions

Hint

First find the tangent slope $m_{\text{tan}} = y'(0)$. The normal slope is $m_{\text{norm}} = -\frac{1}{m_{\text{tan}}}$.

Solution

The derivative is $y' = e^x$. At $x = 0$:

\[ m_{\text{tan}} = e^0 = 1. \]

The slope of the perpendicular normal line is:

\[ m_{\text{norm}} = -\frac{1}{m_{\text{tan}}} = -\frac{1}{1} = -1. \]

Find the non-zero $x$-coordinate where the function $f(x) = x^2 e^{-x}$ has a local maximum.

Uses: Differentiation of Exponential Functions

Hint

Differentiate using the product rule: $f'(x) = 2x e^{-x} - x^2 e^{-x} = x(2 - x)e^{-x}$. Set $f'(x) = 0$.

Solution

Differentiating using the product rule:

\[ f'(x) = 2x\,e^{-x} + x^2(-e^{-x}) = (2x - x^2)e^{-x} = x(2 - x)e^{-x}. \]

Since $e^{-x} > 0$ for all real $x$, setting $f'(x) = 0$ yields:

\[ x = 0 \quad \text{or} \quad x = 2. \]

The non-zero critical point where $f(x)$ attains a local maximum is $x = 2$.
