Pure Imaginary Numbers and Arithmetic Operations

Six practice problems on powers of $i$, equality of complex numbers, quadratic equations with complex roots, arithmetic operations and complex conjugates. Try each one first. Open the hint if you are stuck, then compare with the full step-by-step solution.

Problem 1

Simplify the expression $i^{26} + i^{48} + i^{75} + i^{101}$.

Uses: Pure Imaginary Unit and Complex Numbers

Show hint

Divide each exponent by $4$: $i^1 = i$, $i^2 = -1$, $i^3 = -i$, and $i^4 = 1$.

Show solution
  1. $26 = 4(6) + 2 \implies i^{26} = i^2 = -1$.
  2. $48 = 4(12) \implies i^{48} = 1$.
  3. $75 = 4(18) + 3 \implies i^{75} = i^3 = -i$.
  4. $101 = 4(25) + 1 \implies i^{101} = i^1 = i$.
  5. Total sum: $(-1) + 1 + (-i) + i = 0$.

$0$

Problem 2

Solve the quadratic equation $3x^2 - 4x + 2 = 0$. (Type the real part of the solutions in the box.)

Uses: Pure Imaginary Unit and Complex Numbers

Show hint

Use the quadratic formula $x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$ with $a = 3, b = -4, c = 2$.

Show solution
  1. Compute discriminant: $\Delta = (-4)^2 - 4(3)(2) = 16 - 24 = -8$.
  2. Square root: $\sqrt{-8} = \sqrt{8}\,i = 2\sqrt{2}\,i$.
  3. Solutions: $x = \dfrac{4 \pm 2\sqrt{2}\,i}{6} = \dfrac{2}{3} \pm \dfrac{\sqrt{2}}{3}i$.
  4. The real part is $\dfrac{2}{3}$.

$x = \dfrac{2}{3} \pm \dfrac{\sqrt{2}}{3}i$ (real part is $\dfrac{2}{3}$)

Problem 3

Find the real numbers $x$ and $y$ satisfying $(2x - i)(1 + 2i) = 10 + yi$. (Type $x$ in the box.)

Uses: Pure Imaginary Unit and Complex Numbers, Arithmetic Operations and Conjugates

Show hint

Expand the left side into real and imaginary parts, then equate with $10 + yi$.

Show solution
  1. Expand left side: $(2x - i)(1 + 2i) = 2x + 4xi - i - 2i^2 = (2x + 2) + (4x - 1)i$.
  2. Equate real parts: $2x + 2 = 10 \implies 2x = 8 \implies x = 4$.
  3. Equate imaginary parts: $y = 4x - 1 = 4(4) - 1 = 15$.

$x = 4, \; y = 15$

Problem 4

Given $z_1 = 3 + 2i$ and $z_2 = 2 - 3i$, calculate the product $z_1 z_2$ and find its absolute value $|z_1 z_2|$. (Type $|z_1 z_2|$ in the box.)

Uses: Arithmetic Operations and Conjugates

Show hint

Multiply $(3 + 2i)(2 - 3i)$ directly, or use $|z_1 z_2| = |z_1| \cdot |z_2|$.

Show solution
  1. Multiply: $z_1 z_2 = (3 + 2i)(2 - 3i) = 6 - 9i + 4i - 6i^2 = (6 + 6) + (-9 + 4)i = 12 - 5i$.
  2. Calculate modulus: $|z_1 z_2| = \sqrt{12^2 + (-5)^2} = \sqrt{144 + 25} = \sqrt{169} = 13$.
  3. Alternatively: $|z_1| = \sqrt{3^2 + 2^2} = \sqrt{13}$, $|z_2| = \sqrt{2^2 + (-3)^2} = \sqrt{13}$, so $|z_1 z_2| = \sqrt{13} \cdot \sqrt{13} = 13$.

$z_1 z_2 = 12 - 5i, \;\; |z_1 z_2| = 13$

Problem 5

Express the quotient $z = \dfrac{5 - i}{2 - 3i}$ in the standard rectangular form $a + bi$. (Type the real part $a$ in the box.)

Uses: Arithmetic Operations and Conjugates

Show hint

Multiply numerator and denominator by the complex conjugate of the denominator, $2 + 3i$.

Show solution
  1. Identify the conjugate of the denominator: $\overline{2 - 3i} = 2 + 3i$.
  2. Denominator product: $(2 - 3i)(2 + 3i) = 2^2 + (-3)^2 = 4 + 9 = 13$.
  3. Numerator product: $(5 - i)(2 + 3i) = 10 + 15i - 2i - 3i^2 = (10 + 3) + (15 - 2)i = 13 + 13i$.
  4. Divide: $z = \dfrac{13 + 13i}{13} = 1 + i$.
  5. The real part is $a = 1$ (and imaginary part is $b = 1$).

$z = 1 + i$ (real part is $1$)

Problem 6

If $(x + yi)^2 = 7 + 24i$ for real numbers $x$ and $y$, find the value of $x^2 + y^2$.

Uses: Arithmetic Operations and Conjugates

Show hint

Take the modulus of both sides: $|(x + yi)^2| = |x + yi|^2 = x^2 + y^2$.

Show solution
  1. Taking the modulus of both sides: $|(x + yi)^2| = |7 + 24i|$.
  2. Using $|z^2| = |z|^2$: $(x^2 + y^2) = \sqrt{7^2 + 24^2} = \sqrt{49 + 576} = \sqrt{625} = 25$.
  3. (Direct verification: $x^2 - y^2 = 7$ and $2xy = 24 \implies xy = 12$. Since $(x^2 + y^2)^2 = (x^2 - y^2)^2 + (2xy)^2 = 7^2 + 24^2 = 625$, $x^2 + y^2 = 25$.)

$x^2 + y^2 = 25$
