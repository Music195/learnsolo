Problem 1

Find real numbers $x$ and $y$ such that $(x + yi)(2 - i) = 10$. (Type $x$ in the box.)

Uses: Pure Imaginary Unit and Complex Numbers, Arithmetic Operations and Conjugates

Show hint

Isolate $x + yi = \dfrac{10}{2 - i}$, then multiply top and bottom by the conjugate $2 + i$.

Show solution
  1. Solve for $x + yi$: $$x + yi = \frac{10}{2 - i} = \frac{10(2 + i)}{(2 - i)(2 + i)} = \frac{10(2 + i)}{2^2 + (-1)^2} = \frac{10(2 + i)}{5} = 2(2 + i) = 4 + 2i$$
  2. Equate real and imaginary parts: $x = 4$ and $y = 2$.

$x = 4, \;\; y = 2$

Problem 2

Given $z = 1 - \sqrt{3}\,i$, calculate the modulus $|z^5|$.

Uses: Trigonometric and Polar Form, Powers and De Moivre's Theorem

Show hint

Use the property $|z^n| = |z|^n$.

Show solution
  1. Find the modulus of $z$: $|z| = \sqrt{1^2 + (-\sqrt{3})^2} = \sqrt{1 + 3} = \sqrt{4} = 2$.
  2. By modulus of powers: $|z^5| = |z|^5 = 2^5 = 32$.

$|z^5| = 32$

Problem 3

Evaluate $(1 + \sqrt{3}\,i)^6 + (1 - \sqrt{3}\,i)^6$.

Uses: Powers and De Moivre's Theorem

Show hint

Convert both numbers to polar form with modulus $2$ and angles $\pm \dfrac{\pi}{3}$, then apply De Moivre's theorem.

Show solution
  1. Polar form: $$1 + \sqrt{3}\,i = 2\left(\cos \frac{\pi}{3} + i\sin \frac{\pi}{3}\right), \qquad 1 - \sqrt{3}\,i = 2\left(\cos\left(-\frac{\pi}{3}\right) + i\sin\left(-\frac{\pi}{3}\right)\right)$$
  2. Raise to 6th power by De Moivre's theorem: $$(1 + \sqrt{3}\,i)^6 = 2^6\left(\cos(2\pi) + i\sin(2\pi)\right) = 64(1 + 0) = 64$$ $$(1 - \sqrt{3}\,i)^6 = 2^6\left(\cos(-2\pi) + i\sin(-2\pi)\right) = 64(1 + 0) = 64$$
  3. Sum: $64 + 64 = 128$.

$128$

Problem 4

Solve the equation $z^4 + 16 = 0$ in the complex number system. Find the radius (common distance from the origin) of all four roots on the Argand plane.

Uses: Roots of Complex Numbers

Show hint

Write $z^4 = -16 = 16(\cos\pi + i\sin\pi)$, then find the 4th roots.

Show solution
  1. Rewrite: $z^4 = -16 = 16(\cos\pi + i\sin\pi)$.
  2. The modulus of each root is $r = \sqrt[4]{16} = 2$.
  3. The arguments are $\theta_k = \dfrac{\pi + 2k\pi}{4} = \dfrac{\pi}{4}, \dfrac{3\pi}{4}, \dfrac{5\pi}{4}, \dfrac{7\pi}{4}$ for $k = 0, 1, 2, 3$.
  4. The four roots are $2\left(\pm \dfrac{\sqrt{2}}{2} \pm \dfrac{\sqrt{2}}{2}i\right) = \pm\sqrt{2} \pm \sqrt{2}i$, each having distance $r = 2$ from the origin.

$r = 2$ (roots are $\pm\sqrt{2} \pm \sqrt{2}i$)

Problem 5

Let $z = \cos\theta + i\sin\theta$. Using De Moivre's theorem, evaluate $z^3 + \dfrac{1}{z^3}$ when $\theta = \dfrac{\pi}{6}$.

Uses: Powers and De Moivre's Theorem

Show hint

Recall $z^n = \cos n\theta + i\sin n\theta$ and $\dfrac{1}{z^n} = z^{-n} = \cos n\theta - i\sin n\theta$, so $z^n + \dfrac{1}{z^n} = 2\cos n\theta$.

Show solution
  1. By De Moivre's theorem: $z^3 = \cos 3\theta + i\sin 3\theta$.
  2. Similarly: $\dfrac{1}{z^3} = z^{-3} = \cos(-3\theta) + i\sin(-3\theta) = \cos 3\theta - i\sin 3\theta$.
  3. Adding both: $z^3 + \dfrac{1}{z^3} = 2\cos 3\theta$.
  4. For $\theta = \dfrac{\pi}{6}$: $3\theta = 3 \cdot \dfrac{\pi}{6} = \dfrac{\pi}{2}$.
  5. Since $\cos \dfrac{\pi}{2} = 0$, $2\cos \dfrac{\pi}{2} = 2(0) = 0$.

$0$

Problem 6

If $\omega$ is a complex cube root of unity ($\omega^3 = 1$ and $\omega \neq 1$), find the value of the product $(1 - \omega)(1 - \omega^2)(1 - \omega^4)(1 - \omega^5)$.

Uses: Roots of Complex Numbers

Show hint

Reduce higher powers using $\omega^3 = 1$: $\omega^4 = \omega$ and $\omega^5 = \omega^2$. Then use $1 + \omega + \omega^2 = 0$.

Show solution
  1. Simplify higher powers: $\omega^4 = \omega^3 \cdot \omega = \omega$, and $\omega^5 = \omega^3 \cdot \omega^2 = \omega^2$.
  2. The product becomes: $$(1 - \omega)(1 - \omega^2)(1 - \omega)(1 - \omega^2) = \bigl[(1 - \omega)(1 - \omega^2)\bigr]^2$$
  3. Expand the inner product: $$(1 - \omega)(1 - \omega^2) = 1 - \omega^2 - \omega + \omega^3 = 1 - (\omega + \omega^2) + 1$$
  4. Since $1 + \omega + \omega^2 = 0 \implies \omega + \omega^2 = -1$: $$1 - (-1) + 1 = 3$$
  5. Square the result: $3^2 = 9$.

$9$
