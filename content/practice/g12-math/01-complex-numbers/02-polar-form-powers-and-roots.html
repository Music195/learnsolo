Polar Form, De Moivre's Theorem and Roots

Six practice problems on trigonometric polar form, modulus and argument, products and quotients in polar form, De Moivre's theorem and $n$-th roots of complex numbers. Try each one first. Open the hint if you are stuck, then compare with the full step-by-step solution.

Problem 1

Find the modulus $r$ and principal argument $\theta$ of the complex number $z = -2 + 2\sqrt{3}\,i$. (Type the modulus $r$ in the box.)

Uses: Trigonometric and Polar Form

Show hint

$r = \sqrt{x^2 + y^2}$. Notice that $(-2, 2\sqrt{3})$ lies in the second quadrant ($\frac{\pi}{2} < \theta < \pi$).

Show solution
  1. Modulus: $r = \sqrt{(-2)^2 + (2\sqrt{3})^2} = \sqrt{4 + 12} = \sqrt{16} = 4$.
  2. Reference angle: $\tan \alpha = \left|\dfrac{2\sqrt{3}}{-2}\right| = \sqrt{3} \implies \alpha = \dfrac{\pi}{3}$ ($60^\circ$).
  3. Since $x < 0$ and $y > 0$ (Quadrant II), the principal argument is $\theta = \pi - \dfrac{\pi}{3} = \dfrac{2\pi}{3}$ ($120^\circ$).
  4. In polar form: $z = 4\left(\cos \dfrac{2\pi}{3} + i\sin \dfrac{2\pi}{3}\right)$.

$r = 4, \;\; \theta = \dfrac{2\pi}{3}$ ($120^\circ$)

Problem 2

Given $z_1 = 6(\cos 75^\circ + i\sin 75^\circ)$ and $z_2 = 2(\cos 15^\circ + i\sin 15^\circ)$, evaluate the quotient $\dfrac{z_1}{z_2}$ in rectangular form $a + bi$. (Type the real part $a$ in the box.)

Uses: Trigonometric and Polar Form

Show hint

In polar form, divide the moduli and subtract the angles: $\dfrac{z_1}{z_2} = \dfrac{r_1}{r_2}\bigl(\cos(\theta_1 - \theta_2) + i\sin(\theta_1 - \theta_2)\bigr)$.

Show solution
  1. Modulus: $\dfrac{r_1}{r_2} = \dfrac{6}{2} = 3$.
  2. Argument: $\theta_1 - \theta_2 = 75^\circ - 15^\circ = 60^\circ$.
  3. Trigonometric evaluation: $\dfrac{z_1}{z_2} = 3(\cos 60^\circ + i\sin 60^\circ) = 3\left(\dfrac{1}{2} + \dfrac{\sqrt{3}}{2}i\right) = \dfrac{3}{2} + \dfrac{3\sqrt{3}}{2}i$.
  4. The real part is $\dfrac{3}{2}$.

$\dfrac{3}{2} + \dfrac{3\sqrt{3}}{2}i$ (real part is $\dfrac{3}{2}$)

Problem 3

Use De Moivre's theorem to compute $(1 + i)^{10}$. (Type the imaginary part in the box.)

Uses: Powers and De Moivre's Theorem

Show hint

Convert $1 + i$ into polar form: $r = \sqrt{2}, \theta = \dfrac{\pi}{4}$. Then apply $\bigl[r(\cos\theta + i\sin\theta)\bigr]^n = r^n(\cos n\theta + i\sin n\theta)$.

Show solution
  1. Polar form of $1 + i$: $r = \sqrt{1^2 + 1^2} = \sqrt{2}$, $\theta = \dfrac{\pi}{4}$, so $1 + i = \sqrt{2}\left(\cos \dfrac{\pi}{4} + i\sin \dfrac{\pi}{4}\right)$.
  2. Apply De Moivre's theorem: $$(1 + i)^{10} = (\sqrt{2})^{10}\left(\cos \frac{10\pi}{4} + i\sin \frac{10\pi}{4}\right) = 2^5\left(\cos \frac{5\pi}{2} + i\sin \frac{5\pi}{2}\right)$$
  3. Evaluate trig functions: $\dfrac{5\pi}{2} = 2\pi + \dfrac{\pi}{2}$, so $\cos \dfrac{5\pi}{2} = 0$ and $\sin \dfrac{5\pi}{2} = 1$.
  4. Total: $32(0 + 1i) = 32i$. The imaginary part is $32$.

$32i$ (imaginary part is $32$)

Problem 4

Calculate the exact value of $\left(\dfrac{\sqrt{3} + i}{2}\right)^{12}$.

Uses: Powers and De Moivre's Theorem

Show hint

Recognize that $\dfrac{\sqrt{3}}{2} + \dfrac{1}{2}i = \cos \dfrac{\pi}{6} + i\sin \dfrac{\pi}{6}$.

Show solution
  1. Polar form: $\dfrac{\sqrt{3} + i}{2} = \cos \dfrac{\pi}{6} + i\sin \dfrac{\pi}{6}$ (modulus is $1$).
  2. By De Moivre's theorem: $$\left(\cos \frac{\pi}{6} + i\sin \frac{\pi}{6}\right)^{12} = \cos\left(12 \cdot \frac{\pi}{6}\right) + i\sin\left(12 \cdot \frac{\pi}{6}\right) = \cos(2\pi) + i\sin(2\pi)$$
  3. Since $\cos(2\pi) = 1$ and $\sin(2\pi) = 0$, the value is $1 + 0i = 1$.

$1$

Problem 5

Find the radius (common modulus) of the four fourth roots of $z = -8 - 8\sqrt{3}\,i$.

Uses: Roots of Complex Numbers

Show hint

If $z = r(\cos\theta + i\sin\theta)$, the $n$-th roots all lie on a circle centered at the origin of radius $\sqrt[n]{r}$.

Show solution
  1. Compute modulus $|z|$: $$|z| = \sqrt{(-8)^2 + (-8\sqrt{3})^2} = \sqrt{64 + 64(3)} = \sqrt{64(4)} = \sqrt{256} = 16$$
  2. Each of the $4$ fourth roots $w_k$ has modulus $|w_k| = \sqrt[4]{|z|} = \sqrt[4]{16} = 2$.
  3. (All four roots lie equally spaced at $90^\circ$ intervals on the circle of radius $2$.)

$r = 2$

Problem 6

Let $\omega$ be a non-real complex cube root of unity ($\omega^3 = 1$ and $\omega \neq 1$). Calculate the value of $(1 - \omega + \omega^2)(1 + \omega - \omega^2)$.

Uses: Roots of Complex Numbers

Show hint

Use the fundamental relation of cube roots of unity: $1 + \omega + \omega^2 = 0$, so $1 + \omega^2 = -\omega$ and $1 + \omega = -\omega^2$.

Show solution
  1. From $\omega^3 - 1 = (\omega - 1)(\omega^2 + \omega + 1) = 0$ with $\omega \neq 1$, we have $1 + \omega + \omega^2 = 0$.
  2. Rewrite the first factor: $(1 + \omega^2) - \omega = (-\omega) - \omega = -2\omega$.
  3. Rewrite the second factor: $(1 + \omega) - \omega^2 = (-\omega^2) - \omega^2 = -2\omega^2$.
  4. Multiply the two factors: $(-2\omega)(-2\omega^2) = 4\omega^3 = 4(1) = 4$.

$4$
