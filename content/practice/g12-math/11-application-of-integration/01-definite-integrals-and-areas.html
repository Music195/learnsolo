Application of Integration — Definite Integrals and Areas

Practise the fundamental properties of definite integrals, computing the area between a curve and the $x$-axis, and determining the enclosed area between two intersecting curves.

Given that $\int_1^4 f(x)\,dx = 7$ and $\int_2^4 f(x)\,dx = 3$, find the value of $\int_1^2 f(x)\,dx$.

Uses: Definite Integrals and Properties

Hint

Use the interval additivity property: $\int_1^4 f(x)\,dx = \int_1^2 f(x)\,dx + \int_2^4 f(x)\,dx$.

Solution

By the additivity property of definite integrals:

\[ \int_1^2 f(x)\,dx = \int_1^4 f(x)\,dx - \int_2^4 f(x)\,dx = 7 - 3 = 4. \]

Find the area of the region bounded by the parabola $y = x^2$, the $x$-axis, and the vertical line $x = 3$.

Uses: Area Between a Curve and the x-axis

Hint

Since $y \ge 0$ on $[0, 3]$, the area is $\int_0^3 x^2\,dx$.

Solution

Integrate $y = x^2$ from $0$ to $3$:

\[ \text{Area} = \int_0^3 x^2\,dx = \left[\frac{x^3}{3}\right]_0^3 = \frac{27}{3} - 0 = 9. \]

Find the total area enclosed between the two parabolas $y = 6x - x^2$ and $y = x^2$.

Uses: Area Between Two Curves

Hint

Find the intersection points by setting $6x - x^2 = x^2$. Then integrate $(6x - 2x^2)$ between these bounds.

Solution

Determine the intersection points:

\[ 6x - x^2 = x^2 \implies 2x^2 - 6x = 0 \implies 2x(x - 3) = 0 \implies x = 0 \text{ and } x = 3. \]

On $[0, 3]$, $6x - x^2 \ge x^2$. The enclosed area is:

\[ \text{Area} = \int_0^3 ((6x - x^2) - x^2)\,dx = \int_0^3 (6x - 2x^2)\,dx \] \[ = \left[3x^2 - \frac{2x^3}{3}\right]_0^3 = 3(9) - \frac{2(27)}{3} = 27 - 18 = 9. \]

Find the total geometric area enclosed between the cubic curve $y = x^3$ and the $x$-axis between $x = -1$ and $x = 1$.

Uses: Area Between a Curve and the x-axis

Hint

Area is always positive: $\text{Area} = \int_{-1}^1 |x^3|\,dx = 2\int_0^1 x^3\,dx$.

Solution

Because $x^3 \le 0$ on $[-1, 0]$ and $x^3 \ge 0$ on $[0, 1]$, we take the absolute value:

\[ \text{Area} = \int_{-1}^0 (-x^3)\,dx + \int_0^1 x^3\,dx = 2\int_0^1 x^3\,dx = 2\left[\frac{x^4}{4}\right]_0^1 = 2\left(\frac{1}{4}\right) = 0.5. \]

Find the area of the region enclosed between the straight line $y = x + 2$ and the parabola $y = x^2$ as a decimal.

Uses: Area Between Two Curves

Hint

Find the intersection points by solving $x^2 = x + 2$. Integrate $(x + 2 - x^2)$ from $x = -1$ to $x = 2$.

Solution

Find the points of intersection:

\[ x^2 = x + 2 \implies x^2 - x - 2 = 0 \implies (x - 2)(x + 1) = 0 \implies x = -1, \, x = 2. \]

On $[-1, 2]$, the line is above the parabola ($x + 2 \ge x^2$):

\[ \text{Area} = \int_{-1}^2 (x + 2 - x^2)\,dx = \left[\frac{x^2}{2} + 2x - \frac{x^3}{3}\right]_{-1}^2 \] \[ = \left(\frac{4}{2} + 4 - \frac{8}{3}\right) - \left(\frac{1}{2} - 2 - \left(-\frac{1}{3}\right)\right) = \left(6 - \frac{8}{3}\right) - \left(-\frac{3}{2} + \frac{1}{3}\right) = \frac{10}{3} - \left(-\frac{7}{6}\right) = \frac{27}{6} = 4.5. \]

Evaluate the definite integral $\int_{-3}^3 (2x^5 - 4x^3 + 5)\,dx$.

Uses: Definite Integrals and Properties

Hint

Split into odd and even parts: for an odd function, $\int_{-a}^a g(x)\,dx = 0$.

Solution

Notice that $2x^5 - 4x^3$ is an odd function, so its integral over the symmetric interval $[-3, 3]$ is $0$:

\[ \int_{-3}^3 (2x^5 - 4x^3)\,dx = 0. \]

The remaining constant term gives:

\[ \int_{-3}^3 5\,dx = 5(3 - (-3)) = 5(6) = 30. \]
