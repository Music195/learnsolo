Graphs, Inverse and Composite Functions

Six problems on rational and irrational functions, inverse functions and composite functions. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Find the asymptotes, the domain and the range of $y = \dfrac{-x + 4}{x - 2}$. (Type the $y$ of the horizontal asymptote in the box.)

Uses: Graph of a Rational Function

Show hint

Divide: write the function as $\dfrac{k}{x - p} + q$.

Show solution
  1. $-x + 4 = -(x - 2) + 2$, so $y = \dfrac{2}{x - 2} - 1$.
  2. Asymptotes $x = 2$ and $y = -1$; domain $x \ne 2$, range $y \ne -1$.

Asymptotes $x = 2$, $y = -1$; domain $x \ne 2$; range $y \ne -1$

Problem 2

Find the domain and the range of $y = \sqrt{6 - 2x} - 3$. (Type the largest $x$ in the domain in the box.)

Uses: Graph of an Irrational Function

Show hint

The expression under the root must be $\ge 0$, and $\sqrt{\phantom{x}} \ge 0$.

Show solution
  1. $6 - 2x \ge 0 \iff x \le 3$.
  2. $\sqrt{6 - 2x} \ge 0$, so $y \ge -3$. The graph starts at $(3, -3)$ and goes up to the left.

Domain $x \le 3$, range $y \ge -3$

Problem 3

Find the inverse function of $f(x) = \dfrac{2x - 1}{x + 3}$, and $f^{-1}(1)$. (Type $f^{-1}(1)$ in the box.)

Uses: Finding Inverse Functions

Show hint

Solve $y = \dfrac{2x - 1}{x + 3}$ for $x$, then swap $x$ and $y$.

Show solution
  1. $y(x + 3) = 2x - 1 \iff x(y - 2) = -3y - 1 \iff x = \dfrac{3y + 1}{2 - y}$.
  2. Swap: $f^{-1}(x) = \dfrac{3x + 1}{2 - x}$.
  3. $f^{-1}(1) = \dfrac{4}{1} = 4$. Check: $f(4) = \dfrac{7}{7} = 1$ ✓.

$f^{-1}(x) = \dfrac{3x + 1}{2 - x}$; $f^{-1}(1) = 4$

Problem 4

$f(x) = 2x - 3$ and $g(x) = x^2 + 1$. Find $(g \circ f)(x)$, $(f \circ g)(x)$ and $(f \circ g)(-2)$. (Type the last value in the box.)

Uses: Inverse and Composite Functions

Show hint

$(g \circ f)(x) = g(f(x))$: apply $f$ first, then $g$.

Show solution
  1. $(g \circ f)(x) = (2x - 3)^2 + 1 = 4x^2 - 12x + 10$.
  2. $(f \circ g)(x) = 2(x^2 + 1) - 3 = 2x^2 - 1$.
  3. $(f \circ g)(-2) = 8 - 1 = 7$.

$4x^2 - 12x + 10$; $2x^2 - 1$; $7$

$g \circ f$ and $f \circ g$ are different functions: the order matters.

Problem 5

Solve $\dfrac{2}{x - 1} \ge x - 2$ using the graphs of both sides. (Type the largest $x$ in the box.)

Uses: Graph of a Rational Function

Show hint

Find where the hyperbola $y = \dfrac{2}{x - 1}$ meets the line $y = x - 2$, then see on which intervals the hyperbola is above. Remember $x \ne 1$.

Show solution
  1. Meeting points: $2 = (x - 1)(x - 2) \iff x^2 - 3x = 0 \iff x = 0, 3$.
  2. Left branch ($x < 1$): the hyperbola is above the line for $x \le 0$ (e.g. $x = -1$: $-1 \ge -3$).
  3. Right branch ($x > 1$): above for $1 < x \le 3$ (e.g. $x = 2$: $2 \ge 0$).
  4. Solution: $x \le 0$ or $1 < x \le 3$.

$x \le 0$ or $1 < x \le 3$

Problem 6

$f(x) = \sqrt{2x + 4}$.

  1. (1) Find the domain and the range of $f$.
  2. (2) Find $f^{-1}(x)$ with its domain.
  3. (3) Find the common point of $y = f(x)$ and $y = f^{-1}(x)$. (Type its $x$-coordinate in the box.)

Uses: Graph of an Irrational Function, Finding Inverse Functions, Inverse and Composite Functions

Show hint

$f$ is increasing, so the graphs of $f$ and $f^{-1}$ can only meet on the line $y = x$.

Show solution
  1. (1) Domain $x \ge -2$, range $y \ge 0$.
  2. (2) $y^2 = 2x + 4 \iff x = \dfrac{y^2 - 4}{2}$, with $y \ge 0$. So $f^{-1}(x) = \dfrac{x^2 - 4}{2}$ ($x \ge 0$).
  3. (3) Solve $\sqrt{2x + 4} = x$ with $x \ge 0$: $x^2 - 2x - 4 = 0$, $x = 1 \pm \sqrt{5}$. Only $x = 1 + \sqrt{5}$ is $\ge 0$.
  4. Common point $(1 + \sqrt{5}, 1 + \sqrt{5})$.

(1) $x \ge -2$, $y \ge 0$ (2) $f^{-1}(x) = \dfrac{x^2 - 4}{2}$ ($x \ge 0$) (3) $(1 + \sqrt{5}, 1 + \sqrt{5})$
