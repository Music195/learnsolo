Rational, Irrational and Inverse Functions

Topic review: a mix of the whole topic, best tried after the concept set. Five problems on asymptotes, irrational equations and inverse functions. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Find the asymptotes of $y = \dfrac{2x + 1}{x - 1}$.

Uses: Graph of a Rational Function

Show hint

Divide to get the form $y = \dfrac{k}{x - p} + q$.

Show solution
  1. $2x + 1 = 2(x - 1) + 3$, so $y = \dfrac{3}{x - 1} + 2$.
  2. This is $y = \dfrac{3}{x}$ moved $1$ right and $2$ up.

$x = 1$ and $y = 2$

Problem 2

$f(x) = \dfrac{x + 1}{x - 2}$. Find $f^{-1}(3)$.

Uses: Inverse Function Properties

Show hint

$f^{-1}(3) = b$ means $f(b) = 3$. You don't need the whole inverse function.

Show solution
  1. Solve $\dfrac{b + 1}{b - 2} = 3$: $b + 1 = 3b - 6$, so $b = \dfrac{7}{2}$.
  2. Check: $f\left(\dfrac{7}{2}\right) = \dfrac{9/2}{3/2} = 3$ ✓.

$f^{-1}(3) = \dfrac{7}{2}$

Problem 3

Solve $\sqrt{x + 2} = x$.

Uses: Graph of an Irrational Function

Show hint

Squaring can add false solutions. A square root is never negative, so you need $x \ge 0$.

Show solution
  1. Squaring: $x + 2 = x^2$, so $(x - 2)(x + 1) = 0$, $x = 2$ or $-1$.
  2. $x = -1$: $\sqrt{1} = 1 \ne -1$, so it is not a solution.
  3. $x = 2$: $\sqrt{4} = 2$ ✓.

$x = 2$

On a graph: $y = \sqrt{x + 2}$ meets $y = x$ only once. $x = -1$ is where $y = -\sqrt{x + 2}$ meets it.

Problem 4

Find the inverse function of $f(x) = \sqrt{x - 1}$, with its domain.

Uses: How to Find the Inverse Function

Show hint

Solve $y = \sqrt{x - 1}$ for $x$, then swap $x$ and $y$. The range of $f$ becomes the domain of $f^{-1}$.

Show solution
  1. The range of $f$ is $y \ge 0$.
  2. $y^2 = x - 1$, so $x = y^2 + 1$.
  3. Swap $x$ and $y$: $y = x^2 + 1$, for $x \ge 0$.

$f^{-1}(x) = x^2 + 1$ ($x \ge 0$)

Problem 5

Find the constant $a$ so that $f(x) = \dfrac{ax + 1}{x - 3}$ is its own inverse ($f^{-1} = f$) and is not a constant function.

Uses: How to Find the Inverse Function, Inverse Function Properties

Show hint

Find $f^{-1}$ by solving $y = \dfrac{ax + 1}{x - 3}$ for $x$, then compare the two formulas.

Show solution
  1. $y(x - 3) = ax + 1$, so $x(y - a) = 3y + 1$ and $x = \dfrac{3y + 1}{y - a}$.
  2. So $f^{-1}(x) = \dfrac{3x + 1}{x - a}$.
  3. This equals $\dfrac{ax + 1}{x - 3}$ for all $x$ exactly when $a = 3$.
  4. $a = 3$ is not the constant case ($a = -\dfrac{1}{3}$ makes $ax + 1 = a(x - 3)$).

$a = 3$

A function is its own inverse exactly when its graph is symmetric about $y = x$. Here both asymptotes are $x = 3$ and $y = 3$, so their crossing point $(3, 3)$ is on that line.
