The Derivative and Its Rules

Six problems on the definition of the derivative, differentiability, higher derivatives, and the product, quotient and chain rules. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

(1) Use the definition to find $f'(2)$ for $f(x) = \dfrac{1}{x}$. (2) Is $g(x) = |x - 2|$ differentiable at $x = 2$? (Type $f'(2)$ in the box.)

Uses: Definition of the Derivative, Differentiability and Continuity

Show hint

(1) $\dfrac{f(2 + h) - f(2)}{h}$: combine the fractions first. (2) Compare the limits as $h \to +0$ and $h \to -0$.

Show solution
  1. (1) $\dfrac{1}{h}\left(\dfrac{1}{2 + h} - \dfrac{1}{2}\right) = \dfrac{1}{h} \cdot \dfrac{-h}{2(2 + h)} = -\dfrac{1}{2(2 + h)} \to -\dfrac{1}{4}$.
  2. (2) $\dfrac{g(2 + h) - g(2)}{h} = \dfrac{|h|}{h}$, which is $1$ for $h > 0$ and $-1$ for $h < 0$.
  3. The one-sided limits differ, so $g$ is not differentiable at $x = 2$ (though it is continuous there).

(1) $-\dfrac{1}{4}$ (2) No: the left and right limits are $-1$ and $1$

Problem 2

$y = (x^2 - 1)(3x + 2)$. Find $y'$ with the product rule, then $y''$, and the value of $y''$ at $x = 1$. (Type it in the box.)

Uses: Properties of Derivatives, Derivative Notation

Show hint

$(fg)' = f'g + fg'$, then differentiate again.

Show solution
  1. $y' = 2x(3x + 2) + 3(x^2 - 1) = 9x^2 + 4x - 3$.
  2. $y'' = 18x + 4$, so $y''(1) = 22$.

$y' = 9x^2 + 4x - 3$, $y'' = 18x + 4$, $y''(1) = 22$

Problem 3

Differentiate $y = \dfrac{2x - 1}{x^2 + 2}$, and find $y'$ at $x = 1$.

Uses: Quotient Rule

Show hint

$\left(\dfrac{f}{g}\right)' = \dfrac{f'g - fg'}{g^2}$.

Show solution
  1. $y' = \dfrac{2(x^2 + 2) - (2x - 1) \cdot 2x}{(x^2 + 2)^2} = \dfrac{-2x^2 + 2x + 4}{(x^2 + 2)^2}$.
  2. At $x = 1$: $\dfrac{4}{9}$.

$y' = \dfrac{-2x^2 + 2x + 4}{(x^2 + 2)^2}$; $\dfrac{4}{9}$

Problem 4

Differentiate $y = x(2x - 1)^3$ and factorise the result. Find $y'$ at $x = 1$.

Uses: Properties of Derivatives, Chain Rule and Inverse Function Rule

Show hint

Product rule, with the chain rule for $(2x - 1)^3$: its derivative is $3(2x - 1)^2 \cdot 2$.

Show solution
  1. $y' = (2x - 1)^3 + x \cdot 6(2x - 1)^2 = (2x - 1)^2\{(2x - 1) + 6x\} = (2x - 1)^2(8x - 1)$.
  2. At $x = 1$: $1 \cdot 7 = 7$.

$y' = (2x - 1)^2(8x - 1)$; $7$

Problem 5

$f(x) = x^3$ for $x \le 1$ and $f(x) = ax^2 + bx$ for $x > 1$. Find $a$ and $b$ so that $f$ is differentiable at $x = 1$. (Type $a$ in the box.)

Uses: Differentiability and Continuity, Definition of the Derivative

Show hint

Differentiable implies continuous, so first match the values at $x = 1$. Then match the left and right derivatives.

Show solution
  1. Continuity: $1 = a + b$.
  2. Left derivative: $3x^2 \to 3$. Right derivative: $2ax + b \to 2a + b$. So $2a + b = 3$.
  3. Solving: $a = 2$, $b = -1$.

$a = 2$, $b = -1$

Problem 6

$f(x) = \dfrac{x}{(x + 1)^2}$ ($x \ne -1$).

  1. (1) Show that $f'(x) = \dfrac{1 - x}{(x + 1)^3}$.
  2. (2) Find $f''(x)$ and $f''(1)$. (Type $f''(1)$ in the box.)
  3. (3) Find $\displaystyle\lim_{h \to 0} \frac{f(2h) - f(-h)}{h}$.

Uses: Quotient Rule, Chain Rule and Inverse Function Rule, Derivative Notation, Definition of the Derivative

Show hint

In (1), cancel one factor of $x + 1$. In (3), write the fraction as $2 \cdot \dfrac{f(2h) - f(0)}{2h} + \dfrac{f(-h) - f(0)}{-h}$.

Show solution
  1. (1) $f'(x) = \dfrac{(x + 1)^2 - x \cdot 2(x + 1)}{(x + 1)^4} = \dfrac{(x + 1) - 2x}{(x + 1)^3} = \dfrac{1 - x}{(x + 1)^3}$.
  2. (2) $f''(x) = \dfrac{-(x + 1)^3 - (1 - x) \cdot 3(x + 1)^2}{(x + 1)^6} = \dfrac{-(x + 1) - 3(1 - x)}{(x + 1)^4} = \dfrac{2x - 4}{(x + 1)^4}$.
  3. $f''(1) = \dfrac{-2}{16} = -\dfrac{1}{8}$.
  4. (3) The limit is $2f'(0) + f'(0) = 3f'(0) = 3$.

(2) $f''(x) = \dfrac{2x - 4}{(x + 1)^4}$, $f''(1) = -\dfrac{1}{8}$ (3) $3$
