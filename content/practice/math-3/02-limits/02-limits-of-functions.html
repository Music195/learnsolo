Limits of Functions and Continuity

Seven problems on limits of functions, the limit of sin x / x, and the intermediate value theorem. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Find $\displaystyle\lim_{x \to 3} \frac{x^2 - 9}{x^2 - 2x - 3}$.

Uses: Limits of Functions

Show hint

Substituting gives $\dfrac{0}{0}$. Factorise and cancel $x - 3$.

Show solution
  1. $\dfrac{(x - 3)(x + 3)}{(x - 3)(x + 1)} = \dfrac{x + 3}{x + 1} \to \dfrac{6}{4} = \dfrac{3}{2}$.

$\dfrac{3}{2}$

Problem 2

Find $\displaystyle\lim_{x \to 0} \frac{\sin 4x}{3x}$.

Uses: Limit of sin x / x

Show hint

Make the angle and the denominator match: $\dfrac{\sin 4x}{4x}$.

Show solution
  1. $\dfrac{\sin 4x}{3x} = \dfrac{4}{3} \cdot \dfrac{\sin 4x}{4x} \to \dfrac{4}{3} \cdot 1 = \dfrac{4}{3}$.

$\dfrac{4}{3}$

Problem 3

Find $\displaystyle\lim_{x \to \infty} \left(\sqrt{x^2 + 6x} - x\right)$.

Uses: Limits of Functions

Show hint

Multiply and divide by $\sqrt{x^2 + 6x} + x$.

Show solution
  1. $\dfrac{(x^2 + 6x) - x^2}{\sqrt{x^2 + 6x} + x} = \dfrac{6x}{\sqrt{x^2 + 6x} + x} = \dfrac{6}{\sqrt{1 + \frac{6}{x}} + 1} \to 3$.

$3$

Problem 4

Find $\displaystyle\lim_{x \to 0} \frac{x\tan x}{1 - \cos x}$.

Uses: Limit of sin x / x

Show hint

Multiply top and bottom by $1 + \cos x$, so the bottom becomes $\sin^2 x$.

Show solution
  1. $\dfrac{x\tan x(1 + \cos x)}{1 - \cos^2 x} = \dfrac{x\sin x(1 + \cos x)}{\cos x \sin^2 x} = \dfrac{x}{\sin x} \cdot \dfrac{1 + \cos x}{\cos x}$.
  2. $\to 1 \cdot \dfrac{2}{1} = 2$.

$2$

Problem 5

Show that the equation $\log x = 2 - x$ has a solution in $1 < x < 2$.

Uses: Intermediate Value Theorem

Show hint

Put everything on one side: $f(x) = \log x + x - 2$. Is it continuous? What are the signs of $f(1)$ and $f(2)$?

Show solution
  1. $f(x) = \log x + x - 2$ is continuous on $1 \le x \le 2$.
  2. $f(1) = 0 + 1 - 2 = -1 < 0$ and $f(2) = \log 2 > 0$.
  3. By the intermediate value theorem, $f(x) = 0$ for some $1 < x < 2$, i.e. $\log x = 2 - x$ there.

$f(1) < 0 < f(2)$ and $f$ is continuous, so a solution exists.

Problem 6

Find constants $a, b$ with $\displaystyle\lim_{x \to 1} \frac{a\sqrt{x + 3} - b}{x - 1} = \frac{1}{2}$. (Type $b$ in the box.)

Uses: Limits of Functions

Show hint

The denominator $\to 0$ and the limit is finite, so the numerator must also $\to 0$. That gives one condition.

Show solution
  1. Numerator $\to 2a - b$, which must be $0$: $b = 2a$.
  2. $\dfrac{a(\sqrt{x + 3} - 2)}{x - 1} = \dfrac{a(x - 1)}{(x - 1)(\sqrt{x + 3} + 2)} = \dfrac{a}{\sqrt{x + 3} + 2} \to \dfrac{a}{4}$.
  3. $\dfrac{a}{4} = \dfrac{1}{2}$: $a = 2$, $b = 4$.

$a = 2$, $b = 4$

Problem 7

Let $f(x) = x^3 - 3x + 1$.

  1. (1) Show that $f(x) = 0$ has a solution in $0 < x < 1$.
  2. (2) Find $f(-2)$, $f(-1)$, $f(1)$ and $f(2)$, and decide how many real solutions $f(x) = 0$ has. (Type the number in the box.)
  3. (3) Show that $\sin x = \dfrac{x}{2}$ has a solution in $\dfrac{\pi}{2} < x < \pi$.

Uses: Intermediate Value Theorem

Show hint

Each sign change of a continuous function gives a solution. A cubic equation has at most $3$ real solutions.

Show solution
  1. (1) $f$ is continuous, $f(0) = 1 > 0$ and $f(1) = -1 < 0$: a solution lies in $0 < x < 1$.
  2. (2) $f(-2) = -1$, $f(-1) = 3$, $f(1) = -1$, $f(2) = 3$. Signs change on $(-2, -1)$, $(-1, 1)$ and $(1, 2)$, giving $3$ solutions; a cubic has at most $3$, so exactly $3$.
  3. (3) $g(x) = \sin x - \dfrac{x}{2}$ is continuous; $g\left(\dfrac{\pi}{2}\right) = 1 - \dfrac{\pi}{4} > 0$, $g(\pi) = -\dfrac{\pi}{2} < 0$. So a solution exists.

(1) shown (2) $-1, 3, -1, 3$; $3$ real solutions (3) shown
