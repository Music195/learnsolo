Increase, Extrema, Concavity and Inflection

Six problems on increase and decrease, local extrema, concavity, inflection points and the second derivative test. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Find where $f(x) = x - 2\log x$ ($x > 0$) is increasing and decreasing, and its local minimum. (Type the $x$ of the minimum in the box.)

Uses: Increase, Decrease and the Derivative, Local Extrema

Show hint

$f'(x) = 1 - \dfrac{2}{x} = \dfrac{x - 2}{x}$. Remember $x > 0$.

Show solution
  1. $f'(x) = \dfrac{x - 2}{x}$: negative for $0 < x < 2$, positive for $x > 2$.
  2. Decreasing on $0 < x \le 2$, increasing on $x \ge 2$.
  3. Local minimum $f(2) = 2 - 2\log 2$ at $x = 2$.

Local minimum $2 - 2\log 2$ at $x = 2$

Problem 2

Find where $y = x^3 + 3x^2 - 1$ is concave up and concave down, and its inflection point. (Type the $y$-coordinate in the box.)

Uses: Concavity and the Second Derivative, Inflection Points

Show hint

$y'' = 6x + 6$. Where does it change sign?

Show solution
  1. $y'' = 6x + 6$: negative for $x < -1$, positive for $x > -1$.
  2. Concave down for $x < -1$, concave up for $x > -1$.
  3. Inflection point: $x = -1$, $y = -1 + 3 - 1 = 1$, i.e. $(-1, 1)$.

Inflection point $(-1, 1)$

Problem 3

Find the local extrema of $f(x) = (x^2 - 3)e^x$. (Type the local minimum value in the box.)

Uses: Local Extrema

Show hint

$f'(x) = 2xe^x + (x^2 - 3)e^x$. Factor out $e^x > 0$.

Show solution
  1. $f'(x) = (x^2 + 2x - 3)e^x = (x + 3)(x - 1)e^x$.
  2. $f'$: $+$ for $x < -3$, $-$ for $-3 < x < 1$, $+$ for $x > 1$.
  3. Local maximum $f(-3) = 6e^{-3}$; local minimum $f(1) = -2e$.

Local maximum $\dfrac{6}{e^3}$ ($x = -3$), local minimum $-2e$ ($x = 1$)

Problem 4

Use the second derivative test to find the local extrema of $f(x) = x^4 - 8x^2$. (Type the local minimum value in the box.)

Uses: Second Derivative Test

Show hint

Solve $f'(x) = 0$, then look at the sign of $f''$ at each point.

Show solution
  1. $f'(x) = 4x^3 - 16x = 4x(x - 2)(x + 2) = 0$ at $x = 0, \pm 2$.
  2. $f''(x) = 12x^2 - 16$: $f''(0) = -16 < 0$ (local max), $f''(\pm 2) = 32 > 0$ (local min).
  3. Local maximum $f(0) = 0$; local minimum $f(\pm 2) = 16 - 32 = -16$.

Local maximum $0$ ($x = 0$), local minimum $-16$ ($x = \pm 2$)

Problem 5

A cylinder is placed inside a sphere of radius $\sqrt{3}$ so that both circular edges touch the sphere. Find the largest possible volume of the cylinder.

Uses: Second Derivative Test

Show hint

Let the height be $2t$. Then the radius $r$ satisfies $r^2 + t^2 = 3$. Write the volume in terms of $t$.

Show solution
  1. $V = \pi r^2 \cdot 2t = 2\pi(3 - t^2)t = 2\pi(3t - t^3)$ for $0 < t < \sqrt{3}$.
  2. $V' = 2\pi(3 - 3t^2) = 0 \iff t = 1$.
  3. $V'' = -12\pi t < 0$ at $t = 1$: a maximum. $V = 2\pi(3 - 1) = 4\pi$.

$4\pi$ (radius $\sqrt{2}$, height $2$)

Problem 6

$f(x) = \dfrac{x}{x^2 + 3}$.

  1. (1) Find $f'(x)$, the intervals of increase and decrease, and the local extrema. (Type the local maximum value in the box.)
  2. (2) Show that $f''(x) = \dfrac{2x(x^2 - 9)}{(x^2 + 3)^3}$, and find the inflection points.
  3. (3) Find $\displaystyle\lim_{x \to \pm\infty} f(x)$ and sketch the graph.

Uses: Increase, Decrease and the Derivative, Local Extrema, Concavity and the Second Derivative, Inflection Points

Show hint

Quotient rule. In (2), take out a common factor $x^2 + 3$ from the numerator before simplifying.

Show solution
  1. (1) $f'(x) = \dfrac{(x^2 + 3) - 2x^2}{(x^2 + 3)^2} = \dfrac{3 - x^2}{(x^2 + 3)^2}$.
  2. Decreasing for $x \le -\sqrt{3}$ and $x \ge \sqrt{3}$, increasing for $-\sqrt{3} \le x \le \sqrt{3}$.
  3. Local maximum $f(\sqrt{3}) = \dfrac{\sqrt{3}}{6}$, local minimum $f(-\sqrt{3}) = -\dfrac{\sqrt{3}}{6}$.
  4. (2) $f''(x) = \dfrac{-2x(x^2 + 3) - (3 - x^2) \cdot 4x}{(x^2 + 3)^3} = \dfrac{2x^3 - 18x}{(x^2 + 3)^3} = \dfrac{2x(x^2 - 9)}{(x^2 + 3)^3}$.
  5. $f''$ changes sign at $x = -3, 0, 3$: inflection points $\left(-3, -\dfrac{1}{4}\right)$, $(0, 0)$, $\left(3, \dfrac{1}{4}\right)$.
  6. (3) $f(x) = \dfrac{1/x}{1 + 3/x^2} \to 0$: the $x$-axis is an asymptote. The graph is symmetric about the origin.

(1) local max $\dfrac{\sqrt{3}}{6}$, local min $-\dfrac{\sqrt{3}}{6}$ (2) $\left(-3, -\dfrac{1}{4}\right)$, $(0, 0)$, $\left(3, \dfrac{1}{4}\right)$ (3) $0$
