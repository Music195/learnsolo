Using Derivatives

Five problems on normal lines, local maxima, inflection points, motion, and comparing numbers. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Find the normal line to $y = \sqrt{x}$ at the point $(4, 2)$.

Uses: Equation of the Normal Line

Show hint

The normal is perpendicular to the tangent, so its slope is $-\dfrac{1}{f'(4)}$.

Show solution
  1. $y' = \dfrac{1}{2\sqrt{x}}$, so the tangent slope at $x = 4$ is $\dfrac{1}{4}$.
  2. Normal slope $-4$: $y - 2 = -4(x - 4)$.

$y = -4x + 18$

Problem 2

Find the local maximum value of $f(x) = x^2 e^{-x}$.

Uses: Sign of the Derivative and Monotonicity, Necessary Condition for Local Extrema

Show hint

Product rule: $f'(x) = 2xe^{-x} - x^2e^{-x}$. Factor it and make a sign table. $e^{-x}$ is always positive.

Show solution
  1. $f'(x) = (2x - x^2)e^{-x} = x(2 - x)e^{-x}$, zero at $x = 0, 2$.
  2. $f' < 0$ for $x < 0$, $> 0$ for $0 < x < 2$, $< 0$ for $x > 2$.
  3. Local maximum at $x = 2$: $f(2) = 4e^{-2} = \dfrac{4}{e^2}$. (Local minimum $f(0) = 0$.)

Local maximum $\dfrac{4}{e^2}$, at $x = 2$

Problem 3

Find the inflection point of $y = xe^{-x}$.

Uses: Inflection Points of y = f(x), Second Derivative and Concavity

Show hint

Find $y''$ and where it changes sign.

Show solution
  1. $y' = e^{-x} - xe^{-x} = (1 - x)e^{-x}$.
  2. $y'' = -e^{-x} - (1 - x)e^{-x} = (x - 2)e^{-x}$.
  3. $y'' < 0$ for $x < 2$ and $> 0$ for $x > 2$: the curve changes from concave down to concave up at $x = 2$, where $y = 2e^{-2}$.

Inflection point $\left(2, \dfrac{2}{e^2}\right)$

Problem 4

A point moves on a number line with position $x = t^3 - 6t^2 + 9t$ at time $t$. Find its velocity at the moment its acceleration is $0$.

Uses: Velocity and Acceleration (Straight Line)

Show hint

$v = \dfrac{dx}{dt}$ and $a = \dfrac{dv}{dt}$.

Show solution
  1. $v = 3t^2 - 12t + 9$, $a = 6t - 12$.
  2. $a = 0$ at $t = 2$.
  3. $v(2) = 12 - 24 + 9 = -3$.

$v = -3$ (moving in the negative direction)

Problem 5

Find the maximum of $f(x) = \dfrac{\log x}{x}$ ($x > 0$). Use it to decide which is larger, $e^\pi$ or $\pi^e$.

Uses: Sign of the Derivative and Monotonicity

Show hint

Compare $\log$ of both numbers: $\log e^\pi = \pi$ and $\log \pi^e = e\log\pi$. Dividing both by $e\pi$ turns this into comparing $f(e)$ and $f(\pi)$.

Show solution
  1. $f'(x) = \dfrac{1 - \log x}{x^2}$: positive for $x < e$, negative for $x > e$. So the maximum is $f(e) = \dfrac{1}{e}$.
  2. $\pi > e$ and $f$ decreases for $x > e$, so $f(\pi) < f(e)$: $\dfrac{\log\pi}{\pi} < \dfrac{1}{e}$.
  3. Multiply by $e\pi > 0$: $e\log\pi < \pi$, i.e. $\log\pi^e < \log e^\pi$.
  4. $\log$ is increasing, so $\pi^e < e^\pi$.

Maximum $\dfrac{1}{e}$ at $x = e$; $e^\pi > \pi^e$

Numerically $e^\pi \approx 23.14$ and $\pi^e \approx 22.46$: close, but the derivative settles it without a calculator.
