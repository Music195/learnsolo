Distance Travelled and Curve Length

Six problems on position and distance on a line and in the plane, and on the length of parametric curves and of y = f(x). Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

A point P starts at $x = 0$ and moves on a number line with velocity $v = t^2 - 3t + 2$. Find its position at $t = 3$ and the distance it travels from $t = 0$ to $t = 3$. (Type the distance in the box.)

Uses: Distance Travelled on a Line

Show hint

Position: $\displaystyle\int v\,dt$. Distance: $\displaystyle\int |v|\,dt$; $v = (t - 1)(t - 2)$ is negative for $1 < t < 2$.

Show solution
  1. Position: $\displaystyle\int_0^3 v\,dt = 9 - \frac{27}{2} + 6 = \frac{3}{2}$.
  2. $\displaystyle\int_0^1 v\,dt = \frac{5}{6}$, $\displaystyle\int_1^2 v\,dt = -\frac{1}{6}$, $\displaystyle\int_2^3 v\,dt = \frac{5}{6}$.
  3. Distance $= \dfrac{5}{6} + \dfrac{1}{6} + \dfrac{5}{6} = \dfrac{11}{6}$.

Position $\dfrac{3}{2}$; distance $\dfrac{11}{6}$

Problem 2

Find the length of the curve $x = t - \dfrac{t^3}{3}$, $y = t^2$ for $0 \le t \le 1$.

Uses: Length of a Parametric Curve

Show hint

$\left(\dfrac{dx}{dt}\right)^2 + \left(\dfrac{dy}{dt}\right)^2$ turns out to be a perfect square.

Show solution
  1. $\dfrac{dx}{dt} = 1 - t^2$, $\dfrac{dy}{dt} = 2t$: $(1 - t^2)^2 + 4t^2 = (1 + t^2)^2$.
  2. $L = \displaystyle\int_0^1 (1 + t^2)\,dt = \frac{4}{3}$.

$\dfrac{4}{3}$

Problem 3

Find the length of the curve $y = \dfrac{x^2}{8} - \log x$ for $1 \le x \le e$.

Uses: Length of y = f(x)

Show hint

$y' = \dfrac{x}{4} - \dfrac{1}{x}$; then $1 + (y')^2$ is a perfect square.

Show solution
  1. $1 + \left(\dfrac{x}{4} - \dfrac{1}{x}\right)^2 = \dfrac{x^2}{16} + \dfrac{1}{2} + \dfrac{1}{x^2} = \left(\dfrac{x}{4} + \dfrac{1}{x}\right)^2$.
  2. $L = \displaystyle\int_1^e \left(\frac{x}{4} + \frac{1}{x}\right)dx = \frac{e^2 - 1}{8} + 1 = \frac{e^2 + 7}{8}$.

$\dfrac{e^2 + 7}{8}$

Problem 4

A point P moves in the plane with $(x, y) = (3t^2, 2t^3)$. Find the distance it travels from $t = 0$ to $t = 1$.

Uses: Distance Travelled in the Plane

Show hint

Speed $= \sqrt{(6t)^2 + (6t^2)^2} = 6t\sqrt{1 + t^2}$ for $t \ge 0$. Substitute $u = 1 + t^2$.

Show solution
  1. Distance $= \displaystyle\int_0^1 6t\sqrt{1 + t^2}\,dt$.
  2. $u = 1 + t^2$, $du = 2t\,dt$: $\displaystyle\int_1^2 3\sqrt{u}\,du = \Big[2u^{\frac{3}{2}}\Big]_1^2 = 4\sqrt{2} - 2$.

$4\sqrt{2} - 2$

Problem 5

A point P moves on a number line with velocity $v = \cos t - \dfrac{1}{2}$. For $0 \le t \le \pi$, find how far P ends up from its starting point, and the distance it travels. (Type the distance travelled in the box.)

Uses: Distance Travelled on a Line

Show hint

$v \ge 0$ for $0 \le t \le \dfrac{\pi}{3}$ and $v < 0$ after that.

Show solution
  1. Change in position: $\displaystyle\int_0^{\pi} v\,dt = \Big[\sin t - \frac{t}{2}\Big]_0^{\pi} = -\frac{\pi}{2}$, so it ends $\dfrac{\pi}{2}$ to the left.
  2. $\displaystyle\int_0^{\frac{\pi}{3}} v\,dt = \frac{\sqrt{3}}{2} - \frac{\pi}{6}$ and $\displaystyle\int_{\frac{\pi}{3}}^{\pi} v\,dt = -\frac{\pi}{2} - \left(\frac{\sqrt{3}}{2} - \frac{\pi}{6}\right) = -\frac{\sqrt{3}}{2} - \frac{\pi}{3}$.
  3. Distance $= \left(\dfrac{\sqrt{3}}{2} - \dfrac{\pi}{6}\right) + \left(\dfrac{\sqrt{3}}{2} + \dfrac{\pi}{3}\right) = \sqrt{3} + \dfrac{\pi}{6}$.

$\dfrac{\pi}{2}$ to the left; distance $\sqrt{3} + \dfrac{\pi}{6}$

Problem 6

A point P moves in the plane with $(x, y) = \left(t^2, \;t - \dfrac{t^3}{3}\right)$ for $t \ge 0$.

  1. (1) Find the velocity and show that the speed is $1 + t^2$.
  2. (2) Find the length of the path for $0 \le t \le \sqrt{3}$. (Type it in the box.)
  3. (3) Write the path as $y = f(x)$ ($0 \le x \le 3$) and find the same length with $\displaystyle\int \sqrt{1 + (y')^2}\,dx$.

Uses: Distance Travelled in the Plane, Length of a Parametric Curve, Length of y = f(x)

Show hint

In (3), $t = \sqrt{x}$, so $y = \sqrt{x} - \dfrac{x\sqrt{x}}{3}$. Again $1 + (y')^2$ is a perfect square.

Show solution
  1. (1) $\vec{v} = (2t, 1 - t^2)$, speed $= \sqrt{4t^2 + (1 - t^2)^2} = \sqrt{(1 + t^2)^2} = 1 + t^2$.
  2. (2) $L = \displaystyle\int_0^{\sqrt{3}} (1 + t^2)\,dt = \sqrt{3} + \frac{3\sqrt{3}}{3} = 2\sqrt{3}$.
  3. (3) $y = x^{\frac{1}{2}} - \dfrac{1}{3}x^{\frac{3}{2}}$, $y' = \dfrac{1}{2\sqrt{x}} - \dfrac{\sqrt{x}}{2}$, and $1 + (y')^2 = \left(\dfrac{1}{2\sqrt{x}} + \dfrac{\sqrt{x}}{2}\right)^2$.
  4. $\displaystyle\int_0^3 \left(\frac{1}{2\sqrt{x}} + \frac{\sqrt{x}}{2}\right)dx = \sqrt{3} + \frac{1}{3} \cdot 3\sqrt{3} = 2\sqrt{3}$ ✓.

(1) $(2t, 1 - t^2)$, speed $1 + t^2$ (2) $2\sqrt{3}$ (3) $y = \sqrt{x} - \dfrac{x\sqrt{x}}{3}$, length $2\sqrt{3}$
