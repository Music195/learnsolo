Indefinite Integrals

Six problems on indefinite integrals of powers, trigonometric and exponential functions, substitution and integration by parts. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Find $F(x)$ with $F'(x) = \dfrac{(x^2 + 1)^2}{x^2}$ and $F(1) = 0$. (Type $F(2)$ in the box.)

Uses: Indefinite Integral of x^α, Properties of Indefinite Integrals

Show hint

Expand and divide first: $\dfrac{(x^2 + 1)^2}{x^2} = x^2 + 2 + x^{-2}$.

Show solution
  1. $F(x) = \dfrac{x^3}{3} + 2x - \dfrac{1}{x} + C$.
  2. $F(1) = \dfrac{1}{3} + 2 - 1 + C = 0$, so $C = -\dfrac{4}{3}$.
  3. $F(2) = \dfrac{8}{3} + 4 - \dfrac{1}{2} - \dfrac{4}{3} = \dfrac{29}{6}$.

$F(x) = \dfrac{x^3}{3} + 2x - \dfrac{1}{x} - \dfrac{4}{3}$; $F(2) = \dfrac{29}{6}$

Problem 2

Find $F(x)$ with $F'(x) = 2\sin x + \dfrac{3}{\cos^2 x}$ and $F(0) = 1$. (Type $F\left(\dfrac{\pi}{4}\right)$ in the box.)

Uses: Integrals of Trigonometric Functions

Show hint

$\displaystyle\int \sin x\,dx = -\cos x$ and $\displaystyle\int \frac{dx}{\cos^2 x} = \tan x$.

Show solution
  1. $F(x) = -2\cos x + 3\tan x + C$; $F(0) = -2 + C = 1$, so $C = 3$.
  2. $F\left(\dfrac{\pi}{4}\right) = -\sqrt{2} + 3 + 3 = 6 - \sqrt{2}$.

$F(x) = -2\cos x + 3\tan x + 3$; $6 - \sqrt{2}$

Problem 3

Find $F(x)$ with $F'(x) = \dfrac{(e^x - 1)^2}{e^x}$ and $F(0) = 0$. (Type $F(1)$ in the box.)

Uses: Integrals of Exponential Functions, Properties of Indefinite Integrals

Show hint

Expand and divide: $\dfrac{e^{2x} - 2e^x + 1}{e^x} = e^x - 2 + e^{-x}$.

Show solution
  1. $F(x) = e^x - 2x - e^{-x} + C$; $F(0) = 1 - 1 + C = 0$, so $C = 0$.
  2. $F(1) = e - 2 - \dfrac{1}{e}$.

$F(x) = e^x - 2x - e^{-x}$; $F(1) = e - 2 - \dfrac{1}{e}$

Problem 4

Find (1) $\displaystyle\int x^2(x^3 + 1)^4\,dx$ (2) $\displaystyle\int \frac{e^x}{e^x + 1}\,dx$.

Uses: Integration by Substitution, Integrals of Exponential Functions

Show hint

(1) Put $u = x^3 + 1$, so $du = 3x^2\,dx$. (2) The numerator is the derivative of the denominator.

Show solution
  1. (1) $\displaystyle\int u^4 \cdot \frac{du}{3} = \frac{u^5}{15} + C = \frac{(x^3 + 1)^5}{15} + C$.
  2. (2) $\displaystyle\int \frac{(e^x + 1)'}{e^x + 1}\,dx = \log(e^x + 1) + C$ (no absolute value needed: $e^x + 1 > 0$).

(1) $\dfrac{(x^3 + 1)^5}{15} + C$ (2) $\log(e^x + 1) + C$

Problem 5

Find (1) $\displaystyle\int \sqrt{x}\log x\,dx$ (2) $\displaystyle\int e^x\cos x\,dx$.

Uses: Integration by Parts, Indefinite Integral of x^α

Show hint

(1) Integrate $\sqrt{x}$ and differentiate $\log x$. (2) Integrate by parts twice; the original integral comes back, so solve for it.

Show solution
  1. (1) $\displaystyle\int \sqrt{x}\log x\,dx = \frac{2}{3}x^{\frac{3}{2}}\log x - \int \frac{2}{3}x^{\frac{3}{2}} \cdot \frac{1}{x}\,dx = \frac{2}{3}x\sqrt{x}\log x - \frac{4}{9}x\sqrt{x} + C$.
  2. (2) Let $I = \displaystyle\int e^x\cos x\,dx = e^x\cos x + \int e^x\sin x\,dx = e^x\cos x + e^x\sin x - I$.
  3. So $2I = e^x(\sin x + \cos x)$ and $I = \dfrac{e^x(\sin x + \cos x)}{2} + C$.

(1) $\dfrac{2}{3}x\sqrt{x}\log x - \dfrac{4}{9}x\sqrt{x} + C$ (2) $\dfrac{e^x(\sin x + \cos x)}{2} + C$

Problem 6

Indefinite integrals.

  1. (1) Find $\displaystyle\int x\cos x\,dx$.
  2. (2) Find $\displaystyle\int \cos^3 x\,dx$.
  3. (3) Find $F(x)$ with $F'(x) = x\cos x + \cos^3 x$ and $F(0) = 0$, and find $F\left(\dfrac{\pi}{2}\right)$. (Type it in the box.)

Uses: Integration by Parts, Integration by Substitution, Integrals of Trigonometric Functions

Show hint

(2) $\cos^3 x = (1 - \sin^2 x)\cos x$; put $u = \sin x$.

Show solution
  1. (1) $\displaystyle\int x\cos x\,dx = x\sin x - \int \sin x\,dx = x\sin x + \cos x + C$.
  2. (2) $\displaystyle\int (1 - u^2)\,du = u - \frac{u^3}{3} + C = \sin x - \frac{\sin^3 x}{3} + C$.
  3. (3) $F(x) = x\sin x + \cos x + \sin x - \dfrac{\sin^3 x}{3} + C$; $F(0) = 1 + C = 0$, so $C = -1$.
  4. $F\left(\dfrac{\pi}{2}\right) = \dfrac{\pi}{2} + 0 + 1 - \dfrac{1}{3} - 1 = \dfrac{\pi}{2} - \dfrac{1}{3}$.

(1) $x\sin x + \cos x + C$ (2) $\sin x - \dfrac{\sin^3 x}{3} + C$ (3) $\dfrac{\pi}{2} - \dfrac{1}{3}$
