Quadratic Functions and Equations

Topic review: a mix of the whole topic, best tried after the two concept sets. Five problems on vertices, roots, the discriminant and maximum and minimum values. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Find the minimum value of $y = x^2 - 6x + 5$.

Uses: Graph of y = a(x − p)² + q

Show hint

Complete the square: $x^2 - 6x = (x - 3)^2 - 9$.

Show solution
  1. $y = (x - 3)^2 - 9 + 5 = (x - 3)^2 - 4$.
  2. The graph opens upward with vertex $(3, -4)$, so the minimum is $-4$ at $x = 3$.

Minimum $-4$, at $x = 3$

Problem 2

Solve $x^2 - 4x + 1 = 0$, and give the larger solution.

Uses: Quadratic Formula

Show hint

The $x$ coefficient is even, so the short form $x = \dfrac{-b' \pm \sqrt{b'^2 - ac}}{a}$ with $b' = -2$ is quickest.

Show solution
  1. $x = 2 \pm \sqrt{4 - 1} = 2 \pm \sqrt{3}$.

$x = 2 \pm \sqrt{3}$; the larger is $2 + \sqrt{3}$

Problem 3

Find $k$ so that the graph of $y = x^2 - 4x + k$ touches the $x$-axis, and find the point where it touches.

Uses: Discriminant and Real Solutions, Quadratic Graph and the x-axis

Show hint

The graph touches the $x$-axis when $x^2 - 4x + k = 0$ has a double root, that is when the discriminant is $0$.

Show solution
  1. $\dfrac{D}{4} = (-2)^2 - k = 4 - k = 0$, so $k = 4$.
  2. Then $y = x^2 - 4x + 4 = (x - 2)^2$, which touches the axis at $(2, 0)$.

$k = 4$, touching at $(2, 0)$

Problem 4

Find the minimum value of $y = -x^2 + 2x + 3$ for $0 \le x \le 3$.

Uses: Maximum and Minimum of y = a(x − p)² + q

Show hint

Complete the square and sketch the graph on $0 \le x \le 3$. It opens downward, so the minimum is at an end of the range.

Show solution
  1. $y = -(x - 1)^2 + 4$: a downward parabola with vertex $(1, 4)$.
  2. The end further from the axis $x = 1$ gives the minimum: $x = 3$ is $2$ away, $x = 0$ only $1$.
  3. At $x = 3$: $y = -9 + 6 + 3 = 0$.

Minimum $0$, at $x = 3$ (the maximum is $4$, at $x = 1$)

Problem 5

The minimum of $y = x^2 - 2ax + 3$ for $0 \le x \le 2$ is $-1$. Find $a$.

Uses: Maximum and Minimum of y = a(x − p)² + q

Show hint

$y = (x - a)^2 - a^2 + 3$. Where the minimum is depends on whether the axis $x = a$ is left of, inside, or right of $0 \le x \le 2$.

Show solution
  1. $y = (x - a)^2 - a^2 + 3$, axis $x = a$.
  2. $a < 0$: minimum at $x = 0$, $y = 3 \ne -1$. No solution.
  3. $0 \le a \le 2$: minimum at the vertex, $-a^2 + 3 = -1$, so $a^2 = 4$, $a = 2$ (since $a \ge 0$).
  4. $a > 2$: minimum at $x = 2$, $7 - 4a = -1$, so $a = 2$, but this case needs $a > 2$. No solution.

$a = 2$

Always check each answer against its case: $a = -2$ solves $-a^2 + 3 = -1$ too, but it is not in the range $0 \le a \le 2$.
