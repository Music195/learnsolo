Graphs and Vertex Form

Six problems on function values, linear functions, completing the square, moving graphs and maximum and minimum values. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

$f(x) = 2x^2 - 3x + 1$. Find $f(-2)$, and simplify $f(a) - f(-a)$. (Type $f(-2)$ in the box.)

Uses: General Forms of Linear and Quadratic Functions

Show hint

Put brackets around what you substitute: $f(-2) = 2(-2)^2 - 3(-2) + 1$.

Show solution
  1. $f(-2) = 8 + 6 + 1 = 15$.
  2. $f(a) - f(-a) = (2a^2 - 3a + 1) - (2a^2 + 3a + 1) = -6a$.

$f(-2) = 15$; $f(a) - f(-a) = -6a$

Problem 2

The linear function $y = ax + b$ ($a < 0$) takes values $-1 \le y \le 5$ for $-1 \le x \le 2$. Find $a$ and $b$. (Type $a$ in the box.)

Uses: General Forms of Linear and Quadratic Functions

Show hint

With $a < 0$ the line goes down, so the largest $y$ is at the left end $x = -1$.

Show solution
  1. $a < 0$: $x = -1$ gives $y = 5$ and $x = 2$ gives $y = -1$.
  2. $-a + b = 5$ and $2a + b = -1$. Subtract: $3a = -6$, so $a = -2$ and $b = 3$.

$a = -2$, $b = 3$

Problem 3

Find the vertex and the axis of $y = 3x^2 + 12x + 7$. (Type the $y$-coordinate of the vertex in the box.)

Uses: Graph of y = a(x − p)² + q, Graph Shape of y = ax²

Show hint

Take out the $3$ from the $x$ terms first: $3(x^2 + 4x) + 7$.

Show solution
  1. $3(x^2 + 4x) + 7 = 3\{(x + 2)^2 - 4\} + 7 = 3(x + 2)^2 - 5$.
  2. Vertex $(-2, -5)$, axis $x = -2$.

Vertex $(-2, -5)$, axis $x = -2$

Problem 4

The graph of $y = x^2 + bx + c$ is moved $2$ to the right and $3$ up, and becomes $y = x^2 - 6x + 10$. Find $b$ and $c$. (Type $c$ in the box.)

Uses: Graph of y = a(x − p)² + q, Graph Shape of y = ax²

Show hint

Moving a graph does not change its shape, so the $x^2$ coefficient stays $1$. Work backwards with vertices: find the vertex of the new graph, then move it $2$ left and $3$ down.

Show solution
  1. $y = x^2 - 6x + 10 = (x - 3)^2 + 1$: vertex $(3, 1)$.
  2. Before the move the vertex was $(3 - 2, 1 - 3) = (1, -2)$.
  3. $y = (x - 1)^2 - 2 = x^2 - 2x - 1$, so $b = -2$, $c = -1$.

$b = -2$, $c = -1$

Problem 5

For $y = -x^2 + 4x$ on $0 \le x \le a$ (where $a > 0$), the maximum value is $3$. Find $a$.

Uses: Maximum and Minimum Values, Graph Shape of y = ax²

Show hint

$a = -1 < 0$, so the graph opens downward and the vertex is the highest point, at $x = 2$. Split into cases: is the vertex inside $0 \le x \le a$ or not?

Show solution
  1. $y = -(x - 2)^2 + 4$: vertex $(2, 4)$.
  2. If $a \ge 2$, the vertex is inside and the maximum is $4 \ne 3$.
  3. If $0 < a < 2$, $y$ increases on the whole range, so the maximum is at $x = a$: $-a^2 + 4a = 3$.
  4. $a^2 - 4a + 3 = 0 \Rightarrow a = 1$ or $3$; only $a = 1$ fits $a < 2$.

$a = 1$

Problem 6

Real numbers $x, y$ satisfy $x + 2y = 8$, $x \ge 0$, $y \ge 0$.

  1. (1) Express $xy$ in terms of $y$, and find the range of $y$.
  2. (2) Find the maximum value of $xy$ and the values of $x$, $y$ that give it.
  3. (3) Find the minimum value of $x^2 + y^2$. (Type it in the box.)

Uses: Maximum and Minimum Values, Graph of y = a(x − p)² + q

Show hint

Substitute $x = 8 - 2y$. Both $xy$ and $x^2 + y^2$ become quadratics in $y$ on a closed interval.

Show solution
  1. (1) $x = 8 - 2y \ge 0$ gives $0 \le y \le 4$, and $xy = (8 - 2y)y = -2y^2 + 8y$.
  2. (2) $-2y^2 + 8y = -2(y - 2)^2 + 8$: maximum $8$ at $y = 2$, $x = 4$.
  3. (3) $x^2 + y^2 = (8 - 2y)^2 + y^2 = 5y^2 - 32y + 64 = 5\left(y - \dfrac{16}{5}\right)^2 + \dfrac{64}{5}$.
  4. $y = \dfrac{16}{5}$ is inside $0 \le y \le 4$, so the minimum is $\dfrac{64}{5}$ (at $x = \dfrac{8}{5}$).

(1) $xy = -2y^2 + 8y$, $0 \le y \le 4$ (2) $8$ at $x = 4$, $y = 2$ (3) $\dfrac{64}{5}$

$x^2 + y^2$ is the squared distance from the origin to a point of the line $x + 2y = 8$, so its minimum is the squared distance from the origin to that line.
