Real Numbers and Radicals

Six problems on repeating decimals, square roots, calculating with radicals and double radicals. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Write $0.\overline{36}$ as a fraction in lowest terms.

Uses: Repeating Decimals

Show hint

The repeating block has 2 digits, so multiply by $100$ and subtract.

Show solution
  1. $x = 0.3636\ldots$, $\;100x = 36.3636\ldots$
  2. $100x - x = 36$, so $99x = 36$.
  3. $x = \dfrac{36}{99} = \dfrac{4}{11}$.

$\dfrac{4}{11}$

Problem 2

Find the value of $0.\overline{6} + \sqrt{(-4)^2} + (-\sqrt{3})^2 - \sqrt{(1 - \sqrt{2})^2}$.

Uses: Repeating Decimals, Properties of Square Roots

Show hint

Write $0.\overline{6}$ as a fraction first. Then use $\sqrt{a^2} = |a|$: is $1 - \sqrt{2}$ positive or negative?

Show solution
  1. $x = 0.\overline{6}$: $10x - x = 6$, so $x = \dfrac{6}{9} = \dfrac{2}{3}$.
  2. $\sqrt{(-4)^2} = |-4| = 4$ and $(-\sqrt{3})^2 = 3$.
  3. $\sqrt{(1 - \sqrt{2})^2} = |1 - \sqrt{2}| = \sqrt{2} - 1$, because $\sqrt{2} > 1$.
  4. $\dfrac{2}{3} + 4 + 3 - (\sqrt{2} - 1) = \dfrac{26}{3} - \sqrt{2}$.

$\dfrac{26}{3} - \sqrt{2}$

Problem 3

Simplify $\sqrt{45} - \sqrt{20} + \dfrac{3}{\sqrt{5}}$.

Uses: Calculation with Radicals

Show hint

Take out square factors ($45 = 9 \cdot 5$, $20 = 4 \cdot 5$) and rationalise the last term so every term is a multiple of $\sqrt{5}$.

Show solution
  1. $\sqrt{45} = 3\sqrt{5}$, $\;\sqrt{20} = 2\sqrt{5}$, $\;\dfrac{3}{\sqrt{5}} = \dfrac{3\sqrt{5}}{5}$.
  2. $3\sqrt{5} - 2\sqrt{5} + \dfrac{3}{5}\sqrt{5} = \left(1 + \dfrac{3}{5}\right)\sqrt{5}$.
  3. $= \dfrac{8\sqrt{5}}{5}$.

$\dfrac{8\sqrt{5}}{5}$

Problem 4

Rationalise the denominator of $\dfrac{\sqrt{3} + 1}{\sqrt{3} - 1}$.

Uses: Calculation with Radicals, Expansion Formulas

Show hint

Multiply the top and the bottom by $\sqrt{3} + 1$.

Show solution
  1. Denominator: $(\sqrt{3} - 1)(\sqrt{3} + 1) = 3 - 1 = 2$.
  2. Numerator: $(\sqrt{3} + 1)^2 = 3 + 2\sqrt{3} + 1 = 4 + 2\sqrt{3}$.
  3. $\dfrac{4 + 2\sqrt{3}}{2} = 2 + \sqrt{3}$.

$2 + \sqrt{3}$

Problem 5

Simplify $\sqrt{6 + \sqrt{32}}$.

Uses: Double Radicals

Show hint

First write the inner root as $2\sqrt{\;\;}$: $\sqrt{32} = 2\sqrt{8}$. Then find two numbers with sum $6$ and product $8$.

Show solution
  1. $\sqrt{32} = \sqrt{4 \cdot 8} = 2\sqrt{8}$, so the expression is $\sqrt{6 + 2\sqrt{8}}$.
  2. Sum $6$, product $8$: the numbers are $4$ and $2$.
  3. $\sqrt{6 + 2\sqrt{8}} = \sqrt{4} + \sqrt{2} = 2 + \sqrt{2}$.
  4. Check: $(2 + \sqrt{2})^2 = 4 + 4\sqrt{2} + 2 = 6 + \sqrt{32}$ ✓.

$2 + \sqrt{2}$

Problem 6

Let $x = \dfrac{1}{2 - \sqrt{3}}$.

  1. (1) Rationalise the denominator of $x$.
  2. (2) Let $a$ be the integer part of $x$ and $b = x - a$ its decimal part. Find $a$, and write $b$ using $\sqrt{3}$.
  3. (3) Find the value of $b^2 + 2b$. (Type it in the box.)
  4. (4) Simplify $\sqrt{x}$ by removing the double radical.

Uses: Calculation with Radicals, Properties of Square Roots, Double Radicals

Show hint

$1 < \sqrt{3} < 2$ tells you between which integers $x$ lies. For (3), $b^2 + 2b = (b + 1)^2 - 1$. For (4), $2 + \sqrt{3} = \dfrac{4 + 2\sqrt{3}}{2}$ makes a $2\sqrt{\;\;}$ appear.

Show solution
  1. (1) $x = \dfrac{2 + \sqrt{3}}{(2 - \sqrt{3})(2 + \sqrt{3})} = \dfrac{2 + \sqrt{3}}{4 - 3} = 2 + \sqrt{3}$.
  2. (2) $1 < \sqrt{3} < 2$ gives $3 < x < 4$, so $a = 3$.
  3. $b = (2 + \sqrt{3}) - 3 = \sqrt{3} - 1$.
  4. (3) $b^2 + 2b = (b + 1)^2 - 1 = (\sqrt{3})^2 - 1 = 2$.
  5. (4) $\sqrt{2 + \sqrt{3}} = \dfrac{\sqrt{4 + 2\sqrt{3}}}{\sqrt{2}} = \dfrac{\sqrt{3} + 1}{\sqrt{2}} = \dfrac{\sqrt{6} + \sqrt{2}}{2}$.

(1) $2 + \sqrt{3}$ (2) $a = 3$, $b = \sqrt{3} - 1$ (3) $2$ (4) $\dfrac{\sqrt{6} + \sqrt{2}}{2}$

Completing the square, $(b + 1)^2 - 1$, avoids expanding $(\sqrt{3} - 1)^2$ at all.
