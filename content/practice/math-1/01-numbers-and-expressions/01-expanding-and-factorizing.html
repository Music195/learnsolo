Expanding and Factorizing

Six problems on exponent laws, expanding brackets and factorising, from one rule at a time up to an exam-style question. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Simplify $(-3a^2b)^2 \times 2ab^3$, then find its value when $a = 1$ and $b = -1$.

Uses: Exponent Rules

Show hint

Square every factor in the first bracket, including the $-3$. Then add the exponents of $a$ and of $b$.

Show solution
  1. $(-3a^2b)^2 = (-3)^2(a^2)^2b^2 = 9a^4b^2$.
  2. $9a^4b^2 \times 2ab^3 = 18\,a^{4+1}\,b^{2+3} = 18a^5b^5$.
  3. $a = 1$, $b = -1$: $18 \cdot 1 \cdot (-1)^5 = -18$.

$18a^5b^5$; value $-18$

Problem 2

Expand and simplify $(2x - 3)^2 - (x + 2)(x - 2)$. Then find its value when $x = 2$.

Uses: Distributive Law, Expansion Formulas

Show hint

Use $(a - b)^2 = a^2 - 2ab + b^2$ and $(a + b)(a - b) = a^2 - b^2$. Watch the minus sign in front of the second product.

Show solution
  1. $(2x - 3)^2 = 4x^2 - 12x + 9$.
  2. $(x + 2)(x - 2) = x^2 - 4$, and the minus in front changes both signs: $-x^2 + 4$.
  3. Total: $3x^2 - 12x + 13$. At $x = 2$: $12 - 24 + 13 = 1$.

$3x^2 - 12x + 13$; value $1$

Problem 3

Expand $(x + 1)(x + 2)(x + 3)(x + 4)$ and give the coefficient of $x^2$.

Uses: Distributive Law, Expansion Formulas

Show hint

Pair the brackets so both products start with $x^2 + 5x$: $(x + 1)(x + 4)$ and $(x + 2)(x + 3)$. Then let $t = x^2 + 5x$.

Show solution
  1. $(x + 1)(x + 4) = x^2 + 5x + 4$ and $(x + 2)(x + 3) = x^2 + 5x + 6$.
  2. With $t = x^2 + 5x$: $(t + 4)(t + 6) = t^2 + 10t + 24$.
  3. $t^2 = x^4 + 10x^3 + 25x^2$ and $10t = 10x^2 + 50x$.
  4. So the product is $x^4 + 10x^3 + 35x^2 + 50x + 24$.

$x^4 + 10x^3 + 35x^2 + 50x + 24$; coefficient $35$

Choosing the pairs so a common block appears is a standard trick: it turns a four-bracket product into one two-bracket product.

Problem 4

Factorise completely.

  1. (1) $6x^2 - x - 12$
  2. (2) $x^4 - 13x^2 + 36$

Uses: Factorization Formula

Show hint

(1) Cross method: try $6 = 2 \times 3$. (2) Treat $x^2$ as one letter first, then check whether each factor can be split again.

Show solution
  1. (1) $2 \times 3$ and $-3 \times 4$: cross sum $2 \cdot 4 + 3 \cdot (-3) = -1$ ✓, so $(2x - 3)(3x + 4)$.
  2. (2) With $X = x^2$: $X^2 - 13X + 36 = (X - 4)(X - 9) = (x^2 - 4)(x^2 - 9)$.
  3. Both are differences of squares: $(x + 2)(x - 2)(x + 3)(x - 3)$.

(1) $(2x - 3)(3x + 4)$ (2) $(x + 2)(x - 2)(x + 3)(x - 3)$

Problem 5

Factorise $x^2 + 3xy + 2y^2 - x - 2$. Then use your answer to find its value when $x = 3$, $y = -1$. (Type the value in the box.)

Uses: Factorization Formula

Show hint

Arrange in powers of $x$: $x^2 + (3y - 1)x + (2y^2 - 2)$. The constant term $2y^2 - 2 = 2(y + 1)(y - 1)$ must split into two parts whose sum is $3y - 1$.

Show solution
  1. $x^2 + (3y - 1)x + 2(y + 1)(y - 1)$.
  2. Try $(y + 1)$ and $2(y - 1) = 2y - 2$: their sum is $3y - 1$ ✓.
  3. So the expression is $(x + y + 1)(x + 2y - 2)$.
  4. At $x = 3$, $y = -1$: $(3 - 1 + 1)(3 - 2 - 2) = 3 \times (-1) = -3$.

$(x + y + 1)(x + 2y - 2)$; value $-3$

Problem 6

Real numbers $a$ and $b$ satisfy $a + b = 3$ and $ab = 1$.

  1. (1) Find $a^2 + b^2$.
  2. (2) Find $a^3 + b^3$ in two ways: from $(a + b)^3$, and from $a^3 + b^3 = (a + b)(a^2 - ab + b^2)$.
  3. (3) Find $(a - b)^2$ and $a^4 + b^4$. (Type $a^4 + b^4$ in the box.)

Uses: Expansion Formulas, Factorization Formula, Exponent Rules

Show hint

Everything can be written with $a + b$ and $ab$: $a^2 + b^2 = (a + b)^2 - 2ab$, and $a^4 + b^4 = (a^2 + b^2)^2 - 2(ab)^2$.

Show solution
  1. (1) $a^2 + b^2 = 3^2 - 2 \cdot 1 = 7$.
  2. (2) $(a + b)^3 = a^3 + b^3 + 3ab(a + b)$, so $a^3 + b^3 = 27 - 9 = 18$.
  3. Check: $(a + b)(a^2 - ab + b^2) = 3(7 - 1) = 18$ ✓.
  4. (3) $(a - b)^2 = (a + b)^2 - 4ab = 9 - 4 = 5$.
  5. $(a^2 + b^2)^2 = a^4 + 2a^2b^2 + b^4$ and $a^2b^2 = (ab)^2 = 1$, so $a^4 + b^4 = 49 - 2 = 47$.

(1) $7$ (2) $18$ (3) $(a - b)^2 = 5$, $a^4 + b^4 = 47$
