Absolute Value and Inequalities

Six problems on absolute value, linear inequalities, systems of inequalities and absolute value equations. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Find the value of $|3 - \pi| + |\pi - 4|$.

Uses: Absolute Value

Show hint

$\pi \approx 3.14$. Decide the sign inside each pair of bars before removing them.

Show solution
  1. $3 - \pi < 0$, so $|3 - \pi| = \pi - 3$.
  2. $\pi - 4 < 0$, so $|\pi - 4| = 4 - \pi$.
  3. $(\pi - 3) + (4 - \pi) = 1$.

$1$

Read as distances: $\pi$ lies between $3$ and $4$, so its distances to $3$ and to $4$ add up to $1$.

Problem 2

Solve $\dfrac{2x - 1}{3} - \dfrac{x - 2}{2} < 1$, and give the largest integer $x$ that satisfies it.

Uses: Properties of Inequalities

Show hint

Multiply both sides by $6$ (positive, so the sign stays).

Show solution
  1. $\times 6$: $2(2x - 1) - 3(x - 2) < 6$.
  2. $4x - 2 - 3x + 6 < 6$, so $x + 4 < 6$ and $x < 2$.
  3. The largest integer below $2$ is $1$.

$x < 2$; largest integer $1$

Problem 3

Solve the system $\begin{cases} 5 - 2x \le 3x + 20 \\ 3x - 5 < x + 7 \end{cases}$ and find how many integers satisfy it.

Uses: Properties of Inequalities

Show hint

Solve each inequality on its own, then take the overlap on a number line. Be careful whether each end is included.

Show solution
  1. First: $-15 \le 5x$, so $x \ge -3$.
  2. Second: $2x < 12$, so $x < 6$.
  3. Overlap: $-3 \le x < 6$. Integers $-3, -2, \ldots, 5$: that is $9$ of them.

$-3 \le x < 6$; $9$ integers

Problem 4

Solve $|2x + 3| \le 7$, and find the sum of all integers $x$ that satisfy it.

Uses: Absolute Value Equations and Inequalities

Show hint

$|X| \le c$ means $-c \le X \le c$.

Show solution
  1. $-7 \le 2x + 3 \le 7$.
  2. $-10 \le 2x \le 4$, so $-5 \le x \le 2$.
  3. Integers $-5, -4, \ldots, 2$: the sum is $-5 - 4 - 3 + 0 = -12$ (the pairs $\pm 1$, $\pm 2$ cancel).

$-5 \le x \le 2$; sum $-12$

Problem 5

Solve $|x + 2| = 3x - 4$.

Uses: Absolute Value Equations and Inequalities, Absolute Value

Show hint

$x$ is on both sides, so split at $x = -2$, where the inside is $0$, and check each answer against its case.

Show solution
  1. Case $x \ge -2$: $x + 2 = 3x - 4$, so $x = 3$. It fits $x \ge -2$ ✓.
  2. Case $x < -2$: $-(x + 2) = 3x - 4$, so $x = \dfrac{1}{2}$. It does not fit $x < -2$ ✗.
  3. Only $x = 3$. Check: $|5| = 5 = 9 - 4$ ✓.

$x = 3$

Problem 6

Let $a$ be a constant. Consider the system $\begin{cases} |x - 3| < 2 \\ x \ge a \end{cases}$.

  1. (1) Solve $|x - 3| < 2$.
  2. (2) When $a = 0$, list the integers that satisfy the system.
  3. (3) Find the range of $a$ for which the system has exactly two integer solutions. (Type the largest possible $a$ in the box.)

Uses: Absolute Value Equations and Inequalities, Properties of Inequalities

Show hint

$|x - 3| < 2$: points closer than $2$ to $3$. For (3), the two integer solutions must be the two largest ones; move $a$ along the number line and see when the next integer drops out.

Show solution
  1. (1) $-2 < x - 3 < 2$, so $1 < x < 5$.
  2. (2) $a = 0$: $1 < x < 5$ and $x \ge 0$ give $1 < x < 5$; integers $2, 3, 4$.
  3. (3) Exactly two integers means exactly $3$ and $4$: $3$ must be included and $2$ must not.
  4. $3 \ge a$ and $2 < a$, so $2 < a \le 3$. The largest $a$ is $3$ (then $x \ge 3$ still includes $3$).

(1) $1 < x < 5$ (2) $2, 3, 4$ (3) $2 < a \le 3$; largest $a = 3$
