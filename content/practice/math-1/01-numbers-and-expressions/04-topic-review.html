Radicals and Absolute Values

Five problems on square roots, rationalising, double radicals and absolute values. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Simplify $\sqrt{12} + \sqrt{27} - \sqrt{48}$.

Uses: Properties of Square Root, Calculation with Radicals

Show hint

Take square factors out of each root, e.g. $\sqrt{12} = \sqrt{4 \cdot 3} = 2\sqrt{3}$, then collect like terms.

Show solution
  1. $\sqrt{12} = 2\sqrt{3}$, $\sqrt{27} = 3\sqrt{3}$, $\sqrt{48} = 4\sqrt{3}$.
  2. $2\sqrt{3} + 3\sqrt{3} - 4\sqrt{3} = \sqrt{3}$.

$\sqrt{3}$

Problem 2

Rationalise the denominator of $\dfrac{1}{\sqrt{3} - \sqrt{2}}$.

Uses: Calculation with Radicals, Expansion Formula

Show hint

Multiply the top and bottom by $\sqrt{3} + \sqrt{2}$ and use $(a - b)(a + b) = a^2 - b^2$.

Show solution
  1. $\dfrac{\sqrt{3} + \sqrt{2}}{(\sqrt{3} - \sqrt{2})(\sqrt{3} + \sqrt{2})} = \dfrac{\sqrt{3} + \sqrt{2}}{3 - 2}$.
  2. The denominator is $1$.

$\sqrt{3} + \sqrt{2}$

Problem 3

$x = \dfrac{1}{\sqrt{5} - 2}$ and $y = \dfrac{1}{\sqrt{5} + 2}$. Find $x^2 + y^2$.

Uses: Calculation with Radicals, Expansion Formula

Show hint

Rationalise $x$ and $y$ first, then use $x^2 + y^2 = (x + y)^2 - 2xy$ instead of squaring each one.

Show solution
  1. $x = \sqrt{5} + 2$ and $y = \sqrt{5} - 2$ (the denominators are $5 - 4 = 1$).
  2. $x + y = 2\sqrt{5}$ and $xy = 5 - 4 = 1$.
  3. $x^2 + y^2 = (2\sqrt{5})^2 - 2 \cdot 1 = 20 - 2 = 18$.

$x^2 + y^2 = 18$

Problem 4

Simplify $\sqrt{7 - 2\sqrt{10}}$.

Uses: Double Radicals Expansion

Show hint

Look for two numbers with sum $7$ and product $10$. Then $\sqrt{(a + b) - 2\sqrt{ab}} = \sqrt{a} - \sqrt{b}$ with $a > b$.

Show solution
  1. $5 + 2 = 7$ and $5 \cdot 2 = 10$, so $7 - 2\sqrt{10} = (\sqrt{5} - \sqrt{2})^2$.
  2. $\sqrt{5} - \sqrt{2} > 0$, so the square root is $\sqrt{5} - \sqrt{2}$ (not $\sqrt{2} - \sqrt{5}$).

$\sqrt{5} - \sqrt{2}$

Problem 5

Solve $|x - 2| + |x + 1| = 5$.

Uses: Equations and Inequalities with Absolute Value, Absolute Value

Show hint

The signs inside change at $x = -1$ and $x = 2$. Split into three cases and keep only solutions inside each case's range.

Show solution
  1. $x \ge 2$: $(x - 2) + (x + 1) = 5$, so $2x - 1 = 5$, $x = 3$. In range ✓.
  2. $-1 \le x < 2$: $-(x - 2) + (x + 1) = 3 \ne 5$. No solution.
  3. $x < -1$: $-(x - 2) - (x + 1) = 5$, so $-2x + 1 = 5$, $x = -2$. In range ✓.

$x = -2,\ 3$

$|x - 2| + |x + 1|$ is the total distance from $x$ to $2$ and to $-1$ on the number line. Between them it is always $3$; it reaches $5$ one unit outside each end.
