Sets and Set Operations

Six problems on elements, subsets, intersection, union, complement and De Morgan's laws. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Write $A = \{\,x \mid x \text{ is a positive divisor of } 18\,\}$ by listing its elements, and find how many elements it has.

Uses: Sets and Elements

Show hint

Find the divisors in pairs whose product is $18$.

Show solution
  1. $18 = 1 \times 18 = 2 \times 9 = 3 \times 6$.
  2. $A = \{1, 2, 3, 6, 9, 18\}$: $6$ elements.

$\{1, 2, 3, 6, 9, 18\}$; $6$ elements

Problem 2

Let $A = \{a, b, c, d\}$. How many subsets does $A$ have, and how many of them contain $a$? (Type the second number in the box.)

Uses: Subsets and the Empty Set

Show hint

For each element, a subset either contains it or not. Remember that $\varnothing$ and $A$ itself are subsets too.

Show solution
  1. Each of the $4$ elements is in or out: $2^4 = 16$ subsets (including $\varnothing$ and $A$).
  2. Containing $a$: $a$ is fixed as in, and $b, c, d$ are free: $2^3 = 8$.

$16$ subsets; $8$ contain $a$

Problem 3

$U = \{1, 2, 3, \ldots, 12\}$. $A$ is the set of multiples of $2$ in $U$ and $B$ the set of multiples of $3$ in $U$. Find $A \cap \overline{B}$ and the number of its elements.

Uses: Intersection and Union, Complement of a Set

Show hint

$A \cap \overline{B}$: in $A$ and not in $B$, that is, even but not a multiple of $3$.

Show solution
  1. $A = \{2, 4, 6, 8, 10, 12\}$, $B = \{3, 6, 9, 12\}$.
  2. Remove the elements of $B$ from $A$: $A \cap \overline{B} = \{2, 4, 8, 10\}$, $4$ elements.

$\{2, 4, 8, 10\}$; $4$ elements

Problem 4

$U = \{1, 2, \ldots, 10\}$, $A = \{1, 2, 3, 4, 5\}$, $B = \{4, 5, 6, 7\}$. Find $\overline{A \cup B}$ and check that it equals $\overline{A} \cap \overline{B}$. How many elements does it have?

Uses: De Morgan's Laws, Complement of a Set

Show hint

Work out both sides separately and compare.

Show solution
  1. $A \cup B = \{1, 2, \ldots, 7\}$, so $\overline{A \cup B} = \{8, 9, 10\}$.
  2. $\overline{A} = \{6, 7, 8, 9, 10\}$, $\overline{B} = \{1, 2, 3, 8, 9, 10\}$, so $\overline{A} \cap \overline{B} = \{8, 9, 10\}$ ✓.
  3. $3$ elements.

$\{8, 9, 10\}$; $3$ elements

Problem 5

In a class of $50$ students, $30$ study French, $24$ study Spanish and $8$ study neither. How many study both?

Uses: Intersection and Union, De Morgan's Laws

Show hint

'Neither' is $\overline{F} \cap \overline{S} = \overline{F \cup S}$. Then use $n(F \cup S) = n(F) + n(S) - n(F \cap S)$.

Show solution
  1. $n(\overline{F \cup S}) = 8$, so $n(F \cup S) = 50 - 8 = 42$.
  2. $42 = 30 + 24 - n(F \cap S)$, so $n(F \cap S) = 12$.

$12$ students

Problem 6

For real numbers, let $A = \{\,x \mid -1 < x \le 4\,\}$ and $B = \{\,x \mid a \le x \le a + 3\,\}$, where $a$ is a constant.

  1. (1) When $a = 2$, find $A \cap B$ and $A \cup B$.
  2. (2) Find the range of $a$ for which $B \subset A$. (Type the largest possible $a$ in the box.)
  3. (3) Find the range of $a$ for which $A \cap B = \varnothing$.

Uses: Sets and Elements, Subsets and the Empty Set, Intersection and Union

Show hint

Draw both intervals on one number line. Watch which ends are included: $A$ does not contain $-1$.

Show solution
  1. (1) $B = \{2 \le x \le 5\}$: $A \cap B = \{2 \le x \le 4\}$, $A \cup B = \{-1 < x \le 5\}$.
  2. (2) $B \subset A$ needs $-1 < a$ and $a + 3 \le 4$: $-1 < a \le 1$. The largest $a$ is $1$.
  3. (3) $B$ entirely left of $A$: $a + 3 \le -1$, so $a \le -4$ ($x = -1$ is not in $A$, so touching it is allowed).
  4. $B$ entirely right of $A$: $a > 4$. So $a \le -4$ or $a > 4$.

(1) $2 \le x \le 4$; $-1 < x \le 5$ (2) $-1 < a \le 1$ (3) $a \le -4$ or $a > 4$
