Conditions and Proof

Six problems on necessary and sufficient conditions, negation, converse and contrapositive, and proof by contrapositive. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

For real $x$, is $p$ a sufficient condition, a necessary condition, both, or neither for $q$?

  1. (1) $p$: $x > 2$, $\quad q$: $x > 0$
  2. (2) $p$: $x^2 = x$, $\quad q$: $x = 1$
  3. (3) $p$: $|x| < 1$, $\quad q$: $-1 < x < 1$

Uses: Necessary and Sufficient Conditions

Show hint

Check $p \Rightarrow q$ and $q \Rightarrow p$ separately. One counterexample is enough to show an arrow is false.

Show solution
  1. (1) $x > 2 \Rightarrow x > 0$ is true; $x > 0 \Rightarrow x > 2$ is false ($x = 1$). Sufficient.
  2. (2) $x^2 = x \iff x = 0$ or $1$. $p \Rightarrow q$ is false ($x = 0$); $q \Rightarrow p$ is true. Necessary.
  3. (3) $|x| < 1$ means exactly $-1 < x < 1$, so both arrows hold. Necessary and sufficient.

(1) sufficient (2) necessary (3) necessary and sufficient

Problem 2

Write the negation of each statement ($x$, $y$ real).

  1. (1) $x \ge 2$ or $y < 0$
  2. (2) $1 \le x < 4$
  3. (3) There is a real number $x$ with $x^2 < 0$.

Uses: Negation of And and Or

Show hint

'or' becomes 'and', and each part is negated ($\ge$ becomes $<$). '$1 \le x < 4$' means '$1 \le x$ and $x < 4$'. 'There is' becomes 'for all'.

Show solution
  1. (1) $x < 2$ and $y \ge 0$.
  2. (2) $1 \le x$ and $x < 4$ → negation: $x < 1$ or $x \ge 4$.
  3. (3) For every real $x$, $x^2 \ge 0$ (and this negation is the true one).

(1) $x < 2$ and $y \ge 0$ (2) $x < 1$ or $x \ge 4$ (3) for all real $x$, $x^2 \ge 0$

Problem 3

For real $x, y$, consider the statement “$x + y = 3 \Rightarrow x = 1$ and $y = 2$”. Write its converse, inverse and contrapositive. How many of the four statements (including the original) are true?

Uses: Converse, Inverse and Contrapositive, Negation of And and Or

Show hint

A statement and its contrapositive are always both true or both false; the same holds for the converse and the inverse.

Show solution
  1. Original: false ($x = 0$, $y = 3$). So the contrapositive “$x \ne 1$ or $y \ne 2 \Rightarrow x + y \ne 3$” is false too.
  2. Converse: “$x = 1$ and $y = 2 \Rightarrow x + y = 3$”: true.
  3. Inverse: “$x + y \ne 3 \Rightarrow x \ne 1$ or $y \ne 2$”: the contrapositive of the converse, so true.
  4. $2$ of the four are true.

Converse and inverse true, original and contrapositive false: $2$

Problem 4

For real $x$, let $p$: $|x - 1| < 2$ and $q$: $x < a$. Find the range of $a$ for which $p$ is a sufficient condition for $q$, and give the smallest possible $a$.

Uses: Necessary and Sufficient Conditions, Absolute Value Inequalities

Show hint

$p$ is sufficient for $q$ when the set of $p$ lies inside the set of $q$.

Show solution
  1. $p$: $-2 < x - 1 < 2$, so $-1 < x < 3$.
  2. Need $\{-1 < x < 3\} \subset \{x < a\}$: every $x$ below $3$ (but above $-1$) must be below $a$, so $a \ge 3$.
  3. Smallest $a = 3$ ($x < 3$ already contains all of $-1 < x < 3$).

$a \ge 3$; smallest $a = 3$

Problem 5

For integers $m$ and $n$, prove: if $mn$ is even, then $m$ is even or $n$ is even.

Uses: Proof by Contrapositive, Converse, Inverse and Contrapositive, Negation of And and Or

Show hint

Use the contrapositive. The negation of “$m$ even or $n$ even” is “$m$ odd and $n$ odd”.

Show solution
  1. Contrapositive: if $m$ and $n$ are both odd, then $mn$ is odd.
  2. Write $m = 2k + 1$, $n = 2l + 1$ ($k, l$ integers).
  3. $mn = 4kl + 2k + 2l + 1 = 2(2kl + k + l) + 1$, which is odd.
  4. The contrapositive is true, so the original statement is true.

Proved by contrapositive: $m$, $n$ odd $\Rightarrow mn$ odd.

Problem 6

For real $x$, let $p$: $|x - 2| < 1$ and $q$: $|x - a| < 2$, where $a$ is a constant.

  1. (1) Write the sets of $x$ satisfying $p$ and $q$ as intervals.
  2. (2) Find the range of $a$ for which $p$ is a sufficient condition for $q$, and how many integers $a$ satisfy it. (Type the number of integers in the box.)
  3. (3) Explain why $p$ can never be a necessary condition for $q$.
  4. (4) Prove by contrapositive: if $x^2 - 4x + 3 \ge 0$, then $|x - 2| \ge 1$.

Uses: Necessary and Sufficient Conditions, Absolute Value Inequalities, Subsets and the Empty Set, Proof by Contrapositive, Converse, Inverse and Contrapositive

Show hint

Sufficient means the interval of $p$ fits inside the interval of $q$. Compare the lengths of the two intervals for (3).

Show solution
  1. (1) $p$: $1 < x < 3$. $\;q$: $a - 2 < x < a + 2$.
  2. (2) Need $a - 2 \le 1$ and $3 \le a + 2$: $1 \le a \le 3$. Integers $1, 2, 3$: $3$ of them.
  3. (3) Necessary would mean $q \Rightarrow p$, i.e. the interval of $q$ (length $4$) inside the interval of $p$ (length $2$), which is impossible.
  4. (4) Contrapositive: if $|x - 2| < 1$, then $x^2 - 4x + 3 < 0$. Indeed $|x - 2| < 1$ gives $1 < x < 3$, so $x - 1 > 0$ and $x - 3 < 0$, and $x^2 - 4x + 3 = (x - 1)(x - 3) < 0$. The contrapositive is true, so the statement is true.

(1) $1 < x < 3$; $a - 2 < x < a + 2$ (2) $1 \le a \le 3$; $3$ integers (3) $q$'s interval is longer than $p$'s (4) proved via $|x - 2| < 1 \Rightarrow (x - 1)(x - 3) < 0$
