Summarising Data

Topic review: a mix of the whole topic, best tried after the two concept sets. Five problems on describing data: mean, median, quartiles, standard deviation and correlation. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Find the mean of the data $5, 7, 8, 10, 15$.

Uses: Average (Mean) of Data

Show hint

Add all the values, then divide by how many there are.

Show solution
  1. Sum: $5 + 7 + 8 + 10 + 15 = 45$.
  2. There are $5$ values, so the mean is $\dfrac{45}{5} = 9$.

Mean $= 9$

Problem 2

Find the median of the data $3, 9, 4, 12, 7, 11$.

Uses: Median

Show hint

Sort the data first. With an even number of values, the median is the mean of the middle two.

Show solution
  1. Sorted: $3, 4, 7, 9, 11, 12$.
  2. There are $6$ values, so the middle two are the 3rd and 4th: $7$ and $9$.
  3. Median $= \dfrac{7 + 9}{2} = 8$.

Median $= 8$

Problem 3

Find the interquartile range of the data $2, 4, 5, 7, 8, 10, 11, 13, 15, 16$.

Uses: Quartiles, Quartile Range & Deviation

Show hint

Split the sorted data into a lower half and an upper half. $Q_1$ is the median of the lower half, $Q_3$ of the upper half.

Show solution
  1. There are $10$ values, so the lower half is $2, 4, 5, 7, 8$ and the upper half is $10, 11, 13, 15, 16$.
  2. $Q_1 = 5$ (middle of the lower half) and $Q_3 = 13$ (middle of the upper half).
  3. Interquartile range $= Q_3 - Q_1 = 13 - 5 = 8$.

Interquartile range $= 8$

Problem 4

Find the standard deviation of the data $2, 4, 6, 8, 10$.

Uses: Variance & Standard Deviation

Show hint

Find the mean, then the mean of the squared deviations (the variance). The standard deviation is its square root.

Show solution
  1. Mean $= \dfrac{30}{5} = 6$.
  2. Deviations: $-4, -2, 0, 2, 4$; squares: $16, 4, 0, 4, 16$.
  3. Variance $= \dfrac{40}{5} = 8$, so the standard deviation is $\sqrt{8} = 2\sqrt{2}$.

Standard deviation $= 2\sqrt{2}$

Check with the other formula: (mean of squares) − (mean)$^2 = \dfrac{4 + 16 + 36 + 64 + 100}{5} - 6^2 = 44 - 36 = 8$ ✓.

Problem 5

Five students scored $x = 1, 2, 3, 4, 5$ on test X and $y = 2, 4, 5, 4, 5$ on test Y (in the same order). Find the correlation coefficient $r$ of $x$ and $y$.

Uses: Positive & Negative Correlation, Variance & Standard Deviation

Show hint

$r = \dfrac{\sum (x - \bar{x})(y - \bar{y})}{\sqrt{\sum (x - \bar{x})^2}\sqrt{\sum (y - \bar{y})^2}}$. A table of deviations helps.

Show solution
  1. $\bar{x} = 3$, $\bar{y} = \dfrac{20}{5} = 4$.
  2. Deviations: $x - \bar{x} = -2, -1, 0, 1, 2$ and $y - \bar{y} = -2, 0, 1, 0, 1$.
  3. $\sum (x - \bar{x})(y - \bar{y}) = 4 + 0 + 0 + 0 + 2 = 6$, $\sum (x - \bar{x})^2 = 10$, $\sum (y - \bar{y})^2 = 6$.
  4. $r = \dfrac{6}{\sqrt{10}\sqrt{6}} = \dfrac{6}{2\sqrt{15}} = \dfrac{3}{\sqrt{15}} = \dfrac{\sqrt{15}}{5} \approx 0.77$.

$r = \dfrac{\sqrt{15}}{5} \approx 0.77$, a fairly strong positive correlation

The $\dfrac{1}{n}$ in the covariance and in both standard deviations cancels, so you can work with the plain sums.
