Arithmetic and Geometric Sequences

Seven problems on the general terms and sums of arithmetic and geometric sequences. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

An arithmetic sequence has $a_4 = 11$ and $a_9 = 31$. Find the general term $a_n$ and $a_{30}$. (Type $a_{30}$ in the box.)

Uses: General Term of an Arithmetic Sequence

Show hint

$a_9 - a_4 = 5d$.

Show solution
  1. $5d = 31 - 11 = 20$, so $d = 4$, and $a = a_4 - 3d = -1$.
  2. $a_n = -1 + 4(n - 1) = 4n - 5$, so $a_{30} = 115$.

$a_n = 4n - 5$; $a_{30} = 115$

Problem 2

A geometric sequence has $a_2 = 6$ and $a_5 = 162$. Find the first term, the common ratio and $a_7$. (Type $a_7$ in the box.)

Uses: General Term of a Geometric Sequence

Show hint

$\dfrac{a_5}{a_2} = r^3$.

Show solution
  1. $r^3 = \dfrac{162}{6} = 27$, so $r = 3$ and $a = \dfrac{6}{3} = 2$.
  2. $a_7 = 2 \cdot 3^6 = 1458$.

$a = 2$, $r = 3$, $a_7 = 1458$

Problem 3

Find the sum of all multiples of $7$ between $100$ and $300$.

Uses: Sum of an Arithmetic Sequence, General Term of an Arithmetic Sequence

Show hint

They form an arithmetic sequence. Find the first and last terms, then count the terms with $l = a + (n - 1)d$.

Show solution
  1. First: $105 = 7 \cdot 15$. Last: $294 = 7 \cdot 42$.
  2. $294 = 105 + 7(n - 1)$ gives $n = 28$.
  3. $S = \dfrac{28}{2}(105 + 294) = 14 \cdot 399 = 5586$.

$5586$

Problem 4

For the geometric sequence $3, 6, 12, 24, \ldots$, find the smallest $n$ for which $S_n > 1000$.

Uses: Sum of a Geometric Sequence

Show hint

$S_n = \dfrac{3(2^n - 1)}{2 - 1}$.

Show solution
  1. $3(2^n - 1) > 1000 \iff 2^n > 334.3\ldots$
  2. $2^8 = 256$, $2^9 = 512$: so $n = 9$ ($S_8 = 765$, $S_9 = 1533$).

$n = 9$

Problem 5

$4, x, y$ form an arithmetic sequence, and $x, y, 18$ form a geometric sequence. Find $x$ and $y$ when both are positive. (Type $x + y$ in the box.)

Uses: General Term of an Arithmetic Sequence, General Term of a Geometric Sequence

Show hint

Arithmetic: $2x = 4 + y$. Geometric: $y^2 = 18x$.

Show solution
  1. $x = \dfrac{4 + y}{2}$, so $y^2 = 9(4 + y)$, i.e. $y^2 - 9y - 36 = 0$, $(y - 12)(y + 3) = 0$.
  2. $y = 12$ gives $x = 8$: $4, 8, 12$ and $8, 12, 18$ ✓. ($y = -3$, $x = \tfrac{1}{2}$ is the other, non-positive solution.)
  3. $x + y = 20$.

$x = 8$, $y = 12$

Problem 6

An arithmetic sequence has first term $50$ and common difference $-3$. Find the value of $n$ that makes $S_n$ largest, and that largest value.

Uses: Sum of an Arithmetic Sequence, General Term of an Arithmetic Sequence

Show hint

$S_n$ grows as long as the terms added are positive.

Show solution
  1. $a_n = 50 - 3(n - 1) = 53 - 3n > 0 \iff n \le 17$. ($a_{17} = 2$, $a_{18} = -1$.)
  2. So $S_n$ is largest at $n = 17$: $S_{17} = \dfrac{17}{2}(50 + 2) = 442$.

$n = 17$, $S_{17} = 442$

Problem 7

$\{a_n\}$ is an arithmetic sequence and $\{b_n\}$ a geometric sequence with positive common ratio. $a_1 = b_1 = 2$, $a_3 = b_3$ and $a_2 + b_2 = 9$.

  1. (1) Find the common difference $d$ and the common ratio $r$.
  2. (2) Find $a_1 + a_2 + \cdots + a_{10}$.
  3. (3) Find $b_1 + b_2 + \cdots + b_{10}$.
  4. (4) Find the smallest $n$ for which $b_1 + \cdots + b_n$ exceeds $a_1 + \cdots + a_n$ by more than $1000$. (Type it in the box.)

Uses: General Term of an Arithmetic Sequence, General Term of a Geometric Sequence, Sum of an Arithmetic Sequence, Sum of a Geometric Sequence

Show hint

Write $a_3 = 2 + 2d$ and $b_3 = 2r^2$, and use $a_2 + b_2 = 9$ to eliminate $d$.

Show solution
  1. (1) $(2 + d) + 2r = 9$ gives $d = 7 - 2r$. Then $2 + 2(7 - 2r) = 2r^2$, i.e. $r^2 + 2r - 8 = 0$, so $r = 2$ ($r > 0$), $d = 3$.
  2. (2) $a_n = 3n - 1$: $\dfrac{10}{2}(2 + 29) = 155$.
  3. (3) $\dfrac{2(2^{10} - 1)}{2 - 1} = 2046$.
  4. (4) $\sum a = \dfrac{n(3n + 1)}{2}$, $\sum b = 2^{n + 1} - 2$. $n = 9$: $1022 - 126 = 896$. $n = 10$: $2046 - 155 = 1891 > 1000$. So $n = 10$.

(1) $d = 3$, $r = 2$ (2) $155$ (3) $2046$ (4) $10$
