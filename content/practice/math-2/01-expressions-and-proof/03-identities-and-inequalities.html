Identities and Inequalities

Seven problems on polynomial identities, proving identities, squares, comparing by squaring and the AM-GM inequality. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Find $a, b, c$ so that $2x^2 - 5x + 4 = a(x + 1)^2 + b(x + 1) + c$ is an identity. (Type $c$ in the box.)

Uses: Polynomial Identities

Show hint

Put $t = x + 1$, so $x = t - 1$, and rewrite the left side in $t$. Or expand the right side and compare coefficients.

Show solution
  1. $x = t - 1$: $2(t - 1)^2 - 5(t - 1) + 4 = 2t^2 - 4t + 2 - 5t + 5 + 4 = 2t^2 - 9t + 11$.
  2. So $a = 2$, $b = -9$, $c = 11$.
  3. Check at $x = 0$: left $4$, right $2 - 9 + 11 = 4$ ✓.

$a = 2$, $b = -9$, $c = 11$

Problem 2

$\dfrac{x}{3} = \dfrac{y}{4} = \dfrac{z}{5} \ne 0$. Find $\dfrac{x^2 + y^2}{xz}$.

Uses: Proving Identities

Show hint

Set the common value to $k$: $x = 3k$, $y = 4k$, $z = 5k$.

Show solution
  1. $\dfrac{9k^2 + 16k^2}{3k \cdot 5k} = \dfrac{25k^2}{15k^2} = \dfrac{5}{3}$.

$\dfrac{5}{3}$

Problem 3

Find constants $a$ and $b$ so that $\dfrac{x + 5}{(x - 1)(x + 2)} = \dfrac{a}{x - 1} + \dfrac{b}{x + 2}$ for all $x \ne 1, -2$. (Type $a$ in the box.)

Uses: Polynomial Identities

Show hint

Multiply both sides by $(x - 1)(x + 2)$: $x + 5 = a(x + 2) + b(x - 1)$ must be an identity.

Show solution
  1. $x + 5 = (a + b)x + (2a - b)$ for all $x$: $a + b = 1$ and $2a - b = 5$.
  2. Adding: $3a = 6$, so $a = 2$ and $b = -1$.
  3. Check: $\dfrac{2}{x - 1} - \dfrac{1}{x + 2} = \dfrac{2(x + 2) - (x - 1)}{(x - 1)(x + 2)} = \dfrac{x + 5}{(x - 1)(x + 2)}$ ✓.

$a = 2$, $b = -1$

Problem 4

Which is larger, $\sqrt{7} + \sqrt{3}$ or $\sqrt{6} + 2$?

Uses: Square Inequalities

Show hint

Both numbers are positive, so compare their squares.

Show solution
  1. $(\sqrt{7} + \sqrt{3})^2 = 10 + 2\sqrt{21} = 10 + \sqrt{84}$.
  2. $(\sqrt{6} + 2)^2 = 10 + 4\sqrt{6} = 10 + \sqrt{96}$.
  3. $\sqrt{96} > \sqrt{84}$, and both numbers are positive, so $\sqrt{6} + 2 > \sqrt{7} + \sqrt{3}$.

$\sqrt{6} + 2$ is larger

Problem 5

$a + b + c = 0$. Show that $a^2 + b^2 + c^2 = -2(ab + bc + ca)$, and deduce that $ab + bc + ca \le 0$. When is it equal to $0$?

Uses: Proving Identities, Properties of Squares

Show hint

Square $a + b + c = 0$. Then use that a sum of squares is never negative.

Show solution
  1. $0 = (a + b + c)^2 = a^2 + b^2 + c^2 + 2(ab + bc + ca)$, so $a^2 + b^2 + c^2 = -2(ab + bc + ca)$.
  2. $a^2 + b^2 + c^2 \ge 0$, so $-2(ab + bc + ca) \ge 0$, i.e. $ab + bc + ca \le 0$.
  3. Equality needs $a^2 + b^2 + c^2 = 0$, i.e. $a = b = c = 0$.

Shown; $ab + bc + ca = 0$ only when $a = b = c = 0$.

Problem 6

$x > 2$. Find the minimum value of $x + \dfrac{9}{x - 2}$ and the value of $x$ that gives it.

Uses: AM-GM Inequality

Show hint

Write $x = (x - 2) + 2$, so that the two terms $x - 2$ and $\dfrac{9}{x - 2}$ have a constant product.

Show solution
  1. $x + \dfrac{9}{x - 2} = (x - 2) + \dfrac{9}{x - 2} + 2$.
  2. $x - 2 > 0$, so by AM-GM: $(x - 2) + \dfrac{9}{x - 2} \ge 2\sqrt{9} = 6$.
  3. Equality when $x - 2 = \dfrac{9}{x - 2}$, i.e. $x - 2 = 3$, $x = 5$.
  4. Minimum $6 + 2 = 8$ at $x = 5$.

Minimum $8$ at $x = 5$

Problem 7

$a$ and $b$ are positive real numbers.

  1. (1) Show that $a + b - 2\sqrt{ab} = (\sqrt{a} - \sqrt{b})^2$, and deduce $a + b \ge 2\sqrt{ab}$.
  2. (2) Prove $\sqrt{a} + \sqrt{b} \le \sqrt{2(a + b)}$.
  3. (3) If $a + b = 8$, find the maximum value of $\sqrt{a} + \sqrt{b}$ and when it occurs. (Type the maximum in the box.)

Uses: Properties of Squares, Square Inequalities, AM-GM Inequality

Show hint

For (2), both sides are positive, so it is enough to compare squares; then use (1).

Show solution
  1. (1) $(\sqrt{a} - \sqrt{b})^2 = a - 2\sqrt{ab} + b \ge 0$, so $a + b \ge 2\sqrt{ab}$ (equal when $a = b$).
  2. (2) $\{\sqrt{2(a + b)}\}^2 - (\sqrt{a} + \sqrt{b})^2 = 2a + 2b - (a + b + 2\sqrt{ab}) = a + b - 2\sqrt{ab} \ge 0$ by (1).
  3. Both sides are positive, so $\sqrt{a} + \sqrt{b} \le \sqrt{2(a + b)}$.
  4. (3) $\sqrt{a} + \sqrt{b} \le \sqrt{16} = 4$, with equality when $a = b = 4$.

(1), (2) shown (3) maximum $4$ at $a = b = 4$
