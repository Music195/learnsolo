Polynomial Division and Fractional Expressions

Six problems on polynomial division and on multiplying, dividing, adding and subtracting fractional expressions. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Divide $x^3 - 4x^2 + 2x + 5$ by $x - 3$. Find the quotient and the remainder. (Type the remainder in the box.)

Uses: Polynomial Division

Show hint

Long division: $x^3 \div x = x^2$, then multiply back and subtract, and repeat.

Show solution
  1. $x^2(x - 3) = x^3 - 3x^2$; subtract: $-x^2 + 2x + 5$.
  2. $-x(x - 3) = -x^2 + 3x$; subtract: $-x + 5$.
  3. $-1(x - 3) = -x + 3$; subtract: $2$.
  4. Quotient $x^2 - x - 1$, remainder $2$.

Quotient $x^2 - x - 1$, remainder $2$

Problem 2

Simplify $\dfrac{x^2 - x - 6}{x^2 - 4} \times \dfrac{x + 2}{x - 3}$, then find its value at $x = 6$.

Uses: Multiplying and Dividing Fractions

Show hint

Factorise every numerator and denominator first, then cancel common factors.

Show solution
  1. $\dfrac{(x - 3)(x + 2)}{(x - 2)(x + 2)} \times \dfrac{x + 2}{x - 3} = \dfrac{x + 2}{x - 2}$.
  2. At $x = 6$: $\dfrac{8}{4} = 2$.

$\dfrac{x + 2}{x - 2}$; value $2$

Problem 3

Calculate $\dfrac{1}{x - 1} - \dfrac{2}{x^2 - 1}$, then find its value at $x = 3$.

Uses: Adding and Subtracting Fractions

Show hint

$x^2 - 1 = (x - 1)(x + 1)$ is the common denominator.

Show solution
  1. $\dfrac{x + 1}{(x - 1)(x + 1)} - \dfrac{2}{(x - 1)(x + 1)} = \dfrac{x - 1}{(x - 1)(x + 1)} = \dfrac{1}{x + 1}$.
  2. At $x = 3$: $\dfrac{1}{4}$.

$\dfrac{1}{x + 1}$; value $\dfrac{1}{4}$

Problem 4

$2x^4 - x^3 + ax + b$ is divisible by $x^2 + x - 1$. Find the constants $a$ and $b$. (Type $a$ in the box.)

Uses: Polynomial Division

Show hint

Do the division with $a$ and $b$ left as letters. Divisible means the remainder is $0$ for every $x$.

Show solution
  1. $2x^2(x^2 + x - 1) = 2x^4 + 2x^3 - 2x^2$; subtract: $-3x^3 + 2x^2 + ax + b$.
  2. $-3x(x^2 + x - 1) = -3x^3 - 3x^2 + 3x$; subtract: $5x^2 + (a - 3)x + b$.
  3. $5(x^2 + x - 1) = 5x^2 + 5x - 5$; subtract: remainder $(a - 8)x + (b + 5)$.
  4. Remainder $0$: $a = 8$, $b = -5$.

$a = 8$, $b = -5$

Problem 5

Simplify $\dfrac{1}{x(x + 2)} + \dfrac{1}{(x + 2)(x + 4)} + \dfrac{1}{(x + 4)(x + 6)}$, then find its value at $x = 1$.

Uses: Adding and Subtracting Fractions

Show hint

Split each fraction: $\dfrac{1}{k(k + 2)} = \dfrac{1}{2}\left(\dfrac{1}{k} - \dfrac{1}{k + 2}\right)$. Most terms then cancel.

Show solution
  1. Sum $= \dfrac{1}{2}\left(\dfrac{1}{x} - \dfrac{1}{x + 2} + \dfrac{1}{x + 2} - \dfrac{1}{x + 4} + \dfrac{1}{x + 4} - \dfrac{1}{x + 6}\right)$.
  2. $= \dfrac{1}{2}\left(\dfrac{1}{x} - \dfrac{1}{x + 6}\right) = \dfrac{1}{2} \cdot \dfrac{6}{x(x + 6)} = \dfrac{3}{x(x + 6)}$.
  3. At $x = 1$: $\dfrac{3}{7}$.

$\dfrac{3}{x(x + 6)}$; value $\dfrac{3}{7}$

Problem 6

Let $A = x^3 + 2x^2 - x - 2$ and $B = x^2 + 3x + 2$.

  1. (1) Divide $A$ by $x + 2$, and factorise $A$ completely.
  2. (2) Simplify $\dfrac{A}{B}$.
  3. (3) Simplify $\dfrac{A}{B} - \dfrac{2}{x + 1}$, and find its value at $x = 3$. (Type the value in the box.)

Uses: Polynomial Division, Multiplying and Dividing Fractions, Adding and Subtracting Fractions

Show hint

For (1) the remainder should be $0$. For (3), write $\dfrac{A}{B}$ over the denominator $x + 1$.

Show solution
  1. (1) $A = (x + 2)(x^2 - 1) = (x + 2)(x - 1)(x + 1)$ (remainder $0$).
  2. (2) $B = (x + 1)(x + 2)$, so $\dfrac{A}{B} = x - 1$.
  3. (3) $x - 1 - \dfrac{2}{x + 1} = \dfrac{(x - 1)(x + 1) - 2}{x + 1} = \dfrac{x^2 - 3}{x + 1}$.
  4. At $x = 3$: $\dfrac{6}{4} = \dfrac{3}{2}$.

(1) $(x + 2)(x - 1)(x + 1)$ (2) $x - 1$ (3) $\dfrac{x^2 - 3}{x + 1}$; $\dfrac{3}{2}$
