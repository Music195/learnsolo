Expansion, Division and Inequalities

Five problems on the binomial theorem, cubes, polynomial division and the AM–GM inequality. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Find the coefficient of $x^3$ in the expansion of $(2x + 1)^5$.

Uses: Binomial Theorem

Show hint

The general term is ${}_5\mathrm{C}_r (2x)^r 1^{5-r}$. Which $r$ gives $x^3$?

Show solution
  1. $r = 3$: ${}_5\mathrm{C}_3 (2x)^3 = 10 \cdot 8x^3$.
  2. Coefficient $= 80$.

$80$

Problem 2

$x + y = 3$ and $xy = 1$. Find $x^3 + y^3$.

Uses: Cube Expansion, Cube Factorization

Show hint

$(x + y)^3 = x^3 + y^3 + 3xy(x + y)$.

Show solution
  1. $x^3 + y^3 = (x + y)^3 - 3xy(x + y) = 27 - 9 = 18$.

$x^3 + y^3 = 18$

Problem 3

Divide $x^3 + 2x^2 - 5x + 1$ by $x - 2$. Find the quotient and the remainder.

Uses: Polynomial Division

Show hint

Do long division. You can check the remainder with the remainder theorem: it equals the value at $x = 2$.

Show solution
  1. $x^3 \div x = x^2$; subtract $x^2(x - 2) = x^3 - 2x^2$, leaving $4x^2 - 5x + 1$.
  2. $4x^2 \div x = 4x$; subtract $4x^2 - 8x$, leaving $3x + 1$.
  3. $3x \div x = 3$; subtract $3x - 6$, leaving $7$.
  4. Check: $2^3 + 2 \cdot 2^2 - 5 \cdot 2 + 1 = 7$ ✓.

Quotient $x^2 + 4x + 3$, remainder $7$

Problem 4

Find the coefficient of $a^2bc$ in the expansion of $(a + b + c)^4$.

Uses: Trinomial Theorem

Show hint

The coefficient of $a^p b^q c^r$ in $(a + b + c)^n$ is $\dfrac{n!}{p!\,q!\,r!}$.

Show solution
  1. $p = 2$, $q = 1$, $r = 1$, $n = 4$.
  2. $\dfrac{4!}{2!\,1!\,1!} = \dfrac{24}{2} = 12$.

$12$

Problem 5

$x > 0$ and $y > 0$. Find the minimum value of $\left(x + \dfrac{1}{y}\right)\left(y + \dfrac{4}{x}\right)$.

Uses: AM–GM Inequality

Show hint

Expand first, then use AM–GM on the two terms that multiply to a constant.

Show solution
  1. Expanding: $xy + 4 + 1 + \dfrac{4}{xy} = xy + \dfrac{4}{xy} + 5$.
  2. AM–GM: $xy + \dfrac{4}{xy} \ge 2\sqrt{xy \cdot \dfrac{4}{xy}} = 4$.
  3. Equality when $xy = \dfrac{4}{xy}$, i.e. $xy = 2$ (e.g. $x = 1$, $y = 2$), so the minimum $4 + 5 = 9$ is reached.

Minimum $9$ (when $xy = 2$)

Using AM–GM on each bracket separately gives $\ge 2\sqrt{x/y} \cdot 2\sqrt{4y/x} = 8$, but both equalities can't hold at once, so $8$ is never reached. Always check equality.
