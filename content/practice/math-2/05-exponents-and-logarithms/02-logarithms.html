Logarithms and Logarithmic Functions

Seven problems on the definition and properties of logarithms, change of base, the number of digits, and logarithmic graphs, equations and inequalities. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Calculate $\log_2 32 + \log_3 \dfrac{1}{9} + \log_8 4$.

Uses: Definition of the Logarithm

Show hint

$\log_a M = p$ means $a^p = M$. For $\log_8 4$, write $8 = 2^3$ and $4 = 2^2$.

Show solution
  1. $\log_2 32 = 5$ since $2^5 = 32$.
  2. $\log_3 \dfrac{1}{9} = -2$ since $3^{-2} = \dfrac{1}{9}$.
  3. $8^p = 4 \iff 2^{3p} = 2^2 \iff p = \dfrac{2}{3}$.
  4. Total: $5 - 2 + \dfrac{2}{3} = \dfrac{11}{3}$.

$\dfrac{11}{3}$

Problem 2

Calculate $\log_3 18 + \log_3 6 - 2\log_3 2$.

Uses: Logarithm Properties

Show hint

Combine into one logarithm: $2\log_3 2 = \log_3 4$.

Show solution
  1. $\log_3 \dfrac{18 \cdot 6}{4} = \log_3 27 = 3$.

$3$

Problem 3

Calculate $\log_3 5 \cdot \log_5 9 + \log_4 32$.

Uses: Change of Base, Definition of the Logarithm

Show hint

Change everything to one base: $\log_a b = \dfrac{\log_c b}{\log_c a}$.

Show solution
  1. $\log_3 5 \cdot \dfrac{\log_3 9}{\log_3 5} = \log_3 9 = 2$.
  2. $\log_4 32 = \dfrac{\log_2 32}{\log_2 4} = \dfrac{5}{2}$.
  3. Total: $2 + \dfrac{5}{2} = \dfrac{9}{2}$.

$\dfrac{9}{2}$

Problem 4

How many digits does $3^{40}$ have? Use $\log_{10} 3 = 0.4771$.

Uses: Change of Base, Logarithm Properties

Show hint

$N$ has $k$ digits $\iff k - 1 \le \log_{10} N < k$.

Show solution
  1. $\log_{10} 3^{40} = 40 \times 0.4771 = 19.084$.
  2. $19 \le 19.084 < 20$, so $10^{19} \le 3^{40} < 10^{20}$: $20$ digits.

$20$ digits

Problem 5

Put $\log_3 5$, $\;\log_9 20$ and $\dfrac{3}{2}$ in increasing order.

Uses: Change of Base, Logarithm Function Graph

Show hint

Write all three as $\log_3(\text{something})$. Since $y = \log_3 x$ is increasing, compare the somethings.

Show solution
  1. $\log_9 20 = \dfrac{\log_3 20}{\log_3 9} = \dfrac{1}{2}\log_3 20 = \log_3 \sqrt{20}$.
  2. $\dfrac{3}{2} = \log_3 3^{\frac{3}{2}} = \log_3 \sqrt{27}$, and $\log_3 5 = \log_3 \sqrt{25}$.
  3. $\sqrt{20} < \sqrt{25} < \sqrt{27}$ and the base $3 > 1$, so $\log_9 20 < \log_3 5 < \dfrac{3}{2}$.

$\log_9 20 < \log_3 5 < \dfrac{3}{2}$

Problem 6

Solve $\log_{\frac{1}{2}}(x - 1) \ge \log_{\frac{1}{2}}(3 - x)$. (Type the largest $x$ in the box.)

Uses: Logarithm Function Properties

Show hint

First the domain: both $x - 1$ and $3 - x$ must be positive. Then remember that a base between $0$ and $1$ reverses the inequality.

Show solution
  1. Domain: $x - 1 > 0$ and $3 - x > 0$, so $1 < x < 3$.
  2. The base $\dfrac{1}{2} < 1$, so the inequality reverses: $x - 1 \le 3 - x$, $x \le 2$.
  3. With the domain: $1 < x \le 2$.

$1 < x \le 2$

Problem 7

$f(x) = \log_2(x + 3) - 1$.

  1. (1) Give the domain and the asymptote of $y = f(x)$, and the point where it crosses the $x$-axis.
  2. (2) Solve $f(x) \le 2$.
  3. (3) The graph of $y = g(x)$ is the mirror image of $y = f(x)$ in the line $y = x$. Find $g(x)$ and $g(2)$. (Type $g(2)$ in the box.)

Uses: Logarithm Function Graph, Logarithm Function Properties, Definition of the Logarithm

Show hint

$y = \log_2 x$ moved $3$ left and $1$ down. In (2), keep the domain. In (3), swap $x$ and $y$, then solve for $y$.

Show solution
  1. (1) Domain $x > -3$, asymptote $x = -3$. $\log_2(x + 3) = 1 \iff x + 3 = 2$: crosses at $(-1, 0)$.
  2. (2) $\log_2(x + 3) \le 3 = \log_2 8$, base $2 > 1$: $0 < x + 3 \le 8$, so $-3 < x \le 5$.
  3. (3) $x = \log_2(y + 3) - 1 \iff y + 3 = 2^{x + 1}$, so $g(x) = 2^{x + 1} - 3$ and $g(2) = 8 - 3 = 5$.
  4. Check: $f(5) = \log_2 8 - 1 = 2$, so $(5, 2)$ is on $y = f(x)$ and $(2, 5)$ is on $y = g(x)$ ✓.

(1) $x > -3$; $x = -3$; $(-1, 0)$ (2) $-3 < x \le 5$ (3) $g(x) = 2^{x + 1} - 3$, $g(2) = 5$
