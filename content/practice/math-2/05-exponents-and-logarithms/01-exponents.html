Exponents and Exponential Functions

Six problems on exponent laws, n-th roots, the graph of an exponential function, and exponential equations and inequalities. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Calculate $16^{\frac{3}{4}} \times 9^{-\frac{1}{2}}$.

Uses: Exponent Laws, n-th Roots

Show hint

$a^{\frac{m}{n}} = \left(\sqrt[n]{a}\right)^m$ and $a^{-r} = \dfrac{1}{a^r}$.

Show solution
  1. $16^{\frac{3}{4}} = \left(\sqrt[4]{16}\right)^3 = 2^3 = 8$.
  2. $9^{-\frac{1}{2}} = \dfrac{1}{\sqrt{9}} = \dfrac{1}{3}$.
  3. Product: $\dfrac{8}{3}$.

$\dfrac{8}{3}$

Problem 2

Calculate $\sqrt[4]{48} \div \sqrt[4]{3} + \sqrt[3]{-54} \div \sqrt[3]{2}$.

Uses: n-th Roots

Show hint

$\dfrac{\sqrt[n]{a}}{\sqrt[n]{b}} = \sqrt[n]{\dfrac{a}{b}}$. Odd roots of negative numbers are fine: $\sqrt[3]{-8} = -2$.

Show solution
  1. $\sqrt[4]{48} \div \sqrt[4]{3} = \sqrt[4]{16} = 2$.
  2. $\sqrt[3]{-54} \div \sqrt[3]{2} = \sqrt[3]{-27} = -3$.
  3. Total: $2 - 3 = -1$.

$-1$

Problem 3

Solve (1) $9^x = 27^{x - 1}$ (2) $\left(\dfrac{1}{4}\right)^x < 8$. (Type the answer to (1) in the box.)

Uses: Exponential Function Properties

Show hint

Write both sides as powers of the same base. In (2), $\dfrac{1}{4} = 2^{-2}$; base $2 > 1$ keeps the direction of the inequality.

Show solution
  1. (1) $3^{2x} = 3^{3x - 3}$, so $2x = 3x - 3$, $x = 3$.
  2. (2) $2^{-2x} < 2^3$, and the base $2 > 1$, so $-2x < 3$, $x > -\dfrac{3}{2}$.

(1) $x = 3$ (2) $x > -\dfrac{3}{2}$

Problem 4

Describe how the graph of $y = 3^{x + 2} - 1$ is obtained from $y = 3^x$. Give its asymptote and its $y$-intercept. (Type the $y$-intercept in the box.)

Uses: Exponential Function Graph

Show hint

$y - q = 3^{x - p}$ is $y = 3^x$ moved $p$ to the right and $q$ up.

Show solution
  1. Move $y = 3^x$ by $2$ to the left and $1$ down.
  2. The asymptote $y = 0$ moves to $y = -1$.
  3. $x = 0$: $y = 3^2 - 1 = 8$.

$2$ left, $1$ down; asymptote $y = -1$; $y$-intercept $8$

Problem 5

$a > 0$ and $a^{\frac{1}{2}} - a^{-\frac{1}{2}} = 2$. Find $a + a^{-1}$ and $a^{\frac{3}{2}} - a^{-\frac{3}{2}}$. (Type the second value in the box.)

Uses: Exponent Laws

Show hint

Square the given equation; for the cubes use $x^3 - y^3 = (x - y)(x^2 + xy + y^2)$ with $x = a^{\frac{1}{2}}$, $y = a^{-\frac{1}{2}}$, $xy = 1$.

Show solution
  1. $\left(a^{\frac{1}{2}} - a^{-\frac{1}{2}}\right)^2 = a - 2 + a^{-1} = 4$, so $a + a^{-1} = 6$.
  2. $a^{\frac{3}{2}} - a^{-\frac{3}{2}} = \left(a^{\frac{1}{2}} - a^{-\frac{1}{2}}\right)\left(a + 1 + a^{-1}\right) = 2 \cdot 7 = 14$.

$a + a^{-1} = 6$, $a^{\frac{3}{2}} - a^{-\frac{3}{2}} = 14$

Problem 6

$f(x) = 4^x - 2^{x + 2} + 5$ for $-1 \le x \le 2$.

  1. (1) Let $t = 2^x$. Find the range of $t$.
  2. (2) Write $f(x)$ in terms of $t$.
  3. (3) Find the largest and smallest values of $f(x)$ and the values of $x$ that give them. (Type the largest value in the box.)

Uses: Exponential Function Graph, Exponential Function Properties, Exponent Laws

Show hint

$y = 2^x$ is increasing, so $t$ runs from $2^{-1}$ to $2^2$. $4^x = (2^x)^2$ and $2^{x + 2} = 4 \cdot 2^x$.

Show solution
  1. (1) $2^x$ is increasing: $\dfrac{1}{2} \le t \le 4$.
  2. (2) $f = t^2 - 4t + 5 = (t - 2)^2 + 1$.
  3. (3) Smallest: $1$ at $t = 2$, i.e. $x = 1$.
  4. Largest: at the end farther from $t = 2$, which is $t = 4$: $f = 4 + 1 = 5$, at $x = 2$. (At $t = \dfrac{1}{2}$, $f = \dfrac{13}{4}$.)

(1) $\dfrac{1}{2} \le t \le 4$ (2) $(t - 2)^2 + 1$ (3) largest $5$ at $x = 2$; smallest $1$ at $x = 1$
