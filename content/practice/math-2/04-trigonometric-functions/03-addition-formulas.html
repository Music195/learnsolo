Addition Formulas and Their Uses

Six problems on the addition formulas, double-angle formulas, combining sine and cosine, and product-to-sum formulas. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Find $\cos 105^\circ$. Then find $\cos 105^\circ \cos 15^\circ$ with a product-to-sum formula, and check it with your value of $\cos 105^\circ$. (Type $\cos 105^\circ$ in the box.)

Uses: Addition Formulas, Product-to-Sum Formulas

Show hint

$105^\circ = 60^\circ + 45^\circ$. For the product, $\cos\alpha\cos\beta = \dfrac{1}{2}\{\cos(\alpha + \beta) + \cos(\alpha - \beta)\}$.

Show solution
  1. $\cos 105^\circ = \cos 60^\circ\cos 45^\circ - \sin 60^\circ\sin 45^\circ = \dfrac{\sqrt{2}}{4} - \dfrac{\sqrt{6}}{4} = \dfrac{\sqrt{2} - \sqrt{6}}{4}$.
  2. $\cos 105^\circ\cos 15^\circ = \dfrac{1}{2}(\cos 120^\circ + \cos 90^\circ) = -\dfrac{1}{4}$.
  3. Check: $\cos 15^\circ = \dfrac{\sqrt{6} + \sqrt{2}}{4}$, and $\dfrac{(\sqrt{2} - \sqrt{6})(\sqrt{2} + \sqrt{6})}{16} = \dfrac{2 - 6}{16} = -\dfrac{1}{4}$ ✓.

$\cos 105^\circ = \dfrac{\sqrt{2} - \sqrt{6}}{4}$; product $-\dfrac{1}{4}$

Problem 2

$\cos\alpha = -\dfrac{3}{5}$ and $\dfrac{\pi}{2} < \alpha < \pi$. Find $\sin 2\alpha$ and $\cos 2\alpha$. (Type $\sin 2\alpha$ in the box.)

Uses: Double- and Half-Angle Formulas

Show hint

Find $\sin\alpha$ first (positive in the second quadrant).

Show solution
  1. $\sin\alpha = \sqrt{1 - \dfrac{9}{25}} = \dfrac{4}{5}$.
  2. $\sin 2\alpha = 2 \cdot \dfrac{4}{5} \cdot \left(-\dfrac{3}{5}\right) = -\dfrac{24}{25}$.
  3. $\cos 2\alpha = 2\cos^2\alpha - 1 = \dfrac{18}{25} - 1 = -\dfrac{7}{25}$.

$\sin 2\alpha = -\dfrac{24}{25}$, $\cos 2\alpha = -\dfrac{7}{25}$

Problem 3

$\alpha$ and $\beta$ are acute angles with $\tan\alpha = 2$ and $\tan\beta = 3$. Find $\alpha + \beta$.

Uses: Addition Formulas

Show hint

Find $\tan(\alpha + \beta)$, then decide which angle in $0 < \alpha + \beta < \pi$ has that tangent.

Show solution
  1. $\tan(\alpha + \beta) = \dfrac{2 + 3}{1 - 2 \cdot 3} = \dfrac{5}{-5} = -1$.
  2. $0 < \alpha + \beta < \pi$ and $\tan(\alpha + \beta) = -1$, so $\alpha + \beta = \dfrac{3}{4}\pi$.

$\dfrac{3}{4}\pi$

Problem 4

Write $\sqrt{3}\sin\theta - \cos\theta$ in the form $r\sin(\theta + \alpha)$, and solve $\sqrt{3}\sin\theta - \cos\theta = 1$ for $0 \le \theta < 2\pi$. (Type the larger solution in the box.)

Uses: Combining Sine and Cosine

Show hint

$r = \sqrt{3 + 1} = 2$, $\cos\alpha = \dfrac{\sqrt{3}}{2}$, $\sin\alpha = -\dfrac{1}{2}$.

Show solution
  1. $\sqrt{3}\sin\theta - \cos\theta = 2\sin\left(\theta - \dfrac{\pi}{6}\right)$.
  2. $\sin\left(\theta - \dfrac{\pi}{6}\right) = \dfrac{1}{2}$ with $-\dfrac{\pi}{6} \le \theta - \dfrac{\pi}{6} < \dfrac{11}{6}\pi$.
  3. $\theta - \dfrac{\pi}{6} = \dfrac{\pi}{6}$ or $\dfrac{5}{6}\pi$, so $\theta = \dfrac{\pi}{3}$ or $\pi$.

$2\sin\left(\theta - \dfrac{\pi}{6}\right)$; $\theta = \dfrac{\pi}{3}, \pi$

Problem 5

Find the largest value of $y = \sin^2\theta + 2\sin\theta\cos\theta + 3\cos^2\theta$.

Uses: Double- and Half-Angle Formulas, Combining Sine and Cosine

Show hint

Use $\sin^2\theta = \dfrac{1 - \cos 2\theta}{2}$, $\cos^2\theta = \dfrac{1 + \cos 2\theta}{2}$ and $2\sin\theta\cos\theta = \sin 2\theta$, then combine.

Show solution
  1. $y = \dfrac{1 - \cos 2\theta}{2} + \sin 2\theta + \dfrac{3(1 + \cos 2\theta)}{2} = 2 + \sin 2\theta + \cos 2\theta$.
  2. $\sin 2\theta + \cos 2\theta = \sqrt{2}\sin\left(2\theta + \dfrac{\pi}{4}\right) \le \sqrt{2}$.
  3. Largest: $2 + \sqrt{2}$ (at $\theta = \dfrac{\pi}{8}$, for example).

$2 + \sqrt{2}$

Problem 6

Use the product-to-sum and sum-to-product formulas.

  1. (1) Find $\cos 75^\circ \cos 15^\circ$.
  2. (2) Find $\sin 105^\circ - \sin 15^\circ$. (Type it in the box.)
  3. (3) Solve $\cos 3x + \cos x = 0$ for $0 \le x < \pi$.

Uses: Product-to-Sum Formulas

Show hint

$\cos A + \cos B = 2\cos\dfrac{A + B}{2}\cos\dfrac{A - B}{2}$ and $\sin A - \sin B = 2\cos\dfrac{A + B}{2}\sin\dfrac{A - B}{2}$.

Show solution
  1. (1) $\cos 75^\circ\cos 15^\circ = \dfrac{1}{2}(\cos 90^\circ + \cos 60^\circ) = \dfrac{1}{4}$.
  2. (2) $\sin 105^\circ - \sin 15^\circ = 2\cos 60^\circ\sin 45^\circ = \dfrac{\sqrt{2}}{2}$.
  3. (3) $\cos 3x + \cos x = 2\cos 2x\cos x = 0$.
  4. $\cos x = 0$: $x = \dfrac{\pi}{2}$. $\;\cos 2x = 0$ with $0 \le 2x < 2\pi$: $2x = \dfrac{\pi}{2}, \dfrac{3}{2}\pi$, so $x = \dfrac{\pi}{4}, \dfrac{3}{4}\pi$.

(1) $\dfrac{1}{4}$ (2) $\dfrac{\sqrt{2}}{2}$ (3) $x = \dfrac{\pi}{4}, \dfrac{\pi}{2}, \dfrac{3}{4}\pi$
