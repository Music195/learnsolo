Remainder and Factor Theorems

Six problems on the remainder theorem, the factor theorem, solving cubic equations and the roots and coefficients of a cubic. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Find the remainder when $P(x) = x^3 + 2x^2 - 5x + 3$ is divided by $x + 3$.

Uses: Remainder Theorem

Show hint

The remainder is $P(-3)$: use the value of $x$ that makes $x + 3 = 0$.

Show solution
  1. $P(-3) = -27 + 18 + 15 + 3 = 9$.

$9$

Problem 2

Solve $x^3 - 2x^2 - 5x + 6 = 0$. (Type the largest solution in the box.)

Uses: Factor Theorem

Show hint

Try small divisors of $6$: $x = \pm1, \pm2, \pm3, \ldots$

Show solution
  1. $P(1) = 1 - 2 - 5 + 6 = 0$, so $x - 1$ is a factor.
  2. Dividing: $P(x) = (x - 1)(x^2 - x - 6) = (x - 1)(x - 3)(x + 2)$.
  3. $x = 1, 3, -2$.

$x = -2, 1, 3$

Problem 3

$P(x)$ leaves remainder $7$ when divided by $x - 2$, and remainder $-2$ when divided by $x + 1$. Find the remainder $ax + b$ when $P(x)$ is divided by $(x - 2)(x + 1)$. (Type $a$ in the box.)

Uses: Remainder Theorem

Show hint

Write $P(x) = (x - 2)(x + 1)Q(x) + ax + b$, then substitute $x = 2$ and $x = -1$.

Show solution
  1. $P(2) = 2a + b = 7$ and $P(-1) = -a + b = -2$.
  2. Subtract: $3a = 9$, so $a = 3$, $b = 1$. Remainder $3x + 1$.

$3x + 1$

Problem 4

$\alpha, \beta, \gamma$ are the roots of $x^3 + 2x^2 - 3x + 5 = 0$. Find $(\alpha + 1)(\beta + 1)(\gamma + 1)$.

Uses: Cubic Roots and Coefficients

Show hint

Expand: $(\alpha + 1)(\beta + 1)(\gamma + 1) = \alpha\beta\gamma + (\alpha\beta + \beta\gamma + \gamma\alpha) + (\alpha + \beta + \gamma) + 1$.

Show solution
  1. $\alpha + \beta + \gamma = -2$, $\alpha\beta + \beta\gamma + \gamma\alpha = -3$, $\alpha\beta\gamma = -5$.
  2. $(\alpha + 1)(\beta + 1)(\gamma + 1) = -5 - 3 - 2 + 1 = -9$.

$-9$

Quicker: $x^3 + 2x^2 - 3x + 5 = (x - \alpha)(x - \beta)(x - \gamma)$. Put $x = -1$: $9 = -(\alpha + 1)(\beta + 1)(\gamma + 1)$.

Problem 5

$P(x)$ divided by $(x - 1)^2$ leaves remainder $2x + 3$, and divided by $x + 2$ leaves remainder $8$. Find the remainder when $P(x)$ is divided by $(x - 1)^2(x + 2)$. (Write it as $ax^2 + bx + c$ and type $c$ in the box.)

Uses: Remainder Theorem

Show hint

The remainder $R(x)$ has degree at most $2$, and dividing it by $(x - 1)^2$ must also leave $2x + 3$. So $R(x) = k(x - 1)^2 + 2x + 3$.

Show solution
  1. $P(x) = (x - 1)^2(x + 2)Q(x) + k(x - 1)^2 + 2x + 3$.
  2. $P(-2) = 9k - 4 + 3 = 8$, so $k = 1$.
  3. $R(x) = (x - 1)^2 + 2x + 3 = x^2 + 4$.

$x^2 + 4$

Problem 6

The cubic equation $x^3 + ax^2 + bx - 10 = 0$ ($a, b$ real) has the root $2 - i$.

  1. (1) Explain why $2 + i$ is also a root, and find the quadratic with roots $2 \pm i$.
  2. (2) Find $a$, $b$ and the third root.
  3. (3) Let the three roots be $\alpha, \beta, \gamma$. Find $\alpha^2 + \beta^2 + \gamma^2$. (Type it in the box.)

Uses: Factor Theorem, Cubic Roots and Coefficients, Quadratic From Roots

Show hint

With real coefficients, imaginary roots come in conjugate pairs. The cubic is then $(x^2 + \cdots)(x - r)$; compare constant terms.

Show solution
  1. (1) The coefficients are real, so the conjugate $2 + i$ is a root. Sum $4$, product $5$: $x^2 - 4x + 5$.
  2. (2) $x^3 + ax^2 + bx - 10 = (x^2 - 4x + 5)(x - r)$. Constant terms: $-5r = -10$, so $r = 2$.
  3. $(x^2 - 4x + 5)(x - 2) = x^3 - 6x^2 + 13x - 10$: $a = -6$, $b = 13$, third root $2$.
  4. (3) $\alpha^2 + \beta^2 + \gamma^2 = (\alpha + \beta + \gamma)^2 - 2(\alpha\beta + \beta\gamma + \gamma\alpha) = 6^2 - 2 \cdot 13 = 10$.

(1) $x^2 - 4x + 5$ (2) $a = -6$, $b = 13$, third root $2$ (3) $10$

Check: $(2 - i)^2 + (2 + i)^2 + 2^2 = (3 - 4i) + (3 + 4i) + 4 = 10$ ✓.
