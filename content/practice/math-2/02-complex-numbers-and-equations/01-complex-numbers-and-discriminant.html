Complex Numbers and the Discriminant

Six problems on calculating with complex numbers, square roots of negative numbers, the quadratic formula and the discriminant. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Find real numbers $x, y$ with $(x + 2i)(1 - i) = 5 + yi$. (Type $x$ in the box.)

Uses: Complex Numbers and Equality

Show hint

Expand the left side into (real) $+$ (real)$\,i$, then compare real and imaginary parts.

Show solution
  1. $(x + 2i)(1 - i) = x - xi + 2i - 2i^2 = (x + 2) + (2 - x)i$.
  2. Real parts: $x + 2 = 5$, so $x = 3$. Imaginary parts: $2 - x = y$, so $y = -1$.

$x = 3$, $y = -1$

Problem 2

Calculate $\sqrt{-2}\,\sqrt{-18} + \dfrac{\sqrt{-50}}{\sqrt{-2}}$.

Uses: Square Roots of Negative Numbers

Show hint

Change every $\sqrt{-a}$ to $\sqrt{a}\,i$ before multiplying or dividing.

Show solution
  1. $\sqrt{-2}\,\sqrt{-18} = \sqrt{2}\,i \cdot 3\sqrt{2}\,i = 6i^2 = -6$.
  2. $\dfrac{\sqrt{-50}}{\sqrt{-2}} = \dfrac{5\sqrt{2}\,i}{\sqrt{2}\,i} = 5$.
  3. Total: $-6 + 5 = -1$.

$-1$

Writing $\sqrt{-2}\,\sqrt{-18} = \sqrt{36} = 6$ is the classic mistake: $\sqrt{a}\sqrt{b} = \sqrt{ab}$ fails when both are negative.

Problem 3

Calculate $(1 + i)^8$.

Uses: Square Roots of Negative Numbers, Complex Numbers and Equality

Show hint

Square first: $(1 + i)^2$ is very simple. Then use the powers of $i$.

Show solution
  1. $(1 + i)^2 = 1 + 2i + i^2 = 2i$.
  2. $(1 + i)^8 = (2i)^4 = 16i^4 = 16$.

$16$

Problem 4

Solve $2x^2 - 6x + 5 = 0$. (Type the real part of the solutions in the box.)

Uses: Quadratic Formula

Show hint

$x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$; here $b^2 - 4ac$ is negative.

Show solution
  1. $x = \dfrac{6 \pm \sqrt{36 - 40}}{4} = \dfrac{6 \pm 2i}{4} = \dfrac{3 \pm i}{2}$.
  2. So $x = \dfrac{3}{2} \pm \dfrac{1}{2}i$: real part $\dfrac{3}{2}$.

$x = \dfrac{3 \pm i}{2}$

Problem 5

$k \ne 0$. Find the range of $k$ for which $kx^2 + 4x + k - 3 = 0$ has imaginary solutions, and give the smallest positive integer $k$ in that range.

Uses: Discriminant

Show hint

Imaginary solutions $\iff D < 0$. With an even middle coefficient you can use $\dfrac{D}{4} = 2^2 - k(k - 3)$.

Show solution
  1. $\dfrac{D}{4} = 4 - k(k - 3) < 0 \iff k^2 - 3k - 4 > 0 \iff (k + 1)(k - 4) > 0$.
  2. $k < -1$ or $k > 4$ (and $k \ne 0$ holds automatically).
  3. Smallest positive integer: $k = 5$.

$k < -1$ or $k > 4$; $k = 5$

Problem 6

Let $\alpha = 1 + 2i$.

  1. (1) Write $\alpha^2$ and $\dfrac{1}{\alpha}$ in the form $a + bi$.
  2. (2) Find real numbers $a, b$ with $\alpha^2 + a\alpha + b = 0$.
  3. (3) With these $a, b$, find the discriminant of $x^2 + ax + b = 0$ and solve it.
  4. (4) Find the range of real $k$ for which $x^2 + ax + b = k$ has real solutions. (Type the smallest $k$ in the box.)

Uses: Complex Numbers and Equality, Quadratic Formula, Discriminant

Show hint

In (2), collect real and imaginary parts and set each to $0$. In (4), move $k$ to the left and use $D \ge 0$.

Show solution
  1. (1) $\alpha^2 = 1 + 4i + 4i^2 = -3 + 4i$. $\;\dfrac{1}{1 + 2i} = \dfrac{1 - 2i}{1 + 4} = \dfrac{1}{5} - \dfrac{2}{5}i$.
  2. (2) $(-3 + 4i) + a(1 + 2i) + b = (-3 + a + b) + (4 + 2a)i = 0$: $a = -2$, $b = 5$.
  3. (3) $x^2 - 2x + 5 = 0$: $D = 4 - 20 = -16 < 0$, $x = \dfrac{2 \pm 4i}{2} = 1 \pm 2i$.
  4. (4) $x^2 - 2x + 5 - k = 0$: $\dfrac{D}{4} = 1 - (5 - k) = k - 4 \ge 0$, so $k \ge 4$.

(1) $-3 + 4i$; $\dfrac{1}{5} - \dfrac{2}{5}i$ (2) $a = -2$, $b = 5$ (3) $D = -16$; $x = 1 \pm 2i$ (4) $k \ge 4$
