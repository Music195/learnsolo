Complex Numbers and Polynomials

Five problems on complex arithmetic, roots and coefficients, and the remainder and factor theorems. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Write $\dfrac{3 + i}{1 - i}$ in the form $a + bi$.

Uses: Square Root of Negative, Complex Equality

Show hint

Multiply the top and bottom by the conjugate $1 + i$, and use $i^2 = -1$.

Show solution
  1. $\dfrac{(3 + i)(1 + i)}{(1 - i)(1 + i)} = \dfrac{3 + 3i + i + i^2}{1 - i^2}$.
  2. $= \dfrac{2 + 4i}{2} = 1 + 2i$.

$1 + 2i$

Problem 2

$\alpha$ and $\beta$ are the roots of $x^2 - 3x + 5 = 0$. Find $\alpha^2 + \beta^2$.

Uses: Roots and Coefficients

Show hint

$\alpha + \beta = 3$ and $\alpha\beta = 5$. Write $\alpha^2 + \beta^2$ using only these.

Show solution
  1. $\alpha + \beta = 3$, $\alpha\beta = 5$.
  2. $\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta = 9 - 10 = -1$.

$\alpha^2 + \beta^2 = -1$

A negative sum of squares is no mistake: the discriminant is $9 - 20 < 0$, so $\alpha$ and $\beta$ are imaginary.

Problem 3

$P(x)$ leaves remainder $3$ when divided by $x - 1$, and remainder $-3$ when divided by $x + 2$. Find the remainder when $P(x)$ is divided by $(x - 1)(x + 2)$.

Uses: Remainder Theorem

Show hint

Dividing by a quadratic leaves a remainder $ax + b$: $P(x) = (x - 1)(x + 2)Q(x) + ax + b$. Put in $x = 1$ and $x = -2$.

Show solution
  1. $P(x) = (x - 1)(x + 2)Q(x) + ax + b$.
  2. Remainder theorem: $P(1) = a + b = 3$ and $P(-2) = -2a + b = -3$.
  3. Subtracting: $3a = 6$, so $a = 2$ and $b = 1$.

Remainder $2x + 1$

Problem 4

$\alpha$, $\beta$, $\gamma$ are the roots of $x^3 - 2x^2 + 3x - 4 = 0$. Find $\alpha^2 + \beta^2 + \gamma^2$.

Uses: Cubic Roots and Coefficients

Show hint

$\alpha + \beta + \gamma = 2$ and $\alpha\beta + \beta\gamma + \gamma\alpha = 3$. Square the sum.

Show solution
  1. $\alpha + \beta + \gamma = 2$, $\alpha\beta + \beta\gamma + \gamma\alpha = 3$, $\alpha\beta\gamma = 4$.
  2. $\alpha^2 + \beta^2 + \gamma^2 = (\alpha + \beta + \gamma)^2 - 2(\alpha\beta + \beta\gamma + \gamma\alpha) = 4 - 6 = -2$.

$\alpha^2 + \beta^2 + \gamma^2 = -2$

Problem 5

$x^3 + ax^2 + bx + 6 = 0$ ($a$, $b$ real) has the root $1 + i$. Find $a$, $b$ and the other roots.

Uses: Cubic Roots and Coefficients, Factor Theorem

Show hint

With real coefficients, the conjugate $1 - i$ is a root too. Call the third root $r$ and use the relations between roots and coefficients.

Show solution
  1. The roots are $1 + i$, $1 - i$ and a real $r$.
  2. Product: $(1 + i)(1 - i)r = 2r = -6$, so $r = -3$.
  3. Sum: $(1 + i) + (1 - i) + (-3) = -1 = -a$, so $a = 1$.
  4. Pairs: $(1 + i)(1 - i) + r\{(1 + i) + (1 - i)\} = 2 - 6 = -4 = b$.
  5. Check: $(-3)^3 + (-3)^2 - 4(-3) + 6 = -27 + 9 + 12 + 6 = 0$ ✓.

$a = 1$, $b = -4$; the other roots are $1 - i$ and $-3$
