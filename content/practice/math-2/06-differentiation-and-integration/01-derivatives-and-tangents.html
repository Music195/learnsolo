Derivatives, Tangents and Extreme Values

Six problems on the derivative and its definition, tangent lines, increase and decrease, and extreme values. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

$f(x) = (x - 2)(x^2 + 3)$. Find $f'(x)$ and $f'(1)$. (Type $f'(1)$ in the box.)

Uses: Derivative of xⁿ

Show hint

Expand first, then differentiate term by term.

Show solution
  1. $f(x) = x^3 - 2x^2 + 3x - 6$.
  2. $f'(x) = 3x^2 - 4x + 3$, so $f'(1) = 3 - 4 + 3 = 2$.

$f'(x) = 3x^2 - 4x + 3$, $f'(1) = 2$

Problem 2

$f(x) = x^2 - 3x$. Use the definition of the derivative to find $f'(2)$. Then find the average rate of change of $f$ from $x = 1$ to $x = 4$, and the value $a$ with $f'(a)$ equal to it. (Type $a$ in the box.)

Uses: Derivative of xⁿ

Show hint

$f'(2) = \displaystyle\lim_{h \to 0} \frac{f(2 + h) - f(2)}{h}$. The average rate of change is $\dfrac{f(4) - f(1)}{4 - 1}$.

Show solution
  1. $f(2 + h) - f(2) = (4 + 4h + h^2 - 6 - 3h) - (-2) = h + h^2$, so $f'(2) = \displaystyle\lim_{h \to 0}(1 + h) = 1$.
  2. Average rate: $\dfrac{4 - (-2)}{3} = 2$.
  3. $f'(a) = 2a - 3 = 2$, so $a = \dfrac{5}{2}$.

$f'(2) = 1$; average rate $2$; $a = \dfrac{5}{2}$

Problem 3

Find the tangent to $y = x^3 - 3x$ at the point where $x = 2$. (Type its $y$-intercept in the box.)

Uses: Tangent Line Formula

Show hint

$y - f(a) = f'(a)(x - a)$ with $a = 2$.

Show solution
  1. $f(2) = 8 - 6 = 2$, $f'(x) = 3x^2 - 3$, $f'(2) = 9$.
  2. $y - 2 = 9(x - 2)$, so $y = 9x - 16$.

$y = 9x - 16$

Problem 4

Find the intervals where $f(x) = -x^3 + 3x^2 + 9x - 2$ increases and decreases, and its local maximum and minimum values. (Type the local maximum value in the box.)

Uses: Increase, Decrease and the Derivative

Show hint

Factorise $f'(x)$ and make a sign table.

Show solution
  1. $f'(x) = -3x^2 + 6x + 9 = -3(x + 1)(x - 3)$.
  2. $f' < 0$ for $x < -1$, $f' > 0$ for $-1 < x < 3$, $f' < 0$ for $x > 3$.
  3. Decreasing on $x \le -1$ and $x \ge 3$, increasing on $-1 \le x \le 3$.
  4. Local minimum $f(-1) = 1 + 3 - 9 - 2 = -7$; local maximum $f(3) = -27 + 27 + 27 - 2 = 25$.

Local maximum $25$ ($x = 3$), local minimum $-7$ ($x = -1$)

Problem 5

Find the tangents to $y = x^2 + 1$ that pass through the point $(1, -2)$. (Type the larger slope in the box.)

Uses: Tangent Line Formula

Show hint

$(1, -2)$ is not on the curve. Write the tangent at a general point $(a, a^2 + 1)$, then make it pass through $(1, -2)$.

Show solution
  1. Tangent at $x = a$: $y - (a^2 + 1) = 2a(x - a)$, i.e. $y = 2ax - a^2 + 1$.
  2. Through $(1, -2)$: $-2 = 2a - a^2 + 1 \iff a^2 - 2a - 3 = 0 \iff a = 3$ or $-1$.
  3. $a = 3$: $y = 6x - 8$. $\;a = -1$: $y = -2x$.

$y = 6x - 8$ and $y = -2x$

Problem 6

$f(x) = x^3 + ax^2 + bx$ has a local maximum at $x = -1$ and a local minimum at $x = 3$.

  1. (1) Find $a$ and $b$.
  2. (2) Find the local maximum and minimum values.
  3. (3) Find the largest and smallest values of $f(x)$ on $-2 \le x \le 4$. (Type the smallest value in the box.)
  4. (4) Find the range of $k$ for which $f(x) = k$ has three different real solutions.

Uses: Derivative of xⁿ, Increase, Decrease and the Derivative

Show hint

$f'(-1) = f'(3) = 0$, so $f'(x) = 3(x + 1)(x - 3)$. For (4), count where the line $y = k$ crosses the graph.

Show solution
  1. (1) $f'(x) = 3x^2 + 2ax + b = 3(x + 1)(x - 3) = 3x^2 - 6x - 9$: $a = -3$, $b = -9$.
  2. (2) Local maximum $f(-1) = -1 - 3 + 9 = 5$; local minimum $f(3) = 27 - 27 - 27 = -27$.
  3. (3) Ends: $f(-2) = -8 - 12 + 18 = -2$, $f(4) = 64 - 48 - 36 = -20$. Largest $5$ ($x = -1$), smallest $-27$ ($x = 3$).
  4. (4) $y = k$ crosses the graph three times when it lies strictly between the local values: $-27 < k < 5$.

(1) $a = -3$, $b = -9$ (2) $5$, $-27$ (3) largest $5$, smallest $-27$ (4) $-27 < k < 5$
