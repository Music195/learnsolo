Coordinates and Components in Space

Seven problems on distances in space, magnitudes, operations in components, and the vector AB. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

P$(4, -4, 7)$. Find OP, the point symmetric to P about the $yz$-plane, and the distance from P to the $x$-axis. (Type OP in the box.)

Uses: Distance from the Origin

Show hint

$OP = \sqrt{a^2 + b^2 + c^2}$. The distance to the $x$-axis uses only the $y$ and $z$ coordinates.

Show solution
  1. $OP = \sqrt{16 + 16 + 49} = 9$.
  2. Symmetric about the $yz$-plane: $(-4, -4, 7)$.
  3. Distance to the $x$-axis: $\sqrt{16 + 49} = \sqrt{65}$.

$9$; $(-4, -4, 7)$; $\sqrt{65}$

Problem 2

$\vec{a} = (2, -3, 1)$ and $\vec{b} = (1, 2, -2)$. Find $3\vec{a} - 2\vec{b}$ and $|\vec{a} + \vec{b}|$. (Type $|\vec{a} + \vec{b}|$ in the box.)

Uses: Operations in Components, Magnitude of a Vector

Show hint

Component by component.

Show solution
  1. $3\vec{a} - 2\vec{b} = (6, -9, 3) - (2, 4, -4) = (4, -13, 7)$.
  2. $\vec{a} + \vec{b} = (3, -1, -1)$, length $\sqrt{11}$.

$(4, -13, 7)$; $\sqrt{11}$

Problem 3

$\vec{a} = (2, t, t + 1)$ has $|\vec{a}| = 3$. Find $t$, and for the positive value find the unit vector in the direction of $\vec{a}$. (Type the positive $t$ in the box.)

Uses: Magnitude of a Vector

Show hint

Square both sides: $4 + t^2 + (t + 1)^2 = 9$.

Show solution
  1. $2t^2 + 2t - 4 = 0 \iff (t + 2)(t - 1) = 0$: $t = 1$ or $-2$.
  2. $t = 1$: $\vec{a} = (2, 1, 2)$, unit vector $\dfrac{1}{3}(2, 1, 2)$.

$t = 1, -2$; $\left(\dfrac{2}{3}, \dfrac{1}{3}, \dfrac{2}{3}\right)$

Problem 4

$\vec{a} = (3, -1, 2)$ and $\vec{b} = (x, 2, y)$ are parallel. Find $x$ and $y$. (Type $x$ in the box.)

Uses: Operations in Components

Show hint

$\vec{b} = k\vec{a}$ with one $k$ for all three components.

Show solution
  1. $2 = -k$, so $k = -2$.
  2. $x = 3k = -6$, $y = 2k = -4$.

$x = -6$, $y = -4$

Problem 5

A$(1, 0, 2)$, B$(3, 2, 1)$ and C$(0, 4, 3)$. Find D so that ABCD is a parallelogram, and the length of the diagonal AC. (Type AC in the box.)

Uses: Vector AB in Components

Show hint

$\overrightarrow{AD} = \overrightarrow{BC}$.

Show solution
  1. $\overrightarrow{BC} = (-3, 2, 2)$, so D $= (-2, 2, 4)$.
  2. $\overrightarrow{AC} = (-1, 4, 1)$, $AC = \sqrt{18} = 3\sqrt{2}$.

D$(-2, 2, 4)$; $AC = 3\sqrt{2}$

Problem 6

Find the point P on the $y$-axis that is equally far from A$(2, 1, -1)$ and B$(0, 3, 4)$.

Uses: Vector AB in Components, Distance from the Origin

Show hint

P $= (0, y, 0)$. Set $PA^2 = PB^2$.

Show solution
  1. $PA^2 = 4 + (y - 1)^2 + 1$ and $PB^2 = (y - 3)^2 + 16$.
  2. $y^2 - 2y + 6 = y^2 - 6y + 25$, so $4y = 19$, $y = \dfrac{19}{4}$.

P$\left(0, \dfrac{19}{4}, 0\right)$

Problem 7

For real $t$, P is the point $(t, 1 - t, 2t)$, and A is $(1, 2, 3)$.

  1. (1) Write $\overrightarrow{OP}$ as $\vec{u} + t\vec{d}$ with constant vectors $\vec{u}$, $\vec{d}$.
  2. (2) Find the smallest value of $|\overrightarrow{OP}|$ and the $t$ giving it.
  3. (3) Find the smallest value of AP and the point P giving it. (Type the smallest AP in the box.)

Uses: Operations in Components, Magnitude of a Vector, Vector AB in Components

Show hint

Write the squared length as a quadratic in $t$ and complete the square.

Show solution
  1. (1) $\overrightarrow{OP} = (0, 1, 0) + t(1, -1, 2)$.
  2. (2) $|\overrightarrow{OP}|^2 = t^2 + (1 - t)^2 + 4t^2 = 6t^2 - 2t + 1 = 6\left(t - \dfrac{1}{6}\right)^2 + \dfrac{5}{6}$. Smallest $\sqrt{\dfrac{5}{6}} = \dfrac{\sqrt{30}}{6}$ at $t = \dfrac{1}{6}$.
  3. (3) $\overrightarrow{AP} = (t - 1, -1 - t, 2t - 3)$; $AP^2 = 6t^2 - 12t + 11 = 6(t - 1)^2 + 5$.
  4. Smallest $AP = \sqrt{5}$ at $t = 1$, P$(1, 0, 2)$.

(1) $(0, 1, 0) + t(1, -1, 2)$ (2) $\dfrac{\sqrt{30}}{6}$ at $t = \dfrac{1}{6}$ (3) $\sqrt{5}$ at P$(1, 0, 2)$
