Vector Operations and Components

Seven problems on adding and scaling vectors, parallel vectors, magnitude, components, and the vector AB. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Simplify $\overrightarrow{AB} - \overrightarrow{CB} + \overrightarrow{CD} - \overrightarrow{AD}$.

Uses: Vector Addition

Show hint

$-\overrightarrow{CB} = \overrightarrow{BC}$ and $-\overrightarrow{AD} = \overrightarrow{DA}$. Then chain head to tail.

Show solution
  1. $= \overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CD} + \overrightarrow{DA}$.
  2. The chain starts and ends at A: $= \overrightarrow{AA} = \vec{0}$.

$\vec{0}$

Problem 2

$\vec{a} = (3, -1)$ and $\vec{b} = (-2, 4)$. Find $2\vec{a} - 3\vec{b}$ and $|\vec{a} + \vec{b}|$. (Type $|\vec{a} + \vec{b}|$ in the box.)

Uses: Component Form, Scalar Multiplication, Magnitude of a Vector

Show hint

Work component by component, then $|(x, y)| = \sqrt{x^2 + y^2}$.

Show solution
  1. $2\vec{a} - 3\vec{b} = (6, -2) - (-6, 12) = (12, -14)$.
  2. $\vec{a} + \vec{b} = (1, 3)$, so $|\vec{a} + \vec{b}| = \sqrt{10}$.

$(12, -14)$; $\sqrt{10}$

Problem 3

Solve $2\vec{x} + \vec{y} = \vec{a}$, $\vec{x} - 3\vec{y} = \vec{b}$ for $\vec{x}$ and $\vec{y}$ in terms of $\vec{a}$ and $\vec{b}$. Then find them for $\vec{a} = (3, 1)$, $\vec{b} = (-2, 4)$. (Type $|\vec{x} + \vec{y}|$ in the box.)

Uses: Scalar Multiplication, Component Form

Show hint

Treat it like simultaneous equations: from the first, $\vec{y} = \vec{a} - 2\vec{x}$.

Show solution
  1. $\vec{x} - 3(\vec{a} - 2\vec{x}) = \vec{b}$ gives $7\vec{x} = 3\vec{a} + \vec{b}$, so $\vec{x} = \dfrac{3\vec{a} + \vec{b}}{7}$ and $\vec{y} = \dfrac{\vec{a} - 2\vec{b}}{7}$.
  2. $\vec{x} = \dfrac{(9 - 2, 3 + 4)}{7} = (1, 1)$, $\vec{y} = \dfrac{(3 + 4, 1 - 8)}{7} = (1, -1)$.
  3. $\vec{x} + \vec{y} = (2, 0)$, length $2$.

$\vec{x} = \dfrac{3\vec{a} + \vec{b}}{7} = (1, 1)$, $\vec{y} = \dfrac{\vec{a} - 2\vec{b}}{7} = (1, -1)$

Problem 4

$\vec{a} = (3, 1)$, $\vec{b} = (1, 2)$ and $\vec{c} = (1, -1)$. Find $t$ so that $\vec{a} + t\vec{b}$ is parallel to $\vec{c}$.

Uses: Parallel Vectors, Component Form

Show hint

$(p_1, p_2) \parallel (q_1, q_2) \iff p_1q_2 - p_2q_1 = 0$.

Show solution
  1. $\vec{a} + t\vec{b} = (3 + t, 1 + 2t)$.
  2. $(3 + t)(-1) - (1 + 2t)(1) = 0 \iff -4 - 3t = 0 \iff t = -\dfrac{4}{3}$.
  3. Check: $\left(\dfrac{5}{3}, -\dfrac{5}{3}\right) = \dfrac{5}{3}\vec{c}$ ✓.

$t = -\dfrac{4}{3}$

Problem 5

A$(-1, 2)$, B$(3, 5)$ and C$(6, 1)$. Find D so that ABCD is a parallelogram, and the length of the diagonal BD. (Type BD in the box.)

Uses: Vector AB and Its Magnitude, Vector Addition

Show hint

In parallelogram ABCD, $\overrightarrow{AD} = \overrightarrow{BC}$.

Show solution
  1. $\overrightarrow{BC} = (3, -4)$, so D $= (-1 + 3, 2 - 4) = (2, -2)$.
  2. $\overrightarrow{BD} = (-1, -7)$, $BD = \sqrt{50} = 5\sqrt{2}$.

D$(2, -2)$; $BD = 5\sqrt{2}$

Problem 6

$\vec{p}$ has length $2$ and makes $120^\circ$ with the positive $x$-axis. Write $\vec{p}$ in components, then write it as $s\vec{a} + t\vec{b}$ with $\vec{a} = (1, 1)$, $\vec{b} = (1, -1)$. (Type $s$ in the box.)

Uses: Magnitude of a Vector, Component Form

Show hint

$\vec{p} = |\vec{p}|(\cos\theta, \sin\theta)$. Then compare components.

Show solution
  1. $\vec{p} = 2(\cos 120^\circ, \sin 120^\circ) = (-1, \sqrt{3})$.
  2. $s + t = -1$ and $s - t = \sqrt{3}$.
  3. $s = \dfrac{\sqrt{3} - 1}{2}$, $t = \dfrac{-1 - \sqrt{3}}{2}$.

$\vec{p} = (-1, \sqrt{3})$; $s = \dfrac{\sqrt{3} - 1}{2}$, $t = -\dfrac{1 + \sqrt{3}}{2}$

Problem 7

O is the origin, A$(2, 1)$ and B$(1, 3)$; $\vec{a} = \overrightarrow{OA}$, $\vec{b} = \overrightarrow{OB}$.

  1. (1) Find $\overrightarrow{AB}$ and $|\overrightarrow{AB}|$.
  2. (2) Find the unit vectors parallel to $\overrightarrow{AB}$.
  3. (3) Write $\vec{c} = (5, 10)$ as $s\vec{a} + t\vec{b}$. (Type $t$ in the box.)

Uses: Vector AB and Its Magnitude, Parallel Vectors, Magnitude of a Vector, Component Form

Show hint

(2) Divide by the length, and remember the opposite direction too. (3) Compare $x$ and $y$ components.

Show solution
  1. (1) $\overrightarrow{AB} = (-1, 2)$, $|\overrightarrow{AB}| = \sqrt{5}$.
  2. (2) $\pm\dfrac{1}{\sqrt{5}}(-1, 2)$.
  3. (3) $2s + t = 5$ and $s + 3t = 10$: $t = 5 - 2s$, so $s + 15 - 6s = 10$, $s = 1$, $t = 3$.

(1) $(-1, 2)$, $\sqrt{5}$ (2) $\pm\left(-\dfrac{1}{\sqrt{5}}, \dfrac{2}{\sqrt{5}}\right)$ (3) $s = 1$, $t = 3$
