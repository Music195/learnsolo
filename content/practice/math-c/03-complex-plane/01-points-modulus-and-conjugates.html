Points, Absolute Value and Conjugates

Seven problems on complex numbers as points, absolute value and distance, and complex conjugates. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

$\alpha = 2 - i$ and $\beta = -1 + 3i$. Find $\alpha + 2\beta$ and $|\alpha - \beta|$. (Type $|\alpha - \beta|$ in the box.)

Uses: The Complex Plane, Absolute Value

Show hint

Add real and imaginary parts separately. $|a + bi| = \sqrt{a^2 + b^2}$.

Show solution
  1. $\alpha + 2\beta = (2 - 2) + (-1 + 6)i = 5i$.
  2. $\alpha - \beta = 3 - 4i$, so $|\alpha - \beta| = 5$ (the distance between the two points).

$5i$; $5$

Problem 2

Write $z = \dfrac{4 + 3i}{2 - i}$ in the form $a + bi$, and find $|z|$. (Type $|z|$ in the box.)

Uses: Complex Conjugates, Absolute Value

Show hint

Multiply top and bottom by the conjugate $2 + i$.

Show solution
  1. $z = \dfrac{(4 + 3i)(2 + i)}{(2 - i)(2 + i)} = \dfrac{8 + 4i + 6i - 3}{5} = 1 + 2i$.
  2. $|z| = \sqrt{5}$. (Check: $\dfrac{|4 + 3i|}{|2 - i|} = \dfrac{5}{\sqrt{5}} = \sqrt{5}$ ✓.)

$z = 1 + 2i$, $|z| = \sqrt{5}$

Problem 3

A($2 - i$), B($5 + i$) and C($3 + 4i$). Find the point D for which ABCD is a parallelogram, and the length BD. (Type BD in the box.)

Uses: The Complex Plane, Absolute Value

Show hint

The diagonals of a parallelogram bisect each other: $\alpha + \gamma = \beta + \delta$.

Show solution
  1. $\delta = \alpha + \gamma - \beta = (2 + 3 - 5) + (-1 + 4 - 1)i = 2i$.
  2. $BD = |2i - (5 + i)| = |-5 + i| = \sqrt{26}$.

D($2i$); $BD = \sqrt{26}$

Problem 4

Describe the set of points $z$ with $|z + 2| = |z - 4i|$, and write it as an equation in $x$ and $y$ ($z = x + yi$). (Type its $y$-intercept in the box.)

Uses: Absolute Value

Show hint

$|z + 2|$ is the distance from $z$ to $-2$; $|z - 4i|$ is the distance to $4i$.

Show solution
  1. The points equally far from $-2$ and $4i$: the perpendicular bisector of the segment joining them.
  2. $(x + 2)^2 + y^2 = x^2 + (y - 4)^2 \iff 4x + 4 = -8y + 16 \iff x + 2y = 3$.
  3. $y$-intercept $\dfrac{3}{2}$.

The perpendicular bisector of $-2$ and $4i$: $x + 2y = 3$

Problem 5

The cubic $x^3 + ax^2 + bx + 10 = 0$ ($a$, $b$ real) has the root $1 + 2i$. Find $a$, $b$ and the real root. (Type the real root in the box.)

Uses: Complex Conjugates

Show hint

With real coefficients, $1 - 2i$ is also a root. Both are roots of $x^2 - 2x + 5 = 0$.

Show solution
  1. $1 \pm 2i$ are roots, with sum $2$ and product $5$: $x^2 - 2x + 5$ is a factor.
  2. $x^3 + ax^2 + bx + 10 = (x^2 - 2x + 5)(x + c)$ with $5c = 10$, so $c = 2$.
  3. $(x^2 - 2x + 5)(x + 2) = x^3 + x + 10$: $a = 0$, $b = 1$, real root $-2$.

$a = 0$, $b = 1$; real root $-2$

Problem 6

$|z| = 3$ and $z \ne \pm 3$. Show that $w = \dfrac{z - 3}{z + 3}$ is purely imaginary.

Uses: Complex Conjugates

Show hint

$|z|^2 = z\overline{z} = 9$, so $\overline{z} = \dfrac{9}{z}$. Show that $\overline{w} = -w$.

Show solution
  1. $\overline{w} = \dfrac{\overline{z} - 3}{\overline{z} + 3} = \dfrac{\frac{9}{z} - 3}{\frac{9}{z} + 3} = \dfrac{9 - 3z}{9 + 3z} = \dfrac{3 - z}{3 + z} = -w$.
  2. $z \ne 3$ means $w \ne 0$, so $w$ is purely imaginary.

$\overline{w} = -w$ and $w \ne 0$, so $w$ is purely imaginary.

Geometrically: the angle at $z$ between the directions to $3$ and $-3$ is a right angle, because $z$ is on the circle with diameter from $-3$ to $3$.

Problem 7

The point $z$ moves so that $|z - 2i| = 1$.

  1. (1) Describe the path of $z$.
  2. (2) Find the largest and smallest values of $|z|$.
  3. (3) Find the largest value of $|z - 3|$. (Type it in the box.)
  4. (4) Describe the path of $w = \overline{z}$.

Uses: Absolute Value, The Complex Plane, Complex Conjugates

Show hint

$|z - \alpha|$ is the distance from $z$ to $\alpha$. On a circle, the farthest and nearest points from a point lie on the line through that point and the centre.

Show solution
  1. (1) The circle with centre $2i$ and radius $1$.
  2. (2) The centre is at distance $2$ from $0$: largest $|z| = 3$ (at $3i$), smallest $1$ (at $i$).
  3. (3) The centre is at distance $|2i - 3| = \sqrt{13}$ from $3$: largest $|z - 3| = 1 + \sqrt{13}$.
  4. (4) $\overline{z}$ is the reflection in the real axis: the circle with centre $-2i$ and radius $1$, i.e. $|w + 2i| = 1$.

(1) circle, centre $2i$, radius $1$ (2) $3$ and $1$ (3) $1 + \sqrt{13}$ (4) $|w + 2i| = 1$
