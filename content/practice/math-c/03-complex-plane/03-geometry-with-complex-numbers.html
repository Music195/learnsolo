Geometry with Complex Numbers

Six problems on division points, rotation about a point, angles between rays, and collinearity and perpendicularity. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

A($-1 + 4i$) and B($5 - 2i$). Find the points dividing AB internally in the ratio $1 : 2$ and externally in the ratio $1 : 2$. (Type the imaginary part of the external point in the box.)

Uses: Section and Midpoint Formulas

Show hint

Internal $m : n$: $\dfrac{n\alpha + m\beta}{m + n}$. External: $\dfrac{-n\alpha + m\beta}{m - n}$.

Show solution
  1. Internal: $\dfrac{2(-1 + 4i) + (5 - 2i)}{3} = \dfrac{3 + 6i}{3} = 1 + 2i$.
  2. External: $\dfrac{-2(-1 + 4i) + (5 - 2i)}{-1} = -(7 - 10i) = -7 + 10i$.

$1 + 2i$; $-7 + 10i$

Problem 2

Rotate B($4 + 3i$) about A($1 + i$) through $\dfrac{\pi}{2}$ to get C. Find C and the distance BC. (Type BC in the box.)

Uses: Rotation About a Point

Show hint

$\gamma = \alpha + i(\beta - \alpha)$.

Show solution
  1. $\beta - \alpha = 3 + 2i$; $i(3 + 2i) = -2 + 3i$.
  2. $\gamma = (1 + i) + (-2 + 3i) = -1 + 4i$.
  3. $BC = |-5 + i| = \sqrt{26}$ (also $\sqrt{2} \cdot AB = \sqrt{2} \cdot \sqrt{13}$ ✓).

C($-1 + 4i$); $BC = \sqrt{26}$

Problem 3

A($2 + i$), B($5 + 2i$) and C($1 + 4i$). Compute $\dfrac{\gamma - \alpha}{\beta - \alpha}$, and find $\angle BAC$, $\dfrac{AC}{AB}$ and $\angle ABC$. (Type $\angle ABC$ in degrees in the box.)

Uses: Angle Between Rays

Show hint

The argument of $\dfrac{\gamma - \alpha}{\beta - \alpha}$ is the angle from AB to AC; its modulus is $\dfrac{AC}{AB}$.

Show solution
  1. $\dfrac{-1 + 3i}{3 + i} = \dfrac{(-1 + 3i)(3 - i)}{10} = \dfrac{10i}{10} = i$.
  2. $\angle BAC = 90^\circ$ and $AC = AB$: a right isosceles triangle, so $\angle ABC = 45^\circ$.

$i$; $90^\circ$; $1$; $45^\circ$

Problem 4

A($1 + 2i$), B($3 - i$) and C($x + 5i$), with $x$ real. Find $x$ so that A, B, C lie on one line, and $x$ so that AB ⊥ AC. (Type the second $x$ in the box.)

Uses: Collinearity and Perpendicularity

Show hint

Compute $\dfrac{\gamma - \alpha}{\beta - \alpha}$: real for collinear, purely imaginary for perpendicular.

Show solution
  1. $\dfrac{(x - 1) + 3i}{2 - 3i} = \dfrac{\{(x - 1) + 3i\}(2 + 3i)}{13} = \dfrac{(2x - 11) + (3x + 3)i}{13}$.
  2. Collinear: $3x + 3 = 0$, $x = -1$.
  3. Perpendicular: $2x - 11 = 0$, $x = \dfrac{11}{2}$ (then the imaginary part $\dfrac{39}{2} \ne 0$ ✓).

Collinear: $x = -1$; perpendicular: $x = \dfrac{11}{2}$

Problem 5

A($1 + i$) and B($4 + 2i$). Find the points C that make ABC an equilateral triangle, and the centroid of the one with C above line AB. (Type the real part of that C in the box.)

Uses: Rotation About a Point, Section and Midpoint Formulas

Show hint

Rotate B about A through $\pm\dfrac{\pi}{3}$: $\gamma = \alpha + \left(\dfrac{1}{2} \pm \dfrac{\sqrt{3}}{2}i\right)(\beta - \alpha)$.

Show solution
  1. $\beta - \alpha = 3 + i$.
  2. $+\dfrac{\pi}{3}$: $\left(\dfrac{1}{2} + \dfrac{\sqrt{3}}{2}i\right)(3 + i) = \dfrac{3 - \sqrt{3}}{2} + \dfrac{1 + 3\sqrt{3}}{2}i$, so $\gamma = \dfrac{5 - \sqrt{3}}{2} + \dfrac{3 + 3\sqrt{3}}{2}i$ (above AB).
  3. $-\dfrac{\pi}{3}$: $\gamma = \dfrac{5 + \sqrt{3}}{2} + \dfrac{3 - 3\sqrt{3}}{2}i$.
  4. Centroid of the first: $\dfrac{\alpha + \beta + \gamma}{3} = \dfrac{15 - \sqrt{3}}{6} + \dfrac{9 + 3\sqrt{3}}{6}i$.

$\gamma = \dfrac{5 \mp \sqrt{3}}{2} + \dfrac{3 \pm 3\sqrt{3}}{2}i$

Problem 6

Three points A($\alpha$), B($\beta$), C($\gamma$) satisfy $\dfrac{\gamma - \alpha}{\beta - \alpha} = 1 + \sqrt{3}i$.

  1. (1) Find $\angle BAC$ and $\dfrac{AC}{AB}$.
  2. (2) Take $\alpha = 1$ and $\beta = 2 + i$. Find $\gamma$.
  3. (3) Show that $\angle ABC = 90^\circ$ by computing $\dfrac{\gamma - \beta}{\alpha - \beta}$.
  4. (4) Find the area of triangle ABC. (Type it in the box.)

Uses: Angle Between Rays, Collinearity and Perpendicularity, Rotation About a Point

Show hint

$1 + \sqrt{3}i = 2\left(\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}\right)$. (3) Purely imaginary means a right angle at B.

Show solution
  1. (1) $\angle BAC = 60^\circ$, $\dfrac{AC}{AB} = 2$.
  2. (2) $\gamma = 1 + (1 + \sqrt{3}i)(1 + i) = (2 - \sqrt{3}) + (1 + \sqrt{3})i$.
  3. (3) $\gamma - \beta = -\sqrt{3} + \sqrt{3}i$ and $\alpha - \beta = -1 - i$: $\dfrac{\sqrt{3}(-1 + i)}{-1 - i} = \dfrac{\sqrt{3}(-1 + i)^2}{2} = -\sqrt{3}i$, purely imaginary.
  4. (4) $AB = \sqrt{2}$, $AC = 2\sqrt{2}$: area $= \dfrac{1}{2} \cdot \sqrt{2} \cdot 2\sqrt{2} \cdot \sin 60^\circ = \sqrt{3}$.

(1) $60^\circ$, $2$ (2) $(2 - \sqrt{3}) + (1 + \sqrt{3})i$ (4) $\sqrt{3}$
