Polar Form, Rotation and De Moivre

Seven problems on polar form, products and quotients, rotation about the origin, De Moivre's theorem and n-th roots. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Write $-\sqrt{3} + i$ and $3 - 3i$ in polar form ($0 \le \theta < 2\pi$). (Type $\theta$ for $-\sqrt{3} + i$ in the box.)

Uses: Polar Form

Show hint

$r = |z|$, then $\cos\theta = \dfrac{a}{r}$ and $\sin\theta = \dfrac{b}{r}$. Use both signs to fix the quadrant.

Show solution
  1. $-\sqrt{3} + i$: $r = 2$, $\cos\theta = -\dfrac{\sqrt{3}}{2}$, $\sin\theta = \dfrac{1}{2}$: $\theta = \dfrac{5\pi}{6}$.
  2. $3 - 3i$: $r = 3\sqrt{2}$, $\cos\theta = \dfrac{1}{\sqrt{2}}$, $\sin\theta = -\dfrac{1}{\sqrt{2}}$: $\theta = \dfrac{7\pi}{4}$.

$2\left(\cos\dfrac{5\pi}{6} + i\sin\dfrac{5\pi}{6}\right)$; $3\sqrt{2}\left(\cos\dfrac{7\pi}{4} + i\sin\dfrac{7\pi}{4}\right)$

Problem 2

$z_1 = 4\left(\cos\dfrac{5\pi}{12} + i\sin\dfrac{5\pi}{12}\right)$ and $z_2 = 2\left(\cos\dfrac{\pi}{12} + i\sin\dfrac{\pi}{12}\right)$. Find $z_1z_2$ and $\dfrac{z_1}{z_2}$ in the form $a + bi$. (Type the imaginary part of $\dfrac{z_1}{z_2}$ in the box.)

Uses: Products and Quotients in Polar Form, Modulus and Argument of Products

Show hint

Multiply the moduli and add the arguments; divide the moduli and subtract the arguments.

Show solution
  1. $z_1z_2 = 8\left(\cos\dfrac{\pi}{2} + i\sin\dfrac{\pi}{2}\right) = 8i$.
  2. $\dfrac{z_1}{z_2} = 2\left(\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}\right) = 1 + \sqrt{3}i$.

$8i$; $1 + \sqrt{3}i$

Problem 3

(1) Find $\left|\dfrac{(2 - i)^3(1 + 3i)}{(3 + i)^2}\right|$. (2) $\arg\alpha = \dfrac{2\pi}{3}$ and $\arg\beta = \dfrac{\pi}{4}$. Find $\arg(\alpha^2\overline{\beta})$ ($0 \le \arg < 2\pi$). (Type the answer to (1) in the box.)

Uses: Modulus and Argument of Products, Products and Quotients in Polar Form

Show hint

$|z_1z_2| = |z_1||z_2|$ and $|z^n| = |z|^n$; you never need to multiply out. $\arg\overline{\beta} = -\arg\beta$.

Show solution
  1. (1) $\dfrac{(\sqrt{5})^3 \cdot \sqrt{10}}{(\sqrt{10})^2} = \dfrac{5\sqrt{50}}{10} = \dfrac{5\sqrt{2}}{2}$.
  2. (2) $2 \cdot \dfrac{2\pi}{3} - \dfrac{\pi}{4} = \dfrac{13\pi}{12}$.

(1) $\dfrac{5\sqrt{2}}{2}$ (2) $\dfrac{13\pi}{12}$

Problem 4

Rotate $z = 3 + i$ about O through $\dfrac{\pi}{3}$, and through $-\dfrac{\pi}{2}$. (Type the real part of the first image in the box.)

Uses: Rotation About the Origin

Show hint

Multiply by $\cos\theta + i\sin\theta$.

Show solution
  1. $\left(\dfrac{1}{2} + \dfrac{\sqrt{3}}{2}i\right)(3 + i) = \dfrac{3 - \sqrt{3}}{2} + \dfrac{1 + 3\sqrt{3}}{2}i$.
  2. $-i(3 + i) = 1 - 3i$.

$\dfrac{3 - \sqrt{3}}{2} + \dfrac{1 + 3\sqrt{3}}{2}i$; $1 - 3i$

Problem 5

Compute $(\sqrt{3} - i)^8$. (Type its real part in the box.)

Uses: De Moivre's Theorem, Polar Form

Show hint

$\sqrt{3} - i = 2\left\{\cos\left(-\dfrac{\pi}{6}\right) + i\sin\left(-\dfrac{\pi}{6}\right)\right\}$.

Show solution
  1. $(\sqrt{3} - i)^8 = 2^8\left\{\cos\left(-\dfrac{4\pi}{3}\right) + i\sin\left(-\dfrac{4\pi}{3}\right)\right\}$.
  2. $= 256\left(-\dfrac{1}{2} + \dfrac{\sqrt{3}}{2}i\right) = -128 + 128\sqrt{3}i$.

$-128 + 128\sqrt{3}i$

Problem 6

Solve $z^4 = -8 + 8\sqrt{3}i$. The four solutions are the corners of a square; find its area.

Uses: n-th Roots, De Moivre's Theorem

Show hint

Put $z = r(\cos\theta + i\sin\theta)$ and $-8 + 8\sqrt{3}i = 16\left(\cos\dfrac{2\pi}{3} + i\sin\dfrac{2\pi}{3}\right)$. Add $2k\pi$ before dividing by $4$.

Show solution
  1. $r^4 = 16$, so $r = 2$; $4\theta = \dfrac{2\pi}{3} + 2k\pi$, so $\theta = \dfrac{\pi}{6} + \dfrac{k\pi}{2}$ ($k = 0, 1, 2, 3$).
  2. $z = \sqrt{3} + i,\; -1 + \sqrt{3}i,\; -\sqrt{3} - i,\; 1 - \sqrt{3}i$.
  3. They lie on the circle of radius $2$, $90^\circ$ apart: the side is $2\sqrt{2}$ and the area $8$.

$\pm(\sqrt{3} + i)$, $\pm(-1 + \sqrt{3}i)$; area $8$

Problem 7

$\omega$ is a solution of $z^3 = 1$ with $\omega \ne 1$, and $\arg\omega = \dfrac{2\pi}{3}$.

  1. (1) Show that $\omega^2 + \omega + 1 = 0$.
  2. (2) Show that $1 + \omega = -\omega^2$.
  3. (3) Find $(1 + 2\omega)(1 + 2\omega^2)$. (Type it in the box.)
  4. (4) Write $1 + \omega$ in polar form, and explain why multiplying by $1 + \omega$ is a rotation about O. Through what angle?
  5. (5) Find $(1 + \omega)^{2026}$ in the form $a + bi$.

Uses: n-th Roots, Polar Form, Rotation About the Origin, De Moivre's Theorem

Show hint

(1) $z^3 - 1 = (z - 1)(z^2 + z + 1)$. (5) Use (4) and De Moivre.

Show solution
  1. (1) $(\omega - 1)(\omega^2 + \omega + 1) = 0$ and $\omega \ne 1$.
  2. (2) Immediate from (1).
  3. (3) $1 + 2(\omega + \omega^2) + 4\omega^3 = 1 - 2 + 4 = 3$.
  4. (4) $\omega = -\dfrac{1}{2} + \dfrac{\sqrt{3}}{2}i$, so $1 + \omega = \dfrac{1}{2} + \dfrac{\sqrt{3}}{2}i = \cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}$. Its modulus is $1$, so multiplying by it is the rotation about O through $\dfrac{\pi}{3}$.
  5. (5) $(1 + \omega)^{2026} = \cos\dfrac{2026\pi}{3} + i\sin\dfrac{2026\pi}{3}$. $2026 = 6 \cdot 337 + 4$, so this is $\cos\dfrac{4\pi}{3} + i\sin\dfrac{4\pi}{3} = -\dfrac{1}{2} - \dfrac{\sqrt{3}}{2}i$.

(3) $3$ (4) $\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}$, rotation through $\dfrac{\pi}{3}$ (5) $-\dfrac{1}{2} - \dfrac{\sqrt{3}}{2}i$
