DNA, Replication and the Genetic Code

Six problems on base pairing and Chargaff's rules, hydrogen bonds, semiconservative replication, triplet codons and frameshifts. Try each one first. Open the hint if you are stuck, then compare with the full step-by-step solution.

Problem 1

In a sample of double-stranded DNA, $30\,\%$ of the bases are adenine. Find the percentages of thymine, guanine and cytosine. (Type the percentage of guanine.)

Uses: DNA, RNA and DNA Replication

Show hint

A pairs with T and G pairs with C, so $\%\mathrm{A} = \%\mathrm{T}$ and $\%\mathrm{G} = \%\mathrm{C}$.

Show solution
  1. $\%\mathrm{T} = \%\mathrm{A} = 30\,\%$.
  2. G + C $= 100 - 60 = 40\,\%$, so $\%\mathrm{G} = \%\mathrm{C} = 20\,\%$.

T $30\,\%$, G $20\,\%$, C $20\,\%$

Problem 2

One DNA strand reads $5\prime\text{-AAGCTTGC-}3\prime$. Write the complementary strand, then write it $5\prime \to 3\prime$. How many hydrogen bonds hold this stretch together? (Type the number of hydrogen bonds.)

Uses: DNA, RNA and DNA Replication

Show hint

The strands are antiparallel. A–T has 2 hydrogen bonds; G–C has 3.

Show solution
  1. Pairing base by base: $3\prime\text{-TTCGAACG-}5\prime$.
  2. Written $5\prime \to 3\prime$ (read it backwards): $5\prime\text{-GCAAGCTT-}3\prime$.
  3. There are 4 A–T pairs and 4 G–C pairs: $2(4) + 3(4) = 20$ hydrogen bonds.

$5\prime\text{-GCAAGCTT-}3\prime$; 20 hydrogen bonds

Problem 3

A double-stranded DNA molecule contains $4000$ nucleotides, of which $1200$ contain guanine. How many contain adenine? (Type the number.)

Uses: DNA, RNA and DNA Replication

Show hint

G = C, and A = T.

Show solution
  1. $\mathrm{C} = \mathrm{G} = 1200$, so G + C $= 2400$.
  2. A + T $= 4000 - 2400 = 1600$, so $\mathrm{A} = 800$.

$800$ adenine nucleotides

Problem 4

Imagine life on another planet that uses only $3$ kinds of base but the same $20$ amino acids. What is the shortest codon length that could code for all $20$? (Type the codon length.)

Uses: The Genetic Code

Show hint

With $b$ bases and codons of length $n$ there are $b^n$ codons. On Earth $4^3 = 64 \geq 20$.

Show solution
  1. Length 1: $3^1 = 3$; length 2: $3^2 = 9$. Both are fewer than 20.
  2. Length 3: $3^3 = 27 \geq 20$, so 3-letter codons are the shortest that work.

$3$ (since $3^3 = 27 \geq 20$)

Problem 5

Bacteria whose DNA contains only heavy nitrogen ($^{15}\mathrm{N}$) are moved to a medium with only light nitrogen ($^{14}\mathrm{N}$). Using semiconservative replication, what percentage of DNA molecules are hybrid (one heavy and one light strand) after two rounds of replication? (Type the percentage.)

Uses: DNA, RNA and DNA Replication

Show hint

Each new molecule keeps one old strand and makes one new strand.

Show solution
  1. Start: 1 molecule, heavy/heavy.
  2. After round 1: 2 molecules, both heavy/light (hybrid).
  3. After round 2: each hybrid gives one heavy/light and one light/light, so 2 hybrid and 2 light out of 4.
  4. Hybrid: $\dfrac{2}{4} = 50\,\%$ (this is what Meselson and Stahl found).

$50\,\%$ hybrid, $50\,\%$ light

Problem 6

An mRNA begins $5\prime\text{-AUG GCA UUU AAA}\ldots$, coding Met–Ala–Phe–Lys. The C in the second codon is deleted. Write the new codons and amino acids. Which property of the genetic code explains why one lost base changes so much?

Uses: The Genetic Code

Show hint

Re-group the remaining bases in threes from AUG. GAU = Asp, UUA = Leu.

Show solution
  1. New sequence: AUG GAU UUA AA…
  2. New chain: Met–Asp–Leu–… : every codon after the deletion is different.
  3. The code is continuous (read without spaces or punctuation), so losing one nucleotide shifts the reading frame (a frameshift).

AUG GAU UUA… = Met–Asp–Leu…; the code is continuous, so the reading frame shifts.
