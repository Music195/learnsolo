Problem 1 I Q1 · Range on an interval

Let $f(x) = x^2 - 2x - 3$ and $a > -1$. Let $M$ and $m$ be the maximum and minimum values of $f(x)$ on $-1 \le x \le a$.

  1. (1) Find $m$ for $-1 < a < 1$ and for $a \ge 1$.
  2. (2) Find $M$ for $-1 < a \le 3$ and for $a > 3$.
  3. (3) Find the range of $a$ for which $M - m = 4$, and its largest value. (Type the largest $a$ in the box.)

Uses: Maximum and Minimum of y = a(x − p)² + q, Graph of y = a(x − p)² + q

Show hint

$f(x) = (x - 1)^2 - 4$ and $f(-1) = f(3) = 0$, so $x = 3$ is the mirror image of $x = -1$.

Show solution
  1. (1) $-1 < a < 1$: $m = f(a) = a^2 - 2a - 3$. $a \ge 1$: $m = -4$.
  2. (2) $-1 < a \le 3$: $M = f(-1) = 0$. $a > 3$: $M = f(a) = a^2 - 2a - 3$.
  3. (3) $-1 < a < 1$: $M - m = -(a^2 - 2a - 3) = 4 \iff (a - 1)^2 = 0$, no $a$ in this range.
  4. $1 \le a \le 3$: $M - m = 0 - (-4) = 4$ always. $a > 3$: $a^2 - 2a - 3 + 4 = 4 \iff a = 3$ or $-1$, not in range.
  5. So $1 \le a \le 3$; the largest is $3$.

(3) $1 \le a \le 3$; largest $3$

Problem 2 I Q2 · Largest of three draws

A box holds four tickets numbered $1, 2, 3, 4$. A ticket is drawn and put back, three times. Let $X$ be the largest number drawn.

  1. (1) Find the probability that the three numbers are in strictly increasing order.
  2. (2) Find $P(X \le k)$ for $k = 1, 2, 3, 4$, and then $P(X = 3)$.
  3. (3) Find the expected value of $X$. (Type this one in the box.)

Uses: Probability of Independent Trials, Expectation (Expected Value), Counting Combinations

Show hint

$P(X \le k) = \left(\dfrac{k}{4}\right)^3$, and $P(X = k) = P(X \le k) - P(X \le k - 1)$.

Show solution
  1. (1) Each set of 3 different numbers gives exactly one increasing order: $\dfrac{_4\mathrm{C}_3}{64} = \dfrac{1}{16}$.
  2. (2) $P(X \le k) = \dfrac{k^3}{64}$; $P(X = 3) = \dfrac{27 - 8}{64} = \dfrac{19}{64}$.
  3. (3) $P(X = 1, 2, 3, 4) = \dfrac{1}{64}, \dfrac{7}{64}, \dfrac{19}{64}, \dfrac{37}{64}$.
  4. $E[X] = \dfrac{1 + 14 + 57 + 148}{64} = \dfrac{220}{64} = \dfrac{55}{16}$.

(1) $\dfrac{1}{16}$ (2) $\dfrac{19}{64}$ (3) $\dfrac{55}{16}$

Problem 3 II Q1 · Recurrences with reciprocals

The sequence $\{a_n\}$ is defined by $a_1 = 1$ and $a_{n+1} = \dfrac{a_n}{1 + 2a_n}$.

  1. (1) Let $b_n = \dfrac{1}{a_n}$. Find a relation between $b_{n+1}$ and $b_n$.
  2. (2) Find the general term $a_n$.
  3. (3) Find $\displaystyle\sum_{k=1}^{10} a_k a_{k+1}$. (Type this one in the box.)

Uses: General Term of an Arithmetic Sequence, Properties of Sigma (Σ)

Show hint

Take reciprocals of both sides: $\dfrac{1}{a_{n+1}} = \dfrac{1 + 2a_n}{a_n}$. For (3), $\dfrac{1}{(2k - 1)(2k + 1)} = \dfrac{1}{2}\left(\dfrac{1}{2k - 1} - \dfrac{1}{2k + 1}\right)$.

Show solution
  1. (1) $b_{n+1} = \dfrac{1}{a_n} + 2 = b_n + 2$.
  2. (2) $\{b_n\}$ is arithmetic with $b_1 = 1$, difference $2$: $b_n = 2n - 1$, so $a_n = \dfrac{1}{2n - 1}$.
  3. (3) $\displaystyle\sum_{k=1}^{10} \dfrac{1}{(2k - 1)(2k + 1)} = \dfrac{1}{2}\left(1 - \dfrac{1}{21}\right) = \dfrac{10}{21}$.

(1) $b_{n+1} = b_n + 2$ (2) $a_n = \dfrac{1}{2n - 1}$ (3) $\dfrac{10}{21}$

Problem 4 II Q2 · Spheres

In space, consider the sphere $S$ with centre $C(1, 2, 3)$ and radius $3$.

  1. (1) Write the equation of $S$.
  2. (2) The plane $z = 1$ cuts $S$ in a circle. Find its centre and radius.
  3. (3) Find the largest distance from the origin $O$ to a point on $S$. (Type this one in the box.)

Uses: Equation of a Sphere, Planes Parallel To Coordinate Planes, Distance of Origin and Point 3-D

Show hint

The plane $z = 1$ is at distance $2$ from $C$. The farthest point of $S$ from $O$ lies on the line $OC$, beyond $C$.

Show solution
  1. (1) $(x - 1)^2 + (y - 2)^2 + (z - 3)^2 = 9$.
  2. (2) Put $z = 1$: $(x - 1)^2 + (y - 2)^2 = 5$. Centre $(1, 2, 1)$, radius $\sqrt{5}$.
  3. (3) $OC = \sqrt{1 + 4 + 9} = \sqrt{14} > 3$, so the largest distance is $\sqrt{14} + 3$.

(1) $(x - 1)^2 + (y - 2)^2 + (z - 3)^2 = 9$ (2) $(1, 2, 1)$, $\sqrt{5}$ (3) $\sqrt{14} + 3$

Problem 5 III · Trigonometric functions

Consider $f(x) = 2\sin x + \sin 2x$ on $0 \le x \le 2\pi$.

  1. (1) Show that $f'(x) = 2(2\cos x - 1)(\cos x + 1)$.
  2. (2) Find the values of $x$ where $f'(x) = 0$.
  3. (3) Find the maximum value of $f(x)$. (Type this one in the box.)

Uses: Derivatives of Trigonometric Functions, Half-Angle and Double-Angle Trigonometric Formula, Necessary Condition for Local Extrema

Show hint

$f'(x) = 2\cos x + 2\cos 2x$; use $\cos 2x = 2\cos^2 x - 1$.

Show solution
  1. (1) $f'(x) = 2\cos x + 2(2\cos^2 x - 1) = 2(2\cos^2 x + \cos x - 1) = 2(2\cos x - 1)(\cos x + 1)$.
  2. (2) $\cos x = \dfrac{1}{2}$: $x = \dfrac{\pi}{3}, \dfrac{5\pi}{3}$; $\cos x = -1$: $x = \pi$.
  3. (3) $f' > 0$ on $\left(0, \dfrac{\pi}{3}\right)$ and $f' \le 0$ on $\left(\dfrac{\pi}{3}, \dfrac{5\pi}{3}\right)$, so the maximum is at $x = \dfrac{\pi}{3}$:
  4. $f\left(\dfrac{\pi}{3}\right) = \sqrt{3} + \dfrac{\sqrt{3}}{2} = \dfrac{3\sqrt{3}}{2}$ (and $f(0) = f(2\pi) = 0$).

(2) $\dfrac{\pi}{3}, \pi, \dfrac{5\pi}{3}$ (3) $\dfrac{3\sqrt{3}}{2}$

Problem 6 IV · Techniques of integration

Find the following definite integrals.

  1. (1) $\displaystyle\int_0^1 \dfrac{x}{x^2 + 1}\,dx$.
  2. (2) $\displaystyle\int_0^{\pi/2} \sin^3 x\,dx$.
  3. (3) $\displaystyle\int_0^1 x^2 e^x\,dx$. (Type this one in the box.)

Uses: Definite Integral: Substitution Method, Definite Integral: Integration by Parts, Indefinite Integrals of Exponential Functions

Show hint

(1): substitute $u = x^2 + 1$. (2): $\sin^3 x = (1 - \cos^2 x)\sin x$, then $u = \cos x$. (3): integrate by parts twice.

Show solution
  1. (1) $\dfrac{1}{2}\left[\log(x^2 + 1)\right]_0^1 = \dfrac{1}{2}\log 2$.
  2. (2) With $u = \cos x$: $\displaystyle\int_0^1 (1 - u^2)\,du = 1 - \dfrac{1}{3} = \dfrac{2}{3}$.
  3. (3) $\displaystyle\int x^2e^x\,dx = x^2e^x - 2\int xe^x\,dx = x^2e^x - 2(xe^x - e^x) = (x^2 - 2x + 2)e^x$.
  4. $\left[(x^2 - 2x + 2)e^x\right]_0^1 = e - 2$.

(1) $\dfrac{1}{2}\log 2$ (2) $\dfrac{2}{3}$ (3) $e - 2$
