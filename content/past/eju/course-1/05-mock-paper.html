Problem 1 I Q1 · Quadratic functions

The quadratic function $f(x)$ satisfies $f(-1) = f(3) = 0$, and its maximum value is $8$.

  1. (1) Find $f(x)$.
  2. (2) Find the range of $f(x)$ on $-2 \le x \le 2$.
  3. (3) Find how many integers $k$ make the line $y = k$ meet the graph of $y = f(x)$, $-2 \le x \le 2$, at exactly one point. (Type this one in the box.)

Uses: General Forms of Linear and Quadratic Functions, Maximum and Minimum of y = a(x − p)² + q

Show hint

$f(x) = a(x + 1)(x - 3)$ with axis $x = 1$. For (3), draw the arc for $-2 \le x \le 2$: which heights does it reach once, and which twice?

Show solution
  1. (1) $f(x) = a(x + 1)(x - 3)$, and $f(1) = -4a = 8$ gives $a = -2$: $f(x) = -2x^2 + 4x + 6 = -2(x - 1)^2 + 8$.
  2. (2) $f(-2) = -10$, $f(1) = 8$, $f(2) = 6$: the range is $-10 \le f(x) \le 8$.
  3. (3) Heights $6 \le k < 8$ are reached twice (once on each side of $x = 1$, since $f(0) = f(2) = 6$); $k = 8$ once (the vertex).
  4. For $-10 \le k < 6$ the arc is reached only on $-2 \le x < 0$: once.
  5. Integers: $-10, \dots, 5$ (16 of them) and $8$, so $17$.

(1) $f(x) = -2x^2 + 4x + 6$ (2) $-10 \le f(x) \le 8$ (3) $17$

Problem 2 I Q2 · Permutations

Three-digit numbers are made from the digits $0, 1, 2, 3, 4$, each used at most once.

  1. (1) How many such three-digit numbers are there?
  2. (2) How many of them are even?
  3. (3) One of the numbers is chosen at random. Find the probability that it is a multiple of $3$. (Type this one in the box.)

Uses: Counting Permutations, Multiplication Rule for Counting, Divisibility Rules

Show hint

The first digit cannot be $0$. A number is a multiple of $3$ when its digit sum is; list the sets of three digits whose sum is a multiple of $3$.

Show solution
  1. (1) $4 \cdot 4 \cdot 3 = 48$.
  2. (2) Last digit $0$: $4 \cdot 3 = 12$. Last digit $2$ or $4$: $3 \cdot 3 = 9$ each. Total $30$.
  3. (3) Digit sets with sum a multiple of $3$: $\{0, 1, 2\}$, $\{0, 2, 4\}$, $\{1, 2, 3\}$, $\{2, 3, 4\}$.
  4. Sets with $0$ give $3! - 2! = 4$ numbers each; the others give $3! = 6$ each. Total $4 + 4 + 6 + 6 = 20$.
  5. Probability $\dfrac{20}{48} = \dfrac{5}{12}$.

(1) $48$ (2) $30$ (3) $\dfrac{5}{12}$

Problem 3 II Q1 · Linear inequalities

Let $a$ be a constant and consider the system $\begin{cases} x + 5 \le 3x + 1 \\ 3x - 2 < x + a \end{cases}$

  1. (1) Solve each inequality.
  2. (2) Find the range of $a$ for which the system has a solution.
  3. (3) Find the range of $a$ for which exactly three integers satisfy the system, and give the largest such $a$. (Type the largest $a$ in the box.)

Uses: Properties of Inequalities

Show hint

The first inequality gives a lower bound for $x$ and the second an upper bound. Which three integers must they be?

Show solution
  1. (1) $x + 5 \le 3x + 1 \iff x \ge 2$. $3x - 2 < x + a \iff x < \dfrac{a + 2}{2}$.
  2. (2) Need $2 < \dfrac{a + 2}{2}$: $a > 2$.
  3. (3) The integers must be $2, 3, 4$: $4 < \dfrac{a + 2}{2} \le 5$.
  4. So $6 < a \le 8$; the largest is $a = 8$ (then $x < 5$).

(1) $x \ge 2$; $x < \dfrac{a + 2}{2}$ (2) $a > 2$ (3) $6 < a \le 8$; largest $8$

Problem 4 II Q2 · Quadratic models

A rectangular garden is built against a long wall, using $40\,\text{m}$ of fence for the other three sides. Let $x\,\text{m}$ be the length of each side perpendicular to the wall.

  1. (1) Express the area $S$ in terms of $x$, and give the range of $x$.
  2. (2) Find the range of $x$ for which $S \ge 150$.
  3. (3) Find the largest possible area. (Type this one in the box.)

Uses: Maximum and Minimum of y = a(x − p)² + q, Quadratic Inequality Solutions

Show hint

The side parallel to the wall is $40 - 2x$, and it must be positive.

Show solution
  1. (1) $S = x(40 - 2x) = -2x^2 + 40x$, with $0 < x < 20$.
  2. (2) $-2x^2 + 40x \ge 150 \iff x^2 - 20x + 75 \le 0 \iff (x - 5)(x - 15) \le 0$: $5 \le x \le 15$.
  3. (3) $S = -2(x - 10)^2 + 200$, so the largest area is $200\,\text{m}^2$ at $x = 10$.

(1) $S = -2x^2 + 40x$, $0 < x < 20$ (2) $5 \le x \le 15$ (3) $200\,\text{m}^2$

Problem 5 III · Remainders

Answer the following about remainders when dividing by $7$.

  1. (1) Find the remainder when $3^{100}$ is divided by $7$.
  2. (2) Find all remainders $r$ ($0 \le r \le 6$) of $n$ for which $n^2 + n + 1$ is divisible by $7$.
  3. (3) Find how many integers $n$ with $1 \le n \le 100$ make $n^2 + n + 1$ divisible by $7$. (Type this one in the box.)

Uses: Congruence Rules, Integer Division

Show hint

$3^6 \equiv 1 \pmod 7$. For (2), try the seven remainders $0, 1, \dots, 6$.

Show solution
  1. (1) $3^6 = 729 = 7 \cdot 104 + 1$, so $3^{100} = (3^6)^{16} \cdot 3^4 \equiv 81 \equiv 4$. The remainder is $4$.
  2. (2) $r^2 + r + 1$ for $r = 0, \dots, 6$: $1, 3, 7, 13, 21, 31, 43$. Divisible by $7$ for $r = 2$ and $r = 4$.
  3. (3) $n \equiv 2$: $n = 2, 9, \dots, 100$ ($15$ numbers). $n \equiv 4$: $n = 4, 11, \dots, 95$ ($14$ numbers).
  4. Total $29$.

(1) $4$ (2) $r = 2, 4$ (3) $29$

Problem 6 IV · Tangents and secants

From a point $P$ outside a circle, a line meets the circle at $A$ and $B$ in that order, with $PA = 4$ and $AB = 5$. Another line from $P$ touches the circle at $T$.

  1. (1) Find $PT$.
  2. (2) Show that triangles $PTA$ and $PBT$ are similar, and find the ratio $TA : BT$.
  3. (3) Find the ratio of the areas of triangle $PTA$ and triangle $PBT$. (Type it as a fraction in the box.)

Uses: Power of a Point Theorem, Angle Between Tangent and Chord

Show hint

$PT^2 = PA \cdot PB$. The angle between the tangent $PT$ and the chord $TA$ equals the inscribed angle $\angle TBA$.

Show solution
  1. (1) $PT^2 = PA \cdot PB = 4 \cdot 9 = 36$, so $PT = 6$.
  2. (2) $\angle P$ is shared, and $\angle PTA = \angle PBT$ (tangent–chord angle), so $\triangle PTA \sim \triangle PBT$.
  3. The ratio of similarity is $PT : PB = 6 : 9 = 2 : 3$, so $TA : BT = 2 : 3$.
  4. (3) Areas go with the square of the ratio: $\left(\dfrac{2}{3}\right)^2 = \dfrac{4}{9}$.

(1) $6$ (2) $2 : 3$ (3) $\dfrac{4}{9}$
