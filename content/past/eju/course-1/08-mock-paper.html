Problem 1 I Q1 · Quadratic inequalities

The solution of the inequality $ax^2 + bx + 6 > 0$ is $-2 < x < 3$.

  1. (1) Find $a$ and $b$.
  2. (2) Solve the inequality $6x^2 + bx + a < 0$.
  3. (3) Find the largest value of $ax^2 + bx + 6$. (Type this one in the box.)

Uses: Quadratic Inequality Solutions, Maximum and Minimum of y = a(x − p)² + q

Show hint

The solution is between the roots, so $a < 0$ and $ax^2 + bx + 6 = a(x + 2)(x - 3)$.

Show solution
  1. (1) $a(x + 2)(x - 3) = ax^2 - ax - 6a$. Comparing constants: $-6a = 6$, so $a = -1$, and $b = -a = 1$.
  2. (2) $6x^2 + x - 1 < 0 \iff (3x - 1)(2x + 1) < 0 \iff -\dfrac{1}{2} < x < \dfrac{1}{3}$.
  3. (3) $-x^2 + x + 6 = -\left(x - \dfrac{1}{2}\right)^2 + \dfrac{25}{4}$: largest value $\dfrac{25}{4}$.

(1) $a = -1$, $b = 1$ (2) $-\dfrac{1}{2} < x < \dfrac{1}{3}$ (3) $\dfrac{25}{4}$

Problem 2 I Q2 · Largest number on dice

A die is rolled three times. Let $M$ be the largest of the three numbers.

  1. (1) Find the probability that $M \le 4$.
  2. (2) Find the probability that $M = 4$. (Type this one in the box.)
  3. (3) Find the probability that the product of the three numbers is even.

Uses: Probability of Independent Trials, Probability of the Complement Event

Show hint

$M \le 4$ means every roll is at most $4$. Then $P(M = 4) = P(M \le 4) - P(M \le 3)$.

Show solution
  1. (1) $\left(\dfrac{4}{6}\right)^3 = \dfrac{64}{216} = \dfrac{8}{27}$.
  2. (2) $P(M = 4) = \dfrac{4^3 - 3^3}{216} = \dfrac{37}{216}$.
  3. (3) The product is odd only when all three are odd: $\left(\dfrac{1}{2}\right)^3 = \dfrac{1}{8}$. So even: $\dfrac{7}{8}$.

(1) $\dfrac{8}{27}$ (2) $\dfrac{37}{216}$ (3) $\dfrac{7}{8}$

Problem 3 II Q1 · Sets and intervals

Let $a$ be a constant, $A = \{x \mid x^2 - 5x + 4 \le 0\}$ and $B = \{x \mid |x - a| < 2\}$.

  1. (1) Write $A$ and $B$ as intervals.
  2. (2) Find the range of $a$ for which $A \subset B$.
  3. (3) Find the range of $a$ for which $A \cap B \ne \varnothing$, and how many integers $a$ are in it. (Type the number of integers in the box.)

Uses: Subset and Empty Set, Intersection and Union, Equations and Inequalities with Absolute Value

Show hint

$A$ is a closed interval and $B$ an open interval of length $4$ centred at $a$. Draw both on a number line.

Show solution
  1. (1) $A$: $1 \le x \le 4$. $B$: $a - 2 < x < a + 2$.
  2. (2) $A \subset B$: $a - 2 < 1$ and $a + 2 > 4$, so $2 < a < 3$.
  3. (3) They overlap when $a - 2 < 4$ and $a + 2 > 1$: $-1 < a < 6$.
  4. Integers $0, 1, 2, 3, 4, 5$: $6$ of them.

(1) $1 \le x \le 4$; $a - 2 < x < a + 2$ (2) $2 < a < 3$ (3) $-1 < a < 6$; $6$ integers

Problem 4 II Q2 · Graphs with absolute value

Consider the graph of $y = |x^2 - 4|$.

  1. (1) Write $|x^2 - 4|$ without absolute value signs, and sketch the graph.
  2. (2) Find the value of $k$ for which the line $y = k$ meets the graph at exactly three points. (Type this one in the box.)
  3. (3) Find the $x$-coordinates of the points where the graph meets the line $y = x + 2$.

Uses: Absolute Value, Quadratic Graph and Intersection with x-axis

Show hint

For $-2 < x < 2$ the graph is $y = 4 - x^2$, an upside-down arc with top at $(0, 4)$.

Show solution
  1. (1) $|x^2 - 4| = x^2 - 4$ for $x \le -2$ or $x \ge 2$, and $4 - x^2$ for $-2 < x < 2$.
  2. (2) The arc reaches up to $4$ at $x = 0$; $y = 4$ meets the outer parts at $x = \pm 2\sqrt{2}$. So $k = 4$ gives three points.
  3. ($0 < k < 4$ gives four points, $k = 0$ or $k > 4$ gives two.)
  4. (3) Outer parts: $x^2 - 4 = x + 2 \iff (x - 3)(x + 2) = 0$: $x = 3$ or $x = -2$.
  5. Arc: $4 - x^2 = x + 2 \iff (x + 2)(x - 1) = 0$, and $-2 < x < 2$ gives $x = 1$. So $x = -2, 1, 3$.

(2) $k = 4$ (3) $x = -2, 1, 3$

Problem 5 III · Number bases

Answer the following about numbers in different bases.

  1. (1) Write $2024$ in base $5$.
  2. (2) Write $1101101_{(2)}$ in base $10$.
  3. (3) A number is written $abc_{(7)}$ in base $7$ and $cba_{(9)}$ in base $9$, where $a$, $b$, $c$ are digits and $a, c \ne 0$. Find the number in base $10$. (Type this one in the box.)

Uses: Integer Division

Show hint

For (3), $49a + 7b + c = 81c + 9b + a$. The digits must be at most $6$ (base 7).

Show solution
  1. (1) $2024 = 3 \cdot 625 + 1 \cdot 125 + 0 \cdot 25 + 4 \cdot 5 + 4$: $31044_{(5)}$.
  2. (2) $64 + 32 + 8 + 4 + 1 = 109$.
  3. (3) $48a = 2b + 80c$, so $b = 24a - 40c = 8(3a - 5c)$. Since $0 \le b \le 6$, $b = 0$ and $3a = 5c$.
  4. With $1 \le a, c \le 6$: $a = 5$, $c = 3$. The number is $503_{(7)} = 245 + 3 = 248$ (and $305_{(9)} = 243 + 5 = 248$).

(1) $31044_{(5)}$ (2) $109$ (3) $248$

Problem 6 IV · Circumcircle

Triangle $ABC$ is inscribed in a circle of radius $3$, with $\angle BAC = 60^\circ$ and $AB + AC = 6$.

  1. (1) Find $BC$.
  2. (2) Find $AB \cdot AC$.
  3. (3) Find the area of triangle $ABC$. (Type this one in the box.)

Uses: Law of Sines, Law of Cosines, Triangle Area Formulas

Show hint

$BC = 2R\sin A$. In the law of cosines, write $b^2 + c^2 = (b + c)^2 - 2bc$.

Show solution
  1. (1) $BC = 2 \cdot 3 \sin 60^\circ = 3\sqrt{3}$.
  2. (2) $27 = b^2 + c^2 - bc = (b + c)^2 - 3bc = 36 - 3bc$, so $bc = 3$.
  3. (3) Area $= \dfrac{1}{2} bc \sin 60^\circ = \dfrac{3\sqrt{3}}{4}$.

(1) $3\sqrt{3}$ (2) $3$ (3) $\dfrac{3\sqrt{3}}{4}$
