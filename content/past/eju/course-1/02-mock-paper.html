Problem 1 I Q1 · Quadratic functions

The graph of $y = 2x^2$ is moved by a parallel translation so that it passes through the two points $(0, 3)$ and $(2, -1)$. Let the new graph be $y = f(x)$.

  1. (1) Find $f(x)$.
  2. (2) Find the vertex of $y = f(x)$, and the translation that moves $y = 2x^2$ onto it.
  3. (3) Find the distance between the two points where $y = f(x)$ meets the $x$-axis. (Type this one in the box.)

Uses: Graph of y = a(x − p)² + q, Quadratic Formula, Quadratic Graph and Intersection with x-axis

Show hint

A translation does not change the $x^2$ coefficient, so $f(x) = 2x^2 + bx + c$. For (3), the distance between the roots is $|x_1 - x_2|$.

Show solution
  1. (1) $f(x) = 2x^2 + bx + c$. $f(0) = 3$ gives $c = 3$; $f(2) = 8 + 2b + 3 = -1$ gives $b = -6$. So $f(x) = 2x^2 - 6x + 3$.
  2. (2) $f(x) = 2\left(x - \dfrac{3}{2}\right)^2 - \dfrac{3}{2}$: vertex $\left(\dfrac{3}{2}, -\dfrac{3}{2}\right)$, so the translation is $\dfrac{3}{2}$ in the $x$-direction and $-\dfrac{3}{2}$ in the $y$-direction.
  3. (3) $2x^2 - 6x + 3 = 0$ gives $x = \dfrac{3 \pm \sqrt{3}}{2}$.
  4. The distance is $\dfrac{3 + \sqrt{3}}{2} - \dfrac{3 - \sqrt{3}}{2} = \sqrt{3}$.

(1) $f(x) = 2x^2 - 6x + 3$ (2) vertex $\left(\dfrac{3}{2}, -\dfrac{3}{2}\right)$ (3) $\sqrt{3}$

Problem 2 I Q2 · Probability

Two dice are rolled. Let $X$ be the difference between the larger and the smaller number ($X = 0$ when they are equal).

  1. (1) Find the probability that $X = 0$.
  2. (2) Find the probability that $X \ge 3$.
  3. (3) Find the expected value of $X$. (Type this one in the box.)

Uses: Probability of Event A, Multiplication Rule for Counting, Expectation (Expected Value)

Show hint

Count the 36 equally likely outcomes. For $d \ge 1$, how many outcomes have $X = d$? Try a table of $(a, b)$.

Show solution
  1. (1) Equal numbers: 6 outcomes, so $\dfrac{6}{36} = \dfrac{1}{6}$.
  2. For $d = 1, \dots, 5$ there are $2(6 - d)$ outcomes with $X = d$: $10, 8, 6, 4, 2$.
  3. (2) $X \ge 3$: $6 + 4 + 2 = 12$ outcomes, so $\dfrac{12}{36} = \dfrac{1}{3}$.
  4. (3) $E[X] = \dfrac{1 \cdot 10 + 2 \cdot 8 + 3 \cdot 6 + 4 \cdot 4 + 5 \cdot 2}{36} = \dfrac{70}{36} = \dfrac{35}{18}$.

(1) $\dfrac{1}{6}$ (2) $\dfrac{1}{3}$ (3) $\dfrac{35}{18}$

Problem 3 II Q1 · Absolute value

Consider $g(x) = |x - 2| + |x + 1|$.

  1. (1) Write $g(x)$ without absolute value signs for $x < -1$, $-1 \le x < 2$ and $x \ge 2$, and find the smallest value of $g(x)$.
  2. (2) Solve the equation $g(x) = 5$.
  3. (3) Solve the inequality $g(x) < x + 4$, and find how many integers satisfy it. (Type the number of integers in the box.)

Uses: Absolute Value, Equations and Inequalities with Absolute Value

Show hint

The signs change at $x = -1$ and $x = 2$. Solve in each range, then keep only the answers that lie in that range.

Show solution
  1. (1) $x < -1$: $g = -2x + 1$. $-1 \le x < 2$: $g = 3$. $x \ge 2$: $g = 2x - 1$. The smallest value is $3$.
  2. (2) $-2x + 1 = 5$ gives $x = -2$ (in range); $2x - 1 = 5$ gives $x = 3$ (in range). So $x = -2, 3$.
  3. (3) $x < -1$: $-2x + 1 < x + 4 \iff x > -1$, no solution here.
  4. $-1 \le x < 2$: $3 < x + 4 \iff x > -1$, so $-1 < x < 2$. $x \ge 2$: $2x - 1 < x + 4 \iff x < 5$, so $2 \le x < 5$.
  5. Together $-1 < x < 5$: the integers $0, 1, 2, 3, 4$, so $5$ of them.

(1) smallest value $3$ (2) $x = -2, 3$ (3) $-1 < x < 5$; $5$ integers

Problem 4 II Q2 · Quadratic inequalities

Let $a$ be a constant and consider the inequality $x^2 - (a + 2)x + 2a < 0$.

  1. (1) Solve the inequality when $a = 5$.
  2. (2) Solve the inequality for $a > 2$ and for $a < 2$. What happens when $a = 2$?
  3. (3) Find the range of $a$ for which exactly three integers satisfy the inequality, and give the largest such $a$. (Type the largest $a$ in the box.)

Uses: Quadratic Inequality Solutions, Factorization Formula

Show hint

Factorise: $x^2 - (a + 2)x + 2a = (x - 2)(x - a)$. The solutions lie between $2$ and $a$.

Show solution
  1. (1) $(x - 2)(x - 5) < 0$: $2 < x < 5$.
  2. (2) $a > 2$: $2 < x < a$. $a < 2$: $a < x < 2$. $a = 2$: $(x - 2)^2 < 0$ has no solution.
  3. (3) $a > 2$: the integers must be $3, 4, 5$, so $5 < a \le 6$.
  4. $a < 2$: the integers must be $1, 0, -1$, so $-2 \le a < -1$.
  5. So $-2 \le a < -1$ or $5 < a \le 6$; the largest $a$ is $6$.

(1) $2 < x < 5$ (3) $-2 \le a < -1$ or $5 < a \le 6$; largest $a = 6$

Problem 5 III · GCD and LCM

Positive integers $a$ and $b$ with $a < b$ have greatest common divisor $12$ and least common multiple $360$.

  1. (1) Find the number of positive divisors of $360$.
  2. (2) Write $a = 12m$, $b = 12n$. Find all possible pairs $(m, n)$.
  3. (3) Find the smallest possible value of $a + b$. (Type this one in the box.)

Uses: Number of Divisors, Euclidean Algorithm

Show hint

$m$ and $n$ have no common factor, and $\operatorname{lcm}(a, b) = 12mn$.

Show solution
  1. (1) $360 = 2^3 \cdot 3^2 \cdot 5$, so it has $4 \cdot 3 \cdot 2 = 24$ divisors.
  2. (2) $m$, $n$ are coprime and $12mn = 360$, so $mn = 30$ with $m < n$.
  3. Coprime pairs: $(1, 30), (2, 15), (3, 10), (5, 6)$.
  4. (3) $a + b = 12(m + n)$ is smallest for $(5, 6)$: $12 \cdot 11 = 132$ ($a = 60$, $b = 72$).

(1) $24$ (2) $(1, 30), (2, 15), (3, 10), (5, 6)$ (3) $132$

Problem 6 IV · Triangles

In triangle $ABC$, $AB = 5$, $AC = 3$ and $\angle BAC = 120^\circ$. The bisector of $\angle BAC$ meets $BC$ at $D$.

  1. (1) Find $BC$ and the radius $R$ of the circumcircle.
  2. (2) Find the area $S$ of triangle $ABC$ and the radius $r$ of its incircle.
  3. (3) Find the length $AD$. (Type this one in the box.)

Uses: Law of Cosines, Law of Sines, Triangle Incircle Area Formula, Angle Bisector Theorem in a Triangle

Show hint

For (3), split triangle $ABC$ into triangles $ABD$ and $ACD$; each has an angle of $60^\circ$ at $A$. Compare areas.

Show solution
  1. (1) $BC^2 = 25 + 9 - 2 \cdot 5 \cdot 3 \cos 120^\circ = 49$, so $BC = 7$. $2R = \dfrac{7}{\sin 120^\circ} = \dfrac{14}{\sqrt{3}}$, so $R = \dfrac{7\sqrt{3}}{3}$.
  2. (2) $S = \dfrac{1}{2} \cdot 5 \cdot 3 \sin 120^\circ = \dfrac{15\sqrt{3}}{4}$. $S = \dfrac{r}{2}(5 + 3 + 7)$ gives $r = \dfrac{\sqrt{3}}{2}$.
  3. (3) Let $AD = t$. Area $ABD$ + area $ACD$ = $\dfrac{1}{2} \cdot 5t \sin 60^\circ + \dfrac{1}{2} \cdot 3t \sin 60^\circ = 2\sqrt{3}\,t$.
  4. $2\sqrt{3}\,t = \dfrac{15\sqrt{3}}{4}$, so $t = \dfrac{15}{8}$.

(1) $BC = 7$, $R = \dfrac{7\sqrt{3}}{3}$ (2) $S = \dfrac{15\sqrt{3}}{4}$, $r = \dfrac{\sqrt{3}}{2}$ (3) $AD = \dfrac{15}{8}$
