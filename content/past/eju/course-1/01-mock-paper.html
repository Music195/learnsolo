Problem 1 I Q1 · Quadratic functions

Consider the two quadratic functions $f(x) = x^2$ and $g(x) = -x^2 + ax + b$. Function $g(x)$ takes its maximum value at $x = 2$, and the graphs of $y = f(x)$ and $y = g(x)$ meet at the point where $x = 3$.

  1. (1) Find $a$ and $b$, and the maximum value of $g(x)$.
  2. (2) Find the $x$-coordinate of the other point where the two graphs meet.
  3. (3) Find how many integers $x$ satisfy $g(x) \ge f(x)$, and the maximum value of $g(x) - f(x)$. (Type the maximum value in the box.)

Uses: Maximum and Minimum of y = a(x − p)² + q, Factorization Formula

Show hint

The axis of $y = -x^2 + ax + b$ is $x = \dfrac{a}{2}$. For (2), you already know one solution of $f(x) = g(x)$, so $(x - 3)$ is a factor.

Show solution
  1. (1) Axis $x = \dfrac{a}{2} = 2$, so $a = 4$.
  2. $g(3) = f(3)$: $-9 + 12 + b = 9$, so $b = 6$. Then $g(x) = -(x - 2)^2 + 10$: maximum $10$.
  3. (2) $x^2 = -x^2 + 4x + 6 \iff 2x^2 - 4x - 6 = 0 \iff (x - 3)(x + 1) = 0$. The other point is at $x = -1$.
  4. (3) $g(x) - f(x) = -2x^2 + 4x + 6 = -2(x + 1)(x - 3) \ge 0$ for $-1 \le x \le 3$: the integers $-1, 0, 1, 2, 3$, so $5$ of them.
  5. $-2x^2 + 4x + 6 = -2(x - 1)^2 + 8$, and $x = 1$ is in the range, so the maximum is $8$.

(1) $a = 4$, $b = 6$, maximum $10$ (2) $x = -1$ (3) $5$ integers; maximum $8$ at $x = 1$

Problem 2 I Q2 · Probability

A and B each have a bag with four cards numbered $1, 2, 3, 4$. In one game, each takes one card from their own bag at random. The player with the larger number wins; if the numbers are equal the game is a draw. The cards are put back after every game.

  1. (1) Find the probability that one game is a draw, and the probability that A wins one game.
  2. (2) The game is played 3 times. Find the probability that A wins all 3 games.
  3. (3) Find the probability that A wins once, B wins once and one game is a draw.
  4. (4) Find the probability that A wins more games than B. (Type this one in the box.)

Uses: Repeated Trials, Complementary Events

Show hint

There are $16$ equally likely pairs of cards. For (4), A and B play the same game, so P(A wins more) = P(B wins more). Use P(equal numbers of wins).

Show solution
  1. (1) Draws: $(1,1), \dots, (4,4)$, so $\dfrac{4}{16} = \dfrac{1}{4}$. The other $12$ pairs are shared equally: P(A wins) $= \dfrac{6}{16} = \dfrac{3}{8}$.
  2. (2) $\left(\dfrac{3}{8}\right)^3 = \dfrac{27}{512}$.
  3. (3) The three results can come in $3! = 6$ orders: $6 \cdot \dfrac{3}{8} \cdot \dfrac{3}{8} \cdot \dfrac{1}{4} = \dfrac{27}{128}$.
  4. (4) Equal wins: all draws $\left(\dfrac{1}{4}\right)^3 = \dfrac{1}{64} = \dfrac{2}{128}$, or one each with a draw $\dfrac{27}{128}$. Total $\dfrac{29}{128}$.
  5. By symmetry, P(A wins more) $= \dfrac{1}{2}\left(1 - \dfrac{29}{128}\right) = \dfrac{99}{256}$.

(1) $\dfrac{1}{4}$, $\dfrac{3}{8}$ (2) $\dfrac{27}{512}$ (3) $\dfrac{27}{128}$ (4) $\dfrac{99}{256}$

Problem 3 II Q1 · Radicals

Answer the following.

  1. (1) Find the integers $m$ and $n$ such that $\dfrac{m}{5} < \sqrt{2} < \dfrac{m + 1}{5}$ and $\dfrac{n}{5} < \sqrt{3} < \dfrac{n + 1}{5}$.
  2. (2) Consider the four numbers ① $(\sqrt{2} + 1)^2$ ② $\dfrac{4}{\sqrt{3} - 1}$ ③ $(-1)^3\sqrt{(-6)^2}$ ④ $\sqrt{32}$. Rationalize the denominator of ②. (Type ② in simplest form in the box.)
  3. (3) Using (1), find how many of the four numbers are greater than $5.6$, and arrange ① ~ ④ in increasing order.

Uses: Calculation with Radicals, Properties of Square Roots

Show hint

(1): compare squares, e.g. $5\sqrt{2} = \sqrt{50}$ lies between $7$ and $8$. (3): replace $\sqrt{2}$ and $\sqrt{3}$ by the bounds from (1).

Show solution
  1. (1) $5\sqrt{2} = \sqrt{50}$ and $49 < 50 < 64$, so $m = 7$. $5\sqrt{3} = \sqrt{75}$ and $64 < 75 < 81$, so $n = 8$.
  2. (2) $\dfrac{4}{\sqrt{3} - 1} = \dfrac{4(\sqrt{3} + 1)}{3 - 1} = 2 + 2\sqrt{3}$.
  3. (3) ① $= 3 + 2\sqrt{2} > 3 + 2 \cdot \dfrac{7}{5} = 5.8$; ④ $= 4\sqrt{2} > 4 \cdot \dfrac{7}{5} = 5.6$; ② $= 2 + 2\sqrt{3} < 2 + 2 \cdot \dfrac{9}{5} = 5.6$; ③ $= -6$.
  4. So $2$ numbers are greater than $5.6$ (① and ④), and ③ is the only negative one.
  5. ① − ④ $= 3 - 2\sqrt{2} = 3 - \sqrt{8} > 0$, so ④ < ①. Order: ③ < ② < ④ < ①.

(1) $m = 7$, $n = 8$ (2) $2 + 2\sqrt{3}$ (3) two numbers; ③ < ② < ④ < ①

Problem 4 II Q2 · Quadratics with a parameter

The function $f(x) = x^2 - 2ax + b$ satisfies (i) $f(1) = 4$ and (ii) $0 \le f(2) \le 6$. Let $m$ be the minimum value of $f(x)$.

  1. (1) Express $b$ in terms of $a$, and find the range of $a$.
  2. (2) Express $m$ in terms of $a$.
  3. (3) Find the largest and smallest values of $m$. (Type the smallest value in the box.)

Uses: Maximum and Minimum of y = a(x − p)² + q, Properties of Inequalities

Show hint

Use (i) to remove $b$. Then $m$ is a quadratic in $a$: find its largest and smallest values on the range of $a$ from (1).

Show solution
  1. (1) $f(1) = 1 - 2a + b = 4$, so $b = 2a + 3$.
  2. $f(2) = 4 - 4a + b = 7 - 2a$, and $0 \le 7 - 2a \le 6$ gives $\dfrac{1}{2} \le a \le \dfrac{7}{2}$.
  3. (2) $f(x) = (x - a)^2 + b - a^2$, so $m = -a^2 + 2a + 3 = -(a - 1)^2 + 4$.
  4. (3) On $\dfrac{1}{2} \le a \le \dfrac{7}{2}$: largest $m = 4$ at $a = 1$.
  5. The end further from $a = 1$ is $a = \dfrac{7}{2}$: $m = -\left(\dfrac{5}{2}\right)^2 + 4 = -\dfrac{9}{4}$.

(1) $b = 2a + 3$, $\dfrac{1}{2} \le a \le \dfrac{7}{2}$ (2) $m = -(a - 1)^2 + 4$ (3) largest $4$ ($a = 1$), smallest $-\dfrac{9}{4}$ ($a = \dfrac{7}{2}$)

Problem 5 III · Number bases

A positive integer $N$ is a 3-digit number $abc$ when written in base 7, and the 3-digit number $cba$ (the same digits in reverse order) when written in base 9.

  1. (1) Write the ranges of the digits $a$, $b$, $c$.
  2. (2) Write $N$ in two ways and show that $b = 24a - 40c$.
  3. (3) Find $a$, $b$, $c$, and $N$ in base 10. (Type $N$ in base 10 in the box.)
  4. (4) Write $N$ in base 3.

Uses: Division with Remainder, Divisibility Rules

Show hint

A digit in base 7 is $0$ to $6$, and a leading digit can't be $0$. In (3), $b = 8(3a - 5c)$ is a multiple of 8 between 0 and 6.

Show solution
  1. (1) $a$ and $c$ lead a number, so $1 \le a \le 6$, $1 \le c \le 6$; and $0 \le b \le 6$ (all digits must also be below 9).
  2. (2) $N = 49a + 7b + c = 81c + 9b + a$, so $48a - 80c = 2b$, that is $b = 24a - 40c$.
  3. (3) $b = 8(3a - 5c)$ is a multiple of 8 with $0 \le b \le 6$, so $b = 0$ and $3a = 5c$. With $1 \le a, c \le 6$: $a = 5$, $c = 3$.
  4. $N = 49 \cdot 5 + 0 + 3 = 248$. Check: $81 \cdot 3 + 0 + 5 = 248$.
  5. (4) $248 = 243 + 3 + 2 = 1 \cdot 3^5 + 0 \cdot 3^4 + 0 \cdot 3^3 + 0 \cdot 3^2 + 1 \cdot 3 + 2$, so $N = 100012_{(3)}$.

(3) $a = 5$, $b = 0$, $c = 3$, $N = 248$ (4) $100012_{(3)}$

Problem 6 IV · Triangles and circles

In triangle ABC, $AB = 3$, $AC = 6$ and $\angle A = 120^\circ$. The bisector of $\angle A$ meets side BC at D.

  1. (1) Find BC.
  2. (2) Find BD.
  3. (3) Find AD, using the areas of triangles ABD and ACD.
  4. (4) Find the radius $R$ of the circumscribed circle of triangle ABD. (Type $R$ in the box.)

Uses: Law of Cosines, Angle Bisector Theorem, Law of Sines

Show hint

BD : DC = AB : AC. For AD: area of ABC = area of ABD + area of ACD, and each small triangle has a $60^\circ$ angle at A.

Show solution
  1. (1) $BC^2 = 9 + 36 - 2 \cdot 3 \cdot 6 \cos 120^\circ = 63$, so $BC = 3\sqrt{7}$.
  2. (2) $BD : DC = 3 : 6 = 1 : 2$, so $BD = \dfrac{1}{3} \cdot 3\sqrt{7} = \sqrt{7}$.
  3. (3) $\dfrac{1}{2} \cdot 3 \cdot 6 \sin 120^\circ = \dfrac{1}{2} \cdot 3 \cdot AD \sin 60^\circ + \dfrac{1}{2} \cdot 6 \cdot AD \sin 60^\circ$, so $18 = 9\,AD$ and $AD = 2$.
  4. (4) In triangle ABD the angle opposite BD is $\angle BAD = 60^\circ$: $2R = \dfrac{BD}{\sin 60^\circ} = \dfrac{2\sqrt{7}}{\sqrt{3}}$.
  5. $R = \dfrac{\sqrt{7}}{\sqrt{3}} = \dfrac{\sqrt{21}}{3}$.

(1) $3\sqrt{7}$ (2) $\sqrt{7}$ (3) $AD = 2$ (4) $R = \dfrac{\sqrt{21}}{3}$
