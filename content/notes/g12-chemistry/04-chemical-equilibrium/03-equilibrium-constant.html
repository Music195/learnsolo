The Equilibrium Constant

Concept — One Number for the Position of Equilibrium

In 1864 two Norwegian chemists proposed the law of mass action: for a reversible reaction in a closed system at equilibrium and constant temperature, a certain ratio of product to reactant concentrations is constant.

  • Where it comes from: for $a\mathrm{A} + b\mathrm{B} \rightleftharpoons c\mathrm{C} + d\mathrm{D}$, the forward rate is $k_f[\mathrm{A}]^a[\mathrm{B}]^b$ and the reverse rate is $k_r[\mathrm{C}]^c[\mathrm{D}]^d$. At equilibrium these are equal, so the ratio of the two rate constants is a constant, $K_{eq} = k_f / k_r$.
  • $K_c$ uses molar concentrations; $K_p$ uses partial pressures of gases. Both can be used for gaseous reactions; $K_p$ is not used for reactions in solution.
  • Pure solids and pure liquids are left out of the expression: their concentrations are constant. So for $\mathrm{C_2H_5OH(l) \rightleftharpoons C_2H_5OH(g)}$, $K_c = [\mathrm{C_2H_5OH(g)}]$, and for $\mathrm{I_2(s) \rightleftharpoons I_2(g)}$, $K_c = [\mathrm{I_2(g)}]$.
  • $K$ depends only on the temperature, not on the starting amounts. Its units depend on the expression.
  • Size of K: $K \gg 1$ → equilibrium lies to the right (mostly products); $K \ll 1$ → lies to the left (mostly reactants); $K \approx 1$ → similar amounts.
Core Formulas
$$a\mathrm{A} + b\mathrm{B} \rightleftharpoons c\mathrm{C} + d\mathrm{D}$$ $$K_c = \frac{[\mathrm{C}]^c\,[\mathrm{D}]^d}{[\mathrm{A}]^a\,[\mathrm{B}]^b} \qquad\qquad K_p = \frac{p_{\mathrm{C}}^{\,c}\;p_{\mathrm{D}}^{\,d}}{p_{\mathrm{A}}^{\,a}\;p_{\mathrm{B}}^{\,b}}$$ $$K_{eq} = \frac{k_f}{k_r}$$
  • Products on top, reactants underneath; each concentration raised to its coefficient
  • All concentrations are equilibrium values (mol dm−3)
  • Units: e.g. for $\mathrm{2NO + O_2 \rightleftharpoons 2NO_2}$, $\dfrac{(\text{mol dm}^{-3})^2}{(\text{mol dm}^{-3})^2(\text{mol dm}^{-3})} = \text{dm}^3\,\text{mol}^{-1}$; when the powers cancel (as in $\mathrm{H_2 + I_2 \rightleftharpoons 2HI}$), $K$ has no units
Common Mistakes to Avoid
  • Upside down: products go on top.
  • Forgetting powers: $[\mathrm{HI}]^2$, not $[\mathrm{HI}]$, for $\mathrm{H_2 + I_2 \rightleftharpoons 2HI}$.
  • Including solids or water (as the liquid solvent): they are left out.
  • Using starting amounts: $K$ needs the concentrations at equilibrium.

Worked Examples — Textbook Examples 6–11 (pp. 72–73)

Examples 6–9: Write the equilibrium constant expressions for (6) $\mathrm{N_2(g) + 3H_2(g) \rightleftharpoons 2NH_3(g)}$; (7) $\mathrm{HF(aq) \rightleftharpoons H^+(aq) + F^-(aq)}$ ($K_c$ and $K_p$); (8) $\mathrm{2SO_2(g) + O_2(g) \rightleftharpoons 2SO_3(g)}$ ($K_p$); (9) $\mathrm{2NaHCO_3(s) \rightleftharpoons Na_2CO_3(s) + CO_2(g) + H_2O(g)}$.

Show answer

(6) $K_c = \dfrac{[\mathrm{NH_3}]^2}{[\mathrm{N_2}][\mathrm{H_2}]^3}$

(7) $K_c = \dfrac{[\mathrm{H^+}][\mathrm{F^-}]}{[\mathrm{HF}]}$; there is no gas, so $K_p$ does not apply.

(8) $K_p = \dfrac{p_{\mathrm{SO_3}}^2}{p_{\mathrm{SO_2}}^2\,p_{\mathrm{O_2}}}$

(9) The solids are left out: $K_c = [\mathrm{CO_2}][\mathrm{H_2O}]$ (and $K_p = p_{\mathrm{CO_2}}\,p_{\mathrm{H_2O}}$).

Example 10: For $\mathrm{2NO(g) + O_2(g) \rightleftharpoons 2NO_2(g)}$ at 230 °C, the equilibrium concentrations are [NO] = 0.542, [O2] = 0.127 and [NO2] = 0.059 mol dm−3. Find $K_c$ and the position of equilibrium.

Show step-by-step solution

$K_c = \dfrac{[\mathrm{NO_2}]^2}{[\mathrm{NO}]^2[\mathrm{O_2}]} = \dfrac{(0.059)^2}{(0.542)^2 (0.127)} = \dfrac{0.003481}{0.2938 \times 0.127} = \dfrac{0.003481}{0.03731}$

$K_c = 0.093$ dm3 mol−1. Since $K_c \ll 1$, the equilibrium lies to the left (mostly NO and O2).

Example 11: $\mathrm{2H_2S(g) \rightleftharpoons 2H_2(g) + S_2(g)}$ at 1405 K has $K_c = 2.270 \times 10^{-3}$ mol dm−3. If [S2] = 0.054 and [H2S] = 0.184 mol dm−3, find [H2].

Show step-by-step solution

$K_c = \dfrac{[\mathrm{H_2}]^2[\mathrm{S_2}]}{[\mathrm{H_2S}]^2}$, so $[\mathrm{H_2}]^2 = \dfrac{K_c [\mathrm{H_2S}]^2}{[\mathrm{S_2}]} = \dfrac{2.270 \times 10^{-3} \times (0.184)^2}{0.054}$

$= \dfrac{2.270 \times 10^{-3} \times 0.03386}{0.054} = 1.423 \times 10^{-3}$

$[\mathrm{H_2}] = \sqrt{1.423 \times 10^{-3}} = 0.0377$ mol dm−3

Worked Examples — Review Questions (pp. 73–74) and Exercise 11 (p. 75)

Review Q1 and Q2: Difference between $K_p$ and $K_c$; expressions for (i) $\mathrm{CH_3COOC_2H_5(aq) + H_2O(l) \rightleftharpoons CH_3COOH(aq) + C_2H_5OH(aq)}$, (ii) $\mathrm{Cd^{2+}(aq) + 4Br^-(aq) \rightleftharpoons CdBr_4^{2-}(aq)}$, (iii) $\mathrm{CH_4(g) + 2H_2S(g) \rightleftharpoons CS_2(l) + 4H_2(g)}$.

Show answer

$K_c$ uses equilibrium molar concentrations; $K_p$ uses equilibrium partial pressures and only applies to gases.

(i) $K_c = \dfrac{[\mathrm{CH_3COOH}][\mathrm{C_2H_5OH}]}{[\mathrm{CH_3COOC_2H_5}]}$ (water, the liquid solvent, is left out); no $K_p$.

(ii) $K_c = \dfrac{[\mathrm{CdBr_4^{2-}}]}{[\mathrm{Cd^{2+}}][\mathrm{Br^-}]^4}$; no $K_p$.

(iii) $K_c = \dfrac{[\mathrm{H_2}]^4}{[\mathrm{CH_4}][\mathrm{H_2S}]^2}$ and $K_p = \dfrac{p_{\mathrm{H_2}}^4}{p_{\mathrm{CH_4}}\,p_{\mathrm{H_2S}}^2}$ (liquid CS2 left out).

Review Q3: $K_c = 10.5$ for $\mathrm{CO(g) + 2H_2(g) \rightleftharpoons CH_3OH(g)}$. (a) Find [CH3OH] when [H2] = 0.0661 and [CO] = 3.85 mol dm−3. (b) Find [H2] when [CO] = 1.09 and [CH3OH] = 0.325 mol dm−3.

Show step-by-step solution

$K_c = \dfrac{[\mathrm{CH_3OH}]}{[\mathrm{CO}][\mathrm{H_2}]^2}$

(a) $[\mathrm{CH_3OH}] = 10.5 \times 3.85 \times (0.0661)^2 = 40.43 \times 0.004369 = \mathbf{0.177}$ mol dm−3

(b) $[\mathrm{H_2}]^2 = \dfrac{0.325}{10.5 \times 1.09} = \dfrac{0.325}{11.445} = 0.02840$, so $[\mathrm{H_2}] = \mathbf{0.169}$ mol dm−3

Exercise 11: At 430 °C, $K_p = 54.3$ for $\mathrm{H_2(g) + I_2(g) \rightleftharpoons 2HI(g)}$. H2 and I2 are each put in at 0.500 atm. Find the equilibrium partial pressure of HI.

Show step-by-step solution

Let $x$ atm of H2 react. At equilibrium: $p_{\mathrm{H_2}} = p_{\mathrm{I_2}} = 0.500 - x$, $p_{\mathrm{HI}} = 2x$.

$54.3 = \dfrac{(2x)^2}{(0.500 - x)^2}$. Take square roots: $\dfrac{2x}{0.500 - x} = \sqrt{54.3} = 7.369$.

$2x = 3.684 - 7.369x \;\Rightarrow\; 9.369x = 3.684 \;\Rightarrow\; x = 0.393$ atm.

$p_{\mathrm{HI}} = 2x = 0.787$ atm (with $p_{\mathrm{H_2}} = p_{\mathrm{I_2}} = 0.107$ atm). Check: $0.787^2 / 0.107^2 = 54$. ✓ (Try it in the demo: start 0.5, 0.5, 0.)

Key Takeaways
  • $K_c$ = products over reactants, each raised to its coefficient, using equilibrium concentrations.
  • Leave out pure solids and liquids; $K_p$ uses partial pressures of gases.
  • $K$ changes only with temperature. Large $K$: products favoured; small $K$: reactants favoured.
  • Rearrange the $K$ expression to find an unknown equilibrium concentration.
