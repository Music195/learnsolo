Vibrating Strings

Both ends of a string are nodes, so only whole numbers of half-wavelengths fit

Pluck a guitar string. Waves run along it, reflect at the two fixed ends and overlap, making a standing wave. Since both ends are fixed, both must be nodes.

Node to node is $\lambda/2$, so the string length must hold a whole number of "loops": $L = n\dfrac{\lambda}{2}$, with $n = 1, 2, 3, \dots$ Only these wavelengths (and their frequencies) can survive. They are the string's natural frequencies.

  • $n = 1$: one loop, the fundamental (the lowest note, also called the 1st harmonic).
  • $n = 2, 3, \dots$: the 2nd, 3rd, … harmonics (overtones), at 2, 3, … times the fundamental frequency.

The speed of waves on the string depends on how tight it is and how heavy it is: $v = \sqrt{S/\rho}$, where $S$ is the tension and $\rho$ the mass per metre. A tighter or lighter string gives faster waves and a higher note; a shorter string also gives a higher note.

A string fixed at both ends

$$\lambda_n = \frac{2L}{n} \qquad f_n = \frac{v}{\lambda_n} = \frac{nv}{2L} \qquad v = \sqrt{\frac{S}{\rho}}$$

$L$: length of the vibrating string (m). $n = 1, 2, 3, \dots$ (number of loops). $v$: wave speed on the string (m/s). $S$: tension (N). $\rho$: linear density, mass per unit length (kg/m).

  1. Guess that $v$ depends only on $S$ and $\rho$: $v = kS^a\rho^b$, with $k$ a pure number.
  2. Units: $\mathrm{m\,s^{-1}} = (\mathrm{kg\,m\,s^{-2}})^a(\mathrm{kg\,m^{-1}})^b$.
  3. Match powers. kg: $a + b = 0$. m: $a - b = 1$. s: $-2a = -1$.
  4. So $a = \tfrac12$, $b = -\tfrac12$, and $v = k\sqrt{S/\rho}$. A full calculation shows $k = 1$.

A string of length 0.50 m, ρ = 1.0 × 10⁻³ kg/m

Example 1

A string has linear density $1.0 \times 10^{-3}$ kg/m and tension 40 N. Find the wave speed on it.

Show solution
  1. $v = \sqrt{40/(1.0 \times 10^{-3})} = \sqrt{4.0 \times 10^{4}}$.

$v = 200\ \mathrm{m/s}$

Example 2

That string is 0.50 m long between its fixed ends. Find its fundamental frequency and the frequency of its 3rd harmonic.

Show solution
  1. $f_1 = \dfrac{v}{2L} = \dfrac{200}{1.0}$.
  2. $f_3 = 3f_1$.

200 Hz and 600 Hz

Example 3

A 0.60 m string vibrates at 300 Hz with 3 loops. Find the wavelength and the wave speed.

Show solution
  1. 3 loops: $L = 3\lambda/2$, so $\lambda = 2 \times 0.60/3 = 0.40$ m.
  2. $v = f\lambda = 300 \times 0.40$.

$\lambda = 0.40$ m; $v = 120$ m/s

Example 4

The tension in a string is made 4 times larger. What happens to its fundamental frequency?

Show solution
  1. $v = \sqrt{S/\rho}$: $S \times 4$ gives $v \times 2$.
  2. $f_1 = v/(2L)$ with the same $L$: $f_1 \times 2$.

It doubles (one octave higher)

Example 5

A string driven at a fixed frequency shows 2 loops. How must the tension change so that it shows 4 loops at the same frequency?

Show solution
  1. 4 loops in the same length: $\lambda$ halves.
  2. Same $f$, so $v = f\lambda$ halves.
  3. $v \propto \sqrt S$, so $S$ must become $(1/2)^2 = 1/4$ of before.

Reduce the tension to a quarter

$v$ here is the speed of waves on the string, not the speed of sound in air. The string's frequency is passed on to the air, but the wavelength in air is $340/f$, which is different.
For any string or pipe problem, first draw the standing wave (nodes at fixed ends), count loops, and read off $\lambda$. Then use $f = v/\lambda$.
  • String fixed at both ends: $L = n\lambda/2$, so $f_n = nv/(2L)$.
  • $v = \sqrt{S/\rho}$: tighter or lighter → faster → higher note.
  • All whole-number harmonics are possible.
