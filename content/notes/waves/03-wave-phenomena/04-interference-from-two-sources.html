Interference from Two Sources

Whether two waves strengthen or cancel depends on the difference in the distances they travel

Two sources S₁ and S₂ vibrate with the same frequency and send out circular waves. Where the waves overlap they add (superposition). At some points they always strengthen each other; at others they always cancel. This pattern is interference.

What decides it is the path difference $|PS_1 - PS_2|$ for a point P: how much further one wave has travelled than the other.

  • If the sources vibrate in phase and the path difference is a whole number of wavelengths, the two waves arrive in step (crest on crest): strengthened (constructive). If it is a whole number plus a half, crest meets trough: weakened (destructive).
  • If the sources are in antiphase (one goes up while the other goes down), the conditions swap.

Points with the same path difference lie on a curve (a hyperbola), so the strong and weak points form lines spreading out from between the sources: antinodal lines (strong) and nodal lines (weak).

Two sources in phase ($m = 0, 1, 2, \dots$)

$$|PS_1 - PS_2| = m\lambda \ \text{(strong)} \qquad |PS_1 - PS_2| = \left(m + \tfrac12\right)\lambda \ \text{(weak)}$$

Sources in antiphase: the two conditions swap ($m\lambda$ weak, $(m + \frac12)\lambda$ strong). On the line between the sources, the path difference can't exceed the separation $d$, so only lines with $|PS_1 - PS_2| < d$ exist.

  1. Each extra wavelength of path delays a wave by exactly one period: it arrives at the same stage of its vibration.
  2. So if the sources start in step and the path difference is $m\lambda$, the waves arrive in step: amplitudes add.
  3. An extra half wavelength delays by half a period: the waves arrive in antiphase and cancel.
  4. If the sources start in antiphase, that extra half turn is already built in, so the conditions swap.

Sources 5 cm apart, λ = 2 cm: drag P (red lines strong, grey dashed weak)

Example 1

Two sources in phase are 5.0 cm apart, with $\lambda = 2.0$ cm. How many antinodal (strong) lines cross the segment between them?

Show solution
  1. Between the sources, $|PS_1 - PS_2|$ ranges from 0 up to (not including) 5.0 cm.
  2. Strong: $|PS_1 - PS_2| = 0, 2.0, 4.0$ cm. The values 2.0 and 4.0 each occur on both sides of the centre.
  3. Count: $0$ (1 line) + $\pm2.0$ (2) + $\pm4.0$ (2).

5 strong lines

Example 2

Same set-up but the sources are in antiphase. How many strong lines now?

Show solution
  1. Strong now needs $|PS_1 - PS_2| = (m + \frac12)\lambda = 1.0, 3.0$ cm (5.0 is not less than $d$).
  2. Each occurs on both sides: $2 + 2$.

4 strong lines (and the centre line becomes weak)

Example 3

Sources in phase, $\lambda = 2.0$ cm. A point P has $PS_1 = 12$ cm and $PS_2 = 8.0$ cm. Strong or weak?

Show solution
  1. Path difference $= 4.0$ cm $= 2\lambda$, a whole number of wavelengths.

Strong

Example 4

Same sources, a point Q with $QS_1 = 11$ cm and $QS_2 = 8.0$ cm. Strong or weak? What if the sources were in antiphase?

Show solution
  1. Path difference $3.0$ cm $= 1.5\lambda$: whole number plus a half.
  2. In phase: weak. Antiphase: the conditions swap.

Weak (in phase); strong (antiphase)

Example 5

Two loudspeakers play the same 680 Hz note in phase; sound travels at 340 m/s. You stand 4.00 m from one and 3.25 m from the other. Loud or quiet?

Show solution
  1. $\lambda = 340/680 = 0.500$ m.
  2. Path difference $= 0.75$ m $= 1.5\lambda$.

Quiet (a nodal line)

Always check whether the sources are in phase or in antiphase before using the conditions. Antiphase swaps "strong" and "weak", including on the centre line.
To count lines between sources a distance $d$ apart, list the allowed path differences from 0 up to $d$ (not including $d$): count 0 once and every other value twice.
  • In phase: path difference $m\lambda$ strong, $(m + \frac12)\lambda$ weak.
  • Antiphase: swapped.
  • Strong and weak points form lines (hyperbolas) between and beyond the sources.
