The Lens Formula

One formula links the object distance, the image distance and the focal length

Ray diagrams show roughly where an image is. The lens formula gives it exactly. Write $a$ for the distance from the object to the lens, $b$ for the distance from the lens to the image, and $f$ for the focal length (all positive lengths).

  • Convex lens, real image (image on the far side): $\dfrac1a + \dfrac1b = \dfrac1f$.
  • Convex lens, virtual image (magnifying glass, image on the object side): $\dfrac1a - \dfrac1b = \dfrac1f$.
  • Concave lens (always virtual): $\dfrac1a - \dfrac1b = -\dfrac1f$.

The magnification (how many times taller the image is) is $m = \dfrac ba$ in every case.

You can also use the single "sign" form $\dfrac1a + \dfrac1b = \dfrac1f$ with $b < 0$ meaning a virtual image and $f < 0$ for a concave lens. It gives the same answers; the three-case form above just keeps every number positive.

Lens formula and magnification

$$\frac1a + \frac1b = \frac1f \qquad m = \frac ba$$

Real image (convex): as written. Virtual image (convex): $\frac1a - \frac1b = \frac1f$. Concave lens: $\frac1a - \frac1b = -\frac1f$. $a$: object distance; $b$: image distance; $f$: focal length; $m$: magnification.

  1. Object height $h$ at distance $a$, image height $h'$ at distance $b$ (real image, convex lens).
  2. Ray 2 through the centre makes two similar triangles: $\dfrac{h'}{h} = \dfrac ba$. That is the magnification.
  3. Ray 1 leaves the lens at height $h$ and passes through F′: the triangles with sides $h$, $f$ and $h'$, $b - f$ are similar, so $\dfrac{h'}{h} = \dfrac{b - f}{f}$.
  4. So $\dfrac ba = \dfrac{b-f}{f}$, i.e. $bf = ab - af$. Divide by $abf$: $\dfrac1a = \dfrac1f - \dfrac1b$, which is $\dfrac1a + \dfrac1b = \dfrac1f$.
  5. The virtual and concave cases follow the same way from their diagrams; only signs change.

Image distance b against object distance a (|f| = 10 cm)

Example 1

An object is 15 cm from a convex lens with $f = 10$ cm. Find the image position, magnification and type.

Show solution
  1. $\dfrac1b = \dfrac1{10} - \dfrac1{15} = \dfrac{3 - 2}{30} = \dfrac1{30}$, so $b = 30$ cm (positive: real).
  2. $m = 30/15 = 2$.

30 cm behind the lens; real, inverted, twice the size

Example 2

The object is moved to 5.0 cm from the same lens. Find the image.

Show solution
  1. $a < f$: a virtual image. $\dfrac15 - \dfrac1b = \dfrac1{10}$, so $\dfrac1b = \dfrac15 - \dfrac1{10} = \dfrac1{10}$.
  2. $b = 10$ cm; $m = 10/5.0 = 2$.

Virtual, upright, twice the size, 10 cm from the lens on the object side

Example 3

An object is 15 cm from a concave lens with focal length 10 cm. Find the image.

Show solution
  1. $\dfrac1{15} - \dfrac1b = -\dfrac1{10}$, so $\dfrac1b = \dfrac1{15} + \dfrac1{10} = \dfrac{2 + 3}{30} = \dfrac16$.
  2. $b = 6.0$ cm; $m = 6.0/15 = 0.40$.

Virtual, upright, 0.40 times the size, 6.0 cm from the lens on the object side

Example 4

A sharp image of a lamp 30 cm from a convex lens forms on a screen 15 cm behind the lens. Find the focal length.

Show solution
  1. On a screen, so real: $\dfrac1f = \dfrac1{30} + \dfrac1{15} = \dfrac{1 + 2}{30} = \dfrac1{10}$.

$f = 10$ cm

Example 5

With a convex lens of $f = 10$ cm, you want a real image the same size as the object. Where do the object and screen go?

Show solution
  1. $m = 1$ means $b = a$. Then $\dfrac2a = \dfrac1{10}$, so $a = 20$ cm $= 2f$.

Object 20 cm in front, screen 20 cm behind: 40 cm apart

Decide the case before using the formula. If $a < f$ for a convex lens, $\frac1a + \frac1b = \frac1f$ with positive $b$ has no solution: the image is virtual and the minus-sign form is needed.
Always check a lens-formula answer with a quick ray sketch: is the image on the side, and of the size, that the diagram suggests?
  • Real (convex): $\frac1a + \frac1b = \frac1f$.
  • Virtual (convex): $\frac1a - \frac1b = \frac1f$. Concave: $\frac1a - \frac1b = -\frac1f$.
  • Magnification $m = b/a$.
