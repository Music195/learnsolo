Chapter 10: Method of Integration

Antiderivatives and Fundamental Integration Rules

Integration is the reverse process of differentiation. Given the rate of change $f(x)$, we recover the family of original functions $F(x) + C$ whose derivative is $f(x)$.

1. Antiderivatives and Indefinite Integrals

Suppose we know that $f'(x) = 3x^2$. Since differentiation reduces the power of $x$ by $1$, any function of the form $f(x) = x^3 + C$ (where $C$ is an arbitrary constant, such as $x^3$, $x^3 + 2$, or $x^3 - \frac{1}{2}$) has derivative $3x^2$.

Definition — Antiderivative and Indefinite Integral

If $F(x)$ is a function such that $F'(x) = f(x)$, then $F(x)$ is called an antiderivative of $f(x)$.

We call the general antiderivative the indefinite integral of $f(x)$ with respect to $x$ and write: $$\int f(x)\,dx = F(x) + C$$ where $f(x)$ is the integrand, $x$ is the variable of integration, and $C$ is the constant of integration.

Rules of Integration (Linearity)

Suppose $f(x)$ and $g(x)$ are continuous functions and $k \in \mathbb{R}$:

  1. $\displaystyle \int k\,dx = kx + C$
  2. $\displaystyle \int k f(x)\,dx = k \int f(x)\,dx$
  3. $\displaystyle \int \bigl[f(x) \pm g(x)\bigr]\,dx = \int f(x)\,dx \pm \int g(x)\,dx$

2. Fundamental Integration Formulas

Power, Reciprocal & Exponential Functions
  • $\displaystyle \int x^n\,dx = \frac{1}{n + 1}x^{n + 1} + C \quad (n \ne -1)$
  • $\displaystyle \int x^0\,dx = \int 1\,dx = x + C$
  • $\displaystyle \int \frac{1}{x}\,dx = \ln|x| + C \quad (x \ne 0)$
  • $\displaystyle \int e^x\,dx = e^x + C$
  • $\displaystyle \int a^x\,dx = \frac{1}{\ln a}a^x + C \quad (a > 0,\; a \ne 1)$
Trigonometric Functions
  • $\displaystyle \int \cos x\,dx = \sin x + C$
  • $\displaystyle \int \sin x\,dx = -\cos x + C$
  • $\displaystyle \int \sec^2 x\,dx = \tan x + C$
  • $\displaystyle \cos^2 x = \frac{1}{2}(1 + \cos 2x)$
  • $\displaystyle \sin^2 x = \frac{1}{2}(1 - \cos 2x)$
Integrating Functions of the Form $f(ax + b)$

If $f$ is a differentiable function of $x$ and $a \ne 0$, then by reversing the chain rule $\dfrac{d}{dx}\bigl[f(ax + b)\bigr] = a f'(ax + b)$, we obtain: $$\int f'(ax + b)\,dx = \frac{1}{a}f(ax + b) + C$$

  • $\displaystyle \int (ax + b)^n\,dx = \frac{1}{a(n + 1)}(ax + b)^{n + 1} + C \quad (n \ne -1)$
  • $\displaystyle \int \frac{1}{ax + b}\,dx = \frac{1}{a}\ln|ax + b| + C$
  • $\displaystyle \int \cos(ax + b)\,dx = \frac{1}{a}\sin(ax + b) + C, \qquad \int \sin(ax + b)\,dx = -\frac{1}{a}\cos(ax + b) + C$
  • $\displaystyle \int \sec^2(ax + b)\,dx = \frac{1}{a}\tan(ax + b) + C$
  • $\displaystyle \int e^{px + q}\,dx = \frac{1}{p}e^{px + q} + C, \qquad \int a^{px + q}\,dx = \frac{1}{p\ln a}a^{px + q} + C$

4. Worked Textbook Examples

Example 2 (Textbook p. 172) — Basic Power & Reciprocal Integrals

Evaluate each of the following integrals:

  • (a) $\displaystyle \int (4x^5 + 1)\,dx$: $$\int (4x^5 + 1)\,dx = 4\int x^5\,dx + \int 1\,dx = \frac{4}{6}x^6 + x + C = \frac{2}{3}x^6 + x + C$$
  • (b) $\displaystyle \int \left(x^8 - x^3 + \frac{3}{x}\right)dx$: $$\int x^8\,dx - \int x^3\,dx + 3\int \frac{1}{x}\,dx = \frac{1}{9}x^9 - \frac{1}{4}x^4 + 3\ln|x| + C$$
  • (c) $\displaystyle \int 5x\sqrt[3]{x}\,dx$: $$5\int x \cdot x^{1/3}\,dx = 5\int x^{4/3}\,dx = 5\left(\frac{3}{7}x^{7/3}\right) + C = \frac{15}{7}x^{7/3} + C$$
  • (d) $\displaystyle \int \frac{x^3 - 2x^2 + 1}{x^2}\,dx$: $$\int \left(x - 2 + x^{-2}\right)dx = \frac{1}{2}x^2 - 2x - \frac{1}{x} + C$$
Example 3 & Example 4 (Textbook pp. 173–174) — Exponential & Trigonometric Integrals
  • Ex 3(a): $\displaystyle \int \frac{e^x + 1}{e^x}\,dx = \int (1 + e^{-x})\,dx = x - e^{-x} + C$
  • Ex 3(b): $\displaystyle \int (e^x + 2^x)\,dx = e^x + \frac{1}{\ln 2}2^x + C$
  • Ex 4(a): $\displaystyle \int (8\cos x - 5\sin x)\,dx = 8\sin x + 5\cos x + C$
  • Ex 4(d): $\displaystyle \int (1 + \tan^2 x)\,dx = \int \sec^2 x\,dx = \tan x + C$
Example 5 (Textbook pp. 176–177) — Integrating $f(ax + b)$ and $\cos^2 x$, $\sin^2 x$
  • (a) $\displaystyle \int \frac{1}{\sqrt{3x + 1}}\,dx$: $$\int (3x + 1)^{-1/2}\,dx = \frac{1}{3 \cdot \frac{1}{2}}(3x + 1)^{1/2} + C = \frac{2}{3}\sqrt{3x + 1} + C$$
  • (b) $\displaystyle \int \frac{1}{9x - 2}\,dx = \frac{1}{9}\ln|9x - 2| + C$
  • (c) $\displaystyle \int e^{3x - 2}\,dx = \frac{1}{3}e^{3x - 2} + C$
  • (e) $\displaystyle \int \cos^2 x\,dx$: Using $\cos^2 x = \dfrac{1}{2}(1 + \cos 2x)$: $$\int \cos^2 x\,dx = \frac{1}{2}\int (1 + \cos 2x)\,dx = \frac{1}{2}\left(x + \frac{1}{2}\sin 2x\right) + C = \frac{1}{2}x + \frac{1}{4}\sin 2x + C$$
  • (f) $\displaystyle \int \sin^2 x\,dx$: Using $\sin^2 x = \dfrac{1}{2}(1 - \cos 2x)$: $$\int \sin^2 x\,dx = \frac{1}{2}\int (1 - \cos 2x)\,dx = \frac{1}{2}x - \frac{1}{4}\sin 2x + C$$
