Antiderivatives and Fundamental Integration Rules

Concept — Antiderivatives & Indefinite Integration

Integration is the inverse operation of differentiation. Given a function $f(x)$, we seek a function $F(x)$ whose derivative is $f(x)$:

  • Antiderivative: If $F'(x) = f(x)$, then $F(x)$ is called an antiderivative of $f(x)$.
  • Indefinite Integral (မရေရာကိန်းပြည့်): Since any constant $C$ has derivative $0$, if $F'(x) = f(x)$, then $\dfrac{d}{dx}\bigl[F(x) + C\bigr] = f(x)$ for every constant $C$. We write: $$\int f(x)\,dx = F(x) + C$$ where $f(x)$ is the integrand, $x$ is the variable of integration, and $C$ is the constant of integration.
  • Linearity Rules of Integration: For continuous functions $f(x), g(x)$ and any constant $k \in \mathbb{R}$: $$\int k\,dx = kx + C, \qquad \int k f(x)\,dx = k\int f(x)\,dx, \qquad \int \bigl[f(x) \pm g(x)\bigr]\,dx = \int f(x)\,dx \pm \int g(x)\,dx$$
Core Formulas — Fundamental Integrals & Linear Argument $f(ax + b)$
$$\int x^n\,dx = \frac{1}{n + 1}x^{n + 1} + C \quad (n \neq -1) \qquad\qquad \int \frac{1}{x}\,dx = \ln|x| + C \quad (x \neq 0)$$
  • Exponential Integrals: $\displaystyle \int e^x\,dx = e^x + C$,   $\displaystyle \int a^x\,dx = \frac{1}{\ln a}a^x + C \quad (a > 0,\, a \neq 1)$.
  • Trigonometric Integrals: $\displaystyle \int \cos x\,dx = \sin x + C$,   $\displaystyle \int \sin x\,dx = -\cos x + C$,   $\displaystyle \int \sec^2 x\,dx = \tan x + C$.
  • Linear Composite Rule $\int f'(ax + b)\,dx = \frac{1}{a}f(ax + b) + C$ ($a \neq 0$):
    • $\displaystyle \int (ax + b)^n\,dx = \frac{1}{a(n + 1)}(ax + b)^{n + 1} + C \quad (n \neq -1)$,   $\displaystyle \int \frac{1}{ax + b}\,dx = \frac{1}{a}\ln|ax + b| + C$.
    • $\displaystyle \int \cos(ax + b)\,dx = \frac{1}{a}\sin(ax + b) + C$,   $\displaystyle \int \sin(ax + b)\,dx = -\frac{1}{a}\cos(ax + b) + C$,   $\displaystyle \int \sec^2(ax + b)\,dx = \frac{1}{a}\tan(ax + b) + C$.
    • $\displaystyle \int e^{px + q}\,dx = \frac{1}{p}e^{px + q} + C$,   $\displaystyle \int a^{px + q}\,dx = \frac{1}{p\ln a}a^{px + q} + C$.
  • Half-Angle Identities for $\cos^2 x$ and $\sin^2 x$ (Example 5): $$\int \cos^2 x\,dx = \frac{1}{2}\int (1 + \cos 2x)\,dx = \frac{1}{2}x + \frac{1}{4}\sin 2x + C, \qquad \int \sin^2 x\,dx = \frac{1}{2}\int (1 - \cos 2x)\,dx = \frac{1}{2}x - \frac{1}{4}\sin 2x + C$$
Why $\int \frac{1}{x}\,dx = \ln|x| + C$ for Both Positive and Negative $x$

When $n = -1$, the power rule $\frac{1}{n+1}x^{n+1}$ fails because of division by zero. Instead, we check the derivative of $\ln|x|$ on both $(0, \infty)$ and $(-\infty, 0)$:

  • For $x > 0$: $|x| = x$, so $\dfrac{d}{dx}(\ln|x|) = \dfrac{d}{dx}(\ln x) = \dfrac{1}{x}$.
  • For $x < 0$: $|x| = -x > 0$, so by the Chain Rule, $\dfrac{d}{dx}(\ln|x|) = \dfrac{d}{dx}\bigl(\ln(-x)\bigr) = \dfrac{1}{-x}(-1) = \dfrac{1}{x}$.

Therefore, $\displaystyle \int \frac{1}{x}\,dx = \ln|x| + C$ holds for all $x \neq 0$.

Worked Examples — Textbook Examples 2, 3, 4 & 5

Example 2 (Textbook p. 172): Evaluate each of the following integrals:
(a) $\displaystyle \int (4x^5 + 1)\,dx$   (b) $\displaystyle \int \left(x^8 - x^3 + \frac{3}{x}\right)dx$   (c) $\displaystyle \int 5x\sqrt[3]{x}\,dx$   (d) $\displaystyle \int \frac{x^3 - 2x^2 + 1}{x^2}\,dx$.

Show step-by-step solution
  • (a) $\displaystyle \int (4x^5 + 1)\,dx = 4\left(\frac{x^6}{6}\right) + x + C = \frac{2}{3}x^6 + x + C$.
  • (b) $\displaystyle \int \left(x^8 - x^3 + \frac{3}{x}\right)dx = \frac{1}{9}x^9 - \frac{1}{4}x^4 + 3\ln|x| + C$.
  • (c) $\displaystyle \int 5x\sqrt[3]{x}\,dx = 5\int x^{4/3}\,dx = 5\left(\frac{3}{7}x^{7/3}\right) + C = \frac{15}{7}x^{7/3} + C$.
  • (d) $\displaystyle \int \frac{x^3 - 2x^2 + 1}{x^2}\,dx = \int \left(x - 2 + x^{-2}\right)dx = \frac{1}{2}x^2 - 2x - \frac{1}{x} + C$.

Answer: (a) $\frac{2}{3}x^6 + x + C$; (b) $\frac{1}{9}x^9 - \frac{1}{4}x^4 + 3\ln|x| + C$; (c) $\frac{15}{7}x^{7/3} + C$; (d) $\frac{1}{2}x^2 - 2x - \frac{1}{x} + C$.

Example 3 & Example 4 (Textbook pp. 173–174): Evaluate:
(a) $\displaystyle \int (e^x + 2^x)\,dx$   (b) $\displaystyle \int \left(e^{x\log 5} + \frac{1}{x^2}\right)dx$   (c) $\displaystyle \int \frac{e^x - \sqrt{x}}{2}\,dx$   (d) $\displaystyle \int (1 + \tan^2 x)\,dx$.

Show step-by-step solution
  • (a) $\displaystyle \int (e^x + 2^x)\,dx = e^x + \frac{1}{\ln 2}2^x + C$.
  • (b) Note that $e^{x\log 5}$ has constant factor $\log 5$ in the exponent (or if $\log 5$ is multiplied by $e^x$, $\int e^x\log 5\,dx = e^x\log 5$), so $\displaystyle \int \left(e^x\log 5 + x^{-2}\right)dx = e^x\log 5 - \frac{1}{x} + C$.
  • (c) $\displaystyle \frac{1}{2}\int \left(e^x - x^{1/2}\right)dx = \frac{1}{2}e^x - \frac{1}{3}x^{3/2} + C$.
  • (d) Using $1 + \tan^2 x = \sec^2 x$: $\displaystyle \int (1 + \tan^2 x)\,dx = \int \sec^2 x\,dx = \tan x + C$.

Answer: (a) $e^x + \frac{2^x}{\ln 2} + C$; (b) $e^x\log 5 - \frac{1}{x} + C$; (c) $\frac{1}{2}e^x - \frac{1}{3}x^{3/2} + C$; (d) $\tan x + C$.

Example 5 (Textbook pp. 176–177): Evaluate:
(a) $\displaystyle \int \frac{1}{\sqrt{3x + 1}}\,dx$   (b) $\displaystyle \int \frac{1}{9x - 2}\,dx$   (c) $\displaystyle \int \cos^2 x\,dx$   (d) $\displaystyle \int \sin^2 x\,dx$.

Show step-by-step solution
  • (a) $\displaystyle \int (3x + 1)^{-1/2}\,dx = \frac{1}{3 \cdot \frac{1}{2}}(3x + 1)^{1/2} + C = \frac{2}{3}\sqrt{3x + 1} + C$.
  • (b) $\displaystyle \int \frac{1}{9x - 2}\,dx = \frac{1}{9}\ln|9x - 2| + C$.
  • (c) Using $\cos^2 x = \dfrac{1}{2}(1 + \cos 2x)$: $\displaystyle \int \cos^2 x\,dx = \frac{1}{2}\int (1 + \cos 2x)\,dx = \frac{1}{2}x + \frac{1}{4}\sin 2x + C$.
  • (d) Using $\sin^2 x = \dfrac{1}{2}(1 - \cos 2x)$: $\displaystyle \int \sin^2 x\,dx = \frac{1}{2}\int (1 - \cos 2x)\,dx = \frac{1}{2}x - \frac{1}{4}\sin 2x + C$.

Answer: (a) $\frac{2}{3}\sqrt{3x+1} + C$; (b) $\frac{1}{9}\ln|9x-2| + C$; (c) $\frac{1}{2}x + \frac{1}{4}\sin 2x + C$; (d) $\frac{1}{2}x - \frac{1}{4}\sin 2x + C$.

Common Mistakes to Avoid
  • Forgetting the Factor $\frac{1}{a}$ When Integrating $f(ax + b)$: Always divide by the coefficient $a$ of $x$ (for instance, $\int \cos 2x\,dx = \frac{1}{2}\sin 2x + C$, not $\sin 2x + C$).
  • Omitting the Constant of Integration $C$: Every indefinite integral represents a family of functions and must end with $+ C$.
Key Takeaways
  • $F(x)$ is an antiderivative of $f(x)$ if $F'(x) = f(x)$, and $\int f(x)\,dx = F(x) + C$.
  • $\int x^n\,dx = \frac{1}{n+1}x^{n+1} + C$ for $n \neq -1$, and $\int \frac{1}{x}\,dx = \ln|x| + C$.
  • Reversing the chain rule on a linear inner function gives $\int f'(ax + b)\,dx = \frac{1}{a}f(ax + b) + C$.
