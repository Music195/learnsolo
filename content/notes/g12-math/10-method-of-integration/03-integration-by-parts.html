Integration by Parts

Concept — Reversing the Product Rule (Integration by Parts)

When an integrand is a product of two functions that cannot be simplified by substitution — such as $x e^x$, $x \sin x$, $\ln x$, or $e^x \sin x$ — we use integration by parts (အပိုင်းလိုက်ကိန်းပြည့်ရှာခြင်း), which is derived directly from the product rule of differentiation:

  • Product Rule: $\dfrac{d}{dx}\bigl[u(x)v(x)\bigr] = u'(x)v(x) + u(x)v'(x)$.
  • 4-Step Procedure for Integration by Parts (Textbook p. 184):
    1. Step 1: Choose $u = u(x)$ and $dv = v'(x)\,dx$. (Tip: Choose $u$ so that $du$ is simpler than $u$, such as $\ln x$ or a power $x^n$, and choose $dv$ so that it is easy to integrate.)
    2. Step 2: Differentiate $u$ to find $du = u'(x)\,dx$, and integrate $dv$ to find $v = \int v'(x)\,dx$.
    3. Step 3: Substitute into the formula $\displaystyle \int u\,dv = uv - \int v\,du$.
    4. Step 4: Evaluate $\displaystyle \int v\,du$ and simplify.
Core Formulas — Integration by Parts
$$\int u\,dv = uv - \int v\,du \qquad\Longleftrightarrow\qquad \int u(x)v'(x)\,dx = u(x)v(x) - \int v(x)u'(x)\,dx$$
  • Standard Choices for $u$ and $dv$ in Grade 12 Mathematics:
    • For $\int x^n e^{ax}\,dx$, $\int x^n \sin(ax)\,dx$, $\int x^n \cos(ax)\,dx$: choose $u = x^n$ and $dv = e^{ax}\,dx$ (or $\sin/\cos$).
    • For $\int \ln x\,dx$ or $\int x^n \ln x\,dx$: always choose $u = \ln x$ and $dv = dx$ (or $x^n\,dx$).
    • For $\int e^{ax}\sin(bx)\,dx$ or $\int e^{ax}\cos(bx)\,dx$: apply integration by parts twice and solve algebraically for the original integral $I$.
Why Cyclic Integration by Parts Works for $I = \int e^x\sin x\,dx$ (Example 8e)

Let $I = \displaystyle \int e^x\sin x\,dx$. In the first application, set $u = e^x$ ($du = e^x\,dx$) and $dv = \sin x\,dx$ ($v = -\cos x$):

$$I = -e^x\cos x - \int (-\cos x)e^x\,dx = -e^x\cos x + \int e^x\cos x\,dx \qquad (1)$$

In the second application on $\int e^x\cos x\,dx$, again set $u = e^x$ ($du = e^x\,dx$) and $dv = \cos x\,dx$ ($v = \sin x$):

$$\int e^x\cos x\,dx = e^x\sin x - \int e^x\sin x\,dx = e^x\sin x - I \qquad (2)$$

Substituting $(2)$ into $(1)$ makes the original integral $I$ reappear with a minus sign:

$$I = -e^x\cos x + e^x\sin x - I \implies 2I = e^x(\sin x - \cos x) \implies I = \frac{1}{2}e^x(\sin x - \cos x) + C$$

Worked Examples — Textbook Example 8(a)–(f) (pp. 185–187)

Example 8(a) & 8(b): Evaluate:
(a) $\displaystyle \int x e^x\,dx$   (b) $\displaystyle \int \ln x\,dx$.

Show step-by-step solution

(a) $\displaystyle \int x e^x\,dx$: Let $u = x$ and $dv = e^x\,dx$. Then $du = dx$ and $v = e^x$:

$$\int x e^x\,dx = x e^x - \int e^x\,dx = x e^x - e^x + C = (x - 1)e^x + C$$

(b) $\displaystyle \int \ln x\,dx$: Let $u = \ln x$ and $dv = dx$. Then $du = \dfrac{1}{x}\,dx$ and $v = x$:

$$\int \ln x\,dx = x\ln x - \int x \cdot \frac{1}{x}\,dx = x\ln x - \int 1\,dx = x\ln x - x + C$$

Answer: (a) $x e^x - e^x + C$; (b) $x\ln x - x + C$.

Example 8(c) & 8(d): Evaluate:
(c) $\displaystyle \int x\cos x\,dx$   (d) $\displaystyle \int x\sin x\,dx$.

Show step-by-step solution

(c) $\displaystyle \int x\cos x\,dx$: Let $u = x$ ($du = dx$) and $dv = \cos x\,dx$ ($v = \sin x$):

$$\int x\cos x\,dx = x\sin x - \int \sin x\,dx = x\sin x + \cos x + C$$

(d) $\displaystyle \int x\sin x\,dx$: Let $u = x$ ($du = dx$) and $dv = \sin x\,dx$ ($v = -\cos x$):

$$\int x\sin x\,dx = -x\cos x - \int (-\cos x)\,dx = -x\cos x + \sin x + C$$

Answer: (c) $x\sin x + \cos x + C$; (d) $-x\cos x + \sin x + C$.

Example 8(f): Evaluate $\displaystyle \int x^2 \ln x\,dx$.

Show step-by-step solution

Let $u = \ln x$ and $dv = x^2\,dx$. Then $du = \dfrac{1}{x}\,dx$ and $v = \dfrac{x^3}{3}$:

$$\int x^2 \ln x\,dx = \frac{x^3}{3}\ln x - \int \frac{x^3}{3} \cdot \frac{1}{x}\,dx = \frac{x^3}{3}\ln x - \frac{1}{3}\int x^2\,dx = \frac{x^3}{3}\ln x - \frac{x^3}{9} + C$$

Answer: $\frac{x^3}{3}\ln x - \frac{x^3}{9} + C$.

Common Mistakes to Avoid
  • Choosing $u = x^2$ and $dv = \ln x\,dx$ in $\int x^2\ln x\,dx$: Whenever $\ln x$ is part of a product with $x^n$, always set $u = \ln x$ so that $du = \frac{1}{x}\,dx$ eliminates the logarithm.
  • Switching Roles of $u$ and $dv$ Midway Through $\int e^x\sin x\,dx$: In cyclic integration by parts, if you choose $u = e^x$ in the first step, you must also choose $u = e^x$ in the second step (otherwise the second step simply undoes the first!).
Key Takeaways
  • Integration by parts states that $\int u\,dv = uv - \int v\,du$.
  • To integrate $\ln x$ alone, write $\int (\ln x)(1\,dx)$ with $u = \ln x$ and $dv = dx$, obtaining $x\ln x - x + C$.
  • Products of exponential and sine/cosine functions require two applications of integration by parts followed by solving for $I$.
