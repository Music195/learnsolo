Chapter 10: Method of Integration

10.4 Partial Fraction Method & Finding Functions from Derivatives

Rational functions whose denominators factor into linear terms can be decomposed into simpler partial fractions that integrate directly to logarithms and powers, while initial conditions determine the exact constant of integration $C$.

1. Partial Fraction Decomposition for Rational Integrals

To integrate a proper rational function $\dfrac{P(x)}{Q(x)}$ (where $\deg P < \deg Q$), we factor the denominator $Q(x)$ and split the fraction into a sum of simpler partial fractions:

Case 1: Distinct Linear Factors

If the denominator factors into distinct linear terms $(ax + b)(cx + d)$, we write: $$\frac{px + q}{(ax + b)(cx + d)} = \frac{A}{ax + b} + \frac{B}{cx + d}$$ Integrating term by term gives: $$\frac{A}{a}\ln|ax + b| + \frac{B}{c}\ln|cx + d| + C$$

Case 2: Repeated Linear Factors

If the denominator contains a repeated linear factor $(x - a)^2$, we write: $$\frac{px + q}{(x - a)^2} = \frac{A}{x - a} + \frac{B}{(x - a)^2}$$ Integrating term by term gives: $$A\ln|x - a| - \frac{B}{x - a} + C$$

3. Worked Textbook Examples (Partial Fractions)

Example 9 & Example 10 (Textbook pp. 187–189) — Distinct Linear Factors

(a) Example 9: Evaluate $\displaystyle \int \frac{1}{x^2 + 2x - 3}\,dx$.
Since $x^2 + 2x - 3 = (x + 3)(x - 1)$, we write: $$\frac{1}{(x + 3)(x - 1)} = \frac{A}{x + 3} + \frac{B}{x - 1} \implies 1 = A(x - 1) + B(x + 3)$$ Equating coefficients gives $A + B = 0$ and $-A + 3B = 1$, so $A = -\dfrac{1}{4}$ and $B = \dfrac{1}{4}$. Therefore: $$\int \frac{1}{x^2 + 2x - 3}\,dx = -\frac{1}{4}\int \frac{1}{x + 3}\,dx + \frac{1}{4}\int \frac{1}{x - 1}\,dx = -\frac{1}{4}\ln|x + 3| + \frac{1}{4}\ln|x - 1| + C = \frac{1}{4}\ln\left|\frac{x - 1}{x + 3}\right| + C$$

(b) Example 10: Evaluate $\displaystyle \int \frac{1}{2x^2 + 3x + 1}\,dx$.
Factor $2x^2 + 3x + 1 = (2x + 1)(x + 1)$ and write: $$\frac{1}{(2x + 1)(x + 1)} = \frac{A}{2x + 1} + \frac{B}{x + 1} \implies 1 = A(x + 1) + B(2x + 1)$$ Setting $x = -1$ gives $1 = B(-1) \implies B = -1$. Setting $x = -\dfrac{1}{2}$ gives $1 = A\left(\dfrac{1}{2}\right) \implies A = 2$. Thus: $$\int \frac{1}{2x^2 + 3x + 1}\,dx = \int \frac{2}{2x + 1}\,dx - \int \frac{1}{x + 1}\,dx = \ln|2x + 1| - \ln|x + 1| + C = \ln\left|\frac{2x + 1}{x + 1}\right| + C$$

Example 11 & Example 12 (Textbook pp. 189–191) — Improper Rational & Repeated Factor

(a) Example 11: Evaluate $\displaystyle \int \frac{x^3 - 4x + 4}{x^2 - 4}\,dx$.
Divide first: $\dfrac{x^3 - 4x + 4}{x^2 - 4} = x + \dfrac{4}{x^2 - 4}$. Next, decompose $\dfrac{4}{(x + 2)(x - 2)} = \dfrac{A}{x + 2} + \dfrac{B}{x - 2} = -\dfrac{1}{x + 2} + \dfrac{1}{x - 2}$. Integrating: $$\int \left(x - \frac{1}{x + 2} + \frac{1}{x - 2}\right)dx = \frac{1}{2}x^2 - \ln|x + 2| + \ln|x - 2| + C = \frac{1}{2}x^2 + \ln\left|\frac{x - 2}{x + 2}\right| + C$$

(b) Example 12: Evaluate $\displaystyle \int \frac{2x + 1}{(x - 1)^2}\,dx$.
Write $\dfrac{2x + 1}{(x - 1)^2} = \dfrac{A}{x - 1} + \dfrac{B}{(x - 1)^2} \implies 2x + 1 = A(x - 1) + B = Ax + (-A + B)$.
Equating coefficients gives $A = 2$ and $-A + B = 1 \implies B = 3$. Therefore: $$\int \frac{2x + 1}{(x - 1)^2}\,dx = \int \frac{2}{x - 1}\,dx + \int \frac{3}{(x - 1)^2}\,dx = 2\ln|x - 1| - \frac{3}{x - 1} + C$$

4. Finding $f(x)$ from Initial Conditions (Examples 13 & 14)

Example 13 (Textbook p. 191) — First-Order Initial Value Problem

Find the function $f(x)$ satisfying the equation $f'(x) = \dfrac{x - 1}{\sqrt{x}}$ with $f(1) = 0$.

Solution:

Integrating $f'(x)$ with respect to $x$: $$f(x) = \int \frac{x - 1}{\sqrt{x}}\,dx = \int \left(x^{1/2} - x^{-1/2}\right)dx = \frac{2}{3}x^{3/2} - 2x^{1/2} + C$$ Since $f(1) = 0$, we substitute $x = 1$: $$0 = \frac{2}{3}(1)^{3/2} - 2(1)^{1/2} + C \implies C = 2 - \frac{2}{3} = \frac{4}{3}$$ Therefore, $f(x) = \dfrac{2}{3}x^{3/2} - 2x^{1/2} + \dfrac{4}{3}$.

Example 14 (Textbook pp. 191–192) — Second-Order Initial Value Problem

Find the function $f(x)$ satisfying $f''(x) = \dfrac{e^x - e^{-x}}{2}$ with $f'(0) = 1$ and $f(0) = 1$.

Solution:

Integrating $f''(x)$ once gives: $$f'(x) = \int \frac{e^x - e^{-x}}{2}\,dx = \frac{1}{2}\left(e^x + e^{-x}\right) + C_1$$ Using $f'(0) = 1$: $$1 = \frac{1}{2}\left(e^0 + e^0\right) + C_1 = 1 + C_1 \implies C_1 = 0 \implies f'(x) = \frac{1}{2}\left(e^x + e^{-x}\right)$$ Integrating a second time gives: $$f(x) = \int \frac{e^x + e^{-x}}{2}\,dx = \frac{1}{2}\left(e^x - e^{-x}\right) + C_2$$ Using $f(0) = 1$: $$1 = \frac{1}{2}\left(e^0 - e^0\right) + C_2 = 0 + C_2 \implies C_2 = 1$$ Therefore, $f(x) = \dfrac{1}{2}\left(e^x - e^{-x}\right) + 1$.
