Partial Fraction Method and Initial Value Problems

Concept — Partial Fraction Decomposition & Initial Value Problems

This final section of Chapter 10 introduces two essential techniques:

  • Partial Fraction Method (အပိုင်းကိန်းခွဲထုတ်နည်း): Expressing a rational function $\dfrac{P(x)}{Q(x)}$ whose denominator factors into linear factors as a sum of simpler fractions that can be integrated immediately using logarithms and power rules. (If $\deg P \ge \deg Q$, perform polynomial division first, as in Example 11.)
  • Finding $f(x)$ from Initial Conditions (Examples 13 & 14): When given a derivative equation $f'(x) = g(x)$ together with a known value $f(x_0) = y_0$ (or $f''(x)$ with two conditions $f'(x_0)$ and $f(x_0)$), integrating and substituting the given point determines the unique constant $C$.
Core Formulas — Partial Fraction Forms
  • Case 1 — Distinct Linear Factors: $$\frac{px + q}{(ax + b)(cx + d)} = \frac{A}{ax + b} + \frac{B}{cx + d} \implies \int \frac{px + q}{(ax + b)(cx + d)}\,dx = \frac{A}{a}\ln|ax + b| + \frac{B}{c}\ln|cx + d| + C$$
  • Case 2 — Repeated Linear Factors: $$\frac{px + q}{(x - a)^2} = \frac{A}{x - a} + \frac{B}{(x - a)^2} \implies \int \frac{px + q}{(x - a)^2}\,dx = A\ln|x - a| - \frac{B}{x - a} + C$$
How to Find the Unknown Constants $A$ and $B$

After writing $\dfrac{px + q}{(ax + b)(cx + d)} = \dfrac{A}{ax + b} + \dfrac{B}{cx + d}$, clear denominators to obtain the polynomial identity:

$$px + q = A(cx + d) + B(ax + b)$$

You can determine $A$ and $B$ by either of two equivalent methods:

  1. Equating Coefficients (Example 9 & 12): Expand the right-hand side, collect like powers of $x$, and equate coefficients of $x$ and the constant term.
  2. Strategic Substitution (Example 10 & 11): Substitute the roots $x = -\frac{b}{a}$ and $x = -\frac{d}{c}$ into the identity to solve for $A$ and $B$ directly in one step.

Worked Examples — Textbook Examples 9, 10, 11, 12, 13 & 14

Example 9 & Example 10 (Textbook pp. 187–189): Evaluate:
(a) $\displaystyle \int \frac{1}{x^2 + 2x - 3}\,dx$   (b) $\displaystyle \int \frac{1}{2x^2 + 3x + 1}\,dx$.

Show step-by-step solution

(a) Example 9: Factor $x^2 + 2x - 3 = (x + 3)(x - 1)$ and write $\dfrac{1}{(x + 3)(x - 1)} = \dfrac{A}{x + 3} + \dfrac{B}{x - 1} \implies 1 = A(x - 1) + B(x + 3)$.

Equating coefficients gives $A + B = 0$ and $-A + 3B = 1 \implies A = -\dfrac{1}{4},\; B = \dfrac{1}{4}$. Integrating gives:

$$-\frac{1}{4}\ln|x + 3| + \frac{1}{4}\ln|x - 1| + C = \frac{1}{4}\ln\left|\frac{x - 1}{x + 3}\right| + C$$

(b) Example 10: Factor $2x^2 + 3x + 1 = (2x + 1)(x + 1)$ and write $1 = A(x + 1) + B(2x + 1)$.

Setting $x = -1 \implies B = -1$; setting $x = -\dfrac{1}{2} \implies A = 2$. Integrating gives:

$$\int \frac{2}{2x + 1}\,dx - \int \frac{1}{x + 1}\,dx = \ln|2x + 1| - \ln|x + 1| + C = \ln\left|\frac{2x + 1}{x + 1}\right| + C$$

Answer: (a) $\frac{1}{4}\ln\left|\frac{x-1}{x+3}\right| + C$; (b) $\ln\left|\frac{2x+1}{x+1}\right| + C$.

Example 11 & Example 12 (Textbook pp. 189–191): Evaluate:
(a) $\displaystyle \int \frac{x^3 - 4x + 4}{x^2 - 4}\,dx$   (b) $\displaystyle \int \frac{2x + 1}{(x - 1)^2}\,dx$.

Show step-by-step solution

(a) Example 11: Divide first: $\dfrac{x^3 - 4x + 4}{x^2 - 4} = x + \dfrac{4}{(x + 2)(x - 2)} = x - \dfrac{1}{x + 2} + \dfrac{1}{x - 2}$. Integrating gives:

$$\frac{1}{2}x^2 - \ln|x + 2| + \ln|x - 2| + C = \frac{1}{2}x^2 + \ln\left|\frac{x - 2}{x + 2}\right| + C$$

(b) Example 12: Write $\dfrac{2x + 1}{(x - 1)^2} = \dfrac{A}{x - 1} + \dfrac{B}{(x - 1)^2} \implies 2x + 1 = A(x - 1) + B \implies A = 2,\; B = 3$. Integrating gives:

$$\int \frac{2}{x - 1}\,dx + \int \frac{3}{(x - 1)^2}\,dx = 2\ln|x - 1| - \frac{3}{x - 1} + C$$

Answer: (a) $\frac{1}{2}x^2 + \ln\left|\frac{x-2}{x+2}\right| + C$; (b) $2\ln|x-1| - \frac{3}{x-1} + C$.

Example 13 & Example 14 (Textbook pp. 191–192):
(a) Find $f(x)$ satisfying $f'(x) = \dfrac{x - 1}{\sqrt{x}}$ with $f(1) = 0$.
(b) Find $f(x)$ satisfying $f''(x) = \dfrac{e^x - e^{-x}}{2}$ with $f'(0) = 1$ and $f(0) = 1$.

Show step-by-step solution

(a) Example 13: $f(x) = \displaystyle \int \left(x^{1/2} - x^{-1/2}\right)dx = \frac{2}{3}x^{3/2} - 2x^{1/2} + C$. Using $f(1) = 0 \implies \frac{2}{3} - 2 + C = 0 \implies C = \frac{4}{3}$, so $f(x) = \frac{2}{3}x^{3/2} - 2x^{1/2} + \frac{4}{3}$.

(b) Example 14: Integrating once gives $f'(x) = \frac{1}{2}(e^x + e^{-x}) + C_1$. Since $f'(0) = 1 \implies 1 + C_1 = 1 \implies C_1 = 0$. Integrating again gives $f(x) = \frac{1}{2}(e^x - e^{-x}) + C_2$. Since $f(0) = 1 \implies 0 + C_2 = 1 \implies C_2 = 1$, so $f(x) = \frac{1}{2}(e^x - e^{-x}) + 1$.

Answer: (a) $f(x) = \frac{2}{3}x^{3/2} - 2x^{1/2} + \frac{4}{3}$; (b) $f(x) = \frac{1}{2}(e^x - e^{-x}) + 1$.

Common Mistakes to Avoid
  • Integrating $(x - 1)^{-2}$ as a Logarithm: Only $(x - 1)^{-1}$ integrates to $\ln|x - 1|$; higher powers $(x - 1)^{-2}$ use the power rule to give $-(x - 1)^{-1}$.
  • Applying Partial Fractions Without Checking Degree: If the degree of the numerator is greater than or equal to the degree of the denominator (as in Example 11), divide polynomials first!
Key Takeaways
  • Distinct linear factors split as $\frac{A}{ax+b} + \frac{B}{cx+d}$; repeated linear factors split as $\frac{A}{x-a} + \frac{B}{(x-a)^2}$.
  • Given $f'(x)$ and an initial condition $f(x_0) = y_0$, integrate to get $F(x) + C$ and solve $F(x_0) + C = y_0$ for $C$.
