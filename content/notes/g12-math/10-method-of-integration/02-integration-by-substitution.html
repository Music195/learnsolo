Chapter 10: Method of Integration

10.2 Substitution Method

The substitution method is the integral counterpart of the chain rule, transforming composite integrals of the form $\int f(g(x))g'(x)\,dx$ into simpler integrals $\int f(u)\,du$.

1. Differentials and the Substitution Principle

Let $y = f(x)$ be a differentiable function. For an independent differential $dx$, the dependent differential $dy$ is defined by: $$dy = f'(x)\,dx$$

Substitution Rule for Indefinite Integrals

Suppose $g$ is a differentiable function and $f$ is continuous on the range of $g$. If we set $u = g(x)$, then $du = g'(x)\,dx$ and: $$\int f(g(x))g'(x)\,dx = \int f(u)\,du$$

Basic 5-Step Procedure:

  1. Step 1: Select a substitution $u = g(x)$ (such as an inner function under a power, radical, exponent, or denominator).
  2. Step 2: Differentiate the substitution to find $du = g'(x)\,dx$ and express $dx$ in terms of $du$.
  3. Step 3: Substitute to transform the entire integral from the $x$-variable into the $u$-variable.
  4. Step 4: Integrate with respect to $u$.
  5. Step 5: Replace $u$ by $g(x)$ to write the final answer in terms of $x$.
Logarithmic Derivative Pattern & Secant/Cosecant Integrals
  • Logarithmic Pattern: When the numerator is the derivative of the denominator ($u = g(x),\, du = g'(x)\,dx$): $$\int \frac{g'(x)}{g(x)}\,dx = \int \frac{1}{u}\,du = \ln|u| + C = \ln|g(x)| + C$$
  • Integral of Secant: Multiplying and dividing by $\sec x + \tan x$ and setting $u = \sec x + \tan x$ ($du = (\sec x \tan x + \sec^2 x)\,dx$): $$\int \sec x\,dx = \int \frac{\sec^2 x + \sec x \tan x}{\sec x + \tan x}\,dx = \ln|\sec x + \tan x| + C$$
  • Integral of Cosecant: Multiplying and dividing by $\csc x + \cot x$ and setting $u = \csc x + \cot x$ ($du = -(\csc x \cot x + \csc^2 x)\,dx$): $$\int \csc x\,dx = -\ln|\csc x + \cot x| + C$$

3. Worked Textbook Examples

Example 6 (Textbook pp. 179–181) — Algebraic and Trigonometric Substitutions
  • (a) $\displaystyle \int x e^{x^2}\,dx$: Let $u = x^2$. Then $du = 2x\,dx \implies x\,dx = \dfrac{1}{2}\,du$. $$\int x e^{x^2}\,dx = \int e^u \left(\frac{1}{2}\,du\right) = \frac{1}{2}e^u + C = \frac{1}{2}e^{x^2} + C$$
  • (b) $\displaystyle \int \sin^3 x \cos x\,dx$: Let $u = \sin x$. Then $du = \cos x\,dx$. $$\int \sin^3 x \cos x\,dx = \int u^3\,du = \frac{1}{4}u^4 + C = \frac{1}{4}\sin^4 x + C$$
  • (c) $\displaystyle \int x^2\left(\frac{x^3}{18} + 1\right)^5 dx$: Let $u = \dfrac{x^3}{18} + 1$. Then $du = \dfrac{1}{6}x^2\,dx \implies x^2\,dx = 6\,du$. $$\int x^2\left(\frac{x^3}{18} + 1\right)^5 dx = 6\int u^5\,du = u^6 + C = \left(\frac{x^3}{18} + 1\right)^6 + C$$
  • (d) $\displaystyle \int x\sqrt{1 - x}\,dx$: Let $u = 1 - x$. Then $x = 1 - u$ and $du = -dx$. $$\int x\sqrt{1 - x}\,dx = \int (1 - u)\sqrt{u}(-du) = \int \left(u^{3/2} - u^{1/2}\right)du = \frac{2}{5}(1 - x)^{5/2} - \frac{2}{3}(1 - x)^{3/2} + C$$
  • (e) $\displaystyle \int 8x^3\sqrt{3x^2 + 5}\,dx$: Let $u = 3x^2 + 5$. Then $x^2 = \dfrac{u - 5}{3}$ and $du = 6x\,dx \implies x\,dx = \dfrac{1}{6}\,du$. $$\int 8x^2\sqrt{3x^2 + 5}(x\,dx) = 8\int \frac{u - 5}{3}u^{1/2}\left(\frac{1}{6}\,du\right) = \frac{4}{9}\int \left(u^{3/2} - 5u^{1/2}\right)du = \frac{8}{45}(3x^2 + 5)^{5/2} - \frac{40}{27}(3x^2 + 5)^{3/2} + C$$
  • (f) $\displaystyle \int \cos^3 x\,dx$: Write $\cos^3 x = \cos^2 x \cos x = (1 - \sin^2 x)\cos x$ and let $u = \sin x$ ($du = \cos x\,dx$): $$\int (1 - u^2)\,du = u - \frac{1}{3}u^3 + C = \sin x - \frac{1}{3}\sin^3 x + C$$
Example 7 (Textbook pp. 181–182) — Logarithmic Substitutions $\int \frac{g'(x)}{g(x)}\,dx$
  • (a) $\displaystyle \int \frac{2x - 1}{x^2 - x - 6}\,dx$: Let $u = x^2 - x - 6$, so $du = (2x - 1)\,dx$: $$\int \frac{du}{u} = \ln|u| + C = \ln|x^2 - x - 6| + C$$
  • (b) $\displaystyle \int \frac{x^2 + 2x - 1}{x^2 - 1}\,dx$: Divide first: $\dfrac{x^2 + 2x - 1}{x^2 - 1} = 1 + \dfrac{2x}{x^2 - 1}$. Let $u = x^2 - 1$ ($du = 2x\,dx$): $$\int \left(1 + \frac{2x}{x^2 - 1}\right)dx = x + \ln|x^2 - 1| + C$$
  • (c) $\displaystyle \int \frac{1}{1 + e^x}\,dx$: Multiply numerator and denominator by $e^{-x}$: $$\int \frac{e^{-x}}{e^{-x} + 1}\,dx = -\int \frac{-e^{-x}}{e^{-x} + 1}\,dx = -\ln(e^{-x} + 1) + C$$
  • (d) $\displaystyle \int \tan x\,dx$: Write $\tan x = \dfrac{\sin x}{\cos x}$ and let $u = \cos x$ ($du = -\sin x\,dx$): $$\int \frac{\sin x}{\cos x}\,dx = -\int \frac{du}{u} = -\ln|\cos x| + C = \ln|\sec x| + C$$
