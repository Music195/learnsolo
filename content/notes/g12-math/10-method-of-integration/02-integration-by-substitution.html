Substitution Method

Concept — Differentials & Integration by Substitution

The substitution method transforms a complicated composite integral into a simpler integral by changing the variable of integration from $x$ to $u = g(x)$:

  • Differential of $u = g(x)$: If $g$ is differentiable, the differential $du$ is defined by $du = g'(x)\,dx$.
  • Chain Rule in Reverse: Whenever an integrand has the composite-times-derivative structure $f(g(x))g'(x)$, setting $u = g(x)$ and $du = g'(x)\,dx$ reduces the integral to: $$\int f(g(x))g'(x)\,dx = \int f(u)\,du$$
  • 5-Step Substitution Procedure (Textbook p. 179):
    1. Select a substitution $u = g(x)$ (such as an inner function under a power, radical, exponent, or denominator).
    2. Differentiate to find $du = g'(x)\,dx$ and arrange to express $dx$ in terms of $du$.
    3. Substitute to transform the entire integral from the $x$-variable into the $u$-variable.
    4. Integrate with respect to $u$.
    5. Replace $u$ by $g(x)$ to rewrite the final answer in terms of $x$.
Core Formulas — Substitution Patterns & Secant/Cosecant Integrals
$$\int f(g(x))g'(x)\,dx = \int f(u)\,du \qquad\qquad \int \frac{g'(x)}{g(x)}\,dx = \ln|g(x)| + C$$
  • Power of a Function: $\displaystyle \int \bigl[g(x)\bigr]^n g'(x)\,dx = \frac{1}{n + 1}\bigl[g(x)\bigr]^{n + 1} + C \quad (n \neq -1)$.
  • Tangent and Cotangent: $\displaystyle \int \tan x\,dx = -\ln|\cos x| + C = \ln|\sec x| + C$,   $\displaystyle \int \cot x\,dx = \ln|\sin x| + C$.
  • Secant and Cosecant (Textbook pp. 182–183): $$\int \sec x\,dx = \ln|\sec x + \tan x| + C \qquad\qquad \int \csc x\,dx = -\ln|\csc x + \cot x| + C$$
Proof — Evaluating $\int \sec x\,dx$ and $\int \csc x\,dx$ by Substitution

(a) Integral of $\sec x$: Multiply and divide $\sec x$ by $\sec x + \tan x$:

$$\int \sec x\,dx = \int \sec x \left(\frac{\sec x + \tan x}{\sec x + \tan x}\right)dx = \int \frac{\sec^2 x + \sec x\tan x}{\sec x + \tan x}\,dx$$

Let $u = \sec x + \tan x$. Then $du = (\sec x\tan x + \sec^2 x)\,dx$, which is the exact numerator! Hence:

$$\int \sec x\,dx = \int \frac{1}{u}\,du = \ln|u| + C = \ln|\sec x + \tan x| + C$$

(b) Integral of $\csc x$: Multiply and divide $\csc x$ by $\csc x + \cot x$ and set $u = \csc x + \cot x$ ($du = -(\csc x\cot x + \csc^2 x)\,dx$):

$$\int \csc x\,dx = \int \frac{\csc^2 x + \csc x\cot x}{\csc x + \cot x}\,dx = -\int \frac{1}{u}\,du = -\ln|\csc x + \cot x| + C$$

Worked Examples — Textbook Examples 6 & 7

Example 6(a)–(c) (Textbook pp. 179–180): Evaluate:
(a) $\displaystyle \int x e^{x^2}\,dx$   (b) $\displaystyle \int \sin^3 x\cos x\,dx$   (c) $\displaystyle \int x^2\left(\frac{x^3}{18} + 1\right)^5 dx$.

Show step-by-step solution
  • (a) Let $u = x^2 \implies du = 2x\,dx \implies x\,dx = \dfrac{1}{2}\,du$. Then $\displaystyle \int x e^{x^2}\,dx = \frac{1}{2}\int e^u\,du = \frac{1}{2}e^{x^2} + C$.
  • (b) Let $u = \sin x \implies du = \cos x\,dx$. Then $\displaystyle \int \sin^3 x\cos x\,dx = \int u^3\,du = \frac{1}{4}u^4 + C = \frac{1}{4}\sin^4 x + C$.
  • (c) Let $u = \dfrac{x^3}{18} + 1 \implies du = \dfrac{1}{6}x^2\,dx \implies x^2\,dx = 6\,du$. Then $\displaystyle 6\int u^5\,du = u^6 + C = \left(\frac{x^3}{18} + 1\right)^6 + C$.

Answer: (a) $\frac{1}{2}e^{x^2} + C$; (b) $\frac{1}{4}\sin^4 x + C$; (c) $\left(\frac{x^3}{18} + 1\right)^6 + C$.

Example 6(d)–(f) (Textbook pp. 180–181): Evaluate:
(d) $\displaystyle \int x\sqrt{1 - x}\,dx$   (e) $\displaystyle \int 8x^3\sqrt{3x^2 + 5}\,dx$   (f) $\displaystyle \int \cos^3 x\,dx$.

Show step-by-step solution
  • (d) Let $u = 1 - x \implies x = 1 - u$ and $du = -dx$. Then: $$\int (1 - u)u^{1/2}(-du) = \int \left(u^{3/2} - u^{1/2}\right)du = \frac{2}{5}(1 - x)^{5/2} - \frac{2}{3}(1 - x)^{3/2} + C$$
  • (e) Let $u = 3x^2 + 5 \implies x^2 = \dfrac{u - 5}{3}$ and $du = 6x\,dx \implies x\,dx = \dfrac{1}{6}\,du$. Then: $$8\int \left(\frac{u - 5}{3}\right)u^{1/2}\left(\frac{1}{6}\,du\right) = \frac{4}{9}\int \left(u^{3/2} - 5u^{1/2}\right)du = \frac{8}{45}(3x^2 + 5)^{5/2} - \frac{40}{27}(3x^2 + 5)^{3/2} + C$$
  • (f) Write $\cos^3 x = (1 - \sin^2 x)\cos x$ and let $u = \sin x$ ($du = \cos x\,dx$): $$\int (1 - u^2)\,du = u - \frac{1}{3}u^3 + C = \sin x - \frac{1}{3}\sin^3 x + C$$

Answer: (d) $\frac{2}{5}(1-x)^{5/2} - \frac{2}{3}(1-x)^{3/2} + C$; (e) $\frac{8}{45}(3x^2+5)^{5/2} - \frac{40}{27}(3x^2+5)^{3/2} + C$; (f) $\sin x - \frac{1}{3}\sin^3 x + C$.

Example 7 (Textbook pp. 181–182): Evaluate:
(a) $\displaystyle \int \frac{2x - 1}{x^2 - x - 6}\,dx$   (b) $\displaystyle \int \frac{x^2 + 2x - 1}{x^2 - 1}\,dx$   (c) $\displaystyle \int \frac{1}{1 + e^x}\,dx$   (d) $\displaystyle \int \tan x\,dx$.

Show step-by-step solution
  • (a) Let $u = x^2 - x - 6 \implies du = (2x - 1)\,dx$: $\displaystyle \int \frac{du}{u} = \ln|x^2 - x - 6| + C$.
  • (b) Rewrite as $\displaystyle \int \left(1 + \frac{2x}{x^2 - 1}\right)dx = x + \ln|x^2 - 1| + C$.
  • (c) Multiply top and bottom by $e^{-x}$: $\displaystyle \int \frac{e^{-x}}{e^{-x} + 1}\,dx = -\ln(e^{-x} + 1) + C$ (using $u = e^{-x} + 1$, $du = -e^{-x}\,dx$).
  • (d) Write $\tan x = \dfrac{\sin x}{\cos x}$ and set $u = \cos x$ ($du = -\sin x\,dx$): $\displaystyle -\int \frac{du}{u} = -\ln|\cos x| + C$.

Answer: (a) $\ln|x^2-x-6|+C$; (b) $x+\ln|x^2-1|+C$; (c) $-\ln(e^{-x}+1)+C$; (d) $-\ln|\cos x|+C$.

Common Mistakes to Avoid
  • Leaving the Final Answer in Terms of $u$: For an indefinite integral in $x$, always complete Step 5 by substituting $u = g(x)$ back into your antiderivative.
  • Mixing $x$ and $u$ Inside the Integral: After Step 3, every $x$ and $dx$ must be converted into $u$ and $du$ before integrating.
Key Takeaways
  • With $u = g(x)$ and $du = g'(x)\,dx$, $\int f(g(x))g'(x)\,dx = \int f(u)\,du$.
  • When the numerator is the derivative of the denominator, $\int \frac{g'(x)}{g(x)}\,dx = \ln|g(x)| + C$.
  • $\int \sec x\,dx = \ln|\sec x + \tan x| + C$ and $\int \csc x\,dx = -\ln|\csc x + \cot x| + C$.
