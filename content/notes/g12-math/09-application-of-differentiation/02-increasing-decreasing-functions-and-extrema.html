Chapter 9: Application of Differentiation

9.2 Increasing, Decreasing Functions, Critical Points & Extrema

The sign of the first derivative $f'(x)$ reveals whether a function is rising or falling on an interval and locates its local and global maximum and minimum values.

1. Increasing and Decreasing Functions

Let $f$ be a function defined on an interval $I$, and let $x_1, x_2$ be any two points in $I$.

Definition — Increasing and Decreasing on an Interval
  • A function $f$ is increasing on an interval $I$ if for every $x_1, x_2 \in I$: $$x_1 < x_2 \implies f(x_1) < f(x_2)$$
  • A function $f$ is decreasing on an interval $I$ if for every $x_1, x_2 \in I$: $$x_1 < x_2 \implies f(x_1) > f(x_2)$$
First Derivative Test for Monotonicity

Suppose $f$ is continuous on $[a, b]$ and differentiable on $(a, b)$:

  • If $f'(x) > 0$ for each $x \in (a, b)$, then $f$ is increasing on $[a, b]$.
  • If $f'(x) < 0$ for each $x \in (a, b)$, then $f$ is decreasing on $[a, b]$.
  • If $f'(x) = 0$ for each $x \in (a, b)$, then $f$ is constant on $[a, b]$.

2. Critical Points

Points where the derivative is zero or fails to exist are the key candidates where a function can change direction.

Definition — Critical Point and Critical Number

A point $(c, f(c))$ on the graph of $y = f(x)$ is called a critical point of $f(x)$ if $c$ is in the domain of $f$ and either: $$f'(c) = 0 \qquad \text{or} \qquad f'(c) \text{ does not exist (is undefined).}$$ The number $c$ itself is called a critical number. When $f'(c) = 0$, the point $(c, f(c))$ is also called a stationary point.

Important Caution (Example 7): For $f(x) = \dfrac{1}{x}$, $f'(x) = -\dfrac{1}{x^2}$ is undefined at $x = 0$, but $0$ is not in the domain of $f$. Therefore, $f(x) = \dfrac{1}{x}$ has no critical point.

3. Local and Global Extrema

Global (Absolute) Extrema

Let $D$ be the domain of $f$:

  • $f(c)$ is the global maximum value of $f$ on $D$ if $f(c) \ge f(x)$ for all $x \in D$.
  • $f(c)$ is the global minimum value of $f$ on $D$ if $f(c) \le f(x)$ for all $x \in D$.
Local (Relative) Extrema

Let $I$ be an open interval containing $c$:

  • $f(c)$ is a local maximum value if $f(c) \ge f(x)$ for all $x$ in some open interval containing $c$.
  • $f(c)$ is a local minimum value if $f(c) \le f(x)$ for all $x$ in some open interval containing $c$.
First Derivative Test for Local Extrema

Suppose $c$ is a critical number of a continuous function $f$:

  1. If $f'(x)$ changes sign from positive ($+$) to negative ($-$) at $c$, then $f$ has a local maximum at $c$.
  2. If $f'(x)$ changes sign from negative ($-$) to positive ($+$) at $c$, then $f$ has a local minimum at $c$.
  3. If $f'(x)$ does not change sign at $c$ (same sign on both sides of $c$), then $f$ has no local extremum at $c$.
Closed Interval Method (Global Extrema on $[a, b]$)

To find the global maximum and minimum values of a continuous function $f$ on a closed interval $[a, b]$:

  1. Find the values of $f$ at all critical numbers of $f$ in the open interval $(a, b)$.
  2. Find the values of $f$ at the endpoints $x = a$ and $x = b$.
  3. The largest of the values from Steps 1 and 2 is the global maximum value; the smallest is the global minimum value.

5. Worked Textbook Examples

Example 5 & Example 6 (Textbook pp. 149–150) — Critical Points

(a) Example 5: Find the critical point(s) of $f(x) = x^3 - 3x + 1$ and the open intervals on which $f$ is increasing or decreasing.
Solution: $f'(x) = 3x^2 - 3 = 3(x + 1)(x - 1)$. Setting $f'(x) = 0$ gives $x = -1$ and $x = 1$. Since $f(-1) = 3$ and $f(1) = -1$, the critical points are $(-1, 3)$ and $(1, -1)$.

  • On $(-\infty, -1)$: $f'(x) > 0 \implies f$ is increasing.
  • On $(-1, 1)$: $f'(x) < 0 \implies f$ is decreasing.
  • On $(1, \infty)$: $f'(x) > 0 \implies f$ is increasing.

(b) Example 6: Find the critical point of $f(x) = (x - 1)^{1/3}$.
Solution: $f'(x) = \dfrac{1}{3}(x - 1)^{-2/3} = \dfrac{1}{3(x - 1)^{2/3}}$. Here $f'(x) \ne 0$ for all $x$, and $f'(1)$ does not exist. Since $1$ is in the domain of $f$ and $f(1) = 0$, the critical point is $(1, 0)$. Because $f'(x) > 0$ for all $x \ne 1$, $f$ is increasing on $(-\infty, \infty)$.

Example 8 & Example 9 (Textbook pp. 154–155) — First Derivative Test

(a) Example 8: Find the local extrema of $f(x) = x^3 - 3x^2 + 5$.
Solution: $f'(x) = 3x^2 - 6x = 3x(x - 2) = 0 \implies x = 0, 2$.

  • At $x = 0$: $f'(x)$ changes from $+$ on $(-\infty, 0)$ to $-$ on $(0, 2)$, so $f(0) = 5$ is a local maximum value.
  • At $x = 2$: $f'(x)$ changes from $-$ on $(0, 2)$ to $+$ on $(2, \infty)$, so $f(2) = 1$ is a local minimum value.

(b) Example 9: Find the local extrema of $f(x) = (x^2 - 9)^{2/3}$.
Solution: $f'(x) = \dfrac{2}{3}(x^2 - 9)^{-1/3}(2x) = \dfrac{4x}{3(x^2 - 9)^{1/3}}$.
We have $f'(x) = 0$ at $x = 0$, and $f'(x)$ does not exist at $x = -3$ and $x = 3$. Testing signs on $(-\infty, -3)$, $(-3, 0)$, $(0, 3)$, and $(3, \infty)$ gives signs $-, +, -, +$:

  • Local minimum value at $x = -3$: $f(-3) = 0$.
  • Local maximum value at $x = 0$: $f(0) = (-9)^{2/3} = 3\sqrt[3]{9}$.
  • Local minimum value at $x = 3$: $f(3) = 0$.
Example 10 (Textbook pp. 155–156) — Global Extrema on a Closed Interval

Find the global maximum and minimum values of:

(a) $f(x) = x^2 + 5x - 3$ on $[-4, 5]$:
$f'(x) = 2x + 5 = 0 \implies x = -\dfrac{5}{2} \in (-4, 5)$. Evaluating at the critical number and endpoints: $$f\left(-\frac{5}{2}\right) = -\frac{37}{4} = -9\frac{1}{4}, \qquad f(-4) = -7, \qquad f(5) = 47$$ Global minimum is $-9\dfrac{1}{4}$ at $x = -\dfrac{5}{2}$; global maximum is $47$ at $x = 5$.

(b) $f(x) = \dfrac{x}{x^2 + 1}$ on $[-3, 3]$:
Using the quotient rule, $f'(x) = \dfrac{(x^2 + 1)(1) - x(2x)}{(x^2 + 1)^2} = \dfrac{1 - x^2}{(x^2 + 1)^2} = 0 \implies x = -1, 1 \in (-3, 3)$. Evaluating: $$f(-1) = -\frac{1}{2}, \qquad f(1) = \frac{1}{2}, \qquad f(-3) = -\frac{3}{10}, \qquad f(3) = \frac{3}{10}$$ Global minimum is $-\dfrac{1}{2}$ at $x = -1$; global maximum is $\dfrac{1}{2}$ at $x = 1$.
