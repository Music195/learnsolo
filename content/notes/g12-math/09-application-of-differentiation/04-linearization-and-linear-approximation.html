Linearization and Linear Approximation

Concept — Linearization (Tangent Line Approximation)

When we zoom in closely on a smooth curve $y = f(x)$ near a point of tangency $(a, f(a))$, the curve lies extremely close to its tangent line. We can therefore use the equation of the tangent line at $x = a$ as a simple linear approximation for $f(x)$ when $x$ is near $a$:

  • Linearization of $f$ at $x = a$: The linear function $$L(x) = f(a) + f'(a)(x - a)$$ whose graph is the tangent line to $y = f(x)$ at $(a, f(a))$.
  • Standard Linear Approximation: $f(x) \approx L(x) = f(a) + f'(a)(x - a)$ for $x$ near the center $a$.
  • Approximation Error: $|f(x) - L(x)|$, which shrinks quadratically as $x \to a$.
Core Formulas — Linearization & Error Behavior
$$L(x) = f(a) + f'(a)(x - a) \qquad\qquad f(x) \approx f(a) + f'(a)(x - a) \quad (x \text{ near } a)$$
  • $a$: Center of the approximation (chosen near $x$ so that $f(a)$ and $f'(a)$ are easy to compute exactly).
  • Concave Up ($f''(a) > 0$): The tangent line lies below the curve near $a$, so $L(x) \le f(x)$ (underestimate).
  • Concave Down ($f''(a) < 0$): The tangent line lies above the curve near $a$, so $L(x) \ge f(x)$ (overestimate).
Why the Linear Approximation Error Vanishes Faster Than $|x - a|$

By definition of the derivative at $x = a$:

$$\lim_{x \to a} \frac{f(x) - L(x)}{x - a} = \lim_{x \to a} \left[\frac{f(x) - f(a)}{x - a} - f'(a)\right] = f'(a) - f'(a) = 0$$

Thus the vertical gap $|f(x) - L(x)|$ between the curve and its tangent line not only approaches $0$ as $x \to a$, but becomes negligible even compared to the horizontal distance $|x - a|$ (for instance, in Example 17, dividing $|x - 2|$ by $10$ divides the error $|f(x) - L(x)| = (x - 2)^2$ by $100$).

Worked Examples — Textbook Examples 17, 18 & 19

Example 17 (Textbook p. 165): Find the linearization of $f(x) = x^2 + 2x$ at $x = 2$, and use it to approximate $f(2.5)$, $f(2.05)$, and $f(2.005)$.

Show step-by-step solution

Here $a = 2$, $f(2) = 2^2 + 2(2) = 8$, and $f'(x) = 2x + 2 \implies f'(2) = 6$. Therefore, the linearization at $x = 2$ is:

$$L(x) = f(2) + f'(2)(x - 2) = 8 + 6(x - 2) = 6x - 4$$
$x$ Linear Approximation $L(x) = 6x - 4$ Actual Value $f(x) = x^2 + 2x$ Error $|f(x) - L(x)|$
$2.5$ $L(2.5) = 11$ $f(2.5) = 11.25$ $0.25 = (0.5)^2$
$2.05$ $L(2.05) = 8.3$ $f(2.05) = 8.3025$ $0.0025 = (0.05)^2$
$2.005$ $L(2.005) = 8.03$ $f(2.005) = 8.030025$ $0.000025 = (0.005)^2$

Answer: $L(x) = 6x - 4$; $L(2.5) = 11$, $L(2.05) = 8.3$, $L(2.005) = 8.03$.

Example 18 (Textbook p. 166): The radius $r$ of a circle increases from $r = 5\text{ m}$ to $r = 5.01\text{ m}$. Find the linear approximation of the area $A(r) = \pi r^2$ at $r = 5$, estimate the enlarged area, and find the error.

Show step-by-step solution

For $A(r) = \pi r^2$, we have $A'(r) = 2\pi r$. At $r = 5$, $A(5) = 25\pi$ and $A'(5) = 10\pi$. Thus:

$$L(r) = A(5) + A'(5)(r - 5) = 25\pi + 10\pi(r - 5) = 10\pi r - 25\pi$$

At $r = 5.01\text{ m}$, $L(5.01) = 25\pi + 10\pi(0.01) = 25.1\pi\text{ m}^2$. Since the actual area is $A(5.01) = \pi(5.01)^2 = 25.1001\pi\text{ m}^2$, the error is $0.0001\pi\text{ m}^2$.

Answer: $L(5.01) = 25.1\pi\text{ m}^2$, error $= 0.0001\pi\text{ m}^2$.

Example 19 (Textbook p. 166): Use linear approximation to estimate the value of $\sqrt{101}$.

Show step-by-step solution

Let $f(x) = \sqrt{x}$ and choose the nearby perfect square $a = 100$. Then $f(100) = 10$ and $f'(x) = \dfrac{1}{2\sqrt{x}} \implies f'(100) = \dfrac{1}{20} = 0.05$:

$$L(x) = f(100) + f'(100)(x - 100) = 10 + \frac{1}{20}(x - 100)$$ $$\sqrt{101} \approx L(101) = 10 + \frac{1}{20}(101 - 100) = 10.05$$

Answer: $\sqrt{101} \approx 10.05$.

Common Mistakes to Avoid
  • Using Degrees Instead of Radians in Trigonometric Linearizations: When approximating $\sin x$, $\cos x$, or $\tan x$ near $x = a$, $(x - a)$ must always be expressed in radians.
  • Choosing a Center $a$ Too Far from $x$: Linearization $L(x)$ is accurate only when $|x - a|$ is small.
Key Takeaways
  • The linearization of $f$ at $x = a$ is $L(x) = f(a) + f'(a)(x - a)$.
  • For $x$ close to $a$, the standard linear approximation is $f(x) \approx f(a) + f'(a)(x - a)$.
  • The approximation error $|f(x) - L(x)|$ decreases rapidly as $x$ approaches $a$.
