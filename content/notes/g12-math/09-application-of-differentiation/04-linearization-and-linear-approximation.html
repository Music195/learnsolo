Chapter 9: Application of Differentiation

Linearization and Linear Approximation

When we zoom in closely on a differentiable curve near a point $(a, f(a))$, the curve looks nearly indistinguishable from its tangent line — allowing us to approximate complicated function values with a simple linear formula.

1. The Linearization of a Function

Suppose $f$ is differentiable at $x = a$. The tangent line to the curve $y = f(x)$ at the point $(a, f(a))$ has equation: $$y - f(a) = f'(a)(x - a) \implies y = f(a) + f'(a)(x - a)$$ For values of $x$ sufficiently close to $a$, the height of the tangent line closely approximates the true value $f(x)$.

Definition — Linearization and Standard Linear Approximation

If $f$ is differentiable at $x = a$, then the approximating linear function: $$L(x) = f(a) + f'(a)(x - a)$$ is called the linearization of $f$ at $x = a$.

The approximation: $$f(x) \approx L(x) = f(a) + f'(a)(x - a) \qquad (\text{for } x \text{ near } a)$$ is called the standard linear approximation (or tangent line approximation) of $f$ at $x = a$. The point $x = a$ is called the center of the approximation, and the approximation error is $|f(x) - L(x)|$.

How Concavity Affects Linear Approximation
  • If $f$ is concave up ($f''(x) > 0$) near $a$, the tangent line lies below the curve, so $L(x) \le f(x)$ (underestimate).
  • If $f$ is concave down ($f''(x) < 0$) near $a$, the tangent line lies above the curve, so $L(x) \ge f(x)$ (overestimate).

3. Worked Textbook Examples

Example 17 (Textbook p. 165) — Linearization of $f(x) = x^2 + 2x$ at $x = 2$

Find the linearization of $f(x) = x^2 + 2x$ at $x = 2$, and use it to approximate $f(2.5)$, $f(2.05)$, and $f(2.005)$. Compare the approximations with the exact values.

Solution:

Here $a = 2$, $f(2) = 2^2 + 2(2) = 8$, and $f'(x) = 2x + 2 \implies f'(2) = 6$. Therefore, the linearization at $x = 2$ is: $$L(x) = f(2) + f'(2)(x - 2) = 8 + 6(x - 2) = 6x - 4$$

$x$ Linear Approximation $L(x) = 6x - 4$ Actual Value $f(x) = x^2 + 2x$ Error $|f(x) - L(x)|$
$2.5$ $L(2.5) = 6(2.5) - 4 = 11$ $f(2.5) = 11.25$ $0.25 = (0.5)^2$
$2.05$ $L(2.05) = 6(2.05) - 4 = 8.3$ $f(2.05) = 8.3025$ $0.0025 = (0.05)^2$
$2.005$ $L(2.005) = 6(2.005) - 4 = 8.03$ $f(2.005) = 8.030025$ $0.000025 = (0.005)^2$

Notice that each time the distance $|x - 2|$ is divided by $10$, the approximation error is divided by $100$.

Example 18 (Textbook p. 166) — Approximating Circle Area

The radius $r$ of a circle increases from $r = 5\text{ m}$ to $r = 5.01\text{ m}$. Find the linear approximation of the area $A(r) = \pi r^2$ at $r = 5$, estimate the area of the enlarged circle, and find the error of approximation.

Solution:

Let $A(r) = \pi r^2$. Then $A'(r) = 2\pi r$. At $r = 5$, $A(5) = 25\pi$ and $A'(5) = 10\pi$. The linearization of $A(r)$ at $r = 5$ is: $$L(r) = A(5) + A'(5)(r - 5) = 25\pi + 10\pi(r - 5) = 10\pi r - 25\pi$$ At $r = 5.01\text{ m}$: $$L(5.01) = 25\pi + 10\pi(0.01) = 25.1\pi\text{ m}^2$$ Since the actual area is $A(5.01) = \pi(5.01)^2 = 25.1001\pi\text{ m}^2$, the error is: $$|A(5.01) - L(5.01)| = |25.1001\pi - 25.1\pi| = 0.0001\pi\text{ m}^2$$

Example 19 (Textbook p. 166) — Estimating $\sqrt{101}$

Use linear approximation to estimate the value of $\sqrt{101}$.

Solution:

Consider $f(x) = \sqrt{x}$ and choose the nearby perfect square $a = 100$. We have: $$f(100) = \sqrt{100} = 10, \qquad f'(x) = \frac{1}{2\sqrt{x}} \implies f'(100) = \frac{1}{2\sqrt{100}} = \frac{1}{20} = 0.05$$ The linearization of $f(x) = \sqrt{x}$ at $a = 100$ is: $$L(x) = f(100) + f'(100)(x - 100) = 10 + \frac{1}{20}(x - 100)$$ Setting $x = 101$: $$\sqrt{101} \approx L(101) = 10 + \frac{1}{20}(101 - 100) = 10 + 0.05 = 10.05$$ (Compare with the actual value $\sqrt{101} \approx 10.0498756\dots$, an error of only $0.000124$!)

4. Chapter 9 Summary

  • Tangent & Normal Lines at $(x_1, y_1)$: Tangent is $y - y_1 = y'(x_1)(x - x_1)$; Normal is $y - y_1 = -\dfrac{1}{y'(x_1)}(x - x_1)$.
  • Monotonicity: $f'(x) > 0 \implies f$ increasing; $f'(x) < 0 \implies f$ decreasing.
  • Critical Points: $(c, f(c))$ where $c \in \text{dom}(f)$ and $f'(c) = 0$ or $f'(c)$ is undefined.
  • Concavity & Inflection: $f''(x) > 0 \implies$ concave up; $f''(x) < 0 \implies$ concave down; concavity changes at an inflection point.
  • Linearization at $x = a$: $L(x) = f(a) + f'(a)(x - a)$.
