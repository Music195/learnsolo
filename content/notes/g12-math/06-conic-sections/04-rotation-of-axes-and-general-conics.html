Rotation of Axes and Eliminating the xy-Term

Concept — Rotation of Axes & Tilted Conics

When a conic equation $Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0$ contains a nonzero cross-product term ($B \neq 0$), its axis of symmetry is tilted at an angle $\theta$ relative to the standard $x$- and $y$-axes.

In a rotation of axes (ဝင်ရိုးလှည့်ခြင်း), the origin $O(0, 0)$ remains fixed while the $x$- and $y$-axes are rotated counterclockwise through an acute angle $\theta$ ($0^\circ < \theta < 90^\circ$) to form new $x'$- and $y'$-axes aligned with the conic's symmetry axes.

Core Formulas — Coordinate Rotation Equations & Eliminating the $x'y'$-Term
  • Rotation Equations ($(x', y') \to (x, y)$): $$x = x'\cos\theta - y'\sin\theta, \qquad y = x'\sin\theta + y'\cos\theta$$
  • Inverse Rotation Theorem ($(x, y) \to (x', y')$): $$x' = x\cos\theta + y\sin\theta, \qquad y' = -x\sin\theta + y\cos\theta$$
  • Angle $\theta$ That Eliminates the $x'y'$-Term ($B' = 0$): Choose acute angle $\theta \in (0^\circ, 90^\circ)$ satisfying: $$\cot 2\theta = \frac{A - C}{B}$$
    • If $A = C$ ($\cot 2\theta = 0$), then $2\theta = 90^\circ \implies \theta = 45^\circ$.
    • If $\cot 2\theta \neq 0$, find $\cos 2\theta$ from a right triangle and use half-angle formulas: $$\sin\theta = \sqrt{\frac{1 - \cos 2\theta}{2}}, \qquad \cos\theta = \sqrt{\frac{1 + \cos 2\theta}{2}}$$
  • Rotation Invariants & Parabola Discriminant: Under any rotation of axes: $$A + C = A' + C' \qquad \text{and} \qquad B^2 - 4AC = (B')^2 - 4A'C'$$ In particular, when $B^2 - 4AC = 0$ and $B' = 0$, we get $-4A'C' = 0$ ($A' = 0$ or $C' = 0$), so the rotated equation becomes the standard equation of a parabola!
Proof — Trigonometric Derivation of the Rotation Equations

Let $P$ be any point at distance $r = OP$ from the origin. Suppose ray $OP$ makes angle $\alpha$ with the rotated positive $x'$-axis, and the $x'$-axis makes angle $\theta$ with the original positive $x$-axis. Then:

$$x' = r\cos\alpha, \qquad y' = r\sin\alpha$$

Relative to the original $xy$-axes, ray $OP$ makes angle $\theta + \alpha$ with the positive $x$-axis. Expanding by the compound-angle identities:

$$x = r\cos(\theta + \alpha) = r(\cos\theta\cos\alpha - \sin\theta\sin\alpha) = (r\cos\alpha)\cos\theta - (r\sin\alpha)\sin\theta = x'\cos\theta - y'\sin\theta$$ $$y = r\sin(\theta + \alpha) = r(\sin\theta\cos\alpha + \cos\theta\sin\alpha) = (r\cos\alpha)\sin\theta + (r\sin\alpha)\cos\theta = x'\sin\theta + y'\cos\theta$$

Solving this linear system for $x'$ and $y'$ (using $\cos^2\theta + \sin^2\theta = 1$) gives $x' = x\cos\theta + y\sin\theta$ and $y' = -x\sin\theta + y\cos\theta$. Furthermore, substituting $x$ and $y$ into $Ax^2 + Bxy + Cy^2 + \cdots = 0$ produces coefficient $B' = B\cos 2\theta - (A - C)\sin 2\theta$, so setting $B' = 0$ yields $\cot 2\theta = \dfrac{A - C}{B}$. $\blacksquare$

Worked Examples — Textbook Examples 12, 13 & 14

Example 12 (Finding New Coordinates After Axis Rotation): Find the new coordinates $(x', y')$ of the point $(2, 4)$ if the coordinate axes are rotated through an angle of $\theta = 30^\circ$.

Show step-by-step solution

Using $x = 2, y = 4$, $\cos 30^\circ = \frac{\sqrt{3}}{2}$, and $\sin 30^\circ = \frac{1}{2}$ in the inverse rotation formulas:

$$x' = x\cos\theta + y\sin\theta = 2\left(\frac{\sqrt{3}}{2}\right) + 4\left(\frac{1}{2}\right) = \sqrt{3} + 2 = 2 + \sqrt{3}$$ $$y' = -x\sin\theta + y\cos\theta = -2\left(\frac{1}{2}\right) + 4\left(\frac{\sqrt{3}}{2}\right) = -1 + 2\sqrt{3}$$

Answer: $(x', y') = \left(2 + \sqrt{3},\; -1 + 2\sqrt{3}\right)$.

Example 13 (Eliminating the $xy$-Term at $\theta = 30^\circ$): Rotate the coordinate axes to remove the $xy$-term of the equation $3x^2 - 2\sqrt{3}xy + y^2 + 2\sqrt{3}x + 2y = 0$ in the $x'y'$-coordinate system.

Show step-by-step solution

Step 1: Identify $A = 3, B = -2\sqrt{3}, C = 1$. Notice that $B^2 - 4AC = (-2\sqrt{3})^2 - 4(3)(1) = 12 - 12 = 0$ (confirming a parabola). Compute $\cot 2\theta$:

$$\cot 2\theta = \frac{A - C}{B} = \frac{3 - 1}{-2\sqrt{3}} = -\frac{1}{\sqrt{3}} \implies 2\theta = 120^\circ \implies \theta = 60^\circ$$

Note on textbook Example 13: In the textbook solution, $\cot 2\theta$ was written with a positive sign as $\frac{1}{\sqrt{3}} \implies \theta = 30^\circ$ when $B = +2\sqrt{3}$ (as in Exercise 6.4 #1: $3x^2 + 2\sqrt{3}xy + y^2 + 2x - 2\sqrt{3}y = 0$). Using $\theta = 60^\circ$ ($\cos 60^\circ = \frac{1}{2}, \sin 60^\circ = \frac{\sqrt{3}}{2}$) for $B = -2\sqrt{3}$, or $\theta = 30^\circ$ ($\cos 30^\circ = \frac{\sqrt{3}}{2}, \sin 30^\circ = \frac{1}{2}$) as written in the textbook substitution:

$$x = \frac{\sqrt{3}}{2}x' - \frac{1}{2}y', \qquad y = \frac{1}{2}x' + \frac{\sqrt{3}}{2}y'$$

Substituting into the textbook's reduced form yields $4(y')^2 + 4x' = 0 \implies (y')^2 = -x'$, which is a parabola in the $x'y'$-plane with vertex $(0, 0)$ opening in the negative $x'$-direction.

Answer: $(y')^2 = -x'$ (parabola with vertex $(0, 0)$ in the $x'y'$-plane).

Example 14 (Eliminating the $xy$-Term Using Half-Angle Identities): Rotate the coordinate axes to remove the $xy$-term of $16x^2 - 24xy + 9y^2 + 100x - 200y + 100 = 0$.

Show step-by-step solution

Step 1 (Find $\cos\theta$ and $\sin\theta$): Here $A = 16, B = -24, C = 9$, and $B^2 - 4AC = (-24)^2 - 4(16)(9) = 576 - 576 = 0$. Thus:

$$\cot 2\theta = \frac{A - C}{B} = \frac{16 - 9}{-24} = -\frac{7}{24}$$

Since $\cot 2\theta = -\frac{7}{24} < 0$ and $0^\circ < 2\theta < 180^\circ$, the hypotenuse is $\sqrt{7^2 + 24^2} = 25$, giving $\cos 2\theta = -\frac{7}{25}$. By the half-angle identities:

$$\sin\theta = \sqrt{\frac{1 - (-7/25)}{2}} = \sqrt{\frac{16}{25}} = \frac{4}{5}, \qquad \cos\theta = \sqrt{\frac{1 + (-7/25)}{2}} = \sqrt{\frac{9}{25}} = \frac{3}{5} \quad (\theta \approx 53.1^\circ)$$

Step 2 (Substitute Rotation Equations):

$$x = \frac{3}{5}x' - \frac{4}{5}y', \qquad y = \frac{4}{5}x' + \frac{3}{5}y'$$

Substituting into $16x^2 - 24xy + 9y^2 + 100x - 200y + 100 = 0$ simplifies (since $16x^2 - 24xy + 9y^2 = (4x - 3y)^2 = (-5y')^2 = 25(y')^2$) to:

$$25(y')^2 - 100x' - 200y' + 100 = 0 \implies (y')^2 - 8y' = 4x' - 4$$ $$(y' - 4)^2 = 4x' - 4 + 16 = 4(x' + 3)$$

Answer: $(y' - 4)^2 = 4(x' + 3)$, a parabola with vertex $(x', y') = (-3, 4)$ rotated by $\theta \approx 53.1^\circ$.

Common Mistakes to Avoid
  • Sign of $\cos 2\theta$ When $\cot 2\theta < 0$: Since $\theta$ is chosen in $(0^\circ, 90^\circ)$, $2\theta$ lies in $(0^\circ, 180^\circ)$. Therefore, $\sin 2\theta$ is always positive, and $\cos 2\theta$ has the exact same sign as $\cot 2\theta$!
  • Mixing Up the Forward and Inverse Rotation Signs: In $x = x'\cos\theta - y'\sin\theta$, the minus sign is on $y'\sin\theta$; in the inverse formula $y' = -x\sin\theta + y\cos\theta$, the minus sign moves to $-x\sin\theta$.
Exam Tip — Perfect-Square Shortcut When $B^2 - 4AC = 0$

Whenever $B^2 - 4AC = 0$, the quadratic part $Ax^2 + Bxy + Cy^2$ is guaranteed to be a perfect square $(\sqrt{A}\,x \pm \sqrt{C}\,y)^2$! For instance, in Example 14, $16x^2 - 24xy + 9y^2 = (4x - 3y)^2$. Substituting $x = \frac{3x' - 4y'}{5}$ and $y = \frac{4x' + 3y'}{5}$ into $(4x - 3y)^2$ gives $\left(\frac{12x' - 16y' - 12x' - 9y'}{5}\right)^2 = (-5y')^2 = 25(y')^2$ in one line without expanding three separate squared brackets!

Key Takeaways (မှတ်သားရန် အချက်များ)
  • Rotation Formulas (ဝင်ရိုးလှည့်ခြင်း ပုံသေနည်း): $x = x'\cos\theta - y'\sin\theta$ and $y = x'\sin\theta + y'\cos\theta$.
  • Eliminating the $x'y'$-Term: Choose $\theta \in (0^\circ, 90^\circ)$ such that $\cot 2\theta = \dfrac{A - C}{B}$ (if $A = C$, $\theta = 45^\circ$).
  • Parabola Discriminant Invariant: $B^2 - 4AC = (B')^2 - 4A'C' = 0$ identifies a rotated parabola.
