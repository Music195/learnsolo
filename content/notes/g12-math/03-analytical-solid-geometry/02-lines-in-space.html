Lines in Space

Directed Values and the Parameterization of a 3D Line

In three-dimensional space, a line cannot be described by a single linear equation of the form $y = mx + c$ (in 3D, a single linear equation defines a plane). Instead, a line is described using directed values (direction numbers) and a parameter $k \in \mathbb{R}$.

For any two distinct points $P(x_1, y_1, z_1)$ and $Q(x_2, y_2, z_2)$, the displacement from $P$ to $Q$ defines the directed values: $$(PQ) = (l, m, n) = (x_2 - x_1, \; y_2 - y_1, \; z_2 - z_1)$$ The length of the line segment $PQ$ is: $$PQ = \sqrt{l^2 + m^2 + n^2} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$$

For every real number $k$, there corresponds a unique point $R$ on the line $PQ$ with respect to the initial point $P$:

  • Case 1 ($0 < k < 1$): $R$ lies between $P$ and $Q$ such that $PR = k \cdot PQ$. When $k = \frac{1}{2}$, $R$ is the midpoint.
  • Case 2 ($k > 1$): $R$ lies beyond $Q$ such that $PR = k \cdot PQ$.
  • Case 3 ($k < 0$): $R$ lies before $P$ such that $RP = -k \cdot PQ$.
  • $k = 0$: Point $R$ is $P$; and for $k = 1$: Point $R$ is $Q$.

Forms of the Equation of a Line in Space

1. Coordinate / Parametric Form

$$(x, y, z) = (x_1 + kl, \; y_1 + km, \; z_1 + kn) \quad (k \in \mathbb{R})$$

Equivalently:   $x = x_1 + kl, \quad y = y_1 + km, \quad z = z_1 + kn$

2. Symmetric / Standard Form ($l, m, n \ne 0$)

Solving each parametric equation for the common parameter $k$:

$$\frac{x - x_1}{l} = \frac{y - y_1}{m} = \frac{z - z_1}{n} = k$$

3. Two-Point Form

When the line passes through $P(x_1, y_1, z_1)$ and $Q(x_2, y_2, z_2)$:

$$\frac{x - x_1}{x_2 - x_1} = \frac{y - y_1}{y_2 - y_1} = \frac{z - z_1}{z_2 - z_1} = k$$

4. Directed Values of a Line

If a line segment has directed values $(l, m, n)$, any scalar multiple $(c \cdot l, \; c \cdot m, \; c \cdot n)$ with $c \ne 0$ is also a valid set of directed values for the line.

Example 1 (Textbook Page 28, Example 2)

Given $P(1, 2, 3)$ and $Q(3, 6, 5)$, find the coordinates of point $R(x, y, z)$ on the line $PQ$ with respect to the point $P$ and the following parameters:
(a) $k = \frac{1}{2}$   (b) $k = 2$   (c) $k = -2$.

Show solution
  1. First, calculate the directed values of $PQ$: $$(PQ) = (l, m, n) = (3 - 1, \; 6 - 2, \; 5 - 3) = (2, 4, 2)$$ The parametric equations with respect to $P(1, 2, 3)$ are: $$(x, y, z) = (1 + 2k, \; 2 + 4k, \; 3 + 2k)$$
  2. (a) For $k = \frac{1}{2}$ (Midpoint): $$(x, y, z) = \left(1 + 2\left(\tfrac{1}{2}\right), \; 2 + 4\left(\tfrac{1}{2}\right), \; 3 + 2\left(\tfrac{1}{2}\right)\right) = (1 + 1, \; 2 + 2, \; 3 + 1) = (2, 4, 4)$$
  3. (b) For $k = 2$ (Beyond $Q$): $$(x, y, z) = (1 + 2(2), \; 2 + 4(2), \; 3 + 2(2)) = (1 + 4, \; 2 + 8, \; 3 + 4) = (5, 10, 7)$$
  4. (c) For $k = -2$ (Before $P$): $$(x, y, z) = (1 + 2(-2), \; 2 + 4(-2), \; 3 + 2(-2)) = (1 - 4, \; 2 - 8, \; 3 - 4) = (-3, -6, -1)$$

Example 2: Testing if a Point Lies on a Line (Textbook Page 28, Example 3)

Given $P(-1, 2, 3)$ and $Q(3, 5, -2)$, determine whether or not each of the following points lies on the line $PQ$. If the point is on the line, find the corresponding parameter $k$ with respect to point $P$:
(a) $\left(1, \frac{7}{2}, \frac{1}{2}\right)$   (b) $(7, 8, -7)$   (c) $(-5, -1, 8)$   (d) $(8, 9, -8)$.

Show solution
  1. Find directed values $(PQ)$: $$(PQ) = (l, m, n) = (3 - (-1), \; 5 - 2, \; -2 - 3) = (4, 3, -5)$$ The symmetric equation of the line is: $$\frac{x + 1}{4} = \frac{y - 2}{3} = \frac{z - 3}{-5} = k$$
  2. (a) For $\left(1, \frac{7}{2}, \frac{1}{2}\right)$ : $$\frac{1 + 1}{4} = \frac{2}{4} = \frac{1}{2}, \quad \frac{\frac{7}{2} - 2}{3} = \frac{\frac{3}{2}}{3} = \frac{1}{2}, \quad \frac{\frac{1}{2} - 3}{-5} = \frac{-\frac{5}{2}}{-5} = \frac{1}{2}$$ All three ratios equal $\frac{1}{2}$. Thus, the point lies on the line with parameter $k = \frac{1}{2}$.
  3. (b) For $(7, 8, -7)$ : $$\frac{7 + 1}{4} = \frac{8}{4} = 2, \quad \frac{8 - 2}{3} = \frac{6}{3} = 2, \quad \frac{-7 - 3}{-5} = \frac{-10}{-5} = 2$$ All three ratios equal $2$. Thus, the point lies on the line with parameter $k = 2$.
  4. (c) For $(-5, -1, 8)$ : $$\frac{-5 + 1}{4} = -1, \quad \frac{-1 - 2}{3} = -1, \quad \frac{8 - 3}{-5} = -1$$ All three ratios equal $-1$. Thus, the point lies on the line with parameter $k = -1$.
  5. (d) For $(8, 9, -8)$ : $$\frac{8 + 1}{4} = \frac{9}{4}, \quad \frac{9 - 2}{3} = \frac{7}{3} \ne \frac{9}{4}$$ The ratios are not equal. Thus, the point does not lie on the line.

Key Takeaways & Terminology (အဓိကမှတ်သားဖွယ်ရာများ)

  • Directed Values (ဦးတည်ချက် တန်ဖိုးများ): $(l, m, n) = (x_2 - x_1, y_2 - y_1, z_2 - z_1)$ describe the direction and orientation of a line segment.
  • Parametric Equations (ပါရာမက်ထရစ် ညီမျှခြင်းများ): $x = x_1 + kl, \; y = y_1 + km, \; z = z_1 + kn$. Every real value of $k$ gives exactly one point on the line.
  • Symmetric Form (အချိုးညီ ပုံစံ): $\frac{x - x_1}{l} = \frac{y - y_1}{m} = \frac{z - z_1}{n} = k$.
  • Point Verification: A point $(x, y, z)$ lies on the line if and only if all three coordinate ratios yield the exact same scalar value $k$.
