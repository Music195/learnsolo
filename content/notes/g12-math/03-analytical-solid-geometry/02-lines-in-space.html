Lines in Space

Directed Values and Parameterization of a Line in Space

For a line segment $PQ$ connecting $P(x_1, y_1, z_1)$ and $Q(x_2, y_2, z_2)$, the directed values (ဦးတည်ချက် တန်ဖိုးများ) of $PQ$ are defined by: $$(PQ) = (l, m, n) = (x_2 - x_1, \; y_2 - y_1, \; z_2 - z_1)$$ and the length of segment $PQ$ is $PQ = \sqrt{l^2 + m^2 + n^2}$.

For every real number $k \in \mathbb{R}$, there is a unique point $R(x, y, z)$ on the line $PQ$ with respect to $P$:

  • Case 1 ($0 < k < 1$): $R$ lies between $P$ and $Q$ such that $PR = k \cdot PQ$ (at $k = \frac{1}{2}$, $R$ is the midpoint).
  • Case 2 ($k > 1$): $R$ lies after $Q$ such that $PR = k \cdot PQ$.
  • Case 3 ($k < 0$): $R$ lies before $P$ such that $RP = -k \cdot PQ$.

Coordinate, Parametric, and Symmetric Equations of a Line

$$(x, y, z) = (x_1 + kl, \; y_1 + km, \; z_1 + kn) \qquad (k \in \mathbb{R})$$ $$\frac{x - x_1}{l} = \frac{y - y_1}{m} = \frac{z - z_1}{n} = k \qquad (l, m, n \ne 0)$$

• Here $k$ is the parameter and $(l, m, n) = (x_2 - x_1, y_2 - y_1, z_2 - z_1)$ are the directed values.
• Since $(PR) = (kl, km, kn)$, any non-zero multiple $(kl, km, kn)$ represents the directed values of the line $PQ$.

  1. Project $P(x_1, y_1, z_1)$, $R(x, y, z)$, and $Q(x_2, y_2, z_2)$ onto the $xy$-plane to get $A(x_1, y_1, 0)$, $C(x, y, 0)$, and $B(x_2, y_2, 0)$.
  2. By similar triangles in the vertical projection plane, $\dfrac{z - z_1}{z_2 - z_1} = \dfrac{PR}{PQ} = k \implies z = z_1 + k(z_2 - z_1) = z_1 + kn$.
  3. Projecting onto the $yz$- and $zx$-planes similarly gives $x = x_1 + kl$ and $y = y_1 + km$.

Move parameter $k$ along line $PQ$: $R(x_1 + kl, y_1 + km, z_1 + kn)$ and its $xy$-plane shadow

Example 1 (Textbook Page 28, Example 2)

Given $P(1, 2, 3)$ and $Q(3, 6, 5)$, find the coordinates of point $R(x, y, z)$ on the line $PQ$ with respect to point $P$ and the following parameters: (a) $k = \frac{1}{2}$,   (b) $k = 2$,   (c) $k = -2$.

Show solution
  1. Directed values: $(PQ) = (l, m, n) = (3 - 1, \; 6 - 2, \; 5 - 3) = (2, 4, 2)$.
    Coordinate form: $(x, y, z) = (1 + 2k, \; 2 + 4k, \; 3 + 2k)$.
  2. (a) $k = \frac{1}{2}$: $(x, y, z) = \left(1 + 2(\tfrac{1}{2}), \; 2 + 4(\tfrac{1}{2}), \; 3 + 2(\tfrac{1}{2})\right) = (2, 4, 4)$.
  3. (b) $k = 2$: $(x, y, z) = (1 + 2(2), \; 2 + 4(2), \; 3 + 2(2)) = (5, 10, 7)$.
  4. (c) $k = -2$: $(x, y, z) = (1 + 2(-2), \; 2 + 4(-2), \; 3 + 2(-2)) = (-3, -6, -1)$.

(a) $(2, 4, 4)$,   (b) $(5, 10, 7)$,   (c) $(-3, -6, -1)$

Example 2 (Textbook Page 28, Example 3)

Given $P(-1, 2, 3)$ and $Q(3, 5, -2)$, determine whether each point lies on the line $PQ$, and if so, find the corresponding parameter $k$: (a) $\left(1, \frac{7}{2}, \frac{1}{2}\right)$,   (b) $(7, 8, -7)$,   (c) $(-5, -1, 8)$,   (d) $(8, 9, -8)$.

Show solution
  1. $(PQ) = (4, 3, -5)$, so the line equation is $\dfrac{x + 1}{4} = \dfrac{y - 2}{3} = \dfrac{z - 3}{-5} = k$.
  2. (a) For $\left(1, \frac{7}{2}, \frac{1}{2}\right)$: $\dfrac{1+1}{4} = \dfrac{1}{2}$, $\dfrac{\frac{7}{2}-2}{3} = \dfrac{1}{2}$, $\dfrac{\frac{1}{2}-3}{-5} = \dfrac{1}{2}$. Yes, $k = \dfrac{1}{2}$.
  3. (b) For $(7, 8, -7)$: $\dfrac{7+1}{4} = 2$, $\dfrac{8-2}{3} = 2$, $\dfrac{-7-3}{-5} = 2$. Yes, $k = 2$.
  4. (c) For $(-5, -1, 8)$: $\dfrac{-5+1}{4} = -1$, $\dfrac{-1-2}{3} = -1$, $\dfrac{8-3}{-5} = -1$. Yes, $k = -1$.
  5. (d) For $(8, 9, -8)$: $\dfrac{8+1}{4} = \dfrac{9}{4} \ne \dfrac{9-2}{3} = \dfrac{7}{3}$. Not on the line.

(a) On line ($k = \frac{1}{2}$), (b) On line ($k = 2$), (c) On line ($k = -1$), (d) Not on line

Zero Directed Value: If one of the directed values is zero — for instance $(l, m, n) = (2, 0, 5)$ — we cannot divide by $0$ in symmetric form. Write $\dfrac{x - x_1}{2} = \dfrac{z - z_1}{5}, \; y = y_1$ instead.
Midpoint Formula in 3D: Setting $k = \frac{1}{2}$ in $(x_1 + k(x_2 - x_1), \dots)$ immediately gives the midpoint of $PQ$: $$M = \left(\frac{x_1 + x_2}{2}, \; \frac{y_1 + y_2}{2}, \; \frac{z_1 + z_2}{2}\right)$$
  • Directed values of $PQ$: $(l, m, n) = (x_2 - x_1, y_2 - y_1, z_2 - z_1)$ (ဦးတည်ချက် တန်ဖိုးများ).
  • Coordinate form: $(x, y, z) = (x_1 + kl, y_1 + km, z_1 + kn)$ where $k \in \mathbb{R}$ is the parameter (ပါရာမီတာ).
  • Symmetric form: $\dfrac{x - x_1}{l} = \dfrac{y - y_1}{m} = \dfrac{z - z_1}{n} = k$.
