Planes in Space

Defining a Flat Surface in Three Dimensions

In 3D geometry, a single linear equation in $x, y, z$ represents a plane (မျက်နှာပြင်). A plane is uniquely determined by:

  • Three non-collinear points $A, B$, and $C$.
  • A point $(x_1, y_1, z_1)$ on the plane and a directed normal line perpendicular to the plane.
  • Two intersecting or parallel lines.

If a plane passes through $A(x_1, y_1, z_1)$ and contains two direction vectors $(l_1, m_1, n_1)$ and $(l_2, m_2, n_2)$, every point $P(x, y, z)$ on the plane satisfies the two-parameter equation: $$(x, y, z) = (x_1 + s l_1 + t l_2, \; y_1 + s m_1 + t m_2, \; z_1 + s n_1 + t n_2) \quad (s, t \in \mathbb{R})$$ Eliminating parameters $s$ and $t$ yields the single linear Cartesian equation of the plane.

Equations of a Plane

1. Normal Directed Values from Two Vectors

For two non-parallel directions $(l_1, m_1, n_1)$ and $(l_2, m_2, n_2)$ lying in the plane, the directed values $(a, b, c)$ perpendicular to both directions are:

$$a = m_1 n_2 - m_2 n_1, \quad b = n_1 l_2 - n_2 l_1, \quad c = l_1 m_2 - l_2 m_1$$

These satisfy $a l_1 + b m_1 + c n_1 = 0$ and $a l_2 + b m_2 + c n_2 = 0$.

2. Point-Normal & Cartesian Form

$$a(x - x_1) + b(y - y_1) + c(z - z_1) = 0 \iff ax + by + cz = d$$

where $d = a x_1 + b y_1 + c z_1$. Any line perpendicular to the plane has directed values $(a, b, c)$.

3. Parallel and Perpendicular Planes

  • Parallel Planes: $\frac{a_1}{a_2} = \frac{b_1}{b_2} = \frac{c_1}{c_2}$ (their normal directions are proportional).
  • Perpendicular Planes: $a_1 a_2 + b_1 b_2 + c_1 c_2 = 0$ (their normal directions are perpendicular).

4. Intersection of a Line and a Plane

To find the intersection of line $(x, y, z) = (x_0 + kl, \; y_0 + km, \; z_0 + kn)$ with plane $ax + by + cz = d$:
Substitute the line coordinates into the plane equation and solve for parameter $k$: $$a(x_0 + kl) + b(y_0 + km) + c(z_0 + kn) = d \implies k = \frac{d - (a x_0 + b y_0 + c z_0)}{al + bm + cn}$$

Example 1: Plane Through Three Points (Textbook Page 36, Example 8)

Find the equation of the plane containing the points $A(1, 0, 1)$, $B(3, 6, 4)$, and $C(-2, 3, 1)$.

Show solution
  1. Find the directed values of $AB$ and $AC$: $$(AB) = (l_1, m_1, n_1) = (3 - 1, \; 6 - 0, \; 4 - 1) = (2, 6, 3)$$ $$(AC) = (l_2, m_2, n_2) = (-2 - 1, \; 3 - 0, \; 1 - 1) = (-3, 3, 0)$$
  2. Compute the normal directed values $(a, b, c)$ perpendicular to both $AB$ and $AC$: $$a = m_1 n_2 - m_2 n_1 = (6)(0) - (3)(3) = 0 - 9 = -9$$ $$b = n_1 l_2 - n_2 l_1 = (3)(-3) - (0)(2) = -9 - 0 = -9$$ $$c = l_1 m_2 - l_2 m_1 = (2)(3) - (-3)(6) = 6 + 18 = 24$$ Thus, $(a, b, c) = (-9, -9, 24)$.
  3. Simplify the directed values by dividing by $-3$: $$(a, b, c) = (3, 3, -8)$$
  4. Write the equation of the plane passing through $A(1, 0, 1)$: $$3(x - 1) + 3(y - 0) - 8(z - 1) = 0$$ $$3x - 3 + 3y - 8z + 8 = 0$$ $$3x + 3y - 8z + 5 = 0 \quad (\text{or } 3x + 3y - 8z = -5)$$

Example 2: Perpendicular Line & Plane Intersection (Textbook Page 36, Example 9)

Find the equation of the line that passes through the point $(-1, 3, 2)$ and is perpendicular to the plane $3x - 2y - z = 3$. Find also the point of intersection of the line and the given plane.

Show solution
  1. A line perpendicular to the plane $3x - 2y - z = 3$ has directed values equal to the plane's normal coefficients: $$(l, m, n) = (3, -2, -1)$$
  2. The equation of the line passing through $(-1, 3, 2)$ is: $$\frac{x + 1}{3} = \frac{y - 3}{-2} = \frac{z - 2}{-1} = k$$ In parametric form: $$x = -1 + 3k, \quad y = 3 - 2k, \quad z = 2 - k$$
  3. Substitute these into the plane equation $3x - 2y - z = 3$: $$3(-1 + 3k) - 2(3 - 2k) - (2 - k) = 3$$ $$-3 + 9k - 6 + 4k - 2 + k = 3$$ $$14k - 11 = 3 \implies 14k = 14 \implies k = 1$$
  4. Substitute $k = 1$ back into the parametric equations: $$x = -1 + 3(1) = 2, \quad y = 3 - 2(1) = 1, \quad z = 2 - (1) = 1$$ The point of intersection is $(2, 1, 1)$.

Example 3: Parallel Plane Through a Given Point (Textbook Page 37, Example 10)

Find the equation of the plane containing the point $(-1, 3, 2)$ and parallel to the plane $3x - 2y - 3z = 2$.

Show solution
  1. Since the required plane is parallel to $3x - 2y - 3z = 2$, its normal line has the exact same directed values: $$(a, b, c) = (3, -2, -3)$$
  2. Using the point-normal equation with $(x_1, y_1, z_1) = (-1, 3, 2)$: $$3(x - (-1)) - 2(y - 3) - 3(z - 2) = 0$$ $$3(x + 1) - 2(y - 3) - 3(z - 2) = 0$$ $$3x + 3 - 2y + 6 - 3z + 6 = 0$$ $$3x - 2y - 3z + 15 = 0 \quad (\text{or } 3x - 2y - 3z = -15)$$

Key Takeaways & Terminology (အဓိကမှတ်သားဖွယ်ရာများ)

  • General Plane Equation (မျက်နှာပြင် အထွေထွေညီမျှခြင်း): $ax + by + cz = d$, where $(a, b, c)$ are the directed values of the normal line.
  • Normal Line (ထောင့်မတ်မျဉ်း): A line perpendicular to every line in the plane.
  • Plane Through Three Points: Find cross-directed values $a = m_1 n_2 - m_2 n_1$, $b = n_1 l_2 - n_2 l_1$, $c = l_1 m_2 - l_2 m_1$, then apply point-normal form.
  • Line-Plane Intersection: Substitute the line's parametric form into the plane equation to find parameter $k$.
