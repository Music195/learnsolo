Planes in Space

A Plane Determined by Three Points or a Normal Direction

A plane (မျက်နှာပြင်) in space is uniquely determined by three non-collinear points $A(x_1, y_1, z_1)$, $B(x_2, y_2, z_2)$, and $C(x_3, y_3, z_3)$. Let $(AB) = (l_1, m_1, n_1)$ and $(AC) = (l_2, m_2, n_2)$ be the directed values of two intersecting lines in the plane.

Every point $P(x, y, z)$ on the plane can be reached from $A$ by combining a step along $AB$ (parameter $s$) and a step along $AC$ (parameter $t$): $$x = x_1 + s l_1 + t l_2, \qquad y = y_1 + s m_1 + t m_2, \qquad z = z_1 + s n_1 + t n_2$$ Eliminating $s$ and $t$ produces the single linear Cartesian equation of the plane: $ax + by + cz = d$.

Cartesian Equation of a Plane & Normal Directed Values

$$a = m_1 n_2 - m_2 n_1, \qquad b = n_1 l_2 - n_2 l_1, \qquad c = l_1 m_2 - l_2 m_1$$ $$a(x - x_1) + b(y - y_1) + c(z - z_1) = 0 \iff ax + by + cz = d$$

• Because $a l_1 + b m_1 + c n_1 = 0$ and $a l_2 + b m_2 + c n_2 = 0$, the line through $(x_1, y_1, z_1)$ with directed values $(a, b, c)$ is perpendicular to the plane (the normal line).
• Any line perpendicular to the plane $ax + by + cz = d$ has directed values $(ka, kb, kc)$ for $k \ne 0$.
• Parallel planes share the same normal directed values $(a, b, c)$, differing only in constant $d$.

  1. Multiply the parametric equations by $a, b, c$ and add: $$a(x - x_1) + b(y - y_1) + c(z - z_1) = s(a l_1 + b m_1 + c n_1) + t(a l_2 + b m_2 + c n_2)$$
  2. Substituting $a = m_1 n_2 - m_2 n_1$, $b = n_1 l_2 - n_2 l_1$, $c = l_1 m_2 - l_2 m_1$ makes both parenthetical sums identically $0$.
  3. Thus $a(x - x_1) + b(y - y_1) + c(z - z_1) = 0$ for every point $(x, y, z)$ on the plane, and $(a, b, c) \perp (P - A)$.

Example 1: Plane Containing Three Points (Textbook Page 36, Example 8)

Find the equation of the plane containing $A(1, 0, 1)$, $B(3, 6, 4)$, and $C(-2, 3, 1)$.

Show solution
  1. Directed values of $AB$ and $AC$: $$(AB) = (l_1, m_1, n_1) = (3 - 1, \; 6 - 0, \; 4 - 1) = (2, 6, 3)$$ $$(AC) = (l_2, m_2, n_2) = (-2 - 1, \; 3 - 0, \; 1 - 1) = (-3, 3, 0)$$
  2. Calculate $(a, b, c)$: $$a = m_1 n_2 - m_2 n_1 = 6(0) - 3(3) = -9$$ $$b = n_1 l_2 - n_2 l_1 = 3(-3) - 0(2) = -9$$ $$c = l_1 m_2 - l_2 m_1 = 2(3) - (-3)(6) = 24$$ Divide $(-9, -9, 24)$ by $-3$ to simplify: $(a, b, c) = (3, 3, -8)$.
  3. Substitute point $A(1, 0, 1)$ into $3x + 3y - 8z = d$: $$d = 3(1) + 3(0) - 8(1) = -5$$

$3x + 3y - 8z = -5$

Example 2: Line Perpendicular to a Plane & Intersection (Textbook Page 36, Example 9)

Find the equation of the line that passes through $(-1, 3, 2)$ and is perpendicular to the plane $3x - 2y - z = 3$. Find also the point of intersection of the line and the given plane.

Show solution
  1. The normal directed values of the plane $3x - 2y - z = 3$ are $(3, -2, -1)$.
    The line through $(-1, 3, 2)$ with directed values $(3, -2, -1)$ is: $$\frac{x + 1}{3} = \frac{y - 3}{-2} = \frac{z - 2}{-1} = k \implies (x, y, z) = (-1 + 3k, \; 3 - 2k, \; 2 - k)$$
  2. Substitute into the plane equation $3x - 2y - z = 3$: $$3(-1 + 3k) - 2(3 - 2k) - (2 - k) = 3 \implies 14k - 11 = 3 \implies 14k = 14 \implies k = 1$$
  3. Substitute $k = 1$: $(x, y, z) = (-1 + 3, \; 3 - 2, \; 2 - 1) = (2, 1, 1)$.

Line: $\dfrac{x + 1}{3} = \dfrac{y - 3}{-2} = \dfrac{z - 2}{-1}$;   Intersection: $(2, 1, 1)$

Example 3: Plane Parallel to a Given Plane (Textbook Page 37, Example 10)

Find the equation of the plane containing the point $(-1, 3, 2)$ and parallel to the plane $3x - 2y - 3z = 2$.

Show solution
  1. A line perpendicular to $3x - 2y - 3z = 2$ has directed values $(3, -2, -3)$ and is also perpendicular to the required parallel plane.
  2. Thus the required plane has the form $3x - 2y - 3z = d$.
  3. Since $(-1, 3, 2)$ lies on the plane: $d = 3(-1) - 2(3) - 3(2) = -3 - 6 - 6 = -15$.

$3x - 2y - 3z = -15$

Watch the Middle Sign in $(a, b, c)$! In $b = n_1 l_2 - n_2 l_1$, the indices cycle forward ($m \to n \to l \to m$). If you compute the $2 \times 2$ determinant $\begin{vmatrix} l_1 & n_1 \\ l_2 & n_2 \end{vmatrix} = l_1 n_2 - l_2 n_1$, remember to put a minus sign in front of it!
Quick Check for Three-Point Planes: Once you find $ax + by + cz = d$, plug all three given points $A, B, C$ into your equation! It takes 10 seconds and guarantees 100% accuracy.
  • Cartesian equation of a plane: $ax + by + cz = d$ (မျက်နှာပြင်၏ ကာတီးရှန်းညီမျှခြင်း).
  • The coefficients $(a, b, c)$ are the directed values of any line perpendicular to the plane (ထောင့်မတ်မျဉ်း၏ ဦးတည်ချက်တန်ဖိုးများ).
  • Parallel planes have proportional $(a, b, c)$; perpendicular planes satisfy $a_1 a_2 + b_1 b_2 + c_1 c_2 = 0$.
