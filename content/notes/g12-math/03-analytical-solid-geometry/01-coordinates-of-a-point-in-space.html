Coordinates of a Point in Space

Extending Rectangular Coordinates into Three Dimensions

In a plane, every point corresponds to an ordered pair $(x, y)$. In three-dimensional space, through a fixed origin $O(0, 0, 0)$, we draw three mutually perpendicular axes: the $x$-axis, the $y$-axis, and the $z$-axis. Each point $P$ in space is uniquely determined by an ordered triple of real numbers $(x, y, z)$ (သုံးဖက်မြင် ကိုဩဒိနိတ်).

The three axes taken in pairs determine three mutually perpendicular coordinate planes:

  • $xy$-plane ($z = 0$): Contains the $x$- and $y$-axes; perpendicular to the $z$-axis. Points have the form $(x, y, 0)$.
  • $yz$-plane ($x = 0$): Contains the $y$- and $z$-axes; perpendicular to the $x$-axis. Points have the form $(0, y, z)$.
  • $zx$-plane ($y = 0$): Contains the $z$- and $x$-axes; perpendicular to the $y$-axis. Points have the form $(x, 0, z)$.

Coordinate Planes, Perpendicular Lines, and 3D Distance

$$PQ = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$$

• Coordinate Axes: $x$-axis: $y = 0, z = 0$;   $y$-axis: $x = 0, z = 0$;   $z$-axis: $x = 0, y = 0$.
• Planes Parallel to Coordinate Planes: $z = c$ ($\parallel xy$-plane, points $(x, y, c)$);   $x = a$ ($\parallel yz$-plane, points $(a, y, z)$);   $y = b$ ($\parallel zx$-plane, points $(x, b, z)$).
• Lines Through $(a, b, c)$ Perpendicular to Coordinate Planes:
$\perp xy$-plane: $x = a, y = b$ (points $(a, b, z)$);   $\perp yz$-plane: $y = b, z = c$ (points $(x, b, c)$);   $\perp zx$-plane: $x = a, z = c$ (points $(a, y, c)$).

  1. For $P(x_1, y_1, z_1)$ and $Q(x_2, y_2, z_2)$, let $B(x_2, y_2, z_1)$ be the projection of $Q$ onto the horizontal plane $z = z_1$, and $A(x_1, y_2, z_1)$.
  2. In the horizontal right triangle $PAB$: $PB^2 = PA^2 + AB^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2$.
  3. In the vertical right triangle $PBQ$: $PQ^2 = PB^2 + BQ^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2$.

Example 1 (Textbook Page 24)

Find the equations of the line through the point $(-3, 5, 7)$ and perpendicular to: (a) the $xy$-plane, (b) the $yz$-plane, and (c) the $zx$-plane. Find also the point of intersection of each line with the corresponding plane.

Show solution
  1. (a) Perpendicular to $xy$-plane ($z = 0$):
    Equation: $x = -3, \; y = 5$ (points $(-3, 5, z)$). Intersection with $xy$-plane: $(-3, 5, 0)$.
  2. (b) Perpendicular to $yz$-plane ($x = 0$):
    Equation: $y = 5, \; z = 7$ (points $(x, 5, 7)$). Intersection with $yz$-plane: $(0, 5, 7)$.
  3. (c) Perpendicular to $zx$-plane ($y = 0$):
    Equation: $x = -3, \; z = 7$ (points $(-3, y, 7)$). Intersection with $zx$-plane: $(-3, 0, 7)$.

(a) $(-3, 5, 0)$,   (b) $(0, 5, 7)$,   (c) $(-3, 0, 7)$

Example 2: Right Triangle in Space (Exercise 3.1 Q4)

Show that the points $A(-1, 2, 5)$, $B(1, 1, 6)$, and $C(0, 5, 6)$ form a right triangle.

Show solution
  1. Calculate the squared distances between each pair of vertices: $$AB^2 = (1 - (-1))^2 + (1 - 2)^2 + (6 - 5)^2 = 4 + 1 + 1 = 6$$ $$AC^2 = (0 - (-1))^2 + (5 - 2)^2 + (6 - 5)^2 = 1 + 9 + 1 = 11$$ $$BC^2 = (0 - 1)^2 + (5 - 1)^2 + (6 - 6)^2 = 1 + 16 + 0 = 17$$
  2. Since $AB^2 + AC^2 = 6 + 11 = 17 = BC^2$, $\triangle ABC$ is a right triangle with $\angle A = 90^\circ$.

$AB^2 + AC^2 = BC^2 = 17$, so $\triangle ABC$ is right-angled at $A$

Example 3: Collinear Points in Space (Exercise 3.1 Q5)

Show that the points $P(1, -1, 2)$, $Q(3, -2, 3)$, and $R(5, -3, 4)$ are collinear.

Show solution
  1. Compute the three distances: $$PQ = \sqrt{(3-1)^2 + (-2+1)^2 + (3-2)^2} = \sqrt{4 + 1 + 1} = \sqrt{6}$$ $$QR = \sqrt{(5-3)^2 + (-3+2)^2 + (4-3)^2} = \sqrt{4 + 1 + 1} = \sqrt{6}$$ $$PR = \sqrt{(5-1)^2 + (-3+1)^2 + (4-2)^2} = \sqrt{16 + 4 + 4} = \sqrt{24} = 2\sqrt{6}$$
  2. Since $PQ + QR = \sqrt{6} + \sqrt{6} = 2\sqrt{6} = PR$, the points $P, Q, R$ lie on the same straight line.

$PQ + QR = PR = 2\sqrt{6}$ (Collinear)

Line vs. Plane Equations in 3D: A single equation like $z = 3$ describes a plane (parallel to the $xy$-plane), whereas a pair of equations like $x = -3, y = 5$ describes a line (perpendicular to the $xy$-plane).
Projection Shortcut: To project any point $(a, b, c)$ onto a coordinate plane, simply set the missing coordinate to $0$: onto $xy$-plane $\to (a, b, 0)$; onto $yz$-plane $\to (0, b, c)$; onto $zx$-plane $\to (a, 0, c)$.
  • Coordinate planes: $xy$-plane ($z = 0$), $yz$-plane ($x = 0$), $zx$-plane ($y = 0$) (ကိုဩဒိနိတ် မျက်နှာပြင်များ).
  • A line perpendicular to the $xy$-plane through $(a, b, c)$ has equations $x = a, y = b$.
  • Distance formula: $PQ = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$ (အကွာအဝေး ဖော်မြူလာ).
