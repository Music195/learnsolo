Coordinates of a Point in Space

Extending Geometry into Three Dimensions (3D)

In a 2D plane, every point is identified by an ordered pair of real numbers $(x, y)$. In three-dimensional space, each point is determined by an ordered triple of real numbers $(x, y, z)$.

Through a fixed point called the origin $O(0, 0, 0)$, we construct three mutually perpendicular directed lines: the $x$-axis, the $y$-axis, and the $z$-axis (commonly oriented according to the right-hand rule).

These three axes intersect in pairs to form three fundamental coordinate planes that divide the space into eight regions called octants:

  • $xy$-plane: Contains the $x$-axis and $y$-axis; perpendicular to the $z$-axis. Every point on it has $z = 0$, so its coordinates are $(x, y, 0)$.
  • $yz$-plane: Contains the $y$-axis and $z$-axis; perpendicular to the $x$-axis. Every point on it has $x = 0$, so its coordinates are $(0, y, z)$.
  • $zx$-plane: Contains the $z$-axis and $x$-axis; perpendicular to the $y$-axis. Every point on it has $y = 0$, so its coordinates are $(x, 0, z)$.

Fundamental Equations in 3D Space

1. Coordinate Axes

$x$-axis: $y = 0, \; z = 0$  |  $y$-axis: $x = 0, \; z = 0$  |  $z$-axis: $x = 0, \; y = 0$

2. Planes Parallel to Coordinate Planes

$$\text{Parallel to } xy\text{-plane: } z = c \quad \implies \text{Points: } (x, y, c)$$ $$\text{Parallel to } yz\text{-plane: } x = a \quad \implies \text{Points: } (a, y, z)$$ $$\text{Parallel to } zx\text{-plane: } y = b \quad \implies \text{Points: } (x, b, z)$$

3. Lines Perpendicular to Coordinate Planes (Passing through $(a, b, c)$)

  • Perpendicular to $xy$-plane: $x = a, \; y = b$  (Points: $(a, b, z)$; intersects $xy$-plane at $(a, b, 0)$)
  • Perpendicular to $yz$-plane: $y = b, \; z = c$  (Points: $(x, b, c)$; intersects $yz$-plane at $(0, b, c)$)
  • Perpendicular to $zx$-plane: $x = a, \; z = c$  (Points: $(a, y, c)$; intersects $zx$-plane at $(a, 0, c)$)

4. Distance Between Two Points in Space

$$PQ = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$$

Derivation: In right triangle $PAB$ in the plane, $PB^2 = AB^2 + PA^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2$. In perpendicular right triangle $PBQ$, $PQ^2 = PB^2 + BQ^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2$.

Example 1 (Textbook Page 24)

Find the equations of the line passing through the point $(-3, 5, 7)$ and perpendicular to:
(a) $xy$-plane   (b) $yz$-plane   (c) $zx$-plane.
Find also the point of intersection of the line with each plane.

Show solution
  1. (a) Perpendicular to $xy$-plane:
    Since the line is perpendicular to the $xy$-plane ($z = 0$), its $x$ and $y$ coordinates are fixed at the point's coordinates: $$\text{Equations: } x = -3, \quad y = 5 \quad (\text{or points of form } (-3, 5, z))$$ The intersection with the $xy$-plane ($z = 0$) is $(-3, 5, 0)$.
  2. (b) Perpendicular to $yz$-plane:
    The $y$ and $z$ coordinates are fixed: $$\text{Equations: } y = 5, \quad z = 7 \quad (\text{or points of form } (x, 5, 7))$$ The intersection with the $yz$-plane ($x = 0$) is $(0, 5, 7)$.
  3. (c) Perpendicular to $zx$-plane:
    The $x$ and $z$ coordinates are fixed: $$\text{Equations: } x = -3, \quad z = 7 \quad (\text{or points of form } (-3, y, 7))$$ The intersection with the $zx$-plane ($y = 0$) is $(-3, 0, 7)$.

Example 2: 3D Distance & Right Triangle (Exercise 3.1 Q4)

Show that the points $A(-1, 2, 5)$, $B(1, 1, 6)$, and $C(0, 5, 6)$ form a right-angled triangle.

Show solution
  1. Compute the square of each side length using $d^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2$: $$AB^2 = (1 - (-1))^2 + (1 - 2)^2 + (6 - 5)^2 = 2^2 + (-1)^2 + 1^2 = 4 + 1 + 1 = 6$$ $$BC^2 = (0 - 1)^2 + (5 - 1)^2 + (6 - 6)^2 = (-1)^2 + 4^2 + 0^2 = 1 + 16 + 0 = 17$$ $$AC^2 = (0 - (-1))^2 + (5 - 2)^2 + (6 - 5)^2 = 1^2 + 3^2 + 1^2 = 1 + 9 + 1 = 11$$
  2. Check the converse of Pythagoras' theorem: $$AB^2 + AC^2 = 6 + 11 = 17 = BC^2$$
  3. Since $AB^2 + AC^2 = BC^2$, $\triangle ABC$ is a right-angled triangle with the right angle at vertex $A$.

Example 3: Collinearity in 3D Space (Exercise 3.1 Q5)

Show that the points $P(1, -1, 2)$, $Q(3, -2, 3)$, and $R(5, -3, 4)$ are collinear.

Show solution
  1. Calculate the distances between all pairs of points: $$PQ = \sqrt{(3 - 1)^2 + (-2 - (-1))^2 + (3 - 2)^2} = \sqrt{2^2 + (-1)^2 + 1^2} = \sqrt{4 + 1 + 1} = \sqrt{6}$$ $$QR = \sqrt{(5 - 3)^2 + (-3 - (-2))^2 + (4 - 3)^2} = \sqrt{2^2 + (-1)^2 + 1^2} = \sqrt{4 + 1 + 1} = \sqrt{6}$$ $$PR = \sqrt{(5 - 1)^2 + (-3 - (-1))^2 + (4 - 2)^2} = \sqrt{4^2 + (-2)^2 + 2^2} = \sqrt{16 + 4 + 4} = \sqrt{24} = 2\sqrt{6}$$
  2. Observe that: $$PQ + QR = \sqrt{6} + \sqrt{6} = 2\sqrt{6} = PR$$
  3. Since $PQ + QR = PR$, the point $Q$ lies directly on the line segment connecting $P$ and $R$. Therefore, $P$, $Q$, and $R$ are collinear.

Key Takeaways & Terminology (အဓိကမှတ်သားဖွယ်ရာများ)

  • Three-Dimensional Space (သုံးဖက်မြင် ရပ်ဝန်း): Every point is represented by $(x, y, z)$.
  • Coordinate Planes (ကိုဩဒိနိတ် မျက်နှာပြင်များ): $xy$-plane ($z = 0$), $yz$-plane ($x = 0$), $zx$-plane ($y = 0$).
  • Parallel Planes (အပြိုင် မျက်နှာပြင်များ): $z = c$ is parallel to $xy$-plane; $x = a$ is parallel to $yz$-plane; $y = b$ is parallel to $zx$-plane.
  • Perpendicular Lines (ထောင့်မတ်မျဉ်းများ): Line perpendicular to $xy$-plane through $(a, b, c)$ is $x = a, y = b$.
  • 3D Distance Formula (အကွာအဝေး ဖော်မြူလာ): $d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$.
  • Collinear Points (တစ်ပြေးညီအမှတ်များ): Points $A, B, C$ are collinear if $AB + BC = AC$ (or if direction ratios are proportional).
