Parallel, Skew, and Perpendicular Lines

How Two Lines Can Relate in Three-Dimensional Space

In a 2D plane, any two non-parallel lines must intersect. In 3D space, however, two lines can travel in different directions at different heights (in parallel planes) and never meet! Pairs of lines that are neither parallel nor intersect are called skew lines (စောင်းမျဉ်းများ).

Given two lines $L_1$ and $L_2$ with directed values $(l_1, m_1, n_1)$ and $(l_2, m_2, n_2)$:

  • Parallel ($L_1 \parallel L_2$): Their directed values are scalar multiples of each other: $(l_1, m_1, n_1) = k(l_2, m_2, n_2)$.
  • Perpendicular ($L_1 \perp L_2$): Their directed values satisfy $l_1 l_2 + m_1 m_2 + n_1 n_2 = 0$.
  • Intersecting vs. Skew: If not parallel, equate their parametric coordinates using two distinct parameters $s$ and $t$. If a common solution $(s, t)$ satisfies all three coordinates $x, y, z$, they intersect; otherwise they are skew.

Conditions for Parallel and Perpendicular Lines

$$L_1 \parallel L_2 \iff \frac{l_1}{l_2} = \frac{m_1}{m_2} = \frac{n_1}{n_2} = k \qquad (k \ne 0)$$ $$L_1 \perp L_2 \iff l_1 l_2 + m_1 m_2 + n_1 n_2 = 0$$

For segments $PQ$ with $(PQ) = (l_1, m_1, n_1)$ and $RS$ with $(RS) = (l_2, m_2, n_2)$, apply the exact same tests to $(l_1, m_1, n_1)$ and $(l_2, m_2, n_2)$.

  1. Draw lines through the origin $O$ parallel to $L_1$ and $L_2$, reaching $A(l_1, m_1, n_1)$ and $B(l_2, m_2, n_2)$.
  2. $OA \perp OB \iff OA^2 + OB^2 = AB^2$ by Pythagoras' theorem.
  3. $(l_1^2 + m_1^2 + n_1^2) + (l_2^2 + m_2^2 + n_2^2) = (l_2 - l_1)^2 + (m_2 - m_1)^2 + (n_2 - n_1)^2$, which simplifies by canceling squares to $2(l_1 l_2 + m_1 m_2 + n_1 n_2) = 0 \iff l_1 l_2 + m_1 m_2 + n_1 n_2 = 0$.

Example 1: Testing Parallel, Intersecting, or Skew (Textbook Page 32, Example 5)

Given $P(2, 1, 3)$, $Q(6, -5, 4)$, $R(2, 3, 4)$, and $S(-1, 5, 1)$, determine whether the lines $PQ$ and $RS$ are parallel, skew, or intersect.

Show solution
  1. Directed values: $(PQ) = (6 - 2, -5 - 1, 4 - 3) = (4, -6, 1)$ and $(RS) = (-1 - 2, 5 - 3, 1 - 4) = (-3, 2, -3)$.
  2. Since $\dfrac{4}{-3} \ne \dfrac{-6}{2} \ne \dfrac{1}{-3}$, $(PQ)$ is not a multiple of $(RS)$, so the lines are not parallel.
  3. Write parametric equations with parameters $h$ and $k$:
    Line $PQ$: $(x, y, z) = (2 + 4h, \; 1 - 6h, \; 3 + h)$.
    Line $RS$: $(x, y, z) = (2 - 3k, \; 3 + 2k, \; 4 - 3k)$.
  4. Equate coordinates: $$\begin{cases} 2 + 4h = 2 - 3k & (1) \\ 1 - 6h = 3 + 2k & (2) \\ 3 + h = 4 - 3k & (3) \end{cases}$$ Subtracting $(3)$ from $(1)$ gives $-1 + 3h = -2 \implies h = -\dfrac{1}{3}$.
    Substitute $h = -\dfrac{1}{3}$ into $(1)$: $2 - \dfrac{4}{3} = 2 - 3k \implies k = \dfrac{4}{9}$.
  5. Check $(h, k) = \left(-\dfrac{1}{3}, \dfrac{4}{9}\right)$ in equation $(2)$: $$\text{L.H.S.} = 1 - 6\left(-\frac{1}{3}\right) = 3, \qquad \text{R.H.S.} = 3 + 2\left(\frac{4}{9}\right) = \frac{35}{9} \ne 3$$ Equation $(2)$ is not satisfied, so the lines do not intersect. Therefore, $PQ$ and $RS$ are skew lines.

Lines $PQ$ and $RS$ are skew lines

Example 2: Proving Two Lines Are Perpendicular (Textbook Page 33, Example 6)

Given $P(0, 0, 1)$, $Q(3, 6, 4)$, $R(0, 3, 1)$, and $S(3, 0, 4)$, show that the lines $PQ$ and $RS$ are perpendicular.

Show solution
  1. Find directed values: $$(PQ) = (l_1, m_1, n_1) = (3 - 0, \; 6 - 0, \; 4 - 1) = (3, 6, 3)$$ $$(RS) = (l_2, m_2, n_2) = (3 - 0, \; 0 - 3, \; 4 - 1) = (3, -3, 3)$$
  2. Check $l_1 l_2 + m_1 m_2 + n_1 n_2$: $$(3)(3) + (6)(-3) + (3)(3) = 9 - 18 + 9 = 0$$ Therefore, $PQ \perp RS$.

$l_1 l_2 + m_1 m_2 + n_1 n_2 = 0$, so $PQ \perp RS$

Example 3: Line Through a Point Perpendicular to a Given Line (Textbook Page 34, Example 7)

Find the equation of the line passing through $A(4, 7, -3)$ and perpendicular to the line $(x, y, z) = (8 + 2k, \; -1 + 3k, \; 1 - k)$. Find also their point of intersection.

Show solution
  1. The given line has directed values $(2, 3, -1)$. Let the point of intersection on the line be $P(8 + 2k, -1 + 3k, 1 - k)$.
  2. Directed values of $AP$: $(AP) = (8 + 2k - 4, \; -1 + 3k - 7, \; 1 - k - (-3)) = (4 + 2k, \; -8 + 3k, \; 4 - k)$.
  3. Since $AP$ is perpendicular to the given line: $$2(4 + 2k) + 3(-8 + 3k) + (-1)(4 - k) = 0 \implies 14k - 20 = 0 \implies k = \frac{10}{7}$$ (Or if the point is $(4, 7, -3)$ and line is $(8 + 2k, -1 + 3k, 1 - k)$, plug $k$ back into $P$ and $(AP)$).

Intersection point $\left(\dfrac{76}{7}, \dfrac{23}{7}, -\dfrac{3}{7}\right)$, directed values $(24, -13, 9)$

Always Use Two Different Parameters ($h$ and $k$) When Testing Intersection! Using the same letter $k$ for both lines only checks whether the two points arrive at the intersection at the exact same parameter value, which can miss valid intersections!
Simplifying Directed Values: Before computing $l_1 l_2 + m_1 m_2 + n_1 n_2$, you can divide out any common factor: $(3, 6, 3) \to (1, 2, 1)$ and $(3, -3, 3) \to (1, -1, 1)$, giving $1(1) + 2(-1) + 1(1) = 0$ immediately!
  • Parallel lines: directed values are proportional, $(l_1, m_1, n_1) = c(l_2, m_2, n_2)$ (အပြိုင်မျဉ်းများ).
  • Perpendicular lines: $l_1 l_2 + m_1 m_2 + n_1 n_2 = 0$ (ထောင့်မတ်မျဉ်းများ).
  • Skew lines: neither parallel nor intersecting in 3D space (စောင်းမျဉ်းများ).
