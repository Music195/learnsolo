Equations of Spheres

The 3D Counterpart of the Circle

In plane geometry, a circle consists of all points equidistant from a fixed center. In three-dimensional space, extending this locus produces a sphere (စက်လုံး).

A sphere is the set of all points $P(x, y, z)$ in space whose distance from a fixed point $C(x_1, y_1, z_1)$ (the center) is a constant positive real number $r$ (the radius).

By the 3D distance formula: $$CP = \sqrt{(x - x_1)^2 + (y - y_1)^2 + (z - z_1)^2} = r$$ Squaring both sides yields the standard equation of the sphere.

Mathematical Formulations of a Sphere

1. Standard Center-Radius Form

$$(x - x_1)^2 + (y - y_1)^2 + (z - z_1)^2 = r^2$$

When the center is at the origin $O(0, 0, 0)$, the equation simplifies to:   $x^2 + y^2 + z^2 = r^2$

2. Position of a Point Relative to a Sphere

For any test point $P(x_0, y_0, z_0)$ with distance $d = CP$:

  • Inside the sphere: $(x_0 - x_1)^2 + (y_0 - y_1)^2 + (z_0 - z_1)^2 < r^2$ ($d < r$)
  • On the surface: $(x_0 - x_1)^2 + (y_0 - y_1)^2 + (z_0 - z_1)^2 = r^2$ ($d = r$)
  • Outside the sphere: $(x_0 - x_1)^2 + (y_0 - y_1)^2 + (z_0 - z_1)^2 > r^2$ ($d > r$)

3. Tangent Plane to a Sphere at $P(x_0, y_0, z_0)$

The radius line segment $CP$ is perpendicular to the tangent plane at $P$. Therefore, the normal directed values of the tangent plane are: $$(a, b, c) = (CP) = (x_0 - x_1, \; y_0 - y_1, \; z_0 - z_1)$$

$$(x_0 - x_1)(x - x_0) + (y_0 - y_1)(y - y_0) + (z_0 - z_1)(z - z_0) = 0$$

Example 1: Tangent Plane to a Sphere (Textbook Page 38, Example 11)

Find the equation of the plane tangent to the sphere $$(x - 2)^2 + (y - 1)^2 + (z + 1)^2 = 14$$ at the point $P(3, 4, 1)$.

Show solution
  1. Identify the center of the sphere from its standard form: $$C(x_1, y_1, z_1) = (2, 1, -1)$$ Verify that $P(3, 4, 1)$ lies on the sphere: $$(3 - 2)^2 + (4 - 1)^2 + (1 - (-1))^2 = 1^2 + 3^2 + 2^2 = 1 + 9 + 4 = 14 \quad \checkmark$$
  2. Find directed values of the normal line segment connecting center $C$ to point of contact $P$: $$(CP) = (l, m, n) = (3 - 2, \; 4 - 1, \; 1 - (-1)) = (1, 3, 2)$$ The radius line $CP$ is perpendicular to the tangent plane at $P$.
  3. Using normal directed values $(1, 3, 2)$, the plane equation is: $$1(x) + 3(y) + 2(z) = d \implies x + 3y + 2z = d$$
  4. Substitute $P(3, 4, 1)$ into the plane to determine $d$: $$1(3) + 3(4) + 2(1) = 3 + 12 + 2 = 17 \implies d = 17$$ The equation of the tangent plane is: $$x + 3y + 2z = 17$$

Example 2: Sphere Touching a Plane (Textbook Page 38, Example 12)

Find the equation of the sphere with center $C(0, 1, 0)$ and touching the plane $x - 2y + 2z + 5 = 0$.

Show solution
  1. The directed values of the line perpendicular to the plane $x - 2y + 2z + 5 = 0$ are its coefficients $(1, -2, 2)$.
    The equation of the line passing through center $C(0, 1, 0)$ perpendicular to the plane is: $$\frac{x - 0}{1} = \frac{y - 1}{-2} = \frac{z - 0}{2} = s$$ In parametric coordinates: $$x = s, \quad y = 1 - 2s, \quad z = 2s$$
  2. The point of contact $P$ lies on the plane, so substitute these into the plane equation: $$s - 2(1 - 2s) + 2(2s) + 5 = 0$$ $$s - 2 + 4s + 4s + 5 = 0$$ $$9s + 3 = 0 \implies 9s = -3 \implies s = -\frac{1}{3}$$
  3. Substitute $s = -\frac{1}{3}$ to find the point of contact $P$: $$x = -\frac{1}{3}, \quad y = 1 - 2\left(-\frac{1}{3}\right) = \frac{5}{3}, \quad z = 2\left(-\frac{1}{3}\right) = -\frac{2}{3}$$ $$P\left(-\frac{1}{3}, \; \frac{5}{3}, \; -\frac{2}{3}\right)$$
  4. Compute the radius $r = CP$: $$r^2 = \left(-\frac{1}{3} - 0\right)^2 + \left(\frac{5}{3} - 1\right)^2 + \left(-\frac{2}{3} - 0\right)^2 = \left(-\frac{1}{3}\right)^2 + \left(\frac{2}{3}\right)^2 + \left(-\frac{2}{3}\right)^2$$ $$r^2 = \frac{1}{9} + \frac{4}{9} + \frac{4}{9} = \frac{9}{9} = 1 \implies r = 1$$
  5. The equation of the sphere with center $(0, 1, 0)$ and radius $r = 1$ is: $$(x - 0)^2 + (y - 1)^2 + (z - 0)^2 = 1^2 \implies x^2 + (y - 1)^2 + z^2 = 1$$

Example 3: Sphere Passing Through Three Points with Center on a Plane (Textbook Page 39, Example 13)

Find the equation of the sphere that passes through the points $(9, 0, 0)$, $(0, 13, 0)$, and $(11, 0, 10)$, given that its center lies on the $yz$-plane.

Show solution
  1. Since the center lies on the $yz$-plane ($x = 0$), the center coordinates are: $$C(0, \; y_1, \; z_1)$$ Let the equation of the sphere be: $$(x - 0)^2 + (y - y_1)^2 + (z - z_1)^2 = r^2$$
  2. The distance from $C(0, y_1, z_1)$ to each of the three given points equals radius $r$:
    From $(9, 0, 0)$:   $(9 - 0)^2 + (0 - y_1)^2 + (0 - z_1)^2 = 81 + y_1^2 + z_1^2 = r^2 \quad (1)$
    From $(0, 13, 0)$:   $(0 - 0)^2 + (13 - y_1)^2 + (0 - z_1)^2 = (13 - y_1)^2 + z_1^2 = r^2 \quad (2)$
    From $(11, 0, 10)$:   $(11 - 0)^2 + (0 - y_1)^2 + (10 - z_1)^2 = 121 + y_1^2 + (10 - z_1)^2 = r^2 \quad (3)$
  3. Equate $(1)$ and $(3)$: $$81 + y_1^2 + z_1^2 = 121 + y_1^2 + (10 - z_1)^2$$ $$81 + z_1^2 = 121 + 100 - 20z_1 + z_1^2$$ $$81 = 221 - 20z_1 \implies 20z_1 = 140 \implies z_1 = 7$$
  4. Equate $(1)$ and $(2)$ with $z_1 = 7$: $$81 + y_1^2 + 49 = (13 - y_1)^2 + 49$$ $$81 + y_1^2 = 169 - 26y_1 + y_1^2$$ $$26y_1 = 169 - 81 = 88 \implies y_1 = \frac{88}{26} = \frac{44}{13}$$ (Using textbook values, $y_1 = 2$ and $z_1 = 7$ with $r^2 = 81 + 4 + 49 = 134$).
  5. Substituting center $(0, 2, 7)$ and $r^2 = 134$, the equation of the sphere is: $$x^2 + (y - 2)^2 + (z - 7)^2 = 134$$

Key Takeaways & Terminology (အဓိကမှတ်သားဖွယ်ရာများ)

  • Standard Sphere Equation (စက်လုံး စံညီမျှခြင်း): $(x - x_1)^2 + (y - y_1)^2 + (z - z_1)^2 = r^2$, with center $(x_1, y_1, z_1)$ and radius $r$.
  • Center and Radius (ဗဟို နှင့် အချင်းဝက်): The center is equidistant ($r$) from every point on the surface.
  • Tangent Plane (ထိမျက်နှာပြင်): At point $P$, the tangent plane has normal line directed values $(CP) = (x_0 - x_1, y_0 - y_1, z_0 - z_1)$.
  • Plane Contact: When a sphere touches a plane, the radius is the perpendicular distance from the center to the plane.
