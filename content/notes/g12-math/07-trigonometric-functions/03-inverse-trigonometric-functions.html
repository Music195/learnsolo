Inverse Trigonometric Functions

Concept — Restricting Domains to Define Inverse Trigonometric Functions

Because $\sin x, \cos x,$ and $\tan x$ are periodic, they are not one-to-one on their full domains (a horizontal line intersects their graphs infinitely many times). To define their inverse functions (ပြောင်းပြန် တြိဂံမิติဖန်ရှင်များ), we restrict each function to a standard principal branch where it is strictly one-to-one and covers its entire range:

  • $\sin x$ restricted to $\left[-\dfrac{\pi}{2},\, \dfrac{\pi}{2}\right]$ is one-to-one with range $[-1, 1]$ $\implies$ defines $y = \sin^{-1}x$.
  • $\cos x$ restricted to $[0,\, \pi]$ is one-to-one with range $[-1, 1]$ $\implies$ defines $y = \cos^{-1}x$.
  • $\tan x$ restricted to $\left(-\dfrac{\pi}{2},\, \dfrac{\pi}{2}\right)$ is one-to-one with range $\mathbb{R}$ $\implies$ defines $y = \tan^{-1}x$.
Core Formulas — Definitions, Domains, Principal Ranges & Identities
  • Principal Value Definitions: $$y = \sin^{-1}x \iff x = \sin y \quad \text{with Domain } -1 \le x \le 1 \text{ and Range } -\frac{\pi}{2} \le y \le \frac{\pi}{2}$$ $$y = \cos^{-1}x \iff x = \cos y \quad \text{with Domain } -1 \le x \le 1 \text{ and Range } 0 \le y \le \pi$$ $$y = \tan^{-1}x \iff x = \tan y \quad \text{with Domain } x \in \mathbb{R} \text{ and Range } -\frac{\pi}{2} < y < \frac{\pi}{2}$$
  • Cancellation Laws: $$\sin(\sin^{-1}x) = x \;\; (-1 \le x \le 1), \qquad \cos(\cos^{-1}x) = x \;\; (-1 \le x \le 1), \qquad \tan(\tan^{-1}x) = x \;\; (x \in \mathbb{R})$$ Caution: $\sin^{-1}(\sin x) = x$ holds ONLY when $-\frac{\pi}{2} \le x \le \frac{\pi}{2}$ (and $\cos^{-1}(\cos x) = x$ only when $0 \le x \le \pi$).
  • Negative-Argument & Complementary Identities: $$\sin^{-1}(-x) = -\sin^{-1}x \;\; (\text{odd}), \qquad \tan^{-1}(-x) = -\tan^{-1}x \;\; (\text{odd}), \qquad \cos^{-1}(-x) = \pi - \cos^{-1}x$$ $$\sin^{-1}x + \cos^{-1}x = \frac{\pi}{2} \quad \text{for all } x \in [-1, 1]$$
Proof — Why $\cos^{-1}(-x) = \pi - \cos^{-1}x$ and $\sin^{-1}x + \cos^{-1}x = \frac{\pi}{2}$

1. Proof of $\cos^{-1}(-x) = \pi - \cos^{-1}x$: Let $\theta = \cos^{-1}x$, where $x \in [-1, 1]$ and $0 \le \theta \le \pi$. Then $\cos\theta = x$ and $0 \le \pi - \theta \le \pi$. Using the supplementary angle identity $\cos(\pi - \theta) = -\cos\theta$:

$$\cos(\pi - \theta) = -x \implies \pi - \theta = \cos^{-1}(-x) \quad (\text{since } \pi - \theta \in [0, \pi])$$

Substituting $\theta = \cos^{-1}x$ gives $\cos^{-1}(-x) = \pi - \cos^{-1}x$.

2. Proof of $\sin^{-1}x + \cos^{-1}x = \frac{\pi}{2}$ (Exercise 7.4 #5): Let $y = \sin^{-1}x$, where $-\frac{\pi}{2} \le y \le \frac{\pi}{2}$. Then $x = \sin y = \cos\!\left(\frac{\pi}{2} - y\right)$. Since $-\frac{\pi}{2} \le y \le \frac{\pi}{2}$, we have $0 \le \frac{\pi}{2} - y \le \pi$, which lies in the principal range of $\cos^{-1}$. Therefore $\cos^{-1}x = \frac{\pi}{2} - y = \frac{\pi}{2} - \sin^{-1}x$, so $\sin^{-1}x + \cos^{-1}x = \frac{\pi}{2}$. $\blacksquare$

Worked Examples — Textbook Example 8 & Exercise 7.4

Example 8 (Evaluating Principal Values & Composite Inverse Expressions): Evaluate:
(a) $\sin^{-1}\!\left(\frac{1}{2}\right)$   (b) $\cos^{-1}\!\left(-\frac{1}{2}\right)$   (c) $\tan^{-1}(-\sqrt{3})$   (d) $\sin^{-1}\!\left(\sin\frac{5\pi}{6}\right)$.

Show step-by-step solution
  • (a) Since $\sin\frac{\pi}{6} = \frac{1}{2}$ and $-\frac{\pi}{2} \le \frac{\pi}{6} \le \frac{\pi}{2}$, we have $\sin^{-1}\!\left(\frac{1}{2}\right) = \dfrac{\pi}{6}$.
  • (b) Since $\cos\frac{2\pi}{3} = -\frac{1}{2}$ and $0 \le \frac{2\pi}{3} \le \pi$, we have $\cos^{-1}\!\left(-\frac{1}{2}\right) = \dfrac{2\pi}{3}$ (or via $\pi - \cos^{-1}\frac{1}{2} = \pi - \frac{\pi}{3} = \frac{2\pi}{3}$).
  • (c) Since $\tan\!\left(-\frac{\pi}{3}\right) = -\sqrt{3}$ and $-\frac{\pi}{2} < -\frac{\pi}{3} < \frac{\pi}{2}$, we have $\tan^{-1}(-\sqrt{3}) = -\dfrac{\pi}{3}$.
  • (d) Notice that $\frac{5\pi}{6}$ lies outside the principal interval $\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$, so the answer is NOT $\frac{5\pi}{6}$! Instead, evaluate the inner sine first: $$\sin^{-1}\!\left(\sin\frac{5\pi}{6}\right) = \sin^{-1}\!\left(\frac{1}{2}\right) = \frac{\pi}{6}$$

Answer: (a) $\dfrac{\pi}{6}$, (b) $\dfrac{2\pi}{3}$, (c) $-\dfrac{\pi}{3}$, (d) $\dfrac{\pi}{6}$.

Exercise 7.4 #1 & #3 (Evaluating Trig of Inverse Trig via Right Triangles): Evaluate:
(a) $\csc(\sin^{-1} 0.3)$   (b) $\sin\!\left(\cos^{-1}\frac{\sqrt{2}}{2}\right)$   (c) $\tan\!\left(\sin^{-1}\!\left(-\frac{\sqrt{3}}{2}\right)\right)$.

Show step-by-step solution

(a) Let $\theta = \sin^{-1}(0.3)$, so $\sin\theta = 0.3 = \frac{3}{10}$. Then $\csc(\sin^{-1} 0.3) = \csc\theta = \dfrac{1}{\sin\theta} = \dfrac{1}{0.3} = \dfrac{10}{3}$.

(b) Since $\cos^{-1}\frac{\sqrt{2}}{2} = \frac{\pi}{4}$, we get $\sin\frac{\pi}{4} = \dfrac{\sqrt{2}}{2}$.

(c) Since $\sin^{-1}\!\left(-\frac{\sqrt{3}}{2}\right) = -\frac{\pi}{3}$, we get $\tan\!\left(-\frac{\pi}{3}\right) = -\sqrt{3}$.

Answer: (a) $\dfrac{10}{3}$, (b) $\dfrac{\sqrt{2}}{2}$, (c) $-\sqrt{3}$.

Common Mistakes to Avoid
  • The $\sin^{-1}(\sin x) = x$ Trap (Example 8d): Never cancel $\sin^{-1}(\sin x)$ to $x$ when $x \notin \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$! Always check whether the angle lies inside the principal range first.
  • Quadrant II vs. Quadrant IV for Negative Inputs: For negative $x < 0$, $\sin^{-1}x$ and $\tan^{-1}x$ return negative Quadrant IV angles in $\left[-\frac{\pi}{2}, 0\right)$, whereas $\cos^{-1}x$ returns an obtuse Quadrant II angle in $\left(\frac{\pi}{2}, \pi\right]$!
Exam Tip — Horizontal Asymptotes of $y = \tan^{-1}x$

Just as $y = \tan x$ on $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ has vertical asymptotes $x = \pm\frac{\pi}{2}$, its inverse $y = \tan^{-1}x$ swaps $x$ and $y$ and therefore has horizontal asymptotes $y = \frac{\pi}{2}$ (as $x \to +\infty$) and $y = -\frac{\pi}{2}$ (as $x \to -\infty$).

Key Takeaways (မှတ်သားရန် အချက်များ)
  • Principal Ranges (အဓိက တန်ဖိုးနယ်ပယ်များ): $\sin^{-1}x \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$, $\cos^{-1}x \in [0, \pi]$, and $\tan^{-1}x \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$.
  • Negative-Argument Laws: $\sin^{-1}(-x) = -\sin^{-1}x$, $\tan^{-1}(-x) = -\tan^{-1}x$, and $\cos^{-1}(-x) = \pi - \cos^{-1}x$.
  • Complementary Sum: $\sin^{-1}x + \cos^{-1}x = \dfrac{\pi}{2}$ for all $x \in [-1, 1]$.
