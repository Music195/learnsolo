Powers and De Moivre's Theorem

Computing Large Powers Without Tedious Binomial Expansions

Expanding high powers like $(1 + \sqrt{3}i)^{10}$ by hand requires massive calculations using the binomial theorem. However, using the trigonometric form, multiplying a number by itself simply multiplies its modulus and adds its argument repeatedly.

For any complex number $z = r(\cos\theta + i\sin\theta)$ and any integer $n$, we obtain the celebrated De Moivre's Theorem (ဒီမွိုက်ဗာသီအိုရမ်): $$z^n = r^n [\cos(n\theta) + i\sin(n\theta)]$$

This theorem holds for all integers: positive powers, zero ($z^0 = 1$), and negative powers ($z^{-n} = \frac{1}{z^n}$).

De Moivre's Theorem

$$[r(\cos\theta + i\sin\theta)]^n = r^n (\cos n\theta + i\sin n\theta) \qquad (n \in \mathbb{Z})$$

When $r = 1$ (points on the unit circle):   $(\cos\theta + i\sin\theta)^n = \cos(n\theta) + i\sin(n\theta)$

Negative Integer Powers

$$z^{-n} = r^{-n} [\cos(-n\theta) + i\sin(-n\theta)] = \frac{1}{r^n} [\cos(n\theta) - i\sin(n\theta)]$$

n = 3

Example 1 (Textbook Page 10, Example 9a)

Given $z = 1 + \sqrt{3}i$, compute $z^{10}$.

Show solution
  1. Convert $z$ to trigonometric form: $$r = \sqrt{1^2 + (\sqrt{3})^2} = 2, \quad \theta = \frac{\pi}{3} \implies z = 2\left(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}\right)$$
  2. Apply De Moivre's Theorem with $n = 10$: $$z^{10} = 2^{10} \left[\cos\left(10 \times \frac{\pi}{3}\right) + i\sin\left(10 \times \frac{\pi}{3}\right)\right]$$
  3. Compute modulus: $2^{10} = 1024$.
  4. Simplify the angle $\frac{10\pi}{3}$: $$\frac{10\pi}{3} = 3\pi + \frac{\pi}{3} = 2\pi + \frac{4\pi}{3} \equiv \frac{4\pi}{3} \quad\left(\text{or } -\frac{2\pi}{3}\right)$$
  5. Evaluate trigonometric values: $$\cos\frac{4\pi}{3} = -\frac{1}{2}, \quad \sin\frac{4\pi}{3} = -\frac{\sqrt{3}}{2}$$
  6. Multiply out: $$z^{10} = 1024 \left(-\frac{1}{2} - \frac{\sqrt{3}}{2}i\right) = -512 - 512\sqrt{3}i$$

$-512 - 512\sqrt{3}i$

Example 2 (Textbook Page 10, Example 9b)

Given $z = 1 + \sqrt{3}i$, compute $z^{-10}$.

Show solution
  1. Using $z^{10} = 1024\left(\cos\frac{10\pi}{3} + i\sin\frac{10\pi}{3}\right)$: $$z^{-10} = \frac{1}{z^{10}} = 2^{-10} \left[\cos\left(-\frac{10\pi}{3}\right) + i\sin\left(-\frac{10\pi}{3}\right)\right]$$
  2. Evaluate: $\cos(-\frac{10\pi}{3}) = \cos(\frac{10\pi}{3}) = -\frac{1}{2}$ and $\sin(-\frac{10\pi}{3}) = -\sin(\frac{10\pi}{3}) = +\frac{\sqrt{3}}{2}$.
  3. Multiply by $\frac{1}{1024}$: $$z^{-10} = \frac{1}{1024}\left(-\frac{1}{2} + \frac{\sqrt{3}}{2}i\right) = -\frac{1}{2048} + \frac{\sqrt{3}}{2048}i$$

$-\dfrac{1}{2048} + \dfrac{\sqrt{3}}{2048}i$

Example 3 (Simplifying a Trigonometric Power)

Evaluate $\left(\dfrac{1 + i}{\sqrt{2}}\right)^8$.

Show solution
  1. Notice that $\frac{1 + i}{\sqrt{2}} = \frac{1}{\sqrt{2}} + \frac{1}{\sqrt{2}}i = \cos\frac{\pi}{4} + i\sin\frac{\pi}{4}$.
  2. Apply De Moivre's Theorem: $$\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)^8 = \cos\left(8 \times \frac{\pi}{4}\right) + i\sin\left(8 \times \frac{\pi}{4}\right) = \cos(2\pi) + i\sin(2\pi)$$
  3. Since $\cos(2\pi) = 1$ and $\sin(2\pi) = 0$, the answer is simply $1$.

$1$

Always ensure form is $\cos\theta + i\sin\theta$: De Moivre's Theorem applies when the real part is cosine and the imaginary part is sine, separated by a plus sign. If given $\sin\theta + i\cos\theta$, convert it first using complementary angle formulas: $\sin\theta = \cos(\frac{\pi}{2} - \theta)$ and $\cos\theta = \sin(\frac{\pi}{2} - \theta)$.
Angle Reduction: When $n\theta$ is large (e.g. $10\theta = \frac{10\pi}{3}$), subtract multiples of $2\pi$ to find an equivalent angle within $[0, 2\pi)$ or $(-\pi, \pi]$: $$\frac{10\pi}{3} - 2\pi = \frac{4\pi}{3}$$
  • $[r(\cos\theta + i\sin\theta)]^n = r^n(\cos n\theta + i\sin n\theta)$ (ဒီမွိုက်ဗာသီအိုရမ်).
  • The modulus is raised to the power $n$ ($r \to r^n$), and the angle is multiplied by $n$ ($\theta \to n\theta$).
  • Applies to all integer exponents (အပေါင်း၊ သုည နှင့် အနုတ်ကိန်းပြည့်အားလုံးအတွက်မှန်ကန်သည်).
