Powers and De Moivre's Theorem

Repeated Polar Multiplication Multiplies the Angle by $n$

Computing high powers like $(1 + \sqrt{3}i)^{10}$ by repeated binomial expansion is tedious. In trigonometric form, however, multiplying a complex number by itself $n$ times simply raises its modulus to the $n$-th power and multiplies its argument by $n$!

This fundamental result is known as De Moivre's Theorem (ဒီမွိုက်ဗာ သီအိုရမ်), and it holds for every integer $n \in \mathbb{Z}$ (positive, zero, and negative).

De Moivre's Theorem for Any Integer $n \in \mathbb{Z}$

$$z^n = \left[r(\cos\theta + i\sin\theta)\right]^n = r^n (\cos n\theta + i\sin n\theta)$$

• Unit circle case ($r = 1$): $(\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta$.
• Negative powers ($n = -m$): $z^{-m} = r^{-m}\left[\cos(-m\theta) + i\sin(-m\theta)\right] = \dfrac{1}{r^m}(\cos m\theta - i\sin m\theta)$.

  1. For $n = 1$, $[r(\cos\theta + i\sin\theta)]^1 = r^1(\cos 1\theta + i\sin 1\theta)$ holds trivially.
  2. Assume the formula holds for $n = k$: $z^k = r^k(\cos k\theta + i\sin k\theta)$.
  3. Multiply by $z = r(\cos\theta + i\sin\theta)$ using the polar multiplication rule: $$z^{k+1} = r^k r \left[\cos(k\theta + \theta) + i\sin(k\theta + \theta)\right] = r^{k+1}\left[\cos(k+1)\theta + i\sin(k+1)\theta\right]$$ By mathematical induction, it holds for all positive integers $n$, and by $z^{-n} = (z^{-1})^n$ for negative integers as well.

Drag $z$ and change $n$: watch $1, z, z^2, \dots, z^n$ spiral and rotate

Example 1 (Textbook Page 10, Example 9a)

Given $z = 1 + \sqrt{3}i$, compute $z^{10}$.

Show solution
  1. Convert $z$ to trigonometric form: $$r = \sqrt{1^2 + (\sqrt{3})^2} = 2, \quad \theta = \frac{\pi}{3} \implies z = 2\left(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}\right)$$
  2. Apply De Moivre's Theorem with $n = 10$: $$z^{10} = 2^{10}\left(\cos\frac{10\pi}{3} + i\sin\frac{10\pi}{3}\right) = 1024\left(\cos\frac{4\pi}{3} + i\sin\frac{4\pi}{3}\right)$$
  3. Substitute $\cos\frac{4\pi}{3} = -\frac{1}{2}$ and $\sin\frac{4\pi}{3} = -\frac{\sqrt{3}}{2}$: $$z^{10} = 1024\left(-\frac{1}{2} - \frac{\sqrt{3}}{2}i\right) = -512 - 512\sqrt{3}i$$

$-512 - 512\sqrt{3}i$

Example 2 (Textbook Page 10, Example 9b)

Given $z = 1 + \sqrt{3}i$, compute $z^{-10}$.

Show solution
  1. Apply De Moivre's Theorem with $n = -10$: $$z^{-10} = 2^{-10}\left[\cos\left(-\frac{10\pi}{3}\right) + i\sin\left(-\frac{10\pi}{3}\right)\right]$$
  2. Since $\cos(-\frac{10\pi}{3}) = -\frac{1}{2}$ and $\sin(-\frac{10\pi}{3}) = +\frac{\sqrt{3}}{2}$: $$z^{-10} = \frac{1}{1024}\left(-\frac{1}{2} + \frac{\sqrt{3}}{2}i\right) = -\frac{1}{2048} + \frac{\sqrt{3}}{2048}i$$

$-\dfrac{1}{2048} + \dfrac{\sqrt{3}}{2048}i$

Example 3 (Powers on the Unit Circle)

Evaluate $\left(\dfrac{1 + i}{\sqrt{2}}\right)^8$.

Show solution
  1. Write in polar form: $\dfrac{1 + i}{\sqrt{2}} = \cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}$.
  2. Raise to power $8$: $\cos\left(8 \times \dfrac{\pi}{4}\right) + i\sin\left(8 \times \dfrac{\pi}{4}\right) = \cos 2\pi + i\sin 2\pi = 1$.

$1$

Standard Form Required: De Moivre's Theorem requires $\cos\theta + i\sin\theta$ (cosine in the real part, sine in the imaginary part). If given $\sin\theta + i\cos\theta$, rewrite it first as $\cos\left(\frac{\pi}{2} - \theta\right) + i\sin\left(\frac{\pi}{2} - \theta\right)$.
Spiral Behavior: Compare $|z|$ to the unit circle $r = 1$: if $r > 1$, powers $z^n$ spiral outward; if $r = 1$, powers stay on the unit circle; if $r < 1$, powers spiral inward toward $0$.
  • $[r(\cos\theta + i\sin\theta)]^n = r^n(\cos n\theta + i\sin n\theta)$ (ဒီမွိုက်ဗာ သီအိုရမ်).
  • Modulus is raised to the $n$-th power ($r \to r^n$), while the angle is multiplied by $n$ ($\theta \to n\theta$).
  • Valid for all positive, zero, and negative integer exponents $n \in \mathbb{Z}$.
