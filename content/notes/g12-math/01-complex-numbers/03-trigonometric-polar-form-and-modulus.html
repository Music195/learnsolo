Trigonometric and Polar Form

Describing a Complex Number by Distance $r$ and Angle $\theta$

Instead of rectangular coordinates $(x, y)$, any non-zero complex number $z = x + yi$ can be located on the complex plane by its distance $r$ from the origin $O$ and the directed angle $\theta$ from the positive real axis: $$x = r\cos\theta, \qquad y = r\sin\theta$$

Substituting these into $z = x + yi$ gives the trigonometric (polar) form (တြိဂိုနိုမေတြီပုံစံ): $$z = r(\cos\theta + i\sin\theta)$$ Here $r = |z| = \sqrt{x^2 + y^2}$ is the modulus (မော်ဂျူးလပ်စ်) and $\theta = \arg(z)$ is the argument (အာဂူးမန့်), usually chosen in the principal range $-\pi < \theta \le \pi$.

Modulus, Argument, Multiplication & Division in Polar Form

$$r = |z| = \sqrt{x^2 + y^2}, \qquad \cos\theta = \frac{x}{r}, \quad \sin\theta = \frac{y}{r}$$ $$z_1 z_2 = r_1 r_2 \left[\cos(\theta_1 + \theta_2) + i\sin(\theta_1 + \theta_2)\right]$$ $$\frac{z_1}{z_2} = \frac{r_1}{r_2} \left[\cos(\theta_1 - \theta_2) + i\sin(\theta_1 - \theta_2)\right] \qquad (z_2 \ne 0)$$

• Multiply: Multiply moduli ($r_1 r_2$) and add arguments ($\theta_1 + \theta_2$).
• Divide: Divide moduli ($r_1 / r_2$) and subtract arguments ($\theta_1 - \theta_2$).
• Inverse: $z^{-1} = \dfrac{1}{r}\left[\cos(-\theta) + i\sin(-\theta)\right] = \dfrac{1}{r}(\cos\theta - i\sin\theta)$.

  1. Multiply $z_1 = r_1(\cos\theta_1 + i\sin\theta_1)$ and $z_2 = r_2(\cos\theta_2 + i\sin\theta_2)$: $$z_1 z_2 = r_1 r_2 \left[(\cos\theta_1\cos\theta_2 - \sin\theta_1\sin\theta_2) + i(\sin\theta_1\cos\theta_2 + \cos\theta_1\sin\theta_2)\right]$$
  2. By the compound-angle identities for $\cos(\theta_1 + \theta_2)$ and $\sin(\theta_1 + \theta_2)$, this simplifies directly to: $$z_1 z_2 = r_1 r_2 \left[\cos(\theta_1 + \theta_2) + i\sin(\theta_1 + \theta_2)\right]$$

Example 1 (Textbook Page 7, Example 5)

Find the trigonometric form ($-\pi < \theta \le \pi$) for $z_1 = 1 + \sqrt{3}i$ and $z_2 = -1 + i$.

Show solution
  1. For $z_1 = 1 + \sqrt{3}i$:
    $r_1 = \sqrt{1^2 + (\sqrt{3})^2} = \sqrt{4} = 2$.
    $\cos\theta_1 = \frac{1}{2}$, $\sin\theta_1 = \frac{\sqrt{3}}{2}$ (Quadrant I) $\implies \theta_1 = \frac{\pi}{3}$ ($60^\circ$).
    $$z_1 = 2\left(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}\right)$$
  2. For $z_2 = -1 + i$:
    $r_2 = \sqrt{(-1)^2 + 1^2} = \sqrt{2}$.
    $\cos\theta_2 = -\frac{1}{\sqrt{2}}$, $\sin\theta_2 = \frac{1}{\sqrt{2}}$ (Quadrant II) $\implies \theta_2 = \frac{3\pi}{4}$ ($135^\circ$).
    $$z_2 = \sqrt{2}\left(\cos\frac{3\pi}{4} + i\sin\frac{3\pi}{4}\right)$$

$z_1 = 2\left(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}\right)$ and $z_2 = \sqrt{2}\left(\cos\frac{3\pi}{4} + i\sin\frac{3\pi}{4}\right)$

Example 2 (Textbook Page 8, Example 6)

Given $z_1 = 1 + \sqrt{3}i$ and $z_2 = -1 + i$, find $z_1 z_2$ in trigonometric form and verify by direct expansion.

Show solution
  1. Multiply moduli and add arguments: $$z_1 z_2 = 2\sqrt{2}\left[\cos\left(\frac{\pi}{3} + \frac{3\pi}{4}\right) + i\sin\left(\frac{\pi}{3} + \frac{3\pi}{4}\right)\right] = 2\sqrt{2}\left(\cos\frac{13\pi}{12} + i\sin\frac{13\pi}{12}\right)$$
  2. In principal argument $(-\pi, \pi]$, $\frac{13\pi}{12} - 2\pi = -\frac{11\pi}{12}$.
  3. Direct expansion: $(1 + \sqrt{3}i)(-1 + i) = (-1 - \sqrt{3}) + (1 - \sqrt{3})i$.

$2\sqrt{2}\left(\cos\frac{13\pi}{12} + i\sin\frac{13\pi}{12}\right) = (-1 - \sqrt{3}) + (1 - \sqrt{3})i$

Example 3 (Textbook Page 10, Example 8)

Find $\dfrac{z_1}{z_2}$ for $z_1 = 1 + \sqrt{3}i$ and $z_2 = -1 + i$ in trigonometric form.

Show solution
  1. Divide moduli: $\dfrac{r_1}{r_2} = \dfrac{2}{\sqrt{2}} = \sqrt{2}$.
  2. Subtract arguments: $\theta_1 - \theta_2 = \dfrac{\pi}{3} - \dfrac{3\pi}{4} = -\dfrac{5\pi}{12}$.

$\dfrac{z_1}{z_2} = \sqrt{2}\left[\cos\left(-\frac{5\pi}{12}\right) + i\sin\left(-\frac{5\pi}{12}\right)\right]$

Check the Quadrant! Both $(1, 1)$ in Quadrant I and $(-1, -1)$ in Quadrant III have $\tan\theta = \frac{y}{x} = 1$. Always check the signs of $\cos\theta = \frac{x}{r}$ and $\sin\theta = \frac{y}{r}$ separately to determine the correct quadrant!
Geometric Meaning: Multiplying by $r(\cos\theta + i\sin\theta)$ stretches distances from the origin by factor $r$ and rotates counterclockwise by angle $\theta$.
  • $z = r(\cos\theta + i\sin\theta)$ with modulus $r = \sqrt{x^2 + y^2}$ (မော်ဂျူးလပ်စ်) and argument $\theta$ (အာဂူးမန့်).
  • Multiplication: multiply moduli and add arguments (အလျားများကိုမြှောက်၊ ထောင့်များကိုပေါင်း).
  • Division: divide moduli and subtract arguments (အလျားများကိုစား၊ ထောင့်များကိုနုတ်).
