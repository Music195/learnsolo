Trigonometric and Polar Form

Representing Complex Numbers Using Distance and Angle

In the complex plane, every number $z = x + yi$ corresponds to a unique geometric point $(x, y)$. Instead of horizontal and vertical distances ($x$ and $y$), we can locate this point using:

  • Modulus ($r$ or $|z|$): The straight-line distance from the origin $(0, 0)$ to the point $z$.
  • Argument ($\theta$): The counterclockwise angle, in radians, from the positive real axis to the line segment $Oz$ ($-\pi < \theta \le \pi$).

Using trigonometry, $x = r \cos\theta$ and $y = r \sin\theta$. Substituting these into $z = x + yi$ gives the trigonometric form (ထောင့်ချိုးပုံစံ) of a complex number: $$z = r(\cos\theta + i\sin\theta)$$

Modulus, Argument & Polar Operations

$$z = r(\cos\theta + i\sin\theta) = (r, \theta)$$

Modulus: $r = |z| = \sqrt{x^2 + y^2} \ge 0$  |  Argument: $\cos\theta = \dfrac{x}{r}, \quad \sin\theta = \dfrac{y}{r}$

1. Multiplication in Trigonometric Form

Multiply the lengths, add the angles:

$$z_1 z_2 = r_1 r_2 \left[\cos(\theta_1 + \theta_2) + i\sin(\theta_1 + \theta_2)\right]$$

2. Division in Trigonometric Form

Divide the lengths, subtract the angles:

$$\frac{z_1}{z_2} = \frac{r_1}{r_2} \left[\cos(\theta_1 - \theta_2) + i\sin(\theta_1 - \theta_2)\right] \qquad (z_2 \ne 0)$$

3. Multiplicative Inverse

$z^{-1} = \dfrac{1}{r} \left[\cos(-\theta) + i\sin(-\theta)\right]$

Example 1 (Textbook Page 7, Example 5)

Find the trigonometric form ($-\pi < \theta \le \pi$) for $z = 1 + \sqrt{3}i$ and $z = -1 + i$.

Show solution
  1. For $z = 1 + \sqrt{3}i$:
    $r = \sqrt{1^2 + (\sqrt{3})^2} = \sqrt{1 + 3} = \sqrt{4} = 2$.
    $\cos\theta = \frac{1}{2}$, $\sin\theta = \frac{\sqrt{3}}{2}$. Since both are positive, $\theta$ is in Quadrant I: $\theta = \frac{\pi}{3}$ ($60^\circ$).
    Therefore: $z = 2\left(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}\right)$.
  2. For $z = -1 + i$:
    $r = \sqrt{(-1)^2 + 1^2} = \sqrt{2}$.
    $\cos\theta = -\frac{1}{\sqrt{2}}$, $\sin\theta = \frac{1}{\sqrt{2}}$. Point $(-1, 1)$ is in Quadrant II: $\theta = \pi - \frac{\pi}{4} = \frac{3\pi}{4}$.
    Therefore: $z = \sqrt{2}\left(\cos\frac{3\pi}{4} + i\sin\frac{3\pi}{4}\right)$.

$2\left(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}\right)$ and $\sqrt{2}\left(\cos\frac{3\pi}{4} + i\sin\frac{3\pi}{4}\right)$

Example 2 (Textbook Page 8, Example 6)

Given $z_1 = 1 + \sqrt{3}i$ and $z_2 = -1 + i$, find $z_1 z_2$ using trigonometric forms and verify by direct multiplication.

Show solution
  1. From Example 1: $z_1 = 2(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3})$ and $z_2 = \sqrt{2}(\cos\frac{3\pi}{4} + i\sin\frac{3\pi}{4})$.
  2. Apply the multiplication rule: $$z_1 z_2 = (2)(\sqrt{2})\left[\cos\left(\frac{\pi}{3} + \frac{3\pi}{4}\right) + i\sin\left(\frac{\pi}{3} + \frac{3\pi}{4}\right)\right]$$
  3. Add the angles: $\frac{\pi}{3} + \frac{3\pi}{4} = \frac{4\pi + 9\pi}{12} = \frac{13\pi}{12}$.
    $$z_1 z_2 = 2\sqrt{2}\left(\cos\frac{13\pi}{12} + i\sin\frac{13\pi}{12}\right)$$
  4. Direct verification:
    $(1 + \sqrt{3}i)(-1 + i) = -1 + i - \sqrt{3}i + \sqrt{3}i^2 = (-1 - \sqrt{3}) + (1 - \sqrt{3})i$. ✓

$2\sqrt{2}\left(\cos\frac{13\pi}{12} + i\sin\frac{13\pi}{12}\right) = (-1 - \sqrt{3}) + (1 - \sqrt{3})i$

Example 3 (Textbook Page 10, Example 8)

Find $\dfrac{z_1}{z_2}$ for $z_1 = 1 + \sqrt{3}i$ and $z_2 = -1 + i$ using trigonometric form.

Show solution
  1. Apply the division rule: $$\frac{z_1}{z_2} = \frac{2}{\sqrt{2}}\left[\cos\left(\frac{\pi}{3} - \frac{3\pi}{4}\right) + i\sin\left(\frac{\pi}{3} - \frac{3\pi}{4}\right)\right]$$
  2. Calculate length ratio: $\frac{2}{\sqrt{2}} = \sqrt{2}$.
  3. Subtract the angles: $\frac{\pi}{3} - \frac{3\pi}{4} = \frac{4\pi - 9\pi}{12} = -\frac{5\pi}{12}$.
  4. Result: $$\frac{z_1}{z_2} = \sqrt{2}\left[\cos\left(-\frac{5\pi}{12}\right) + i\sin\left(-\frac{5\pi}{12}\right)\right]$$

$\sqrt{2}\left[\cos\left(-\frac{5\pi}{12}\right) + i\sin\left(-\frac{5\pi}{12}\right)\right]$

Check the Quadrant: $\tan\theta = \frac{y}{x}$ has period $\pi$, so $\tan\theta = 1$ could mean $\theta = \frac{\pi}{4}$ (Quadrant I) or $\theta = -\frac{3\pi}{4}$ (Quadrant III). Always look at the signs of both $x$ and $y$ to choose the correct angle!
Geometric Meaning of Multiplication: Multiplying any complex number by $z = r(\cos\theta + i\sin\theta)$ scales its distance from the origin by $r$ and rotates it counterclockwise by angle $\theta$.
  • $z = r(\cos\theta + i\sin\theta)$ where $r = \sqrt{x^2 + y^2}$ (မော်ဂျူးလပ်စ်) and $\theta = \text{arg}(z)$ (အာဂူးမန့်).
  • To multiply complex numbers in polar form, multiply their moduli and add their arguments (အလျားများကိုမြှောက်၊ ထောင့်များကိုပေါင်း).
  • To divide, divide their moduli and subtract their arguments (အလျားများကိုစား၊ ထောင့်များကိုနုတ်).
