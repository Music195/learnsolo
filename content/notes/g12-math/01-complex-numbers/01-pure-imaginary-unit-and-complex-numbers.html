Pure Imaginary Unit and Complex Numbers

Extending the Real Numbers Beyond $x^2 \ge 0$

For every real number $x$, its square is always non-negative ($x^2 \ge 0$). Because of this, simple quadratic equations like $x^2 = -1$ or $x^2 + 4 = 0$ have no real solution.

To solve such equations, we introduce the pure imaginary unit $i$ (စိတ်ကူးယဉ်ယူနစ်), defined by the property: $$i^2 = -1 \qquad (\text{so } i = \sqrt{-1})$$

Combining real numbers with the imaginary unit produces complex numbers (ကွန်ပလက်စ်ကိန်းများ) of the form $z = x + yi$, which correspond one-to-one with ordered pairs $(x, y)$ on the complex plane.

Complex Numbers $z = x + yi = (x, y)$

$$(x_1, y_1) + (x_2, y_2) = (x_1 + x_2, \; y_1 + y_2)$$ $$(x_1, y_1)(x_2, y_2) = (x_1 x_2 - y_1 y_2, \; x_1 y_2 + x_2 y_1)$$

$x = \text{Re}(z)$ is the real part and $y = \text{Im}(z)$ is the imaginary part.
• Equality: $(x_1, y_1) = (x_2, y_2) \iff x_1 = x_2$ and $y_1 = y_2$.
• Cyclic Powers of $i$: $i^1 = i, \;\; i^2 = -1, \;\; i^3 = -i, \;\; i^4 = 1, \;\; i^{4k+r} = i^r$.

  1. Write $(x_1, y_1) = x_1 + y_1 i$ and $(x_2, y_2) = x_2 + y_2 i$, then expand using the distributive law: $$(x_1 + y_1 i)(x_2 + y_2 i) = x_1 x_2 + x_1 y_2 i + y_1 x_2 i + y_1 y_2 i^2$$
  2. Substitute $i^2 = -1$, so $y_1 y_2 i^2 = -y_1 y_2$.
  3. Group real and imaginary parts: $(x_1 x_2 - y_1 y_2) + (x_1 y_2 + x_2 y_1)i = (x_1 x_2 - y_1 y_2, \; x_1 y_2 + x_2 y_1)$.

Drag $z = (x, y)$ on the Complex Plane: projections and $90^\circ$ rotation by $i$

Example 1 (Textbook Page 1)

Solve $x^2 + 2x + 5 = 0$.

Show solution
  1. Complete the square: $x^2 + 2x + 1 = -5 + 1 \implies (x + 1)^2 = -4$.
  2. Take square roots using $i^2 = -1$: $x + 1 = \pm \sqrt{-4} = \pm 2i$.
  3. Solve for $x$: $x = -1 \pm 2i$.

$x = -1 + 2i$ and $x = -1 - 2i$

Example 2 (Textbook Page 2)

Solve $x^2 + 2x + 3 = 0$ and verify your solutions.

Show solution
  1. Rewrite as $(x + 1)^2 = -2 \implies x + 1 = \pm \sqrt{2}i \implies x = -1 \pm \sqrt{2}i$.
  2. Check $x = -1 + \sqrt{2}i$: $$(-1 + \sqrt{2}i)^2 + 2(-1 + \sqrt{2}i) + 3 = (1 - 2\sqrt{2}i + 2i^2) - 2 + 2\sqrt{2}i + 3 = (1 - 2) - 2 + 3 = 0 \quad \checkmark$$

$x = -1 + \sqrt{2}i$ and $x = -1 - \sqrt{2}i$

Example 3 (Textbook Page 4)

Calculate $(-2, 3)(1, -2) + (1, 1)(0, 1)$ using both ordered pairs and $x + yi$ form.

Show solution
  1. Ordered pairs:
    $(-2, 3)(1, -2) = ((-2)(1) - (3)(-2), \; (-2)(-2) + (3)(1)) = (4, 7)$.
    $(1, 1)(0, 1) = ((1)(0) - (1)(1), \; (1)(1) + (1)(0)) = (-1, 1)$.
    Sum: $(4, 7) + (-1, 1) = (3, 8)$.
  2. Algebraic $x + yi$ form:
    $(-2 + 3i)(1 - 2i) + (1 + i)i = (-2 + 7i - 6i^2) + (i + i^2) = (4 + 7i) + (-1 + i) = 3 + 8i$.

$(3, 8)$ or $3 + 8i$

Common Mistake: For positive $a, b$, $\sqrt{-a} \cdot \sqrt{-b} \ne \sqrt{(-a)(-b)}$. Always extract $i$ first: $\sqrt{-4} \cdot \sqrt{-9} = (2i)(3i) = 6i^2 = -6$, not $+6$.
Quick Power Rule for $i^n$: Divide $n$ by $4$ and keep only the remainder $r \in \{0, 1, 2, 3\}$: $i^0 = 1$, $i^1 = i$, $i^2 = -1$, $i^3 = -i$. For example, $i^{35} = i^{4 \times 8 + 3} = i^3 = -i$.
  • $i^2 = -1$ defines the pure imaginary unit (စိတ်ကူးယဉ်ယူနစ် $i$).
  • $z = x + yi = (x, y)$, with real part $x$ on the horizontal axis and imaginary part $y$ on the vertical axis.
  • Multiplying any complex number $z = (x, y)$ by $i$ gives $iz = (-y, x)$, a $90^\circ$ counterclockwise rotation.
