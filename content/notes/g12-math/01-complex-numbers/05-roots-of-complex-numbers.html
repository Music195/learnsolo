Roots of Complex Numbers

Finding All $n$ Solutions to $w^n = z$

In real numbers, finding an $n$-th root often yields only one or two real answers (e.g. $x^3 = 1$ gives only $x = 1$). In the complex number system, however, every non-zero complex number has exactly $n$ distinct $n$-th roots.

Because adding any multiple of $2\pi$ ($360^\circ$) gives the same angle, we write: $$z = r [\cos(\theta + 2k\pi) + i\sin(\theta + 2k\pi)] \qquad (k \in \mathbb{Z})$$ Applying De Moivre's Theorem with power $\frac{1}{n}$ distributes the root evenly across $n$ values ($k = 0, 1, 2, \dots, n-1$).

Geometric Beauty: All $n$ roots have the exact same modulus $\sqrt[n]{r}$ and are spaced apart by equal angles of $\frac{2\pi}{n}$. Plotted on the complex plane, they form the vertices of a regular $n$-sided polygon centered at the origin!

The $n$-th Roots Formula

$$w_k = \sqrt[n]{r} \left[ \cos\left(\frac{\theta + 2k\pi}{n}\right) + i\sin\left(\frac{\theta + 2k\pi}{n}\right) \right] \qquad (k = 0, 1, 2, \dots, n-1)$$

$r = |z|$ is the modulus  |  $\theta = \text{arg}(z)$ is the principal argument  |  $n$ is a positive integer

The $n$-th Roots of Unity ($z^n = 1$)

Since $1 = 1(\cos 0 + i\sin 0)$, the roots of $z^n = 1$ are:

$$z_k = \cos\left(\frac{2k\pi}{n}\right) + i\sin\left(\frac{2k\pi}{n}\right) \qquad (k = 0, 1, \dots, n-1)$$

Example 1 (Textbook Page 12, Example 10)

Find the cube roots of $z = -2 - 2i$.

Show solution
  1. Find the modulus and argument of $z = -2 - 2i$: $$r = \sqrt{(-2)^2 + (-2)^2} = \sqrt{4 + 4} = \sqrt{8} = 2\sqrt{2}$$ $$\cos\theta = \frac{-2}{2\sqrt{2}} = -\frac{1}{\sqrt{2}}, \quad \sin\theta = -\frac{1}{\sqrt{2}} \implies \theta = -\frac{3\pi}{4}$$
  2. Write in trigonometric form with $2k\pi$: $$z = 2\sqrt{2} \left[\cos\left(-\frac{3\pi}{4} + 2k\pi\right) + i\sin\left(-\frac{3\pi}{4} + 2k\pi\right)\right]$$
  3. Compute the modulus of the cube roots ($n = 3$): $$\sqrt[3]{r} = \sqrt[3]{2\sqrt{2}} = \sqrt[3]{2^{3/2}} = 2^{1/2} = \sqrt{2}$$
  4. Apply the formula for $k = 0, 1, 2$: $$\text{Angle } \phi_k = \frac{-\frac{3\pi}{4} + 2k\pi}{3} = -\frac{\pi}{4} + \frac{2k\pi}{3}$$
    • For $k = 0$: $\phi_0 = -\frac{\pi}{4}$
      $$w_0 = \sqrt{2}\left(\cos\left(-\frac{\pi}{4}\right) + i\sin\left(-\frac{\pi}{4}\right)\right) = \sqrt{2}\left(\frac{1}{\sqrt{2}} - \frac{1}{\sqrt{2}}i\right) = 1 - i$$
    • For $k = 1$: $\phi_1 = -\frac{\pi}{4} + \frac{2\pi}{3} = \frac{5\pi}{12}$
      $$w_1 = \sqrt{2}\left(\cos\frac{5\pi}{12} + i\sin\frac{5\pi}{12}\right)$$
    • For $k = 2$: $\phi_2 = -\frac{\pi}{4} + \frac{4\pi}{3} = \frac{13\pi}{12}$
      $$w_2 = \sqrt{2}\left(\cos\frac{13\pi}{12} + i\sin\frac{13\pi}{12}\right)$$

$w_0 = 1 - i, \quad w_1 = \sqrt{2}\left(\cos\frac{5\pi}{12} + i\sin\frac{5\pi}{12}\right), \quad w_2 = \sqrt{2}\left(\cos\frac{13\pi}{12} + i\sin\frac{13\pi}{12}\right)$

Example 2 (Textbook Page 13, Example 11)

Solve $z^6 = 1$.

Show solution
  1. Write $1$ in trigonometric form: $1 = 1(\cos(0 + 2k\pi) + i\sin(0 + 2k\pi))$.
  2. Apply the $6$-th root formula ($n = 6, r = 1, \theta = 0$): $$z_k = \cos\left(\frac{2k\pi}{6}\right) + i\sin\left(\frac{2k\pi}{6}\right) = \cos\left(\frac{k\pi}{3}\right) + i\sin\left(\frac{k\pi}{3}\right) \qquad (k = 0, 1, 2, 3, 4, 5)$$
  3. Evaluate for each $k$:
    • $k = 0$: $z_0 = \cos 0 + i\sin 0 = 1$
    • $k = 1$: $z_1 = \cos\frac{\pi}{3} + i\sin\frac{\pi}{3} = \frac{1}{2} + \frac{\sqrt{3}}{2}i$
    • $k = 2$: $z_2 = \cos\frac{2\pi}{3} + i\sin\frac{2\pi}{3} = -\frac{1}{2} + \frac{\sqrt{3}}{2}i$
    • $k = 3$: $z_3 = \cos\pi + i\sin\pi = -1$
    • $k = 4$: $z_4 = \cos\frac{4\pi}{3} + i\sin\frac{4\pi}{3} = -\frac{1}{2} - \frac{\sqrt{3}}{2}i$
    • $k = 5$: $z_5 = \cos\frac{5\pi}{3} + i\sin\frac{5\pi}{3} = \frac{1}{2} - \frac{\sqrt{3}}{2}i$

$\pm 1, \quad \pm \frac{1}{2} \pm \frac{\sqrt{3}}{2}i$ (6 distinct roots)

Why only up to $k = n - 1$? If you plug in $k = n$, the angle becomes $\frac{\theta + 2n\pi}{n} = \frac{\theta}{n} + 2\pi$, which is the exact same point as $k = 0$! Roots start repeating after $k = n - 1$, so there are always exactly $n$ unique roots.
Sum of $n$-th Roots of Unity: The sum of all $n$-th roots of unity is always zero: $$\sum_{k=0}^{n-1} z_k = 0$$ This corresponds to the center of gravity of the regular $n$-gon sitting right at the origin!
  • Every non-zero complex number has exactly $n$ distinct $n$-th roots (ကွန်ပလက်စ်ကိန်းတစ်ခုတွင် $n$ ထပ်ကိန်းရင်း $n$ ခု အတိအကျရှိသည်).
  • All roots share the same length $\sqrt[n]{r}$ and are spaced by angle $\frac{2\pi}{n}$.
  • Graphically, the roots form a regular $n$-sided polygon inscribed in a circle of radius $\sqrt[n]{r}$ (စက်ဝိုင်းအတွင်းရှိ ပုံမှန် $n$ ထောင့်စုံပုံသဏ္ဍာန်).
