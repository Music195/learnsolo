Roots of Complex Numbers

Every Non-Zero Complex Number Has Exactly $n$ Distinct $n$-th Roots

To find the $n$-th roots of a complex number $z = r(\cos\theta + i\sin\theta)$, we seek all complex numbers $w = R(\cos\phi + i\sin\phi)$ such that $w^n = z$.

By De Moivre's Theorem, $w^n = R^n(\cos n\phi + i\sin n\phi) = r(\cos(\theta + 2k\pi) + i\sin(\theta + 2k\pi))$. Equating moduli and arguments gives $R = \sqrt[n]{r}$ and $\phi_k = \dfrac{\theta + 2k\pi}{n}$ for $k = 0, 1, 2, \dots, n - 1$.

Geometrically, the $n$ roots all lie on a circle of radius $\sqrt[n]{r}$ centered at the origin, spaced equally by $\dfrac{2\pi}{n}$ radians ($\dfrac{360^\circ}{n}$), forming the vertices of a regular $n$-sided polygon!

The $n$-th Roots Formula ($w^n = z$)

$$w_k = \sqrt[n]{r} \left[\cos\left(\frac{\theta + 2k\pi}{n}\right) + i\sin\left(\frac{\theta + 2k\pi}{n}\right)\right] \qquad (k = 0, 1, 2, \dots, n - 1)$$

• $n$-th Roots of Unity ($z^n = 1$, where $r = 1, \theta = 0$): $w_k = \cos\left(\dfrac{2k\pi}{n}\right) + i\sin\left(\dfrac{2k\pi}{n}\right)$ for $k = 0, 1, \dots, n - 1$.
• Angular spacing: Consecutive roots differ in angle by $\Delta\theta = \dfrac{2\pi}{n} = \dfrac{360^\circ}{n}$.

  1. For $k = 0, 1, \dots, n - 1$, the angles $\phi_k = \dfrac{\theta}{n} + \dfrac{2k\pi}{n}$ lie strictly within one full revolution of width $2\pi$, so all $n$ points are distinct.
  2. When $k = n$, $\phi_n = \dfrac{\theta + 2n\pi}{n} = \dfrac{\theta}{n} + 2\pi \equiv \phi_0 \pmod{2\pi}$, which gives the exact same complex number as $k = 0$.
  3. Thus, there are exactly $n$ distinct $n$-th roots.

Example 1 (Textbook Page 12, Example 10)

Find the cube roots of $z = -2 - 2i$.

Show solution
  1. Find the modulus and argument of $z = -2 - 2i$: $$r = \sqrt{(-2)^2 + (-2)^2} = \sqrt{8} = 2\sqrt{2}, \qquad \theta = -\frac{3\pi}{4} \quad (\text{Quadrant III})$$
  2. The cube root modulus is $\sqrt[3]{r} = \sqrt[3]{2\sqrt{2}} = \sqrt[3]{(\sqrt{2})^3} = \sqrt{2}$.
  3. Apply the formula for $n = 3$ and $k = 0, 1, 2$ with $\phi_k = \dfrac{-\frac{3\pi}{4} + 2k\pi}{3} = -\dfrac{\pi}{4} + \dfrac{2k\pi}{3}$:
    • $k = 0$: $w_0 = \sqrt{2}\left[\cos\left(-\frac{\pi}{4}\right) + i\sin\left(-\frac{\pi}{4}\right)\right] = 1 - i$.
    • $k = 1$: $w_1 = \sqrt{2}\left(\cos\frac{5\pi}{12} + i\sin\frac{5\pi}{12}\right)$.
    • $k = 2$: $w_2 = \sqrt{2}\left(\cos\frac{13\pi}{12} + i\sin\frac{13\pi}{12}\right)$.

$w_0 = 1 - i, \quad w_1 = \sqrt{2}\left(\cos\frac{5\pi}{12} + i\sin\frac{5\pi}{12}\right), \quad w_2 = \sqrt{2}\left(\cos\frac{13\pi}{12} + i\sin\frac{13\pi}{12}\right)$

Example 2 (Textbook Page 13, Example 11)

Solve $z^6 = 1$.

Show solution
  1. Write $1 = \cos(0 + 2k\pi) + i\sin(0 + 2k\pi)$, so $z_k = \cos\left(\dfrac{k\pi}{3}\right) + i\sin\left(\dfrac{k\pi}{3}\right)$ for $k = 0, 1, 2, 3, 4, 5$.
  2. Evaluate each root: $z_0 = 1$,   $z_1 = \frac{1}{2} + \frac{\sqrt{3}}{2}i$,   $z_2 = -\frac{1}{2} + \frac{\sqrt{3}}{2}i$,   $z_3 = -1$,   $z_4 = -\frac{1}{2} - \frac{\sqrt{3}}{2}i$,   $z_5 = \frac{1}{2} - \frac{\sqrt{3}}{2}i$.

$\pm 1, \quad \pm\dfrac{1}{2} \pm \dfrac{\sqrt{3}}{2}i$

Include $+2k\pi$ BEFORE Dividing by $n$: You must add $2k\pi$ to $\theta$ before dividing by $n$: $\dfrac{\theta + 2k\pi}{n} = \dfrac{\theta}{n} + \dfrac{2k\pi}{n}$, NOT $\dfrac{\theta}{n} + 2k\pi$.
Sum of $n$-th Roots is Always Zero: For any $n \ge 2$, the sum of all $n$-th roots $w_0 + w_1 + \dots + w_{n-1} = 0$ because the center of symmetry of the regular $n$-gon is the origin.
  • Every non-zero complex number has $n$ distinct $n$-th roots ($n$ ထပ်ကိန်းရင်း $n$ ခု အတိအကျရှိသည်).
  • All $n$ roots have modulus $\sqrt[n]{r}$ and angles spaced by $\dfrac{2\pi}{n}$ ($\dfrac{360^\circ}{n}$).
  • They form the vertices of a regular $n$-sided polygon centered at the origin (ပုံမှန် $n$ ထောင့်စုံပုံသဏ္ဍာန်).
