Arithmetic Operations and Conjugates

Conjugates Turn Complex Denominators into Real Numbers

For any complex number $z = x + yi$, its complex conjugate (တွဲဖက်ကွန်ပလက်စ်ကိန်း), denoted by $\bar{z}$, is obtained by reversing the sign of the imaginary part: $$\bar{z} = x - yi = (x, -y)$$ Geometrically, $\bar{z}$ is the reflection of $z$ across the real axis.

When you multiply a complex number by its own conjugate, the imaginary parts cancel out completely: $$z\bar{z} = (x + yi)(x - yi) = x^2 - (yi)^2 = x^2 + y^2$$ Because $x^2 + y^2$ is always a real number (and positive whenever $z \ne 0$), multiplying the top and bottom of a complex fraction $\dfrac{z_1}{z_2}$ by $\bar{z}_2$ clears $i$ from the denominator!

Conjugate, Multiplicative Inverse, and Division

$$z^{-1} = \frac{\bar{z}}{z\bar{z}} = \left(\frac{x}{x^2 + y^2}, \; \frac{-y}{x^2 + y^2}\right) \qquad (z \ne 0)$$ $$\frac{z_1}{z_2} = \frac{z_1 \bar{z}_2}{z_2 \bar{z}_2} = \frac{(x_1 + y_1 i)(x_2 - y_2 i)}{x_2^2 + y_2^2} = \frac{x_1 x_2 + y_1 y_2}{x_2^2 + y_2^2} + \frac{x_2 y_1 - x_1 y_2}{x_2^2 + y_2^2}i$$

Properties of Conjugates: $\overline{z_1 + z_2} = \bar{z}_1 + \bar{z}_2$,   $\overline{z_1 z_2} = \bar{z}_1 \bar{z}_2$,   $\overline{(z_1 / z_2)} = \bar{z}_1 / \bar{z}_2$,   $\overline{\bar{z}} = z$.

  1. Let $z_1 = x_1 + y_1 i$ and $z_2 = x_2 + y_2 i \ne 0$.
  2. Multiply numerator and denominator of $\dfrac{z_1}{z_2}$ by the conjugate $\bar{z}_2 = x_2 - y_2 i$: $$\frac{z_1}{z_2} = \frac{(x_1 + y_1 i)(x_2 - y_2 i)}{(x_2 + y_2 i)(x_2 - y_2 i)}$$
  3. Since $i^2 = -1$, the numerator becomes $(x_1 x_2 + y_1 y_2) + (x_2 y_1 - x_1 y_2)i$ and the denominator becomes $x_2^2 + y_2^2$.

Example 1 (Textbook Page 5, Example 4)

Calculate $\dfrac{2 + 3i}{3 + i}$.

Show solution
  1. The conjugate of the denominator $3 + i$ is $3 - i$.
  2. Multiply numerator and denominator by $(3 - i)$: $$\frac{2 + 3i}{3 + i} = \frac{(2 + 3i)(3 - i)}{(3 + i)(3 - i)}$$
  3. Expand the numerator: $6 - 2i + 9i - 3i^2 = 6 + 7i + 3 = 9 + 7i$.
  4. Expand the denominator: $3^2 + 1^2 = 9 + 1 = 10$.

$\dfrac{9}{10} + \dfrac{7}{10}i$ or $(0.9, \; 0.7)$

Example 2 (Textbook Page 6)

Find the multiplicative inverse $z^{-1}$ for $z = 3 - 2i$, and verify that $z z^{-1} = 1$.

Show solution
  1. Compute $z\bar{z} = x^2 + y^2 = 3^2 + (-2)^2 = 9 + 4 = 13$.
  2. The conjugate is $\bar{z} = 3 + 2i$, so $z^{-1} = \dfrac{\bar{z}}{z\bar{z}} = \dfrac{3 + 2i}{13} = \dfrac{3}{13} + \dfrac{2}{13}i$.
  3. Check: $(3 - 2i)\left(\dfrac{3 + 2i}{13}\right) = \dfrac{9 - 4i^2}{13} = \dfrac{9 + 4}{13} = 1$.

$z^{-1} = \dfrac{3}{13} + \dfrac{2}{13}i$

Example 3 (Conjugate Symmetry)

Let $z_1 = -2 + 3i$ and $z_2 = 5 + 2i$. Verify that $\overline{z_1 + z_2} = \bar{z}_1 + \bar{z}_2$.

Show solution
  1. $z_1 + z_2 = (-2 + 5) + (3 + 2)i = 3 + 5i \implies \overline{z_1 + z_2} = 3 - 5i$.
  2. $\bar{z}_1 + \bar{z}_2 = (-2 - 3i) + (5 - 2i) = 3 - 5i$.

Both sides equal $3 - 5i$

Caution on $z\bar{z}$: Notice that $(x + yi)(x - yi) = x^2 + y^2$ (a plus sign, not minus!), because $-y^2 i^2 = -y^2(-1) = +y^2$.
Testing if a Complex Number is Real: A complex number $z$ is purely real if and only if $\bar{z} = z$, and purely imaginary if and only if $\bar{z} = -z$.
  • The conjugate of $z = x + yi$ is $\bar{z} = x - yi$, reflected across the real axis (တွဲဖက်ကွန်ပလက်စ်ကိန်း).
  • $z\bar{z} = x^2 + y^2$ is always a non-negative real number.
  • To divide $\dfrac{z_1}{z_2}$, multiply numerator and denominator by $\bar{z}_2$ (ကိန်းခြေ၏ တွဲဖက်ကိန်းဖြင့် အပေါ်အောက်မြှောက်ပါ).
