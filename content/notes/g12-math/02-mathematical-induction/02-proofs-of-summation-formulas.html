Proofs of Summation Formulas

Replacing the First $k$ Terms with the Induction Hypothesis

One of the most important applications of mathematical induction is proving closed-form formulas for finite series: $$S_n = a_1 + a_2 + \dots + a_n = f(n)$$

In the inductive step ($n = k \implies n = k + 1$), the sum of the first $k + 1$ terms always splits into the sum of the first $k$ terms plus the single new term $a_{k+1}$: $$S_{k+1} = \underbrace{(a_1 + a_2 + \dots + a_k)}_{= f(k) \text{ by hypothesis}} + \; a_{k+1} = f(k) + a_{k+1}$$ Factoring $f(k) + a_{k+1}$ algebraically shows that it equals $f(k + 1)$!

Classic Summation Identities Proved by Induction

$$1 + 2 + 3 + \dots + n = \frac{n(n + 1)}{2}$$ $$1^2 + 2^2 + 3^2 + \dots + n^2 = \frac{n(n + 1)(2n + 1)}{6}$$ $$1^3 + 2^3 + 3^3 + \dots + n^3 = \left[\frac{n(n + 1)}{2}\right]^2$$

For arithmetic-geometric series like $\sum_{r=1}^n r \cdot 3^r = \dfrac{(2n - 1)3^{n+1} + 3}{4}$, factor out the common exponential $3^{k+1}$ in Step 2.

  1. Assume $1 + 2 + \dots + k = \dfrac{k(k + 1)}{2}$ holds for $n = k$.
  2. Add $(k + 1)$ to get the sum for $n = k + 1$: $$\frac{k(k + 1)}{2} + (k + 1) = \frac{k(k + 1) + 2(k + 1)}{2}$$
  3. Factor out $(k + 1)$ in the numerator: $\dfrac{(k + 1)(k + 2)}{2} = \dfrac{(k + 1)((k + 1) + 1)}{2}$.

Staircase Proof of $1 + 2 + \dots + n = \dfrac{n(n + 1)}{2}$

Example 1 (Textbook Page 16, Example 2)

Use mathematical induction to prove that $$1 + 2 + 3 + \dots + n = \frac{n(n + 1)}{2}$$ for all natural numbers $n$.

Show solution
  1. (1) For $n = 1$: $\text{L.H.S.} = 1$ and $\text{R.H.S.} = \dfrac{1(1 + 1)}{2} = 1$. True for $n = 1$.
  2. (2) Assume true for $n = k$: $1 + 2 + 3 + \dots + k = \dfrac{k(k + 1)}{2}$.
    For $n = k + 1$: $$\text{L.H.S.} = (1 + 2 + \dots + k) + (k + 1) = \frac{k(k + 1)}{2} + (k + 1) = \frac{(k + 1)(k + 2)}{2} = \text{R.H.S.}$$ Therefore, the statement is true for $n = k + 1$.
  3. (3) Conclusion: By the principle of mathematical induction, the formula holds for all $n \in \mathbb{N}$.

Proved true for all $n \in \mathbb{N}$

Example 2 (Textbook Page 18, Example 5)

Prove that $1\cdot 3 + 2\cdot 3^2 + 3\cdot 3^3 + \dots + n\cdot 3^n = \dfrac{(2n - 1)3^{n+1} + 3}{4}$ for all natural numbers $n$.

Show solution
  1. (1) For $n = 1$: $\text{L.H.S.} = 1 \cdot 3^1 = 3$, and $\text{R.H.S.} = \dfrac{(2(1) - 1)3^2 + 3}{4} = \dfrac{9 + 3}{4} = 3$. True for $n = 1$.
  2. (2) Assume true for $n = k$: $$1\cdot 3 + 2\cdot 3^2 + \dots + k\cdot 3^k = \frac{(2k - 1)3^{k+1} + 3}{4}$$ For $n = k + 1$, add the $(k + 1)$-th term $(k + 1)3^{k+1}$: $$\text{L.H.S.} = \frac{(2k - 1)3^{k+1} + 3}{4} + (k + 1)3^{k+1} = \frac{[(2k - 1) + 4(k + 1)]3^{k+1} + 3}{4}$$
  3. Simplify the bracket: $(2k - 1) + 4k + 4 = 6k + 3 = 3(2k + 1)$: $$= \frac{3(2k + 1)3^{k+1} + 3}{4} = \frac{(2k + 1)3^{k+2} + 3}{4} = \frac{(2(k + 1) - 1)3^{(k+1)+1} + 3}{4} = \text{R.H.S.}$$ Therefore, true for $n = k + 1$.
  4. (3) Conclusion: By mathematical induction, the statement is true for all natural numbers $n$.

Proved true for all $n \in \mathbb{N}$

Factor Instead of Expanding! In Step 2, do not multiply out brackets like $k(k + 1)(2k + 1)$ into a cubic polynomial unless necessary. Factor out common terms like $(k + 1)$ or $3^{k+1}$ first — it saves half the algebra!
Write Down the Target R.H.S. First: Before simplifying $f(k) + a_{k+1}$, write down $f(k + 1)$ on scratch paper so you know the exact factored form you are aiming for.
  • Split the $(k + 1)$-term sum as $S_{k+1} = S_k + a_{k+1}$ and substitute the induction hypothesis for $S_k$.
  • Factor out common binomials like $(k + 1)$ or common powers like $3^{k+1}$ over a common denominator.
  • Applies to arithmetic, geometric, power, and telescoping series (ကိန်းစဉ်တန်းပေါင်းလဒ် ဖော်မြူလာများ).
