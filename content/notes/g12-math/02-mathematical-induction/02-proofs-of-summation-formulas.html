Proofs of Summation Formulas

Using Induction to Verify Series and Summation Identities

One of the most practical and frequent applications of mathematical induction is proving formulas for the sum of the first $n$ terms of a sequence.

Whether finding the sum of consecutive integers, sums of squares, or mixed arithmetic-geometric series, the induction method always proceeds with the same powerful strategy:

  1. Verify the formula works for the first term ($n = 1$).
  2. To find the sum of $k + 1$ terms, take the known sum of $k$ terms from the hypothesis and add the $(k+1)$-th term.
  3. Algebraically factor and simplify until the expression matches the formula with $n$ replaced by $(k+1)$.

Essential Summation Identities

1. Sum of First $n$ Natural Numbers

$$1 + 2 + 3 + \dots + n = \sum_{r=1}^n r = \frac{n(n + 1)}{2}$$

2. Sum of Squares

$$1^2 + 2^2 + 3^2 + \dots + n^2 = \sum_{r=1}^n r^2 = \frac{n(n + 1)(2n + 1)}{6}$$

3. Arithmetic-Geometric Series

$$1\cdot 3 + 2\cdot 3^2 + 3\cdot 3^3 + \dots + n\cdot 3^n = \frac{(2n - 1)3^{n+1} + 3}{4}$$

Example 1 (Textbook Page 16, Example 2)

Use mathematical induction to prove that: $$1 + 2 + 3 + \dots + n = \frac{n(n + 1)}{2}$$ for all natural numbers $n \in \mathbb{N}$.

Show solution
  1. Initial Step: For $n = 1$,
    $\text{L.H.S.} = 1$.
    $\text{R.H.S.} = \frac{1(1 + 1)}{2} = \frac{2}{2} = 1$.
    $\text{L.H.S.} = \text{R.H.S.}$, so the statement is true for $n = 1$.
  2. Inductive Step: Assume true for $n = k$, that is: $$1 + 2 + 3 + \dots + k = \frac{k(k + 1)}{2}$$ We will show it is true for $n = k + 1$, meaning we must show: $$1 + 2 + 3 + \dots + k + (k + 1) = \frac{(k + 1)((k + 1) + 1)}{2} = \frac{(k + 1)(k + 2)}{2}$$
  3. Using the hypothesis: $$\underbrace{1 + 2 + 3 + \dots + k}_{= \frac{k(k + 1)}{2}} + (k + 1) = \frac{k(k + 1)}{2} + (k + 1)$$ Take common denominator $2$: $$= \frac{k(k + 1) + 2(k + 1)}{2} = \frac{(k + 1)(k + 2)}{2} = \text{R.H.S.}$$ Therefore, the statement is true for $n = k + 1$.
  4. Conclusion: Hence, by the principle of mathematical induction, the statement is true for all natural numbers $n$.

Proved true for all $n \in \mathbb{N}$

Example 2 (Textbook Page 18, Example 5)

Prove that $1\cdot 3 + 2\cdot 3^2 + 3\cdot 3^3 + \dots + n\cdot 3^n = \dfrac{(2n - 1)3^{n+1} + 3}{4}$ for all natural numbers $n$.

Show solution
  1. Initial Step ($n = 1$):
    $\text{L.H.S.} = 1 \cdot 3^1 = 3$.
    $\text{R.H.S.} = \frac{(2(1) - 1)3^{1+1} + 3}{4} = \frac{(1)(9) + 3}{4} = \frac{12}{4} = 3$.
    $\text{L.H.S.} = \text{R.H.S.}$, true for $n = 1$.
  2. Inductive Step: Assume true for $n = k$: $$1\cdot 3 + 2\cdot 3^2 + \dots + k\cdot 3^k = \frac{(2k - 1)3^{k+1} + 3}{4}$$ We will show true for $n = k + 1$, that is: $$\text{Sum} = \frac{(2(k + 1) - 1)3^{k+2} + 3}{4} = \frac{(2k + 1)3^{k+2} + 3}{4}$$
  3. Add the $(k + 1)$-th term to both sides: $$\text{L.H.S.} = \left[\frac{(2k - 1)3^{k+1} + 3}{4}\right] + (k + 1)3^{k+1}$$ Combine over common denominator $4$: $$= \frac{(2k - 1)3^{k+1} + 3 + 4(k + 1)3^{k+1}}{4}$$ Factor out $3^{k+1}$: $$= \frac{[(2k - 1) + 4(k + 1)]3^{k+1} + 3}{4} = \frac{(6k + 3)3^{k+1} + 3}{4}$$ Notice $(6k + 3) = 3(2k + 1)$: $$= \frac{3(2k + 1)3^{k+1} + 3}{4} = \frac{(2k + 1)3^{k+2} + 3}{4} = \text{R.H.S.}$$ Therefore, true for $n = k + 1$.
  4. Conclusion: Hence, by induction, the identity holds for all $n \in \mathbb{N}$.

Proved true for all $n \in \mathbb{N}$

Algebraic factoring tip: In Step 2, resist the temptation to expand everything immediately. Look for common factors (like $(k + 1)$ or $3^{k+1}$) to factor out cleanly!
Target the Goal: Write down clearly what the R.H.S. looks like for $n = k + 1$ before beginning the algebra. That way you know the destination expression you are working toward.
  • Summation induction replaces the first $k$ terms with the induction hypothesis formula.
  • Combine fractions using a common denominator and factor out common binomial terms like $(k + 1)$.
