Rails with a Battery

A battery pushes the rod, the moving rod makes a back emf, and it speeds up until the current falls to zero

A rod lies on rails in a field $B$, in a circuit with a battery $E$ and a resistor $R$. It is held still and then released. Follow the chain of cause and effect:

  1. The battery drives a current $I$ through the rod.
  2. A current in a field: the rod feels the electromagnetic force $IBL$.
  3. A force gives the rod an acceleration, which means its velocity changes: it picks up a speed $v$.
  4. A conductor moving in a field: the rod makes an induced emf $vBL$. It points against the battery (a "back emf").
  5. The back emf weakens the current: $I = (E - vBL)/R$.
  6. Smaller current, smaller force, smaller acceleration.

The acceleration keeps shrinking until it reaches zero. Then the speed is constant, $v_1$. With nothing else pushing or pulling, zero acceleration means zero force, which means zero current. So the back emf exactly matches the battery: $v_1BL = E$.

If something else acts on the rod (a load on a string, or gravity on a slope), the current at the steady speed is not zero. Use the balance of forces instead: $IBL$ = the other force.

Battery $E$, resistor $R$, rod moving at $v$

$$I = \frac{E - vBL}{R}, \qquad \text{free rod: } v_1 = \frac{E}{BL} \;(I = 0), \qquad \text{with a load } F\text{: } IBL = F$$

$E$: battery emf (V). $vBL$: the rod's back emf, opposing $E$. $B$: field (T). $L$: rod length between the rails (m). $F$: a steady force the rod must overcome (N).

  1. Kirchhoff's second law round the loop: $E - vBL = RI$.
  2. The rod's motion: $M\dfrac{\Delta v}{\Delta t} = IBL$ (free rod).
  3. Steady speed means $\Delta v/\Delta t = 0$, so $I = 0$. Then $E = v_1BL$.

E = 1.5 V, R = 0.50 Ω, B = 0.50 T, L = 0.40 m, rod 0.020 kg; released from rest (slowed down 3 times)

Example 1

In the demo's circuit ($E = 1.5$ V, $R = 0.50$ Ω, $B = 0.50$ T, $L = 0.40$ m, rod 0.020 kg), find the current, the force and the acceleration just after the rod is released.

Show solution
  1. At rest, there is no back emf: $I = 1.5/0.50 = 3.0$ A.
  2. $F = IBL = 3.0 \times 0.50 \times 0.40 = 0.60$ N.
  3. $a = F/M = 0.60/0.020 = 30$ m/s².

3.0 A; 0.60 N; 30 m/s²

Example 2

Find the current and the force when the rod has reached 3.0 m/s.

Show solution
  1. Back emf: $vBL = 3.0 \times 0.50 \times 0.40 = 0.60$ V.
  2. $I = (1.5 - 0.60)/0.50 = 1.8$ A, so $F = 1.8 \times 0.20 = 0.36$ N.

1.8 A; 0.36 N

Example 3

Find the rod's final steady speed $v_1$ in symbols, and then with the numbers.

Show solution
  1. Steady speed means no acceleration, so no force, so no current.
  2. No current means the back emf equals the battery: $v_1BL = E$, so $v_1 = \dfrac{E}{BL}$.
  3. $v_1 = 1.5/(0.50 \times 0.40) = 7.5$ m/s.

$v_1 = E/(BL) = 7.5$ m/s

Example 4

The rod now has to pull a steady load of 0.20 N. Find the current and the speed when it moves steadily.

Show solution
  1. Steady: $IBL = 0.20$ N, so $I = 0.20/0.20 = 1.0$ A. The current is not zero this time.
  2. $E - vBL = RI$: $1.5 - 0.20v = 0.50$, so $v = 5.0$ m/s.

1.0 A; 5.0 m/s

Example 5

At the steady speed of Example 4, where does the battery's power go?

Show solution
  1. Battery: $EI = 1.5 \times 1.0 = 1.5$ W.
  2. Heat in the resistor: $I^2R = 0.50$ W. Work on the load: $Fv = 0.20 \times 5.0 = 1.0$ W.
  3. $0.50 + 1.0 = 1.5$ W ✓. This is how an electric motor works.

0.50 W as heat, 1.0 W into the load

"Steady speed, so the current is zero" is only true when nothing else acts on the rod. With a load, a slope or a hanging mass, use the force balance $IBL = F$.
Write the chain out once: current → force → acceleration → speed → back emf → less current. Every rail problem is this chain, run until something balances.
  • $I = (E - vBL)/R$: the moving rod opposes the battery.
  • Free rod: it speeds up until $vBL = E$ and $I = 0$.
  • With a load: steady when $IBL = F$.
