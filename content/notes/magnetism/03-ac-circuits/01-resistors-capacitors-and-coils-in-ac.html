Resistors, Capacitors and Coils in AC

On an AC supply, each part acts like a resistance ($R$, $1/\omega C$, $\omega L$), and the current is in step, a quarter cycle ahead, or a quarter cycle behind

Direct current (DC) always flows the same way. In alternating current (AC), the voltage and current reverse direction over and over. We describe them with $\sin$ and $\cos$: $V = V_0\sin\omega t$, where $\omega = 2\pi f$ is the angular frequency.

A link with mechanics. Displacement → velocity → acceleration: each is the rate of change of the one before. In circuits, the same chain is charge $q$ → current $I$ → rate of change of current $\Delta I/\Delta t$. Each of the three parts uses one of these:

  • resistor: $V = RI$ (current);
  • capacitor: $q = CV$ (charge);
  • coil: $V = L\,\Delta I/\Delta t$ (rate of change of current).

Put $V = V_0\sin\omega t$ across each one:

  • Resistor: $I = \dfrac{V_0}{R}\sin\omega t$. The current is in step with the voltage: both peak at the same moment.
  • Capacitor: $q = CV_0\sin\omega t$, and the current is its rate of change: $I = \omega CV_0\cos\omega t$. The current leads the voltage by a quarter cycle ($\pi/2$). This matches the transient rule: current first, then voltage.
  • Coil: $I = -\dfrac{V_0}{\omega L}\cos\omega t$. The current lags by $\pi/2$. Again it matches the transient rule: voltage first, then current.

In each case the peak current is $V_0$ divided by something that acts like a resistance. It is called the reactance: $1/(\omega C)$ for a capacitor and $\omega L$ for a coil, both in ohms.

Writing the answer quickly. You only need two facts for each part: its reactance, and whether the current is in step, ahead or behind. Picture the phase as an arrow going round anticlockwise. Starting from $\sin$, a quarter turn ahead is $\cos$ and a quarter turn behind is $-\cos$.

With $V = V_0\sin\omega t$ across the part

$$I_R = \frac{V_0}{R}\sin\omega t, \qquad I_C = \frac{V_0}{1/\omega C}\cos\omega t, \qquad I_L = -\frac{V_0}{\omega L}\cos\omega t$$

Reactances: $X_C = \dfrac{1}{\omega C}$, $X_L = \omega L$ (Ω). $\omega = 2\pi f$ (rad/s). The current is in step for R, leads by $\pi/2$ for C, lags by $\pi/2$ for L. If instead $I = I_0\sin\omega t$ is given, the voltage lags for C ($-\cos$) and leads for L ($+\cos$).

  1. Capacitor: $q = CV_0\sin\omega t$. The rate of change of $\sin\omega t$ is $\omega\cos\omega t$, so $I = \omega CV_0\cos\omega t = \dfrac{V_0}{1/(\omega C)}\cos\omega t$.
  2. Coil: $\dfrac{\Delta I}{\Delta t} = \dfrac{V_0}{L}\sin\omega t$. We need a current whose rate of change is this, and $-\cos\omega t$ has rate of change $\omega\sin\omega t$. So $I = -\dfrac{V_0}{\omega L}\cos\omega t$.
  3. $\cos\omega t$ reaches its peak a quarter cycle before $\sin\omega t$ does (lead), and $-\cos\omega t$ a quarter cycle after (lag).

Example 1

$V = 10\sin(100\pi t)$ V is applied across a 50 Ω resistor. Write the current.

Show solution
  1. In step, with peak $10/50 = 0.20$ A.

$I = 0.20\sin(100\pi t)$ A

Example 2

The same voltage is applied across a 100 μF capacitor. Find the reactance and write the current.

Show solution
  1. $X_C = \dfrac{1}{\omega C} = \dfrac{1}{100\pi \times 100\times10^{-6}} = 31.8$ Ω.
  2. Peak $10/31.8 = 0.31$ A, leading by $\pi/2$: $\sin \to \cos$.

31.8 Ω; $I = 0.31\cos(100\pi t)$ A

Example 3

The same voltage is applied across a 0.10 H coil. Find the reactance and write the current.

Show solution
  1. $X_L = \omega L = 100\pi \times 0.10 = 31.4$ Ω.
  2. Peak $10/31.4 = 0.32$ A, lagging by $\pi/2$: $\sin \to -\cos$.

31.4 Ω; $I = -0.32\cos(100\pi t)$ A

Example 4

What happens to the capacitor's and the coil's reactance if the frequency is doubled?

Show solution
  1. $X_C = 1/(\omega C)$ halves: a capacitor lets high frequencies through more easily.
  2. $X_L = \omega L$ doubles: a coil blocks high frequencies more. Try this with the slider.

$X_C$ halves; $X_L$ doubles

Example 5

This time the current is given: $I = I_0\sin\omega t$. Write the voltage across a resistor $R$, a capacitor $C$ and a coil $L$.

Show solution
  1. Now the current is the reference, so "current leads" becomes "voltage lags", and the other way round.
  2. Resistor: $V_R = RI_0\sin\omega t$.
  3. Capacitor: the voltage lags by $\pi/2$: $V_C = -\dfrac{I_0}{\omega C}\cos\omega t$.
  4. Coil: the voltage leads by $\pi/2$: $V_L = \omega LI_0\cos\omega t$.

$RI_0\sin\omega t$, $-\dfrac{I_0}{\omega C}\cos\omega t$, $\omega LI_0\cos\omega t$

"Leads" and "lags" depend on which one you start from. Relative to the voltage, a capacitor's current leads. Relative to the current, a capacitor's voltage lags. Always check which quantity is given as $\sin\omega t$.
Picture an arrow going round a circle anticlockwise, as in the demo. $\sin\omega t$ is the arrow that starts pointing right (its height starts at 0 and rises). A quarter turn ahead of it is $\cos$, half a turn is $-\sin$, and three quarters is $-\cos$. With this you can write any of the four without calculus.
  • Reactance: $R$, $1/(\omega C)$, $\omega L$.
  • Current vs voltage: in step (R), leads by $\pi/2$ (C), lags by $\pi/2$ (L).
  • Peak current = peak voltage ÷ reactance.
