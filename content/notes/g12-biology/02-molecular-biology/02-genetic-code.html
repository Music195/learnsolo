The Genetic Code

Concept — Three Letters Make One Amino Acid

The genetic code is the set of rules for turning the nucleotide sequence of a gene into the amino acid sequence of a protein. It links each nucleotide codon to an amino acid.

  • Why triplets? RNA has only 4 nucleotides (A, U, G, C) but proteins use 20 amino acids. One nucleotide per amino acid gives only 4 codes; two give 4 × 4 = 16, still too few. Three give 4 × 4 × 4 = 64 combinations, enough for 20. This is the triplet hypothesis: a combination of three nucleotides is a codon.
  • Between 1961 and 1965, research groups compared artificial RNA of known sequence with the polypeptides made from it, and worked out every mRNA codon.
  • AUG is the start codon and also codes for methionine. UAA, UAG and UGA are stop (terminator) codons. The code is written as mRNA codons, not as DNA.

Three important characteristics:

  1. Redundant: more than one codon can code for the same amino acid (e.g. six codons for leucine). Only the three stop codons code for no amino acid.
  2. Continuous: read as a series of three-letter codons without spaces, punctuation or overlap. Knowing where to start and stop is essential: adding or losing one or two nucleotides shifts the codon groups and gives a wrong amino acid sequence.
  3. Nearly universal: almost all organisms use the same code (rare exceptions in some protists). A codon in a fruit fly codes for the same amino acid as in a human, so a gene moved from one organism into another makes the same protein: the basis of gene technology and cloning.
Counting the Codes
$$4^1 = 4 \qquad 4^2 = 16 \qquad 4^3 = 64 \ \ (\geq 20 \text{ amino acids})$$ $$64 \text{ codons} = 61 \text{ coding for amino acids} + 3 \text{ stop codons}$$
  • Start: AUG (Met). Stop: UAA, UAG, UGA
  • A protein of n amino acids needs n codons + 1 stop codon = 3(n + 1) nucleotides of mRNA
Common Mistakes to Avoid
  • Reading the table with DNA letters: the table uses mRNA codons, so there is U, never T.
  • Stop codons code for an amino acid: they do not; they end translation.
  • The textbook's Table 2.2: in the G column (second base G), the C, A and G rows are printed as UGU, UGC, UGA, UGG again. They should be CGU–CGG (Arg), AGU, AGC (Ser), AGA, AGG (Arg), and GGU–GGG (Gly). The table in the demo below is the correct one.

Worked Examples — Sample Questions (pp. 36–37)

Example A (translate): Translate the mRNA 5′-AUG UUU GGC UCA UGG UAG-3′.

Show answer

AUG = Met (start), UUU = Phe, GGC = Gly, UCA = Ser, UGG = Trp, UAG = stop.

Met–Phe–Gly–Ser–Trp (5 amino acids), then translation stops.

Example B (length): A protein has 150 amino acids. What is the smallest number of mRNA nucleotides that code for it, counting the stop codon?

Show answer

Each amino acid needs one codon of 3 nucleotides, and one more codon is needed to stop.

3 × (150 + 1) = 453 nucleotides.

Example C (frame shift): The mRNA AUG GCC UUU GGA UCA … loses the first U of UUU. What are the first four amino acids now?

Show answer

The sequence becomes AUG GCC UUG GAU CA…: the codons after the deletion are regrouped.

Met–Ala–Leu–Asp (instead of Met–Ala–Phe–Gly): the code has no punctuation, so one lost base changes every later codon.

Q3 (iv): A triple code of nucleotides could produce (A. 8 B. 16 C. 64 D. 32) possible combinations.

Show answer

C, 64 (= 4 × 4 × 4).

Q4 (ii): A codon is matched with (A. always pairs with thymine … F. a combination of three nucleotides).

Show answer

F, a combination of three nucleotides.

Q8 (b): State the three important characteristics of the genetic code.

Show answer

(1) Redundant: more than one codon can code for the same amino acid; only the three stop codons code for none.

(2) Continuous: read as three-letter codons without spaces, punctuation or overlap, so the start and stop are essential; a shift of one or two nucleotides changes the codon groups.

(3) Nearly universal: almost all organisms use the same code, so a gene moved into another organism makes the same protein (important for gene technology).

Key Takeaways
  • A codon is three mRNA nucleotides; 43 = 64 codons for 20 amino acids.
  • AUG = start and methionine; UAA, UAG, UGA = stop.
  • The code is redundant, continuous (no punctuation) and nearly universal.
