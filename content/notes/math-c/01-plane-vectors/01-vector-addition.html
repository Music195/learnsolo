Vector Addition Properties

Adding vectors = doing one move after another

A vector (ベクトル) has a length and a direction, but no fixed starting point. Think of it as a move: "3 right, 2 up".

$\vec{a} + \vec{b}$ means "do $\vec{a}$, then do $\vec{b}$": put the tail of $\vec{b}$ at the head of $\vec{a}$ (triangle rule). Doing the moves in the other order ends at the same place, so $\vec{a} + \vec{b} = \vec{b} + \vec{a}$; the two paths form a parallelogram.

Rules of addition

$$\vec{a} + \vec{b} = \vec{b} + \vec{a}, \qquad (\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c})$$
$$\vec{a} + \vec{0} = \vec{a}, \qquad \vec{a} + (-\vec{a}) = \vec{0}, \qquad \vec{a} - \vec{b} = \vec{a} + (-\vec{b})$$

With points: $\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}$, $\;\overrightarrow{BA} = -\overrightarrow{AB}$, $\;\overrightarrow{AA} = \vec{0}$.

  1. Draw $\overrightarrow{OA} = \vec{a}$ and $\overrightarrow{OB} = \vec{b}$, and complete the parallelogram OACB.
  2. Opposite sides of a parallelogram are equal and parallel, so $\overrightarrow{AC} = \vec{b}$ and $\overrightarrow{BC} = \vec{a}$.
  3. $\vec{a} + \vec{b} = \overrightarrow{OA} + \overrightarrow{AC} = \overrightarrow{OC}$ and $\vec{b} + \vec{a} = \overrightarrow{OB} + \overrightarrow{BC} = \overrightarrow{OC}$.

Drag the tips of $\vec{a}$ (blue) and $\vec{b}$ (orange): both paths reach the same point

Example 1

Simplify $\overrightarrow{AB} + \overrightarrow{CA} + \overrightarrow{BC}$.

Show solution
  1. Reorder so the letters chain: $\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CA}$.
  2. $= \overrightarrow{AC} + \overrightarrow{CA} = \overrightarrow{AA}$.

$\vec{0}$

Example 2

Simplify $\overrightarrow{AB} - \overrightarrow{AC}$.

Show solution
  1. $-\overrightarrow{AC} = \overrightarrow{CA}$, so the expression is $\overrightarrow{CA} + \overrightarrow{AB}$.

$\overrightarrow{CB}$

Example 3

In parallelogram ABCD, let $\overrightarrow{AB} = \vec{a}$ and $\overrightarrow{AD} = \vec{b}$. Write $\overrightarrow{AC}$ and $\overrightarrow{BD}$ in terms of $\vec{a}$ and $\vec{b}$.

Show solution
  1. $\overrightarrow{BC} = \overrightarrow{AD} = \vec{b}$, so $\overrightarrow{AC} = \overrightarrow{AB} + \overrightarrow{BC}$.
  2. $\overrightarrow{BD} = \overrightarrow{BA} + \overrightarrow{AD} = -\vec{a} + \vec{b}$.

$\overrightarrow{AC} = \vec{a} + \vec{b}$, $\;\overrightarrow{BD} = \vec{b} - \vec{a}$

Example 4

Find $\vec{x}$ if $\vec{x} + \overrightarrow{AB} = \overrightarrow{CB}$.

Show solution
  1. $\vec{x} = \overrightarrow{CB} - \overrightarrow{AB} = \overrightarrow{CB} + \overrightarrow{BA}$.

$\vec{x} = \overrightarrow{CA}$

$\vec{a} - \vec{b}$ drawn from a common tail points from the head of $\vec{b}$ to the head of $\vec{a}$, not the other way. For example $\overrightarrow{OA} - \overrightarrow{OB} = \overrightarrow{BA}$.
Chain rule for letters: when the end of one vector is the start of the next, they join, as in $\overrightarrow{PQ} + \overrightarrow{QR} = \overrightarrow{PR}$. Rewrite $-\overrightarrow{XY}$ as $\overrightarrow{YX}$ first.
  • Head-to-tail (triangle rule) or tail-to-tail (parallelogram rule).
  • Order and grouping don't matter in a sum.
  • $\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}$ and $\overrightarrow{OA} - \overrightarrow{OB} = \overrightarrow{BA}$.
