Vector Magnitude

A vector is "so far across, so far up"

Draw $\vec{a}$ from the origin O. If its head is at $(a_1, a_2)$, we write $\vec{a} = (a_1, a_2)$: these are its components (成分). With the unit vectors $\vec{e_1} = (1, 0)$ and $\vec{e_2} = (0, 1)$, this means $\vec{a} = a_1\vec{e_1} + a_2\vec{e_2}$.

The components are the two legs of a right triangle, so Pythagoras gives the magnitude (大きさ) $|\vec{a}|$. If $\vec{a}$ makes angle $\theta$ with the positive $x$-axis, the legs are $|\vec{a}|\cos\theta$ and $|\vec{a}|\sin\theta$.

$\vec{a} = (a_1, a_2)$

$$|\vec{a}| = \sqrt{a_1^2 + a_2^2}, \qquad \vec{a} = |\vec{a}|(\cos\theta, \sin\theta)$$

$\theta$: angle from the positive $x$-axis, found from $\cos\theta = \dfrac{a_1}{|\vec{a}|}$ and $\sin\theta = \dfrac{a_2}{|\vec{a}|}$. Unit vector along $\vec{a}$: $\dfrac{1}{|\vec{a}|}(a_1, a_2)$.

  1. From O, go $a_1$ along the $x$-axis to Q$(a_1, 0)$, then $a_2$ up to A$(a_1, a_2)$.
  2. Triangle OQA has a right angle at Q with legs $|a_1|$ and $|a_2|$.
  3. So $|\vec{a}|^2 = \text{OA}^2 = a_1^2 + a_2^2$.

Drag the tip of $\vec{a}$: its components, length and direction

Example 1

Find $|\vec{a}|$ for $\vec{a} = (6, -8)$, and the unit vector along it.

Show solution
  1. $\sqrt{36 + 64} = 10$.

$10$; $\;\left(\dfrac{3}{5}, -\dfrac{4}{5}\right)$

Example 2

Find the angle $\theta$ ($0° \le \theta < 360°$) that $\vec{a} = (-1, \sqrt{3})$ makes with the positive $x$-axis.

Show solution
  1. $|\vec{a}| = \sqrt{1 + 3} = 2$.
  2. $\cos\theta = -\dfrac{1}{2}$, $\sin\theta = \dfrac{\sqrt{3}}{2}$.

$\theta = 120°$

Example 3

Write in components the vector of length $4$ that makes $150°$ with the positive $x$-axis.

Show solution
  1. $4(\cos 150°, \sin 150°) = 4\left(-\dfrac{\sqrt{3}}{2}, \dfrac{1}{2}\right)$.

$(-2\sqrt{3}, 2)$

Example 4

$\vec{a} = (t, t - 1)$ has $|\vec{a}| = 5$. Find $t$.

Show solution
  1. $t^2 + (t - 1)^2 = 25$, so $2t^2 - 2t - 24 = 0$, $t^2 - t - 12 = 0$.
  2. $(t - 4)(t + 3) = 0$.

$t = 4$ or $t = -3$

Use both $\cos\theta$ and $\sin\theta$ to fix the angle. $\cos\theta = -\dfrac{1}{2}$ alone allows $120°$ or $240°$; the sign of $\sin\theta$ decides.
When a length is given as a condition, square it: $|\vec{a}| = 5$ becomes $a_1^2 + a_2^2 = 25$, with no square roots to handle.
  • $\vec{a} = (a_1, a_2) = a_1\vec{e_1} + a_2\vec{e_2}$.
  • $|\vec{a}| = \sqrt{a_1^2 + a_2^2}$.
  • $\vec{a} = |\vec{a}|(\cos\theta, \sin\theta)$.
