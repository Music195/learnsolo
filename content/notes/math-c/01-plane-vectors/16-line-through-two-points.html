Vector Equation of a Line Through Two Points

Mix A and B with weights that add to 1

The line through A$(\vec{a})$ and B$(\vec{b})$ has direction $\vec{b} - \vec{a}$, so $\vec{p} = \vec{a} + t(\vec{b} - \vec{a}) = (1 - t)\vec{a} + t\vec{b}$. At $t = 0$ we are at A, at $t = 1$ at B.

Writing $s = 1 - t$: $\vec{p} = s\vec{a} + t\vec{b}$ with $s + t = 1$. If also $s \ge 0$ and $t \ge 0$, P stays on the segment AB.

A$(\vec{a})$, B$(\vec{b})$, A ≠ B

$$\vec{p} = (1 - t)\vec{a} + t\vec{b} \iff \vec{p} = s\vec{a} + t\vec{b}, \;\; s + t = 1$$

Segment AB: $s + t = 1$, $s \ge 0$, $t \ge 0$. P divides AB internally in $t : (1 - t)$ when $0 < t < 1$.

  1. The line passes through A with direction $\vec{d} = \overrightarrow{AB} = \vec{b} - \vec{a}$.
  2. By note 15: $\vec{p} = \vec{a} + t(\vec{b} - \vec{a}) = (1 - t)\vec{a} + t\vec{b}$.
  3. For $0 \le t \le 1$, $\overrightarrow{AP} = t\overrightarrow{AB}$ is a part of $\overrightarrow{AB}$, so P is on the segment.

Drag A and B; change $t$: P $= (1 - t)$A $+ t$B (teal on the segment, red off it)

Example 1

Write the line through A$(2, 1)$ and B$(4, 3)$ in parametric form.

Show solution
  1. $(1 - t)(2, 1) + t(4, 3) = (2 + 2t, 1 + 2t)$.

$x = 2 + 2t$, $y = 1 + 2t$ (that is, $y = x - 1$)

Example 2

A$(1, 2)$, B$(5, 4)$. Use $t$ to find the point dividing AB internally in $1 : 2$.

Show solution
  1. $\overrightarrow{AP} = \dfrac{1}{3}\overrightarrow{AB}$, so $t = \dfrac{1}{3}$.
  2. $\dfrac{2}{3}(1, 2) + \dfrac{1}{3}(5, 4) = \left(\dfrac{7}{3}, \dfrac{8}{3}\right)$.

$\left(\dfrac{7}{3}, \dfrac{8}{3}\right)$

Example 3

Write P$(3, 2)$ as $s\vec{a} + t\vec{b}$ ($s + t = 1$) for A$(1, 1)$, B$(5, 3)$.

Show solution
  1. $x$: $s + 5t = 3$; $y$: $s + 3t = 2$.
  2. Subtract: $2t = 1$, so $t = \dfrac{1}{2}$, $s = \dfrac{1}{2}$ (and $s + t = 1$ ✓).

$\vec{p} = \dfrac{1}{2}\vec{a} + \dfrac{1}{2}\vec{b}$: P is the midpoint of AB

Example 4

O, A, B are not on one line. Describe the points P with $\overrightarrow{OP} = s\vec{a} + t\vec{b}$, $s + t = 2$.

Show solution
  1. Divide the condition by $2$: $\dfrac{s}{2} + \dfrac{t}{2} = 1$.
  2. Write $\overrightarrow{OP} = \dfrac{s}{2}(2\vec{a}) + \dfrac{t}{2}(2\vec{b})$: weights adding to $1$ on the points A$'(2\vec{a})$, B$'(2\vec{b})$.

The line A$'$B$'$, where $\overrightarrow{OA'} = 2\vec{a}$ and $\overrightarrow{OB'} = 2\vec{b}$

In $(1 - t)\vec{a} + t\vec{b}$, the weight on $\vec{b}$ is $t$: larger $t$ moves P towards B. Don't swap them. The segment needs both $s \ge 0$ and $t \ge 0$, not just $s + t = 1$.
For conditions like $s + t = 2$ or $2s + 3t = 1$, rescale so the new weights add to $1$, and absorb the factors into the vectors (Example 4).
  • Line AB: $\vec{p} = (1 - t)\vec{a} + t\vec{b}$.
  • Same as $s\vec{a} + t\vec{b}$ with $s + t = 1$.
  • Segment AB: also $s, t \ge 0$.
