Vector Component Form

Work on each component separately

Once vectors are written as $(a_1, a_2)$, adding, subtracting and multiplying by a real number all happen component by component. Two vectors are equal exactly when both components match.

If $\vec{a}$ and $\vec{b}$ are nonzero and not parallel, every vector $\vec{p}$ in the plane can be written as $s\vec{a} + t\vec{b}$ in exactly one way. Finding $s$ and $t$ is just a pair of simultaneous equations.

$\vec{a} = (a_1, a_2)$, $\vec{b} = (b_1, b_2)$, $k$ real

$$\vec{a} \pm \vec{b} = (a_1 \pm b_1,\; a_2 \pm b_2), \qquad k\vec{a} = (ka_1,\; ka_2)$$
$$\vec{a} = \vec{b} \iff a_1 = b_1 \text{ and } a_2 = b_2$$
  1. $\vec{a} = a_1\vec{e_1} + a_2\vec{e_2}$ and $\vec{b} = b_1\vec{e_1} + b_2\vec{e_2}$.
  2. By the addition and real-multiple rules: $\vec{a} + \vec{b} = (a_1 + b_1)\vec{e_1} + (a_2 + b_2)\vec{e_2}$.
  3. So the components of $\vec{a} + \vec{b}$ are $(a_1 + b_1, a_2 + b_2)$; subtraction and $k\vec{a}$ work the same way.

Drag $\vec{a}$, $\vec{b}$ and P: P $= s\vec{a} + t\vec{b}$ along the slanted grid

Example 1

$\vec{a} = (2, 1)$, $\vec{b} = (1, 3)$. Find $\vec{a} + \vec{b}$, $\vec{a} - \vec{b}$ and $3\vec{a} - 2\vec{b}$.

Show solution
  1. $3\vec{a} - 2\vec{b} = (6, 3) - (2, 6)$.

$(3, 4)$, $\;(1, -2)$, $\;(4, -3)$

Example 2

Find $x$ and $y$ if $(x + 1, 2y) = (3, y + 4)$.

Show solution
  1. $x + 1 = 3$ and $2y = y + 4$.

$x = 2$, $y = 4$

Example 3

$\vec{a} = (2, 1)$, $\vec{b} = (1, -2)$. Write $\vec{p} = (5, 0)$ as $s\vec{a} + t\vec{b}$.

Show solution
  1. $(2s + t,\; s - 2t) = (5, 0)$.
  2. $s = 2t$, then $5t = 5$.

$\vec{p} = 2\vec{a} + \vec{b}$

Example 4

$\vec{x} + \vec{y} = (3, 5)$ and $\vec{x} - \vec{y} = (1, -1)$. Find $\vec{x}$ and $\vec{y}$.

Show solution
  1. Add: $2\vec{x} = (4, 4)$. Subtract: $2\vec{y} = (2, 6)$.

$\vec{x} = (2, 2)$, $\vec{y} = (1, 3)$

"$\vec{p} = s\vec{a} + t\vec{b}$ in exactly one way" needs $\vec{a}$ and $\vec{b}$ nonzero and not parallel. If they are parallel, $s\vec{a} + t\vec{b}$ only reaches one line.
For equations like Example 4, solve for $\vec{x}$ and $\vec{y}$ as vectors first, then put in components. It's less writing than two pairs of equations.
  • Add, subtract and scale component by component.
  • Equal vectors: equal components.
  • Non-parallel $\vec{a}$, $\vec{b}$: any $\vec{p} = s\vec{a} + t\vec{b}$, uniquely.
