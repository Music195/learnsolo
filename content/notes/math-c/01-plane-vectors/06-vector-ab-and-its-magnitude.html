Vector AB and Its Magnitude

End minus start

The vector $\overrightarrow{AB}$ is the move from A to B. Its components are (B's coordinates) − (A's coordinates), and its magnitude is the distance AB.

This turns many geometry questions into algebra: "ABCD is a parallelogram" becomes $\overrightarrow{AD} = \overrightarrow{BC}$, and "P is equally far from A and B" becomes $|\overrightarrow{PA}| = |\overrightarrow{PB}|$.

A$(a_1, a_2)$, B$(b_1, b_2)$

$$\overrightarrow{AB} = (b_1 - a_1,\; b_2 - a_2), \qquad |\overrightarrow{AB}| = \sqrt{(b_1 - a_1)^2 + (b_2 - a_2)^2}$$
  1. $\overrightarrow{OA} + \overrightarrow{AB} = \overrightarrow{OB}$, so $\overrightarrow{AB} = \overrightarrow{OB} - \overrightarrow{OA}$.
  2. In components: $(b_1, b_2) - (a_1, a_2) = (b_1 - a_1, b_2 - a_2)$.
  3. Its magnitude is $\sqrt{(b_1 - a_1)^2 + (b_2 - a_2)^2}$, which is the distance formula.

Drag A and B: the move A → B is "across, then up"

Example 1

A$(1, 2)$, B$(4, 6)$. Find $\overrightarrow{AB}$ and $|\overrightarrow{AB}|$.

Show solution
  1. $\overrightarrow{AB} = (3, 4)$, $\sqrt{9 + 16}$.

$(3, 4)$, $\;5$

Example 2

A$(1, 1)$, B$(5, 2)$, C$(4, 5)$. Find D so that ABCD is a parallelogram.

Show solution
  1. $\overrightarrow{AD} = \overrightarrow{BC} = (-1, 3)$.
  2. D $= (1 - 1, 1 + 3)$.

D$(0, 4)$

Example 3

Find the point P on the $x$-axis with PA = PB, for A$(1, 3)$ and B$(4, 2)$.

Show solution
  1. P$(x, 0)$: $(x - 1)^2 + 9 = (x - 4)^2 + 4$.
  2. $-2x + 10 = -8x + 20$, so $6x = 10$.

P$\left(\dfrac{5}{3}, 0\right)$

Example 4

A$(1, t)$ and B$(4, 2)$ are $5$ apart. Find $t$.

Show solution
  1. $3^2 + (2 - t)^2 = 25$, so $(2 - t)^2 = 16$, $2 - t = \pm 4$.

$t = -2$ or $t = 6$

$\overrightarrow{AB}$ is B − A. Doing A − B gives $\overrightarrow{BA}$: same length, opposite direction. For ABCD to be a parallelogram, the letters go round in order: $\overrightarrow{AD} = \overrightarrow{BC}$, not $\overrightarrow{AD} = \overrightarrow{CB}$.
"PA = PB" is easiest as PA$^2$ = PB$^2$: the $x^2$ terms cancel and a linear equation is left.
  • $\overrightarrow{AB} = (b_1 - a_1, b_2 - a_2)$: end minus start.
  • AB $= |\overrightarrow{AB}|$.
  • Parallelogram ABCD $\iff$ $\overrightarrow{AD} = \overrightarrow{BC}$.
