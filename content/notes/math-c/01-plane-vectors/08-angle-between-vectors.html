Vector Angle

Turn the dot product around

The dot product has two forms: $|\vec{a}||\vec{b}|\cos\theta$ and $a_1b_1 + a_2b_2$. The second is easy to compute from components, so solving for $\cos\theta$ gives the angle between any two nonzero vectors.

For "nice" values like $\pm\dfrac{1}{2}$, $\pm\dfrac{1}{\sqrt{2}}$, $\pm\dfrac{\sqrt{3}}{2}$, read $\theta$ off the unit circle. Otherwise, leave the answer as $\cos\theta = \ldots$ or give an approximate angle.

$\vec{a} = (a_1, a_2) \ne \vec{0}$, $\vec{b} = (b_1, b_2) \ne \vec{0}$, $0° \le \theta \le 180°$

$$\cos\theta = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|} = \frac{a_1b_1 + a_2b_2}{\sqrt{a_1^2 + a_2^2}\,\sqrt{b_1^2 + b_2^2}}$$

$\theta$ is unique in $0° \le \theta \le 180°$, because $\cos$ takes each value from $-1$ to $1$ exactly once there.

  1. From note 07: $|\vec{a}||\vec{b}|\cos\theta = a_1b_1 + a_2b_2$.
  2. Both lengths are positive, so divide by $|\vec{a}||\vec{b}|$.

Drag the tips of $\vec{a}$ and $\vec{b}$: the arc marks $\theta$

Example 1

Find the angle between $\vec{a} = (2, 1)$ and $\vec{b} = (1, 3)$.

Show solution
  1. $\vec{a} \cdot \vec{b} = 5$, $|\vec{a}| = \sqrt{5}$, $|\vec{b}| = \sqrt{10}$.
  2. $\cos\theta = \dfrac{5}{\sqrt{50}} = \dfrac{1}{\sqrt{2}}$.

$\theta = 45°$

Example 2

Find the angle between $\vec{a} = (\sqrt{3}, 1)$ and $\vec{b} = (-\sqrt{3}, 1)$.

Show solution
  1. $\vec{a} \cdot \vec{b} = -3 + 1 = -2$, $|\vec{a}| = |\vec{b}| = 2$.
  2. $\cos\theta = -\dfrac{2}{4} = -\dfrac{1}{2}$.

$\theta = 120°$

Example 3

Find $\cos\theta$ for $\vec{a} = (2, 3)$ and $\vec{b} = (4, 1)$, and estimate $\theta$.

Show solution
  1. $\vec{a} \cdot \vec{b} = 11$, $|\vec{a}| = \sqrt{13}$, $|\vec{b}| = \sqrt{17}$.
  2. $\cos\theta = \dfrac{11}{\sqrt{221}} \approx 0.740$, between $\cos 45° \approx 0.707$ and $\cos 40° \approx 0.766$.

$\cos\theta = \dfrac{11}{\sqrt{221}}$, $\theta \approx 42.3°$

Example 4

$|\vec{a}| = 1$, $|\vec{b}| = 2$ and $|\vec{a} - \vec{b}| = \sqrt{7}$. Find the angle between $\vec{a}$ and $\vec{b}$.

Show solution
  1. $|\vec{a} - \vec{b}|^2 = |\vec{a}|^2 - 2\vec{a} \cdot \vec{b} + |\vec{b}|^2$: $7 = 1 - 2\vec{a} \cdot \vec{b} + 4$, so $\vec{a} \cdot \vec{b} = -1$.
  2. $\cos\theta = \dfrac{-1}{1 \cdot 2} = -\dfrac{1}{2}$.

$\theta = 120°$

The angle between vectors is always in $0° \le \theta \le 180°$. A negative $\cos\theta$ means an obtuse angle, not a "negative angle".
When only lengths are given (Example 4), square the length you know, expand with dot-product rules, and solve for $\vec{a} \cdot \vec{b}$ first.
  • $\cos\theta = \dfrac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|}$, $\;0° \le \theta \le 180°$.
  • $\cos\theta > 0$: acute; $= 0$: right; $< 0$: obtuse.
  • Parallel: $\cos\theta = \pm 1$ ($\theta = 0°$ or $180°$).
