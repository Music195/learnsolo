Points On a Straight Line

Same line ⇔ one vector is a multiple of the other

Three points A, B, C (A ≠ B) are on one straight line (一直線上) exactly when the move A → C is a real multiple of the move A → B: $\overrightarrow{AC} = k\overrightarrow{AB}$.

The value of $k$ tells where C is: $0 < k < 1$ between A and B, $k > 1$ beyond B, $k < 0$ on the far side of A.

A ≠ B

$$\text{A, B, C on one line} \iff \overrightarrow{AC} = k\overrightarrow{AB} \text{ for some real } k$$

With position vectors from O: $\vec{c} = (1 - k)\vec{a} + k\vec{b}$, i.e. $\vec{c} = s\vec{a} + t\vec{b}$ with $s + t = 1$.

  1. $\overrightarrow{AC} = k\overrightarrow{AB}$ means $\vec{c} - \vec{a} = k(\vec{b} - \vec{a})$.
  2. So $\vec{c} = (1 - k)\vec{a} + k\vec{b}$. The two coefficients add to $1$.

Drag A, B and C; C snaps onto line AB when close

Example 1

Are A$(2, 3)$, B$(4, 7)$, C$(6, 11)$ on one line? And A$(1, 1)$, B$(2, 2)$, C$(3, 4)$?

Show solution
  1. $\overrightarrow{AB} = (2, 4)$, $\overrightarrow{AC} = (4, 8) = 2\overrightarrow{AB}$.
  2. $\overrightarrow{AB} = (1, 1)$, $\overrightarrow{AC} = (2, 3)$: $k = 2$ from $x$ but $k = 3$ from $y$.

The first three are on one line ($k = 2$); the second three are not

Example 2

A$(1, 2)$, B$(3, 4)$, C$(x, 6)$ are on one line. Find $x$.

Show solution
  1. $\overrightarrow{AC} = (x - 1, 4) = k(2, 2)$: $k = 2$, so $x - 1 = 4$.

$x = 5$

Example 3

Are A$(1, -1)$, B$(2, 1)$, C$(3, 3)$ on one line?

Show solution
  1. $\overrightarrow{AB} = (1, 2)$, $\overrightarrow{AC} = (2, 4) = 2\overrightarrow{AB}$.

Yes; B is the midpoint of AC

Example 4

In triangle OAB with $\overrightarrow{OA} = \vec{a}$, $\overrightarrow{OB} = \vec{b}$, point P has $\overrightarrow{OP} = \dfrac{1}{3}\vec{a} + k\vec{b}$ and lies on line AB. Find $k$, and the ratio AP : PB.

Show solution
  1. On line AB, the coefficients add to $1$: $\dfrac{1}{3} + k = 1$.
  2. $\overrightarrow{OP} = \dfrac{1 \cdot \vec{a} + 2\vec{b}}{3}$: the internal division formula with $m : n = 2 : 1$.

$k = \dfrac{2}{3}$, AP : PB $= 2 : 1$

The "$s + t = 1$" test needs $\vec{a}$ and $\vec{b}$ to be position vectors from the same origin O, with O, A, B not on one line. And use one $k$ for both components: matching just one is not enough.
With coordinates, use $\overrightarrow{AC} = k\overrightarrow{AB}$ (or $a_1b_2 - a_2b_1 = 0$ for the two vectors). With $\vec{a}$, $\vec{b}$ symbols, use "coefficients add to 1".
  • A, B, C on one line $\iff$ $\overrightarrow{AC} = k\overrightarrow{AB}$.
  • $\iff$ $\vec{c} = s\vec{a} + t\vec{b}$ with $s + t = 1$.
  • $k$ shows where C is relative to A and B.
