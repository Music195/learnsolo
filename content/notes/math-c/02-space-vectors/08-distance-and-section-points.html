Distance and Section Points

The plane formulas, with a $z$ added

The point dividing AB internally in the ratio $m : n$ (内分) sits between A and B, $m$ parts from A and $n$ parts from B. Its position vector is a weighted average: the weight on A is $n$, the weight on B is $m$ (each point is pulled by the other part of the ratio).

For external division (外分), the point lies on line AB but outside the segment, with AP : PB $= m : n$. The formula is the same with $n$ replaced by $-n$.

A$(\vec{a})$, B$(\vec{b})$, ratio $m : n$ ($m, n > 0$)

$$\text{internal: } \frac{n\vec{a} + m\vec{b}}{m + n}, \qquad \text{external: } \frac{-n\vec{a} + m\vec{b}}{m - n} \;\; (m \ne n)$$
$$\text{AB} = \sqrt{(b_1 - a_1)^2 + (b_2 - a_2)^2 + (b_3 - a_3)^2}$$

Apply the vector formula to each coordinate: e.g. the $x$-coordinate of the internal point is $\dfrac{na_1 + mb_1}{m + n}$.

  1. P divides AB internally in $m : n$, so $\overrightarrow{AP} = \dfrac{m}{m + n}\overrightarrow{AB}$.
  2. $\vec{p} = \vec{a} + \dfrac{m}{m + n}(\vec{b} - \vec{a}) = \dfrac{(m + n)\vec{a} - m\vec{a} + m\vec{b}}{m + n} = \dfrac{n\vec{a} + m\vec{b}}{m + n}$.
  3. External: $\overrightarrow{AP} = \dfrac{m}{m - n}\overrightarrow{AB}$, which gives $\dfrac{-n\vec{a} + m\vec{b}}{m - n}$ the same way.

A$(-1, -2, 0)$, B$(2, 1, 2)$: P divides internally (teal), Q externally (red) in $m : n$

Example 2

A$(1, 2, 3)$, B$(4, 5, 6)$. Find the point dividing AB internally in the ratio $2 : 1$.

Show solution
  1. $\dfrac{1 \cdot (1, 2, 3) + 2 \cdot (4, 5, 6)}{3} = \dfrac{(9, 12, 15)}{3}$

$(3, 4, 5)$

Example 3

A$(2, 3, 4)$, B$(6, 7, 8)$. Find the point dividing AB externally in the ratio $3 : 1$, and in the ratio $1 : 3$.

Show solution
  1. $3 : 1$: $\dfrac{-1 \cdot (2, 3, 4) + 3 \cdot (6, 7, 8)}{3 - 1} = \dfrac{(16, 18, 20)}{2}$.
  2. $1 : 3$: $\dfrac{-3 \cdot (2, 3, 4) + 1 \cdot (6, 7, 8)}{1 - 3} = \dfrac{(0, -2, -4)}{-2}$.

$(8, 9, 10)$ (beyond B) and $(0, 1, 2)$ (beyond A)

Example 4

Find the point on the $yz$-plane that line AB passes through, for A$(2, 1, 3)$, B$(-1, 4, 0)$.

Show solution
  1. Points on line AB: $\vec{a} + t(\vec{b} - \vec{a}) = (2 - 3t,\; 1 + 3t,\; 3 - 3t)$.
  2. $yz$-plane: $x = 0$, so $t = \dfrac{2}{3}$.

$(0, 3, 1)$ (it divides AB internally in $2 : 1$)

In $\dfrac{n\vec{a} + m\vec{b}}{m + n}$ the ratio numbers are crossed: $n$ goes with A, $m$ with B. A common slip is writing $m\vec{a} + n\vec{b}$. For external division with $m = n$ there is no such point (the denominator is $0$).
External $m : n$ with $m > n$: the point is beyond B. With $m < n$: beyond A. A quick sketch on a line checks your answer.
  • Internal $m : n$: $\dfrac{n\vec{a} + m\vec{b}}{m + n}$; external: $\dfrac{-n\vec{a} + m\vec{b}}{m - n}$.
  • Midpoint: $m = n = 1$.
  • AB $= |\vec{b} - \vec{a}|$.
