Magnitude of Vector 3-D

A vector's length is a distance

A space vector $\vec{a} = (a_1, a_2, a_3)$ can be drawn as the arrow from O to the point A$(a_1, a_2, a_3)$. Its magnitude (大きさ) $|\vec{a}|$ is the length OA, so the distance formula of note 01 gives it.

Dividing a vector by its own length gives a unit vector (単位ベクトル): length $1$, same direction. Multiplying that by any $k > 0$ gives a vector of length $k$ in that direction.

$\vec{a} = (a_1, a_2, a_3)$

$$|\vec{a}| = \sqrt{a_1^2 + a_2^2 + a_3^2}, \qquad \vec{e} = \frac{\vec{a}}{|\vec{a}|} \;\; (\vec{a} \ne \vec{0})$$

The unit vectors along the axes are $\vec{e_1} = (1, 0, 0)$, $\vec{e_2} = (0, 1, 0)$, $\vec{e_3} = (0, 0, 1)$, and $\vec{a} = a_1\vec{e_1} + a_2\vec{e_2} + a_3\vec{e_3}$.

  1. $|\vec{a}|$ is the distance from O to A$(a_1, a_2, a_3)$: $\sqrt{a_1^2 + a_2^2 + a_3^2}$ (note 01).
  2. For a real $k$: $|k\vec{a}| = \sqrt{k^2(a_1^2 + a_2^2 + a_3^2)} = |k||\vec{a}|$.
  3. With $k = \dfrac{1}{|\vec{a}|}$: $\left|\dfrac{\vec{a}}{|\vec{a}|}\right| = \dfrac{|\vec{a}|}{|\vec{a}|} = 1$.

Example 1

Find $|\vec{a}|$ for $\vec{a} = (2, -1, 2)$ and the unit vector in the same direction.

Show solution
  1. $|\vec{a}| = \sqrt{4 + 1 + 4} = 3$.

$3$; $\;\left(\dfrac{2}{3}, -\dfrac{1}{3}, \dfrac{2}{3}\right)$

Example 2

Find the vector of length $10$ in the same direction as $(3, 0, 4)$.

Show solution
  1. Unit vector: $\dfrac{1}{5}(3, 0, 4)$. Times $10$.

$(6, 0, 8)$

Example 3

$\vec{a} = (1, t, 2)$ has $|\vec{a}| = 3$. Find $t$.

Show solution
  1. $1 + t^2 + 4 = 9$, so $t^2 = 4$.

$t = \pm 2$

Example 4

$\vec{a} = (1, 2, -1)$, $\vec{b} = (1, 0, 1)$. Find the real $t$ that makes $|\vec{a} + t\vec{b}|$ smallest, and the smallest value.

Show solution
  1. $\vec{a} + t\vec{b} = (1 + t, 2, -1 + t)$, so $|\vec{a} + t\vec{b}|^2 = (1 + t)^2 + 4 + (t - 1)^2 = 2t^2 + 6$.
  2. Smallest at $t = 0$: $\sqrt{6}$.

$t = 0$, minimum $\sqrt{6}$

$|k\vec{a}| = |k||\vec{a}|$: the factor comes out as $|k|$, not $k$. For example, $|-2\vec{a}| = 2|\vec{a}|$. And $|\vec{a} + \vec{b}|$ is not $|\vec{a}| + |\vec{b}|$ in general.
To minimise or compare lengths, work with $|\vec{v}|^2$ (no square root). It is usually a quadratic in the parameter.
  • $|\vec{a}| = \sqrt{a_1^2 + a_2^2 + a_3^2}$.
  • Unit vector: $\dfrac{\vec{a}}{|\vec{a}|}$; length $k$: $k\dfrac{\vec{a}}{|\vec{a}|}$.
  • $|k\vec{a}| = |k||\vec{a}|$.
