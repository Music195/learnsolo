Vector Operations Component Form

Same rules as in the plane, one more component

Space vectors add, subtract and scale component by component, exactly like plane vectors. The parallelogram rule still holds: $\vec{a} + \vec{b}$ is the diagonal of the parallelogram on $\vec{a}$ and $\vec{b}$.

Two nonzero vectors are parallel (平行) when one is a real multiple of the other. In components, that means all three components are in the same ratio.

$\vec{a} = (a_1, a_2, a_3)$, $\vec{b} = (b_1, b_2, b_3)$, $k$ real

$$\vec{a} \pm \vec{b} = (a_1 \pm b_1,\, a_2 \pm b_2,\, a_3 \pm b_3), \qquad k\vec{a} = (ka_1,\, ka_2,\, ka_3)$$
$$\vec{a} \parallel \vec{b} \iff \vec{b} = k\vec{a} \text{ for some real } k \qquad (\vec{a}, \vec{b} \ne \vec{0})$$

Equal vectors: $\vec{a} = \vec{b} \iff a_1 = b_1$, $a_2 = b_2$, $a_3 = b_3$.

  1. Write $\vec{a} = a_1\vec{e_1} + a_2\vec{e_2} + a_3\vec{e_3}$ and $\vec{b} = b_1\vec{e_1} + b_2\vec{e_2} + b_3\vec{e_3}$.
  2. Vector addition and real multiples obey the usual algebra rules, so the $\vec{e_1}$, $\vec{e_2}$ and $\vec{e_3}$ parts can be collected separately.
  3. So $\vec{a} + \vec{b} = (a_1 + b_1)\vec{e_1} + (a_2 + b_2)\vec{e_2} + (a_3 + b_3)\vec{e_3}$, and the same for $-$ and $k$.

$s\vec{a} + t\vec{b}$ for $\vec{a} = (2, 0, 1)$ (blue), $\vec{b} = (0, 2, 1)$ (orange)

Example 1

$\vec{a} = (1, 2, 3)$, $\vec{b} = (-1, 0, 2)$. Find $2\vec{a} - 3\vec{b}$.

Show solution
  1. $(2, 4, 6) - (-3, 0, 6)$

$(5, 4, 0)$

Example 2

$\vec{u} + \vec{v} = (5, 7, -2)$ and $\vec{u} - \vec{v} = (1, -1, 4)$. Find $\vec{u}$ and $\vec{v}$.

Show solution
  1. Add: $2\vec{u} = (6, 6, 2)$. Subtract: $2\vec{v} = (4, 8, -6)$.

$\vec{u} = (3, 3, 1)$, $\vec{v} = (2, 4, -3)$

Example 3

$\vec{a} = (2, -1, 3)$ and $\vec{b} = (x, 2, y)$ are parallel. Find $x$ and $y$.

Show solution
  1. $\vec{b} = k\vec{a}$: $x = 2k$, $2 = -k$, $y = 3k$.
  2. $k = -2$.

$x = -4$, $y = -6$

Example 4

Write $\vec{p} = (3, 1, 4)$ as $s\vec{a} + t\vec{b} + u\vec{c}$, where $\vec{a} = (1, 1, 0)$, $\vec{b} = (0, 1, 1)$, $\vec{c} = (1, 0, 1)$.

Show solution
  1. Components: $s + u = 3$, $s + t = 1$, $t + u = 4$.
  2. Adding all three: $2(s + t + u) = 8$, so $s + t + u = 4$. Then $t = 1$, $u = 3$, $s = 0$.

$\vec{p} = \vec{b} + 3\vec{c}$ ($s = 0$, $t = 1$, $u = 3$)

For parallel vectors, use one $k$ for all three components. Matching two components is not enough. With zero components, avoid dividing: write $\vec{b} = k\vec{a}$ instead of comparing ratios.
Three vectors that don't lie in one plane (1次独立) can build any space vector as $s\vec{a} + t\vec{b} + u\vec{c}$, in exactly one way. Example 4 finds such $s$, $t$, $u$.
  • Add, subtract and scale component by component.
  • $\vec{a} \parallel \vec{b}$ $\iff$ $\vec{b} = k\vec{a}$ (same $k$ for all components).
  • Equal vectors: all three components equal.
