Absolute Value of Complex Number

Absolute value = distance

The absolute value (絶対値) $|z|$ is the distance from the origin to the point $z$. For a real number it is the usual absolute value.

More generally, $|\beta - \alpha|$ is the distance between the points A($\alpha$) and B($\beta$). So equations like $|z - \alpha| = r$ describe circles.

$z = a + bi$

$$|z| = \sqrt{a^2 + b^2}, \qquad \text{AB} = |\beta - \alpha|, \qquad |z|^2 = z\overline{z}$$

$|z| = r$: circle with centre O, radius $r$. $\;|z - \alpha| = r$: circle with centre $\alpha$. $\;|z - \alpha| = |z - \beta|$: perpendicular bisector of AB.

  1. The point $(a, b)$ is at distance $\sqrt{a^2 + b^2}$ from O (Pythagoras).
  2. $\beta - \alpha$ is the arrow from A to B moved to start at O. It has the same length as AB, so AB $= |\beta - \alpha|$.
  3. $z\overline{z} = (a + bi)(a - bi) = a^2 - b^2i^2 = a^2 + b^2 = |z|^2$.

Example 3

Describe the set of points $z$ with $|z - 2 + i| = 3$, and with $|z - 1| = |z + i|$.

Show solution
  1. $|z - (2 - i)| = 3$: distance $3$ from $2 - i$.
  2. Equal distances from $1$ and $-i$: the perpendicular bisector of the segment joining them. That is the line $y = -x$.

Circle, centre $2 - i$, radius $3$; the line $y = -x$

Example 4

Find the points $z$ with $|z - 3| = 2|z|$.

Show solution
  1. Square and use $|w|^2 = w\overline{w}$: $(z - 3)(\overline{z} - 3) = 4z\overline{z}$.
  2. $z\overline{z} - 3z - 3\overline{z} + 9 = 4z\overline{z}$, so $z\overline{z} + z + \overline{z} = 3$.
  3. $(z + 1)(\overline{z} + 1) = 4$, i.e. $|z + 1|^2 = 4$.

The circle with centre $-1$ and radius $2$

$|a + bi| = \sqrt{a^2 + b^2}$, not $\sqrt{a^2 + (bi)^2}$. Use the real numbers $a$ and $b$. And $|z - 2 + i|$ is centred at $2 - i$: rewrite it as $|z - (2 - i)|$ first.
To work with $|\ |$ algebraically, square it and use $|w|^2 = w\overline{w}$. This avoids square roots and lets you collect terms in $z$ and $\overline{z}$.
  • $|a + bi| = \sqrt{a^2 + b^2}$; $|z|^2 = z\overline{z}$.
  • $|\beta - \alpha|$ = distance AB.
  • $|z - \alpha| = r$: circle. $|z - \alpha| = |z - \beta|$: perpendicular bisector.
