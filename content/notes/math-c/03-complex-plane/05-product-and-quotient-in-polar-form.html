Product and Quotient In Polar Form

Multiply the lengths, add the angles

In polar form, multiplication is easy: multiply the moduli and add the arguments. Division divides the moduli and subtracts the arguments.

The reason is the addition formulas for sine and cosine (Math II). They are hidden inside the product $(\cos\alpha + i\sin\alpha)(\cos\beta + i\sin\beta)$.

$z_1 = r_1(\cos\theta_1 + i\sin\theta_1)$, $z_2 = r_2(\cos\theta_2 + i\sin\theta_2)$

$$z_1z_2 = r_1r_2\{\cos(\theta_1 + \theta_2) + i\sin(\theta_1 + \theta_2)\}$$
$$\frac{z_1}{z_2} = \frac{r_1}{r_2}\{\cos(\theta_1 - \theta_2) + i\sin(\theta_1 - \theta_2)\}$$
  1. $(\cos\theta_1 + i\sin\theta_1)(\cos\theta_2 + i\sin\theta_2) = (\cos\theta_1\cos\theta_2 - \sin\theta_1\sin\theta_2) + i(\sin\theta_1\cos\theta_2 + \cos\theta_1\sin\theta_2)$.
  2. By the addition formulas this is $\cos(\theta_1 + \theta_2) + i\sin(\theta_1 + \theta_2)$. Multiply by $r_1r_2$.
  3. For the quotient, let $w = \dfrac{z_1}{z_2}$. Then $z_1 = wz_2$, so by the product rule $r_1 = |w|r_2$ and $\theta_1 = \arg w + \theta_2$.

Example 1

$z_1 = 2\left(\cos\dfrac{\pi}{6} + i\sin\dfrac{\pi}{6}\right)$, $z_2 = 3\left(\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}\right)$. Find $z_1z_2$ and $\dfrac{z_1}{z_2}$.

Show solution
  1. $z_1z_2 = 6\left(\cos\dfrac{\pi}{2} + i\sin\dfrac{\pi}{2}\right) = 6i$.
  2. $\dfrac{z_1}{z_2} = \dfrac{2}{3}\left\{\cos\left(-\dfrac{\pi}{6}\right) + i\sin\left(-\dfrac{\pi}{6}\right)\right\} = \dfrac{2}{3}\left(\dfrac{\sqrt{3}}{2} - \dfrac{1}{2}i\right)$.

$6i$ and $\dfrac{\sqrt{3}}{3} - \dfrac{1}{3}i$

Example 2

Use polar form to find $(1 + i)(\sqrt{3} + i)$, and deduce the exact values of $\cos\dfrac{5\pi}{12}$ and $\sin\dfrac{5\pi}{12}$.

Show solution
  1. $1 + i = \sqrt{2}\left(\cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}\right)$, $\;\sqrt{3} + i = 2\left(\cos\dfrac{\pi}{6} + i\sin\dfrac{\pi}{6}\right)$.
  2. Product: $2\sqrt{2}\left(\cos\dfrac{5\pi}{12} + i\sin\dfrac{5\pi}{12}\right)$. Directly: $(1 + i)(\sqrt{3} + i) = (\sqrt{3} - 1) + (\sqrt{3} + 1)i$.
  3. Compare real and imaginary parts.

$\cos\dfrac{5\pi}{12} = \dfrac{\sqrt{6} - \sqrt{2}}{4}$, $\;\sin\dfrac{5\pi}{12} = \dfrac{\sqrt{6} + \sqrt{2}}{4}$

Example 3

Find $\dfrac{-1 + \sqrt{3}i}{1 + i}$ in polar form.

Show solution
  1. $-1 + \sqrt{3}i = 2\left(\cos\dfrac{2\pi}{3} + i\sin\dfrac{2\pi}{3}\right)$, $\;1 + i = \sqrt{2}\left(\cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}\right)$.
  2. Divide moduli: $\sqrt{2}$. Subtract arguments: $\dfrac{2\pi}{3} - \dfrac{\pi}{4} = \dfrac{5\pi}{12}$.

$\sqrt{2}\left(\cos\dfrac{5\pi}{12} + i\sin\dfrac{5\pi}{12}\right)$

Arguments add when you multiply. Don't multiply them. And the moduli multiply; they don't add. The resulting angle may fall outside your chosen range, so adjust it by $2\pi$ if needed.
For sums, use $a + bi$. For products, quotients and powers, use polar form. Comparing the two forms gives exact trig values, as in Example 2.
  • Product: moduli multiply, arguments add.
  • Quotient: moduli divide, arguments subtract.
  • Proof: the addition formulas for sine and cosine.
