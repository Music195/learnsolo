Rotation About the Origin

Multiplying turns the plane

Multiplying by $\cos\theta + i\sin\theta$ (modulus $1$) adds $\theta$ to the argument and keeps the modulus. So it rotates the point about O through $\theta$, anticlockwise if $\theta > 0$.

Multiplying by $r(\cos\theta + i\sin\theta)$ rotates through $\theta$ and scales the distance from O by $r$. In particular, multiplying by $i$ is a quarter-turn.

The image $w$ of $z$

$$w = (\cos\theta + i\sin\theta)\,z: \text{ rotation about O through } \theta$$
$$w = r(\cos\theta + i\sin\theta)\,z: \text{ rotation through } \theta, \text{ then scaling by } r$$

$iz$: quarter-turn anticlockwise; $-iz$: quarter-turn clockwise; $-z$: half-turn.

  1. Let $z = s(\cos\varphi + i\sin\varphi)$.
  2. By note 05, $(\cos\theta + i\sin\theta)z = s\{\cos(\varphi + \theta) + i\sin(\varphi + \theta)\}$.
  3. Same distance $s$ from O, angle increased by $\theta$: that is exactly a rotation through $\theta$.

Drag $z$; the orange point is $r(\cos\theta + i\sin\theta)z$

Example 1

Rotate $z = 2 + i$ about O through $\dfrac{\pi}{2}$ and through $\dfrac{\pi}{3}$.

Show solution
  1. $\dfrac{\pi}{2}$: multiply by $i$: $i(2 + i) = -1 + 2i$.
  2. $\dfrac{\pi}{3}$: $\left(\dfrac{1}{2} + \dfrac{\sqrt{3}}{2}i\right)(2 + i) = 1 + \dfrac{1}{2}i + \sqrt{3}i - \dfrac{\sqrt{3}}{2}$.

$-1 + 2i$ and $\dfrac{2 - \sqrt{3}}{2} + \dfrac{1 + 2\sqrt{3}}{2}i$

Example 2

$z = 2 + 3i$ is rotated about O to $w = -2 + 3i$. Find $\cos\theta$ and $\sin\theta$ for the angle of rotation.

Show solution
  1. $|z| = |w| = \sqrt{13}$, so it is a pure rotation and $\cos\theta + i\sin\theta = \dfrac{w}{z}$.
  2. $\dfrac{-2 + 3i}{2 + 3i} = \dfrac{(-2 + 3i)(2 - 3i)}{13} = \dfrac{-4 + 6i + 6i - 9i^2}{13} = \dfrac{5 + 12i}{13}$.

$\cos\theta = \dfrac{5}{13}$, $\sin\theta = \dfrac{12}{13}$ (about $67.4°$)

Example 3

An equilateral triangle has vertices O, A($2 + 2i$) and B. Find B.

Show solution
  1. B is A rotated about O through $\pm\dfrac{\pi}{3}$.
  2. $\left(\dfrac{1}{2} \pm \dfrac{\sqrt{3}}{2}i\right)(2 + 2i) = (1 \mp \sqrt{3}) + (1 \pm \sqrt{3})i$.

B $= (1 - \sqrt{3}) + (1 + \sqrt{3})i$ or $(1 + \sqrt{3}) + (1 - \sqrt{3})i$

Example 4

Describe the map $z \mapsto (1 + i)z$.

Show solution
  1. $1 + i = \sqrt{2}\left(\cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}\right)$.

Rotate about O through $\dfrac{\pi}{4}$ and enlarge by $\sqrt{2}$ from O

"Rotate through $60°$" with no direction stated usually means both directions are possible. For example, an equilateral triangle can lie on either side of OA, so give both answers.
To find the rotation taking $z$ to $w$, compute $\dfrac{w}{z}$. Its argument is the angle and its modulus is the scale factor.
  • $(\cos\theta + i\sin\theta)z$: rotate about O through $\theta$.
  • $r(\cos\theta + i\sin\theta)z$: rotate and scale by $r$.
  • $iz$: rotate by $90°$; $-z$: rotate by $180°$.
