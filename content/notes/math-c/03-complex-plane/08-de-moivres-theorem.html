De Moivre's Theorem

Powers: the angle is multiplied by $n$

Multiplying by $\cos\theta + i\sin\theta$ turns by $\theta$, so multiplying by it $n$ times turns by $n\theta$. That is De Moivre's theorem (ド・モアブルの定理).

With a modulus $r$, the powers $z, z^2, z^3, \ldots$ turn by $\theta$ each step while their distance from O is multiplied by $r$. They spiral outwards if $r > 1$, stay on a circle if $r = 1$, and spiral in if $r < 1$.

$n$: any integer

$$(\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta$$
$$\{r(\cos\theta + i\sin\theta)\}^n = r^n(\cos n\theta + i\sin n\theta)$$
  1. $n = 1$ is clear. If it holds for $n = k$, then $(\cos\theta + i\sin\theta)^{k+1} = (\cos k\theta + i\sin k\theta)(\cos\theta + i\sin\theta) = \cos(k + 1)\theta + i\sin(k + 1)\theta$ by note 05. So it holds for all $n \ge 1$ (mathematical induction).
  2. $n = 0$: both sides are $1$.
  3. $n = -m$ ($m \ge 1$): $\dfrac{1}{\cos m\theta + i\sin m\theta} = \cos(-m\theta) + i\sin(-m\theta)$ by the quotient rule.

The powers $z^0, z^1, \ldots, z^n$ of $z = r(\cos\theta + i\sin\theta)$

Example 1

Compute $(1 + \sqrt{3}i)^6$.

Show solution
  1. $1 + \sqrt{3}i = 2\left(\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}\right)$.
  2. Sixth power: $2^6(\cos 2\pi + i\sin 2\pi) = 64$.

$64$

Example 2

Compute $(1 - i)^{-8}$.

Show solution
  1. $1 - i = \sqrt{2}\left\{\cos\left(-\dfrac{\pi}{4}\right) + i\sin\left(-\dfrac{\pi}{4}\right)\right\}$.
  2. Power $-8$: $(\sqrt{2})^{-8}(\cos 2\pi + i\sin 2\pi) = \dfrac{1}{16}$.

$\dfrac{1}{16}$

Example 3

Express $\cos 3\theta$ and $\sin 3\theta$ in terms of $\cos\theta$ and $\sin\theta$.

Show solution
  1. Write $c = \cos\theta$, $s = \sin\theta$. Expand $(c + is)^3 = c^3 + 3ic^2s - 3cs^2 - is^3$.
  2. By De Moivre this equals $\cos 3\theta + i\sin 3\theta$. Compare the real parts, and the imaginary parts.
  3. Real: $c^3 - 3c(1 - c^2) = 4c^3 - 3c$. Imaginary: $3(1 - s^2)s - s^3 = 3s - 4s^3$.

$\cos 3\theta = 4\cos^3\theta - 3\cos\theta$, $\;\sin 3\theta = 3\sin\theta - 4\sin^3\theta$

Example 4

Find the smallest positive integer $n$ for which $(\sqrt{3} + i)^n$ is real.

Show solution
  1. $\sqrt{3} + i = 2\left(\cos\dfrac{\pi}{6} + i\sin\dfrac{\pi}{6}\right)$, so the $n$-th power has argument $\dfrac{n\pi}{6}$.
  2. It is real when $\sin\dfrac{n\pi}{6} = 0$, i.e. $n$ is a multiple of $6$.

$n = 6$ (value $-64$)

De Moivre's theorem is for integer $n$. It is not a formula for roots like $z^{\frac{1}{3}}$; roots are handled in note 09. Always rewrite the number in polar form first. Don't apply the theorem to $(a + bi)^n$ directly.
Expanding $(\cos\theta + i\sin\theta)^n$ with the binomial theorem and comparing parts gives the $n$-fold angle formulas. It is easier than repeating the addition formulas.
  • $(\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta$ for every integer $n$.
  • $z^n$: modulus $r^n$, argument $n\theta$.
  • Polar form first, then the power, then back to $a + bi$.
