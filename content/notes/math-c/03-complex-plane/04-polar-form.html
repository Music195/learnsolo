Polar Form of Complex Number

Length and direction

A nonzero $z$ is fixed by its distance $r = |z|$ from O and the angle $\theta$ that Oz makes with the positive real axis. $\theta$ is the argument (偏角), written $\arg z$.

Writing $z$ with $r$ and $\theta$ gives the polar form (極形式). It is the natural form for multiplying, dividing and taking powers, as the following notes show.

$z = a + bi \ne 0$

$$z = r(\cos\theta + i\sin\theta), \qquad r = |z| = \sqrt{a^2 + b^2}$$
$$\cos\theta = \frac{a}{r}, \qquad \sin\theta = \frac{b}{r}$$

$\theta$ is fixed up to adding $2n\pi$. Usually choose $0 \le \theta < 2\pi$ or $-\pi < \theta \le \pi$. Use the signs of both $\cos\theta$ and $\sin\theta$ to pick the quadrant.

  1. The point $(a, b)$ at distance $r$ and angle $\theta$ has $a = r\cos\theta$, $b = r\sin\theta$ (definition of sine and cosine).
  2. So $z = a + bi = r\cos\theta + ir\sin\theta = r(\cos\theta + i\sin\theta)$.
  3. $r$ must be positive: $-2(\cos\theta + i\sin\theta)$ is not in polar form. Rewrite it as $2\{\cos(\theta + \pi) + i\sin(\theta + \pi)\}$.

Example 1

Write $1 + \sqrt{3}i$ and $-2 - 2i$ in polar form ($0 \le \theta < 2\pi$).

Show solution
  1. $1 + \sqrt{3}i$: $r = 2$, $\cos\theta = \dfrac{1}{2}$, $\sin\theta = \dfrac{\sqrt{3}}{2}$, so $\theta = \dfrac{\pi}{3}$.
  2. $-2 - 2i$: $r = 2\sqrt{2}$, $\cos\theta = \sin\theta = -\dfrac{1}{\sqrt{2}}$ (third quadrant), so $\theta = \dfrac{5\pi}{4}$.

$2\left(\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}\right)$, $\;2\sqrt{2}\left(\cos\dfrac{5\pi}{4} + i\sin\dfrac{5\pi}{4}\right)$

Example 2

Write $-3i$ and $-5$ in polar form ($0 \le \theta < 2\pi$).

Show solution
  1. $-3i$: straight down, $r = 3$, $\theta = \dfrac{3\pi}{2}$.
  2. $-5$: to the left, $r = 5$, $\theta = \pi$.

$3\left(\cos\dfrac{3\pi}{2} + i\sin\dfrac{3\pi}{2}\right)$, $\;5(\cos\pi + i\sin\pi)$

Example 3

Write $4\left(\cos\dfrac{5\pi}{6} + i\sin\dfrac{5\pi}{6}\right)$ in the form $a + bi$.

Show solution
  1. $4\left(-\dfrac{\sqrt{3}}{2} + \dfrac{1}{2}i\right)$

$-2\sqrt{3} + 2i$

Example 4

$z = r(\cos\theta + i\sin\theta)$. Write $\overline{z}$ and $-z$ in polar form.

Show solution
  1. $\overline{z} = r(\cos\theta - i\sin\theta) = r\{\cos(-\theta) + i\sin(-\theta)\}$ (reflection: the angle changes sign).
  2. $-z = r(-\cos\theta - i\sin\theta) = r\{\cos(\theta + \pi) + i\sin(\theta + \pi)\}$ (half-turn).

$\arg\overline{z} = -\theta$, $\;\arg(-z) = \theta + \pi$, both with modulus $r$

Polar form is exactly $r(\cos\theta + i\sin\theta)$ with $r > 0$: cos first, a plus sign, the same angle in both. $2(\cos\theta - i\sin\theta)$ or $2(\sin\theta + i\cos\theta)$ are not polar form until rewritten.
Plot the point before choosing $\theta$. The quadrant is then obvious, and you only need the reference angle from the exact trig values.
  • $z = r(\cos\theta + i\sin\theta)$, $r = |z| > 0$, $\theta = \arg z$.
  • $\theta$ from $\cos\theta = \dfrac{a}{r}$ and $\sin\theta = \dfrac{b}{r}$ together.
  • $\arg\overline{z} = -\arg z$; $\arg(-z) = \arg z + \pi$.
