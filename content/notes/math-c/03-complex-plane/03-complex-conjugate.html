Properties of Complex Conjugate

A mirror in the real axis

The conjugate (共役複素数) of $z = a + bi$ is $\overline{z} = a - bi$. In the plane it is the reflection of $z$ in the real axis.

Conjugation works nicely with every operation: the conjugate of a sum, product or quotient is the sum, product or quotient of the conjugates. It also gives clean tests: $z$ is real when $\overline{z} = z$, and purely imaginary when $\overline{z} = -z$.

Rules for conjugates

$$\overline{\alpha \pm \beta} = \overline{\alpha} \pm \overline{\beta}, \qquad \overline{\alpha\beta} = \overline{\alpha}\,\overline{\beta}, \qquad \overline{\left(\frac{\alpha}{\beta}\right)} = \frac{\overline{\alpha}}{\overline{\beta}}$$
$$z \text{ real} \Leftrightarrow \overline{z} = z, \qquad z \text{ purely imaginary} \Leftrightarrow \overline{z} = -z \;\; (z \ne 0)$$

Also $z + \overline{z} = 2a$ (real), $z - \overline{z} = 2bi$, $z\overline{z} = |z|^2$, $\overline{\overline{z}} = z$.

  1. Let $\alpha = a + bi$, $\beta = c + di$. Then $\alpha\beta = (ac - bd) + (ad + bc)i$, so $\overline{\alpha\beta} = (ac - bd) - (ad + bc)i$.
  2. $\overline{\alpha}\,\overline{\beta} = (a - bi)(c - di) = (ac - bd) - (ad + bc)i$. The two are the same.
  3. $\overline{z} = z$ means $a - bi = a + bi$, so $b = 0$. And $\overline{z} = -z$ means $a - bi = -a - bi$, so $a = 0$.

Example 1

Compute $\overline{(2 + 3i)(1 - i)}$ in two ways.

Show solution
  1. Multiply first: $(2 + 3i)(1 - i) = 2 - 2i + 3i - 3i^2 = 5 + i$, so the conjugate is $5 - i$.
  2. Conjugate first: $(2 - 3i)(1 + i) = 2 + 2i - 3i - 3i^2 = 5 - i$.

$5 - i$ both ways

Example 2

Write $\dfrac{3 + i}{1 - 2i}$ in the form $a + bi$.

Show solution
  1. Multiply top and bottom by the conjugate of the bottom: $\dfrac{(3 + i)(1 + 2i)}{(1 - 2i)(1 + 2i)} = \dfrac{3 + 7i + 2i^2}{5}$.

$\dfrac{1}{5} + \dfrac{7}{5}i$

Example 3

$|z| = 1$. Show that $z + \dfrac{1}{z}$ is real.

Show solution
  1. $z\overline{z} = |z|^2 = 1$, so $\dfrac{1}{z} = \overline{z}$.
  2. $w = z + \overline{z}$ satisfies $\overline{w} = \overline{z} + z = w$.

$\overline{w} = w$, so $w$ is real (in fact $w = 2\,\mathrm{Re}\,z$)

Example 4

A cubic equation with real coefficients has root $1 + 2i$. Explain why $1 - 2i$ is also a root.

Show solution
  1. Let $f(x) = ax^3 + bx^2 + cx + d$ with $a$, $b$, $c$, $d$ real, and $f(\alpha) = 0$.
  2. Conjugate both sides: $\overline{f(\alpha)} = a\overline{\alpha}^3 + b\overline{\alpha}^2 + c\overline{\alpha} + d = f(\overline{\alpha})$, since real numbers are their own conjugates.

$f(\overline{\alpha}) = \overline{0} = 0$, so $1 - 2i$ is a root

$\overline{z} = -z$ also holds for $z = 0$, which is real, not purely imaginary. Add the condition $z \ne 0$ when you use this test.
To divide by $c + di$, multiply top and bottom by $c - di$. The bottom becomes the real number $c^2 + d^2$.
  • $\overline{z}$: reflection in the real axis.
  • Conjugate of sum, product, quotient = sum, product, quotient of conjugates.
  • Real: $\overline{z} = z$; purely imaginary: $\overline{z} = -z$, $z \ne 0$; $z\overline{z} = |z|^2$.
