Rotation About a Point

Move the centre to O, rotate, move back

Multiplying only rotates about the origin (note 07). To rotate about another point A($\alpha$), use three steps. Shift everything so A goes to O (subtract $\alpha$), rotate (multiply), then shift back (add $\alpha$).

In other words, the arrow from A to the point is rotated: $\gamma - \alpha$ is $\beta - \alpha$ turned through $\theta$.

B($\beta$) rotated about A($\alpha$) through $\theta$ gives C($\gamma$)

$$\gamma - \alpha = (\cos\theta + i\sin\theta)(\beta - \alpha), \qquad \gamma = \alpha + (\cos\theta + i\sin\theta)(\beta - \alpha)$$

Half-turn ($\theta = \pi$): $\gamma = 2\alpha - \beta$ (A is the midpoint of BC). Quarter-turn: $\gamma - \alpha = \pm i(\beta - \alpha)$.

  1. Translate by $-\alpha$: A goes to O and B goes to $\beta - \alpha$. Translations keep lengths and angles.
  2. Rotate about O: $\beta - \alpha$ goes to $(\cos\theta + i\sin\theta)(\beta - \alpha)$.
  3. Translate back by $+\alpha$: $\gamma = \alpha + (\cos\theta + i\sin\theta)(\beta - \alpha)$.

Example 1

Rotate B($3 + 2i$) about A($1 + i$) through $\dfrac{\pi}{2}$.

Show solution
  1. $\beta - \alpha = 2 + i$; times $i$: $-1 + 2i$.
  2. Add $\alpha$: $(1 + i) + (-1 + 2i)$.

$3i$

Example 2

Find the image of $-1 + 3i$ under a half-turn about $2 - 2i$.

Show solution
  1. $\gamma = 2\alpha - \beta = 2(2 - 2i) - (-1 + 3i)$

$5 - 7i$

Example 3

The triangle with vertices $1 + i$, $3 + i$, $2 + 3i$ is rotated about $2 + 2i$ through $\dfrac{\pi}{2}$. Find the new vertices.

Show solution
  1. $1 + i$: $i(-1 - i) = 1 - i$, so the image is $(2 + 2i) + (1 - i) = 3 + i$.
  2. $3 + i$: $i(1 - i) = 1 + i$, so the image is $3 + 3i$.
  3. $2 + 3i$: $i \cdot i = -1$, so the image is $1 + 2i$.

$3 + i$, $\;3 + 3i$, $\;1 + 2i$

Example 4

A($1$), B($3 + 2i$). Find C so that ABC is an equilateral triangle.

Show solution
  1. C is B rotated about A through $\pm\dfrac{\pi}{3}$: $\gamma = 1 + \left(\dfrac{1}{2} \pm \dfrac{\sqrt{3}}{2}i\right)(2 + 2i)$.
  2. $\left(\dfrac{1}{2} \pm \dfrac{\sqrt{3}}{2}i\right)(2 + 2i) = (1 \mp \sqrt{3}) + (1 \pm \sqrt{3})i$.

C $= (2 - \sqrt{3}) + (1 + \sqrt{3})i$ or $(2 + \sqrt{3}) + (1 - \sqrt{3})i$

$(\cos\theta + i\sin\theta)\beta$ rotates about the origin, not about A. Always rotate the difference $\beta - \alpha$, then add $\alpha$ back.
"$\gamma - \alpha = i(\beta - \alpha)$" says three things at once: AB = AC, the angle at A is $90°$, and C comes after B anticlockwise. Learn to read shapes like this from the equation.
  • $\gamma = \alpha + (\cos\theta + i\sin\theta)(\beta - \alpha)$.
  • Subtract the centre, rotate, add the centre.
  • Half-turn: $\gamma = 2\alpha - \beta$.
