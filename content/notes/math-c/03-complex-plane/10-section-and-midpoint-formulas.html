Section and Midpoint Formula

Same formulas as for vectors

Complex numbers add like position vectors, so the section formulas from vectors carry over unchanged. The point dividing AB in the ratio $m : n$ is a weighted average of $\alpha$ and $\beta$. Each end's weight is the part of the ratio on the other side.

"Internal" points lie between A and B. "External" points lie on the line AB beyond A or beyond B.

A($\alpha$), B($\beta$), ratio $m : n$

$$\text{internal: } \frac{n\alpha + m\beta}{m + n}, \qquad \text{external: } \frac{-n\alpha + m\beta}{m - n} \;\; (m \ne n)$$
$$\text{midpoint: } \frac{\alpha + \beta}{2}, \qquad \text{centroid of ABC: } \frac{\alpha + \beta + \gamma}{3}$$
  1. P divides AB internally in $m : n$, so $\overrightarrow{AP} = \dfrac{m}{m + n}\overrightarrow{AB}$, i.e. $z - \alpha = \dfrac{m}{m + n}(\beta - \alpha)$.
  2. $z = \alpha + \dfrac{m}{m + n}(\beta - \alpha) = \dfrac{(m + n)\alpha - m\alpha + m\beta}{m + n} = \dfrac{n\alpha + m\beta}{m + n}$.
  3. External division is the same with $n$ replaced by $-n$.

Example 1

A($3 + 2i$), B($1 - 4i$). Find the point dividing AB internally in the ratio $2 : 3$.

Show solution
  1. $\dfrac{3(3 + 2i) + 2(1 - 4i)}{5} = \dfrac{11 - 2i}{5}$

$\dfrac{11}{5} - \dfrac{2}{5}i$

Example 2

A($1 + i$), B($4 + 7i$). Find the point dividing AB externally in the ratio $2 : 1$, and in the ratio $1 : 2$.

Show solution
  1. $2 : 1$: $\dfrac{-(1 + i) + 2(4 + 7i)}{2 - 1} = 7 + 13i$ (beyond B).
  2. $1 : 2$: $\dfrac{-2(1 + i) + (4 + 7i)}{1 - 2} = -2 - 5i$ (beyond A).

$7 + 13i$ and $-2 - 5i$

Example 3

Find the centroid of the triangle with vertices $2 + i$, $3 - 2i$ and $-1 + 3i$.

Show solution
  1. $\dfrac{(2 + 3 - 1) + (1 - 2 + 3)i}{3}$

$\dfrac{4}{3} + \dfrac{2}{3}i$

Example 4

The midpoint of AB is $2 + i$ and A is $-1 + 4i$. Find B.

Show solution
  1. $\dfrac{\alpha + \beta}{2} = 2 + i$, so $\beta = 2(2 + i) - \alpha$.

$5 - 2i$

In $\dfrac{n\alpha + m\beta}{m + n}$, $\alpha$ is multiplied by $n$, not $m$. The weights swap, because a point closer to B leans more on $\beta$. External division has no point when $m = n$.
Check your answer: an internal point must lie between A and B. An external point with $m > n$ lies beyond B, and with $m < n$ beyond A.
