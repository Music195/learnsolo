N-th Roots of 1

$n$ points evenly spaced on a circle

To solve $z^n = 1$, write $z = r(\cos\theta + i\sin\theta)$. De Moivre gives $r^n(\cos n\theta + i\sin n\theta) = 1$, so $r = 1$ and $n\theta$ must be a multiple of $2\pi$.

That gives exactly $n$ different solutions, the vertices of a regular $n$-gon on the unit circle with one vertex at $1$. The same method solves $z^n = \alpha$ for any $\alpha$.

The $n$ solutions of $z^n = 1$ ($k = 0, 1, \ldots, n - 1$)

$$z_k = \cos\frac{2k\pi}{n} + i\sin\frac{2k\pi}{n}$$

With $\omega = z_1$, the roots are $1, \omega, \omega^2, \ldots, \omega^{n-1}$, and for $n \ge 2$: $1 + \omega + \omega^2 + \cdots + \omega^{n-1} = 0$. For $z^n = \rho(\cos\varphi + i\sin\varphi)$: $z_k = \sqrt[n]{\rho}\left\{\cos\dfrac{\varphi + 2k\pi}{n} + i\sin\dfrac{\varphi + 2k\pi}{n}\right\}$.

  1. $z^n = 1 = \cos 0 + i\sin 0$ with $z = r(\cos\theta + i\sin\theta)$: $r^n = 1$ and $n\theta = 2k\pi$ ($k$ an integer).
  2. $r > 0$, so $r = 1$, and $\theta = \dfrac{2k\pi}{n}$. The values $k = 0, \ldots, n - 1$ give different points; $k = n$ gives $1$ again.
  3. Sum: $\omega^n = 1$ and $\omega \ne 1$, so $(\omega - 1)(1 + \omega + \cdots + \omega^{n-1}) = \omega^n - 1 = 0$, and the second factor is $0$.

The solutions of $z^n = \alpha$

Example 1

Solve $z^3 = 1$, and show that $\omega = \dfrac{-1 + \sqrt{3}i}{2}$ satisfies $\omega^2 + \omega + 1 = 0$.

Show solution
  1. $k = 0, 1, 2$: $1$, $\cos\dfrac{2\pi}{3} + i\sin\dfrac{2\pi}{3}$, $\cos\dfrac{4\pi}{3} + i\sin\dfrac{4\pi}{3}$.
  2. $z^3 - 1 = (z - 1)(z^2 + z + 1)$, and $\omega \ne 1$ is a root, so $\omega^2 + \omega + 1 = 0$.

$1$, $\dfrac{-1 + \sqrt{3}i}{2}$, $\dfrac{-1 - \sqrt{3}i}{2}$

Example 2

Solve $z^4 = -4$.

Show solution
  1. $-4 = 4(\cos\pi + i\sin\pi)$. Then $r^4 = 4$ and $4\theta = \pi + 2k\pi$, so $r = \sqrt{2}$, $\theta = \dfrac{\pi}{4} + \dfrac{k\pi}{2}$.
  2. $\sqrt{2}\left(\cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}\right) = 1 + i$, and the rest follow by quarter-turns.

$\pm 1 \pm i$ (all four sign choices)

Example 3

Solve $z^3 = 8i$.

Show solution
  1. $8i = 8\left(\cos\dfrac{\pi}{2} + i\sin\dfrac{\pi}{2}\right)$. Then $r = 2$ and $\theta = \dfrac{\pi}{6} + \dfrac{2k\pi}{3}$, i.e. $\dfrac{\pi}{6}$, $\dfrac{5\pi}{6}$, $\dfrac{3\pi}{2}$.

$\sqrt{3} + i$, $\;-\sqrt{3} + i$, $\;-2i$

Example 4

$\omega$ is a root of $z^3 = 1$ with $\omega \ne 1$. Find $\omega^{10} + \omega^5 + 1$.

Show solution
  1. $\omega^3 = 1$, so $\omega^{10} = \omega$ and $\omega^5 = \omega^2$.
  2. $\omega + \omega^2 + 1 = 0$.

$0$

$z^n = \alpha$ ($\alpha \ne 0$) has exactly $n$ solutions. Writing only one, such as "$\sqrt[3]{8i}$", is not an answer. Add $2k\pi$ to the argument before dividing by $n$; otherwise you only find one root.
Once you have one root, the others are that root rotated by $\dfrac{2\pi}{n}$ again and again. In other words, multiply it by the roots of $1$.
  • $z^n = 1$: $z_k = \cos\dfrac{2k\pi}{n} + i\sin\dfrac{2k\pi}{n}$, a regular $n$-gon on the unit circle.
  • $1 + \omega + \cdots + \omega^{n-1} = 0$ ($n \ge 2$); for $n = 3$: $\omega^2 + \omega + 1 = 0$, $\omega^3 = 1$.
  • $z^n = \alpha$: polar form, compare modulus and argument $+ 2k\pi$.
