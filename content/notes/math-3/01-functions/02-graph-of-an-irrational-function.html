Graph of an Irrational Function

Half of a sideways parabola

Squaring $y = \sqrt{ax}$ gives $y^2 = ax$, a parabola lying on its side. The square root keeps only the upper half ($y \ge 0$); $y = -\sqrt{ax}$ is the lower half.

$y = \sqrt{a(x - p)} + q$ starts at the point $(p, q)$, going right if $a > 0$ and left if $a < 0$.

$y = \pm\sqrt{a(x - p)} + q$

$$\text{start point } (p, q), \qquad \text{domain: } a(x - p) \ge 0$$
$$\text{range: } y \ge q \text{ for } +\sqrt{\phantom{x}}, \qquad y \le q \text{ for } -\sqrt{\phantom{x}}$$

$y = \sqrt{ax + b}$: take out $a$, e.g. $\sqrt{2x - 4} = \sqrt{2(x - 2)}$ starts at $(2, 0)$.

  1. $y = \sqrt{ax} \iff y \ge 0$ and $y^2 = ax$, i.e. $x = \dfrac{1}{a}y^2$.
  2. $x = \dfrac{1}{a}y^2$ is a parabola with axis the $x$-axis; the condition $y \ge 0$ keeps the upper half.

$y = s\sqrt{a(x - p)} + q$ and the line $y = x + n$

Example 1

Find the domain and range of $y = -\sqrt{4 - 2x} + 1$.

Show solution
  1. $y = -\sqrt{-2(x - 2)} + 1$: start $(2, 1)$, $a < 0$ so it goes left; the minus sign puts it below $y = 1$.

Domain $x \le 2$; range $y \le 1$

Example 2

Solve $\sqrt{x + 2} = x$.

Show solution
  1. Square: $x + 2 = x^2$, so $(x - 2)(x + 1) = 0$.
  2. Check: the left side is $\ge 0$, so $x \ge 0$ is needed. $x = -1$ is an extra root created by squaring.

$x = 2$

Example 3

Solve $\sqrt{x + 2} > x$.

Show solution
  1. Domain $x \ge -2$. The curve meets $y = x$ only at $x = 2$ (Example 2).
  2. From the graph, the curve is above the line from its start $x = -2$ up to $x = 2$.

$-2 \le x < 2$

Squaring can add false solutions. Always check the answers in the original equation (or require both sides to be $\ge 0$).
For equations and inequalities with roots, a quick sketch of both sides shows how many solutions there are and which side is bigger.
