How to Find the Inverse Function of f(x)

Run the function backwards

If every output $y$ of $f$ comes from exactly one input $x$ (the function is one-to-one), we can go back from $y$ to $x$. That backwards function is the inverse $f^{-1}$. Its graph is the graph of $f$ reflected in the line $y = x$.

Finding $f^{-1}$

$$y = f(x) \;\xrightarrow{\text{solve}}\; x = g(y) \;\xrightarrow{\text{swap}}\; y = g(x) = f^{-1}(x)$$

Domain of $f^{-1}$ = range of $f$; range of $f^{-1}$ = domain of $f$.

  1. $(a, b)$ is on $y = f(x)$ $\iff$ $f(a) = b$ $\iff$ $f^{-1}(b) = a$ $\iff$ $(b, a)$ is on $y = f^{-1}(x)$.
  2. $(a, b)$ and $(b, a)$ are mirror images in $y = x$, so the two graphs are too.

Drag $P$ on $y = f(x)$; $Q$ is on $y = f^{-1}(x)$

Example 1

Find the inverse of $f(x) = x^2 + 4$ ($x \ge 0$).

Show solution
  1. Range of $f$: $y \ge 4$. Solve: $x^2 = y - 4$, and $x \ge 0$, so $x = \sqrt{y - 4}$.
  2. Swap: $y = \sqrt{x - 4}$, domain $x \ge 4$.

$f^{-1}(x) = \sqrt{x - 4}$ ($x \ge 4$)

Example 2

Find the inverse of $f(x) = \dfrac{x + 1}{x - 2}$.

Show solution
  1. $y(x - 2) = x + 1 \Rightarrow x(y - 1) = 2y + 1 \Rightarrow x = \dfrac{2y + 1}{y - 1}$ (range of $f$: $y \ne 1$).
  2. Swap.

$f^{-1}(x) = \dfrac{2x + 1}{x - 1}$ ($x \ne 1$)

Example 3

Find the inverse of $f(x) = \log_2(x + 1)$.

Show solution
  1. $y = \log_2(x + 1) \Rightarrow x + 1 = 2^y \Rightarrow x = 2^y - 1$ (range of $f$: all reals).

$f^{-1}(x) = 2^x - 1$

$f(x) = x^2$ on all reals has no inverse ($f(2) = f(-2)$). Restrict the domain first (e.g. $x \ge 0$), and give the inverse's domain with your answer.
Find the range of $f$ before solving: it becomes the domain of $f^{-1}$, and it tells you which sign of a square root to keep.
  • Solve $y = f(x)$ for $x$, then swap $x$ and $y$.
  • Domain of $f^{-1}$ = range of $f$.
  • Graphs are mirror images in $y = x$.
