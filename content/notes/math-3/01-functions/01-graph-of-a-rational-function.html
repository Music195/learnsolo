Graph of a Rational Function

A moved hyperbola

$y = \dfrac{k}{x}$ is a hyperbola with the two axes as asymptotes. $y = \dfrac{k}{x - p} + q$ is the same curve moved $p$ right and $q$ up, so its asymptotes become $x = p$ and $y = q$.

For $k > 0$ the two branches lie top-right and bottom-left of the asymptote cross; for $k < 0$, top-left and bottom-right.

$y = \dfrac{k}{x - p} + q$ ($k \ne 0$)

$$\text{asymptotes } x = p,\; y = q, \qquad \text{domain } x \ne p, \qquad \text{range } y \ne q$$

$y = \dfrac{ax + b}{cx + d}$: divide to bring it to this form, e.g. $\dfrac{2x + 1}{x - 1} = \dfrac{3}{x - 1} + 2$.

  1. $2x + 1 = 2(x - 1) + 3$, so $\dfrac{2x + 1}{x - 1} = \dfrac{2(x - 1) + 3}{x - 1} = 2 + \dfrac{3}{x - 1}$.
  2. So it is $y = \dfrac{3}{x}$ moved $1$ right and $2$ up: asymptotes $x = 1$, $y = 2$.

$y = \dfrac{k}{x - p} + q$ and the line $y = mx$

Example 1

Find the asymptotes, domain and range of $y = \dfrac{-2}{x + 1} - 1$.

Show solution
  1. $p = -1$, $q = -1$, $k = -2 < 0$ (branches top-left and bottom-right).

Asymptotes $x = -1$, $y = -1$; domain $x \ne -1$; range $y \ne -1$

Example 2

Find the asymptotes of $y = \dfrac{3x - 4}{x - 2}$.

Show solution
  1. $3x - 4 = 3(x - 2) + 2$, so $y = \dfrac{2}{x - 2} + 3$.

$x = 2$, $y = 3$

Example 3

Solve $\dfrac{3}{x - 1} + 2 > x$ using the graphs.

Show solution
  1. Intersections: $3 + 2(x - 1) = x(x - 1)$ ($x \ne 1$), so $x^2 - 3x - 1 = 0$, $x = \dfrac{3 \pm \sqrt{13}}{2}$.
  2. Left branch ($x < 1$): far left the curve is near $y = 2$, above the line; it crosses at $x = \dfrac{3 - \sqrt{13}}{2} \approx -0.30$ and then drops to $-\infty$.
  3. Right branch ($x > 1$): starts at $+\infty$, above the line, until $x = \dfrac{3 + \sqrt{13}}{2} \approx 3.30$.

$x < \dfrac{3 - \sqrt{13}}{2}$, $\;1 < x < \dfrac{3 + \sqrt{13}}{2}$
