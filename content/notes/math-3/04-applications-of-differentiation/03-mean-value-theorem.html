Mean Value Theorem

Somewhere the tangent is parallel to the chord

Draw the chord from $(a, f(a))$ to $(b, f(b))$. Its slope is the average rate of change. If the curve is smooth in between, at some point $c$ the tangent has exactly that slope: the instantaneous rate equals the average rate.

Example: if you drive 120 km in 2 hours, at some moment your speedometer read exactly 60 km/h.

Mean value theorem

$$\frac{f(b) - f(a)}{b - a} = f'(c), \qquad a < c < b$$

Conditions: $f$ continuous on $[a, b]$ and differentiable on $a < x < b$. Then at least one such $c$ exists. Equivalent form: $f(b) - f(a) = f'(c)(b - a)$.

  1. Rolle's theorem: if also $f(a) = f(b)$, then $f$ has a maximum or minimum inside $(a, b)$ (or is constant), and there $f'(c) = 0$.
  2. In general, subtract the chord: $g(x) = f(x) - \dfrac{f(b) - f(a)}{b - a}(x - a)$. Then $g(a) = g(b) = f(a)$.
  3. Rolle gives $g'(c) = 0$, i.e. $f'(c) = \dfrac{f(b) - f(a)}{b - a}$.

Example 1

Find $c$ in the mean value theorem for $f(x) = x^3$ on $[-1, 2]$.

Show solution
  1. Average slope: $\dfrac{8 - (-1)}{2 - (-1)} = 3$.
  2. $3c^2 = 3 \Rightarrow c = \pm 1$. Only $c = 1$ lies strictly between $-1$ and $2$.

$c = 1$

Example 2

For $0 < a < b$, show $\dfrac{b - a}{b} < \log b - \log a < \dfrac{b - a}{a}$.

Show solution
  1. Mean value theorem for $\log x$ on $[a, b]$: $\dfrac{\log b - \log a}{b - a} = \dfrac{1}{c}$ with $a < c < b$.
  2. $a < c < b \Rightarrow \dfrac{1}{b} < \dfrac{1}{c} < \dfrac{1}{a}$.
  3. Multiply through by $b - a > 0$.

$\dfrac{b - a}{b} < \log b - \log a < \dfrac{b - a}{a}$ ✓

Example 3

Find $\displaystyle\lim_{x \to 0} \frac{e^{x} - e^{\sin x}}{x - \sin x}$.

Show solution
  1. Mean value theorem for $e^t$ between $\sin x$ and $x$: $\dfrac{e^x - e^{\sin x}}{x - \sin x} = e^c$ with $c$ between $\sin x$ and $x$.
  2. As $x \to 0$, both $\sin x$ and $x$ go to $0$, so $c \to 0$ (squeezed).

$e^0 = 1$

Check the conditions. $f(x) = |x|$ on $[-1, 1]$ has average slope $0$, but no point has $f'(c) = 0$, because $|x|$ is not differentiable at $0$.
A difference $f(b) - f(a)$ (like $\log b - \log a$, or $e^x - e^{\sin x}$) is a hint: turn it into $f'(c)(b - a)$, then bound $c$.
  • $\dfrac{f(b) - f(a)}{b - a} = f'(c)$ for some $a < c < b$.
  • Needs continuity on $[a, b]$ and differentiability inside.
  • Used for inequalities and limits: replace a difference by $f'(c)$ and squeeze $c$.
