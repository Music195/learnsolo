Second Derivative Test for Extrema

A flat point in a bowl is a bottom

Suppose $f'(a) = 0$, so the tangent is flat. If the curve is concave up there ($f''(a) > 0$), the flat point sits at the bottom of a bowl: a local minimum. If it is concave down ($f''(a) < 0$), it is the top of a cap: a local maximum.

If $f''(a) = 0$ the test says nothing, so go back to the sign of $f'$.

When $f'(a) = 0$

$$f''(a) > 0 \Rightarrow \text{local min}, \qquad f''(a) < 0 \Rightarrow \text{local max}, \qquad f''(a) = 0 \Rightarrow \text{no conclusion}$$

Maximum and minimum on a closed interval $[p, q]$: compare the local extrema with the end values $f(p)$, $f(q)$.

  1. Let $f'(a) = 0$ and $f''(a) > 0$. Since $f''$ is the derivative of $f'$, $f'$ is increasing near $a$.
  2. So near $a$: $f'(x) < f'(a) = 0$ to the left and $f'(x) > 0$ to the right.
  3. $f'$ goes from $-$ to $+$: a local minimum. The case $f''(a) < 0$ is the mirror image.

At each flat point: the matching bowl or cap (dashed)

Example 1

Find the local extrema of $f(x) = x^3 - 3x^2 - 9x + 5$ with the second derivative test.

Show solution
  1. $f'(x) = 3(x + 1)(x - 3)$: zero at $x = -1, 3$. $\;f''(x) = 6x - 6$.
  2. $f''(-1) = -12 < 0$: local max $f(-1) = 10$. $\;f''(3) = 12 > 0$: local min $f(3) = -22$.

Local max $10$ ($x = -1$), local min $-22$ ($x = 3$)

Example 2

Find the local extrema of $f(x) = x + \dfrac{1}{x}$.

Show solution
  1. $f'(x) = 1 - \dfrac{1}{x^2} = 0 \Rightarrow x = \pm 1$. $\;f''(x) = \dfrac{2}{x^3}$.
  2. $f''(1) = 2 > 0$: min $f(1) = 2$. $\;f''(-1) = -2 < 0$: max $f(-1) = -2$.

Local min $2$, local max $-2$ (the local max is smaller than the local min!)

Example 3

Find the maximum and minimum of $f(x) = x^3 - 3x$ on $-2 \le x \le 3$.

Show solution
  1. Local: $f(-1) = 2$ (max), $f(1) = -2$ (min).
  2. Ends: $f(-2) = -2$, $f(3) = 18$.
  3. Compare all four values.

Maximum $18$ ($x = 3$); minimum $-2$ ($x = -2$ and $x = 1$)

Example 4

Cut equal squares of side $x$ from the corners of a $12 \times 12$ sheet and fold up a box. Which $x$ gives the largest volume?

Show solution
  1. $V = x(12 - 2x)^2$ with $0 < x < 6$.
  2. $V' = (12 - 2x)^2 - 4x(12 - 2x) = (12 - 2x)(12 - 6x)$, zero in range only at $x = 2$.
  3. $V'' = 24x - 96$ (expand $V = 4x^3 - 48x^2 + 144x$), so $V''(2) = -48 < 0$: a maximum.

$x = 2$, volume $128$

$f''(a) = 0$ does not mean "no extremum". $x^4$ has a minimum at $0$, $-x^4$ a maximum, and $x^3$ neither, yet all three have $f'(0) = f''(0) = 0$. Use the sign of $f'$ instead.
For the maximum or minimum on an interval, list the candidates: local extrema inside, plus both ends. Then compare their values. A local maximum need not be the biggest value overall.
  • $f'(a) = 0$ and $f''(a) > 0$: local min; $f''(a) < 0$: local max.
  • $f''(a) = 0$: undecided; check the sign change of $f'$.
  • Max/min on $[p, q]$: compare local extrema with $f(p)$ and $f(q)$.
