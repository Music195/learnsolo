Necessary Condition for Local Extrema

Hilltops and valley floors are flat

$f$ has a local maximum (極大) at $a$ if $f(a)$ is bigger than $f(x)$ for every other $x$ near $a$. A local minimum (極小) is the same with "smaller". Together they are called local extrema (極値).

At a smooth hilltop the tangent must be horizontal, so $f'(a) = 0$. But a flat tangent alone is not enough: the slope must also change sign there.

Necessary condition

$$f \text{ differentiable at } a \text{ and } f(a) \text{ is a local extremum} \implies f'(a) = 0$$

Deciding with the sign of $f'$

$$f' : + \to - \text{ at } a \Rightarrow \text{local max}, \qquad f' : - \to + \text{ at } a \Rightarrow \text{local min}$$

No sign change (like $x^3$ at $0$): no extremum. Extrema can also occur where $f$ is not differentiable, e.g. $|x|$ at $0$.

  1. Let $f(a)$ be a local maximum. For small $h$, $f(a + h) - f(a) \le 0$.
  2. $h > 0$: $\dfrac{f(a + h) - f(a)}{h} \le 0$, so the right-hand limit gives $f'(a) \le 0$. $\;h < 0$: the fraction is $\ge 0$, so $f'(a) \ge 0$.
  3. Both together: $f'(a) = 0$. (A local minimum is the same with the inequalities reversed.)

$f(x) = x^3 + px + 1$: when are there extrema?

Example 1

Find the local extrema of $f(x) = x^2e^{-x}$.

Show solution
  1. $f'(x) = 2xe^{-x} - x^2e^{-x} = x(2 - x)e^{-x}$, zero at $x = 0, 2$.
  2. Sign of $f'$ ($e^{-x} > 0$, so read $x(2 - x)$): $-$, then $+$, then $-$.

Local min $f(0) = 0$; local max $f(2) = \dfrac{4}{e^2}$

Example 2

Does $f(x) = x + \cos x$ have a local extremum at $x = \dfrac{\pi}{2}$?

Show solution
  1. $f'(x) = 1 - \sin x$, and $f'\left(\dfrac{\pi}{2}\right) = 0$.
  2. But $1 - \sin x \ge 0$ on both sides, so there is no sign change: $f$ keeps increasing.

No: $f'(\frac{\pi}{2}) = 0$, yet it is not an extremum

Example 3

$f(x) = x^3 + ax^2 + bx$ has a local maximum $4$ at $x = -1$. Find $a$ and $b$.

Show solution
  1. Necessary: $f'(-1) = 3 - 2a + b = 0$ and $f(-1) = -1 + a - b = 4$. Solving: $a = -2$, $b = -7$.
  2. Check it really is a maximum: $f'(x) = 3x^2 - 4x - 7 = (x + 1)(3x - 7)$ changes from $+$ to $-$ at $x = -1$ ✓.

$a = -2$, $b = -7$

Example 4

For which $a$ does $f(x) = x^3 + ax^2 + 3x$ have local extrema?

Show solution
  1. Extrema need $f'(x) = 3x^2 + 2ax + 3$ to change sign, i.e. two different real roots.
  2. $\dfrac{D}{4} = a^2 - 9 > 0$

$a < -3$ or $a > 3$

$f'(a) = 0$ is necessary, not sufficient. When you find unknowns from $f'(a) = 0$ (Example 3), always check afterwards that $f'$ really changes sign.
For a cubic, $f'$ is a quadratic. Extrema exist $\iff$ $f'$ has two different real roots $\iff D > 0$. If $D \le 0$, the cubic only goes one way.
  • Local extremum (where differentiable) $\Rightarrow f'(a) = 0$; the converse is false.
  • Decide with the sign change of $f'$: $+ \to -$ max, $- \to +$ min.
  • After solving for unknowns, check the sign change.
