Limit of rⁿ

Multiply by $r$ again and again

Each step multiplies by $r$. If $|r| < 1$ every step shrinks the size, so the terms fade to $0$. If $r > 1$ every step grows them. If $r$ is negative the sign flips each step, so for $r \le -1$ the terms jump between positive and negative and never settle.

Behaviour of $\{r^n\}$ as $n \to \infty$

$$r > 1: \; r^n \to \infty \qquad r = 1: \; r^n \to 1 \qquad |r| < 1: \; r^n \to 0 \qquad r \le -1: \text{ oscillates}$$

So $\{r^n\}$ converges exactly when $-1 < r \le 1$.

  1. $r > 1$: write $r = 1 + h$ with $h > 0$. By the binomial theorem $(1 + h)^n \ge 1 + nh$, and $1 + nh \to \infty$.
  2. $0 < |r| < 1$: $\dfrac{1}{|r|} > 1$, so $\left(\dfrac{1}{|r|}\right)^n \to \infty$ and $|r^n| = |r|^n \to 0$. (For $r = 0$ every term is $0$.)
  3. $r = -1$: $-1, 1, -1, 1, \dots$. $\;r < -1$: the size $|r|^n \to \infty$ while the sign keeps flipping.

Dots $(n, r^n)$ for $n = 1, 2, \dots, 20$

Example 1

Find $\displaystyle\lim_{n \to \infty} \left(-\frac{4}{5}\right)^n$ and $\displaystyle\lim_{n \to \infty} \left(\frac{3}{2}\right)^n$.

Show solution
  1. $\left|-\dfrac{4}{5}\right| < 1$, so the first goes to $0$, even though the signs alternate.
  2. $\dfrac{3}{2} > 1$, so the second goes to $\infty$.

$0$ and $\infty$

Example 2

Find $\displaystyle\lim_{n \to \infty} \frac{3^n - 2^n}{3^n + 2^n}$.

Show solution
  1. Divide top and bottom by the biggest base, $3^n$: $\dfrac{1 - \left(\frac{2}{3}\right)^n}{1 + \left(\frac{2}{3}\right)^n}$.
  2. $\left(\dfrac{2}{3}\right)^n \to 0$.

$1$

Example 3

For which $x$ does the sequence $\{(2x - 1)^n\}$ converge? Give the limit.

Show solution
  1. It converges exactly when $-1 < 2x - 1 \le 1$, i.e. $0 < x \le 1$.
  2. For $0 < x < 1$ the ratio has size less than $1$, so the limit is $0$. For $x = 1$ the ratio is $1$, so the limit is $1$.

$0 < x \le 1$; limit $0$ (if $0 < x < 1$) or $1$ (if $x = 1$)

Example 4

Find $\displaystyle\lim_{n \to \infty} \frac{r^n}{1 + r^n}$ for $r > 0$.

Show solution
  1. $0 < r < 1$: $r^n \to 0$, so the limit is $\dfrac{0}{1} = 0$.
  2. $r = 1$: every term is $\dfrac{1}{2}$.
  3. $r > 1$: divide by $r^n$ to get $\dfrac{1}{\left(\frac{1}{r}\right)^n + 1} \to \dfrac{1}{0 + 1} = 1$.

$0$ ($0 < r < 1$), $\;\dfrac{1}{2}$ ($r = 1$), $\;1$ ($r > 1$)

Don't lump the boundary cases together. $r = 1$ converges (to $1$), but $r = -1$ oscillates. That is why the condition is $-1 < r \le 1$, not $|r| \le 1$.
When $r$ is a letter, split into the cases $|r| < 1$, $r = 1$, $|r| > 1$ (and $r = -1$ if needed). In the $|r| > 1$ case, divide by $r^n$ so that only $\left(\frac{1}{r}\right)^n \to 0$ is left.
  • $|r| < 1 \Rightarrow r^n \to 0$; $\;r = 1 \Rightarrow 1$; $\;r > 1 \Rightarrow \infty$; $\;r \le -1 \Rightarrow$ oscillates.
  • Converges $\iff -1 < r \le 1$.
  • With several powers, divide by the one with the biggest base.
