Intermediate Value Theorem

An unbroken curve can't skip a height

A function is continuous at $a$ when $\displaystyle\lim_{x \to a} f(x) = f(a)$, so its graph has no break there. If the graph of $f$ on $[a, b]$ is one unbroken curve, it goes from height $f(a)$ to height $f(b)$ without lifting the pen. So it must cross every height in between at least once.

Intermediate value theorem

$$f \text{ continuous on } [a, b],\; f(a) \ne f(b),\; k \text{ between } f(a) \text{ and } f(b) \implies f(c) = k \text{ for some } a < c < b$$

For equations

$$f \text{ continuous on } [a, b],\; f(a)f(b) < 0 \implies f(x) = 0 \text{ has a solution in } a < x < b$$

Polynomials, $\sin x$, $\cos x$, $e^x$, $\log x$ and their sums, products and compositions are continuous wherever they are defined.

  1. Name the function and say it is continuous on the closed interval.
  2. Work out $f(a)$ and $f(b)$ and show they have opposite signs (or that $k$ lies between them).
  3. Conclude with the theorem: there is at least one $c$ with $a < c < b$.

Every height $k$ between $f(a)$ and $f(b)$ is reached

Example 1

Show that $x^3 + x - 1 = 0$ has a solution in $0 < x < 1$.

Show solution
  1. $f(x) = x^3 + x - 1$ is a polynomial, so it is continuous on $[0, 1]$.
  2. $f(0) = -1 < 0$, $f(1) = 1 > 0$.

By the theorem there is a solution in $0 < x < 1$

Example 2

Show that $x = \cos x$ has a solution in $0 < x < \dfrac{\pi}{2}$.

Show solution
  1. Bring everything to one side: $f(x) = x - \cos x$, continuous on $\left[0, \dfrac{\pi}{2}\right]$.
  2. $f(0) = -1 < 0$, $f\left(\dfrac{\pi}{2}\right) = \dfrac{\pi}{2} > 0$.

There is a solution in $0 < x < \dfrac{\pi}{2}$

Example 3

Show that $e^x = x + 2$ has a solution in $0 < x < 2$.

Show solution
  1. $f(x) = e^x - x - 2$ is continuous on $[0, 2]$.
  2. $f(0) = 1 - 2 = -1 < 0$, $f(2) = e^2 - 4 > 0$ (since $e > 2$ gives $e^2 > 4$).

There is a solution in $0 < x < 2$

Example 4

$f(x) = \dfrac{1}{x}$ has $f(-1) = -1 < 0$ and $f(1) = 1 > 0$. Why is there no solution of $\dfrac{1}{x} = 0$ in $-1 < x < 1$?

Show solution
  1. $\dfrac{1}{x}$ is not defined at $x = 0$, so it is not continuous on $[-1, 1]$.
  2. The graph jumps from $-\infty$ to $+\infty$ at $x = 0$ without crossing the $x$-axis, so the theorem does not apply.

Continuity on the whole interval fails, so the theorem can't be used

The theorem says "at least one" solution. There may be several (try $x^3 - 3x + 1$ with $k = 1$ in the demo). And $f(a)f(b) > 0$ does not mean there is no solution: $x^2 - x$ has $f(-1)f(2) > 0$ but roots $0$ and $1$ inside.
To trap a solution more tightly, check the sign at the midpoint and keep the half where the sign still changes. Each step halves the interval.
  • Continuous on $[a, b]$ + $k$ between $f(a)$ and $f(b)$ $\Rightarrow$ $f(c) = k$ for some $a < c < b$.
  • For equations: $f(a)f(b) < 0 \Rightarrow$ a root in $a < x < b$.
  • Always state continuity; it guarantees existence only, not the number of solutions.
