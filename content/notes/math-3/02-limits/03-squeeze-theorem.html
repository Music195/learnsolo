Properties of Limits of Sequences 2

Inequalities survive the limit

If one sequence is always below another, its limit can't end up above the other's limit.

The most useful version is the squeeze theorem (はさみうちの原理). If $c_n$ is trapped between two sequences that head for the same number $\alpha$, then $c_n$ has nowhere else to go.

Order

$$a_n \le b_n \text{ for all } n, \;\; a_n \to \alpha, \;\; b_n \to \beta \implies \alpha \le \beta$$

Squeeze theorem

$$a_n \le c_n \le b_n \text{ for all } n, \;\; \lim a_n = \lim b_n = \alpha \implies \lim c_n = \alpha$$

Divergence version: if $a_n \le c_n$ and $a_n \to \infty$, then $c_n \to \infty$.

  1. $\sin n$ jumps around with no limit, but it always stays between $-1$ and $1$.
  2. Divide by $n > 0$: $-\dfrac{1}{n} \le \dfrac{\sin n}{n} \le \dfrac{1}{n}$.
  3. Both outer sequences go to $0$, so the squeeze theorem gives $\dfrac{\sin n}{n} \to 0$.

A sequence squeezed between two bounds

Example 1

Find $\displaystyle\lim_{n \to \infty} \frac{\cos n}{n^2}$.

Show solution
  1. $-1 \le \cos n \le 1$, so $-\dfrac{1}{n^2} \le \dfrac{\cos n}{n^2} \le \dfrac{1}{n^2}$.
  2. Both bounds go to $0$.

$0$

Example 2

If $\dfrac{n}{n + 1} \le a_n \le 1$ for all $n$, find $\lim a_n$.

Show solution
  1. $\dfrac{n}{n + 1} = \dfrac{1}{1 + \frac{1}{n}} \to 1$, and the constant sequence $1$ also has limit $1$.
  2. Squeeze theorem.

$1$

Example 3

Find $\displaystyle\lim_{n \to \infty} \frac{1}{n}\sin\frac{n\pi}{3}$.

Show solution
  1. $\left|\sin\dfrac{n\pi}{3}\right| \le 1$, so $\left|\dfrac{1}{n}\sin\dfrac{n\pi}{3}\right| \le \dfrac{1}{n}$.
  2. That is $-\dfrac{1}{n} \le \dfrac{1}{n}\sin\dfrac{n\pi}{3} \le \dfrac{1}{n}$, and both bounds go to $0$.

$0$

Example 4

Show that $c_n = n + \sin n$ diverges to $\infty$.

Show solution
  1. $\sin n \ge -1$, so $c_n \ge n - 1$.
  2. $n - 1 \to \infty$, and $c_n$ is always at least that big.

$c_n \to \infty$

A strict inequality can turn into equality in the limit. $\dfrac{1}{n^2} < \dfrac{1}{n}$ for $n \ge 2$, yet both limits are $0$. So from $a_n < b_n$ you may only conclude $\alpha \le \beta$.
Reach for the squeeze theorem when a bounded but jumpy factor ($\sin$, $\cos$, $(-1)^n$) is multiplied by something that goes to $0$.
  • $a_n \le b_n$ gives $\lim a_n \le \lim b_n$.
  • Squeeze: $a_n \le c_n \le b_n$ with equal outer limits pins down $\lim c_n$.
  • To show $c_n \to \infty$, find a smaller sequence that goes to $\infty$.
