Derivatives of Logarithmic and Exponential Functions

The base $e$ makes the slope equal the height

For $y = a^x$, the slope at every point is the height times a fixed number that depends only on $a$. For $a = 2$ that number is about $0.69$; for $a = 3$, about $1.10$. Somewhere in between it is exactly $1$, and that base is $e = 2.71828\ldots$. For $y = e^x$ the slope equals the height.

In Mathematics III, $\log x$ with no base means the natural logarithm $\log_e x$ (also written $\ln x$).

The number $e$

$$e = \lim_{h \to 0} (1 + h)^{\frac{1}{h}} = 2.71828\ldots$$

Derivatives

$$(\log x)' = \frac{1}{x}, \qquad (\log |x|)' = \frac{1}{x}, \qquad (\log_a x)' = \frac{1}{x\log a}$$
$$(e^x)' = e^x, \qquad (a^x)' = a^x\log a$$

$a > 0$, $a \ne 1$. With an inside function: $\{\log|f(x)|\}' = \dfrac{f'(x)}{f(x)}$, $\;\{e^{f(x)}\}' = e^{f(x)}f'(x)$.

  1. $\dfrac{\log(x + h) - \log x}{h} = \dfrac{1}{h}\log\left(1 + \dfrac{h}{x}\right) = \dfrac{1}{x}\log\left(1 + \dfrac{h}{x}\right)^{\frac{x}{h}}$. Put $k = \dfrac{h}{x} \to 0$: this is $\dfrac{1}{x}\log(1 + k)^{\frac{1}{k}} \to \dfrac{1}{x}\log e = \dfrac{1}{x}$.
  2. For $x < 0$: $\log|x| = \log(-x)$, and the chain rule gives $\dfrac{-1}{-x} = \dfrac{1}{x}$.
  3. $y = e^x \iff x = \log y$, so $\dfrac{dx}{dy} = \dfrac{1}{y}$ and $\dfrac{dy}{dx} = y = e^x$ (inverse function rule).
  4. $a^x = e^{x\log a}$, so $(a^x)' = e^{x\log a} \cdot \log a = a^x\log a$. Similarly $\log_a x = \dfrac{\log x}{\log a}$.

For $y = a^x$, slope ÷ height is the same everywhere

Example 1

Differentiate $y = e^{2x}$ and $y = 2^x$.

Show solution
  1. $(e^{2x})' = e^{2x} \cdot 2$
  2. $(2^x)' = 2^x\log 2$

$2e^{2x}$ and $2^x\log 2$

Example 2

Differentiate $y = \log(x^2 + 1)$ and $y = \log|\cos x|$.

Show solution
  1. $\dfrac{(x^2 + 1)'}{x^2 + 1} = \dfrac{2x}{x^2 + 1}$
  2. $\dfrac{(\cos x)'}{\cos x} = \dfrac{-\sin x}{\cos x}$

$\dfrac{2x}{x^2 + 1}$ and $-\tan x$

Example 3

Differentiate $y = x^2e^{-x}$.

Show solution
  1. Product rule: $y' = 2xe^{-x} + x^2 \cdot (-e^{-x})$

$y' = x(2 - x)e^{-x}$

Example 4

Differentiate $y = x^x$ ($x > 0$) by taking logarithms (対数微分法).

Show solution
  1. Both sides are positive: $\log y = x\log x$.
  2. Differentiate with respect to $x$: $\dfrac{y'}{y} = \log x + x \cdot \dfrac{1}{x} = \log x + 1$.

$y' = x^x(\log x + 1)$

Example 5

Show that $(x^p)' = px^{p-1}$ for every real $p$ ($x > 0$).

Show solution
  1. $y = x^p$, so $\log y = p\log x$.
  2. $\dfrac{y'}{y} = \dfrac{p}{x}$, so $y' = x^p \cdot \dfrac{p}{x}$.

$y' = px^{p-1}$ ✓

$(2^x)' = 2^x\log 2$ (variable in the exponent), but $(x^2)' = 2x$ (variable in the base). Don't mix them up. Also, $e^x$ is not the only function equal to its own derivative: $Ce^x$ is too, for any constant $C$.
For $x^x$, or a big product or quotient of powers, take $\log$ of both sides first. Products become sums and powers come down as factors, which makes differentiating much easier.
  • $(\log|x|)' = \dfrac{1}{x}$, $\;(\log|f|)' = \dfrac{f'}{f}$.
  • $(e^x)' = e^x$, $\;(a^x)' = a^x\log a$.
  • Variable in both base and exponent: take logs, then differentiate.
