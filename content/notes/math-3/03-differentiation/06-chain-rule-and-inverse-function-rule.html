Chain Rule and Inverse Function Rule for Derivatives

Rates multiply along a chain

In $y = (x^2 - 1)^2$ there is an inner function $u = x^2 - 1$ and an outer function $y = u^2$. Suppose $u$ changes $\dfrac{du}{dx}$ times as fast as $x$, and $y$ changes $\dfrac{dy}{du}$ times as fast as $u$. Then $y$ changes $\dfrac{dy}{du} \cdot \dfrac{du}{dx}$ times as fast as $x$.

For an inverse function the roles of $x$ and $y$ swap, so the rate becomes its reciprocal.

Chain rule (合成関数の微分法)

$$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}, \qquad \{f(g(x))\}' = f'(g(x))\,g'(x)$$

Most used case: $\{(g(x))^n\}' = n(g(x))^{n-1}g'(x)$.

Inverse function rule (逆関数の微分法)

$$\frac{dy}{dx} = \frac{1}{\dfrac{dx}{dy}} \qquad \left(\frac{dx}{dy} \ne 0\right)$$

Use it when $x$ is easy to write in terms of $y$, e.g. $y = \sqrt[3]{x} \iff x = y^3$.

  1. Let $x$ change by $\Delta x$; then $u$ changes by $\Delta u$ and $y$ by $\Delta y$. If $\Delta u \ne 0$: $\dfrac{\Delta y}{\Delta x} = \dfrac{\Delta y}{\Delta u} \cdot \dfrac{\Delta u}{\Delta x}$.
  2. As $\Delta x \to 0$, $\Delta u \to 0$ too ($u$ is continuous), so the two fractions tend to $\dfrac{dy}{du}$ and $\dfrac{du}{dx}$.
  3. Inverse: $\dfrac{\Delta y}{\Delta x} = 1 \Big/ \dfrac{\Delta x}{\Delta y}$, and let $\Delta y \to 0$.

$\dfrac{dy}{dx} = \dfrac{dy}{du} \cdot \dfrac{du}{dx}$ at a point

Example 1

Differentiate $y = (x^2 + 3x + 1)^5$.

Show solution
  1. $u = x^2 + 3x + 1$, $y = u^5$: $\dfrac{dy}{du} = 5u^4$, $\dfrac{du}{dx} = 2x + 3$.

$y' = 5(x^2 + 3x + 1)^4(2x + 3)$

Example 2

Differentiate $y = \dfrac{1}{(2x - 1)^3}$.

Show solution
  1. $y = (2x - 1)^{-3}$, so $y' = -3(2x - 1)^{-4} \cdot 2$.

$y' = -\dfrac{6}{(2x - 1)^4}$

Example 3

Use the inverse function rule to differentiate $y = \sqrt[3]{x}$ ($x \ne 0$).

Show solution
  1. $x = y^3$, so $\dfrac{dx}{dy} = 3y^2$.
  2. $\dfrac{dy}{dx} = \dfrac{1}{3y^2} = \dfrac{1}{3\left(\sqrt[3]{x}\right)^2}$

$y' = \dfrac{1}{3\sqrt[3]{x^2}}$

Example 4

On the circle $x^2 + y^2 = 25$, find $\dfrac{dy}{dx}$ and the slope of the tangent at $(3, 4)$.

Show solution
  1. Differentiate both sides with respect to $x$. Since $y$ depends on $x$, the chain rule gives $(y^2)' = 2y\dfrac{dy}{dx}$.
  2. $2x + 2y\dfrac{dy}{dx} = 0$, so $\dfrac{dy}{dx} = -\dfrac{x}{y}$ ($y \ne 0$).

$\dfrac{dy}{dx} = -\dfrac{x}{y}$; slope $-\dfrac{3}{4}$ at $(3, 4)$

The most common slip is dropping the inner derivative: $\{(2x - 1)^3\}' = 3(2x - 1)^2 \cdot 2$, not $3(2x - 1)^2$.
Work from the outside in: differentiate the outer function and leave the inside unchanged, then multiply by the derivative of the inside. Repeat if the inside is itself a composite.
  • $\{f(g(x))\}' = f'(g(x))g'(x)$; $\;\dfrac{dy}{dx} = \dfrac{dy}{du}\dfrac{du}{dx}$.
  • $\dfrac{dy}{dx} = 1 \Big/ \dfrac{dx}{dy}$.
  • Equations in $x$ and $y$: differentiate both sides, treating $y$ as a function of $x$.
