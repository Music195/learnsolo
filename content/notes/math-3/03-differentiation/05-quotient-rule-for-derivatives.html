Quotient Rule for Derivatives

Differentiating a fraction

Start with the reciprocal: if $g$ grows, $\dfrac{1}{g}$ shrinks, and the rate is $-\dfrac{g'}{g^2}$. A general fraction $\dfrac{f}{g}$ is $f \cdot \dfrac{1}{g}$, so the product rule then gives the quotient rule.

Reciprocal and quotient

$$\left\{\frac{1}{g(x)}\right\}' = -\frac{g'(x)}{\{g(x)\}^2}, \qquad \left\{\frac{f(x)}{g(x)}\right\}' = \frac{f'(x)g(x) - f(x)g'(x)}{\{g(x)\}^2}$$

Short form: $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$. Consequence: $(x^n)' = nx^{n-1}$ also holds for negative integers $n$.

  1. $\dfrac{1}{h}\left\{\dfrac{1}{g(x + h)} - \dfrac{1}{g(x)}\right\} = -\dfrac{g(x + h) - g(x)}{h} \cdot \dfrac{1}{g(x + h)g(x)} \to -\dfrac{g'(x)}{\{g(x)\}^2}$.
  2. $\dfrac{f}{g} = f \cdot \dfrac{1}{g}$, so by the product rule $\left(\dfrac{f}{g}\right)' = \dfrac{f'}{g} + f \cdot \left(-\dfrac{g'}{g^2}\right) = \dfrac{f'g - fg'}{g^2}$.
  3. For $n = -m$ ($m$ a positive integer): $\left(\dfrac{1}{x^m}\right)' = -\dfrac{mx^{m-1}}{x^{2m}} = -mx^{-m-1} = nx^{n-1}$.

The quotient rule gives the tangent slope

Example 1

Differentiate $y = \dfrac{1}{x^2 + 1}$.

Show solution
  1. Reciprocal rule with $g = x^2 + 1$, $g' = 2x$.

$y' = -\dfrac{2x}{(x^2 + 1)^2}$

Example 2

Differentiate $y = \dfrac{x^2 + 1}{x - 1}$.

Show solution
  1. $y' = \dfrac{2x(x - 1) - (x^2 + 1) \cdot 1}{(x - 1)^2}$
  2. $= \dfrac{2x^2 - 2x - x^2 - 1}{(x - 1)^2}$

$y' = \dfrac{x^2 - 2x - 1}{(x - 1)^2}$

Example 3

Differentiate $y = \tan x$ (using $(\sin x)' = \cos x$, $(\cos x)' = -\sin x$ from note 08).

Show solution
  1. $\tan x = \dfrac{\sin x}{\cos x}$, so $y' = \dfrac{\cos x \cdot \cos x - \sin x \cdot (-\sin x)}{\cos^2 x}$.
  2. $= \dfrac{\cos^2 x + \sin^2 x}{\cos^2 x}$

$y' = \dfrac{1}{\cos^2 x}$

Example 4

Differentiate $y = \dfrac{3}{x^4}$.

Show solution
  1. $y = 3x^{-4}$, and $(x^n)' = nx^{n-1}$ holds for $n = -4$.
  2. $y' = 3 \cdot (-4)x^{-5}$

$y' = -\dfrac{12}{x^5}$

The top is $f'g - fg'$. It starts with the derivative of the numerator, and the order matters because of the minus sign. Also, $\left(\dfrac{f}{g}\right)' \ne \dfrac{f'}{g'}$.
A constant on top or a single power below? Use the reciprocal rule or a negative power instead: $\dfrac{3}{x^4} = 3x^{-4}$. Dividing out first also helps: $\dfrac{x^2 + 1}{x} = x + \dfrac{1}{x}$.
  • $\left(\dfrac{1}{g}\right)' = -\dfrac{g'}{g^2}$; $\;\left(\dfrac{f}{g}\right)' = \dfrac{f'g - fg'}{g^2}$.
  • $(x^n)' = nx^{n-1}$ for every integer $n$.
  • $(\tan x)' = \dfrac{1}{\cos^2 x}$.
