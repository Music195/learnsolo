Derivative Notation

Several names for one idea, and differentiating again

The derivative of $y = f(x)$ can be written in several ways that all mean the same thing. The prime style $f'(x)$ is short. The $d$ style $\dfrac{dy}{dx}$ shows which variable you differentiate with respect to.

Since $f'(x)$ is itself a function, you can differentiate it again. That gives the second derivative $f''(x)$, the slope of the slope. Repeating gives the third, and then the $n$-th derivative.

The examples use the differentiation rules from notes 04–09.

First derivative

$$y' = f'(x) = \frac{dy}{dx} = \frac{d}{dx}f(x)$$

Higher derivatives

$$y'' = f''(x) = \frac{d^2y}{dx^2}, \qquad y''' = f'''(x) = \frac{d^3y}{dx^3}, \qquad y^{(n)} = f^{(n)}(x) = \frac{d^ny}{dx^n}$$

From the 4th derivative on, write $y^{(4)}$, $y^{(5)}$, … (brackets, so they don't look like powers). If $t$ is the variable, write $\dfrac{dx}{dt}$, $\dfrac{d^2x}{dt^2}$, and so on.

  1. $y = \sin x$: $y' = \cos x$, $y'' = -\sin x$, $y''' = -\cos x$, $y^{(4)} = \sin x$, so the cycle repeats every 4 steps.
  2. Each step shifts the graph left by $\dfrac{\pi}{2}$: $\cos x = \sin\left(x + \dfrac{\pi}{2}\right)$.
  3. So $y^{(n)} = \sin\left(x + \dfrac{n\pi}{2}\right)$.

$f$ (blue), $f'$ (orange), $f''$ (teal)

Example 1

$y = x^4 - 2x^3$. Find $y'$, $y''$, $y'''$, $y^{(4)}$ and $y^{(5)}$.

Show solution
  1. $y' = 4x^3 - 6x^2$, $\;y'' = 12x^2 - 12x$, $\;y''' = 24x - 12$
  2. $y^{(4)} = 24$, and the derivative of a constant is $0$.

$y^{(4)} = 24$, $y^{(5)} = 0$

Example 2

$y = e^{2x}$. Find $y^{(n)}$.

Show solution
  1. $y' = 2e^{2x}$, $y'' = 2^2e^{2x}$, $y''' = 2^3e^{2x}$: each step multiplies by $2$.

$y^{(n)} = 2^ne^{2x}$

Example 3

Show that $y = \sin 3x$ satisfies $y'' + 9y = 0$.

Show solution
  1. $y' = 3\cos 3x$, $\;y'' = -9\sin 3x$.
  2. $y'' + 9y = -9\sin 3x + 9\sin 3x = 0$.

$y'' + 9y = 0$ ✓

$y^{(4)}$ is the 4th derivative; $y^4$ is $y$ to the power 4. And $\dfrac{d^2y}{dx^2}$ is not $\left(\dfrac{dy}{dx}\right)^2$.
For $y^{(n)}$, differentiate three or four times, spot the pattern, then write the general form (and prove it by induction if the question asks).
  • $y' = f'(x) = \dfrac{dy}{dx}$; $\;y'' = \dfrac{d^2y}{dx^2}$; $\;y^{(n)} = \dfrac{d^ny}{dx^n}$.
  • $f''$ is the slope of $f'$.
  • $(\sin x)^{(n)} = \sin\left(x + \frac{n\pi}{2}\right)$, $\;(e^{kx})^{(n)} = k^ne^{kx}$.
