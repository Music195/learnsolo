Properties of Derivatives

Sums split up; products need a rule

Differentiation works term by term: constants come out, and sums and differences split.

A product is different. If both factors change, the product changes in two ways at once. Think of a rectangle with sides $u$ and $v$: when both sides grow, the area gains a strip $v\,\Delta u$ on one side and a strip $u\,\Delta v$ on the other.

Constant multiple, sum and difference

$$\{kf(x) + lg(x)\}' = kf'(x) + lg'(x)$$

Product rule

$$\{f(x)g(x)\}' = f'(x)g(x) + f(x)g'(x)$$

Short form: $(uv)' = u'v + uv'$. Three factors: $(uvw)' = u'vw + uv'w + uvw'$.

  1. Add and subtract $f(x)g(x + h)$: $f(x + h)g(x + h) - f(x)g(x) = \{f(x + h) - f(x)\}g(x + h) + f(x)\{g(x + h) - g(x)\}$.
  2. Divide by $h$: $\dfrac{f(x + h) - f(x)}{h} \cdot g(x + h) + f(x) \cdot \dfrac{g(x + h) - g(x)}{h}$.
  3. As $h \to 0$: the fractions tend to $f'(x)$ and $g'(x)$, and $g(x + h) \to g(x)$ (differentiable functions are continuous). So the limit is $f'(x)g(x) + f(x)g'(x)$.

Rectangle $u \times v$ with $u = x + 1$, $v = \dfrac{x^2}{4} + 1$

Example 1

Differentiate $y = (x^2 + 1)(2x - 3)$.

Show solution
  1. $y' = (x^2 + 1)'(2x - 3) + (x^2 + 1)(2x - 3)' = 2x(2x - 3) + 2(x^2 + 1)$
  2. $= 4x^2 - 6x + 2x^2 + 2$

$y' = 6x^2 - 6x + 2$

Example 2

Differentiate $y = (x + 1)(x + 2)(x + 3)$.

Show solution
  1. Three factors: $y' = (x + 2)(x + 3) + (x + 1)(x + 3) + (x + 1)(x + 2)$.
  2. $= (x^2 + 5x + 6) + (x^2 + 4x + 3) + (x^2 + 3x + 2)$

$y' = 3x^2 + 12x + 11$

Example 3

$f(x) = (x - a)^2g(x)$ with $g$ differentiable. Show that $f'(a) = 0$.

Show solution
  1. $f'(x) = 2(x - a)g(x) + (x - a)^2g'(x)$. (For $(x - a)^2$, expand to $x^2 - 2ax + a^2$ and differentiate.)
  2. Both terms contain $(x - a)$, so $f'(a) = 0$.

$f'(a) = 0$: a double root of $f$ is also a root of $f'$

$(uv)' \ne u'v'$. For example $(x \cdot x)' = 2x$, but $(x)'(x)' = 1$.
For small polynomials, expanding first and the product rule give the same answer, so pick whichever is quicker. When a factor is not a polynomial ($\sqrt{x}$, $\sin x$, …), use the product rule.
  • $(kf + lg)' = kf' + lg'$.
  • $(uv)' = u'v + uv'$; $\;(uvw)' = u'vw + uv'w + uvw'$.
  • Proof: add and subtract a middle term, then use continuity.
