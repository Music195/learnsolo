Definite Integral and Derivative

A moving upper limit makes a function

If the upper limit is the variable $x$, then $S(x) = \displaystyle\int_a^x f(t)\,dt$ is a function of $x$: the area accumulated so far. Moving $x$ a little adds a thin strip of height $f(x)$, so the area grows at rate $f(x)$.

So differentiating "undoes" the integral, and you don't need to find an antiderivative first. Also, an integral with fixed limits, like $\displaystyle\int_0^1 f(t)\,dt$, is just a constant.

$a$: a constant

$$\frac{d}{dx}\int_a^x f(t)\,dt = f(x), \qquad \frac{d}{dx}\int_{h(x)}^{g(x)} f(t)\,dt = f(g(x))\,g'(x) - f(h(x))\,h'(x)$$

Inside the integral the variable is $t$, so $x$ outside it is a constant there: $\displaystyle\int_a^x x f(t)\,dt = x\int_a^x f(t)\,dt$.

  1. Let $F' = f$. Then $\displaystyle\int_a^x f(t)\,dt = F(x) - F(a)$.
  2. $F(a)$ is a constant, so the derivative is $F'(x) = f(x)$.
  3. With limits $h(x)$ to $g(x)$: the integral is $F(g(x)) - F(h(x))$. By the chain rule its derivative is $f(g(x))g'(x) - f(h(x))h'(x)$.

Area so far $S(x)$ (orange) climbs at rate $f(x)$ (blue)

Example 1

Find $\dfrac{d}{dx}\displaystyle\int_1^x \frac{\sin t}{t}\,dt$ and $\dfrac{d}{dx}\displaystyle\int_0^{x^2} e^{t^2}\,dt$.

Show solution
  1. First: replace $t$ by $x$, giving $\dfrac{\sin x}{x}$.
  2. Second: upper limit $x^2$, so $e^{(x^2)^2} \cdot 2x$.

$\dfrac{\sin x}{x}$ and $2xe^{x^4}$

Example 2

Find the function $f(x)$ and the constant $a$ such that $\displaystyle\int_a^x f(t)\,dt = x^2 - 3x + 2$.

Show solution
  1. Differentiate: $f(x) = 2x - 3$.
  2. Put $x = a$: the left side is $0$, so $a^2 - 3a + 2 = 0$ and $a = 1, 2$.

$f(x) = 2x - 3$; $a = 1$ or $a = 2$

Example 3

Find $f(x)$ such that $f(x) = x + 2\displaystyle\int_0^1 f(t)\,dt$.

Show solution
  1. The integral is a constant. Call it $k$, so $f(x) = x + 2k$.
  2. $k = \displaystyle\int_0^1 (t + 2k)\,dt = \frac{1}{2} + 2k$, so $k = -\dfrac{1}{2}$.

$f(x) = x - 1$ (check: $\int_0^1 (t - 1)\,dt = -\frac{1}{2} = k$)

Example 4

Find the minimum value of $S(x) = \displaystyle\int_0^x (t^2 - 4)\,dt$ for $x \ge 0$.

Show solution
  1. $S'(x) = x^2 - 4$, which is $0$ at $x = 2$. $S$ decreases on $[0, 2]$ and increases after.
  2. $S(2) = \Big[\dfrac{t^3}{3} - 4t\Big]_0^2 = \dfrac{8}{3} - 8$

Minimum $-\dfrac{16}{3}$ at $x = 2$

If $x$ appears inside the integrand, as in $\displaystyle\int_0^x (x - t)f(t)\,dt$, take it out first: $x\displaystyle\int_0^x f(t)\,dt - \int_0^x tf(t)\,dt$. Then differentiate, using the product rule on the first part.
In an equation like $\displaystyle\int_a^x f(t)\,dt = g(x)$, do two things: differentiate to find $f$, and put $x = a$ (where the integral is $0$) to find the constant.
  • $\dfrac{d}{dx}\displaystyle\int_a^x f(t)\,dt = f(x)$.
  • A variable limit $g(x)$ adds the factor $g'(x)$ (chain rule).
  • $\displaystyle\int_0^1 f(t)\,dt$ is a constant: name it $k$ and solve for it.
