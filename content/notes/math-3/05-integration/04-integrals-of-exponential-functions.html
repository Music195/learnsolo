Indefinite Integrals of Exponential Functions

$e^x$ is its own antiderivative

Since $(e^x)' = e^x$, integrating $e^x$ gives $e^x$ back. For another base $a$, $(a^x)' = a^x\log a$. So to undo it, divide by the constant $\log a$.

A linear inside, as in $e^{kx + b}$, works the same way: integrate as usual, then divide by the inner slope $k$.

$a > 0$, $a \ne 1$; $k \ne 0$

$$\int e^x\,dx = e^x + C, \qquad \int a^x\,dx = \frac{a^x}{\log a} + C, \qquad \int e^{kx}\,dx = \frac{e^{kx}}{k} + C$$

$\log$ is the natural logarithm (base $e$), also written $\ln$.

  1. $\left(\dfrac{a^x}{\log a}\right)' = \dfrac{a^x\log a}{\log a} = a^x$.
  2. $\left(\dfrac{e^{kx}}{k}\right)' = \dfrac{k e^{kx}}{k} = e^{kx}$ (chain rule).
  3. In general, if $F' = f$, then $\displaystyle\int f(kx + b)\,dx = \frac{1}{k}F(kx + b) + C$.

For $a > 1$, the shaded area to the left of $x$ equals $\dfrac{a^x}{\log a}$

Example 1

Find $\displaystyle\int (2e^x - 3^x)\,dx$.

Show solution
  1. $2e^x - \dfrac{3^x}{\log 3} + C$

$2e^x - \dfrac{3^x}{\log 3} + C$

Example 2

Find $\displaystyle\int e^{3x - 1}\,dx$ and $\displaystyle\int e^{-x}\,dx$.

Show solution
  1. Inner slope $3$: $\dfrac{e^{3x - 1}}{3} + C$.
  2. Inner slope $-1$: $\dfrac{e^{-x}}{-1} + C$.

$\dfrac{1}{3}e^{3x - 1} + C$ and $-e^{-x} + C$

Example 3

Find $\displaystyle\int (e^x + e^{-x})^2\,dx$.

Show solution
  1. Expand: $e^{2x} + 2 + e^{-2x}$.
  2. $\dfrac{e^{2x}}{2} + 2x - \dfrac{e^{-2x}}{2} + C$

$\dfrac{1}{2}(e^{2x} - e^{-2x}) + 2x + C$

Example 4

Find $\displaystyle\int \frac{e^{2x} - 1}{e^x}\,dx$.

Show solution
  1. Divide each term: $e^x - e^{-x}$.

$e^x + e^{-x} + C$

$a^x$ is not a power of $x$. $\displaystyle\int 2^x\,dx$ is not $\dfrac{2^{x+1}}{x+1}$: the variable is in the exponent. The power rule is only for $x^\alpha$ with a fixed exponent.
$\dfrac{1}{k}$ is the only adjustment needed when the inside is $kx + b$. It undoes the factor $k$ that the chain rule would produce.
  • $\displaystyle\int e^x\,dx = e^x + C$.
  • $\displaystyle\int a^x\,dx = \frac{a^x}{\log a} + C$.
  • $\displaystyle\int f(kx + b)\,dx = \frac{1}{k}F(kx + b) + C$.
