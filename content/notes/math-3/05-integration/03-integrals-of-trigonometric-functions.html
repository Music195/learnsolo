Indefinite Integrals of Trigonometric Functions

Read the derivative table backwards

Each trig derivative gives an integral: $(\sin x)' = \cos x$, $(\cos x)' = -\sin x$, $(\tan x)' = \dfrac{1}{\cos^2 x}$.

Squares and products such as $\sin^2 x$ or $\sin x\cos x$ are not in the table. Turn them into single sines and cosines first, using the double-angle and product-to-sum formulas (Math II).

Basic integrals ($x$ in radians)

$$\int \sin x\,dx = -\cos x + C, \qquad \int \cos x\,dx = \sin x + C$$
$$\int \frac{1}{\cos^2 x}\,dx = \tan x + C, \qquad \int \frac{1}{\sin^2 x}\,dx = -\frac{1}{\tan x} + C$$

Lowering the power: $\sin^2 x = \dfrac{1 - \cos 2x}{2}$, $\;\cos^2 x = \dfrac{1 + \cos 2x}{2}$, $\;\sin x\cos x = \dfrac{\sin 2x}{2}$.

  1. $(\tan x)' = \left(\dfrac{\sin x}{\cos x}\right)' = \dfrac{\cos^2 x + \sin^2 x}{\cos^2 x} = \dfrac{1}{\cos^2 x}$.
  2. $\left(-\dfrac{1}{\tan x}\right)' = -\left(\dfrac{\cos x}{\sin x}\right)' = -\dfrac{-\sin^2 x - \cos^2 x}{\sin^2 x} = \dfrac{1}{\sin^2 x}$.
  3. For $\cos 2x$: $\left(\dfrac{\sin 2x}{2}\right)' = \cos 2x$. In general $\displaystyle\int \cos kx\,dx = \frac{\sin kx}{k} + C$.

A square of a trig function is a wave around a constant

Example 1

Find $\displaystyle\int (3\sin x - 2\cos x)\,dx$.

Show solution
  1. $3(-\cos x) - 2\sin x + C$

$-3\cos x - 2\sin x + C$

Example 2

Find $\displaystyle\int \tan^2 x\,dx$.

Show solution
  1. $\tan^2 x = \dfrac{\sin^2 x}{\cos^2 x} = \dfrac{1 - \cos^2 x}{\cos^2 x} = \dfrac{1}{\cos^2 x} - 1$.
  2. Integrate each term.

$\tan x - x + C$

Example 3

Find $\displaystyle\int \cos^2 x\,dx$.

Show solution
  1. $\cos^2 x = \dfrac{1 + \cos 2x}{2}$
  2. $\dfrac{x}{2} + \dfrac{1}{2} \cdot \dfrac{\sin 2x}{2} + C$

$\dfrac{x}{2} + \dfrac{\sin 2x}{4} + C$

Example 4

Find $\displaystyle\int \sin 3x \cos x\,dx$.

Show solution
  1. Product to sum: $\sin 3x\cos x = \dfrac{1}{2}(\sin 4x + \sin 2x)$.
  2. $\dfrac{1}{2}\left(-\dfrac{\cos 4x}{4} - \dfrac{\cos 2x}{2}\right) + C$

$-\dfrac{\cos 4x}{8} - \dfrac{\cos 2x}{4} + C$

Watch the signs: $\displaystyle\int \sin x\,dx = -\cos x + C$, not $\cos x$. For $\sin kx$ and $\cos kx$, divide by $k$: $\displaystyle\int \sin 2x\,dx = -\dfrac{\cos 2x}{2} + C$.
Not sure of a sign? Differentiate your answer. For example, $(-\cos x)' = \sin x$ confirms the first formula.
  • $\int \sin x = -\cos x$, $\;\int \cos x = \sin x$, $\;\int \dfrac{1}{\cos^2 x} = \tan x$ (each $+ C$).
  • Squares: lower the power with the double-angle formulas.
  • Products: use the product-to-sum formulas.
