Integration by Parts

The product rule run backwards

Use this for a product of two different kinds of function, such as $x e^x$, $x\sin x$ or $\log x$ (that is, $1 \cdot \log x$).

Integrate one factor and differentiate the other. The goal is a new integral that is easier than the one you started with.

Integration by parts

$$\int f(x)\,g'(x)\,dx = f(x)\,g(x) - \int f'(x)\,g(x)\,dx$$

$f$: the factor to differentiate (it should get simpler). $g'$: the factor to integrate.

  1. Product rule: $\{f(x)g(x)\}' = f'(x)g(x) + f(x)g'(x)$.
  2. Integrate both sides: $f(x)g(x) = \displaystyle\int f'(x)g(x)\,dx + \int f(x)g'(x)\,dx$.
  3. Move one integral across to get the formula.

Area under the curve + area beside it = difference of two rectangles

Example 1

Find $\displaystyle\int x e^x\,dx$.

Show solution
  1. Differentiate $f = x$ ($f' = 1$); integrate $g' = e^x$ ($g = e^x$).
  2. $x e^x - \displaystyle\int 1 \cdot e^x\,dx = x e^x - e^x + C$

$(x - 1)e^x + C$

Example 2

Find $\displaystyle\int \log x\,dx$.

Show solution
  1. Write it as $\displaystyle\int (x)' \log x\,dx$: integrate $1$, differentiate $\log x$.
  2. $x\log x - \displaystyle\int x \cdot \frac{1}{x}\,dx = x\log x - x + C$

$x\log x - x + C$

Example 3

Find $\displaystyle\int x\cos x\,dx$.

Show solution
  1. $f = x$, $g' = \cos x$, $g = \sin x$.
  2. $x\sin x - \displaystyle\int \sin x\,dx = x\sin x + \cos x + C$

$x\sin x + \cos x + C$

Example 4

Find $\displaystyle\int x^2 e^x\,dx$.

Show solution
  1. Once: $x^2 e^x - \displaystyle\int 2x e^x\,dx$.
  2. Use Example 1: $\displaystyle\int 2xe^x\,dx = 2(x - 1)e^x + C$.

$(x^2 - 2x + 2)e^x + C$

Example 5

Find $I = \displaystyle\int e^x \sin x\,dx$.

Show solution
  1. Parts with $g' = e^x$: $I = e^x\sin x - \displaystyle\int e^x\cos x\,dx$.
  2. Parts again: $\displaystyle\int e^x\cos x\,dx = e^x\cos x + \int e^x\sin x\,dx = e^x\cos x + I$.
  3. So $I = e^x\sin x - e^x\cos x - I$, and $2I = e^x(\sin x - \cos x)$.

$\dfrac{1}{2}e^x(\sin x - \cos x) + C$

If the new integral is harder than the old one, you chose the wrong factor to differentiate. For $x e^x$, differentiating $e^x$ instead of $x$ gives $\displaystyle\int \frac{x^2}{2}e^x\,dx$, which is worse.
Differentiate the factor that gets simpler: $\log x$ first, then powers of $x$. Integrate the factor that stays easy: $e^x$, $\sin x$, $\cos x$.
  • $\displaystyle\int f g' = fg - \int f' g$.
  • $\displaystyle\int \log x\,dx = x\log x - x + C$.
  • $x^n \times$(exp or trig): use parts $n$ times. $e^x \times$ trig: use parts twice and solve for $I$.
