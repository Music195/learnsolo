Definite Integral: Substitution Method

Change the variable, and change the limits with it

Substitution works the same way as in note 05, with one extra step: the limits belong to the old variable, so convert them too. Then you never need to go back to $x$; just evaluate in the new variable.

For $\sqrt{a^2 - x^2}$, put $x = a\sin\theta$; for $\dfrac{1}{x^2 + a^2}$, put $x = a\tan\theta$. Both turn the expression into a simple trig one.

$x = g(t)$, with $a = g(\alpha)$ and $b = g(\beta)$

$$\int_a^b f(x)\,dx = \int_\alpha^\beta f(g(t))\,g'(t)\,dt$$

Make a small table of the limits: $x$: $a \to b$ becomes $t$: $\alpha \to \beta$.

  1. Let $F' = f$. By the chain rule, $\{F(g(t))\}' = f(g(t))\,g'(t)$.
  2. So $\displaystyle\int_\alpha^\beta f(g(t))g'(t)\,dt = F(g(\beta)) - F(g(\alpha)) = F(b) - F(a)$.
  3. And $F(b) - F(a) = \displaystyle\int_a^b f(x)\,dx$.

Blue (in $x$, from $0$ to $b$) and orange (in $u$, from $g(0)$ to $g(b)$) have equal area

Example 1

Evaluate $\displaystyle\int_0^1 x(x^2 + 1)^3\,dx$.

Show solution
  1. $u = x^2 + 1$, $du = 2x\,dx$. Limits: $x$: $0 \to 1$ gives $u$: $1 \to 2$.
  2. $\displaystyle\frac{1}{2}\int_1^2 u^3\,du = \frac{1}{2}\Big[\frac{u^4}{4}\Big]_1^2 = \frac{1}{8}(16 - 1)$

$\dfrac{15}{8}$

Example 2

Evaluate $\displaystyle\int_0^1 \sqrt{1 - x^2}\,dx$.

Show solution
  1. $x = \sin\theta$, $dx = \cos\theta\,d\theta$. Limits: $x$: $0 \to 1$ gives $\theta$: $0 \to \dfrac{\pi}{2}$.
  2. On that range $\cos\theta \ge 0$, so $\sqrt{1 - \sin^2\theta} = \cos\theta$.
  3. $\displaystyle\int_0^{\frac{\pi}{2}} \cos^2\theta\,d\theta = \Big[\frac{\theta}{2} + \frac{\sin 2\theta}{4}\Big]_0^{\frac{\pi}{2}} = \frac{\pi}{4}$

$\dfrac{\pi}{4}$ (a quarter of the unit circle's area, as expected)

Example 3

Evaluate $\displaystyle\int_0^1 \frac{1}{x^2 + 1}\,dx$.

Show solution
  1. $x = \tan\theta$, $dx = \dfrac{d\theta}{\cos^2\theta}$. Limits: $\theta$: $0 \to \dfrac{\pi}{4}$.
  2. $\tan^2\theta + 1 = \dfrac{1}{\cos^2\theta}$, so the integrand becomes $\cos^2\theta \cdot \dfrac{1}{\cos^2\theta} = 1$.
  3. $\displaystyle\int_0^{\frac{\pi}{4}} 1\,d\theta$

$\dfrac{\pi}{4}$

Example 4

Evaluate $\displaystyle\int_1^e \frac{(\log x)^2}{x}\,dx$.

Show solution
  1. $u = \log x$, $du = \dfrac{dx}{x}$. Limits: $u$: $0 \to 1$.
  2. $\displaystyle\int_0^1 u^2\,du = \frac{1}{3}$

$\dfrac{1}{3}$

The most common mistake is to change the variable but keep the old limits. If you do switch back to $x$ instead, then use the original limits. Never mix the two.
$\sqrt{a^2 - x^2}$: $x = a\sin\theta$. $\;\dfrac{1}{x^2 + a^2}$: $x = a\tan\theta$. Pick the $\theta$-range so that $\cos\theta \ge 0$; then the square root simplifies without a sign problem.
  • $x = g(t)$: change $dx$ to $g'(t)\,dt$ and the limits to $\alpha$, $\beta$.
  • Then evaluate in $t$; no need to go back to $x$.
  • $\displaystyle\int_0^a \sqrt{a^2 - x^2}\,dx = \frac{\pi a^2}{4}$ (a quarter circle).
