Area Bounded by Curve y = f(x)

Area is never negative

The integral counts parts below the $x$-axis as negative. An area must count every part as positive, so integrate $|f(x)|$ instead.

In practice: find where the curve crosses the axis, split the interval there, and integrate each piece with the sign that makes it positive.

Area between $y = f(x)$ and the $x$-axis, $a \le x \le b$

$$S = \int_a^b |f(x)|\,dx: \qquad f \ge 0 \text{ gives } S = \int_a^b f(x)\,dx, \qquad f \le 0 \text{ gives } S = -\int_a^b f(x)\,dx$$
  1. Solve $f(x) = 0$ to find the crossing points between $a$ and $b$.
  2. On each piece, check the sign of $f$ (sketch the graph or test one point).
  3. Add $\displaystyle\int f$ for pieces above the axis and $-\displaystyle\int f$ for pieces below.

Each piece between crossings counted as a positive area

Example 1

Find the area between $y = x^2 - 2x$ and the $x$-axis.

Show solution
  1. Crossings: $x(x - 2) = 0$, so $x = 0, 2$. Between them the curve is below the axis.
  2. $S = -\displaystyle\int_0^2 (x^2 - 2x)\,dx = -\Big[\frac{x^3}{3} - x^2\Big]_0^2 = -\left(\frac{8}{3} - 4\right)$

$\dfrac{4}{3}$ (or by the 1/6 formula: $\dfrac{1}{6}(2 - 0)^3$)

Example 2

Find the total area enclosed by $y = x^3 - 3x$ and the $x$-axis.

Show solution
  1. Crossings: $x(x^2 - 3) = 0$, so $x = -\sqrt{3}, 0, \sqrt{3}$.
  2. The function is odd, so the two loops have equal area. On $[0, \sqrt{3}]$ the curve is below the axis: $-\displaystyle\int_0^{\sqrt{3}} (x^3 - 3x)\,dx = -\Big[\frac{x^4}{4} - \frac{3x^2}{2}\Big]_0^{\sqrt{3}} = -\left(\frac{9}{4} - \frac{9}{2}\right) = \frac{9}{4}$.
  3. Total: $2 \times \dfrac{9}{4}$.

$\dfrac{9}{2}$ (but $\displaystyle\int_{-\sqrt{3}}^{\sqrt{3}} (x^3 - 3x)\,dx = 0$)

Example 3

Find the area between $y = \sin x$ ($0 \le x \le 2\pi$) and the $x$-axis.

Show solution
  1. $\displaystyle\int_0^{\pi} \sin x\,dx - \int_{\pi}^{2\pi} \sin x\,dx = 2 - (-2)$

$4$

Example 4

Find the area bounded by $y = \log x$, the $x$-axis and the line $x = e$.

Show solution
  1. $\log x = 0$ at $x = 1$, and $\log x \ge 0$ on $[1, e]$.
  2. $\displaystyle\int_1^e \log x\,dx = \Big[x\log x - x\Big]_1^e = 0 - (-1)$

$1$

Integrating straight across a crossing point lets the parts above and below the axis cancel. You get the signed area, not the area. Always find the zeros first.
A parabola $y = a(x - \alpha)(x - \beta)$ and the axis enclose area $\dfrac{|a|}{6}(\beta - \alpha)^3$. It saves a lot of arithmetic.
