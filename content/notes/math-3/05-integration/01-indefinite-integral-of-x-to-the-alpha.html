Indefinite Integrals of x^α

Differentiation run backwards

$F(x)$ is an antiderivative (原始関数) of $f(x)$ if $F'(x) = f(x)$. Adding any constant keeps the derivative the same. So the antiderivatives form a family $F(x) + C$, all vertical shifts of one curve. This family is the indefinite integral $\displaystyle\int f(x)\,dx$.

For powers: raise the power by $1$ and divide by the new power. The one exception is $\dfrac{1}{x}$, whose antiderivative is $\log|x|$.

Powers of $x$ ($C$: constant of integration)

$$\int x^\alpha\,dx = \frac{x^{\alpha+1}}{\alpha + 1} + C \;\; (\alpha \ne -1), \qquad \int \frac{1}{x}\,dx = \log|x| + C$$

$\alpha$ may be any real number, e.g. $\sqrt{x} = x^{\frac{1}{2}}$, $\dfrac{1}{x^2} = x^{-2}$.

  1. $\left(\dfrac{x^{\alpha+1}}{\alpha + 1}\right)' = \dfrac{(\alpha + 1)x^\alpha}{\alpha + 1} = x^\alpha$. This needs $\alpha + 1 \ne 0$.
  2. For $\alpha = -1$: $(\log|x|)' = \dfrac{1}{x}$ (Differentiation note 09).
  3. If $F' = G' = f$, then $(F - G)' = 0$, so $F - G$ is a constant. That is why one constant $C$ covers all antiderivatives.

The family $F(x) + C$: same slope at every $x$

Example 1

Find $\displaystyle\int x^5\,dx$ and $\displaystyle\int \frac{1}{x^3}\,dx$.

Show solution
  1. $\dfrac{x^6}{6} + C$
  2. $\displaystyle\int x^{-3}\,dx = \frac{x^{-2}}{-2} + C$

$\dfrac{x^6}{6} + C$ and $-\dfrac{1}{2x^2} + C$

Example 2

Find $\displaystyle\int \sqrt[3]{x^2}\,dx$ and $\displaystyle\int \frac{1}{\sqrt{x}}\,dx$.

Show solution
  1. $\displaystyle\int x^{\frac{2}{3}}\,dx = \frac{x^{\frac{5}{3}}}{\frac{5}{3}} + C = \frac{3}{5}x\sqrt[3]{x^2} + C$
  2. $\displaystyle\int x^{-\frac{1}{2}}\,dx = \frac{x^{\frac{1}{2}}}{\frac{1}{2}} + C = 2\sqrt{x} + C$

$\dfrac{3}{5}x\sqrt[3]{x^2} + C$ and $2\sqrt{x} + C$

Example 3

Find $F(x)$ with $F'(x) = \dfrac{1}{x}$ ($x > 0$) and $F(1) = 3$.

Show solution
  1. $F(x) = \log x + C$, and $F(1) = 0 + C = 3$.

$F(x) = \log x + 3$

The power rule fails for $\alpha = -1$ (it would divide by $0$). Use $\log|x|$ instead. And never drop the $+ C$.
You can always check an integral: differentiate your answer and see if you get the original function back.
  • $\displaystyle\int x^\alpha\,dx = \frac{x^{\alpha+1}}{\alpha+1} + C$ ($\alpha \ne -1$).
  • $\displaystyle\int \frac{dx}{x} = \log|x| + C$.
  • Rewrite roots and fractions as powers first.
