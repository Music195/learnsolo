Riemann Sum and Definite Integral

Many thin rectangles

Cut $[a, b]$ into $n$ equal strips of width $\dfrac{b - a}{n}$, and replace each strip by a rectangle whose height is a value of $f$. Adding the rectangles gives an approximate area.

As $n \to \infty$ the rectangles fit the curve better and better, and the sum tends to the definite integral. Turned around, this lets you evaluate the limit of certain sums by integrating. This method is called 区分求積法.

Right-end heights ($k = 1, \ldots, n$) or left-end heights ($k = 0, \ldots, n - 1$)

$$\lim_{n \to \infty} \frac{b - a}{n}\sum_{k=1}^{n} f\!\left(a + \frac{b - a}{n}k\right) = \int_a^b f(x)\,dx$$
$$\text{Most used: } \lim_{n \to \infty} \frac{1}{n}\sum_{k=1}^{n} f\!\left(\frac{k}{n}\right) = \lim_{n \to \infty} \frac{1}{n}\sum_{k=0}^{n-1} f\!\left(\frac{k}{n}\right) = \int_0^1 f(x)\,dx$$
  1. $\dfrac{1}{n}$ is the strip width ($dx$), and $\dfrac{k}{n}$ is the $x$-coordinate of the $k$-th right end.
  2. So $\dfrac{1}{n}f\!\left(\dfrac{k}{n}\right)$ is the area of the $k$-th rectangle on $[0, 1]$.
  3. For a continuous $f$, the gap between the rectangles and the curve goes to $0$ as $n \to \infty$. The sum then tends to $\displaystyle\int_0^1 f(x)\,dx$.

$n$ rectangles under $f$ on $[0, 1]$

Example 1

Find $\displaystyle\lim_{n \to \infty} \frac{1}{n^3}(1^2 + 2^2 + \cdots + n^2)$.

Show solution
  1. Rewrite as $\dfrac{1}{n}\displaystyle\sum_{k=1}^n \left(\frac{k}{n}\right)^2$, so $f(x) = x^2$.
  2. $\displaystyle\int_0^1 x^2\,dx = \frac{1}{3}$

$\dfrac{1}{3}$ (agrees with $\dfrac{n(n + 1)(2n + 1)}{6n^3} \to \dfrac{2}{6}$)

Example 2

Find $\displaystyle\lim_{n \to \infty} \left(\frac{1}{n + 1} + \frac{1}{n + 2} + \cdots + \frac{1}{2n}\right)$.

Show solution
  1. $\dfrac{1}{n + k} = \dfrac{1}{n} \cdot \dfrac{1}{1 + \frac{k}{n}}$, so the sum is $\dfrac{1}{n}\displaystyle\sum_{k=1}^n \frac{1}{1 + \frac{k}{n}}$.
  2. $\displaystyle\int_0^1 \frac{dx}{1 + x} = \Big[\log(1 + x)\Big]_0^1$

$\log 2$

Example 3

Find $\displaystyle\lim_{n \to \infty} \frac{1}{n}\sum_{k=1}^{n} \sin\frac{k\pi}{n}$.

Show solution
  1. $f(x) = \sin \pi x$ on $[0, 1]$.
  2. $\displaystyle\int_0^1 \sin\pi x\,dx = \Big[-\frac{\cos\pi x}{\pi}\Big]_0^1 = \frac{2}{\pi}$

$\dfrac{2}{\pi}$

Example 4

Find $\displaystyle\lim_{n \to \infty} \frac{1}{n}\sum_{k=1}^{2n} \frac{k}{n}$.

Show solution
  1. $k$ runs to $2n$, so $\dfrac{k}{n}$ runs up to $2$: the interval is $[0, 2]$.
  2. $\displaystyle\int_0^2 x\,dx = 2$

$2$

Look at the range of $\dfrac{k}{n}$ to find the interval. If $k$ goes up to $2n$, the interval is $[0, 2]$, not $[0, 1]$. Also check that there is exactly one factor $\dfrac{1}{n}$ outside the sum.
Recipe: pull out $\dfrac{1}{n}$, then write each term using only $\dfrac{k}{n}$. Whatever function of $\dfrac{k}{n}$ remains is $f(x)$.
  • $\displaystyle\lim \frac{1}{n}\sum f\!\left(\frac{k}{n}\right) = \int_0^1 f(x)\,dx$.
  • $\dfrac{1}{n} \leftrightarrow dx$, $\;\dfrac{k}{n} \leftrightarrow x$.
  • Left ends, right ends or midpoints all give the same limit.
