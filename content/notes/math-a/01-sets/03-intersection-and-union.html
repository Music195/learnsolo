Intersection and Union

Combining two sets

The intersection $A \cap B$ keeps only the elements that are in both sets.

The union $A \cup B$ collects every element that is in at least one of the sets.

Intersection ("and")

$$A \cap B = \{\,x \mid x \in A \text{ and } x \in B\,\}$$

Union ("or")

$$A \cup B = \{\,x \mid x \in A \text{ or } x \in B\,\}$$

In maths "or" includes "both".

$\cup$ looks like a cup that holds everything (union). $\cap$ is the cup turned upside down, holding only what is shared (intersection).

Rules

RuleIntersectionUnion
Order doesn't matter$A \cap B = B \cap A$$A \cup B = B \cup A$
Grouping doesn't matter$(A \cap B) \cap C = A \cap (B \cap C)$$(A \cup B) \cup C = A \cup (B \cup C)$
Distributive$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$
With $\varnothing$ and $U$$A \cap \varnothing = \varnothing,\ \ A \cap U = A$$A \cup \varnothing = A,\ \ A \cup U = U$
When $A \subset B$$A \cap B = A$$A \cup B = B$
Write each element once in a union: $\{1, 2, 3\} \cup \{3, 4\} = \{1, 2, 3, 4\}$, not $\{1, 2, 3, 3, 4\}$. And if two sets share nothing, the intersection is $\varnothing$; don't leave it blank.

Example 1

$A = \{2, 4, 6, 8, 10\}$, $B = \{1, 3, 5, 7, 9\}$. Find $A \cap B$ and $A \cup B$.

Show solution
  1. $A$ is even numbers, $B$ is odd numbers: nothing is in both.
  2. Together they contain every number from 1 to 10.

$A \cap B = \varnothing$, $\;A \cup B = \{1, 2, 3, \dots, 10\}$

Example 2

$C$ = the vowels $\{a, e, i, o, u\}$, $D$ = the letters of "mathematics". Find $C \cap D$ and $C \cup D$.

Show solution
  1. Letters of "mathematics", each once: $D = \{m, a, t, h, e, i, c, s\}$
  2. Vowels that appear in $D$: $a, e, i$
  3. All letters from either set: $a, c, e, h, i, m, o, s, t, u$

$C \cap D = \{a, e, i\}$, $\;C \cup D = \{a, c, e, h, i, m, o, s, t, u\}$

Example 3

Check $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$ for $A = \{1, 2, 3, 4\}$, $B = \{2, 3, 5, 6\}$, $C = \{3, 4, 7, 8\}$.

Show solution
  1. Left side: $B \cup C = \{2, 3, 4, 5, 6, 7, 8\}$, so $A \cap (B \cup C) = \{2, 3, 4\}$
  2. Right side: $A \cap B = \{2, 3\}$, $A \cap C = \{3, 4\}$, so their union is $\{2, 3, 4\}$

Both sides equal $\{2, 3, 4\}$. ✔

  • $A \cap B$: in both. $\;A \cup B$: in at least one.
  • Both operations ignore order and grouping, and each distributes over the other.
  • If $A \subset B$, then $A \cap B = A$ and $A \cup B = B$.
  • No common elements means $A \cap B = \varnothing$.
