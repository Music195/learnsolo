Set and Elements

What is a set?

A set is a collection of things that is clearly defined: for any object you can say for certain whether it belongs or not. The things in a set are its elements.

"The positive divisors of 15" is a set. "Big numbers" is not a set, because "big" isn't clearly defined.

Belongs / does not belong

$$a \in A \qquad\qquad b \notin A$$

$a \in A$: $a$ is an element of $A$
$b \notin A$: $b$ is not an element of $A$

Two ways to write a set

List the elements

$$A = \{1, 3, 5, 15\}$$

Good for small sets.

Describe the condition

$$A = \{\,x \mid x \text{ is a positive divisor of } 15\,\}$$

Read "the set of $x$ such that…". Needed for large or infinite sets, e.g. $\{\,x \mid 2 \le x \le 7\,\}$.

Order and repeats don't matter in a set: $\{1, 2, 3\} = \{3, 2, 1\} = \{2, 1, 3, 2\}$. Two sets are equal when they have exactly the same elements.

Special sets

Finite sethas a countable number of elements; $n(A)$ is how many
$5$ and $\{5\}$ are different things: $5$ is a number, $\{5\}$ is a set containing that number. So $5 \in \{5\}$ is correct, but $\{5\} \in \{5\}$ is wrong.

Is it an element?

Example 1

Let $A = \{1, 3, 5, 7, 9\}$. True or false? (a) $5 \in A$   (b) $6 \in A$   (c) $10 \notin A$

Show solution
  1. (a) $5$ is listed in $A$: true
  2. (b) $6$ is not listed in $A$: false
  3. (c) $10$ is not listed in $A$, so "$10$ is not an element" is true

Example 2

Write $\{\,x \mid x \text{ is a positive divisor of } 12\,\}$ by listing its elements.

Show solution
  1. Find the pairs that multiply to 12: $1 \times 12$, $2 \times 6$, $3 \times 4$

$\{1, 2, 3, 4, 6, 12\}$

Example 3

Are $A = \{2, 4, 6\}$ and $B = \{6, 4, 2, 4\}$ equal?

Show solution
  1. Remove the repeat in $B$: $B = \{6, 4, 2\}$
  2. Both sets contain exactly $2, 4, 6$; order doesn't matter.

Yes, $A = B$.

  • A set is a clearly defined collection; its members are elements.
  • $a \in A$ means "$a$ is in $A$"; $b \notin A$ means "$b$ is not in $A$".
  • Write a set by listing elements or by a condition $\{\,x \mid \dots\}$.
  • Order and repeats don't matter; $5$ and $\{5\}$ are different.
