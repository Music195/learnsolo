Equal Tangent Lengths from a Point

Two tangents, same length

A tangent touches a circle at exactly one point, and it is at right angles to the radius there.

From a point $P$ outside a circle you can draw two tangents, touching at $A$ and $B$. The distances $PA$ and $PB$ (the tangent lengths) are always equal.

Tangent lengths

$$PA = PB = \sqrt{OP^2 - r^2}$$

$O$: centre, $r$: radius. $OA \perp PA$, so $\triangle OAP$ is right-angled at $A$.

  1. $\angle OAP = \angle OBP = 90°$ (tangent ⊥ radius).
  2. $OA = OB$ (radii) and $OP$ is shared.
  3. So $\triangle OAP \equiv \triangle OBP$ (right angle, hypotenuse and one side), and $PA = PB$.
  4. Bonus: $\angle APO = \angle BPO$, so $PO$ bisects the angle between the tangents.

Drag $P$

Example 1

A circle has radius 5 and $OP = 13$. Find the tangent length from $P$.

Show solution
  1. $PA^2 = 13^2 - 5^2 = 144$

$PA = PB = 12$

Example 2

A circle is inscribed in quadrilateral $ABCD$ (it touches all four sides). $AB = 6$, $BC = 7$, $CD = 8$. Find $DA$.

Show solution
  1. Call the tangent lengths from the corners $a, b, c, d$. Each side is made of two of them: $AB = a + b$, $BC = b + c$, $CD = c + d$, $DA = d + a$.
  2. So $AB + CD = a + b + c + d = BC + DA$.
  3. $6 + 8 = 7 + DA$

$DA = 7$

Example 3

Tangents $PA$, $PB$ meet at $\angle APB = 60°$. The radius is 3. Find $PA$.

Show solution
  1. $PO$ bisects the angle, so $\angle APO = 30°$; $\triangle OAP$ is a $30°$-$60°$-$90°$ triangle.
  2. $OA = 3$ is opposite $30°$, so $OP = 6$ and $PA = 3\sqrt{3}$.

$PA = 3\sqrt{3}$

In a figure with an inscribed circle, label each corner's tangent length with one letter. Every side becomes a sum of two letters (see note 04, Example 3).
  • Tangent ⊥ radius at the touching point.
  • From one outside point, the two tangent lengths are equal: $\sqrt{OP^2 - r^2}$.
  • Quadrilateral with an inscribed circle: $AB + CD = BC + DA$.
