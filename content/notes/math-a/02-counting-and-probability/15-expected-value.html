Expectation (Expected Value)

The long-run average

Suppose a game pays different amounts with different probabilities. If you play it many, many times, the average payout per game settles near one number: the expected value.

To find it, weight each value by how likely it is: multiply value × probability for each outcome, then add.

Expected value

$$E = x_1 p_1 + x_2 p_2 + \dots + x_n p_n$$

$x_1, \dots, x_n$: the possible values. $\;p_1, \dots, p_n$: their probabilities, with $p_1 + p_2 + \dots + p_n = 1$.

Expected value calculator

One value and its probability per line, e.g. 100, 0.1. Fractions like 1/6 work too.

Example 1

Find the expected value of the number shown when a die is rolled.

Show solution
  1. Each face has probability $\dfrac{1}{6}$
  2. $E = (1 + 2 + 3 + 4 + 5 + 6) \times \dfrac{1}{6} = \dfrac{21}{6}$

$\dfrac{7}{2} = 3.5$ (not a face you can roll; it's an average)

Example 2

Three coins are tossed. Find the expected number of heads.

Show solution
  1. 0, 1, 2, 3 heads have probabilities $\dfrac{1}{8}, \dfrac{3}{8}, \dfrac{3}{8}, \dfrac{1}{8}$ (from ${}_3\mathrm{C}_r$)
  2. $E = 0 \cdot \dfrac{1}{8} + 1 \cdot \dfrac{3}{8} + 2 \cdot \dfrac{3}{8} + 3 \cdot \dfrac{1}{8} = \dfrac{12}{8}$

$\dfrac{3}{2}$

Example 3

A bag has 3 red and 2 white balls. Two are taken out together. You get 100 yen for each red ball. Find the expected amount.

Show solution
  1. All ways: ${}_5\mathrm{C}_2 = 10$
  2. 0 red: ${}_2\mathrm{C}_2 = 1$; $\;$1 red: $3 \times 2 = 6$; $\;$2 red: ${}_3\mathrm{C}_2 = 3$
  3. $E = 0 \cdot \dfrac{1}{10} + 100 \cdot \dfrac{6}{10} + 200 \cdot \dfrac{3}{10} = 60 + 60$

$120$ yen

Example 4

Game A: win 1000 yen with probability 0.1, otherwise lose 100 yen. Game B: win 100 yen or lose 50 yen, each with probability 0.5. Which game is better on average?

Show solution
  1. A: $1000 \times 0.1 + (-100) \times 0.9 = 100 - 90 = 10$
  2. B: $100 \times 0.5 + (-50) \times 0.5 = 50 - 25 = 25$

Game B (25 yen per game vs 10 yen)

Before multiplying, check that your probabilities add to 1. If they don't, an outcome is missing.
A loss is a negative value. If a game costs money to play, subtract the cost from each payout (or subtract it from $E$ at the end).
  • $E = \sum x_k p_k$: value × probability, added up.
  • The probabilities must add to 1.
  • $E$ is a long-run average; it need not be a value that can actually happen.
