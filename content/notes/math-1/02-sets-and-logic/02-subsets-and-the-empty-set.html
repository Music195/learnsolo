Subsets and the Empty Set

What is a subset?

$A$ is a subset of $B$ when every element of $A$ is also an element of $B$. In a Venn diagram, circle $A$ sits completely inside circle $B$.

For example, $\{1, 2\}$ is a subset of $\{1, 2, 3, 4\}$, but $\{1, 5\}$ is not, because $5$ is missing from the second set.

Subset

$$A \subset B$$

"$A$ is a subset of $B$" ($A$ is allowed to equal $B$)
$A \not\subset B$: at least one element of $A$ is not in $B$

Equal sets

$$A = B \iff A \subset B \;\text{ and }\; B \subset A$$

Each is a subset of the other, so they have exactly the same elements.

Symbols differ between textbooks. In Japanese high-school maths (used in these notes) $A \subset B$ includes the case $A = B$. Many English textbooks write this as $A \subseteq B$ and use $A \subset B$ only when $A \neq B$ (a proper subset, also written $A \subsetneq B$). Check which convention your exam uses.

The empty set $\varnothing$

$\varnothing$ is the set with no elements. Sets defined by an impossible condition are empty:

$$\{\,x \mid x \text{ is real and } x^2 = -1\,\} = \varnothing \qquad \{\,x \mid x \text{ is an integer and } 5 < x < 6\,\} = \varnothing$$

$\varnothing$ is a subset of every set: $\varnothing \subset A$. To break "every element of $\varnothing$ is in $A$" you would need an element of $\varnothing$ that is not in $A$, and there are none.

A set with $n$ elements has $2^n$ subsets: for each element you choose "in" or "out". $\{1, 2\}$ has $2^2 = 4$ subsets: $\varnothing,\ \{1\},\ \{2\},\ \{1, 2\}$.

Is $A$ a subset of $B$?

Example 1

Let $A = \{1, 2, 3\}$, $B = \{1, 2\}$, $C = \{1, 2, 3, 4\}$. True or false? (a) $B \subset A$   (b) $A \subset C$   (c) $C \subset A$   (d) $A \subset B$

Show solution
  1. (a) $1, 2$ are both in $A$: true
  2. (b) $1, 2, 3$ are all in $C$: true
  3. (c) $4 \in C$ but $4 \notin A$: false
  4. (d) $3 \in A$ but $3 \notin B$: false

Example 2

List all the subsets of $\{a, b, c\}$.

Show solution
  1. No elements: $\varnothing$
  2. One element: $\{a\},\ \{b\},\ \{c\}$
  3. Two elements: $\{a, b\},\ \{a, c\},\ \{b, c\}$
  4. Three elements: $\{a, b, c\}$

8 subsets in total, which matches $2^3 = 8$.

Example 3

Write $\{\,x \mid x \text{ is real and } x^2 = -1\,\}$ by listing its elements.

Show solution
  1. The square of any real number is $\ge 0$, so no real $x$ has $x^2 = -1$.

$\varnothing$ (the empty set)

  • $A \subset B$: every element of $A$ is in $B$ (in these notes, $A = B$ is allowed).
  • $A = B$ exactly when $A \subset B$ and $B \subset A$.
  • $\varnothing$ has no elements and is a subset of every set.
  • A set with $n$ elements has $2^n$ subsets.
