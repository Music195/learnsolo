Proof by Contrapositive

Prove the easier twin

$p \Rightarrow q$ and its contrapositive $\overline{q} \Rightarrow \overline{p}$ are true or false together (note 08). So if the contrapositive is easier to prove, prove that instead.

This helps most when "not $q$" gives you something concrete to work with, for example "$n$ is odd" means $n = 2k + 1$.

Proof by contrapositive

$$\text{to prove } p \Rightarrow q, \text{ prove } \overline{q} \Rightarrow \overline{p}$$

Steps: (1) write the contrapositive, (2) assume $\overline{q}$, (3) show $\overline{p}$ follows, (4) conclude the original is true.

Why "$n^2$ is a multiple of 3 ⇒ $n$ is a multiple of 3"

Contrapositive: if $n$ is not a multiple of 3, then $n^2$ is not either. Check the remainders.

Example 1

For an integer $n$, prove: $n^2$ is even $\Rightarrow$ $n$ is even.

Show solution
  1. Contrapositive: $n$ is odd ⇒ $n^2$ is odd.
  2. Let $n = 2k + 1$ ($k$ an integer). $n^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1$, which is odd.
  3. The contrapositive is true, so the original is true.

Proved ∎

Example 2

For an integer $n$, prove: $n^2$ is a multiple of 3 $\Rightarrow$ $n$ is a multiple of 3.

Show solution
  1. Contrapositive: $n$ is not a multiple of 3 ⇒ $n^2$ is not a multiple of 3.
  2. Then $n = 3k + 1$ or $n = 3k + 2$.
  3. $(3k + 1)^2 = 3(3k^2 + 2k) + 1$ and $(3k + 2)^2 = 3(3k^2 + 4k + 1) + 1$: remainder 1 either way.

Proved ∎

Example 3

For real $x, y$, prove: $x + y > 2 \Rightarrow x > 1$ or $y > 1$.

Show solution
  1. Contrapositive: $x \le 1$ and $y \le 1$ ⇒ $x + y \le 2$.
  2. Add the two inequalities: $x + y \le 1 + 1 = 2$.

Proved ∎

Example 4 (proof by contradiction, 背理法)

Prove that $\sqrt{2}$ is irrational.

Show solution
  1. Suppose not: $\sqrt{2} = \dfrac{a}{b}$ with $a, b$ positive integers sharing no common factor.
  2. Then $a^2 = 2b^2$, so $a^2$ is even, so $a$ is even (Example 1). Write $a = 2c$.
  3. $4c^2 = 2b^2 \Rightarrow b^2 = 2c^2$, so $b$ is even too.
  4. Now $a$ and $b$ share the factor 2, contradicting our assumption. So $\sqrt{2}$ is irrational.

Proved ∎

Contrapositive: prove a different statement, $\overline{q} \Rightarrow \overline{p}$. Contradiction: assume the conclusion is false and reach something impossible. Use contradiction for "is irrational", "there are infinitely many", "cannot be".
Proving the converse $q \Rightarrow p$ or the inverse $\overline{p} \Rightarrow \overline{q}$ does not prove $p \Rightarrow q$. Only the contrapositive works.
  • $p \Rightarrow q$ is proved by proving $\overline{q} \Rightarrow \overline{p}$.
  • "Not even" → $2k + 1$; "not a multiple of 3" → $3k + 1$ or $3k + 2$.
  • Irrationality and similar: use proof by contradiction.
