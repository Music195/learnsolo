Necessary and Sufficient Conditions

"$p \Rightarrow q$" means the set for $p$ sits inside the set for $q$

A proposition (命題) is a statement that is clearly true or false. "$p \Rightarrow q$" (if $p$ then $q$) is true when every case of $p$ is also a case of $q$.

Write $P$ for the set of values that make $p$ true and $Q$ for $q$ (truth sets, 真理集合). Then $p \Rightarrow q$ is true exactly when $P \subset Q$. One counterexample (反例), a case in $P$ but not in $Q$, makes it false.

When $p \Rightarrow q$ is true

$$p \text{ is a } \textbf{sufficient} \text{ condition for } q, \qquad q \text{ is a } \textbf{necessary} \text{ condition for } p$$

Arrow points from the sufficient condition to the necessary one. If both $p \Rightarrow q$ and $q \Rightarrow p$ hold, write $p \iff q$: $p$ is a necessary and sufficient condition for $q$ (they are equivalent, 同値).

$p$: $x$ is in the blue interval, $q$: $x$ is in the orange one. Drag the ends.

Example 1

$p$: $x = 2$, $\;q$: $x^2 = 4$. Which kind of condition is $p$ for $q$?

Show solution
  1. $p \Rightarrow q$: $2^2 = 4$ ✓.
  2. $q \Rightarrow p$: false; counterexample $x = -2$.

$p$ is sufficient but not necessary for $q$

Example 2

$p$: $x > 5$, $\;q$: $x > 3$. Which kind of condition is $p$ for $q$?

Show solution
  1. $P = \{x \mid x > 5\} \subset Q = \{x \mid x > 3\}$, so $p \Rightarrow q$ is true.
  2. $q \Rightarrow p$: counterexample $x = 4$.

Sufficient but not necessary

Example 3

For real $x, y$: $p$: $xy = 0$, $\;q$: $x = 0$. Which kind of condition is $p$ for $q$?

Show solution
  1. $p \Rightarrow q$: false; counterexample $x = 1, y = 0$.
  2. $q \Rightarrow p$: $x = 0$ makes $xy = 0$ ✓.

Necessary but not sufficient

Example 4

For a quadrilateral: $p$: all four sides are equal, $\;q$: it is a rhombus.

Show solution
  1. A rhombus is defined as a quadrilateral with four equal sides, so each implies the other.

Necessary and sufficient ($p \iff q$)

Memory aid: the smaller set is sufficient, the bigger set is necessary. Being a square (small set) is enough to be a rectangle (big set).
To show $p \Rightarrow q$ is false, one counterexample is enough, and it must satisfy $p$ but not $q$.
  • $p \Rightarrow q$ true ⟺ $P \subset Q$.
  • $p \Rightarrow q$: $p$ sufficient, $q$ necessary.
  • Both ways: necessary and sufficient, $p \iff q$.
