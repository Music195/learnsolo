Quadratic Inequality Solutions

Read the answer off the graph

$ax^2 + bx + c > 0$ asks: for which $x$ is the graph above the $x$-axis? And $< 0$ asks where it is below.

Make $a$ positive first (multiply by $-1$ and flip the sign if needed). Then the parabola opens upward: it is below the axis between the solutions $\alpha < \beta$ and above it outside them.

$a > 0$, $D > 0$, solutions $\alpha < \beta$ of $ax^2 + bx + c = 0$

$$ax^2 + bx + c > 0 \iff x < \alpha \text{ or } \beta < x, \qquad ax^2 + bx + c < 0 \iff \alpha < x < \beta$$

For $\ge$ / $\le$, include $\alpha$ and $\beta$ themselves.

$a > 0$, $D \le 0$ (the graph never goes below the axis)

$$D = 0 \;(\text{touches at } x = \alpha):\; > 0 \text{ for all } x \ne \alpha,\; \ge 0 \text{ for all } x,\; < 0 \text{ none},\; \le 0 \text{ only } x = \alpha$$
$$D < 0:\; > 0 \text{ and } \ge 0 \text{ for all } x,\; < 0 \text{ and } \le 0 \text{ none}$$

Solve $ax^2 + bx + c \;\square\; 0$

Example 1

Solve $x^2 - 5x + 6 > 0$.

Show solution
  1. $(x - 2)(x - 3) > 0$; the solutions of $= 0$ are $2$ and $3$.
  2. $> 0$ with $a > 0$: outside.

$x < 2$ or $3 < x$

Example 2

Solve $-x^2 + 2x + 3 \ge 0$.

Show solution
  1. Multiply by $-1$ and flip: $x^2 - 2x - 3 \le 0$.
  2. $(x + 1)(x - 3) \le 0$: between, ends included.

$-1 \le x \le 3$

Example 3

Solve $x^2 - 2x - 1 \le 0$.

Show solution
  1. Doesn't factorise: $x = 1 \pm \sqrt{2}$ (note 05).

$1 - \sqrt{2} \le x \le 1 + \sqrt{2}$

Example 4

Solve (i) $x^2 - 4x + 4 > 0$ and (ii) $x^2 + x + 1 < 0$.

Show solution
  1. (i) $(x - 2)^2 > 0$: true except where $(x - 2)^2 = 0$.
  2. (ii) $D = 1 - 4 < 0$ and $a > 0$: the graph is always above the axis.

(i) all $x$ except $x = 2$   (ii) no solution

Example 5

Find $k$ so that $x^2 + kx + k + 3 > 0$ for every real $x$.

Show solution
  1. $a = 1 > 0$, so we need the graph never to reach the axis: $D < 0$.
  2. $k^2 - 4(k + 3) < 0 \Rightarrow (k + 2)(k - 6) < 0$.

$-2 < k < 6$

The "between / outside" rule is for $a > 0$. With $a < 0$, multiply by $-1$ first and remember to flip $>$ ↔ $<$.
Don't memorise the table: sketch the parabola, mark where it meets the axis, and shade the part above or below as the question asks.
  • Make $a > 0$, find $\alpha, \beta$.
  • $> 0$: outside; $< 0$: between.
  • $D \le 0$: use the graph (always above, or touching).
