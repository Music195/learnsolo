General Forms of Linear and Quadratic Functions

Highest power of $x$: 1 gives a line, 2 gives a parabola

A function gives exactly one $y$ for each $x$; we write $y = f(x)$, and $f(3)$ means "the value of $y$ when $x = 3$".

If the highest power of $x$ is 1, the graph is a straight line. If it is 2, the graph is a curve called a parabola.

General forms

$$\text{linear: } y = ax + b \;(a \ne 0), \qquad \text{quadratic: } y = ax^2 + bx + c \;(a \ne 0)$$

Linear: $a$ is the slope, $b$ the $y$-intercept. Quadratic: $c$ is the $y$-intercept and $a$ decides which way the parabola opens.

Change the coefficients

Example 1

$f(x) = x^2 - 3x + 2$. Find $f(0)$, $f(-1)$ and $f(a + 1)$.

Show solution
  1. $f(0) = 2$, $\;f(-1) = 1 + 3 + 2 = 6$.
  2. $f(a + 1) = (a + 1)^2 - 3(a + 1) + 2 = a^2 + 2a + 1 - 3a - 3 + 2$.

$2$, $\;6$, $\;a^2 - a$

Example 2

Find the linear function whose graph passes through $(1, 3)$ and $(3, -1)$.

Show solution
  1. Slope $a = \dfrac{-1 - 3}{3 - 1} = -2$.
  2. $3 = -2 \cdot 1 + b \Rightarrow b = 5$.

$y = -2x + 5$

Example 3

For $y = 2x - 1$ with $-1 \le x \le 2$, find the range of $y$ (値域).

Show solution
  1. The slope is positive, so $y$ grows with $x$: smallest at $x = -1$, largest at $x = 2$.
  2. $y(-1) = -3$, $\;y(2) = 3$.

$-3 \le y \le 3$

The allowed $x$ values are the domain (定義域); the $y$ values you get are the range (値域). For a straight line, the range comes from the two ends of the domain.
$y = ax^2 + bx + c$ is only quadratic when $a \ne 0$. If a question says "$y = ax^2 + bx + c$" without that condition, check the case $a = 0$ separately.
  • $y = ax + b$: line, slope $a$, intercept $b$.
  • $y = ax^2 + bx + c$: parabola, intercept $c$.
  • $f(\text{something})$: substitute it for every $x$.
