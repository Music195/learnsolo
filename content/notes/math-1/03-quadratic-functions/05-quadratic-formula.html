Quadratic Formula

One formula that solves every quadratic equation

Try factorising first; it is quickest. When the equation doesn't factorise nicely, the quadratic formula always works. It comes from completing the square on $ax^2 + bx + c = 0$ once, in general.

Quadratic formula ($a \ne 0$, $b^2 - 4ac \ge 0$)

$$ax^2 + bx + c = 0 \;\Rightarrow\; x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

When $b$ is even: $b = 2b'$

$$ax^2 + 2b'x + c = 0 \;\Rightarrow\; x = \frac{-b' \pm \sqrt{b'^2 - ac}}{a}$$

Same answer with smaller numbers, so there is less to simplify.

  1. Divide by $a$: $x^2 + \dfrac{b}{a}x = -\dfrac{c}{a}$.
  2. Add $\left(\dfrac{b}{2a}\right)^2$ to both sides: $\left(x + \dfrac{b}{2a}\right)^2 = \dfrac{b^2 - 4ac}{4a^2}$.
  3. Take square roots: $x + \dfrac{b}{2a} = \pm\dfrac{\sqrt{b^2 - 4ac}}{2a}$, and move $\dfrac{b}{2a}$ across.

Solve $ax^2 + bx + c = 0$

Example 1

Solve $2x^2 - 7x + 3 = 0$.

Show solution
  1. $x = \dfrac{7 \pm \sqrt{49 - 24}}{4} = \dfrac{7 \pm 5}{4}$
  2. (It also factorises: $(2x - 1)(x - 3) = 0$.)

$x = 3, \dfrac{1}{2}$

Example 2

Solve $x^2 + 4x + 1 = 0$.

Show solution
  1. $b = 4$ is even: $b' = 2$. $\;x = \dfrac{-2 \pm \sqrt{4 - 1}}{1}$

$x = -2 \pm \sqrt{3}$

Example 3

Solve $3x^2 - 2x - 2 = 0$.

Show solution
  1. $b' = -1$: $\;x = \dfrac{1 \pm \sqrt{1 + 6}}{3}$

$x = \dfrac{1 \pm \sqrt{7}}{3}$

Example 4

Solve $x^2 - 2x + 3 = 0$.

Show solution
  1. $b'^2 - ac = 1 - 3 = -2 < 0$: the square root of a negative number is not real.

No real solutions

Simplify fully: $\dfrac{2 \pm 2\sqrt{3}}{2} = 1 \pm \sqrt{3}$. Divide every term on top by the bottom, not just one.
In Mathematics 2 you'll meet complex numbers, which give a meaning to $\sqrt{-2}$. In Mathematics 1, a negative value under the root simply means "no real solution".
  • $x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$.
  • Even $b$: $x = \dfrac{-b' \pm \sqrt{b'^2 - ac}}{a}$.
  • Factorise first if you can; it's faster.
