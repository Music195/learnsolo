Maximum and Minimum of y = a(x − p)² + q

Look at the vertex, then at the ends

On all real $x$, a parabola opening upward has a lowest point (the vertex) but no highest point; one opening downward is the other way round.

If $x$ is limited to an interval, the extreme values occur at the vertex (if it is inside the interval) or at the ends of the interval.

For $y = a(x - p)^2 + q$ (all real $x$)

$$a > 0: \text{ minimum } q \text{ at } x = p, \text{ no maximum} \qquad a < 0: \text{ maximum } q \text{ at } x = p, \text{ no minimum}$$

With a limited domain $\alpha \le x \le \beta$: compare the vertex (if $\alpha \le p \le \beta$) and the two ends $x = \alpha$, $x = \beta$.

$y = x^2 - 4x + 1$: drag the ends $L$ and $R$ of the domain

Example 1

Find the maximum or minimum of $y = -2x^2 + 4x + 1$.

Show solution
  1. $y = -2(x - 1)^2 + 3$; $a < 0$ so the vertex is the highest point.

Maximum $3$ at $x = 1$; no minimum

Example 2

Find the maximum and minimum of $y = x^2 - 4x + 1$ for $0 \le x \le 3$.

Show solution
  1. $y = (x - 2)^2 - 3$. The vertex $x = 2$ is inside the domain → minimum $-3$.
  2. Ends: $y(0) = 1$, $y(3) = -2$. The end farther from the axis, $x = 0$, gives the maximum.

Maximum $1$ ($x = 0$), minimum $-3$ ($x = 2$)

Example 3

Find the maximum and minimum of $y = x^2 - 4x + 1$ for $3 \le x \le 5$.

Show solution
  1. The vertex $x = 2$ is outside the domain; on $3 \le x \le 5$ the graph only rises.
  2. $y(3) = -2$, $\;y(5) = 6$.

Maximum $6$ ($x = 5$), minimum $-2$ ($x = 3$)

Example 4

A rectangle has perimeter 20 cm. What is its largest possible area?

Show solution
  1. Width $x$, height $10 - x$, with $0 < x < 10$. Area $S = x(10 - x) = -(x - 5)^2 + 25$.
  2. The vertex $x = 5$ is in the domain.

$25\ \text{cm}^2$ (a $5 \times 5$ square)

The vertex value is only an answer if the vertex is inside the domain. Always draw the graph with the domain marked.
For $a > 0$ the maximum on an interval is at the end farther from the axis $x = p$. For $a < 0$ it's the minimum that's there.
  • Complete the square to find the vertex.
  • All real $x$: only one of max/min exists.
  • Limited domain: check the vertex (if inside) and both ends.
