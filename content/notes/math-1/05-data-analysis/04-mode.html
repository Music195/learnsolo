Mode

The most common value

The mode is the value that appears most often. Count how many times each value appears and pick the biggest count.

There can be more than one mode if two values tie. The mode also works for non-numbers, like the most popular shoe size or colour.

Mode of grouped data

$$\text{mode} = \text{class value of the class with the highest frequency}$$

The class value (階級値) is the middle of the class: for 20–30 it is 25.

Frequency chart

Example 1

Find the mode of 12, 15, 18, 15, 20, 15, 22.

Show solution
  1. 15 appears 3 times; every other value once.

Mode $= 15$

Example 2

Find the mode of 5, 7, 5, 8, 7, 9, 5, 7.

Show solution
  1. 5 and 7 both appear 3 times; 8 and 9 once.

Two modes: 5 and 7

Example 3

Scores: 10–20 (5 students), 20–30 (12), 30–40 (8), 40–50 (6). Find the mode.

Show solution
  1. The class 20–30 has the highest frequency, 12.
  2. Its class value is $\dfrac{20 + 30}{2}$.

Mode $= 25$

The mode is the value, not its count. In Example 1 the mode is 15, not 3.
  • Mode = most frequent value (there may be several).
  • Grouped data: the class value of the most frequent class.
  • Mean, median and mode are the three "typical values" (代表値).
