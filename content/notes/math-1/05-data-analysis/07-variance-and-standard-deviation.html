Variance & Standard Deviation

Average distance from the mean

Each value is some distance from the mean: its deviation $x - \overline{x}$. The deviations always add to 0, so we can't just average them. Instead we square them (all positive now) and average those: that's the variance $s^2$.

The variance is in squared units (cm²), so take the square root to get back to the data's units: the standard deviation $s$.

Variance and standard deviation

$$s^2 = \frac{(x_1 - \overline{x})^2 + \cdots + (x_n - \overline{x})^2}{n}, \qquad s = \sqrt{s^2}$$

Shortcut

$$s^2 = \overline{x^2} - \left(\overline{x}\right)^2$$

"Mean of the squares minus the square of the mean." Easier when $\overline{x}$ is not a whole number.

Variance step by step

Example 1

Find the variance and standard deviation of 4, 6, 8, 10, 12.

Show solution
  1. $\overline{x} = 8$. Deviations: $-4, -2, 0, 2, 4$.
  2. Squares: $16, 4, 0, 4, 16$; total $40$. $s^2 = \dfrac{40}{5} = 8$.

$s^2 = 8$, $s = 2\sqrt{2} \approx 2.83$

Example 2

Use the shortcut to find the variance of 1, 2, 3, 4, 5.

Show solution
  1. $\overline{x^2} = \dfrac{1 + 4 + 9 + 16 + 25}{5} = 11$, $\;\overline{x} = 3$
  2. $s^2 = 11 - 3^2$

$s^2 = 2$, $s = \sqrt{2}$

Example 3

Data $x$ has mean 50 and standard deviation 8. Each value is changed to $y = 2x + 10$. Find the mean and standard deviation of $y$.

Show solution
  1. Mean: $\overline{y} = 2 \times 50 + 10 = 110$.
  2. Adding 10 shifts everything and doesn't change the spread; doubling doubles every distance: $s_y = 2 \times 8$.

$\overline{y} = 110$, $s_y = 16$ (variance $256$)

For $y = ax + b$: $\;\overline{y} = a\overline{x} + b$, $\;s_y = |a|\, s_x$, $\;s_y^2 = a^2 s_x^2$. The $+b$ never changes the spread.
In this course we divide by $n$. Calculators and statistics courses sometimes divide by $n - 1$ (the "sample" variance), which gives a slightly larger answer.
  • $s^2$ = mean of the squared deviations; $s = \sqrt{s^2}$.
  • Shortcut: $s^2 = \overline{x^2} - (\overline{x})^2$.
  • $s = 0$ only when every value is the same.
  • $y = ax + b$: $s_y = |a| s_x$.
