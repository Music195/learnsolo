Double Radicals Expansion

A root inside a root, removed by spotting a square

$(\sqrt{3} + \sqrt{2})^2 = 5 + 2\sqrt{6}$. Read backwards: $\sqrt{5 + 2\sqrt{6}} = \sqrt{3} + \sqrt{2}$.

So to simplify $\sqrt{p + 2\sqrt{q}}$, look for two numbers that add to $p$ and multiply to $q$.

Removing a double radical ($a > 0$, $b > 0$)

$$\sqrt{(a + b) + 2\sqrt{ab}} = \sqrt{a} + \sqrt{b}, \qquad \sqrt{(a + b) - 2\sqrt{ab}} = \sqrt{a} - \sqrt{b} \quad (a > b)$$

In the minus case write the larger number first, because a square root is never negative.

  1. $(\sqrt{a} \pm \sqrt{b})^2 = a + b \pm 2\sqrt{ab}$.
  2. So $\sqrt{a + b \pm 2\sqrt{ab}} = \sqrt{(\sqrt{a} \pm \sqrt{b})^2} = |\sqrt{a} \pm \sqrt{b}|$ (note 07).
  3. $\sqrt{a} + \sqrt{b} > 0$, and $\sqrt{a} - \sqrt{b} > 0$ when $a > b$, so the bars can be dropped.

Simplify $\sqrt{p \pm 2\sqrt{q}}$

Example 1

Simplify $\sqrt{5 + 2\sqrt{6}}$.

Show solution
  1. Sum 5, product 6: the numbers are 3 and 2.

$\sqrt{3} + \sqrt{2}$

Example 2

Simplify $\sqrt{7 - 4\sqrt{3}}$.

Show solution
  1. Make the middle term "$2\sqrt{\;}$": $4\sqrt{3} = 2\sqrt{12}$.
  2. Sum 7, product 12: 4 and 3. Larger first: $\sqrt{4} - \sqrt{3}$.

$2 - \sqrt{3}$

Example 3

Simplify $\sqrt{4 + \sqrt{15}}$.

Show solution
  1. There is no 2 in front of the root, so make one: $\sqrt{4 + \sqrt{15}} = \sqrt{\dfrac{8 + 2\sqrt{15}}{2}} = \dfrac{\sqrt{8 + 2\sqrt{15}}}{\sqrt{2}}$.
  2. Sum 8, product 15: 5 and 3, so the top is $\sqrt{5} + \sqrt{3}$.
  3. $\dfrac{\sqrt{5} + \sqrt{3}}{\sqrt{2}}$; rationalise.

$\dfrac{\sqrt{10} + \sqrt{6}}{2}$

$\sqrt{7 - 4\sqrt{3}} = \sqrt{3} - 2$ is wrong: $\sqrt{3} - 2$ is negative and a square root cannot be. Larger minus smaller.
Always get the inner root into the form $2\sqrt{q}$ first: move a factor inside ($4\sqrt{3} = 2\sqrt{12}$) or multiply by $\dfrac{2}{2}$ (Example 3).
