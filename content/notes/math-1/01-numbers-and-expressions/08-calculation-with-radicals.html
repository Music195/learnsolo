Calculation with Radicals

Treat $\sqrt{2}$ like a letter

Roots multiply and divide nicely, but they do not add: $\sqrt{2} + \sqrt{3} \ne \sqrt{5}$. Simplify each root first, then collect "like" roots the way you collect $2x + 3x = 5x$.

Rules ($a > 0$, $b > 0$, $k > 0$)

$$\sqrt{a}\sqrt{b} = \sqrt{ab}, \qquad \frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}}, \qquad \sqrt{k^2a} = k\sqrt{a}$$

Simplest form: take every square factor out, so the number left under the root has no square factor.

Rationalising the denominator

$$\frac{1}{\sqrt{a}} = \frac{\sqrt{a}}{a}, \qquad \frac{1}{\sqrt{a} + \sqrt{b}} = \frac{\sqrt{a} - \sqrt{b}}{(\sqrt{a} + \sqrt{b})(\sqrt{a} - \sqrt{b})} = \frac{\sqrt{a} - \sqrt{b}}{a - b}$$

For a sum or difference in the denominator, multiply top and bottom by the same terms with the sign changed, and use $(x + y)(x - y) = x^2 - y^2$.

Simplify $\sqrt{n}$

Example 1

Simplify $\sqrt{50} - \sqrt{18} + \sqrt{8}$.

Show solution
  1. $5\sqrt{2} - 3\sqrt{2} + 2\sqrt{2}$

$4\sqrt{2}$

Example 2

Expand $(2\sqrt{3} + \sqrt{2})^2$.

Show solution
  1. $(2\sqrt{3})^2 + 2 \cdot 2\sqrt{3} \cdot \sqrt{2} + (\sqrt{2})^2 = 12 + 4\sqrt{6} + 2$

$14 + 4\sqrt{6}$

Example 3

Rationalise $\dfrac{6}{\sqrt{3}}$ and $\dfrac{2}{\sqrt{5} - \sqrt{3}}$.

Show solution
  1. $\dfrac{6\sqrt{3}}{3} = 2\sqrt{3}$
  2. $\dfrac{2(\sqrt{5} + \sqrt{3})}{5 - 3} = \sqrt{5} + \sqrt{3}$

$2\sqrt{3}$, $\;\sqrt{5} + \sqrt{3}$

Example 4

$x = \dfrac{1}{\sqrt{2} - 1}$, $y = \dfrac{1}{\sqrt{2} + 1}$. Find $x + y$, $xy$ and $x^2 + y^2$.

Show solution
  1. Rationalise: $x = \sqrt{2} + 1$, $y = \sqrt{2} - 1$.
  2. $x + y = 2\sqrt{2}$, $\;xy = 2 - 1 = 1$.
  3. $x^2 + y^2 = (x + y)^2 - 2xy = 8 - 2$.

$2\sqrt{2}$, $\;1$, $\;6$

$\sqrt{a} + \sqrt{b} \ne \sqrt{a + b}$. Check: $\sqrt{9} + \sqrt{16} = 7$, but $\sqrt{25} = 5$.
When asked for $x^2 + y^2$, $x^3 + y^3$ etc., find $x + y$ and $xy$ first; it is much quicker than substituting directly.
  • Multiply/divide under one root; never add under one root.
  • Pull out square factors: $\sqrt{72} = 6\sqrt{2}$.
  • Rationalise with $(x + y)(x - y) = x^2 - y^2$.
