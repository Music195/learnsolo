Equations and Inequalities with Absolute Value

Think "distance"

$|x| = 3$ asks for the points at distance 3 from $0$: $x = \pm 3$. $|x| < 3$ means closer than 3 (between $-3$ and $3$); $|x| > 3$ means farther than 3 (outside).

If the other side also contains $x$, split into cases instead (inside $\ge 0$ / inside $< 0$) and check each answer against its case.

For a constant $c > 0$

$$|x| = c \iff x = \pm c, \qquad |x| < c \iff -c < x < c, \qquad |x| > c \iff x < -c \text{ or } x > c$$

Replace $x$ by any expression: $|2x - 1| < 5 \iff -5 < 2x - 1 < 5$.

Where is $|x - a|$ below $c$?

Example 1

Solve $|x - 2| = 3$.

Show solution
  1. $x - 2 = 3$ or $x - 2 = -3$.

$x = 5, -1$

Example 2

Solve $|2x - 1| < 5$ and $|x + 1| \ge 3$.

Show solution
  1. $-5 < 2x - 1 < 5 \Rightarrow -4 < 2x < 6 \Rightarrow -2 < x < 3$.
  2. $x + 1 \le -3$ or $x + 1 \ge 3$.

$-2 < x < 3$; $\;x \le -4$ or $x \ge 2$

Example 3

Solve $|x - 1| = 2x - 5$.

Show solution
  1. Case $x \ge 1$: $x - 1 = 2x - 5 \Rightarrow x = 4$. Fits $x \ge 1$ ✓
  2. Case $x < 1$: $-(x - 1) = 2x - 5 \Rightarrow x = 2$. Does not fit $x < 1$ ✗

$x = 4$

Example 4

Solve $|x| + |x - 2| < 4$.

Show solution
  1. Split at $x = 0$ and $x = 2$.
  2. $x < 0$: $-x - (x - 2) < 4 \Rightarrow x > -1$, so $-1 < x < 0$.
  3. $0 \le x < 2$: $x - (x - 2) = 2 < 4$, always true, so $0 \le x < 2$.
  4. $x \ge 2$: $x + x - 2 < 4 \Rightarrow x < 3$, so $2 \le x < 3$.
  5. Join the three pieces.

$-1 < x < 3$

When you split into cases, every answer must lie in its own case. In Example 3, $x = 2$ solves the equation of the second case but breaks $x < 1$, so it is rejected.
$|x| \ge 0$ always, so $|x| = -2$ and $|x| < 0$ have no solution, while $|x| > -2$ holds for every $x$.
  • $|X| = c$ → $X = \pm c$; $|X| < c$ → between; $|X| > c$ → outside.
  • $x$ on both sides → split at the point where the inside is 0.
  • Keep only answers that fit their case; join the pieces at the end.
