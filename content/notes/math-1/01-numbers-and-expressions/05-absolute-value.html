Absolute Value

Distance from 0

$|a|$ is the distance between $a$ and $0$ on the number line, so it is never negative: $|5| = 5$ and $|-5| = 5$.

More generally, $|a - b|$ is the distance between the points $a$ and $b$.

Definition

$$|a| = \begin{cases} a & (a \ge 0) \\ -a & (a < 0) \end{cases}$$

If $a$ is negative, $-a$ is positive. For example $|-3| = -(-3) = 3$.

Properties

$$|a| \ge 0, \qquad |-a| = |a|, \qquad |ab| = |a||b|, \qquad |a|^2 = a^2$$

Example 2

Find $|\sqrt{2} - 2|$.

Show solution
  1. $\sqrt{2} \approx 1.41 < 2$, so $\sqrt{2} - 2 < 0$.
  2. Negative inside, so take the negative: $-(\sqrt{2} - 2)$.

$2 - \sqrt{2}$

Example 3

Write $|x - 3| + |x + 1|$ without absolute value signs when $-1 \le x < 3$.

Show solution
  1. $x - 3 < 0$, so $|x - 3| = -(x - 3) = 3 - x$.
  2. $x + 1 \ge 0$, so $|x + 1| = x + 1$.
  3. Add: $(3 - x) + (x + 1)$.

$|-a|$ is not always $a$. If $a = -2$, then $|-a| = |2| = 2 = -a$. Always ask: is the inside positive or negative?
The cases change where the inside equals $0$. For $|x - 3|$ split at $x = 3$; for $|2x + 1|$ split at $x = -\dfrac{1}{2}$. Equations and inequalities with absolute values are in note 11.
  • $|a|$ = distance from $0$; $|a - b|$ = distance between $a$ and $b$.
