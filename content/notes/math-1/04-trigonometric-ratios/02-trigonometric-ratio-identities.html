Trigonometric Ratio Identities

Know one ratio, find the other two

$\sin\theta$, $\cos\theta$ and $\tan\theta$ come from the same triangle, so they are tied together. The three relations below let you find all three from any one of them.

Relations

$$\tan\theta = \frac{\sin\theta}{\cos\theta}, \qquad \sin^2\theta + \cos^2\theta = 1, \qquad 1 + \tan^2\theta = \frac{1}{\cos^2\theta}$$

$\sin^2\theta$ means $(\sin\theta)^2$.

  1. Take a right triangle with hypotenuse $r$, adjacent side $x$, opposite side $y$, so $\sin\theta = \dfrac{y}{r}$, $\cos\theta = \dfrac{x}{r}$.
  2. $\dfrac{\sin\theta}{\cos\theta} = \dfrac{y/r}{x/r} = \dfrac{y}{x} = \tan\theta$.
  3. Pythagoras: $x^2 + y^2 = r^2$. Divide by $r^2$: $\cos^2\theta + \sin^2\theta = 1$.
  4. Divide $\sin^2\theta + \cos^2\theta = 1$ by $\cos^2\theta$: $\tan^2\theta + 1 = \dfrac{1}{\cos^2\theta}$.

From one ratio to all three (acute $\theta$)

Example 1

$\theta$ is acute and $\sin\theta = \dfrac{3}{5}$. Find $\cos\theta$ and $\tan\theta$.

Show solution
  1. $\cos^2\theta = 1 - \dfrac{9}{25} = \dfrac{16}{25}$, and $\cos\theta > 0$, so $\cos\theta = \dfrac{4}{5}$.
  2. $\tan\theta = \dfrac{3/5}{4/5}$

$\cos\theta = \dfrac{4}{5}$, $\tan\theta = \dfrac{3}{4}$

Example 2

$\theta$ is acute and $\tan\theta = 2$. Find $\cos\theta$ and $\sin\theta$.

Show solution
  1. $\dfrac{1}{\cos^2\theta} = 1 + 4 = 5$, so $\cos\theta = \dfrac{1}{\sqrt{5}}$.
  2. $\sin\theta = \tan\theta \cos\theta = \dfrac{2}{\sqrt{5}}$

$\cos\theta = \dfrac{\sqrt{5}}{5}$, $\sin\theta = \dfrac{2\sqrt{5}}{5}$

Example 3

$\sin\theta + \cos\theta = \dfrac{1}{2}$. Find $\sin\theta\cos\theta$.

Show solution
  1. Square both sides: $\sin^2\theta + 2\sin\theta\cos\theta + \cos^2\theta = \dfrac{1}{4}$.
  2. $1 + 2\sin\theta\cos\theta = \dfrac{1}{4}$

$\sin\theta\cos\theta = -\dfrac{3}{8}$

$\cos^2\theta = \dfrac{16}{25}$ gives $\cos\theta = \pm\dfrac{4}{5}$. Use the size of $\theta$ to choose the sign: for an acute angle it is $+$, for $90° < \theta < 180°$ cosine is negative (note 04).
  • $\tan\theta = \dfrac{\sin\theta}{\cos\theta}$.
  • $\sin^2\theta + \cos^2\theta = 1$ (Pythagoras divided by $r^2$).
  • $1 + \tan^2\theta = \dfrac{1}{\cos^2\theta}$: use it when $\tan\theta$ is given.
