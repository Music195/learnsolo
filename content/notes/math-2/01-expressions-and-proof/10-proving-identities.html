Proving Identities A = B

Three ways to show $A = B$

Never start by writing "$A = B$" and working on both sides at once: that assumes what you want to prove. Instead:

  • change $A$ step by step until it becomes $B$ (or $B$ into $A$);
  • change both $A$ and $B$ separately into the same expression $C$;
  • show $A - B = 0$.

With a condition such as $a + b + c = 0$, use it to remove one letter. With a ratio $\dfrac{a}{b} = \dfrac{c}{d}$, set both equal to $k$.

Using a condition

$$a + b + c = 0 \;\Rightarrow\; c = -(a + b), \qquad \frac{a}{b} = \frac{c}{d} = k \;\Rightarrow\; a = bk,\; c = dk$$
  1. Prove $(a^2 + b^2)(c^2 + d^2) = (ac + bd)^2 + (ad - bc)^2$.
  2. Left: $a^2c^2 + a^2d^2 + b^2c^2 + b^2d^2$.
  3. Right: $(a^2c^2 + 2abcd + b^2d^2) + (a^2d^2 - 2abcd + b^2c^2) = a^2c^2 + a^2d^2 + b^2c^2 + b^2d^2$.
  4. Both sides equal the same expression, so the identity holds.

If $a + b + c = 0$, then $a^2 - bc = b^2 - ca = c^2 - ab$

Example 1

$a + b + c = 0$. Prove $a^2 - bc = b^2 - ca$.

Show solution
  1. $c = -a - b$. Left: $a^2 - b(-a - b) = a^2 + ab + b^2$.
  2. Right: $b^2 - (-a - b)a = a^2 + ab + b^2$.

Both sides equal $a^2 + ab + b^2$.

Example 2

$\dfrac{a}{b} = \dfrac{c}{d}$ with $b \ne d$. Prove $\dfrac{a + c}{b + d} = \dfrac{a - c}{b - d}$ (assume $b + d \ne 0$).

Show solution
  1. Let $\dfrac{a}{b} = \dfrac{c}{d} = k$, so $a = bk$, $c = dk$.
  2. Left: $\dfrac{(b + d)k}{b + d} = k$. Right: $\dfrac{(b - d)k}{b - d} = k$.

Both sides equal $k$.

Example 3

$\dfrac{x}{2} = \dfrac{y}{3} = \dfrac{z}{4} \ne 0$. Find $\dfrac{x + y + z}{x - y + z}$.

Show solution
  1. Set each equal to $k$: $x = 2k$, $y = 3k$, $z = 4k$.
  2. $\dfrac{9k}{3k}$.

$3$

A chain that starts from "$A = B$" and ends in something true (like $0 = 0$) proves nothing. Write $A = \cdots = B$, or $A - B = \cdots = 0$.
Start from the more complicated side; it has more to simplify.
  • $A \to B$, or $A \to C \leftarrow B$, or $A - B \to 0$.
  • Condition $a + b + c = 0$: remove one letter.
  • Ratio $\dfrac{a}{b} = \dfrac{c}{d}$: put both equal to $k$.
