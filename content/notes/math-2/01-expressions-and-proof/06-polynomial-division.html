Polynomial Division

Long division with powers of $x$

Dividing polynomials works like long division of numbers: divide the leading terms, multiply back, subtract, repeat. Stop when what is left has a lower degree than the divisor; that is the remainder.

Dividing $A$ by $B$

$$A = BQ + R, \qquad (\text{degree of } R) < (\text{degree of } B)$$

$Q$: quotient; $R$: remainder. "$A$ is divisible by $B$" means $R = 0$.

  1. $(x^3 + 2x^2 - x + 1) \div (x - 1)$: $x^3 \div x = x^2$; subtract $x^2(x - 1)$, leaving $3x^2 - x + 1$.
  2. $3x^2 \div x = 3x$; subtract $3x(x - 1)$, leaving $2x + 1$.
  3. $2x \div x = 2$; subtract $2(x - 1)$, leaving $3$ (degree 0 < 1, stop).
  4. So $x^3 + 2x^2 - x + 1 = (x - 1)(x^2 + 3x + 2) + 3$.

Divide any two polynomials

Example 1

Divide $2x^3 - 3x^2 + 4x - 5$ by $x + 1$.

Show solution
  1. $2x^2$: subtract $2x^3 + 2x^2$, leaving $-5x^2 + 4x - 5$.
  2. $-5x$: subtract $-5x^2 - 5x$, leaving $9x - 5$.
  3. $+9$: subtract $9x + 9$, leaving $-14$.

Quotient $2x^2 - 5x + 9$, remainder $-14$

Example 2

Divide $x^4 + x^2 + 1$ by $x^2 + x + 1$.

Show solution
  1. Write the missing powers with $0$: $x^4 + 0x^3 + x^2 + 0x + 1$.
  2. $x^2$: leaves $-x^3 + 0x^2 + 0x + 1$. $\;-x$: leaves $x^2 + x + 1$. $\;+1$: leaves $0$.

Quotient $x^2 - x + 1$, remainder $0$

Example 3

Dividing $A$ by $x^2 - 1$ gives quotient $x + 2$ and remainder $3x - 1$. Find $A$.

Show solution
  1. $A = (x^2 - 1)(x + 2) + 3x - 1 = x^3 + 2x^2 - x - 2 + 3x - 1$.

$A = x^3 + 2x^2 + 2x - 3$

Example 4

Dividing $x^3 + ax + 2$ by $x^2 + x + 1$ leaves remainder $3x + 3$. Find $a$.

Show solution
  1. The quotient starts with $x$, then $-1$: $(x^2 + x + 1)(x - 1) = x^3 - 1$.
  2. So $x^3 + ax + 2 = (x^2 + x + 1)(x - 1) + ax + 3$, and $ax + 3$ has degree < 2: it is the remainder.
  3. $ax + 3 = 3x + 3$.

$a = 3$

Leave a gap (write $0$) for every missing power, e.g. $x^3 - 1 = x^3 + 0x^2 + 0x - 1$. Otherwise the columns slip and the answer is wrong.
Check every division by multiplying back: $BQ + R$ must give $A$ again.
  • $A = BQ + R$ with $\deg R < \deg B$.
  • Divide leading terms → multiply → subtract → repeat.
  • Write $0$ for missing powers.
