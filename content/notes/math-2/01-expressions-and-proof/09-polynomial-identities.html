Properties of Polynomial Identities

True for every $x$, not just some

An equation like $x^2 = 4$ holds only for some $x$. An identity (恒等式) like $(x + 1)^2 = x^2 + 2x + 1$ holds for every $x$.

Two polynomials are identical exactly when their coefficients match. Two ways to find unknown coefficients: compare coefficients, or substitute convenient values of $x$.

Identity in $x$

$$ax^2 + bx + c = a'x^2 + b'x + c' \text{ is an identity} \iff a = a',\; b = b',\; c = c'$$

In particular $ax^2 + bx + c = 0$ is an identity $\iff a = b = c = 0$.

  1. Suppose $ax^2 + bx + c = 0$ for every $x$. Put $x = 0$: $c = 0$.
  2. Put $x = 1$ and $x = -1$: $a + b = 0$ and $a - b = 0$, so $a = b = 0$.
  3. For two polynomials, apply this to their difference $(a - a')x^2 + (b - b')x + (c - c')$.

Make $ax^2 + bx + c$ identical to $2x^2 - 3x + 1$

Example 1 (compare coefficients)

Find $a, b, c$ so that $x^2 + 3x - 1 = a(x - 1)^2 + b(x - 1) + c$ is an identity.

Show solution
  1. Right side: $ax^2 + (b - 2a)x + (a - b + c)$.
  2. $a = 1$; $\;b - 2 = 3 \Rightarrow b = 5$; $\;1 - 5 + c = -1 \Rightarrow c = 3$.

$a = 1,\; b = 5,\; c = 3$

Example 2 (substitute values)

Find $a, b, c$ so that $3x^2 - x + 2 = a(x - 1)(x - 2) + b(x - 1) + c$ is an identity.

Show solution
  1. $x = 1$: $4 = c$. $\;x = 2$: $12 = b + c$, so $b = 8$. $\;x = 0$: $2 = 2a - b + c$, so $a = 3$.
  2. Check: both sides have degree 2 and agree at 3 values of $x$, so they are identical (see the demo).

$a = 3,\; b = 8,\; c = 4$

Example 3 (partial fractions)

Find $a, b$ with $\dfrac{x + 5}{(x + 1)(x - 1)} = \dfrac{a}{x + 1} + \dfrac{b}{x - 1}$ for all $x \ne \pm 1$.

Show solution
  1. Multiply by $(x + 1)(x - 1)$: $x + 5 = a(x - 1) + b(x + 1)$, an identity.
  2. Compare: $a + b = 1$ and $-a + b = 5$.

$a = -2,\; b = 3$

Substituting values only gives necessary conditions. You must then confirm the identity, either by expanding, or by noting that two polynomials of degree $n$ that agree at $n + 1$ values of $x$ are identical.
Choose values that make brackets zero ($x = 1$, $x = 2$ in Example 2): each one leaves a single unknown.
  • Identity ⇔ all coefficients equal.
  • Method 1: expand and compare coefficients.
  • Method 2: substitute values, then confirm.
