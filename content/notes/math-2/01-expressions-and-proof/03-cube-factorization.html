Cubic Factorization Formulas

Read note 02 backwards

To factorise, first write each term as a cube: $8x^3 = (2x)^3$, $27 = 3^3$. Then the formulas of note 02, read from right to left, give the factors.

For three letters there is a longer formula for $a^3 + b^3 + c^3 - 3abc$. It is used when $a + b + c = 0$.

Sum and difference of cubes

$$a^3 + b^3 = (a + b)(a^2 - ab + b^2)$$
$$a^3 - b^3 = (a - b)(a^2 + ab + b^2)$$

Three cubes

$$a^3 + b^3 + c^3 - 3abc = (a + b + c)(a^2 + b^2 + c^2 - ab - bc - ca)$$

So if $a + b + c = 0$, then $a^3 + b^3 + c^3 = 3abc$.

  1. Let $s = a + b$. By note 02, $a^3 + b^3 = s^3 - 3abs$.
  2. So $a^3 + b^3 + c^3 - 3abc = (s^3 + c^3) - 3ab(s + c) = (s + c)(s^2 - sc + c^2) - 3ab(s + c)$.
  3. $= (s + c)(s^2 - 3ab - sc + c^2)$, and $s^2 - 3ab = a^2 - ab + b^2$, $sc = ac + bc$.
  4. This gives $(a + b + c)(a^2 + b^2 + c^2 - ab - bc - ca)$.

Factorise $Mx^3 \pm N$

Example 1

Factorise $x^3 + 27$ and $8a^3 - 125b^3$.

Show solution
  1. $x^3 + 3^3 = (x + 3)(x^2 - 3x + 9)$.
  2. $(2a)^3 - (5b)^3 = (2a - 5b)\{(2a)^2 + (2a)(5b) + (5b)^2\}$.

$(x + 3)(x^2 - 3x + 9)$; $\;(2a - 5b)(4a^2 + 10ab + 25b^2)$

Example 2

Factorise $x^6 - 64$ completely.

Show solution
  1. Difference of squares first: $(x^3)^2 - 8^2 = (x^3 - 8)(x^3 + 8)$.
  2. Then each cube: $x^3 - 8 = (x - 2)(x^2 + 2x + 4)$, $x^3 + 8 = (x + 2)(x^2 - 2x + 4)$.

$(x - 2)(x + 2)(x^2 + 2x + 4)(x^2 - 2x + 4)$

Example 3

Factorise $x^3 - 3x^2 + 3x - 1 - y^3$.

Show solution
  1. The first four terms are $(x - 1)^3$ (note 01).
  2. $(x - 1)^3 - y^3 = (x - 1 - y)\{(x - 1)^2 + (x - 1)y + y^2\}$.

$(x - y - 1)(x^2 + xy + y^2 - 2x - y + 1)$

Example 4

$a + b + c = 0$ and $abc = 2$. Find $a^3 + b^3 + c^3$.

Show solution
  1. From the three-cubes formula, $a^3 + b^3 + c^3 - 3abc = 0 \times (\cdots) = 0$.

$a^3 + b^3 + c^3 = 3abc = 6$

$a^2 - ab + b^2$ is not $(a - b)^2$: its middle term is $-ab$, not $-2ab$. It cannot be factorised further over the real numbers.
For $x^6 - y^6$, use the difference of squares first and the cube formulas second. This gives four factors straight away.
  • $a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)$.
  • Write each term as a cube first: $8x^3 = (2x)^3$.
  • $a + b + c = 0 \Rightarrow a^3 + b^3 + c^3 = 3abc$.
