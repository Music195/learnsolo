Addition & Subtraction of Fractional Expressions

Common denominator, then add the numerators

As with numbers, fractions can only be added when they have the same denominator. Factorise the denominators, build the lowest common denominator, then add the numerators and simplify.

Working backwards, splitting one fraction into a difference of two (partial fractions) makes long sums cancel.

Adding and splitting

$$\frac{A}{C} \pm \frac{B}{C} = \frac{A \pm B}{C}, \qquad \frac{A}{B} \pm \frac{C}{D} = \frac{AD \pm BC}{BD}$$
$$\frac{1}{k(k + 1)} = \frac{1}{k} - \frac{1}{k + 1}$$

$\dfrac{1}{1 \cdot 2} + \dfrac{1}{2 \cdot 3} + \cdots + \dfrac{1}{n(n + 1)}$ on the number line

Example 1

Calculate $\dfrac{x + 1}{x - 1} + \dfrac{x + 2}{x + 3}$.

Show solution
  1. $\dfrac{(x + 1)(x + 3) + (x + 2)(x - 1)}{(x - 1)(x + 3)} = \dfrac{(x^2 + 4x + 3) + (x^2 + x - 2)}{(x - 1)(x + 3)}$.

$\dfrac{2x^2 + 5x + 1}{(x - 1)(x + 3)}$

Example 2

Calculate $\dfrac{2}{x^2 - 1} - \dfrac{1}{x^2 - x}$.

Show solution
  1. Factorise: $\dfrac{2}{(x - 1)(x + 1)} - \dfrac{1}{x(x - 1)}$. Common denominator $x(x - 1)(x + 1)$.
  2. Numerator: $2x - (x + 1) = x - 1$, which cancels with the denominator.

$\dfrac{1}{x(x + 1)}$

Example 3

Calculate $\dfrac{1}{x(x + 1)} + \dfrac{1}{(x + 1)(x + 2)} + \dfrac{1}{(x + 2)(x + 3)}$.

Show solution
  1. Split each one: $\left(\dfrac{1}{x} - \dfrac{1}{x + 1}\right) + \left(\dfrac{1}{x + 1} - \dfrac{1}{x + 2}\right) + \left(\dfrac{1}{x + 2} - \dfrac{1}{x + 3}\right)$.
  2. The middle terms cancel: $\dfrac{1}{x} - \dfrac{1}{x + 3}$.

$\dfrac{3}{x(x + 3)}$

When subtracting, put the whole second numerator in brackets: $\dfrac{2x - (x + 1)}{\cdots}$, not $\dfrac{2x - x + 1}{\cdots}$.
Factorise the denominators first and use each factor once (Example 2 uses $x(x - 1)(x + 1)$, not $(x^2 - 1)(x^2 - x)$). The working stays smaller.
  • Factorise denominators → lowest common denominator → add numerators → simplify.
  • $\dfrac{1}{k(k + 1)} = \dfrac{1}{k} - \dfrac{1}{k + 1}$: sums of these cancel in a chain.
  • Brackets round the numerator you subtract.
