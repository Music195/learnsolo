Cube Expansion Formulas 2

Six products, four cancel

Multiply $(a + b)$ by $(a^2 - ab + b^2)$: there are $2 \times 3 = 6$ products. The $a^2b$ terms cancel and the $ab^2$ terms cancel, leaving only $a^3 + b^3$. The second bracket is chosen exactly so that this happens.

The same idea, with signs changed, gives $a^3 - b^3$.

Products giving the sum / difference of cubes

$$(a + b)(a^2 - ab + b^2) = a^3 + b^3$$
$$(a - b)(a^2 + ab + b^2) = a^3 - b^3$$

Useful link with note 01: $a^3 + b^3 = (a + b)^3 - 3ab(a + b)$.

  1. $(a + b)(a^2 - ab + b^2) = a^3 - a^2b + ab^2 + a^2b - ab^2 + b^3 = a^3 + b^3$.
  2. $(a - b)(a^2 + ab + b^2) = a^3 + a^2b + ab^2 - a^2b - ab^2 - b^3 = a^3 - b^3$.
  3. From note 01, $(a + b)^3 = a^3 + b^3 + 3ab(a + b)$, so $a^3 + b^3 = (a + b)^3 - 3ab(a + b)$.

Expand $(px + q)(p^2x^2 - pqx + q^2)$ term by term

Example 1

Expand $(x + 2)(x^2 - 2x + 4)$ and $(3x - 1)(9x^2 + 3x + 1)$.

Show solution
  1. First: $a = x$, $b = 2$, so $x^3 + 2^3$.
  2. Second: $a = 3x$, $b = 1$, so $(3x)^3 - 1^3$.

$x^3 + 8$; $\;27x^3 - 1$

Example 2

Expand $(x + 1)(x - 1)(x^2 + x + 1)(x^2 - x + 1)$.

Show solution
  1. Pair them: $(x + 1)(x^2 - x + 1) = x^3 + 1$ and $(x - 1)(x^2 + x + 1) = x^3 - 1$.
  2. $(x^3 + 1)(x^3 - 1) = x^6 - 1$.

$x^6 - 1$

Example 3

$a + b = 3$ and $ab = 1$. Find $a^3 + b^3$.

Show solution
  1. $a^3 + b^3 = (a + b)^3 - 3ab(a + b) = 27 - 3 \cdot 1 \cdot 3$.

$18$

The sign in the middle of the long bracket is the opposite of the sign in the short bracket: $(a + b)$ goes with $-ab$, $(a - b)$ goes with $+ab$.
To spot the pattern, check that the long bracket is (first)² ∓ (first)(second) + (second)², built from the two terms of the short bracket.
  • $(a + b)(a^2 - ab + b^2) = a^3 + b^3$.
  • $(a - b)(a^2 + ab + b^2) = a^3 - b^3$.
  • $a^3 + b^3 = (a + b)^3 - 3ab(a + b)$ when you know $a + b$ and $ab$.
