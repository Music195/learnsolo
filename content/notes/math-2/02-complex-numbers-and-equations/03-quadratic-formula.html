Quadratic Formula

Every quadratic equation now has solutions

In Mathematics 1, a negative number under the root meant "no real solution". With complex numbers, $\sqrt{-16} = 4i$, so the same formula gives two imaginary solutions (虚数解). They always come as a conjugate pair $p \pm qi$ when $a, b, c$ are real.

Quadratic formula ($a, b, c$ real, $a \ne 0$)

$$ax^2 + bx + c = 0 \iff x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

With $b = 2b'$: $x = \dfrac{-b' \pm \sqrt{b'^2 - ac}}{a}$. If $b^2 - 4ac < 0$, write $\sqrt{b^2 - 4ac} = \sqrt{4ac - b^2}\;i$.

Solve $ax^2 + bx + c = 0$

Example 1

Solve $x^2 + 2x + 5 = 0$.

Show solution
  1. $b' = 1$: $x = -1 \pm \sqrt{1 - 5} = -1 \pm \sqrt{-4}$

$x = -1 \pm 2i$

Example 2

Solve $2x^2 - 2x + 1 = 0$.

Show solution
  1. $b' = -1$: $x = \dfrac{1 \pm \sqrt{1 - 2}}{2} = \dfrac{1 \pm i}{2}$

$x = \dfrac{1 \pm i}{2}$

Example 3

Solve $3x^2 + 2x + 1 = 0$.

Show solution
  1. $b' = 1$: $x = \dfrac{-1 \pm \sqrt{1 - 3}}{3} = \dfrac{-1 \pm \sqrt{2}\,i}{3}$

$x = \dfrac{-1 \pm \sqrt{2}\,i}{3}$

Example 4

Solve $x^4 - x^2 - 6 = 0$.

Show solution
  1. Let $t = x^2$: $t^2 - t - 6 = 0 \Rightarrow (t - 3)(t + 2) = 0$.
  2. $x^2 = 3 \Rightarrow x = \pm\sqrt{3}$; $\;x^2 = -2 \Rightarrow x = \pm\sqrt{2}\,i$.

$x = \pm\sqrt{3}, \pm\sqrt{2}\,i$

Write answers in the form $p + qi$: $\dfrac{-4 \pm 6i}{2} = -2 \pm 3i$. Divide both the real and imaginary parts.
Check with note 05: the two solutions must add to $-\dfrac{b}{a}$ and multiply to $\dfrac{c}{a}$. For Example 1: $(-1 + 2i) + (-1 - 2i) = -2$ ✓ and $(-1)^2 + 2^2 = 5$ ✓.
  • The same formula; a negative under the root gives $\pm$ an imaginary part.
  • Real coefficients → imaginary solutions come as $p \pm qi$.
  • Substitute $t = x^2$ for $x^4 + \ldots$ equations.
