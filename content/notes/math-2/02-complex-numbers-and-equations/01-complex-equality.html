Complex Equality

A new number $i$ with $i^2 = -1$

No real number squares to $-1$, so we add one: the imaginary unit $i$, with $i^2 = -1$. A complex number is $a + bi$ with $a, b$ real: $a$ is the real part and $b$ the imaginary part.

Calculate exactly as with letters, then replace every $i^2$ by $-1$.

Equality ($a, b, c, d$ real)

$$a + bi = c + di \iff a = c \text{ and } b = d, \qquad a + bi = 0 \iff a = 0 \text{ and } b = 0$$

One complex equation gives two real equations. The "real" condition matters: with complex $a, b$ this fails.

Conjugate and division

$$\overline{a + bi} = a - bi, \qquad (a + bi)(a - bi) = a^2 + b^2, \qquad \frac{c + di}{a + bi} = \frac{(c + di)(a - bi)}{a^2 + b^2}$$

To divide, multiply top and bottom by the conjugate of the bottom, the same idea as rationalising.

Calculate with $z = a + bi$ and $w = c + di$

Example 1

Calculate $(2 + 3i)(1 - 2i)$.

Show solution
  1. $2 - 4i + 3i - 6i^2 = 2 - i + 6$

$8 - i$

Example 2

Calculate $\dfrac{1 + 2i}{2 - i}$.

Show solution
  1. $\dfrac{(1 + 2i)(2 + i)}{(2 - i)(2 + i)} = \dfrac{2 + i + 4i + 2i^2}{4 + 1} = \dfrac{5i}{5}$

$i$

Example 3

Find real $x, y$ with $(2x + 3) + (x + 2y)i = 7 + 5i$.

Show solution
  1. Real parts: $2x + 3 = 7 \Rightarrow x = 2$.
  2. Imaginary parts: $x + 2y = 5 \Rightarrow y = \dfrac{3}{2}$.

$x = 2$, $y = \dfrac{3}{2}$

Example 4

Find real $x, y$ with $(x + yi)(2 - i) = 5$.

Show solution
  1. Expand: $(2x + y) + (2y - x)i = 5$.
  2. $2x + y = 5$ and $2y - x = 0$ give $x = 2$, $y = 1$.

$x = 2$, $y = 1$

Before comparing parts, write both sides in the form (real) + (real)$\,i$. And check that $x, y$ are stated to be real.
$z + \overline{z} = 2a$ and $z\overline{z} = a^2 + b^2$ are always real. This is why multiplying by the conjugate clears $i$ from a denominator.

  • Equal ⟺ real parts equal and imaginary parts equal.
  • Divide by multiplying by the conjugate of the denominator.
