Quadratic Factorization

Solve, then write the factors

If you can solve $ax^2 + bx + c = 0$, you can factorise $ax^2 + bx + c$, even when it doesn't factorise with whole numbers. With complex numbers allowed, every quadratic factorises into two linear factors.

If $\alpha, \beta$ are the roots of $ax^2 + bx + c = 0$

$$ax^2 + bx + c = a(x - \alpha)(x - \beta)$$

Don't forget the leading $a$ in front.

Factorise $ax^2 + bx + c$ using its roots

Example 1

Factorise $x^2 + 4x + 5$ (complex numbers allowed).

Show solution
  1. Roots: $x = -2 \pm \sqrt{4 - 5} = -2 \pm i$.
  2. $\{x - (-2 + i)\}\{x - (-2 - i)\}$

$(x + 2 - i)(x + 2 + i)$

Example 2

Factorise $2x^2 - 4x + 1$.

Show solution
  1. Roots: $x = \dfrac{2 \pm \sqrt{4 - 2}}{2} = \dfrac{2 \pm \sqrt{2}}{2}$.
  2. Keep the 2 in front.

$2\left(x - \dfrac{2 + \sqrt{2}}{2}\right)\left(x - \dfrac{2 - \sqrt{2}}{2}\right)$

Example 3

Factorise $x^4 - 4$ (i) with rational numbers (ii) with real numbers (iii) with complex numbers.

Show solution
  1. (i) $(x^2 - 2)(x^2 + 2)$
  2. (ii) $x^2 - 2 = (x + \sqrt{2})(x - \sqrt{2})$
  3. (iii) $x^2 + 2 = (x + \sqrt{2}\,i)(x - \sqrt{2}\,i)$

(iii) $(x + \sqrt{2})(x - \sqrt{2})(x + \sqrt{2}\,i)(x - \sqrt{2}\,i)$

Example 4

Factorise $3x^2 - 10x + 8$.

Show solution
  1. Roots $x = \dfrac{5 \pm \sqrt{25 - 24}}{3} = 2, \dfrac{4}{3}$.
  2. $3(x - 2)\left(x - \dfrac{4}{3}\right)$; move the 3 into the second bracket.

$(x - 2)(3x - 4)$

"Factorise" depends on which numbers are allowed. Unless told otherwise, use rational numbers. Only go to $\sqrt{\ }$ or $i$ when asked.
  • $ax^2 + bx + c = a(x - \alpha)(x - \beta)$.
  • Find $\alpha, \beta$ with the quadratic formula.
  • With complex numbers, every quadratic splits into two linear factors.
