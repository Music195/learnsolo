Exponential Function Properties

Same base → compare the exponents

Because $y = a^x$ is always increasing ($a > 1$) or always decreasing ($0 < a < 1$), each $y$ comes from exactly one $x$. So once both sides are powers of the same base, you can compare the exponents directly.

Equations and inequalities

$$a^p = a^q \iff p = q$$
$$a > 1: \; a^p < a^q \iff p < q \qquad\quad 0 < a < 1: \; a^p < a^q \iff p > q$$

With a base between 0 and 1, the inequality sign flips when you compare exponents.

Example 1

Solve $8^x = 4^{x+1}$.

Show solution
  1. Base 2: $2^{3x} = 2^{2x + 2}$, so $3x = 2x + 2$.

$x = 2$

Example 2

Solve $4^x - 3 \cdot 2^x - 4 = 0$.

Show solution
  1. Let $t = 2^x$ ($t > 0$): $t^2 - 3t - 4 = 0 \Rightarrow (t - 4)(t + 1) = 0$.
  2. $t > 0$, so $t = 4$ ($t = -1$ is rejected): $2^x = 4$.

$x = 2$

Example 3

Solve $\left(\dfrac{1}{3}\right)^x > 9$.

Show solution
  1. $9 = \left(\dfrac{1}{3}\right)^{-2}$: $\left(\dfrac{1}{3}\right)^x > \left(\dfrac{1}{3}\right)^{-2}$.
  2. Base less than 1: flip. $x < -2$.

$x < -2$

Example 4

Put $\sqrt{2}$, $\sqrt[3]{3}$, $\sqrt[6]{6}$ in increasing order.

Show solution
  1. All are positive, so compare their 6th powers: $(\sqrt{2})^6 = 8$, $(\sqrt[3]{3})^6 = 9$, $(\sqrt[6]{6})^6 = 6$.

$\sqrt[6]{6} < \sqrt{2} < \sqrt[3]{3}$

When you substitute $t = a^x$, remember $t > 0$. Throw away any $t \le 0$ before going back to $x$.
Write every number as a power of the same small base: $8 = 2^3$, $\dfrac{1}{4} = 2^{-2}$, $\sqrt{2} = 2^{\frac{1}{2}}$.
  • Same base: compare exponents.
  • Base between 0 and 1: flip the inequality.
  • $a^{2x}$ and $a^x$ together: let $t = a^x > 0$.
