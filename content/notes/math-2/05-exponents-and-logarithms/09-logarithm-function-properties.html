Logarithm Function Properties

Same base → compare the antilogarithms

$y = \log_a x$ is always increasing or always decreasing, so $\log_a p = \log_a q$ only when $p = q$, and an inequality between logs becomes one between the antilogarithms.

First write down the conditions: every antilogarithm must be positive. Check your answers against them at the end.

For $p, q > 0$

$$\log_a p = \log_a q \iff p = q$$
$$a > 1: \; \log_a p < \log_a q \iff p < q \qquad\quad 0 < a < 1: \; \log_a p < \log_a q \iff p > q$$

Solve $\log_a x > c$ from the graph

Example 1

Solve $\log_2 (x - 1) + \log_2 (x + 1) = 3$.

Show solution
  1. Conditions: $x - 1 > 0$ and $x + 1 > 0$, i.e. $x > 1$.
  2. $\log_2 (x^2 - 1) = 3 \Rightarrow x^2 - 1 = 8 \Rightarrow x = \pm 3$.
  3. Only $x = 3$ satisfies $x > 1$.

$x = 3$

Example 2

Solve $\log_{\frac{1}{2}} x > 2$.

Show solution
  1. Condition $x > 0$. $\;2 = \log_{\frac{1}{2}} \dfrac{1}{4}$.
  2. Base less than 1: flip. $x < \dfrac{1}{4}$.

$0 < x < \dfrac{1}{4}$

Example 3

Solve $(\log_2 x)^2 - \log_2 x - 2 = 0$.

Show solution
  1. Let $t = \log_2 x$ (any real $t$): $(t - 2)(t + 1) = 0$.
  2. $\log_2 x = 2$ or $-1$.

$x = 4, \dfrac{1}{2}$

Example 4

Put $\log_2 3$, $\;\log_4 5$, $\;\dfrac{3}{2}$ in increasing order.

Show solution
  1. Base 2 for all: $\log_4 5 = \dfrac{\log_2 5}{2} = \log_2 \sqrt{5}$, and $\dfrac{3}{2} = \log_2 2\sqrt{2} = \log_2 \sqrt{8}$.
  2. Compare $\sqrt{5} < \sqrt{8} < 3$ (base 2 > 1 keeps the order).

$\log_4 5 < \dfrac{3}{2} < \log_2 3$

Always state the antilogarithm conditions first. In Example 1, $x = -3$ solves $x^2 - 1 = 8$ but makes $\log_2(x - 1)$ meaningless.
As with exponentials: base $> 1$ keeps the inequality, base between 0 and 1 flips it.
  • Conditions first: antilogarithms $> 0$.
  • Same base, then compare antilogarithms (flip if $0 < a < 1$).
  • $\log_a x$ appearing squared: let $t = \log_a x$.
