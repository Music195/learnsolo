Power Function Indefinite Integral

Differentiation run backwards

An antiderivative (原始関数) of $f(x)$ is any $F(x)$ with $F'(x) = f(x)$. Since constants differentiate to $0$, $F(x) + C$ works for every constant $C$. All of them together are the indefinite integral $\displaystyle\int f(x)\,dx$.

Rules ($n = 0, 1, 2, \ldots$; $C$ is the constant of integration)

$$\int x^n\,dx = \frac{x^{n+1}}{n + 1} + C, \qquad \int \{kf(x) + lg(x)\}\,dx = k\!\int f(x)\,dx + l\!\int g(x)\,dx$$

Raise the power by 1, then divide by the new power. $\displaystyle\int 1\,dx = x + C$.

$\displaystyle\int (x^2 - 1)\,dx = \frac{x^3}{3} - x + C$: change $C$

Example 1

Find $\displaystyle\int (3x^2 - 4x + 5)\,dx$.

Show solution
  1. $3 \cdot \dfrac{x^3}{3} - 4 \cdot \dfrac{x^2}{2} + 5x + C$

$x^3 - 2x^2 + 5x + C$

Example 2

Find $\displaystyle\int (x + 1)(x - 3)\,dx$.

Show solution
  1. Expand: $\displaystyle\int (x^2 - 2x - 3)\,dx$.

$\dfrac{x^3}{3} - x^2 - 3x + C$

Example 3

Find $F(x)$ with $F'(x) = 6x^2 - 2x$ and $F(1) = 4$.

Show solution
  1. $F(x) = 2x^3 - x^2 + C$.
  2. $F(1) = 2 - 1 + C = 4 \Rightarrow C = 3$.

$F(x) = 2x^3 - x^2 + 3$

Example 4

A curve passes through $(0, 1)$ and its tangent slope at each point $(x, y)$ is $2x - 3$. Find the curve.

Show solution
  1. $y' = 2x - 3 \Rightarrow y = x^2 - 3x + C$.
  2. $(0, 1)$: $C = 1$.

$y = x^2 - 3x + 1$

Always write $+ C$ for an indefinite integral. Without it you have found only one antiderivative, not all of them.
Check by differentiating your answer: you must get back the function you integrated.
  • $\displaystyle\int x^n\,dx = \dfrac{x^{n+1}}{n + 1} + C$.
  • Term by term; expand products first.
  • A given point fixes $C$.
