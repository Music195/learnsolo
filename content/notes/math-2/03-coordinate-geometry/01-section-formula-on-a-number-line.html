Section Formula on a Number Line

Dividing a segment in the ratio $m : n$

A point $P$ divides $AB$ internally in the ratio $m : n$ if $P$ is between $A$ and $B$ and $AP : PB = m : n$.

A point $Q$ divides $AB$ externally in the ratio $m : n$ ($m \ne n$) if $Q$ is outside the segment and $AQ : QB = m : n$. $Q$ lies beyond $B$ if $m > n$, and beyond $A$ if $m < n$.

On a number line, $A(a)$ and $B(b)$

$$AB = |b - a|, \qquad \text{internal: } \frac{na + mb}{m + n}, \qquad \text{external: } \frac{-na + mb}{m - n}$$

Midpoint: $\dfrac{a + b}{2}$ (internal division with $m = n = 1$). The external formula is the internal one with $n$ replaced by $-n$.

  1. Let $a < b$ and $P(x)$ divide $AB$ internally: $AP = x - a$, $PB = b - x$.
  2. $(x - a) : (b - x) = m : n \Rightarrow n(x - a) = m(b - x)$.
  3. $(m + n)x = na + mb$, so $x = \dfrac{na + mb}{m + n}$. The case $a > b$ gives the same formula.

Drag $A$ and $B$; choose the ratio

Example 1

$A(-2)$, $B(6)$. Find the points dividing $AB$ internally and externally in the ratio $3 : 1$.

Show solution
  1. Internal: $\dfrac{1 \cdot (-2) + 3 \cdot 6}{3 + 1} = \dfrac{16}{4} = 4$.
  2. External: $\dfrac{-1 \cdot (-2) + 3 \cdot 6}{3 - 1} = \dfrac{20}{2} = 10$.

$4$ and $10$

Example 2

$A(-2)$, $B(6)$. Find the point dividing $AB$ externally in the ratio $1 : 3$.

Show solution
  1. $\dfrac{-3 \cdot (-2) + 1 \cdot 6}{1 - 3} = \dfrac{12}{-2}$.
  2. $m < n$, so the point lies beyond $A$: check $-6 < -2$.

$-6$

Example 3

Find the distance between $A(-3)$ and $B(5)$, and the midpoint of $AB$.

Show solution
  1. $AB = |5 - (-3)| = 8$; midpoint $\dfrac{-3 + 5}{2}$.

$8$; $\;1$

In $\dfrac{na + mb}{m + n}$, $n$ goes with $a$ and $m$ goes with $b$ (the numbers cross over). Swapping them gives the point dividing in the ratio $n : m$.
Remember only the internal formula. For external division, change $n$ to $-n$.
  • Distance $|b - a|$.
  • Internal $m : n$: $\dfrac{na + mb}{m + n}$; external: $\dfrac{-na + mb}{m - n}$.
  • External with $m > n$: beyond $B$; with $m < n$: beyond $A$.
