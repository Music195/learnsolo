Distance Between a Point and a Line

The shortest way is perpendicular

The distance from a point $P$ to a line is the length $PH$, where $H$ is the foot of the perpendicular from $P$. There is a formula that gives it straight from the equation of the line, without finding $H$.

From $P(x_1, y_1)$ to $ax + by + c = 0$

$$d = \frac{|ax_1 + by_1 + c|}{\sqrt{a^2 + b^2}}$$

Write the line as "$\ldots = 0$" first, then substitute the point into the left side.

  1. The line has slope $-\dfrac{a}{b}$, so a perpendicular goes $a$ across for every $b$ up. Hence $H = (x_1 + at,\; y_1 + bt)$ for some number $t$.
  2. $H$ is on the line: $a(x_1 + at) + b(y_1 + bt) + c = 0$, so $t = -\dfrac{ax_1 + by_1 + c}{a^2 + b^2}$.
  3. $PH = \sqrt{(at)^2 + (bt)^2} = |t|\sqrt{a^2 + b^2} = \dfrac{|ax_1 + by_1 + c|}{\sqrt{a^2 + b^2}}$.

Line $ax + by + c = 0$; drag $P$

Example 1

Find the distance from $(7, 3)$ to $3x + 4y - 24 = 0$, and from $(3, 4)$ to $2x + 3y - 6 = 0$.

Show solution
  1. $\dfrac{|21 + 12 - 24|}{\sqrt{9 + 16}} = \dfrac{9}{5}$.
  2. $\dfrac{|6 + 12 - 6|}{\sqrt{4 + 9}} = \dfrac{12}{\sqrt{13}}$.

$\dfrac{9}{5}$; $\;\dfrac{12\sqrt{13}}{13}$

Example 2

Find the foot $H$ of the perpendicular from $P(2, 3)$ to $x - 2y + 1 = 0$.

Show solution
  1. The line has slope $\dfrac{1}{2}$, so $PH$ has slope $-2$: $y - 3 = -2(x - 2)$, i.e. $2x + y - 7 = 0$.
  2. Solve with $x - 2y + 1 = 0$: from the first, $y = 7 - 2x$; then $x - 14 + 4x + 1 = 0$, $x = \dfrac{13}{5}$, $y = \dfrac{9}{5}$.

$H\left(\dfrac{13}{5}, \dfrac{9}{5}\right)$

Example 3

Find the area of the triangle $O(0, 0)$, $A(4, 1)$, $B(1, 3)$.

Show solution
  1. Line $AB$: slope $-\dfrac{2}{3}$, $2x + 3y - 11 = 0$. Height from $O$: $\dfrac{11}{\sqrt{13}}$.
  2. Base $AB = \sqrt{9 + 4} = \sqrt{13}$. Area $= \dfrac{1}{2} \cdot \sqrt{13} \cdot \dfrac{11}{\sqrt{13}}$.

$\dfrac{11}{2}$

The formula needs the line in the form $ax + by + c = 0$. For $y = 2x + 1$ use $2x - y + 1 = 0$, so $a = 2$, $b = -1$, $c = 1$.
This formula is the quickest way to decide if a line touches a circle: compare the distance from the centre with the radius (note 13).
  • $d = \dfrac{|ax_1 + by_1 + c|}{\sqrt{a^2 + b^2}}$.
  • Foot $H$: intersect with the perpendicular through $P$.
  • Triangle area: $\dfrac{1}{2} \times$ base $\times$ distance.
