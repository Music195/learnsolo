Trigonometric Identities

Coordinates on the unit circle

Turn by an angle $\theta$ (any size) from the positive $x$-axis to reach $P(x, y)$ on the circle of radius $1$. Define $\cos\theta = x$, $\sin\theta = y$, $\tan\theta = \dfrac{y}{x}$. This extends Math 1 (which stopped at $180°$) to every angle.

The signs depend on the quadrant of $P$; the relations between $\sin$, $\cos$ and $\tan$ stay the same.

Relations (for every $\theta$ where they are defined)

$$\sin^2\theta + \cos^2\theta = 1, \qquad \tan\theta = \frac{\sin\theta}{\cos\theta}, \qquad 1 + \tan^2\theta = \frac{1}{\cos^2\theta}$$

Signs: quadrant I all $+$; II only $\sin$ $+$; III only $\tan$ $+$; IV only $\cos$ $+$. $\tan\theta$ is undefined when $\cos\theta = 0$.

  1. $P(\cos\theta, \sin\theta)$ is on $x^2 + y^2 = 1$, so $\cos^2\theta + \sin^2\theta = 1$.
  2. $\tan\theta = \dfrac{y}{x} = \dfrac{\sin\theta}{\cos\theta}$.
  3. Divide the first by $\cos^2\theta$: $\tan^2\theta + 1 = \dfrac{1}{\cos^2\theta}$.

Drag $P$ round the whole circle

Example 1

$\sin\theta = \dfrac{4}{5}$ and $\dfrac{\pi}{2} < \theta < \pi$. Find $\cos\theta$ and $\tan\theta$.

Show solution
  1. $\cos^2\theta = 1 - \dfrac{16}{25} = \dfrac{9}{25}$. Second quadrant: $\cos\theta < 0$.

$\cos\theta = -\dfrac{3}{5}$, $\tan\theta = -\dfrac{4}{3}$

Example 2

$\tan\theta = \dfrac{3}{4}$ and $\pi < \theta < \dfrac{3}{2}\pi$. Find $\cos\theta$ and $\sin\theta$.

Show solution
  1. $\dfrac{1}{\cos^2\theta} = 1 + \dfrac{9}{16} = \dfrac{25}{16}$, so $\cos^2\theta = \dfrac{16}{25}$.
  2. Third quadrant: $\cos\theta < 0$, so $\cos\theta = -\dfrac{4}{5}$; $\sin\theta = \tan\theta\cos\theta = -\dfrac{3}{5}$.

$\cos\theta = -\dfrac{4}{5}$, $\sin\theta = -\dfrac{3}{5}$

Example 3

$\sin\theta + \cos\theta = \dfrac{1}{2}$. Find $\sin\theta\cos\theta$ and $\sin^3\theta + \cos^3\theta$.

Show solution
  1. Square: $1 + 2\sin\theta\cos\theta = \dfrac{1}{4}$, so $\sin\theta\cos\theta = -\dfrac{3}{8}$.
  2. $\sin^3\theta + \cos^3\theta = (\sin\theta + \cos\theta)(1 - \sin\theta\cos\theta) = \dfrac{1}{2} \cdot \dfrac{11}{8}$.

$-\dfrac{3}{8}$; $\;\dfrac{11}{16}$

$\cos^2\theta = \dfrac{9}{25}$ gives $\cos\theta = \pm\dfrac{3}{5}$. The quadrant decides the sign; without it, both are possible.
