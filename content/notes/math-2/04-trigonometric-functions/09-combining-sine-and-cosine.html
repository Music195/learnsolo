Sum of Sine and Cosine Formula

Two waves add up to one wave

Adding $a\sin\theta$ and $b\cos\theta$ gives a single sine wave of height $r = \sqrt{a^2 + b^2}$, shifted by an angle $\alpha$. Find $\alpha$ by plotting the point $(a, b)$: $\alpha$ is its angle from the positive $x$-axis.

This turns maximum/minimum and equation problems with both $\sin$ and $\cos$ into problems with one $\sin$.

Combining

$$a\sin\theta + b\cos\theta = r\sin(\theta + \alpha), \qquad r = \sqrt{a^2 + b^2}, \quad \cos\alpha = \frac{a}{r}, \; \sin\alpha = \frac{b}{r}$$

$-r \le a\sin\theta + b\cos\theta \le r$.

  1. Let $P(a, b)$, at distance $r$ from $O$ and at angle $\alpha$: $a = r\cos\alpha$, $b = r\sin\alpha$.
  2. $a\sin\theta + b\cos\theta = r(\sin\theta\cos\alpha + \cos\theta\sin\alpha) = r\sin(\theta + \alpha)$ (note 07).

$a\sin\theta + b\cos\theta$ and $r\sin(\theta + \alpha)$

Example 1

Write $\sin\theta + \sqrt{3}\cos\theta$ as $r\sin(\theta + \alpha)$, and solve $\sin\theta + \sqrt{3}\cos\theta = 2$ for $0 \le \theta < 2\pi$.

Show solution
  1. $(a, b) = (1, \sqrt{3})$: $r = 2$, $\alpha = \dfrac{\pi}{3}$. So $2\sin\left(\theta + \dfrac{\pi}{3}\right) = 2$, i.e. $\sin\left(\theta + \dfrac{\pi}{3}\right) = 1$.
  2. $\dfrac{\pi}{3} \le \theta + \dfrac{\pi}{3} < \dfrac{7}{3}\pi$, and $\sin = 1$ only at $\dfrac{\pi}{2}$ in this range.

$2\sin\left(\theta + \dfrac{\pi}{3}\right)$; $\;\theta = \dfrac{\pi}{6}$

Example 2

Find the largest and smallest values of $3\sin\theta + 4\cos\theta$.

Show solution
  1. $r = \sqrt{9 + 16} = 5$, so it equals $5\sin(\theta + \alpha)$ for some $\alpha$.

Largest $5$, smallest $-5$

Example 3

Find the range of $y = \sin\theta - \sqrt{3}\cos\theta$ for $0 \le \theta \le \pi$.

Show solution
  1. $(a, b) = (1, -\sqrt{3})$: $r = 2$, $\alpha = -\dfrac{\pi}{3}$. $\;y = 2\sin\left(\theta - \dfrac{\pi}{3}\right)$.
  2. $-\dfrac{\pi}{3} \le \theta - \dfrac{\pi}{3} \le \dfrac{2}{3}\pi$, so $-\dfrac{\sqrt{3}}{2} \le \sin\left(\theta - \dfrac{\pi}{3}\right) \le 1$.

$-\sqrt{3} \le y \le 2$ (largest at $\theta = \dfrac{5}{6}\pi$, smallest at $\theta = 0$)

Example 4

Write $-5\sin\theta + 12\cos\theta$ as $r\sin(\theta + \alpha)$. In which quadrant is $\alpha$?

Show solution
  1. $r = \sqrt{25 + 144} = 13$, $\cos\alpha = -\dfrac{5}{13}$, $\sin\alpha = \dfrac{12}{13}$.
  2. $\cos\alpha < 0$, $\sin\alpha > 0$: the point $(-5, 12)$ is in the second quadrant.

$13\sin(\theta + \alpha)$ with $\alpha$ in the second quadrant ($\alpha \approx 112.6°$)

The coefficient of $\sin\theta$ gives $\cos\alpha$ and the coefficient of $\cos\theta$ gives $\sin\alpha$. Swapping them is the most common mistake: plot $(a, b)$ to be sure.
When $\theta$ is restricted (Example 3), work out the range of $\theta + \alpha$ before reading off the largest and smallest values.
  • $a\sin\theta + b\cos\theta = \sqrt{a^2 + b^2}\,\sin(\theta + \alpha)$.
  • $\alpha$ = angle of the point $(a, b)$.
  • Range $-\sqrt{a^2 + b^2}$ to $\sqrt{a^2 + b^2}$ (if $\theta$ is free).
