Half-Angle and Double-Angle Trigonometric Formula

Put $\beta = \alpha$ in the addition formulas

Taking $\beta = \alpha$ in note 07 gives the double-angle formulas. Solving $\cos 2\alpha = 1 - 2\sin^2\alpha$ for $\sin^2\alpha$ gives the half-angle formulas, which turn squares into first powers of $\cos 2\alpha$.

Double angle

$$\sin 2\alpha = 2\sin\alpha\cos\alpha, \qquad \cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 1 - 2\sin^2\alpha = 2\cos^2\alpha - 1$$
$$\tan 2\alpha = \frac{2\tan\alpha}{1 - \tan^2\alpha}$$

Half angle (squares → $\cos$)

$$\sin^2\frac{\alpha}{2} = \frac{1 - \cos\alpha}{2}, \qquad \cos^2\frac{\alpha}{2} = \frac{1 + \cos\alpha}{2}, \qquad \tan^2\frac{\alpha}{2} = \frac{1 - \cos\alpha}{1 + \cos\alpha}$$
  1. $\sin(\alpha + \alpha) = 2\sin\alpha\cos\alpha$; $\;\cos(\alpha + \alpha) = \cos^2\alpha - \sin^2\alpha$; replace $\cos^2$ or $\sin^2$ using $\sin^2 + \cos^2 = 1$.
  2. From $\cos 2\theta = 1 - 2\sin^2\theta$: $\sin^2\theta = \dfrac{1 - \cos 2\theta}{2}$. Put $\theta = \dfrac{\alpha}{2}$.
  3. Similarly $\cos^2\dfrac{\alpha}{2} = \dfrac{1 + \cos\alpha}{2}$; divide for $\tan^2$.

Two formulas, one graph

Example 1

$\sin\alpha = \dfrac{3}{5}$ and $\dfrac{\pi}{2} < \alpha < \pi$. Find $\sin 2\alpha$ and $\cos 2\alpha$.

Show solution
  1. $\cos\alpha = -\dfrac{4}{5}$ (second quadrant).
  2. $\sin 2\alpha = 2 \cdot \dfrac{3}{5} \cdot \left(-\dfrac{4}{5}\right)$; $\;\cos 2\alpha = 1 - 2 \cdot \dfrac{9}{25}$.

$\sin 2\alpha = -\dfrac{24}{25}$, $\cos 2\alpha = \dfrac{7}{25}$

Example 2

Find $\cos\dfrac{\pi}{8}$.

Show solution
  1. $\cos^2\dfrac{\pi}{8} = \dfrac{1 + \cos\frac{\pi}{4}}{2} = \dfrac{2 + \sqrt{2}}{4}$.
  2. $\dfrac{\pi}{8}$ is in the first quadrant, so $\cos\dfrac{\pi}{8} > 0$.

$\dfrac{\sqrt{2 + \sqrt{2}}}{2}$

Example 3

Find the largest and smallest values of $y = \cos 2\theta + 2\sin\theta$ ($0 \le \theta < 2\pi$).

Show solution
  1. $\cos 2\theta = 1 - 2\sin^2\theta$. With $t = \sin\theta$ ($-1 \le t \le 1$): $y = -2t^2 + 2t + 1 = -2\left(t - \dfrac{1}{2}\right)^2 + \dfrac{3}{2}$.
  2. Largest at $t = \dfrac{1}{2}$: $\dfrac{3}{2}$ ($\theta = \dfrac{\pi}{6}, \dfrac{5}{6}\pi$). Smallest at $t = -1$: $-3$ ($\theta = \dfrac{3}{2}\pi$).

Largest $\dfrac{3}{2}$, smallest $-3$

Half-angle formulas give a square. Choose the sign of $\sin\dfrac{\alpha}{2}$ or $\cos\dfrac{\alpha}{2}$ from the quadrant of $\dfrac{\alpha}{2}$.
Choose the form of $\cos 2\alpha$ that matches the rest: with $\sin\theta$ in the problem use $1 - 2\sin^2\theta$; with $\cos\theta$ use $2\cos^2\theta - 1$.
  • $\sin 2\alpha = 2\sin\alpha\cos\alpha$.
  • $\cos 2\alpha = 1 - 2\sin^2\alpha = 2\cos^2\alpha - 1$.
  • $\sin^2\theta = \dfrac{1 - \cos 2\theta}{2}$, $\cos^2\theta = \dfrac{1 + \cos 2\theta}{2}$.
