Two Connected Objects

Split them apart, write one equation each, then add

Two objects joined by a string, or one pushing the other, move together: they have the same size of acceleration $a$. To find $a$ and the force between them, use the same steps every time:

  1. Draw each object on its own, with only its own forces: its gravity, and one force for each thing it touches. A force on the other object is not a force on this one.
  2. Give both objects the same $a$, each pointing the way that object moves.
  3. Write one equation of motion for each, one under the other.
  4. Add the two equations. The force between them (tension $T$, or the push $N$) appears with $+$ in one and $-$ in the other, so it cancels. Find $a$.
  5. Put $a$ back into the simpler equation to find the force between them.

Two strings on the same light string pull with the same tension $T$ everywhere, even around a pulley. A pulley only changes the direction of the motion.

Pulling two objects along a smooth floor

$$\begin{aligned} m_A a &= T \\ m_B a &= F - T \\ \hline (m_A + m_B)\,a &= F \end{aligned} \qquad a = \frac{F}{m_A + m_B}, \quad T = \frac{m_A F}{m_A + m_B}$$

B is pulled with $F$, and B pulls A along with the string (tension $T$). Over a pulley, with B heavier: $a = \dfrac{(m_B - m_A)g}{m_A + m_B}$ and $T = \dfrac{2m_A m_B\,g}{m_A + m_B}$.

  1. A and B hang on the two sides of a pulley, with $m_B > m_A$. B goes down and A goes up, so take up positive for A and down positive for B. Both have acceleration $a$.
  2. A: $m_A a = T - m_A g$.   B: $m_B a = m_B g - T$.
  3. Add: $(m_A + m_B)\,a = (m_B - m_A)\,g$, so $a = \dfrac{(m_B - m_A)g}{m_A + m_B}$.
  4. Put this into A's equation: $T = m_A(g + a) = m_A g \cdot \dfrac{(m_A + m_B) + (m_B - m_A)}{m_A + m_B} = \dfrac{2m_A m_B\,g}{m_A + m_B}$.

Four problems: each object drawn on its own, with its equation

Example 1

On a smooth floor, block A ($2.0\ \mathrm{kg}$) is tied by a string to block B ($3.0\ \mathrm{kg}$). B is pulled with $F = 20\ \mathrm{N}$. Find the acceleration and the tension.

Show solution
  1. A: $2.0\,a = T$.   B: $3.0\,a = 20 - T$.
  2. Add: $5.0\,a = 20$, so $a = 4.0$.
  3. From A: $T = 2.0 \times 4.0$.

$a = 4.0\ \mathrm{m/s^2}$, $T = 8.0\ \mathrm{N}$

Example 2

A ($3.0\ \mathrm{kg}$) and B ($5.0\ \mathrm{kg}$) hang over a light pulley. Find the acceleration and the tension.

Show solution
  1. A up: $3.0\,a = T - 3.0 \times 9.8$.   B down: $5.0\,a = 5.0 \times 9.8 - T$.
  2. Add: $8.0\,a = 2.0 \times 9.8 = 19.6$, so $a = 2.45$.
  3. From A: $T = 3.0 \times (9.8 + 2.45) = 36.75$.

$a \approx 2.5\ \mathrm{m/s^2}$, $T \approx 37\ \mathrm{N}$

Example 3

Block A ($2.0\ \mathrm{kg}$) sits on block B ($3.0\ \mathrm{kg}$). A hand pushes B up with $F = 60\ \mathrm{N}$. Find the acceleration and the normal force between A and B.

Show solution
  1. A: only gravity and B's push $N$ act on it: $2.0\,a = N - 2.0 \times 9.8$.
  2. B: $F$ up, A's push $N$ down (the reaction), its gravity: $3.0\,a = 60 - N - 3.0 \times 9.8$.
  3. Add: $5.0\,a = 60 - 49$, so $a = 2.2$. Then $N = 2.0 \times (9.8 + 2.2)$.

$a = 2.2\ \mathrm{m/s^2}$; $N = 24\ \mathrm{N}$, not $2.0 \times 9.8 = 19.6\ \mathrm{N}$

Example 4

In Example 1, why can't you say "the $20\ \mathrm{N}$ pulls A too"?

Show solution
  1. The hand touches only B, so the $20\ \mathrm{N}$ acts only on B.
  2. A touches the string, so the force on A is the tension $T$. A only feels the hand's pull through the string.

A force acts only on what it touches; on A, it's $T = 8.0\ \mathrm{N}$

Two common mistakes: (1) putting the hand's force $F$ on an object it doesn't touch, and (2) drawing "the weight of A" as a force on B. Gravity acts only on its own object. What B feels from A is a contact force (a normal force $N$), and $N = m_A g$ only if they are not accelerating.
Always write the two equations one under the other, with the same $a$, and add them. The force between the objects always cancels, because it is an action–reaction pair: $+T$ on one, $-T$ on the other.
  • Draw each object on its own, with only its own forces. Both get the same $a$.
  • Write one equation each, add them: the force between them cancels and gives $a$.
  • Put $a$ back into the simpler equation to find the tension or the push between them.
