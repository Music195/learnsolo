Stacked Objects: Pulling the Board

Pull gently and they move together; pull hard and the board slips out

Block A (mass $m$) rests on board B (mass $M$), on a smooth floor. Between A and B the coefficient of static friction is $\mu_0$ and of kinetic friction is $\mu$. Now pull only B with a force $F$. This is the tablecloth trick: pull slowly and the plates come with the cloth; pull fast and the cloth slides out from under them.

  • Small $F$: A and B move together with the same $a$. The friction on A is static friction: it is just big enough to give A the same acceleration. It is not $\mu N$.
  • $F$ reaches $F_1$: the static friction on A reaches its maximum $\mu_0 mg$, and A starts to slip on B.
  • $F$ bigger than $F_1$: A slides on B. The friction is now kinetic, $\mu mg$, and A and B get different accelerations. A falls behind: seen from B, it slides backwards.

Friction on A points forwards (the way B drags it); its reaction on B points backwards.

Pulling the lower board with $F$

$$\text{together: } f = \frac{m F}{m + M} \qquad \text{slips when } F_1 = \mu_0 (m + M) g$$

After it slips: $a_A = \mu g$ and $a_B = \dfrac{F - \mu m g}{M}$. The time for A to slide back a distance $L$ along B: $L = \tfrac{1}{2}(a_B - a_A)\,t^2$.

  1. Together, with friction $f$ on A (forwards) and on B (backwards): A: $ma = f$.   B: $Ma = F - f$.
  2. Add: $(m + M)a = F$, so $a = \dfrac{F}{m + M}$, and from A, $f = ma = \dfrac{mF}{m + M}$. It grows with $F$.
  3. A starts to slip when $f$ reaches the maximum static friction $\mu_0 N = \mu_0 mg$: $\dfrac{m F_1}{m + M} = \mu_0 m g$, so $F_1 = \mu_0 (m + M) g$.
  4. Sliding: A: $m a_A = \mu m g$.   B: $M a_B = F - \mu m g$. B is faster, so A moves backwards relative to B with relative acceleration $a_B - a_A$.
  5. On a v–t graph both lines start at $0$; the area between them, a triangle, is the distance A slides back: $L = \tfrac{1}{2}(a_B - a_A)t^2$.

Pull board B with $F$ ($m = 1\ \mathrm{kg}$, $M = 2\ \mathrm{kg}$, $\mu_0 = 0.5$, $\mu = 0.3$)

Example 1

A $1.0\ \mathrm{kg}$ block sits on a $2.0\ \mathrm{kg}$ board on a smooth floor. The board is pulled with $9.0\ \mathrm{N}$ and they move together. Find the friction on the block.

Show solution
  1. Together: $3.0\,a = 9.0$, so $a = 3.0$.
  2. Block: $1.0 \times 3.0 = f$.

$f = 3.0\ \mathrm{N}$ (static friction, forwards), not $\mu N$

Example 2

In Example 1, $\mu_0 = 0.50$. Find the force $F_1$ at which the block starts to slip.

Show solution
  1. Maximum static friction on the block: $\mu_0 mg = 0.50 \times 1.0 \times 9.8 = 4.9\ \mathrm{N}$.
  2. $\dfrac{1.0 \times F_1}{3.0} = 4.9$.

$F_1 = 14.7\ \mathrm{N}$

Example 3

Now the board is pulled with $21\ \mathrm{N}$ from rest, and $\mu = 0.30$. Find both accelerations, and the time for the block to slide $0.50\ \mathrm{m}$ back along the board.

Show solution
  1. Kinetic friction: $\mu mg = 2.94\ \mathrm{N}$. Block: $a_A = 2.94\ \mathrm{m/s^2}$.
  2. Board: $2.0\,a_B = 21 - 2.94$, so $a_B = 9.03\ \mathrm{m/s^2}$.
  3. Relative: $0.50 = \tfrac{1}{2}(9.03 - 2.94)t^2$, so $t^2 = 0.164$.

$a_A \approx 2.9$, $a_B \approx 9.0\ \mathrm{m/s^2}$; $t \approx 0.41\ \mathrm{s}$

Example 4

A student writes the relative motion as $L = \tfrac{1}{2}(a_A - a_B)t^2$ and gets a square root of a negative number. What went wrong?

Show solution
  1. $a_A - a_B$ (right positive) is A's acceleration as seen from B. It is negative: A moves backwards relative to B.
  2. So A's displacement relative to B is $-L$, not $L$: $-L = \tfrac{1}{2}(a_A - a_B)t^2$.

A sign mistake: a displacement has a direction, and here it is $-L$

While they move together, the friction is static: find it from the equation of motion, not from $\mu N$. Only at the moment of slipping is it $\mu_0 N$, and only while sliding is it $\mu N$.
With relative acceleration, $x = \tfrac{1}{2}at^2$ gives a displacement, with a sign. If you prefer to avoid sign mistakes, draw both v–t lines and use the area between them, which is a distance.
  • Moving together: same $a = \dfrac{F}{m+M}$; friction on the top block $f = ma$ (static).
  • It slips when that friction reaches $\mu_0 mg$: $F_1 = \mu_0(m+M)g$.
  • Sliding: separate equations, $a_A = \mu g$, $a_B = \dfrac{F - \mu mg}{M}$; the top block slides backwards relative to the board.
