Gravity and Tension

Gravity has a formula, tension does not

Gravity is the Earth's pull on an object. It acts at the centre of gravity, straight down, and its size is $W = mg$: the mass times the gravitational acceleration $g$.

Tension is the pull of a string. It acts where the string is attached (the point of contact), along the string, away from the object. A string can only pull, never push.

The important difference: tension has no formula. A string pulls exactly as hard as the situation needs, so its size is found by writing the balance of forces, or later the equation of motion.

Gravity on an object of mass $m$

$$W = mg$$

$m$ mass in $\mathrm{kg}$, $g = 9.8\ \mathrm{m/s^2}$, $W$ in newtons ($\mathrm{N}$). Tension $T$: no formula; find it from the balance of forces.

  1. Without air resistance, every object falls with the same acceleration, $g = 9.8\ \mathrm{m/s^2}$. This is measured.
  2. Newton's second law (topic 03) says force = mass × acceleration, so the pull that makes it fall is $W = mg$.
  3. A string, on the other hand, can pull with any size of force (up to breaking). Hang $1.0\ \mathrm{kg}$ from it and it pulls with $9.8\ \mathrm{N}$; hang $2.0\ \mathrm{kg}$ and the same string pulls with $19.6\ \mathrm{N}$.
  4. So tension depends on the situation, not on the string: it is whatever keeps the forces balanced.

Example 1

Find the size of the gravity on a $2.0\ \mathrm{kg}$ bag. Use $g = 9.8\ \mathrm{m/s^2}$.

Show solution
  1. $W = mg = 2.0 \times 9.8$.

$19.6\ \mathrm{N}$ (about $20\ \mathrm{N}$)

Example 2

A $3.0\ \mathrm{kg}$ lamp hangs at rest from a single vertical string. Find the tension.

Show solution
  1. Forces on the lamp: gravity $mg$ down, tension $T$ up.
  2. At rest, up = down: $T = mg = 3.0 \times 9.8$.

$T = 29.4\ \mathrm{N}$

Example 3

Block P ($2.0\ \mathrm{kg}$) hangs from the ceiling by string 1. Block Q ($1.0\ \mathrm{kg}$) hangs below P by string 2. Find both tensions.

Show solution
  1. Forces on Q: gravity $1.0 \times 9.8$ down, $T_2$ up. So $T_2 = 9.8\ \mathrm{N}$.
  2. Forces on P: gravity $2.0 \times 9.8$ down, $T_2$ down (string 2 pulls P down), $T_1$ up.
  3. $T_1 = 19.6 + 9.8$.

$T_1 = 29.4\ \mathrm{N}$, $T_2 = 9.8\ \mathrm{N}$

Example 4

A $1.0\ \mathrm{kg}$ picture hangs from two strings, each at $60°$ to the vertical, one on each side. Find the tension in each string.

Show solution
  1. By symmetry both tensions are equal, $T$. Each pulls up by $T\cos 60° = \tfrac{1}{2}T$.
  2. Up = down: $2 \times \tfrac{1}{2}T = mg$, so $T = mg = 1.0 \times 9.8$.

$T = 9.8\ \mathrm{N}$ each: as much as the whole weight

Example 5

A spring scale reads $49\ \mathrm{N}$ when a box hangs from it at rest. What is the mass of the box?

Show solution
  1. At rest, the scale pulls up as hard as gravity pulls down: $mg = 49$.
  2. $m = 49 \div 9.8$.

$m = 5.0\ \mathrm{kg}$

Don't write $T = mg$ as if it were a formula. It is only true for one vertical string holding an object still. With two strings, an angle or an acceleration, the tension is different (Example 4: the strings pull with the whole weight each).
Keep mass and force apart: mass is in $\mathrm{kg}$, gravity is a force in $\mathrm{N}$. A $1\ \mathrm{kg}$ object weighs $9.8\ \mathrm{N}$, so roughly $1\ \mathrm{N}$ is the weight of $100\ \mathrm{g}$, about an apple.
  • Gravity: $W = mg$, from the centre of gravity, straight down.
  • Tension: from the point of attachment, along the string, pulling away.
  • Tension has no formula: find it from the balance of forces.
