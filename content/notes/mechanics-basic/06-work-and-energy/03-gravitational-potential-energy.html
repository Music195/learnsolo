Gravitational Potential Energy

A raised object stores energy: gravity can do work on it as it falls

A big rock sitting high on a cliff feels dangerous even though it isn't moving. If it falls, gravity does work on it and it speeds up, and then it can do work on whatever it hits. So a raised object already stores energy. This is gravitational potential energy, $U = mgh$.

The height $h$ is measured from a reference level that you choose (often the floor or the lowest point). At the reference level $U = 0$; above it $U$ is positive, and below it $U$ is negative.

Changing the reference level changes every $U$ by the same amount, so the differences in $U$, which are what matter, stay the same.

Gravitational potential energy

$$U = mgh$$

$m$ mass in $\mathrm{kg}$, $g = 9.8\ \mathrm{m/s^2}$, $h$ height above the reference level in $\mathrm{m}$ (negative below it). When the object falls a height $h$, gravity does work $mgh$ on it, and $U$ goes down by $mgh$.

  1. Let an object of mass $m$ fall from height $h$ to the reference level. Gravity $mg$ points down and the displacement $h$ points down: the angle between them is $0^\circ$.
  2. Work done by gravity: $W = mg \times h \times \cos 0^\circ = mgh$.
  3. By the work–energy relation, the object gains $mgh$ of kinetic energy, which it can then use to do work on something else.
  4. So at height $h$ it was already storing $mgh$ of energy, ready to be released. We call this its potential energy.

Example 1

Find the potential energy of a $3.0\ \mathrm{kg}$ book on a shelf $2.0\ \mathrm{m}$ above the floor, with the floor as the reference level.

Show solution
  1. $U = 3.0 \times 9.8 \times 2.0$.

$58.8\ \mathrm{J}$

Example 2

The same book, but with a table top $0.80\ \mathrm{m}$ high as the reference level. Find $U$ on the shelf and on the floor.

Show solution
  1. Shelf: $h = 2.0 - 0.80 = 1.2$, $U = 3.0 \times 9.8 \times 1.2 = 35.3$.
  2. Floor: $h = -0.80$, $U = 3.0 \times 9.8 \times (-0.80) = -23.5$.

$35.3\ \mathrm{J}$ and $-23.5\ \mathrm{J}$ (difference $58.8\ \mathrm{J}$, the same as before)

Example 3

A $0.50\ \mathrm{kg}$ ball falls $10\ \mathrm{m}$. Find the work done by gravity and the speed it reaches if it started at rest.

Show solution
  1. $W = mgh = 0.50 \times 9.8 \times 10 = 49\ \mathrm{J}$.
  2. $\tfrac{1}{2} \times 0.50 \times v^2 = 49$, so $v^2 = 196$.

$49\ \mathrm{J}$; $v = 14\ \mathrm{m/s}$

Example 4

A $60\ \mathrm{kg}$ climber goes up $500\ \mathrm{m}$ of height. By how much does their potential energy change?

Show solution
  1. $\Delta U = mg\,\Delta h = 60 \times 9.8 \times 500$.

It increases by $2.94 \times 10^5\ \mathrm{J}$

A value of $U$ means nothing until you say where $h = 0$ is. Choose one reference level at the start of a problem and use it for every position. Below it, $h$ and $U$ are negative.
Choosing the lowest point in the problem as the reference level keeps every $U$ positive or zero, which makes sign mistakes less likely.
  • $U = mgh$, with $h$ measured from a reference level you choose.
  • $U$ is negative below the reference level.
  • Only differences in $U$ matter: falling $h$ releases $mgh$, whatever the reference.
