Differentiation Rules

Five problems on the chain, quotient and product rules, and the definition of the derivative. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

$f(x) = (2x - 1)^3$. Find $f'(1)$.

Uses: Chain Rule

Show hint

Chain rule: $\{g(x)^3\}' = 3g(x)^2 g'(x)$.

Show solution
  1. $f'(x) = 3(2x - 1)^2 \cdot 2 = 6(2x - 1)^2$.
  2. $f'(1) = 6 \cdot 1 = 6$.

$f'(1) = 6$

Problem 2

$f(x) = \dfrac{x}{x^2 + 1}$. Find $f'(2)$.

Uses: Quotient Rule

Show hint

$\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$.

Show solution
  1. $f'(x) = \dfrac{1 \cdot (x^2 + 1) - x \cdot 2x}{(x^2 + 1)^2} = \dfrac{1 - x^2}{(x^2 + 1)^2}$.
  2. $f'(2) = \dfrac{1 - 4}{25} = -\dfrac{3}{25}$.

$f'(2) = -\dfrac{3}{25}$

Problem 3

$f(x) = x^2\log x$. Find $f'(e)$.

Uses: Derivatives of Log and Exponential Functions, Properties of Derivatives

Show hint

Product rule, with $(\log x)' = \dfrac{1}{x}$.

Show solution
  1. $f'(x) = 2x\log x + x^2 \cdot \dfrac{1}{x} = 2x\log x + x$.
  2. $f'(e) = 2e \cdot 1 + e = 3e$.

$f'(e) = 3e$

Problem 4

$f(x) = \sin^3 x$. Find $f'\left(\dfrac{\pi}{6}\right)$.

Uses: Derivatives of Trigonometric Functions, Chain Rule

Show hint

$\sin^3 x = (\sin x)^3$: use the chain rule with the inside $\sin x$.

Show solution
  1. $f'(x) = 3\sin^2 x \cos x$.
  2. $f'\left(\dfrac{\pi}{6}\right) = 3 \cdot \dfrac{1}{4} \cdot \dfrac{\sqrt{3}}{2} = \dfrac{3\sqrt{3}}{8}$.

$\dfrac{3\sqrt{3}}{8}$

Problem 5

$f(x) = x^3$. Find $\displaystyle\lim_{h \to 0} \dfrac{f(1 + 2h) - f(1 - h)}{h}$ without expanding.

Uses: Definition of Derivative

Show hint

Subtract and add $f(1)$ in the numerator, then make each part look like $\dfrac{f(1 + k) - f(1)}{k}$.

Show solution
  1. $\dfrac{f(1 + 2h) - f(1 - h)}{h} = 2 \cdot \dfrac{f(1 + 2h) - f(1)}{2h} + \dfrac{f(1 - h) - f(1)}{-h}$.
  2. As $h \to 0$, both fractions tend to $f'(1)$, so the limit is $2f'(1) + f'(1) = 3f'(1)$.
  3. $f'(x) = 3x^2$, so $f'(1) = 3$ and the limit is $9$.

$9$

Check by expanding: $(1 + 2h)^3 - (1 - h)^3 = 9h + 9h^2 + 9h^3$, so the fraction is $9 + 9h + 9h^2 \to 9$ ✓.
