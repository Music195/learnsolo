Complex Numbers in the Plane

Five problems on absolute values, polar form, De Moivre's theorem, perpendicular lines and roots of unity. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Find $\left|\dfrac{3 + 4i}{1 - i}\right|$.

Uses: Absolute Value of Complex Number, Modulus of Product and Quotient

Show hint

$\left|\dfrac{\alpha}{\beta}\right| = \dfrac{|\alpha|}{|\beta|}$, so there is no need to divide first.

Show solution
  1. $|3 + 4i| = 5$ and $|1 - i| = \sqrt{2}$.
  2. $\dfrac{5}{\sqrt{2}} = \dfrac{5\sqrt{2}}{2}$.

$\dfrac{5\sqrt{2}}{2}$

Problem 2

Write $z = 1 + \sqrt{3}i$ in polar form ($0 \le \theta < 2\pi$).

Uses: Polar Form of Complex Number

Show hint

$r = |z|$, then $\cos\theta = \dfrac{1}{r}$ and $\sin\theta = \dfrac{\sqrt{3}}{r}$. Type the argument $\theta$.

Show solution
  1. $r = \sqrt{1 + 3} = 2$.
  2. $\cos\theta = \dfrac{1}{2}$, $\sin\theta = \dfrac{\sqrt{3}}{2}$, so $\theta = \dfrac{\pi}{3}$.

$z = 2\left(\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}\right)$

Problem 3

Find $(1 + i)^8$.

Uses: De Moivre's Theorem

Show hint

Write $1 + i$ in polar form, then $\{r(\cos\theta + i\sin\theta)\}^n = r^n(\cos n\theta + i\sin n\theta)$.

Show solution
  1. $1 + i = \sqrt{2}\left(\cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}\right)$.
  2. $(1 + i)^8 = (\sqrt{2})^8(\cos 2\pi + i\sin 2\pi) = 16 \cdot 1 = 16$.

$(1 + i)^8 = 16$

Another way: $(1 + i)^2 = 2i$, so $(1 + i)^8 = (2i)^4 = 16i^4 = 16$.

Problem 4

A$(1 + i)$, B$(2 + 3i)$ and C$(a + 2i)$, with $a$ real. Find $a$ so that $AB \perp AC$.

Uses: Collinearity and Perpendicularity

Show hint

$AB \perp AC$ exactly when $\dfrac{\gamma - \alpha}{\beta - \alpha}$ is purely imaginary (real part $0$, not $0$ itself).

Show solution
  1. $\dfrac{\gamma - \alpha}{\beta - \alpha} = \dfrac{(a - 1) + i}{1 + 2i} = \dfrac{\{(a - 1) + i\}(1 - 2i)}{5}$.
  2. $= \dfrac{(a + 1) + (3 - 2a)i}{5}$.
  3. Real part $0$: $a = -1$. Then the imaginary part is $\dfrac{5}{5} = 1 \ne 0$ ✓.

$a = -1$

Check with vectors: $\overrightarrow{AB} = (1, 2)$ and $\overrightarrow{AC} = (-2, 1)$ have dot product $-2 + 2 = 0$ ✓.

Problem 5

$z$ satisfies $z^5 = 1$ and $z \ne 1$. Find $(1 - z)(1 - z^2)(1 - z^3)(1 - z^4)$.

Uses: N-th Roots of 1

Show hint

The five 5th roots of $1$ are $1, z, z^2, z^3, z^4$. So $x^5 - 1 = (x - 1)(x - z)(x - z^2)(x - z^3)(x - z^4)$.

Show solution
  1. $x^5 - 1 = (x - 1)(x^4 + x^3 + x^2 + x + 1)$, so $x^4 + x^3 + x^2 + x + 1 = (x - z)(x - z^2)(x - z^3)(x - z^4)$.
  2. Put in $x = 1$: $(1 - z)(1 - z^2)(1 - z^3)(1 - z^4) = 1 + 1 + 1 + 1 + 1 = 5$.

$5$

Geometrically: the roots are the corners of a regular pentagon on the unit circle, and $|1 - z^k|$ is the distance from the corner $1$ to each other corner. The product of those four distances is $5$.
