Parabolas, Ellipses and Hyperbolas

Five problems on foci, eccentricity and a polar equation. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

P is the point on the parabola $y^2 = 12x$ with $x$-coordinate $4$. Find the distance from P to the focus.

Uses: Parabola Basic Properties

Show hint

$y^2 = 4px$ has focus $(p, 0)$ and directrix $x = -p$. Every point is the same distance from both.

Show solution
  1. $4p = 12$, so $p = 3$: focus $(3, 0)$, directrix $x = -3$.
  2. Distance to the focus = distance to the directrix $= 4 - (-3) = 7$.

$7$

Problem 2

Find the foci of the ellipse $\dfrac{x^2}{25} + \dfrac{y^2}{9} = 1$, and the distance between them.

Uses: Ellipse Basic Properties

Show hint

For $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ with $a > b$, the foci are $(\pm c, 0)$ where $c^2 = a^2 - b^2$.

Show solution
  1. $c^2 = 25 - 9 = 16$, so $c = 4$.
  2. Foci $(\pm 4, 0)$, which are $8$ apart.

Foci $(\pm 4, 0)$; distance $8$

Problem 3

Find the asymptotes and the eccentricity of the hyperbola $\dfrac{x^2}{9} - \dfrac{y^2}{16} = 1$.

Uses: Hyperbola Basic Properties, Conic Eccentricity

Show hint

Asymptotes $y = \pm\dfrac{b}{a}x$. For a hyperbola $c^2 = a^2 + b^2$, and $e = \dfrac{c}{a}$. Type $e$.

Show solution
  1. $a = 3$, $b = 4$: asymptotes $y = \pm\dfrac{4}{3}x$.
  2. $c = \sqrt{9 + 16} = 5$, so $e = \dfrac{5}{3}$.

Asymptotes $y = \pm\dfrac{4}{3}x$; $e = \dfrac{5}{3}$

Problem 4

Find the equation of the ellipse with foci $(\pm 3, 0)$ that passes through $(0, 4)$.

Uses: Ellipse Basic Properties

Show hint

$(0, 4)$ is an end of the minor axis, so $b = 4$. Then $a^2 = b^2 + c^2$.

Show solution
  1. The centre is the origin and the foci are on the $x$-axis: $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$.
  2. $(0, 4)$ on it gives $b = 4$; $c = 3$, so $a^2 = 16 + 9 = 25$.

$\dfrac{x^2}{25} + \dfrac{y^2}{16} = 1$

Problem 5

Write the polar equation $r = \dfrac{2}{1 - \cos\theta}$ in $x, y$ coordinates, and say what curve it is.

Uses: Polar and Cartesian Coordinates, Conic Eccentricity

Show hint

Multiply out: $r - r\cos\theta = 2$. Then use $r\cos\theta = x$ and $r = \sqrt{x^2 + y^2}$.

Show solution
  1. $r = r\cos\theta + 2 = x + 2$.
  2. Square ($r \ge 0$): $x^2 + y^2 = x^2 + 4x + 4$.
  3. $y^2 = 4x + 4 = 4(x + 1)$.

$y^2 = 4(x + 1)$: a parabola with vertex $(-1, 0)$ and focus at the origin

$r = x + 2$ says: distance to the origin = distance to the line $x = -2$. That is the focus–directrix definition with $e = 1$, so it had to be a parabola.
