Sets and Conditions

Five problems on sets, necessary and sufficient conditions, and statements. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

$U = \{1, 2, \ldots, 10\}$, $A$ is the set of divisors of $12$ in $U$, and $B$ is the set of odd numbers in $U$. Find $n(A \cup B)$.

Uses: Intersection and Union of Sets

Show hint

List both sets. $n(A \cup B) = n(A) + n(B) - n(A \cap B)$.

Show solution
  1. $A = \{1, 2, 3, 4, 6\}$, $B = \{1, 3, 5, 7, 9\}$, $A \cap B = \{1, 3\}$.
  2. $n(A \cup B) = 5 + 5 - 2 = 8$.

$n(A \cup B) = 8$

Problem 2

With $U$, $A$ and $B$ as in Problem 1, find $\overline{A} \cap \overline{B}$.

Uses: De Morgan's Laws, Complement Set

Show hint

De Morgan: $\overline{A} \cap \overline{B} = \overline{A \cup B}$. Type how many elements it has.

Show solution
  1. $\overline{A} \cap \overline{B} = \overline{A \cup B}$.
  2. $A \cup B = \{1, 2, 3, 4, 5, 6, 7, 9\}$, so its complement is $\{8, 10\}$.

$\overline{A} \cap \overline{B} = \{8, 10\}$ (2 elements)

Problem 3

For real $x$: is $x^2 = 4$ a necessary condition, a sufficient condition, both, or neither, for $x = 2$?

Uses: Necessary and Sufficient Condition

Show hint

Check both directions: does $x = 2 \Rightarrow x^2 = 4$ hold? Does $x^2 = 4 \Rightarrow x = 2$ hold?

Show solution
  1. $x = 2 \Rightarrow x^2 = 4$ is true.
  2. $x^2 = 4 \Rightarrow x = 2$ is false: $x = -2$ is a counterexample.
  3. So $x = 2$ is sufficient for $x^2 = 4$, and $x^2 = 4$ is necessary for $x = 2$.

Necessary, but not sufficient

Problem 4

Write the negation of “$x > 0$ and $y > 0$”, and the contrapositive of “if $x + y > 0$, then $x > 0$ or $y > 0$”.

Uses: Negation of And and Or, Converse, Contrapositive and Inverse

Show hint

Negation turns “and” into “or” and $>$ into $\le$. The contrapositive of “if $p$ then $q$” is “if not $q$, then not $p$”.

Show solution
  1. Negation: “$x \le 0$ or $y \le 0$”.
  2. Not ($x > 0$ or $y > 0$) is “$x \le 0$ and $y \le 0$”; not ($x + y > 0$) is “$x + y \le 0$”.
  3. Contrapositive: “if $x \le 0$ and $y \le 0$, then $x + y \le 0$”. It is clearly true, so the original statement is true too.

Negation: $x \le 0$ or $y \le 0$. Contrapositive: if $x \le 0$ and $y \le 0$, then $x + y \le 0$ (true)

Problem 5

Prove: for an integer $n$, if $n^2$ is a multiple of $3$, then $n$ is a multiple of $3$.

Uses: Proof by Contrapositive

Show hint

Prove the contrapositive instead: if $n$ is not a multiple of $3$, then $n^2$ is not. Write $n = 3k + 1$ or $n = 3k + 2$.

Show solution
  1. Contrapositive: if $n$ is not a multiple of $3$, then $n^2$ is not a multiple of $3$.
  2. $n = 3k + 1$: $n^2 = 9k^2 + 6k + 1 = 3(3k^2 + 2k) + 1$, remainder $1$.
  3. $n = 3k + 2$: $n^2 = 9k^2 + 12k + 4 = 3(3k^2 + 4k + 1) + 1$, remainder $1$.
  4. Either way $n^2$ is not a multiple of $3$. The contrapositive is true, so the original statement is true.

Proved (by contrapositive)

This is the key step in the classic proof that $\sqrt{3}$ is irrational.
