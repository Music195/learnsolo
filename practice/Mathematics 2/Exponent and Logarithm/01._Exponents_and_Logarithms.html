Exponents and Logarithms

Five problems on exponent laws, logarithm rules, change of base, and a log equation. Try each one first. Open the hint if you are stuck, then compare with the full solution.

Problem 1

Evaluate $8^{\frac{2}{3}} \times 4^{-\frac{1}{2}}$.

Uses: Exponent Laws, Radical Properties

Show hint

Write both as powers of $2$: $8 = 2^3$ and $4 = 2^2$.

Show solution
  1. $8^{\frac{2}{3}} = (2^3)^{\frac{2}{3}} = 2^2 = 4$.
  2. $4^{-\frac{1}{2}} = (2^2)^{-\frac{1}{2}} = 2^{-1} = \dfrac{1}{2}$.
  3. $4 \times \dfrac{1}{2} = 2$.

$2$

Problem 2

Evaluate $\log_2 24 - \log_2 3$.

Uses: Logarithm Properties

Show hint

$\log_a M - \log_a N = \log_a \dfrac{M}{N}$.

Show solution
  1. $\log_2 \dfrac{24}{3} = \log_2 8 = 3$.

$3$

Problem 3

Evaluate $\log_2 9 \cdot \log_3 8$.

Uses: Logarithm Change of Base

Show hint

Change $\log_3 8$ to base $2$: $\log_3 8 = \dfrac{\log_2 8}{\log_2 3}$.

Show solution
  1. $\log_2 9 = 2\log_2 3$ and $\log_3 8 = \dfrac{\log_2 8}{\log_2 3} = \dfrac{3}{\log_2 3}$.
  2. Product: $2\log_2 3 \cdot \dfrac{3}{\log_2 3} = 6$.

$6$

Problem 4

Solve $\log_2 (x - 1) + \log_2 (x + 1) = 3$.

Uses: Logarithm Properties, Logarithm Function Properties

Show hint

First write down the condition for the logs to exist. Then combine: $\log_2 (x - 1)(x + 1) = \log_2 8$.

Show solution
  1. The logs need $x - 1 > 0$ and $x + 1 > 0$, so $x > 1$.
  2. $\log_2 (x - 1)(x + 1) = 3$ gives $x^2 - 1 = 8$, so $x = \pm 3$.
  3. Only $x = 3$ satisfies $x > 1$.

$x = 3$

Problem 5

Find the minimum value of $y = (\log_2 x)^2 - 4\log_2 x + 5$ for $1 \le x \le 8$, and the $x$ that gives it.

Uses: Logarithm Function Graph, Logarithm Function Properties

Show hint

Put $t = \log_2 x$. Find the range of $t$ first, then it is a quadratic in $t$.

Show solution
  1. $t = \log_2 x$ increases with $x$, so $1 \le x \le 8$ means $0 \le t \le 3$.
  2. $y = t^2 - 4t + 5 = (t - 2)^2 + 1$.
  3. $t = 2$ is in $0 \le t \le 3$, so the minimum is $1$, at $t = 2$, that is $x = 2^2 = 4$.

Minimum $1$, at $x = 4$
